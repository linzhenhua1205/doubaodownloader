# Skill Security Vetter

在安装任何Skill前，先进行安全审查。

## 安全风险警示

Skill生态存在与浏览器插件类似的安全问题：
- **恶意Skill**可能读取环境变量、获取API Key、访问本地文件、执行系统命令
- 已知漏洞如CVE-2026-25253：恶意Skill可窃取OpenAI Key、Claude Key、云服务器Key

## 审查流程

### 步骤1：来源验证

- 检查Skill来源是否可信
- 验证发布者身份
- 查看下载量和评分（使用100/3原则）

### 步骤2：代码审查

**网络请求检查：**
- 是否有未授权的外部API调用
- 是否向未知域名发送数据
- 是否有数据泄露风险

**文件访问检查：**
- 读写范围是否合理
- 是否访问敏感目录（如~/.ssh, ~/.aws）
- 是否有越权访问行为

**Shell命令检查：**
- 是否执行危险命令（rm, chmod, curl | sh）
- 是否有命令注入风险
- 是否有用户可控输入传递给shell

**环境变量检查：**
- 是否读取敏感环境变量（API_KEY, TOKEN, SECRET）
- 是否硬编码密钥
- 是否有密钥泄露风险

### 步骤3：权限评估

| 权限类型 | 风险等级 | 审查重点 |
|---------|---------|---------|
| 网络请求 | 中 | 请求目标、数据传输加密 |
| 文件读写 | 高 | 读写范围、敏感文件 |
| Shell执行 | 高 | 命令内容、参数来源 |
| 环境变量 | 高 | 读取的变量名称 |
| 进程管理 | 高 | 进程创建、权限提升 |

### 步骤4：安全评级

根据审查结果给出安全评级：

| 评级 | 含义 | 处理方式 |
|------|------|---------|
| SAFE | 安全 | 可正常使用 |
| CAUTION | 警告 | 谨慎使用，限制权限 |
| DANGEROUS | 危险 | 直接删除，禁止使用 |

## 100/3原则

只安装满足以下条件的Skill：
- **下载量 > 100**（社区认可）
- **发布时间 > 3个月**（稳定成熟）

```
安全审查清单
├── 来源验证
│   ├── [ ] 发布者身份可验证
│   ├── [ ] 下载量 > 100
│   └── [ ] 发布时间 > 3个月
├── 代码审查
│   ├── [ ] 无恶意网络请求
│   ├── [ ] 文件访问范围合理
│   ├── [ ] 无危险shell命令
│   └── [ ] 无密钥硬编码
├── 权限评估
│   ├── [ ] 权限最小化
│   ├── [ ] 无越权访问
│   └── [ ] 无敏感数据处理
└── 安全评级
    └── [ ] SAFE / CAUTION / DANGEROUS
```

## 使用建议

1. 安装Skill前必做安全审查
2. 使用官方安全扫描工具
3. 定期更新和审查已安装的Skills
4. 对CAUTION级别的Skill进行权限隔离
5. 遇到安全问题及时报告

## 产出

- 安全审查报告
- 风险等级评估
- 问题清单和修复建议
- 使用限制和注意事项
