# Skill Evolver

**"Evolution is not optional. Adapt or die."**

让你的AI助手越用越聪明——自动识别短板、优化策略、迭代进化。

## 核心机制

### 1. 自动日志分析

扫描会话记录和运行时日志，识别：
- 错误模式和崩溃
- 性能瓶颈和低效操作
- 用户反馈和满意度
- Skill使用频率和成功率

### 2. 自我修复与优化

基于分析结果，自动：
- 修复运行时错误
- 优化Skill配置和参数
- 改进提示词和指令
- 提升执行效率

### 3. GEP基因组进化协议

将进化过程标准化为可复用资产：

**Gene（基因）**：解决问题的核心思路
- 触发条件
- 修改方案
- 验证命令

**Capsule（胶囊）**：相关基因的组合包
- 错误恢复胶囊：超时处理、重试策略、降级方案
- 优化胶囊：性能优化、代码精简、效率提升

**Evolution Event（进化事件）**：完整的进化审计日志
- 触发信号
- 选中的基因
- 验证结果
- 应用效果

## 进化策略

| 策略 | 权重分配 | 适用场景 |
|------|---------|---------|
| balanced | 50%创新 + 30%优化 + 20%修复 | 日常运行默认 |
| innovate | 80%创新 | 系统稳定时加速探索 |
| harden | 40%修复 | 刚做完大改动，需要收敛 |
| repair-only | 100%修复 | 紧急修复模式 |

## 工作流程

```
┌─────────────────────────────────────────────────────────┐
│                    进化循环                              │
├─────────────────────────────────────────────────────────┤
│  1. 扫描阶段                                             │
│     └── 分析会话日志、识别问题模式                         │
├─────────────────────────────────────────────────────────┤
│  2. 匹配阶段                                             │
│     └── 从基因库匹配最合适的进化基因                       │
├─────────────────────────────────────────────────────────┤
│  3. 验证阶段                                             │
│     └── 执行验证命令，确认安全和有效性                     │
├─────────────────────────────────────────────────────────┤
│  4. 应用阶段                                             │
│     └── 生成优化方案，应用到Skill                        │
├─────────────────────────────────────────────────────────┤
│  5. 记录阶段                                             │
│     └── 记录进化事件，更新基因库                          │
└─────────────────────────────────────────────────────────┘
```

## 运行模式

### 自动模式（Mad Dog Mode）

```bash
/evolve
```

完全自动化执行，无需人工干预。

### 审查模式（Human-in-the-Loop）

```bash
/evolve --review
```

每一步进化前暂停，等待人工确认。

### 循环模式（Continuous Loop）

```bash
/evolve --loop
```

持续运行进化循环，适合后台进程。

## 安全机制

- **无自动代码修改**：只生成指导性提示词，不直接执行代码修改
- **可审计日志**：所有进化事件都有完整记录
- **回滚机制**：支持git stash/hard reset回滚失败的进化
- **权限控制**：可配置是否允许修改Evolver自身代码

## 配置参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| EVOLVE_STRATEGY | balanced | 进化策略：balanced/innovate/harden/repair-only |
| EVOLVER_ROLLBACK_MODE | hard | 回滚策略：hard/stash/none |
| EVOLVER_LLM_REVIEW | 0 | 是否启用LLM二次审查 |
| EVOLVER_AUTO_ISSUE | 0 | 是否自动创建GitHub Issue |

## 产出

- 进化事件记录
- 优化后的Skill配置
- 基因库更新
- 进化报告和效果评估

## 使用建议

1. 定期运行进化引擎
2. 首次使用建议review模式
3. 记录每次进化的效果
4. 根据实际情况调整进化策略
5. 定期清理无效基因
