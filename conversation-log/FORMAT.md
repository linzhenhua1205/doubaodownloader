# 📝 对话记录格式规范

> 目的：保存完整的对话过程，包括用户问题、助手思考、工具调用、回复内容
> 位置：`~/cow/conversation-log/YYYY-MM-DD.md`

## 文件结构

```
# 📝 对话记录: YYYY-MM-DD

## 回合 N - HH:MM

### 🗣️ 用户
[用户原始输入原文]

### 💭 思考
[助手推理过程、分析逻辑、决策链路]

### 🛠️ 工具调用
| # | 工具 | 参数 | 结果概要 |
|:-:|:-----|:------|:---------|
| 1 | tool_name | key=value, ... | 返回摘要 |
| 2 | ... | ... | ... |

### 💬 回复
[助手的完整回复内容]
```

## 规则

1. **每个用户输入作为一个回合（回合）**
2. 工具调用表格记录：
   - 工具名
   - 核心参数（敏感信息脱敏）
   - 返回结果的关键数据摘要
3. 思考过程保留关键决策点（为什么选这个工具、为什么这样分析）
4. 表格内容保持可读性，过长的参数/结果可省略并标注`[截断]`
5. 每天一个文件，跨天的对话按日期拆分

## 数据库历史会话导出

`db-sessions/` 目录下存放从 `~/cow/memory/long-term/index.db` 导出的**历史会话记录**（2026-05-09 起），按会话拆分：

- **`db-sessions/index.md`** — 所有会话的索引表格（104个会话）
- **`db-sessions/YYYY-MM-DD-title.md`** — 每个会话的文件

涵盖来源：
- **web** — CowAgent Web 控制台交互记录
- **feishu** — 飞书渠道交互记录
- **scheduler** — 定时调度任务执行记录

导出方式：从 SQLite 数据库 `conversation_store` 的 `sessions` + `messages` 表提取，按 FORMART 格式渲染。
