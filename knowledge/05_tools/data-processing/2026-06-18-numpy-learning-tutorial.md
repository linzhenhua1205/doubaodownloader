## 内容结构

完整覆盖 NumPy 基础操作的 8 个章节，含整页代码示例和 10 道综合练习题：

| 章节 | 内容 |
|:-----|:------|
| 1. 出现原因 | Python list vs NumPy 性能对比（100万元素平方求和，0.2591s vs 0.0109s） |
| 2. ndarray 核心特性 | 多维性·同质性（类型自动提升规则）·高效性（连续内存+向量化） |
| 3. ndarray 创建 | 6 大类：基础构造·预定义填充·数值范围·特殊矩阵·随机数组·高级构造 |
| 4. 数据类型 | int8~int64/float16~float64/complex128 等完整类型表 + 类型代码 |
| 5. 索引与切片 | 基本索引·start:stop:step·slice()·布尔条件·⚠️ 内存共享特性 |
| 6. 基本运算 | 四则运算（元素级）·矩阵乘法（dot/@）·**广播机制**（3条规则+案例） |
| 7. 常见函数 | 数学（sqrt/exp/log/sin/abs/power/round/ceil/floor/rint/isnan）·统计（sum/mean/median/std/var/min/max/argmin/argmax）·比较（greater/less/equal/logical_and/or/not/any/all/where/select）·排序（sort/argsort）·去重（unique/in1d）·其他（concatenate/split/reshape/flatten） |
| 8. 综合练习 | 10 道实战题：温度分析·成绩统计·矩阵运算·随机数据·数组变形·布尔索引·统计应用·拼接·唯一值·缺失值处理 |

## 亮点

- **广播机制的三条规则**用案例逐步拆解，比官方文档更易理解
- **随机种子澄清**：`seed(42)` 不是每次都返回同一个值，而是从 42 号位置开始按顺序输出伪随机序列——常见的错误认知纠正
- **练习题量充足**（10 道），覆盖了基础到中等难度，适合自测
