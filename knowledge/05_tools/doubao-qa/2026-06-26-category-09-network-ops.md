## 一、网络架构（10个问题）

### 1.1 核心技术

**高速互联**：

- PCIe 4.0/5.0/6.0
- InfiniBand
- RDMA

**网络技术**：

- RoCE
- NVLink
- 液冷网络

### 1.2 数据中心网络

**网络设计要点**：

- 三层架构（核心层、汇聚层、接入层）
- 高带宽、低延迟
- 可靠性、容错性

## 二、运维自动化（10个问题）

### 2.1 AIOps落地

**核心能力**：

- 异常检测
- 根因分析
- 自动报警
- 自动修复

**实施路径**：

```text
基础监控 -> 智能告警 -> 根因分析 -> 自动修复 -> 持续优化
```

### 2.2 知识库建设

**运维知识图谱**：

- 故障模式
- 处置方案
- 规则关联

**自动化运维**：

- 告警自动归类
- 报案自动生成
- 方案自动推荐
- 回答自动填写
