## 一、平台概述

**Dify** 是全球领先的开源 LLM 应用开发平台（GitHub 89K+ Stars），提供从 Prompt 编排、RAG 知识库、Agent 智能体到工作流编排的全链路能力。

| 属性 | 详情 |
|:-----|:------|
| 创立时间 | 2023 年 3 月 |
| 开源协议 | Apache License 2.0（有限商业许可） |
| 技术栈 | 后端 Python/Flask/PostgreSQL，前端 Next.js |
| 发版周期 | 平均每周一次 |
| 部署方式 | Docker、Helm（Kubernetes） |

## 二、核心功能全景

### 1. 应用类型

| 类型 | 说明 | 适用场景 |
|:-----|:------|:---------|
| **对话型应用** | 基于对话的 AI 助手 | 客服、问答、个人助理 |
| **文本生成应用** | 单次生成完成任务 | 翻译、摘要、文案 |
| **Agent** | 调用工具/API 完成任务 | 多步骤自动执行 |
| **工作流（Workflow）** | 可视化流程编排 | 复杂业务自动化 |

### 2. 模型支持

- **商业模型**：OpenAI / Anthropic / Google / MiniMax 等 10+ 家
- **MaaS 供应商**：Hugging Face / Replicate / AWS Bedrock 等 7 家
- **本地模型**：Ollama / Xinference / LocalAI 等 6 家
- **自定义模型**：兼容 OpenAI API 标准的无限家

### 3. RAG 知识库系统

Dify 知识库是平台最核心能力之一，提供从数据接入、分段解析、向量化到检索优化完整的 Pipeline。

**数据处理流程**：

```text
文档上传(多格式) -> 分段策略 -> 向量化嵌入 -> 索引存储 -> 检索优化
```

**支持的索引方式**：

| 索引类型 | 说明 |
|:---------|:------|
| 关键词索引 | BM25 全文检索 |
| 文本向量索引 | 语义相似度检索 |
| LLM 辅助问题-分段 | 用 LLM 生成 Q&A 对索引 |

**检索方式**：

| 检索类型 | 说明 |
|:---------|:------|
| 关键词搜索 | 精确匹配 |
| 文本相似度 | 向量检索 |
| 混合检索 | 向量(0.7) + 关键词(0.3) |
| 多路召回 | 多维度检索 + RRF 融合 |

**父子分段策略**：

- **父段**：4000 token，覆盖文档宏观结构
- **子段**：1000 token，聚焦技术细节
- 适用于 Excel 等结构化数据处理

| 优化手段 | 说明 |
|:---------|:------|
| Rerank 模型 | 对候选段重排序，提升命中精度 |
| Unstructured ETL | 集成第三方解析器，处理复杂格式 |
| Notion/网页同步 | 外部知识源自动同步 |

### 4. Agentic Workflow

可视化流程编辑器，支持节点：

| 节点类型 | 功能 |
|:---------|:------|
| LLM | 调用大模型生成内容 |
| 知识库检索 | 从知识库中召回相关片段 |
| 问题分类 | 根据输入自动路由分支 |
| 条件分支 | IF/ELSE 逻辑判断 |
| 代码执行 | Python/JS 代码执行 |
| 模板转换 | 内容格式转换 |
| HTTP 请求 | 调用外部 API |

### 5. Prompt 编排

提供三种模式：

| 模式 | 适用场景 |
|:-----|:---------|
| 简易模式 | 快速构建，单轮 Prompt |
| Assistant 模式 | 上下文管理，多轮对话 |
| Flow 模式 | 复杂业务逻辑，工作流编排 |

### 6. 其他能力

| 功能 | 说明 |
|:-----|:------|
| 日志与标注 | 记录对话日志，支持标注与微调数据导出 |
| 内容审查 | OpenAI Moderation / 外部 API |
| 团队协同 | 工作空间、多成员、权限管理 |
| RESTful API | 全功能 API 覆盖 |
| 向量数据库 | Qdrant/Milvus/Weaviate/Pgvector 等 20+ |

## 三、Dify 知识库场景：证据链问答

Dify 支持"证据链"推理模式，从检索到的知识片段中构建结构化回答：

### 核心流程

```text
用户问题 -> 知识检索(Top-K) -> 多文档交叉验证 -> 证据链构建 -> 结构化回答
                            |
                            +- 时间线印证
                            +- 因果链推导
                            +- 数据状态差异分析
```

### 关键配置建议

| 参数 | 推荐值 | 说明 |
|:-----|:-------|:------|
| 混合检索权重 | 向量 0.7 + 关键词 0.3 | 通用场景均衡配置 |
| Top-K | 3 | 平衡信息量与 Token 消耗 |
| 相似度阈值 | ≥ 0.65 | 低于此值建议标注"未找到相关知识" |
| Rerank 模型 | 启用 | 显著提升命中率 |

## 五、知识库 Prompt 最佳实践

### 通用 Prompt 模板

```markdown
你是一位严格依赖 Dify 知识库的专家助手，基于提供的知识内容回答问题。
当前知识库文件：{{知识库名称}}（版本：{{更新日期}}）
用户问题：{{用户输入}}

要求：
1. 仅使用知识库内容，未收录信息输出"未找到相关知识"
2. 按三级输出：核心结论 ≤3 点 → 技术细节分点 → 来源标注
3. 关键术语加粗，来源文档名称需完整
4. 涉及界面截图或流程图时，在相关文本后附加图片
```

### 证据链 Prompt 示例

```markdown
针对场景推理类问题，需从检索到的知识库信息中构建证据链：
1. 时间线印证：关联多个时间点的数据状态差异
2. 因果链推导：连接"触发条件→执行过程→结果状态"
3. 优先级：检索结果 > 给定上下文 > "未找到相关知识"

输出格式：
- 核心结论（加粗关键数据）
- 技术细节（标注检索依据）
- 图表说明（图片紧随相关文本）
- 来源标注（所有结论关联具体文档）
```
