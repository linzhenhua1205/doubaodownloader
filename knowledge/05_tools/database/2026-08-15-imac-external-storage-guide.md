## 一、结论概要

23 款 iMac 丐版（基础款）**外接存储的核心约束是接口带宽瓶颈**：理论 40Gbps，实际约 32Gbps（3700MB/s），盲目上 PCIe 4.0 高速盘是性能浪费：

| 维度 | 要点 |
|:-----|:-----|
| 接口理论值 | 40Gbps（雷电/USB4） |
| 实际可用 | 约 32Gbps ≈ 3700MB/s（视频功能占带宽） |
| SSD 选购上限 | 读写 ≤4000MB/s，避免浪费 |
| 最佳匹配 | PCIe 3.0 盘（如海力士 P31：读 3500MB/s） |
| 推荐方案 | 绿联 USB4 硬盘盒（599 元）+ 三星 990 EVO（629 元）≈1228 元 |

**核心结论**：
1. **带宽决定选型**：iMac 实际只能跑 ~3700MB/s，PCIe 4.0 盘（7000MB/s+）性能溢出
2. **PCIe 3.0 是甜点**：海力士 P31（3500MB/s）完美匹配，价格还低
3. **首选硬盘盒方案**：可升级、发挥雷电性能，优于移动固态（速度 500-800MB/s 反而慢）
4. **内存不可升级是更大坑**：原厂 8GB 易卡顿，强烈建议官网定制 16-32GB

| 指标 | 数值 | 说明 |
|:-----|:-----|:-----|
| 接口理论带宽 | 40Gbps | 雷电/USB4 |
| 实际可用带宽 | 约 32Gbps | 视频功能占用后 |
| 实际换算 | 约 3700MB/s | 32Gbps / 8 |
| SSD 选购上限 | ≤4000MB/s | 超过即性能浪费 |

> 通过 USB4 数据线连接雷电接口，可支持 USB 3.2 20Gb/s 速率（约 2500MB/s）。

## 六、最终推荐与避坑

### 6.1 最终推荐

| 项目 | 选择 | 价格 |
|:-----|:-----|:----:|
| 硬盘盒 | 绿联 USB4 | 599 元 |
| SSD | 三星 990 EVO | 629 元 |
| **合计** | — | **1228 元** |

- 预期性能：实测 2500-3000MB/s，温度 50-70℃
- 优势：后期可升级更大容量，发挥雷电接口性能

### 6.2 避坑警告

| 坑 | 说明 |
|:---|:-----|
| 原厂 8GB 内存 | 开 4 个网页 + 基础软件即卡顿 |
| 内存不可升级 | 强烈建议官网定制 16-32GB |
| PCIe 4.0 盘 | 性能溢出，浪费预算 |
| 移动固态 | 速度 500-800MB/s，不适合主力盘 |
