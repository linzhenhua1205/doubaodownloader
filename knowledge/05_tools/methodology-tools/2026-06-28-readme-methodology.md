## 核心要点

### 方法论层面

- **深度研究流程**：信息聚合→逻辑拆解→推理论证→方案沉淀→迭代复盘
- **SPC思维**：过程控制、数据驱动、反馈调节的系统方法论
- **第一性原理**：基于客观事实、底层规律独立研判，不默认输入正确

### 工具层面

- **低代码平台**：可视化编排 + 预制组件 + 自动生成
- **Agent框架**：模型层+工具层+编排层三层架构
- **爬虫框架**：Scrapy全流程能力 vs BeautifulSoup仅解析
