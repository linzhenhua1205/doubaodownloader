## §0 执行摘要

**"在同一个岗位（或岗位域）坚持20年以上"是极小概率事件——不是因为它难，而是因为它需要个人、组织、行业、家庭、制度、偶然性六个维度的条件同时成立。任一维度出现断裂，长期主义即告瓦解。人员流动不是"谁做错了什么"，而是多维约束系统失衡的表征。**

1. **达成率现实**：按五年分段存活率模型，20年仍在岗者仅占入行群体的 3-5%，其中达到行业公认专家水平者不足 1-3% [来源: 内部 04_person/career/2026-07-22-career-divergence-20-year-expert-myth.md]。长期主义是统计学上的"异常值"，不是常态。
2. **分析框架（推-拉-滞模型）**：人员流动 = **组织推力**（岗位/薪酬/管理/文化/变动） + **外部拉力**（市场机会/更好选择/行业诱惑） + **个人自推力**（动机衰减/能力错配/健康/倦怠）；留下 = **组织拉力**（成长/公平/情感/利益绑定） + **个人定力**（内在动机复利/沉没资产/路径依赖） + **环境稳态**（行业长坡/制度保护/家庭支持）。双方都是多维合力，任何一方失衡即触发流动。
3. **六维流失原因清单（核心章节）**：个人内在 8 类、组织治理 12 类、行业市场 8 类、家庭生活 7 类、制度社会 6 类、偶发事件 5 类——合计 46 类流失原因，按"可控性×作用方向"归位。
4. **动态权重**：0-3 年个人维度主导（适配性筛选）、3-7 年个人×组织各半（能力天花板+成长机会）、7-12 年组织主导（晋升/薪酬/管理）、12-18 年结构主导（机会锁死/家庭/周期，个体可控性仅 ~20%）、18 年+ 行业×制度主导（技术变迁/退休安排）。
5. **关键结论**：对组织——20年人才保留无法靠单一手段（涨薪或情怀）达成，必须建立"六维支撑系统"；对个人——长期主义的主动权不在"坚持"本身，而在**提前构建可迁移的复利资产与反脆弱结构**，让"留下"成为主动选择而非被动困守。

## §1 问题定义与第一性原理

### 1.1 什么是"长期主义"在此语境下的真实含义

用户所指的长期主义，不是抽象的价值观，而是**具体事实**：一个人在同一个岗位（或一个窄幅岗位域）内持续工作 20 年以上，且保持产出质量与成长性。

拆解为三个可验证的命题：

| 命题 | 现实检验 |
|:-----|:---------|
| "在同一领域持续工作 20 年" | 20 年仍在岗者占入行群体 3-5%，中国一线城市约 3-5%，二线以下约 5-8% [来源: 内部 career-divergence §2.3] |
| "保持产出质量" | 能力曲线在 7-12 年进入平台期，之后大多数人不再有质的跃升——"20年经验"常是"1年经验重复20年" [来源: 内部 career-divergence §1.1] |
| "保持成长性" | 12-18 年阶段 60-70% 的人陷入停滞/转型/淘汰，不再具备深度成长机会 [来源: 内部 career-divergence §6.3] |

**第一性原理**：长期主义 = 一个多变量系统的稳态解。系统变量包括个人状态、组织状态、环境状态三大类，任一变量在 20 年时间尺度上发生"非弹性断裂"（不可逆、不可修复的偏离），稳态即被打破，人员流动发生。

### 1.2 为什么"长期"是稀缺的：时间尺度的放大效应

20 年不是 20 个 1 年相加，而是**概率的连乘**：

```text
P(stay 20yr) = P(no churn yr1) x P(no churn yr2) x ... x P(no churn yr20)

If annual retention = 90% (annual churn 10%):
  survival after 20yr = 0.9^20 ~= 12%
If annual retention = 85% (annual churn 15%):
  survival after 20yr = 0.85^20 ~= 3.9%  <-- matches empirical data
```

**推论**：长期主义的稀缺不是"某一年出了问题"，而是**每年都有 10-15% 的流失概率、且这些概率在 20 年内从未同时归零**。这解释了为什么 20 年留存率必然落在个位数——不需要任何单一"致命原因"，常态化的多因累积即可。

### 1.3 分析框架：推-拉-滞模型（Push-Pull-Stay）

将人员流动的全部原因组织为一个力学模型：

```text
                    EXTERNAL PULL
                    + market offers / better pay / industry lure
                    + geography shift / lifestyle switch
                         |
                         v
+------------------+  +--+----------------------------+  +------------------+
|  ORGANIZATION    |  |      THE PERSON (DECIDER)      |  |   PERSONAL DRIVE |
|  PUSH            |->|  stay = f(push, pull, stay-f)  |<-|  self-push       |
|  career ceiling  |  |  psych contract / commitment / |  |  motivation loss |
|  pay failure     |  |  sunk cost                     |  |  skill mismatch  |
|  mgmt conflict   |  |  STAY FORCES: affective /      |  |  burnout / health|
|  org churn       |  |  continuance / normative       |  |  value shift     |
|  culture clash   |  |  + side-bet / compounding      |  |  self re-framing |
|  layoff / margin |  |  + path dependence             |  |                   |
+------------------+  +---------------------------------+  +------------------+
                         ^
                         |
                    ENVIRONMENTAL STABILITY
                    + industry long-runway / institution / family support
```

> 中文对照：EXTERNAL PULL=外部拉力；ORGANIZATION PUSH=组织推力；PERSONAL DRIVE=个人自推力；STAY FORCES=定力（情感/持续/规范承诺、单方投入、复利资产、路径依赖）；ENVIRONMENTAL STABILITY=环境稳态（行业长坡/制度保护/家庭支持）。

**模型要点**：
1. **流失是合力结果**：多数离职不是单一原因，而是推力累积 + 拉力出现 + 定力衰减三者叠加的临界点突破。
2. **推力 vs 拉力的不对称性**：推力是"慢性压力"（可累积、可忍受、可拖延），拉力是"急性触发"（一个 offer、一次家庭变故、一次被裁通知）。多数离职表面由拉力/事件触发，深层是推力长期累积的结果 [来源: 外部 MBA智库-员工流失：绝大多数人不喜欢变化，若无特别原因不会主动换工作——流失总是有原因的]。
3. **定力是缓冲器**：组织承诺（情感/持续/规范三因素，Meyer & Allen 1991）与单方投入（Becker 1960 side-bet：随年限积累的退休金、管理权等"附属利益"）构成留下决策的惯性 [来源: 外部 MBA智库-组织承诺]。定力越强，需要越大的推力+拉力合力才能触发流动。

### 维度一：个人内在维度（8 类）——"我不行了"或"我不想干了"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 1.1 | **内在动机衰减** | 岗位失去兴趣/意义感，外部激励无法替代内在驱动；自我决定理论：自主/胜任/归属三基本心理需要长期不满足则内在动机衰减 [来源: 外部 MBA智库-自我决定理论（Deci & Ryan：自主需要满足对内在动机影响最大）] | 做了 10 年重复性工作，热情耗尽 |
| 1.2 | **能力天花板** | 技能与岗位需求错配：要么岗位需求超过能力（不胜任被淘汰），要么能力超过岗位需求（大材小用留不住） | 资深工程师被安排做初级执行 |
| 1.3 | **职业倦怠（burnout）** | Freudenberger(1974) 提出；MBI 三维度：情感衰竭+去人格化+低成就感；中国职场人 70% 轻微倦怠、13% 重度倦怠 [来源: 外部 MBA智库-职业倦怠] | 长期 996/高责任岗位 |
| 1.4 | **健康因素** | 身体或心理疾病使岗位无法继续承担（职业病、抑郁焦虑、重大疾病） | 腰椎/颈椎/心理崩溃退出技术岗 |
| 1.5 | **价值观转变** | 人生阶段变化导致价值排序重排：从"事业成就"转向"家庭/健康/自由"；流失总趋向个人利益与个人目标（追求物质型/环境型/稳定型）[来源: 外部 MBA智库-员工流失：趋利性] | 35 岁后追求生活平衡，主动降级 |
| 1.6 | **自我认知重塑** | 职业自我概念（career self-concept）更新：发现自己更适合其他赛道 | 技术人发现管理天赋/创业基因 |
| 1.7 | **学习能力退化** | 新知识吸收速度跟不上岗位演进要求，主动或被动退场；而年龄越大流动损失越多，本应更稳定——退化后反而被迫流动 [来源: 外部 MBA智库-人力资源流动：年龄越大工作年限越长，流动可能性相对越小] | 45 岁面对 AI 工具链系统性落后 |
| 1.8 | **风险偏好变化** | 中年危机两种极端：要么过度求稳（接受停滞），要么破釜沉舟（赌一把离开） | 40 岁裸辞创业/接受养老岗位 |

**机制洞察**：个人维度流失的共性——**不是能力问题就是动力问题，且二者会互相强化**（能力不足→挫败→动力衰减→更学不进→更不足）。这是 0-7 年阶段的主流失原因，占比约 55% 流失中的主体 [来源: 内部 career-divergence §3.1 55255法则]。

### 维度二：组织治理维度（12 类）——"组织不让我留"或"组织不值得留"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 2.1 | **薪酬激励失效** | 薪酬低于市场水平、分配不公、涨幅停滞；薪酬是离职决策首要因素 [来源: 外部 MBA智库-员工流失；重庆IT跳槽调查：78%对薪金待遇不满、13%对经营管理制度不满、9%考虑前途] | 多年不加薪，同岗市场价高出 30%+ |
| 2.2 | **晋升天花板** | 组织金字塔岗位萎缩：越往上岗位越少，能力足够但无空位 [来源: 内部 career-divergence §8.1] | 部门只有一个总监位，等待者数十人 |
| 2.3 | **管理者因素** | 领导风格冲突、微管理、信任缺失、功劳归上/锅归下；领导风格/管理方式/组织精神直接影响人力资源流动 [来源: 外部 MBA智库-人力资源流动：工作环境因素] | 空降领导推倒重来，老员工集体离心 |
| 2.4 | **组织文化冲突** | 价值观不匹配、人际关系紧张、办公室政治、内卷文化；缺乏良好企业文化与氛围是流失重要原因 [来源: 外部 MBA智库-员工流失] | 技术文化 vs 关系文化冲突 |
| 2.5 | **组织变动频繁** | reorg/领导更换=验收函数更换：在途工作反复被推翻，安全感崩塌 [来源: 内部 enterprise-mgmt/2026-08-27-org-churn-work-destruction-defense §0] | 一年两三次架构调整 |
| 2.6 | **培训投入不足** | 能力发展无人负责，组织"购买即用"不承担培养成本；不注重员工发展与培训是流失原因之一 [来源: 内部 career-divergence §10.1；外部 MBA智库-员工流失] | 骨干自费学习，组织无成长体系 |
| 2.7 | **绩效评价不公** | 考核主观、努力无回报、评价周期与长期价值错配；报酬/绩效/选拔"三公平"缺失直接打击留任意愿 [来源: 内部 career-divergence §10.3；外部 MBA智库-员工流失 对策节] | 长期价值贡献被短期 KPI 抹杀 |
| 2.8 | **工作设计固化** | 岗位内容固化、挑战性消失、职业高原（career plateau）：能力不再被使用即开始退化 | 维护型岗位做 5 年无新挑战 |
| 2.9 | **组织战略性淘汰** | 裁员/调岗/边缘化：成本性淘汰（太贵了）+ 战略淘汰（领域被砍）；能力性淘汰仅占淘汰的 ~20%，80% 是结构性淘汰 [来源: 内部 career-divergence §9.2E] | 35-42 岁高薪中层优先被优化 |
| 2.10 | **工作强度失衡** | 加班文化、工作-生活冲突，长期过载不可持续 | 996 文化下家庭崩溃 |
| 2.11 | **保障与安全缺失** | 合同不稳定、劳动权益无保障、随时可被替换的恐惧 | 劳务派遣/外包身份长期化 |
| 2.12 | **组织愿景漂移** | 公司方向与个人职业愿景错位：组织转型（如硬件转软件）使个人积累贬值 | 公司 All in AI，传统硬件专家被边缘 |

**机制洞察**：组织维度是 3-18 年阶段的主导推力。其特殊性在于——**组织维度的大多数原因不是"组织做错了什么"，而是组织利益与个人发展的结构性矛盾**：组织最优解是"在最佳使用年限内榨取最大产出+标准化可替代"，个人最优解是"持续投入培养深度"，二者天然冲突 [来源: 内部 career-divergence §10.1]。这意味着即使组织"什么都没做错"，流失仍会发生——这是长期主义最难跨越的结构性障碍。

### 维度三：行业与市场维度（8 类）——"赛道没了"或"赛道不香了"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 3.1 | **技术范式变迁** | 技能折旧：岗位所依赖的技术栈被替代，个人资产变负债 [来源: 内部 career-divergence §8.5 技能路径依赖] | 模拟电路→数字电路→软件定义 |
| 3.2 | **经济周期下行** | 行业性裁员：下行期优先裁撤高成本老员工，中层被定向打击；经济低速增长时人力资源流出比率提高 [来源: 内部 career-divergence §8.2；外部 MBA智库-人力资源流动：环境因素] | 2023-2026 互联网/硬件结构性调整 |
| 3.3 | **产业结构变迁** | 夕阳产业衰落、新兴产业崛起，岗位域整体萎缩；产业升级直接改变人力资源需求 [来源: 外部 MBA智库-人力资源流动：科技发展/产业结构变化影响流动] | 教培/房地产/传统零售 |
| 3.4 | **人才市场竞争** | 挖角与薪酬战：稀缺人才被更高价"买走"，市场流动性推高；现代市场经济下企业间人才竞争趋向高层化 [来源: 外部 MBA智库-人力资源流动：人才竞争特征] | 高级工程师被竞对 1.5x 薪资挖走 |
| 3.5 | **行业声誉下降** | 职业评价（occupational prestige）降低，从业者羞耻感/无意义感上升，主动逃离 [来源: 外部 MBA智库-人力资源流动：职业评价影响流动] | 教培老师、保险电销 |
| 3.6 | **政策监管冲击** | 行业性政策突变使岗位需求瞬间归零 | "双减"教培、游戏版号、房地产三道红线 |
| 3.7 | **地域产业转移** | 产业集聚迁移，岗位随工厂/研发中心转移，不愿随迁者流失 | 制造业内迁、总部外迁 |
| 3.8 | **技能半衰期缩短** | AI 时代技能加速折旧：岗位知识半衰期从 5-10 年缩至 2-3 年 [来源: 内部 career/2026-08-13-talent-value-era-shift §4.3] | 框架/工具类技能快速过时 |

**机制洞察**：行业维度是"不可控性最高"的维度——个体和组织都无法抵御技术范式与政策突变。它同时制造**推力**（本行业萎缩）与**拉力**（新兴行业吸引），是"行业切换"型流动的主因。幸存者（那 1-3%）的共同特征是**在旧技能仍值钱时提前 2-3 年开始新方向学习**（顺势而为），而非等到贬值后被迫转型 [来源: 内部 career-divergence §11.2]。

### 维度四：家庭与生活维度（7 类）——"家让我走"或"家不让我留"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 4.1 | **家庭生命周期** | 育儿/养老高峰（35-42 岁核心期），时间精力可分配量骤降，无法承受高压岗位 [来源: 内部 career-divergence §8.4：每天可用于额外学习/机会探索的时间 <0.5小时] | 双职工带娃+照顾老人 |
| 4.2 | **地域迁移** | 配偶工作变动、回乡、子女教育（学区/户籍）迫使离开岗位所在城市 | 离开一线回省会 |
| 4.3 | **经济压力挤压** | 房贷/教育/医疗支出高峰，要么被迫追求更高薪（跳槽），要么被迫求稳（不敢动）——双向都扭曲职业选择 | 房贷高压下放弃创业/转型 |
| 4.4 | **照料责任** | 老人长期护理、特殊需求子女，需要弹性时间或离岗 | 父母重病辞职陪护 |
| 4.5 | **配偶职业同步** | 双职工同龄：一方晋升/调动制约另一方选择（两地分居或一方牺牲） | 配偶外派，随迁转岗 |
| 4.6 | **代际期望** | 家族/社会期望（进体制、稳定、体面）与个人职业选择冲突 | 技术人被迫考编 |
| 4.7 | **生活成本倒挂** | 通勤时间、城市生活成本与收入不匹配，性价比核算后离开 | 高薪但时薪极低的岗位 |

**机制洞察**：家庭维度是 12-18 年阶段（35-42 岁）最活跃的流失变量，且与组织/行业维度**共振放大**——家庭责任加重→可承受的工作强度下降→组织视为"性价比下降"→优先淘汰。家庭不是"外因"，而是与职业系统深度耦合的约束方程。

### 维度五：制度与社会维度（6 类）——"规则不让我留"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 5.1 | **用工制度差异** | 编制/合同/劳务派遣身份差异：非核心身份无法积累长期权益 | 派遣 10 年无晋升资格 |
| 5.2 | **年龄与退休制度** | "35 岁门槛"、退休年龄制度使部分岗位存在隐性年龄天花板 [来源: 内部 career-divergence §8.2] | 招聘 JD 限 35 岁以下 |
| 5.3 | **社保福利可携带性** | 养老金/公积金/医保跨地区转移受限，地域流动被"锁定"或被迫"断缴" | 换城市损失多年社保 |
| 5.4 | **户籍与公共服务** | 子女入学、医疗、购房资格与户籍挂钩，非户籍者长期不确定性 | 一线无户口家庭被迫离开 |
| 5.5 | **政策制度调整** | 国企改革、事业单位改制、行业监管收紧等制度性冲击 | 事业单位改制后人才流失 |
| 5.6 | **社会观念变迁** | 跳槽文化 vs 忠诚文化：社会对"频繁跳槽"与"多年坚守"的评价随时间摇摆 | 90 后跳槽常态化 vs 父辈从一而终 |

**机制洞察**：制度维度提供的是**底层约束/激励框架**——它不直接触发流失，但决定其他维度的作用强度（如社保可携带性决定地域流动成本、年龄制度决定行业维度打击力度）。制度维度与行业维度同为"个体与组织均不可控"的宏观变量。

### 维度六：偶发事件维度（5 类）——"最后一根稻草"与"命运转折"

| # | 流失原因 | 机制说明 | 典型场景 |
|:-:|:---------|:---------|:---------|
| 6.1 | **关键人物离开** | 导师/上级/同盟者离开：情感锚点与政治保护网同时消失 | 赏识自己的领导调走，随即被边缘化 |
| 6.2 | **被挖角/重大机遇** | 市场拉力突然放大：高薪 offer、创业邀约、贵人引荐——触发临界点 | 竞对给出无法拒绝的条件 |
| 6.3 | **重大失败/危机** | 项目失败背锅、重大事故责任、公开羞辱：信任与尊严崩塌后无法继续 | 项目事故后被迫离职 |
| 6.4 | **组织突发变动** | 并购、破产、总部搬迁、业务砍撤——外部冲击直接取消岗位 | 公司被收购后整体裁员 |
| 6.5 | **个人突发变故** | 重大疾病、家庭变故（离异/丧亲）、意外——非职业因素强制退场 | 大病后无法胜任原岗位 |

**机制洞察**：偶发事件是"触发器"而非"原因"——多数情况下，事件只是压垮长期累积问题的最后一根稻草（推力早已累积，定力早已衰减，事件提供离场理由）。但也存在**独立致命事件**（并购/破产/重大疾病）——不依赖任何累积，单点即触发流动。幸存者研究中"足够幸运"（95%+ 的幸存者遇到过关键转折点）正是对这一维度的实证 [来源: 内部 career-divergence §7.1]。

## §3 支撑20年长期主义的必要条件（正反对照）

> 方法：对 §2 的 46 类流失原因取反，即得支撑条件。长期主义 = 六维支撑系统同时成立。下表按"个人可行动 vs 组织可治理 vs 环境可依赖"三侧组织。

### 3.1 个人侧：定力的来源（4 项核心）

| 支撑条件 | 对抗的流失原因 | 机制说明 |
|:---------|:--------------|:---------|
| **内在动机复利** | 1.1 动机衰减、1.5 价值观转变 | 对领域本身的热爱（非工资/头衔驱动）是 95%+ 幸存者的共性 [来源: 内部 career-divergence §7.1]；兴趣×意义×成就感形成自我强化回路 |
| **复利型资产结构** | 1.2 能力天花板、3.1 技术变迁 | 技能分配 60% 当前核心 + 25% 相邻 + 15% 新种子 [来源: 内部 career-divergence §11.3]；判断力/网络/领域纵深属复利资产，随年限增值 [来源: 内部 talent-value-era-shift §4.3] |
| **健康与精力管理** | 1.3 倦怠、1.4 健康 | 20 年马拉松的体能前提：可持续的工作节奏优于短期冲刺 |
| **财务缓冲与反脆弱结构** | 2.9 裁员、6.5 变故 | 主业+副业+储蓄+行业身份多维结构，使任何单一打击不致命 [来源: 内部 career-divergence §13.3] |

### 3.2 组织侧：拉力的来源（6 项核心）

| 支撑条件 | 对抗的流失原因 | 机制说明 |
|:---------|:--------------|:---------|
| **真实成长通道** | 2.2 晋升天花板、2.6 培训不足 | 技术/管理双通道"真实化"：薪酬上限与决策权对等（现实中管理通道薪酬上限高 30-50%，双通道是幻象）[来源: 内部 career-divergence §5.3] |
| **长期激励绑定** | 2.1 薪酬失效、6.2 被挖角 | 股权/期权/年金/递延奖金：制造 Becker 式"单方投入"，离开成本随年限上升；随年限积累的退休金与管理权即"附属利益" [来源: 外部 MBA智库-组织承诺；内部 career-divergence §5.3] |
| **组织稳定性** | 2.5 组织变动、2.9 淘汰 | 低 reorg 频率 + 验收锚点稳定（物理/标准/契约层），让长期投入可见回报 [来源: 内部 org-churn-work-destruction-defense §0] |

| **评价体系长期化** | 2.7 绩效不公、2.8 设计固化 | 将"避坑价值/知识传承/系统判断"纳入评价——专家价值延迟体现，需 5-10 年尺度评价 [来源: 内部 career-divergence §10.3] |
| **弹性与人文设计** | 2.10 强度失衡、4.x 家庭 | 弹性工作制、家庭支持（托育/弹性工时）对冲家庭维度拉力 |

### 3.3 环境侧：稳态的来源（3 项核心）

| 支撑条件 | 对抗的流失原因 | 机制说明 |
|:---------|:--------------|:---------|
| **行业长坡厚雪** | 3.1-3.3 技术/周期/结构 | 岗位所在领域 20 年不萎缩、范式连续演进（如基础设施硬件→云计算→AI 算力的连续升级而非断裂）|
| **制度保护** | 5.2 年龄门槛、5.3 社保 | 反年龄歧视执法、社保可携带、退休制度弹性——制度不制造"非弹性断裂" |
| **家庭支持系统** | 4.1-4.5 家庭变量 | 配偶理解、老人健康、经济缓冲——家庭维度的"稳态化"是 12-18 年阶段留守的前提 |

## §4 动态视角：不同阶段的流失原因权重

> 承接内部 career-divergence 的五年分段存活率模型 [来源: 内部 career-divergence §2.1]，将六维原因映射到时间轴，展示"主导流失原因"随职业生涯的迁移。

```text
Stage        0-3yr    3-7yr      7-12yr     12-18yr     18yr+
          +--------+-----------+-----------+------------+-----------+
Personal  #### 60%  ### 45%     ## 25%      # 15%        # 20%
Org       ## 20%    ### 40%     #### 50%    ### 35%      ## 25%
Industry  # 10%     # 10%       ## 15%      ### 30%      #### 40%
Family    # 5%      # 5%        # 10%       ### 20%      ## 15%
Institution #5%    # 0%        # 0%        # 5%         # 0%
Events    trigger   trigger     trigger     trigger      trigger
          +--------+-----------+-----------+------------+-----------+
Theme     fit-filter skill-split org-game  structure-out industry-end
Control   60%       50%         35%         20%          30%
```

> 中文对照：Personal=个人内在、Org=组织治理、Industry=行业市场、Family=家庭生活、Institution=制度社会、Events=偶发事件；Theme=主导主题（适配性筛选/能力分化/组织博弈/结构挤出/行业终局）、Control=个体可控性。

**解读**：
1. **早期（0-7 年）**：流失主因在个人——兴趣匹配、能力分化、痛苦阈值。此阶段"坚持不下去"多属个人选择/能力筛选，组织责任有限。
2. **中期（7-18 年）**：流失主因转移至组织与结构——晋升、薪酬、管理、组织变动、机会锁死。此阶段个体可控性降至 20-35%，"不是不够好，而是太贵了、选择少、被锁定了" [来源: 内部 career-divergence §6.2]。
3. **后期（18 年+）**：流失主因转向行业终局——技术范式更替、行业生命周期、退休安排。能到达此阶段者已是幸存者（3-5%），其流失多属"自然代谢"而非"被迫出局"。
4. **偶发事件贯穿全周期**：任何阶段都可能被急性事件触发流动，但**事件的作用取决于当时的推力累积与定力存量**——定力强时事件被吸收（挺过去），定力弱时事件被放大（顺势离开）。

## §5 综合模型与结论

### 5.1 长期主义达成公式

```text
P(20yr stay) = P(personal) x P(org) x P(env) x P(no fatal event)

P(personal) = intrinsic-loop x compounding-assets x health x financial-buffer
P(org)      = growth-path x long-term-incentive x stability x culture x long-cycle-eval
P(env)      = industry-long-runway x institution x family-support
P(no fatal) = 1 - P(M&A / bankruptcy / severe illness / accident)

Calibration (per retention math in Sec 1.2):
0.6 x 0.4 x 0.5 x 0.9 ~= 0.11  -> still needs 89%+ annual retention
                                to approach the empirical 3-5% / 20yr
```

**含义**：四个概率项是**相乘**而非相加——任何一项归零，长期主义整体归零。组织再优秀，行业赛道崩塌（环境项≈0）也无法留住人；个人定力再强，组织持续变动（组织项衰减）也会被磨灭。**这就是为什么长期主义"不是那么容易达成"——它是多维系统的联合稳态，而非单点意志的胜利。**

### 5.2 对组织（技术决策者）的启示

1. **人才保留不是 HR 职能，是组织设计职能**：46 类流失原因中组织可直接治理的约 12 类（维度二全量 + 维度一部分），但组织可通过**环境侧建设**（选择有长坡的赛道、参与行业标准）间接影响行业维度——把组织的"赛道选择"当作最大的留人手段。
2. **20 年人才保留的 ROI 逻辑**：老员工的真正价值（避坑/判断/传承）无法被短期 KPI 度量 [来源: 内部 career-divergence §10.3]，但流失成本可量化——一个员工离职引发约 3 个员工产生离职想法 [来源: 外部 MBA智库-员工流失]；技术骨干流失带走核心知识，可能直接威胁竞争力 [来源: 外部 MBA智库-员工流失 成本节]。建立"长期价值评价体系"是组织的复利投资。
3. **组织稳定性的稀缺溢价**：在 reorg 常态化的环境中，一个"组织稳定 + 验收锚点稳定"的平台本身就是最强留人机制——它让员工的长期投入可预期、可累积 [来源: 内部 org-churn-work-destruction-defense §0]。

### 5.3 对个人（长期主义者）的启示

1. **把"留下"建立在复利资产上，而非岗位惯性上**：岗位会变、组织会变、行业会变，只有可迁移的复利资产（判断力/领域纵深/网络/行业身份）是恒定项 [来源: 内部 talent-value-era-shift §6]。
2. **主动管理六维约束**：个人能直接干预的是个人维度（动机/健康/能力结构）与部分家庭维度（财务缓冲/家庭沟通）；对组织/行业/制度维度，策略是**提前预判 + 保持迁移选项**（在旧技能仍值钱时准备新技能）[来源: 内部 career-divergence §11.2]。
3. **区分"坚持"与"困守"**：长期主义的高级形态是**主动选择的长期**——因为热爱、因为复利、因为不可替代而留下；低级形态是**被动困守**——因为沉没成本、因为恐惧、因为没有选择而留下。前者是资产，后者是负债。检验标准：如果明天收到一个更好的机会，你的"留下"理由是否依然成立？

### 5.4 结语

> **长期主义不是一种心态，而是一个六维系统的稳态解。** 20 年的坚守，是个人定力、组织支撑、环境稳态与好运气的联合产物——缺失任何一维，流动就会发生。因此：对组织，别把留人寄托于情怀，要建设系统；对个人，别把坚守寄托于意志，要构建复利。**系统的建设者赢得长期，单点的坚持者输给概率。**
