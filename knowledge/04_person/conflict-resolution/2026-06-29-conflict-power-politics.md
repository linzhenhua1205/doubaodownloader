## 1. 权力转换的常见模式

权力更替是组织冲突的核心触发机制之一。不同模式的冲突烈度差异巨大：

| 类型 | 模式 | 冲突烈度 | 典型场景 |
|:-----|:-----|:---------|:---------|
| **和平有序** | 法定选举/委任 | 无 | 董事会换届、管理层正常调整 |
| **和平有序** | 制度委任/层级递补 | 无 | 正职空缺副职接任 |
| **和平有序** | 契约转让 | 低 | 企业并购、股权收购 |
| **博弈协商** | 派系妥协与共治 | 中 | 多派系势力均衡、合伙制 |
| **博弈协商** | 渐进式权力移交 | 低-中 | 新老管理层交替、创始人退休 |
| **动荡激进** | 政变/内部夺权 | 高 | 军队夺权、管理层突然清洗 |
| **动荡激进** | 逼宫/胁迫交权 | 中-高 | 集体施压迫使卸任 |
| **特殊** | 权力真空与争夺 | 极高 | 组织解体、创始人猝逝 |

**对个人的启示**：

- 在权力交接期，**站队风险最大**，但也是**获得信任的窗口期**
- 和平有序的模式中，能力和业绩仍是主要评价标准
- 博弈协商的模式中，**中立但公开表态**比"两面讨好"更安全

## 2. 利益冲突识别与管理

### 2.1 六类利益冲突速查

| 类别 | 典型表现 | 识别信号 |
|:-----|:---------|:---------|
| **经济利益** | 收受回扣、兼职经商、不当获利 | 生活水平与收入不匹配 |
| **关联关系** | 亲属回避缺失、熟人偏袒 | 同一亲属在同一单位关键岗位 |
| **履职行为** | 决策偏私、权责混用、内外勾结 | 某供应商或人员反复得到特殊对待 |
| **信息滥用** | 保密信息私用、公共资源私占 | 离职时带走大量资料 |
| **离职延续** | 竞业冲突、事后利益输送 | 离职后短期内入职客户/供应商 |
| **情感偏好** | 因个人好恶差异化对待 | 小圈子明显获益 |

### 2.2 核心判定标准

1. 是否存在**私人利益**介入本职工作？
2. 是否影响**客观、公正、独立**履职？
3. 是否存在潜在腐败、合规风险？

## 3. 在政治环境中自保的六个原则

### 3.1 第一原则：分清"能改变的"和"不能改变的"

| 能改变 | 不能改变 |
|:-------|:---------|
| 自己的技能和履历 | 公司政治格局 |
| 自己的沟通方式 | 领导的管理风格 |
| 自己的工作边界 | 组织的制度缺陷 |
| 是否继续留在这里 | 别人对你的评价 |

### 3.2 政治自保 checklist

| # | 原则 | 操作 |
|:-:|:-----|:-----|
| 1 | **不站队** | 在派系对立中保持中立，除非你确定要离开 |
| 2 | **留痕迹** | 关键决策、任务分配、评价记录全部书面留存 |
| 3 | **不吐槽** | 不和同事吐槽管理层，管住嘴，防传话 |
| 4 | **不恋战** | 没有胜算的博弈不参与，及时止损 |
| 5 | **有筹码** | 持续提升不可替代性——能力是最后的底牌 |
| 6 | **知进退** | 知道什么时候该争，什么时候该撤 |

## 4. 当决定"打"：策略性冲突的艺术

不是所有冲突都要回避——当涉及**原则问题、核心利益、关键决策**时，策略性参与是必要的。

### 4.1 什么时候该打

| 判断维度 | 该打 | 不该打 |
|:---------|:-----|:-------|
| 影响范围 | 涉及团队/公司长期方向 | 仅个人感受 |
| 胜算概率 | 有数据、有同盟、有方案 | 纯情绪对抗、无备选 |
| 成本收益 | 打赢的收益 > 损耗的成本 | 双输或损失大于收益 |
| 替代方案 | 没有其他途径能解决 | 可以用其他方式绕过 |

### 4.2 怎么打——策略性对抗五步

1. **选战场**：挑最有胜算、最重要的一个议题
2. **备弹药**：收集数据、准备方案、寻找同盟
3. **定底线**：什么必须拿到？什么是可以妥协的？
4. **控情绪**：对事不对人，用数据不用指责
5. **留台阶**：给对方体面下台的路径，不把关系彻底撕破

### 4.3 输了的后手

- 接受结果，不纠缠
- **记录过程**（为什么输、谁在关键节点做了什么）
- 调整策略，等待下一个窗口
- 如果连续输且影响核心利益 → 认真考虑离开

## 5. 从长远看：能力是最好的政治筹码

> "把自己不可替代性的壁垒筑得越高，别人动你的成本就越大。最终，技术人的终极护城河从来不是跟对了谁，而是自己能解决别人解决不了的问题。" — import/md/研发行业低毛利避坑指南_0608045333.md

### 提升不可替代性

| 路径 | 做法 |
|:-----|:------|
| **深度专精** | 在某个领域做到团队/行业前列 |
| **宽度覆盖** | 掌握跨领域知识，成为"连结点" |
| **经验资产化** | 将经验沉淀为文档、工具、流程 |
| **外部影响力** | 通过技术博客、开源贡献建立行业声誉 |
