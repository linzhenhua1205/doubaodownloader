## 1. 核心结论

### 1.1 一句话总结

> **同一套"七维运营框架"，七家厂商给出了七种截然不同的答案——每个维度的做法本质上是商业模式的外显，不存在"最佳实践"，只有"匹配实践"。**

### 1.2 各厂商的"运营底色"

| 厂商 | 运营底色 | 七维中最强维度 | 七维中最弱维度 | 一句话特征 |
|:-----|:---------|:--------------|:--------------|:-----------|
| **浪潮信息** | 规模效率驱动 | 制造、通用 | 智能、研发 | "把标准化做到极致，靠量摊薄一切" |
| **华为(计算线)** | 全栈技术驱动 | 研发、智能、平台 | 制造、通用 | "从芯片到集群全栈自研，用技术深度换市场宽度" |
| **新华三** | 方案整合驱动 | 平台、管理 | 智能、制造 | "网络锁定服务器，方案溢价替代单品竞争" |
| **工业富联** | 制造服务驱动 | 制造、通用 | 研发、智能 | "全球最大服务器制造工厂，ODM模式做到极致" |
| **超聚变** | AI赛道聚焦驱动 | 智能、经营 | 平台、通用 | "砍掉一切非AI业务，全速追击AI服务器" |
| **联想ISG** | 全球品牌驱动 | 经营、管理 | 研发、制造 | "Think品牌全球信任+ODM拼图+服务捆绑" |
| **DELL ISG** | 直销+供应链驱动 | 经营、通用、制造 | 研发、智能 | "直销模式砍掉渠道成本，供应链数字化全球标杆" |

### 1.3 七维之间的因果链

```text
七个维度的运作顺序和逻辑关系:

    经营(收入/利润目标)
         |
         v
    管理(组织设计/流程/决策)
         |
    +----+----+
    v         v
  通用      研发
  (共享服务)  (技术能力)
    |         |
    v         v
  制造 <---- 平台(硬件/软件平台化)
  (交付)      |
              v
            智能(AI集成/软件栈)
              |
              v
         回到经营(新的增长点)

核心洞察:
- 通用和研发是"输入端"——决定了成本和效率的基本面
- 平台是"杠杆端"——通过复用放大研发投入的效益
- 智能是"增值端"——AI是当前最大的差异化来源
- 制造是"交付端"——再好的设计做不出来等于零
- 管理和经营是"控制端"——确保所有环节对齐目标
```

## 3. 通用（Common/Shared）

### 3.1 维度定义

"通用"是指跨产品线、跨BU的**共享基础设施和服务**。在服务器行业，通用维度的核心是：

1. **CBB（Common Building Block）共用模块**——不同产品线共享的硬件/固件模块
2. **共享采购平台**——通过集采压降BOM成本
3. **IT系统和数字平台**——ERP/PLM/MES等共享IT基础设施
4. **实验室和测试资源**——SI实验室、环境实验室、可靠性实验室

### 3.2 各厂商实践

#### 🏢 浪潮信息：强大的共享采购平台

```text
浪潮的"通用"模式——"平台共享化"：

                    浪潮信息
                        |
            +-----------+-----------+
            |                       |
        +---+---+             +---+---+
        | 研发平台 |             |供应链平台|  <- 核心技术
        | (共享)  |             | (共享)   |
        |         |             |         |
        |. 基板共享|             |. 集采平台 |
        |. BMC统一|             |. 物流共享 |
        |. BIOS统一|             |. 制造共享 |
        |. 测试共享|             |. 仓库共享 |
        +--------+             +--------+
            |                       |
    +-------+-------+       +-------+-------+
    v       v       v       v       v       v
  通用服务器  AI服务器  存储   通用服务器  AI服务器  存储
  产品线     产品线    产品线   制造线    制造线    制造线
```

**具体实践**：

- **CBB复用率达到70%+**：不同产品线共享基板设计，同一个BMC固件覆盖80%产品
- **年采购额超600亿**：通过共享采购平台统一议价，GPU/CPU/内存采购价低于同行3-5%
- **共享测试中心**：济南总部集中式测试实验室，所有产品线共用，减少重复投资
- **PLM一体化**：所有产品线在同一个Teamcenter平台上管理，BOM数据统一

**效果**：CBB复用+集采每年节省成本约**15-20亿**，是浪潮"薄利多销"模式能盈利的关键。

#### 🏢 华为：重研发轻通用

华为的"通用"并非通过共享模块降本，而是通过**平台化架构**实现技术复用。

```text
华为的"通用"模式——"架构平台化"：

                     华为计算产品线
                           |
              +------------+------------+
              |                         |
         +----+----+             +----+----+
         | 硬件平台  |             | 软件平台  |
         |         |             |         |
         |. 统一机箱 |             |. 统一BMC  |
         |. 模块化电源|             |. 统一OS  |
         |. 统一背板 |             |. 统一管理 |
         +---------+             +---------+
              |                         |
              +------------+------------+
                           v
                    +--------------+
                    | 不同产品实例化  |
                    | (鲲鹏/昇腾/存储)|
                    +--------------+
```

**差异**：华为的"通用"强调的是**架构级复用**而非**组件级共享**——比如统一电源模块设计，不同的计算节点插同一个机箱。这比组件级共享更高效，但对架构设计要求更高。

**局限性**：华为因制裁供应链受限，其共享采购平台的采购规模远不如浪潮。这是华为"通用"维度的短板。

#### 🏢 工业富联：极致的制造服务共享

```text
工业富联的"通用"模式——"客户共享制造"：

                   工业富联
                       |
            +----------+----------+
            |                     |
      +-----+-----+       +-----+-----+
      | NVIDIA客户  |       | Apple客户   |
      +-----+-----+       +-----+-----+
            |                   |
            +---------+---------+
                      v
                 +--------------+
                 |  全球制造平台  |  <- 6大基地共享
                 |              |
                 |. SMT产线共享  |
                 |. 自动化方案共享|
                 |. AI质检平台共享|
                 |. 全球物流共享  |
                 +--------------+
```

**核心特征**：工业富联的"通用"不是产品层面的CBB，而是**制造能力层面的共享**——不同客户的服务器，在同样的SMT线、同样的测试工位、同样的仓库里生产。柔性制造能力是最大的"通用资源"。

#### 🏢 新华三：方案共享而非组件共享

H3C的"通用"围绕**解决方案**展开：网络+服务器+安全作为一个整体方案出售，共享市场渠道和客户关系。服务器本身并没有很强的CBB共享——因为服务器体量本身不够大（仅占H3C约40-50%营收）。

**关键差异**：

- 浪潮：共享**组件/采购**
- 华为：共享**架构/平台**
- 工业富联：共享**制造/产能**
- H3C：共享**渠道/方案**

### 3.3 维度总结

| 特征 | 浪潮 | 华为 | H3C | 工业富联 | 超聚变 |
|:-----|:----|:-----|:----|:--------|:------|
| CBB复用率 | 70%+ | 50-60% | 40-50% | 极低(ODM) | 40-50% |
| 采购规模 | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐ | ⭐⭐⭐⭐⭐ | ⭐⭐ |
| 共享模式 | 组件共享 | 架构共享 | 方案共享 | 制造共享 | 初创期 |
| 成本节省 | 15-20亿/年 | 非核心考量 | 中 | 制造规模效应 | 有限 |

## 4. 研发（R&D）

### 4.1 维度定义

研发维度覆盖从技术预研到产品量产的完整创新链。在服务器行业，研发包含：

- **硬件研发**：主板设计、电源设计、结构/散热/液冷设计、SI/PI仿真
- **固件研发**：BIOS/BMC/IPMI/Redfish开发
- **软件研发**：管理软件、AI软件栈、集群管理工具
- **测试验证**：硬件测试、兼容性测试、可靠性测试、认证测试
- **架构预研**：下一代产品架构探索、新技术验证(PoC)

## 5. 平台（Platform）

### 5.1 维度定义

"平台"是指**硬件/软件的平台化策略**——通过精心设计可以复用的平台架构，使不同产品线可以基于同一套基础快速衍生出多种产品。在服务器行业：

- **硬件平台**：基板平台、机箱平台、电源平台、背板平台
- **固件平台**：统一BMC/BIOS固件架构
- **软件平台**：统一管理软件平台
- **生态平台**：开发者社区、合作伙伴体系

### 5.2 各厂商实践

#### 🏢 华为：极致平台化——"一个架构覆盖全场景"

```text
            |            |            |
            |   +--------+--------+   |
            |   v                v   |
            | +--------+ +----------+ |
            | | 鲲鹏计算  | | 昇腾计算  | |  <- 不同计算节点
            | | 节点模块  | | 节点模块  | |     插同样机箱
            | +--------+ +----------+ |
```

**核心实践**：

- **CANN统一计算架构**：不管是AI训练还是推理，上层应用通过同一套API调用底层算力

**效果**：平台化使华为能用较少的研发资源覆盖更多的产品场景——这是华为"人均附加值80万"高于浪潮"64万"的技术基础。

```text
浪潮制造布局：

  济南(总部)          苏州                海外
  +---------+     +---------+     +---------+
  | 自有SMT  |     | 整机组装   |     | 组装+测试  |
  | 自有组装  |     | 自有+外协  |     | (印度等)  |
  | 月产5万+  |     | 月产3万+   |     | 月产1万+  |
  +---------+     +---------+     +---------+

  制造能力特征:
  . SMT自给率: 60%(核心板卡自产)
  . 整机组装自给率: 80%
  . 液冷方案: 自建CDU产线
  . 品控: ISO 9001+14001, 六西格玛
```

**和工业富联的差异**：

- 浪潮制造是"**为了自己卖**"——品质控制权在自己手上，但规模不如ODM
- 工业富联制造是"**为了别人卖**"——规模极致，但对产品定义无话语权

#### 🏢 华为：制造"精干+外协"

华为的制造策略独特：

> **华为计算产品线不做大规模自建制造——把制造交给合作伙伴，自己聚焦研发和品牌。**

- 东莞自有产能主要是**样品和小批量**试制
- 批量生产委托给**富士康、比亚迪电子、华勤等ODM/OEM**
- 品质管控通过驻厂QA+验收测试实现
- 这与华为"重研发轻制造"的战略一致

**启示**：华为的模式说明——如果不把制造作为核心竞争力，完全可以外包。但代价是失去了对品质和交付的完全控制。

### 7.3 自建 vs 外包的选择逻辑

```text
自建制造 vs 外包制造的决策树:

Q: 制造是你的核心竞争力吗？
+-- ✅ 是 (如工业富联、浪潮)-> 自建
|   +-- 优势: 品质可控、成本可控、响应快
|   +-- 代价: 资本支出大、产能利用率风险
|
+-- ❌ 否 (如华为、H3C) -> 外包+品控
    +-- 优势: 轻资产、聚焦研发
    +-- 代价: 品质依赖供应商、响应慢

基于4000人BG的自建vs外包建议:
- 如果年产10万台+ -> 自建核心SMT和总装线(浪潮模式)
- 如果年产5万台 -> 整机组装自建+主板外协(混合模式)
- 如果年产<3万台 -> 全部外包(华为模式)
```

## 8. 管理（Management）

### 8.1 维度定义

管理维度覆盖：

- **组织架构设计**：BG制/产品线制/矩阵制
- **流程体系**：IPD/LTC/ITR等核心流程
- **绩效管理**：KPI/OKR设定、考核方式
- **人才发展**：招聘、培训、晋升、保留
- **决策机制**：决策权分配、审批流程、响应速度

### 8.2 各厂商实践

#### 🏢 华为：IPD圣殿——"流程即管理"

```text
华为管理体系：

                   华为
                     |
           +---------+---------+
           |     董事会/EMT     |  <- 最高决策机构
           +---------+---------+
                     |
         +-----------+-----------+
         |      IPD管理体系       |
         +-----------------------+
         |                       |
         |  IRB(投资评审委员会)   |  <- 管研发投资方向
         |  PDT(产品开发团队)    |  <- 管具体产品开发
         |  TDT(技术开发团队)    |  <- 管技术预研
         |  LMT(生命周期团队)    |  <- 管产品退市
         |  IPMT(集成组合管理)   |  <- 管产品组合
         |                       |
         +-----------------------+
         |  其他管理体系          |
         |  LTC(线索到回款)       |
         |  ITR(问题到解决)       |
         |  MTL(市场到线索)       |
         |  SD(服务交付)          |
         +-----------------------+
```

**管理特征**：

1. **流程驱动的决策**——凡事有流程，流程有评审，评审有记录
2. **矩阵式组织**——产品线与资源线交叉，双向汇报
3. **干部轮岗制**——关键岗位3-5年必须轮换
4. **末位淘汰**——每年5-10%的淘汰率，保持组织活力
5. **管理成本高**——管理占员工比例~15-18%，这是"流程冗余"的代价

**对服务器BG的启示**：华为的管理体系是最完善的，但也是**最昂贵的**——需要足够的利润支撑管理冗余。如果BG毛利率只有14%，养不起华为级别的管理流程。

#### 🏢 浪潮：结果导向——"人少、事多、钱多"

```text
浪潮管理模式：

  特征: 结果导向 · 扁平化 · 快速决策

  组织:                   决策:
  +--------------+       +--------------+
  |  BG总经理 ->   |       |  总经理办公会   |
  |  BU负责人 ->   |       |  每周一次     |
  |  产品线经理 ->  |       |  2小时内决策  |
  |  项目经理 ->   |       |  执行即可     |
  |  工程师       |       +--------------+
  +--------------+
  层级: 4-5层           人均管理幅度: 1:15

  绩效:
  +--------------+
  | . 季度KPI考核 |
  | . 强结果导向   |
  | . 绩效工资30%+ |
  | . 末位淘汰5%  |
  +--------------+
```

**关键差异**：

- 浪潮的管理更"**野**"——流程少、决策快、执行力强
- 人均管理幅度1:15（华为约1:8），管理费用低
- 管理轻便化的代价：流程规范性不足，沟通成本隐性增加

#### 🏢 新华三：稳健中台

H3C的管理介于华为和浪潮之间——有流程但不冗余，有层级但不僵化。

```text
H3C管理特征:
- 产品线+区域双矩阵(类似IBM模式)
- 销售团队按区域划分,研发团队按产品划分
- 管理流程跟随紫光集团(国资背景)
- 稳健为主,不激进扩张
- 管理成本中等,管理占比~12%
```

### 8.3 管理模式对比

```text
管理模式光谱:

轻管理                       重管理
  |                           |
  |                           |
浪潮                        华为
  |                           |
  结果导向                   流程驱动
  扁平快速                   矩阵严谨
  人少事多                   流程完善
  管理成本低                 管理成本高
  v                          v
管理占比: ~12%              管理占比: ~15-18%
决策速度: 快                 决策速度: 慢(但质量高)
执行力: 强                  执行力: 强(但不灵活)
```

**核心结论**：没有"更好的管理模式"，只有"更适合商业模式的管理模式"。

- 浪潮的薄利模式养不起重管理——所以轻管理是对的
- 华为的高毛利模式撑得住重管理——所以流程完善是对的
- 本BG如果追求14-16%毛利率，管理应采用"浪潮级"的轻管理，而非"华为级"的重管理

## 9. 经营（Business Operations）

### 9.1 维度定义

经营维度覆盖：

- **定价策略**：成本加成vs价值定价vs竞争定价
- **客户管理**：大客户/渠道/直销模式
- **渠道体系**：分销/直销/集成商
- **财务管控**：利润中心/成本中心/投资回报管控
- **增长策略**：市场拓展/产品扩张/并购整合

### 9.2 各厂商实践

#### 🏢 浪潮：规模制胜——"以量定价，以量盈利"

```text
浪潮经营模型：

  营收850亿
      |
  +---+---+
  | 毛利率  |
  |  10%   |
  |  ->85亿 |
  +---+---+
      |
  +---+---+
  | 费用   |
  | ~55亿  |
  +---+---+
      |
  +---+---+
  | 净利   |
  | ~30亿  |
  | 净利率 |
  | 3.5%   |
  +-------+

  经营密码:
  - 毛利率10% × 营收850亿 = 毛利85亿
  - 只要费用控制在~55亿 -> 净利30亿
  - 所以经营的核心是"营收规模"而非"毛利率"

  定价策略:
  - 招标市场上"以价换量"
  - 中标后再通过集采降本确保利润
  - 大客户订单可接受更低毛利率(8-9%>5亿以上订单)
```

**客户结构**：

| 客户类型 | 营收占比 | 毛利率 | 账期 |
|:---------|:--------:|:------:|:----:|
| 互联网(阿里/腾讯/字节) | ~40% | 8-10% | 60-90天 |
| 运营商(移动/联通/电信) | ~25% | 10-12% | 30-60天 |
| 政企(政府/金融/教育) | ~20% | 12-15% | 30天 |
| 海外 | ~15% | 10-12% | 30-60天 |

#### 🏢 联想/DELL：全球品牌溢价

```text
DELL ISG经营模型（参考）：

  DELL ISG营收: ~$3,000亿(RMB)+
       |
   +---+---+
   | 毛利率  |
   |  23%   |
   +---+---+
       |
   +---+---+
   | 净利   |
   | 6%     |
   +-------+

  经营核心差异:
  1. 直销模式: DELL直销到客户,省去渠道成本约5-8%
  2. 品牌溢价: PowerEdge品牌,企业客户愿多付10-15%
  3. 服务捆绑: ProSupport/TruScale等增值服务提升ARPU
  4. 全球定价: 不同市场差异化定价,全球利润最大化
```

#### 🏢 超聚变：聚焦定价——"不做全品类，只赚AI的钱"

```text
超聚变经营策略:

  +-------------------------------------+
  |  超聚变不做的事情:                    |
  |  . 不做低价通用服务器(留给浪潮)       |
  |  . 不做存储产品                      |
  |  . 不做网络设备                      |
  |  . 不做海外市场(暂)                  |
  +-------------------------------------+
  |  超聚变专注做的事情:                   |
  |  . AI服务器(昇腾为主+NVIDIA为辅)      |
  |  . 液冷方案(华为生态延续)             |
  |  . 国产替代场景(运营商/政府)          |
  |  . 快速响应的客户定制                 |
  +-------------------------------------+
```

**经营效果**：

- 用200亿营收支撑14%毛利率——没有低毛利通用服务器的拖累
- 但当AI服务器市场进入价格战阶段（预计2027年后），聚焦模式可能面临瓶颈

### 9.3 维度总结

| 经营特征 | 浪潮 | 华为 | H3C | 工业富联 | 超聚变 |
|:---------|:----|:-----|:----|:--------|:------|
