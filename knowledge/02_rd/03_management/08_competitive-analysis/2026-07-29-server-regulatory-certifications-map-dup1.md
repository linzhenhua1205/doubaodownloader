## 1. 方法论与排查框架

### 1.1 认证的三层分类

服务器产品面临的认证可以从三个维度理解：

| 层 | 类别 | 性质 | 示例 |
|:--|:-----|:----|:-----|
| **L1** 🛑 | **强制市场准入** | 无此认证不得销售 | CCC、CE、FCC、KC、PSE |
| **L2** 🔶 | **法规效率要求** | 必须满足但可通过DoC | ErP、CEC、MEPS、能效标识 |
| **L3** ✅ | **自愿性竞争力** | 不强制但提升竞争力 | UL、80 PLUS、Energy Star、云厂商认证 |

### 1.2 排查方法论

每个认证从以下 6 个维度排查：

1. **适用性**：该认证是否适用于服务器产品
2. **法律依据**：对应的法规/指令编号
3. **技术标准**：具体的测试标准（如 GB 4943.1、EN 62368-1）
4. **认证模式**：自我声明 vs 第三方测试 vs 工厂审查
5. **周期与成本**：典型周期和费用范围
6. **特殊注意事项**：服务器特有条款

## 2. 中国

### 2.1 CCC — 中国强制性产品认证

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器适用**。CCC目录中"信息技术设备"（08类）涵盖服务器、PC、工控机 |
| **法律依据** | 《强制性产品认证管理规定》（CNCA） |
| **技术标准** | **安全**: GB 4943.1-2022（等同 IEC 62368-1）|
| | **EMC**: GB/T 9254.1-2021（信息技术设备） |
| | **谐波**: GB 17625.1（等同 IEC 61000-3-2）|
| **认证模式** | 型式试验 + 初始工厂审查 + 获证后监督（年度工厂检查） |
| **周期** | 10-14周（含测试+工厂审查+发证） |
| **成本** | ¥30K-80K（取决于测试项目数量），工厂审查另计 |
| **注意事项** | ⚠️ 服务器若含无线模块（WiFi/BT/5G），需额外做 **SRRC**（型号核准）和 **NAL**（进网许可） |
| | ⚠️ 工厂审查是CCC核心成本——多型号可做"认证单元"减少审查次数 |
| | ⚠️ 2024年后全面切换GB 4943.1-2022，旧版GB 4943.1-2011已废止 |

**服务器特别条款**：

- 服务器通常按 **Class A**（工业/企业环境）测试EMC，限值较Class B宽松
- 冗余电源（1+1/2+2）需按最大单电源功率评估
- 液冷服务器需增加液冷安全评估（GB 4943.1 附录）

### 2.2 SRRC — 无线电发射设备型号核准

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ⚠️ **仅当服务器含无线模块时适用**。如：WiFi/BT/5G/NFC模块 |
| **法律依据** | 《无线电管理条例》、《无线电发射设备管理规定》 |
| **技术标准** | 根据无线制式不同（WiFi 6E/5G NR等） |
| **认证模式** | 型式试验 + 型号核准 |
| **周期** | 8-12周 |
| **注意事项** | 服务器若标配WiFi/BT模块（如管理网口、BMC无线调试），必须做SRRC |

### 2.3 NAL — 电信设备进网许可（CTA）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ⚠️ **仅当服务器接入公共电信网络时适用**。如：内置5G模块的Edge Server |
| **法律依据** | 《电信条例》、《电信设备进网管理办法》 |
| **认证模式** | 型式试验 + 工厂审查 + 进网许可证 |
| **周期** | 8-16周 |
| **注意事项** | 普通服务器（仅以太网口）**不**需要进网许可。仅含蜂窝通信模块时需要 |

### 2.4 中国能效标识（China Energy Label）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器适用**。GB 28332-2012《微型计算机能效限定值及能效等级》含服务器 |
| | ⚠️ 实际执行中，**企业级服务器**的能效标识不如家电严格，但数据中心服务器在政策趋势下日益重要 |
| **技术标准** | GB 28332、GB 40880-2021《数据中心资源利用》 |
| **周期** | 2-4周（备案制） |

### 2.5 中国RoHS（China RoHS 2）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **所有电子电器产品含服务器**。管理办法要求标注有害物质含量 |
| **标准依据** | 《电器电子产品有害物质限制使用管理办法》、GB/T 26572 |
| **形式** | 自我声明 + 绿标/橙标标识 |

## 3. 欧盟

### 3.1 CE — 欧盟强制性认证

CE标记是服务器进入欧盟市场的**通行证**，覆盖多个指令。

#### 3.1.1 LVD — 低电压指令 2014/35/EU

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用**。服务器额定电压50-1000V AC / 75-1500V DC |
| **标准** | EN 62368-1（音视频/信息技术设备安全标准） |
| **认证模式** | 制造商自我声明（DoC）+ 技术文档 |
| **周期** | 4-8周（测试）+ 2周（文档准备） |
| **成本** | €5K-15K |

#### 3.1.2 EMC Directive 2014/30/EU

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用** |
| **标准** | EN 55032（辐射/传导发射）、EN 55035（抗扰度）、EN 61000系列 |
| **服务器等级** | Class A（企业环境） |
| **认证模式** | 自我声明 + 测试报告 |

#### 3.1.3 ErP — 能源相关产品指令 2009/125/EC

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器适用** |
| **实施法规** | EU 617/2013（计算机及服务器生态设计要求）→ 已更新为新版 |
| **要求** | 待机功耗 ≤ 2W、关机功耗 ≤ 1W、电源效率 ≥ 80% @ 20%负载、效率≥ 85%@50%、效率≥ 82%@100% |
| **文档** | 需提供产品生态设计信息 |

**ErP Lot 9** 专门针对企业服务器和数据中心设备，要求：

- 空闲状态电源效率
- 电源管理功能（如空闲自动休眠）
- 信息提供（IT设备能耗数据声明）

#### 3.1.4 RoHS 2011/65/EU

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **所有电子电气产品含服务器** |
| **限制物质** | 铅、汞、镉、六价铬、PBB、PBDE、4种邻苯二甲酸酯（DEHP/BBP/DBP/DIBP）→ **共10项** |
| **认证模式** | 自我声明 + 技术文档 |

#### 3.1.5 REACH Regulation (EC) 1907/2006

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器所有物料需合规** |
| **要求** | SVHC物质申报（每年更新候选清单）、SCIP数据库提交 |
| **影响** | 影响BOM物料选择，尤其线缆/塑胶件/PCB阻燃剂 |

#### 3.1.6 WEEE Directive 2012/19/EU

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用** |
| **要求** | 产品注册 + WEEE标识 + 回收安排 |
| **方式** | 各成员国分别注册（德国EAR、英国等） |

### 3.2 CE标记核心流程

```text
测试（LVD+EMC+ErP+RoHS）
    v
技术文档编制（含风险分析、电路图、元器件清单、测试报告）
    v
EC Declaration of Conformity（DoC）签署
    v
CE标识粘贴在产品铭牌/包装上
    v
欧盟境内授权代表（AR）指定（非欧盟制造商必须）
    v
产品信息数据库提交（相关指令要求）
```

## 4. 美国

### 4.1 FCC — 联邦通信委员会认证

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **强制适用**。FCC Part 15 涵盖所有数字设备（含服务器） |
| **服务器类别** | **Class A**（企业级）：辐射限值较宽松，仅用于商业/工业环境 |
| **标准** | FCC Part 15 Subpart B（无意辐射体） |
| | 含无线 → 需做 FCC Part 15 Subpart C/E（有意辐射体） |
| **认证模式** | **SDoC**（Supplier's Declaration of Conformity）—— 标准路径 |
| | 含无线模块 → **FCC Certification**（需TCB发证） |
| **周期** | SDoC: 2-4周；Certification: 6-10周 |
| **成本** | $3K-8K（EMC测试）；$15K-30K（含无线的全项） |
| **注意事项** | ⚠️ FCC不接受自我声明后标签标注"FCC Certified"——SDoC产品只能标FCC标志 |
| | ⚠️ 服务器若带WiFi 6E/7，FCC对6GHz频段有新规 |

### 4.2 UL — 自愿性安全认证（但事实强制）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **事实强制**。虽然法律不要求UL认证，但美国主要渠道商（Amazon、Walmart、系统集成商）普遍要求UL listing或NRTL认证 |
| **标准** | UL 62368-1（等同IEC/EN 62368-1）|
| **认证模式** | 第三方测试 + UL工厂检查 + UL列名 |
| **周期** | 12-20周 |
| **成本** | $20K-60K（视项目复杂度） |
| **替代方案** | **ETL**（Intertek）或 **CSA**，费用和时间约UL的60-80% |

### 4.3 CEC — 加州能源委员会能效要求

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用**。CEC能效标准覆盖外置电源、计算机系统（含服务器） |
|  | ⚠️ 加州要求最为严格——美国联邦层面的Energy Star是自愿的，CEC在加州是**强制**的 |
| **法律依据** | California Code of Regulations (CCR) Title 20 |
| **范围** | 外部电源（EPS）、计算机系统、服务器电源 |
| **要求** | 电源效率必须满足CEC能效标准（通常≥87% @ 20%负载） |
| **认证模式** | 测试 + 数据上报CEC数据库 + 制造商认证 |
| **注意事项** | ⚠️ 服务器电源的CEC要求通常与**80 PLUS**联动——80 PLUS Gold/Titanium可同时满足CEC |
| | ⚠️ CEC每年更新效率阈值，需跟踪最新版本 |

### 4.4 Energy Star — 自愿性能效标识

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器可选**。Energy Star for Computers and Servers |
| **版本** | 当前最新为 **Energy Star 4.0 for Servers**（2024年更新） |
| **要求** | 空闲功耗、满载功耗、电源效率、高级电源管理 |
| **价值** | 政府采购加分（美国联邦、州政府），企业ESG报告亮点 |
| **周期** | 4-8周 |

### 4.5 80 PLUS — 电源效率认证

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **服务器电源核心认证**。虽为自愿，但几乎已成为行业通行标准 |
| **等级** | 白牌→Bronze→Silver→Gold→Platinum→Titanium |
| **服务器典型** | **Gold**（87%/90%/87% @ 20%/50%/100%负载）为入门 |
| | **Platinum/Titanium** 为AI服务器高性能电源标配 |
| **价值** | 直接影响TCO——Titanium vs Gold 约差2-3%效率，万台集群年省数十万电费 |

## 5. 日本

### 5.1 PSE — 电气用品安全法认证

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **强制适用**。服务器属于"非特定电气用品"（非特定電気用品）|
| **法律依据** | 電気用品安全法（DENAN Law） |
| **分类** | **菱形PSE**（特定電気用品）：116品类，需第三方认证 |
| | **圆形PSE**（非特定電気用品）：340+品类，制造商自我声明 |
| | 服务器 → **圆形PSE**（通常路径）|
| **标准** | JIS C 62368-1（等同IEC 62368-1）|
| **认证模式** | 圆形PSE：自我确认 + 测试记录保存 |
| **周期** | 4-8周 |
| **成本** | ¥300K-800K JPY |

### 5.2 VCCI — 自愿性EMC认证（事实强制）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **事实强制**。VCCI虽为自愿性，但日本市场几乎100%要求 |
| **分类** | **Class A**：企业/工业环境用（服务器适用）|
| | **Class B**：家庭环境用 |
| **标准** | VCCI V-2/3/4（等同CISPR 32/35）|
| **认证模式** | 自我声明 + VCCI注册实验室测试 |
| **周期** | 2-4周 |
| **注意事项** | ⚠️ 服务器电源含PFC电路，需特别关注谐波电流（VCCI V-4） |

### 5.3 MIC — 电波法认证（含无线模块时）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ⚠️ **仅当服务器含无线模块时** |
| **法律依据** | 電波法（Radio Act）|
| **周期** | 4-8周 |

### 5.4 日本节能法（Top Runner Program）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用**。日本节能法将服务器列为"特定機器" |
| **要求** | 能效指标（APF/年度性能系数）达标，能效标签标示 |
| **实测** | 服务器按"性能/kWh"评价 |

### 5.5 J-Moss（日本RoHS）

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **适用**。要求标注6种有害物质含量 |
| **标准** | JIS C 0950 |

### 5.6 日本认证打包策略

**建议路径**：PSE + VCCI 同步测试（共用实验室），周期可压缩至6-8周。

## 7. 其他国际认证排查

### 7.1 PTCRB — PCS Type Certification Review Board

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ❌ **不适用普通服务器**。PTCRB是**移动设备**的蜂窝（3GPP）一致性认证 |
| | ✅ **仅在服务器含蜂窝模块时适用**（如5G Edge Server）|
| **覆盖范围** | 北美运营商验证（AT&T/T-Mobile/Verizon等） |
| **标准** | 3GPP TS 34.x系列 |

### 7.2 GCF — Global Certification Forum

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ❌ **不适用普通服务器**。与PTCRB类似，是移动设备蜂窝认证 |
| | ✅ **仅在服务器含蜂窝模块时适用** |
| **与PTCRB差异** | GCF覆盖全球（非北美），PTCRB聚焦北美 |
| **选择策略** | 若服务器销北美 → PTCRB；销欧洲/亚太 → GCF |

**结论**：PTCRB + GCF 对标准服务器产品线（机架式/塔式/刀片）均 **不适用**，仅对5G Edge Server、MEC服务器等含蜂窝通信的产品有意义。

### 7.3 EVO — Efficiency Valuation Organization

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ❌ **不是产品认证**。EVO是国际能效评估组织 |
| **核心产品** | IPMVP（国际能效测量与验证协议）|
| **对服务器的意义** | EVO本身不认证产品，但其IPMVP协议被数据中心能效评估广泛引用 |
| | 与之相关的 **ISO 50001**（能源管理体系）是数据中心常用的管理框架 |
| | 可视为数据中心PUE评估的方法论基础 |

**排查结论**：EVO在企业产品认证体系中**不构成独立认证项目**，其影响通过ISO 50001、数据中心能效评估等间接体现。

### 7.4 CTA — Consumer Technology Association

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ❌ **非标准产品认证**。CTA(美国消费技术协会)管理CTA Mark和CTA Green Mark |
| | ⚠️ 与**中国CTA（电信设备进网许可）** 易混淆 |
| **服务器相关性** | 美标CTA：CTA Mark主要用于AV/CE产品，**服务器通常不适用** |
| | 中国CTA（NAL）：无线通信服务器需另外关注 |
| **排查结论** | 用户清单中"CTA"若指美标CTA → **不适用** |
| | 若指中国进网许可 → 见 §2.3 |

## 8. 云厂商认证

### 8.1 微软认证 — Windows Server / Azure

#### 8.1.1 WHCP — Windows Hardware Compatibility Program

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **运行Windows Server的服务器**必须通过 |
| **旧称** | WHQL（Windows Hardware Quality Labs） |
| **认证范围** | 驱动程序签名 + 硬件兼容性测试 |

| **认证模式** | 通过微软合作伙伴中心提交 → HLK/HCK测试 → 微软签名 |
| **周期** | 4-8周（含驱动开发和测试） |
| **成本** | $5K-15K（测试费）+ 驱动开发成本 |

#### 8.1.2 Azure Certified Server Program — Azure认证服务器

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **面向Azure Stack HCI、Azure本地部署的服务器** |
| **要求** | 完整的硬件验证：CPU/内存/存储/网卡兼容性列表 |
| | 固件配置验证：UEFI设置、Secure Boot、TPM 2.0 |
| | 稳定性测试：长时间负载稳定性 |
| | 管理接口验证：符合Azure管理标准 |
| **等级** | **Azure Stack HCI Catalog**（硬件认证列表）|
| | **Windows Server OEM** 认证 |
| **周期** | 8-16周 |
| **价值** | 入列Azure认证清单 = 可被企业客户选择和采购 |
| | 微软渠道联盟伙伴的市场门槛 |

#### 8.1.3 微软认证的服务器硬件要求

- **TPM 2.0**（强制）
- **Secure Boot**（强制）
- **UEFI**（取代Legacy BIOS）
- **支持Virtualization**（SLAT/IOMMU）
- **特定网卡型号**在Azure Stack HCI认证列表上
- **NVMe SSD**推荐

### 8.2 Google 认证

#### 8.2.1 Google TA — Google Technical Assessment

| 维度 | 内容 |
|:-----|:------|
| **适用性** | ✅ **面向Google自用基础设施的供应商认证** |
| **性质** | Google硬件供应商资质认证，非产品级认证 |
| **场景** | ODM/OEM向Google数据中心供货时必须通过 |

| 认证 | 说明 |
|:-----|:------|
| **Google Cloud Ready** | 面向软件/SaaS产品与GCP的兼容性认证 |
| | 服务器厂商可作为**GCP兼容硬件**申请认证 |
| **Chrome OS认证** | 仅Chromebook/Chromebox，**不涉及服务器** |

#### 8.2.3 关于 Google TA 的进一步说明

"Google TA"在不同语境下的含义：

| 含义 | 服务器相关性 |
|:-----|:------------|
| Google Technical Assessment（供应商硬件认证）| ✅ 高——ODM/OEM供应商认证 |

| Google TensorFlow Approved（AI硬件认证）| ❌ 已改为NVIDIA认证为主 |

**结论**：用户清单中的"Google TA"最可能指**Google Technical Assessment**——Google对其数据中心硬件供应商的全面技术评估认证。这对服务器ODM/OEM有实质意义，但对品牌服务器厂商（Dell/HPE/联想）向Google以外的客户销售无直接影响。
