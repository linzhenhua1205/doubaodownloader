## 1 加工厂互动体系

### 1.1 互动模式与协同流程

| 阶段 | 活动 | 产出 | 超节点变更点 |
|:-----|:-----|:-----|:-------------|
| 需求对接 | 设计需求/工艺要求传递 | 需求确认书 | 液冷/高密度互联专项需求 |
| 工艺确认 | 制造可行性分析 (DFM) | DFM 报告 | 74-78层背钻/盲埋孔 DFM |
| 样品试制 | 工程样机(ES)打样, 工艺参数验证 | ES 测试报告 | 冷板+Manifold试装配 |
| 小批量试产 | 设计验证(DVT) → 小批量(20-50台) | DVT 报告 | 液冷系统气密性验证 |
| 批量爬坡 | 大批量爬坡 | 过程控制数据(SPC) | 产能爬坡节奏 N-2-N |
| 质量验收 | 批次检验, 问题闭环 | 验收报告 | 8D + CAR 闭环 |
| 异常反馈 | 质量问题/产能异常及时预警 | 8D 报告 / SCAR | 48h 内响应 |

### 1.2 加工厂能力资质考核

| 维度 | 考核内容 | 最低要求 | 超节点专项 |
|:-----|:---------|:---------|:-----------|
| PCB 工艺 | 40-78 层高速板, 背钻, 盲埋孔 | 量产良率 ≥95% | 74-78层大背板 + 刚挠结合板 |
| SMT 能力 | 01005 器件, 高密度 BGA | 不良率 <500ppm | 超大尺寸 PCB 的 SMT 精度 |
| 组装能力 | 模组化装配, 线缆规整 | 满足量产节拍 | 液冷管路的 QD 盲配+气密检测 |
| 测试能力 | ICT/飞针/老化/出厂 | 100% 覆盖 | 液冷系统漏液测试台 |
| 质量体系 | ISO9001 / IATF16949 | 已认证 | 超节点级 QA 驻厂 |
| 扩产能力 | 产能可弹性扩展 30%+ | — | 液冷组件产线弹性 50%+ |

### 1.3 加工厂现场稽核要点

```text
稽核前准备(1周) -> 首次会议 -> 现场巡查(2-3天)
  +- 产线: SMT -> DIP -> 组装 -> 测试 -> 包装 全流程
  +- 品质: IQC -> IPQC -> FQC -> OQC 四级检验
  +- 仓储: 温湿度/防潮/ESD/FIFO (先进先出)
  +- 设备: 点检记录/校准证书/CPK 数据
  +- 人员: 上岗证/培训记录/技能矩阵
末次会议 -> 稽核报告 -> CAR 跟踪 (30天闭环)
```

### 1.4 超节点加工厂的特别要求

- **液冷组件产线**: 冷板/Manifold/CDU/QD 组装+测试+气密性检测专业化产线
- **电缆束预组装**: 6144 根 Cable tray 预组装 + 打标 + 防呆设计
- **三方协调**: 芯片(GPU/CPU) + 整机厂 + 液冷部件三方联合生产调度
- **洁净度要求**: 液冷水路系统组装需 Class 1000 洁净间

### 2.2 PCB 制程（服务器级）

| 工序 | 关键参数 | 服务器等级 |
|:-----|:---------|:-----------|
| **层数** | 普通服务器 40-56 层, 超节点背板 74-78 层 | ±2 层容差 |
| **板材** | Megtron 6 (112Gbps), Megtron 7 (224Gbps) | Dk/Df 一致性 ±5% |
| **背钻深度** | 残桩 < 8mil (减少 stub 效应) | 深度公差 ±1mil |
| **胀缩控制** | 大板 (24"×30") 涨缩量 < ±3mil | 多层对位精度 |
| **阻抗控制** | 单端 50Ω ±10%, 差分 85/100Ω ±10% | TDR 全检 |
| **阻焊桥** | 0.1mm 阻焊桥 (BGA 扇出区) | 无桥连 |
| **表面处理** | ENIG (化镍金) / OSP | 金厚 2-5μ" |

### 2.3 SMT 贴片工艺

| 工序 | 关键控制点 | 超节点特殊要求 |
|:-----|:-----------|:--------------|
| **锡膏印刷** | 钢网厚度 0.1-0.12mm, 脱模速度 1-3mm/s | 底部填充胶预涂 |
| **高速贴片** | 0201/01005 元件贴装精度 ±40μm | BGA 贴装精度 ±25μm |
| **回流焊接** | 温度曲线 235-245℃ (峰值), 升温斜率 <3℃/s | 大板温均性 ±2℃ |
| **AOI 检测** | 焊点形态/偏移/桥连/缺件 100% 覆盖 | X-Ray 全检 (BGA/QFN) |
| **返修** | BGA 植球/更换 + X-Ray 确认 | 超大 BGA 返修工装 |

### 2.4 整机组装工艺

| 模组 | 组装流程 | 关键质量点 | 工时 (min) |
|:-----|:---------|:-----------|:----------:|
| **主板入箱** | 主板定位 → 螺钉锁付(扭矩管控) → 散热器安装 | 螺钉扭矩 ±5% | 8-12 |
| **背板互联** | PCIe Riser 装配 → 高速线缆连接 → 锁附 | PCIe 金手指插入深度 | 5-8 |
| **电源模组** | PSU 导轨安装 → PSU 插入 → 电源线束 | 电源模组 ID 读取 | 3-5 |
| **风扇墙** | 风扇 tach 检测 → 热插拔安装 → 线缆归束 | 风扇 PWN 信号 | 5-8 |
| **液冷管路** | 冷板→Manifold→QD→CDU 全链路装配 | QD 盲配力 + 气密性 | 15-25 |
| **线缆布放** | 数据线/电源线/信号线分层扎带 | 最小弯曲半径 5×线径 | 10-15 |
| **系统盲配** | 节点推入机柜 → 背板对位 → QD 盲配 | 插入力 < 200N | 5-10 |

### 2.5 液冷系统专项工艺

| 项目 | 工艺要求 | 检测方法 | 允收标准 |
|:-----|:---------|:---------|:---------|
| **冷板平面度** | ≤0.1mm | 激光干涉仪 | Cpk ≥ 1.33 |
| **管路去焊渣** | 内腔无颗粒 >200μm | 压差法 + 颗粒计数器 | ISO 4406 等级 16/13 |
| **QD 盲配寿命** | ≥1000 次插拔 | 寿命测试 | 插入力变化 < 20% |
| **气密性** | 氮气加压 1.5×工作压力 | 压降法 (10min < 0.1bar) | 零泄漏 |
| **水路洁净度** | ≤100μm 颗粒, 无毛刺 | 内窥镜 + 冲洗 | 清洁度等级 |
| **保温** | 管路外壁保温棉 + 防凝露 | 露点测试 | 无冷凝 |

## 4 良率管理

### 4.1 良率金字塔模型

```text
                        +--------------------+
                        |   最终出货良率       |  Y_final ≥ 97%
                        |  Y_final = Y_pcb ×  |
                        |  Y_smt × Y_assem ×  |
                        |  Y_test × Y_burn    |
                        +----------+---------+
                                   |
              +--------------------+--------------------+
              v                    v                    v
     +----------------+  +----------------+  +----------------+
     |  PCB 良率       |  |  SMT 良率       |  |  组装良率       |
     |  Y_pcb ≥ 85%    |  |  Y_smt ≥ 98%    |  |  Y_assem ≥ 97%  |
     |  (含拼板损耗)    |  |  (含 DPMO)       |  |  (含返修损耗)    |
     |  . 内层短路/开路 |  |  . 立碑/偏移     |  |  . 螺钉漏锁     |
     |  . 层间对准度    |  |  . 少锡/空焊     |  |  . 线缆错接     |
     |  . 阻抗偏差     |  |  . BGA 桥接     |  |  . 液冷泄漏     |
     |  . 板弯板翘     |  |  . 元件损伤     |  |  . 金手指划伤   |
     +----------------+  +----------------+  +----------------+
```

### 4.2 各阶段良率目标 (AI 服务器)

| 阶段 | 当前行业水平 | 挑战目标 | 超节点特殊要求 |
|:-----|:------------|:---------|:--------------|
| **PCB 制造良率** | 75-85% (74层) | ≥85% | 超大背板 (700×600mm) 挑战大 |
| **SMT 一次良率** | 97-99% | ≥98% | 超大 PCB + 高密度 BGA |
| **组装一次良率** | 95-97% | ≥97% | 液冷管路 + QD 盲配 |
| **测试一次通过率** | 90-95% | ≥93% | 72 GPU 互联故障排查复杂 |
| **老化通过率** | 95-98% | ≥97% | 全互联负载下温控稳定性 |
| **最终出货良率** | 85-93% | ≥92% | 首批 85%, 爬坡后 93% |
| **36 月返修率** | 3-5% | ≤3% | 液冷系统 ≤1% |

### 4.3 良率损失分析 (YLA)

```text
YLA 方法论: 发现 -> 量化 -> 根因 -> 改善 -> 闭环

步骤1: 分层良率损失识别
  +- PCB 层: 内层短路(30%) / 阻抗偏差(20%) / 板弯(15%)
  +- SMT 层: BGA 虚焊(25%) / 立碑(15%) / 少锡(12%)
  +- 组装层: 线缆错接(20%) / 漏锁螺丝(15%) / 液冷泄漏(10%)
  +- 测试层: 上电失败(15%) / 传感器异常(12%) / 链路问题(10%)

步骤2: Pareto 分析
  - 前三项缺陷占总损失的 50-60%
  - 集中资源攻克 Top 3 -> 良率提升 5-10%

步骤3: 改善行动
  短期 (1-2周): 工艺参数调整 + 操作 SOP 优化
  中期 (1-3月): 治具改良 + 防呆设计 + 自动化
  长期 (3-6月): 设计优化 -> 下一代 DFX
```

### 4.4 良率管控关键工具

| 工具/方法 | 用途 | 服务器场景 |
|:----------|:-----|:-----------|
| **SPC (统计过程控制)** | 关键参数监控 (X-bar R Chart) | 焊膏厚度/回流温度/线缆插拔力 |
| **Cpk 过程能力** | 衡量过程稳定性 (目标 ≥1.33) | 阻抗控制/螺钉扭矩/平面度 |
| **Pareto 分析** | 缺陷主次排序 | Top-3 缺陷集中改善 |
| **FMEA (失效模式分析)** | 预防性识别风险 | 液冷泄漏 / QD 盲配失败 |
| **8D 报告** | 批量问题根因 & 持久纠正 | 产线重大质量问题 |
| **GR&R (量具重复性)** | 检测系统一致性 (GR&R <10%) | 扭矩扳手/气密检测仪 |
| **DPU / DPMO** | 单位缺陷数 / 百万机会缺陷 | SMT 目标 DPMO < 500 |

### 4.5 超节点良率特别关注

| 挑战 | 影响 | 改善措施 |
|:-----|:-----|:---------|
| **74-78层大背板** | 胀缩+对准导致良率 75-85% | 采用低 CTE 材料 + 工艺窗口优化 |

```text
| . BMC 远程   | . 模块替换  | . 维修/翻新    | . 备件库存策略    |
| . 日志分析   | . 固件升级  | . 质量分析     | . 全球备件网络    |
| . 知识库     | . 现场测试  | . 文件更新     | . 逆向物流        |
+-------------+-------------+---------------+------------------+
```

### 9.2 FRU (现场可更换单元) 定义

| FRU 级别 | 定义 | 更换时间目标 | 技术要求 | 超节点示例 |
|:---------|:-----|:------------|:---------|:-----------|
| **Level 1** | 客户自更换 (CRU) | < 5 min | 免工具, 有指南 | 风扇/PSU/SSD |
| **Level 2** | 现场工程师更换 (FRU) | < 30 min | 基本工具 | 计算 Tray/GPU 模组 |
| **Level 3** | 现场高级更换 | < 2h | 专用工具+培训 | NVSwitch Tray/CDU |
| **Level 4** | 返厂维修 | 7-15 天 | 产线级 | 主板/液冷系统 |

### 9.3 各 FRU 级别更换说明

```text
                  更换难度与时间
                    ^
                    |  L4: 主板/液冷系统
                    |     (返厂, 7-15天)
                    |
                    |  L3: NVSwitch tray / CDU
                    |     (高级现场, <2h)
                    |
                    |  L2: 计算 Tray / GPU 模组
                    |     (现场工程师, <30min)
                    |
                    |  L1: 风扇 / PSU / SSD
                    |     (客户自换, <5min)
                    +--------------------------> 更换频率
                         高 <---------> 低
```

### 9.4 RMA 流程

```text
客户报修 -> 远程诊断 (BMC日志+故障现象)
  +- 远程可解 -> 远程修复 (固件升级/配置恢复)
  +- 远程不可解 -> 派单
       +- 现场维修 -> 携带 FRU 备件 -> 现场更换 -> 旧件回收 -> 维修报告
       +- 返厂维修 (RMA)
            +- 客户寄回故障品
            +- 入库扫描 -> 故障复现 -> 根因分析
            +- 维修/翻新 -> 功能测试 -> 老化测试
            +- 出库 -> 返还客户
            +- 质量数据录入 -> 8D 报告 (批量问题) -> 设计/工艺改善
```

### 9.5 故障数据闭环 (FBC)

```text
现场故障 -> RMA 记录 -> 根因分析 -> 改善行动 -> 验证 -> 闭环
  v           v          v          v         v       v
服务工单  故障码   失效分析   ECN/工艺  小批量  关闭
          FRU PN   (FMA)     改善      验证     + 知识库
```

| 数据项 | RMA 必填 | 用途 |
|:-------|:--------:|:-----|
| 故障码 | ✅ | 分类统计 (Top-N 分析) |
| FRU PN + 序列号 | ✅ | 备件追溯 + 批次分析 |
| 运行时长 | ✅ | 可靠性统计 (MTBF/wear-out) |
| 故障日志 | ✅ | 根因分析输入 |
| 环境数据 (温度/湿度) | ⚠️ 推荐 | 环境关联分析 |
| 维修操作记录 | ✅ | 维修质量追溯 |

### 9.6 备件库存策略

| 备件等级 | 覆盖范围 | 库存策略 | 响应时间 |
|:---------|:---------|:---------|:---------|
| **P1 关键备件** | 区域备件库 | 安全库存 ≥ 在用量的 5% | 4h 到场 |
| **P2 重要备件** | 区域备件库 + 中央 | 安全库存 ≥ 在用量的 2% | 24h 到场 |
| **P3 常规备件** | 中央备件库 | 按照历史消耗备货 | 48h 送达 |
| **P4 非常规** | 按需采购 | 不常备, 下单后 5-7 天 | 按订单 |

## 11 整机包装与运输

### 11.1 防护层级

| 防护层级 | 方案 | 标准 | 超节点变更点 |
|:---------|:-----|:------|:-------------|
| **内层** | 防静电袋 (ESD Bag) | ESD S20.20 | 液冷接头防尘帽+防静电 |
| **中层** | 定制 EPE/EPP 防震衬垫 | ISTA 3E | 液冷管路 EPE 定制槽 |
| **外层** | 五层瓦楞纸箱/木箱 | ISTA 3A | 木箱加固 (≥500kg) |
| **标识** | 易碎/防潮/向上/SN | 物流规范 | 液冷警告 + 倾角监测 |
| **运输** | 陆运/空运/海运 | -20℃~60℃ | 液冷排空+干燥 |

### 11.2 液冷系统运输专项

| 项目 | 要求 | 检测方法 |
|:-----|:-----|:---------|
| **运输前排空** | 冷却液 100% 排空 | 称重对比 + 气吹残余 |
| **QD 防泄漏** | QD 自动密封 + 防误触盖 | 压降法 |
| **倾角监测** | 安装倾角标签 (≤30°) | 倾角指示器变色即报警 |
| **防震包装** | 冷板+Manifold 独立固定 | ISTA 3E 随机振动 |
| **温度记录** | 内置温度记录仪 (-20~60℃) | 全程数据回传 |
| **首次加注** | 现场加注冷却液 | 现场服务流程 |

### 11.3 运输过程管控

| 运输方式 | 适用场景 | 周期 | 风险 | 备选方案 |
|:---------|:---------|:----:|:-----|:---------|
| **陆运 (专车)** | 国内/省份内 | 1-3 天 | 颠簸/天气 | 保险 + 倾角监测 |
| **陆运 (零担)** | 国内/小批量 | 2-5 天 | 中转多次, 破损率↑ | 减少中转次数 |
| **空运** | 海外/紧急 | 1-3 天 | 成本高 | 加急 |
| **海运** | 海外/批量 | 15-30 天 | 盐雾/湿度/时间长 | 真空包装+干燥剂 |
