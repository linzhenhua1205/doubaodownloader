## 1. NUMA概述

### 1.1 NUMA定义

NUMA（Non-Uniform Memory Access）：

- 非统一内存访问架构
- 每个处理器节点有本地内存
- 本地内存访问速度快于远程内存

### 1.2 NUMA特点

特点：

- **本地内存**：访问延迟低
- **远程内存**：访问延迟高
- **内存节点**：多个内存节点
- **CPU节点**：多个CPU节点

### 1.3 NUMA架构

架构组成：

- **NUMA节点**：包含CPU和内存
- **节点间互联**：节点间通信
- **内存控制器**：内存控制
- **缓存一致性**：缓存一致性协议

## 2. NUMA感知

### 2.1 NUMA节点信息

查看NUMA信息：

```bash
numactl --hardware
numa_node -v
```

信息内容：

- **节点数量**：NUMA节点数量
- **CPU数量**：每个节点的CPU数量
- **内存大小**：每个节点的内存大小
- **节点距离**：节点间距离

### 2.2 进程NUMA分配

分配策略：

- **默认分配**：系统默认分配
- **本地分配**：优先本地内存
- **绑定分配**：绑定到特定节点

### 2.3 内存分配策略

策略类型：

- **interleave**：交错分配
- **preferred**：首选节点
- **localalloc**：本地分配
- **bind**：绑定节点

## 3. NUMA优化策略

### 3.1 进程绑定

绑定方法：

```bash
numactl --cpunodebind=0 --membind=0 ./program
taskset -c 0-7 ./program
```

绑定原则：

- **CPU绑定**：绑定到特定CPU
- **内存绑定**：绑定到特定内存节点
- **节点绑定**：绑定到同一NUMA节点

### 3.2 内存分配优化

优化策略：

- **本地内存优先**：优先分配本地内存
- **内存预分配**：提前分配内存
- **内存对齐**：内存地址对齐
- **大页内存**：使用大页内存

### 3.3 线程调度优化

调度策略：

- **线程绑定**：绑定线程到CPU
- **亲和性设置**：设置CPU亲和性
- **负载均衡**：均衡CPU负载
- **避免跨节点调度**：避免线程跨节点

### 3.4 数据布局优化

布局策略：

- **数据本地化**：数据放在本地内存
- **数组分块**：数组按NUMA节点分块
- **共享数据**：减少跨节点共享数据
- **私有数据**：每个线程私有数据

## 4. NUMA优化工具

### 4.1 numactl

numactl命令：

- `numactl --hardware`：查看NUMA硬件信息
- `numactl --show`：查看当前NUMA设置
- `numactl --cpunodebind`：绑定CPU节点
- `numactl --membind`：绑定内存节点

### 4.2 libnuma

libnuma函数：

- `numa_available()`：检查NUMA支持
- `numa_max_node()`：获取最大节点号
- `numa_run_on_node()`：设置运行节点
- `numa_alloc_onnode()`：在指定节点分配内存

### 4.3 其他工具

工具列表：

- **numastat**：NUMA内存统计
- **numa_node**：NUMA节点信息
- **perf**：性能分析
- **pthread**：线程亲和性设置

## 6. NUMA优化注意事项

### 6.1 常见问题

问题类型：

- **跨节点访问**：线程跨NUMA节点访问内存
- **内存分配不均**：内存分配不均匀
- **负载不均衡**：CPU负载不均衡
- **缓存失效**：缓存频繁失效

### 6.2 优化原则

原则：

- **数据本地化**：数据尽量放在本地内存
- **计算本地化**：计算尽量靠近数据
- **避免跨节点**：避免跨NUMA节点操作
- **均衡负载**：均衡各节点负载
