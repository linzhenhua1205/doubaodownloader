## 1. 操作系统定义与目标

### 1.1 操作系统概念

操作系统是管理计算机硬件和软件资源的系统软件，为用户和应用程序提供接口。

### 1.2 操作系统目标

| 目标 | 描述 |
|:-----|:-----|
| **方便性** | 使计算机易于使用 |
| **效率** | 高效利用计算机资源 |
| **可扩展性** | 支持新的硬件和软件 |
| **可靠性** | 保证系统稳定运行 |
| **安全性** | 保护系统和数据安全 |

## 2. 操作系统结构

### 2.1 单内核结构

- 所有功能模块运行在内核态
- 性能高但可靠性差
- 代表：Linux（传统）

### 2.2 微内核结构

- 核心功能最小化，运行在内核态
- 其他服务作为用户态进程
- 可靠性高但性能开销大
- 代表：QNX、MINIX

### 2.3 混合内核结构

- 结合单内核和微内核优点
- 核心功能在内核态，部分服务在用户态
- 代表：Windows NT、Linux（现代）

## 3. 进程管理

### 3.1 进程概念

进程是程序的一次执行，包含：

- **代码段**：程序指令
- **数据段**：程序数据
- **栈段**：函数调用和局部变量
- **PCB（进程控制块）**：进程状态信息

### 3.2 进程状态

进程生命周期包含以下状态：

| 状态 | 描述 |
|:-----|:-----|
| **就绪** | 进程已准备好执行，等待CPU |
| **运行** | 进程正在执行 |
| **阻塞** | 进程等待某个事件（如I/O完成） |
| **终止** | 进程执行完毕 |

### 3.3 进程调度

调度算法：

- **FCFS（先来先服务）**：按到达顺序调度
- **SJF（短作业优先）**：优先调度执行时间短的进程
- **RR（时间片轮转）**：每个进程分配时间片轮流执行
- **优先级调度**：按优先级调度进程
- **多级反馈队列**：结合多种算法的综合调度

### 3.4 进程同步

同步机制：

- **信号量**：用于进程间同步和互斥
- **管程**：封装共享资源和同步操作
- **消息传递**：进程间通过消息通信

### 3.5 死锁

死锁条件：

1. **互斥**：资源只能被一个进程占用
2. **占有并等待**：进程占用资源并等待其他资源
3. **非抢占**：资源不能被强制剥夺
4. **循环等待**：进程间形成等待循环

死锁处理：

- 预防：破坏死锁条件
- 避免：银行家算法
- 检测与恢复：定期检测并恢复

## 4. 内存管理

### 4.1 内存管理目标

- 高效利用内存空间
- 支持多道程序设计
- 保护进程内存空间
- 提供虚拟内存

### 4.2 内存分配策略

- **连续分配**：为进程分配连续内存空间
- **非连续分配**：为进程分配非连续内存空间

### 4.3 分页管理

将内存和进程划分为固定大小的页：

- **页表**：记录页号到物理块号的映射
- **TLB（快表）**：加速页表查询

### 4.4 分段管理

将进程划分为逻辑段：

- 代码段、数据段、栈段等
- 段表记录段的基址和长度

### 4.5 段页式管理

结合分段和分页的优点：

- 段内分页
- 先查段表，再查页表

### 4.6 虚拟内存

利用磁盘扩展内存空间：

- **请求分页**：仅在需要时调入页面
- **页面置换算法**：
  - FIFO（先进先出）
  - LRU（最近最少使用）
  - OPT（最优置换）

## 5. 文件系统

### 5.1 文件概念

文件是存储在外部存储设备上的一组相关数据的集合。

### 5.2 文件类型

- **普通文件**：文本文件、二进制文件
- **目录文件**：包含文件和子目录
- **特殊文件**：设备文件、管道文件

### 5.3 文件访问控制

- **权限位**：读、写、执行权限
- **用户分类**：所有者、组、其他用户

### 5.4 文件系统结构

- **引导块**：系统引导信息
- **超级块**：文件系统元数据
- **inode**：文件索引节点
- **数据块**：文件实际数据

### 5.5 文件分配策略

- **连续分配**：为文件分配连续磁盘空间
- **链式分配**：文件数据块链式链接
- **索引分配**：通过索引表管理数据块

## 6. I/O管理

### 6.1 I/O设备分类

- **块设备**：按块访问，如磁盘
- **字符设备**：按字符访问，如键盘
- **网络设备**：网络接口

### 6.2 I/O管理层次

1. **用户层**：用户程序调用
2. **设备无关层**：提供统一接口
3. **设备驱动层**：与具体设备交互
4. **中断处理层**：处理设备中断

### 6.3 I/O调度

优化I/O请求顺序：

- **FCFS**：按到达顺序处理
- **SSTF**：最短寻道时间优先
- **SCAN**：电梯算法
- **C-SCAN**：循环扫描

## 7. 操作系统安全

### 7.1 安全威胁

- 恶意软件
- 网络攻击
- 未授权访问
- 数据泄露

### 7.2 安全机制

- **身份认证**：验证用户身份
- **访问控制**：限制资源访问
- **加密**：保护数据传输和存储
- **审计**：记录系统活动

## 8. 服务器操作系统特性

### 8.1 高可用性

- 容错设计
- 故障转移
- 热备份

### 8.2 高性能

- 多处理器支持
- 大内存管理
- I/O优化

### 8.3 可扩展性

- 水平扩展
- 垂直扩展
- 集群支持

### 8.4 可管理性

- 远程管理
- 监控告警
- 自动化运维

## 9. 实时操作系统

### 9.1 实时系统特性

- **确定性**：任务执行时间可预测
- **及时性**：满足截止时间要求
- **可靠性**：高可靠性要求

### 9.2 实时调度

- **静态优先级调度**：固定优先级
- **动态优先级调度**：根据情况调整优先级
- **速率单调调度**：周期越短优先级越高
