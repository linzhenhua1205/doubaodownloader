## 1. CPU架构基础

### 1.1 CPU核心组件

| 组件 | 功能 | 关键特性 |
|:-----|:-----|:---------|
| **算术逻辑单元 (ALU)** | 执行算术和逻辑运算 | 整数运算、布尔运算 |
| **控制单元 (CU)** | 控制指令执行流程 | 指令解码、时序控制 |
| **寄存器** | 临时存储数据和地址 | 高速、少量 |
| **缓存** | 存储常用数据 | L1/L2/L3多级缓存 |
| **总线接口** | 与内存和I/O通信 | 内存总线、PCIe总线 |

### 1.2 CPU指令集架构

| 类型 | 特点 | 代表 |
|:-----|:-----|:-----|
| **CISC** | 复杂指令、可变长度 | x86 |
| **RISC** | 简单指令、固定长度 | ARM、RISC-V |
| **VLIW** | 超长指令字、并行执行 | Itanium |

### 1.3 CPU流水线

流水线阶段：

1. **取指令**：从内存读取指令
2. **指令解码**：解释指令含义
3. **执行**：执行运算
4. **访存**：访问内存
5. **写回**：写回结果

流水线优化：

- **超标量**：同时发射多条指令
- **乱序执行**：不按顺序执行指令
- **推测执行**：提前执行可能需要的指令

### 1.4 多核处理器

多核架构特点：

- 多个独立核心集成在同一芯片
- 共享L3缓存和内存总线
- 需要多核调度和同步机制

### 1.5 NUMA架构

NUMA（非统一内存访问）：

- 每个处理器有本地内存
- 本地内存访问速度快于远程内存
- 需要NUMA感知的应用优化

## 2. GPU架构基础

### 2.1 GPU与CPU差异

| 维度 | CPU | GPU |
|:-----|:----|:----|
| **核心数量** | 少（2-64） | 多（数百到数千） |
| **线程模型** | 重量级线程 | 轻量级线程 |
| **缓存** | 大缓存 | 小缓存 |
| **控制逻辑** | 复杂 | 简单 |
| **适用场景** | 通用计算 | 并行计算、图形处理 |

### 2.2 GPU核心架构

GPU核心组成：

- **CUDA核心/流处理器**：执行计算
- **Tensor核心**：加速矩阵运算
- **RT核心**：加速光线追踪
- **共享内存**：线程块内共享

### 2.3 GPU编程模型

CUDA编程模型：

- **线程 (Thread)**：最小执行单元
- **线程块 (Block)**：一组线程，共享内存
- **线程格 (Grid)**：一组线程块
- **层次结构**：Grid → Block → Thread

### 2.4 GPU内存层次

内存层次：

1. **寄存器**：每个线程私有，最快
2. **共享内存**：线程块共享，较快
3. **全局内存**：所有线程共享，较慢
4. **常量内存**：只读，缓存优化
5. **纹理内存**：专门优化的只读内存

## 3. 服务器CPU架构

### 3.1 主流服务器CPU

| 厂商 | 系列 | 架构特点 |
|:-----|:-----|:---------|
| **Intel** | Xeon | x86-64、超线程、AVX-512 |
| **AMD** | EPYC | x86-64、多核心、Infinity Fabric |
| **ARM** | 鲲鹏、Ampere | ARMv8/ARMv9、能效比高 |
| **IBM** | POWER | RISC、高可靠性 |

### 3.2 鲲鹏处理器

鲲鹏处理器特点：

- 基于ARMv8架构
- 多核设计（32/48/64核）
- 高集成度SoC设计
- 支持PCIe 4.0、DDR4/5

### 3.3 CPU性能指标

关键指标：

- **主频**：CPU时钟频率（GHz）
- **核心数**：物理核心数量
- **线程数**：逻辑线程数量
- **缓存大小**：L1/L2/L3缓存容量
- **TDP**：热设计功耗（W）
- **IPC**：每时钟周期指令数

## 4. 服务器GPU架构

### 4.1 主流服务器GPU

| 厂商 | 系列 | 应用场景 |
|:-----|:-----|:---------|
| **NVIDIA** | A100/H100 | AI训练、推理、HPC |
| **AMD** | MI200/MI300 | AI训练、HPC |
| **Intel** | Ponte Vecchio | HPC、AI |
| **国产** | 寒武纪、海光 | AI推理、训练 |

### 4.2 GPU性能指标

关键指标：

- **FP32算力**：单精度浮点运算能力（TFLOPS）
- **FP16算力**：半精度浮点运算能力（TFLOPS）
- **INT8算力**：整数运算能力（TOPS）
- **显存容量**：GPU内存大小（GB）
- **显存带宽**：显存数据传输速率（GB/s）
- **TDP**：热设计功耗（W）

### 4.3 GPU加速应用

典型应用：

- **深度学习训练**：大规模神经网络训练
- **深度学习推理**：实时预测服务
- **科学计算**：分子模拟、气候建模
- **图形渲染**：影视渲染、游戏引擎

## 5. 异构计算架构

### 5.1 异构计算概念

异构计算：利用不同类型的处理器协同工作。

### 5.2 异构架构模式

| 模式 | 描述 | 适用场景 |
|:-----|:-----|:---------|
| **CPU+GPU** | CPU负责控制，GPU负责计算 | AI、HPC |
| **CPU+FPGA** | CPU负责通用计算，FPGA负责定制加速 | 低延迟场景 |
| **CPU+ASIC** | CPU负责控制，ASIC负责专用计算 | 大规模推理 |

### 5.3 异构通信

通信方式：

- **PCIe**：CPU与GPU/FPGA通信
- **NVLink**：NVIDIA GPU间高速互联
- **InfiniBand**：多节点间高速通信
- **CXL**：新一代缓存一致性互联

### 5.4 异构计算挑战

- **数据传输**：CPU-GPU数据传输开销
- **编程模型**：异构编程复杂性
- **负载均衡**：任务分配优化
- **能耗管理**：多设备能耗协调

## 6. 处理器可靠性

### 6.1 故障类型

- **硬故障**：永久性损坏
- **软故障**：瞬时错误（如宇宙射线）
- **性能故障**：性能下降

### 6.2 可靠性技术

- **ECC内存**：错误纠正码
- **寄存器冗余**：关键寄存器备份
- **时钟监控**：时钟异常检测
- **温度监控**：过热保护

### 6.3 RAS特性

RAS（可靠性、可用性、可维护性）：

- **可靠性**：系统无故障运行能力
- **可用性**：系统可用时间比例
- **可维护性**：故障后恢复能力
