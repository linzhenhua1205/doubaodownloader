## 1. BIOS基础

### 1.1 BIOS定义

BIOS（Basic Input/Output System）：

- 基本输入输出系统
- 计算机启动时运行的固件
- 初始化硬件、引导操作系统

### 1.2 BIOS功能

核心功能：

1. **POST（加电自检）**：检测硬件是否正常
2. **硬件初始化**：配置硬件参数
3. **引导操作系统**：从存储设备加载OS
4. **提供运行时服务**：为OS提供硬件访问接口

### 1.3 BIOS启动流程

启动步骤：

1. **加电**：电源供应启动
2. **POST**：检测CPU、内存、显卡等
3. **初始化**：配置硬件参数
4. **引导**：读取MBR或GPT，加载OS
5. **移交**：将控制权交给OS

### 1.4 BIOS设置

BIOS配置项：

- **启动顺序**：设置启动设备优先级
- **CPU设置**：倍频、电压等
- **内存设置**：频率、时序等
- **安全设置**：密码保护、安全启动

## 2. UEFI基础

### 2.1 UEFI定义

UEFI（Unified Extensible Firmware Interface）：

- 统一可扩展固件接口
- BIOS的替代品
- 支持更大的启动磁盘、更快的启动速度

### 2.2 UEFI特点

与BIOS对比：

| 特性 | BIOS | UEFI |
|:-----|:-----|:-----|
| **启动速度** | 较慢 | 较快 |
| **磁盘支持** | 最大2TB | 支持GPT，无限制 |
| **图形界面** | 无 | 支持 |
| **扩展性** | 有限 | 高度可扩展 |
| **安全性** | 基本 | 安全启动、Secure Boot |
| **驱动** | 内置 | 可加载驱动 |

### 2.3 UEFI架构

UEFI组成：

- **UEFI Boot Services**：启动时服务
- **UEFI Runtime Services**：运行时服务
- **UEFI Shell**：命令行界面
- **UEFI Applications**：可执行应用

### 2.4 UEFI启动流程

启动步骤：

1. **SEC阶段**：安全验证
2. **PEI阶段**：平台初始化
3. **DXE阶段**：驱动执行环境
4. **BDS阶段**：启动设备选择
5. **TSL阶段**：过渡到OS

### 2.5 UEFI安全特性

安全功能：

- **Secure Boot**：验证启动程序签名
- **TPM支持**：可信平台模块
- **Secure Memory**：保护内存区域

## 3. BIOS/UEFI开发

### 3.1 开发环境

开发工具：

- **EDK II**：UEFI开发套件
- **GCC/Clang**：编译器
- **QEMU**：模拟器
- **Flash编程器**：固件烧录

### 3.2 开发流程

开发步骤：

1. **环境搭建**：安装EDK II和编译工具
2. **模块开发**：编写UEFI驱动或应用
3. **编译**：生成BIOS/UEFI固件
4. **测试**：在模拟器或硬件上测试
5. **烧录**：写入BIOS芯片

### 3.3 BIOS/UEFI调试

调试方法：

- **串口调试**：通过串口输出调试信息
- **UEFI Shell**：在Shell中调试
- **JTAG调试**：硬件调试
- **模拟器调试**：QEMU调试

### 3.4 BIOS/UEFI更新

更新方式：

- **BIOS刷新工具**：Windows/Linux工具
- **UEFI内置更新**：BIOS内直接更新
- **远程更新**：通过BMC远程更新

## 4. BIOS/UEFI与操作系统交互

### 4.1 ACPI接口

ACPI（Advanced Configuration and Power Interface）：

- 高级配置与电源接口
- 操作系统与BIOS/UEFI通信标准
- 支持电源管理、设备配置

ACPI组成：

- **ACPI Tables**：描述硬件信息
- **ACPI Methods**：操作系统可调用的方法
- **ACPI Events**：硬件事件通知

### 4.2 SMBIOS接口

SMBIOS（System Management BIOS）：

- 系统管理BIOS
- 提供系统硬件信息
- 包括主板、CPU、内存等信息

### 4.3 UEFI Runtime Services

运行时服务：

- **GetTime/SetTime**：时间管理
- **GetVariable/SetVariable**：变量管理
- **ResetSystem**：系统重置
- **QueryCapsuleCapabilities**：固件更新

## 5. 服务器BIOS/UEFI特性

### 5.1 服务器特有功能

服务器功能：

- **RAID配置**：BIOS中配置RAID
- **IPMI配置**：配置BMC网络
- **内存配置**：ECC、镜像等
- **CPU配置**：超线程、节能等
- **PCIe配置**：插槽配置、SR-IOV等

### 5.2 高可用性支持

HA支持：

- **冗余BIOS**：双BIOS芯片
- **BIOS恢复**：自动恢复损坏的BIOS
- **远程管理**：通过BMC管理BIOS

### 5.3 安全性

安全特性：

- **安全启动**：防止恶意软件启动
- **BIOS密码**：保护BIOS设置
- **TPM集成**：硬件安全模块

### 5.4 性能优化

优化选项：

- **内存频率**：调整内存速度
- **CPU倍频**：调整CPU频率
- **电源模式**：性能模式或节能模式
- **PCIe速度**：调整PCIe链路速度

## 6. BIOS/UEFI常见问题

### 6.1 启动问题

常见问题：

- **无法启动**：检查启动顺序、硬盘连接
- **启动慢**：优化BIOS设置、禁用不必要设备
- **蓝屏**：检查硬件兼容性、更新BIOS

### 6.2 硬件识别问题

识别问题：

- **内存不识别**：检查内存兼容性、插槽
- **硬盘不识别**：检查RAID配置、数据线
- **PCIe设备不识别**：检查插槽、BIOS设置

### 6.3 更新问题

更新问题：

- **更新失败**：检查电源、固件版本
- **更新后无法启动**：使用BIOS恢复功能
- **兼容性问题**：检查更新说明
