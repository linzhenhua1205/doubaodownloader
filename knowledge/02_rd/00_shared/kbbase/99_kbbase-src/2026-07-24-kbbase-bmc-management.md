## 1. BMC基础

### 1.1 BMC定义

BMC（Baseboard Management Controller）：

- 基板管理控制器
- 独立于主CPU的微控制器
- 提供服务器远程管理能力

### 1.2 BMC功能

核心功能：

1. **远程监控**：温度、电压、风扇状态
2. **远程控制**：开机、关机、重启
3. **远程访问**：KVM over IP、虚拟介质
4. **日志管理**：系统事件日志
5. **告警管理**：硬件故障告警

### 1.3 BMC架构

BMC组成：

- **处理器**：ARM或MIPS架构
- **内存**：Flash和RAM
- **网络接口**：以太网连接
- **传感器接口**：温度、电压传感器
- **系统总线**：I2C、LPC、SPI等

### 1.4 BMC与主系统关系

BMC独立性：

- 独立电源供电
- 独立于主CPU运行
- 即使主系统关机也可工作

## 2. IPMI协议

### 2.1 IPMI定义

IPMI（Intelligent Platform Management Interface）：

- 智能平台管理接口
- 标准化的服务器管理协议
- 支持远程管理和监控

### 2.2 IPMI版本

版本演进：

- **IPMI 1.0**：基础功能
- **IPMI 1.5**：增加LAN接口支持
- **IPMI 2.0**：增加加密、远程KVM等

### 2.3 IPMI命令

命令分类：

- **传感器命令**：读取传感器信息
- **电源命令**：控制电源状态
- **日志命令**：读取系统日志
- **FRU命令**：读取FRU信息
- **SEL命令**：读取系统事件日志

### 2.4 IPMI工具

常用工具：

- **ipmitool**：命令行工具
- **IPMIView**：图形化工具
- **Redfish**：RESTful API

## 3. BMC配置

### 3.1 网络配置

网络参数：

- **IP地址**：静态IP或DHCP
- **子网掩码**：网络掩码
- **网关**：默认网关
- **DNS**：域名服务器

配置方式：

- **BIOS设置**：在BIOS中配置
- **Web GUI**：通过浏览器配置
- **ipmitool**：命令行配置

### 3.2 用户管理

用户配置：

- **用户名**：管理员、操作员等
- **密码**：密码强度策略
- **权限**：管理员、只读、操作员

认证方式：

- **本地认证**：BMC本地用户
- **LDAP认证**：集成LDAP
- **Active Directory**：集成AD

### 3.3 传感器配置

传感器类型：

- **温度传感器**：CPU、主板、硬盘温度
- **电压传感器**：CPU电压、内存电压
- **风扇传感器**：风扇转速
- **电流传感器**：电源电流

告警阈值：

- **下限阈值**：低于此值告警
- **上限阈值**：高于此值告警
- **严重阈值**：严重告警

### 3.4 日志配置

日志类型：

- **系统事件日志 (SEL)**：记录硬件事件
- **FRU信息**：硬件配置信息
- **操作日志**：用户操作记录

日志管理：

- 日志查看
- 日志清除
- 日志导出

### 3.5 网络配置

网络设置：

- **IP地址**：静态或DHCP
- **端口设置**：HTTP/HTTPS端口
- **加密设置**：SSL/TLS配置

## 4. BMC远程管理

### 4.1 Web GUI管理

Web功能：

- **系统状态**：实时监控硬件状态
- **远程控制**：开机、关机、重启
- **虚拟控制台**：KVM over IP
- **虚拟介质**：远程挂载ISO
- **固件更新**：更新BMC和BIOS

### 4.2 命令行管理

ipmitool命令：

- **电源控制**：`ipmitool chassis power on/off/reset`
- **传感器读取**：`ipmitool sensor list`
- **日志读取**：`ipmitool sel list`
- **用户管理**：`ipmitool user list/set`

### 4.3 Redfish API

Redfish特点：

- RESTful API
- 标准接口
- 易于集成

Redfish资源：

- **Chassis**：机箱信息
- **Systems**：系统信息
- **Managers**：BMC信息
- **Sensors**：传感器信息

### 4.4 SNMP管理

SNMP功能：

- 监控服务器状态
- 接收告警信息
- 集成到监控系统

SNMP版本：

- **SNMPv2c**：社区字符串认证
- **SNMPv3**：加密和认证

## 5. BMC安全

### 5.1 安全威胁

威胁类型：

- **未授权访问**：弱密码、默认密码
- **数据泄露**：明文传输
- **恶意固件**：固件篡改
- **拒绝服务**：网络攻击

### 5.2 安全措施

安全策略：

- **强密码**：复杂密码要求
- **加密传输**：HTTPS、IPMI加密
- **固件签名**：验证固件完整性
- **访问控制**：IP白名单、权限分级
- **定期更新**：及时更新固件

### 5.3 安全最佳实践

最佳实践：

- 禁用默认账户
- 启用加密传输
- 配置IP白名单
- 定期审计日志
- 及时更新固件

## 6. BMC固件更新

### 6.1 更新流程

更新步骤：

1. **准备**：下载最新固件
2. **备份**：备份当前固件
3. **上传**：上传固件到BMC
4. **更新**：执行固件更新
5. **验证**：验证更新成功

### 6.2 更新方式

更新方法：

- **Web GUI**：浏览器上传更新
- **ipmitool**：命令行更新
- **远程更新**：通过管理平台更新

### 6.3 更新注意事项

注意事项：

- 保持电源稳定
- 不要中断更新过程
- 检查固件兼容性
- 更新后验证功能

## 7. BMC常见问题

### 7.1 连接问题

连接问题：

- **无法访问BMC**：检查网络连接、IP地址
- **认证失败**：检查用户名密码
- **超时**：检查网络延迟、防火墙

### 7.2 监控问题

监控问题：

- **传感器异常**：检查传感器连接
- **告警误报**：调整阈值
- **日志丢失**：检查日志配置

### 7.3 性能问题

性能问题：

- **响应慢**：检查BMC负载、网络带宽
- **KVM卡顿**：检查网络质量
- **虚拟介质慢**：检查网络带宽
