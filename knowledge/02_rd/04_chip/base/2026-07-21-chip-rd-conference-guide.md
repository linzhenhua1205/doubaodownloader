## 1️⃣ 会议全景分类

芯片研发会议按定位可分为五类，覆盖从器件物理到系统集成的全部研发环节：

```text
+---------------------------------------------------------------------+
|                    芯片研发会议全景分类                                |
+---------------+---------------+---------------+-------------------+
|   学术顶会      |   产业展会     |   中国区学术    |   垂直专题        |
|               |               |               |                   |
|  ISSCC/ISSCC  |  SEMICON West |  ISCAS/ICTA   |  AI芯片专题        |
|  IEDM/VLSI    |  GTC/NVIDIA   |  APCCAS/ICEPT |  封装/Chiplet      |
|  DAC/ICCAD    |  3D Summit    |  CSEAC        |  车规/EDA         |
|  ISCA/HPCA    |  IP Summit    |               |  存储专题          |
|               |               |               |                   |
|  --- 学术 ---  |  --- 产业 --- |  --- 本土 --- |  --- 垂直 ---     |
|  论文/成果      |  产品/商务     |  政策/合作     |  深度/聚焦        |
+---------------+---------------+---------------+-------------------+
```

| 类别 | 典型会议 | 核心目的 | 目标人群 | 参会成本 |
|:-----|:---------|:---------|:---------|:--------|
| **国际学术顶会** | ISSCC/DAC/IEDM/ISCA | 发布原创成果、跟踪前沿技术 | 学术/研发 | 高（差旅+注册$500-1500） |
| **国际产业展会** | SEMICON/GTC | 产品发布、商务对接、路线图 | 产业/商务 | 较高（展位+差旅） |
| **中国区学术** | ISCAS/ICTA/ICEPT | 国产成果、本土合作、政策解读 | 国内研发 | 中等（$200-500） |
| **中国产业大会** | SEMICON China/IC China | 国产化、产业链对接、人才招聘 | 全产业链 | 中等 |
| **垂直专题论坛** | AI Chip/Chiplet/车规 | 深度技术、同行交流 | 细分领域 | 低-中 |

| **ESSCIRC** | ~45% | ~250篇 | ★★★☆☆ 中等 | 欧洲电路设计 → 区域友好 |

**投稿成功率提升策略**：

1. **数据完整性**：有流片测试结果的文章录用率是纯仿真稿的 2-3×
2. **量化对比**：与 SOTA 做同条件 benchmark，不含糊比较
3. **可复现性**：开源代码/开放数据集可增加 20-30% 审稿人好感
4. **评审针对**：了解该会议审稿人偏好（DAC 重算法、ISSCC 重实测）
