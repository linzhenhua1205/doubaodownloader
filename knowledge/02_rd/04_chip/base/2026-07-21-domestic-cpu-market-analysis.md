## 1. 执行摘要

**核心结论**: 国产 CPU 产业已从"政策驱动"进入"政策+市场双轮驱动"阶段。六大厂商形成 **3+3 格局**（三大自主路线 + 三大兼容路线），2026 年国内 CPU 国产化率约 **10-18%**（按价值计），政策驱动的信创市场替代率约 **50-70%**。未来 3-5 年可替代的 Intel+AMD 空间约 **$4-8B/年**（服务器）+ **$2-4B/年**（桌面/笔记本）。

| 指标 | 2024E | 2025E | 2026E | 2027E | 2028E |
|:-----|:-----:|:-----:|:-----:|:-----:|:-----:|
| 中国服务器 CPU TAM ($B) | $6.5-8.0 | $7.0-8.5 | $7.5-9.0 | $8.0-9.5 | $8.5-10 |
| Intel+AMD 占比 | 88-92% | 83-87% | 78-82% | 70-75% | 60-68% |
| 国产 CPU 占比（价值） | 6-10% | 10-15% | 13-18% | 18-25% | 25-35% |
| 信创市场国产化率 | 40-50% | 50-60% | 55-70% | 65-80% | 75-85% |

## 2. 国产 CPU 六大系全景

中国 CPU 产业按**指令集架构（ISA）**可分为三大路线：

```text
国产 CPU 六大系
|
+- === 自主 ISA 路线 ===
|   +-- 🐉 龙芯 (Loongson) -> LoongArch（完全自主）
|   +-- 🖥️ 申威 (SW/Shenwei) -> SW64（自主迭代，Alpha衍生）
|
+- === ARM 授权路线 ===
|   +-- 🦅 华为鲲鹏 (Kunpeng) -> ARM v8.2+ (TaiShan 核)
|   +-- 🐯 飞腾 (Phytium) -> ARM v8.2+ (自研核)
|
+- === x86 兼容路线 ===
|   +-- 💠 海光 (Hygon) -> x86 (AMD Zen 1 授权迭代)
|   +-- 🔷 兆芯 (Zhaoxin) -> x86 (VIA Centaur 授权迭代)
|
+-- 🔮 新兴力量
    +-- 平头哥 (T-Head) -> RISC-V / ARM (AI 推理)
    +-- 进迭时空 / 算能 -> RISC-V (IoT/边缘)
```

## 3. 各厂商深度分析

### 3.1 华为鲲鹏 (Kunpeng)

| 维度 | 内容 |
|:-----|:------|
| **架构** | ARM v8.2+，自研 **TaiShan** 核心 |
| **代表产品** | Kunpeng 920 (7nm, 48-64核, 2.6GHz), Kunpeng 930 (传闻 5nm+) |
| **定位** | 数据中心 / 云服务器 / 华为云生态 |
| **母公司** | 华为海思 (HiSilicon) |
| **制程** | 7nm (台积电/受限)，转向中芯国际 N+2 替代 |

**机会点**:

- 🏆 **全栈优势**: 从 CPU→昇腾 NPU→HCCS 互联→MindSpore→CANN→华为云，华为拥有国产最完整的 AI 基础设施堆栈
- ☁️ **华为云入口**: 鲲鹏是华为云和昇腾超节点的 Host CPU，随华为云增长锁定份额
- 🌐 **Kunpeng 生态**: openEuler 开源操作系统 + Kunpeng DevKit + 鲲鹏社区，软件生态成熟度国产最高
- 📈 **信创主力**: 在电信运营商（移动/联通/电信）、金融（工行/建行）已有大规模部署

**风险**:

- ⛔ **制裁受限**: 5nm 以上先进制程被卡，Kunpeng 930 迭代节奏受制造产能制约
- 🏢 **单一绑定**: 华为云非中立平台，外部 CSP 客户（阿里/腾讯/字节）有顾虑
- 🔄 **异构复杂度**: 鲲鹏 + 昇腾的双芯片生态维护成本高

### 3.2 飞腾 (Phytium)

| 维度 | 内容 |
|:-----|:------|
| **架构** | ARM v8.2+，自研 FTC66x/FTC86x 核心 |
| **代表产品** | 腾锐 S2500 (64核, 服务器), D2000 (8核, 桌面), S5000C (新代) |
| **定位** | 信创服务器 / 桌面 / 嵌入式 |
| **母公司** | 中国电子信息产业集团 (CEC) 旗下 |
| **制程** | 16nm / 14nm / 7nm |

**机会点**:

- 🏛️ **信创核心底座**: CEC 旗下权威国企身份，在党政军、央国企信创采购中占据核心位置
- 🖥️ **桌面生态先行**: D2000 是信创桌面 CPU 的主力选型之一，适配 200+ 款国产操作系统/软件
- 🌉 **ARM 生态桥梁**: ARM 生态服务器软件兼容性好，迁移成本低于自主 ISA
- 🔬 **新制程追赶**: S5000C 系列传言采用更先进制程，性能向 Intel Xeon Silver 看齐

**风险**:

- 🐢 **性能掉队**: 与 Intel/AMD 最新代差仍大（S2500 约等于至强 Gold 5xxx 入门级）
- 🔗 **ARM 授权风险**: ARM 与中美关系交叉影响长期授权稳定性
- 🔄 **交叉竞争**: 与鲲鹏同为 ARM 路线，在信创市场直接竞争

### 3.3 龙芯 (Loongson)

| 维度 | 内容 |
|:-----|:------|
| **架构** | **LoongArch**（完全自主 ISA，非 ARM/x86/RISC-V 授权） |
| **代表产品** | 3C6000 (16-128核, 服务器), 3A6000 (4-8核, 桌面), 2K3000 (嵌入式) |
| **定位** | 信创 / 工控 / 边缘计算 / 轻量化服务器 |
| **母公司** | 龙芯中科 (Loongson Technology) |
| **制程** | 12nm / 14nm |

**关键动态**:

- ✅ **3C6000 系列**: 128 核服务器 CPU（对标 Intel 第三代至强），**2026 年已适配 48 家企业整机方案**，核心元器件 100% 国产化
- ✅ **终端集成**: 3B6000M / 2K3000 集成自研 LG200 GPGPU（230.4 GFLOPS），4K@60fps 视频处理
- ✅ **生态闭环**: 35 家企业推出工控终端与笔记本产品
- ✅ **低功耗优势**: 3C3000 16核仅 **40W**，适合边缘/轻量部署

**机会点**:

- 🛡️ **100% 自主可控**: LoongArch 是中国唯一不受任何外国 ISA 授权限制的 CPU 架构，在最高安全等级场景（军工/涉密）具备独特优势
- ⚡ **低功耗差异化**: 服务器 CPU 40W 功耗远低于 x86 竞品（同级别 100-200W），适合边缘/绿色数据中心
- 🔩 **工控+终端**: LG200 GPU 集成打造真正的国产 SoC，在工业控制、单板计算机领域打开新市场
- 📈 **政策红利**: "核心元器件 100% 国产化"在信创最高等级采购中有加分

**风险**:

- 🐌 **性能代差**: 128 核对标 Intel Gen3 Xeon（Ice Lake, 2021），落后当前 Intel Granite Rapids 2-3 代
- 🔌 **PCIe 通道少**: 仅 32 条 PCIe lanes（AMD EPYC 128+，Intel Xeon 80+），限制高密度部署
- 🧩 **生态孤岛**: LoongArch 需独立适配操作系统和中间件，软件丰富度远低于 ARM/x86
- 📊 **服务器性能**: 16核 40W 定位的 3C3000 "匹配前代 3C5000" 暗示性能提升有限

### 3.4 海光 (Hygon)

| 维度 | 内容 |
|:-----|:------|
| **架构** | x86 兼容（基于 AMD Zen 1 架构 IP 授权）|
| **代表产品** | 海光 71xx/72xx (x86 服务器), 海光 7000 系列 (新代) |
| **定位** | 高性能计算 / AI 训练推理 / 数据中心 |
| **母公司** | 成都海光集成电路 (中科曙光持股) |
| **制程** | 14nm / 7nm |

**关键动态**:

- 📈 **H1 2026 预增**: 海光信息发布 H1 预增公告，全精度路线驱动增长（来源: 双周报 §2.8）
- 🧠 **AI 推理**: 海光 AI 处理器（DCU）在信创 AI 推理场景快速渗透
- 🏢 **中科曙光关联**: 深度绑定中科曙光服务器渠道，形成"海光 CPU + 曙光服务器"闭环

**机会点**:

- ⚡ **x86 无缝兼容**: 对信创用户来说，x86 兼容是**迁移成本最低**的路线——现有 x86 应用无需重编译
- 🧮 **AI 全精度**: 海光 DCU 支持 FP32/FP64 全精度训练，在科学计算/传统 HPC 领域有独特优势
- 🏛️ **双 CPU 生态**: 海光 + 曙光组成"国产 x86+HPC"标杆方案，在教育科研、气象、石油勘探等传统 HPC 市场稳固
- 🚀 **企业治理进步**: 海光信息在科创板上市，资本化后研发投入有保障

**风险**:

- 🔐 **技术路径依赖**: Zen 1 架构（2017）基础，后续自主迭代受限，与 Intel/AMD 最新架构（Zen 5/Granite Rapids）差距拉大
- 🇺🇸 **制裁升级风险**: Hygon 已在 2019 年被列入 US Entity List，后续技术升级路径严重受限
- 📉 **性能天花板**: 基于 Zen 1 的深度优化可能遇到架构本身的上限

### 3.5 兆芯 (Zhaoxin)

| 维度 | 内容 |
|:-----|:------|
| **架构** | **x86 兼容**（VIA Centaur Technology 授权 + 自主迭代） |
| **代表产品** | KX-7000 (8核, 桌面), KH-40000 (16-32核, 服务器) |
| **定位** | 桌面 / 轻量服务器 / 政府办公 |
| **母公司** | 上海兆芯集成电路 (VIA + 上海国资委合资) |
| **制程** | 16nm / 7nm (计划) |

**机会点**:

- 🖥️ **桌面 x86 垄断**: 在信创桌面替换中，x86 兼容是最平滑的用户体验——不改变操作习惯
- 🏛️ **地方政府信创**: 兆芯深度绑定上海/长三角地方政府信创采购
- 💰 **授权稳定性**: VIA 长期持有 x86 交叉授权，法律风险低于 Hygon

**风险**:

- 🐢 **性能严重滞后**: KX-7000 8核桌面 CPU 大致对标 Intel 第 10-11 代酷睿，落后主流 4-5 代
- 🛑 **服务器竞争力弱**: KH-40000 服务器 CPU 在核心数/内存通道/PCIe 通道上与竞品差距大
- 📉 **市场份额萎缩**: 在桌面信创市场，飞腾 D2000 和华为鲲鹏 920 正在挤压兆芯份额

### 3.6 申威 (SW/Shenwei)

| 维度 | 内容 |
|:-----|:------|
| **架构** | **SW64**（自主 ISA，DEC Alpha 衍生后完全剥离） |
| **代表产品** | SW26010 (众核, HPC), SW26010Pro (改进版), 新一代 SW CPU |
| **定位** | 超算 / HPC / 国防 / 科学研究 |
| **母公司** | 上海高性能集成电路设计中心 (军方背景) |
| **制程** | 28nm / 14nm |

**机会点**:

- 🎯 **超算独苗**: 神威·太湖之光（SW26010）至今仍是国产超算标志，在新一代超算采购中有不可替代地位
- 🛡️ **国防市场**: SW64 在涉密最高等级场景有独占优势
- 🏆 **特定领域算力**: SW26010 的众核架构在特定 HPC 应用场景有性能优势

**风险**:

- 📉 **通用性极低**: 软件生态几乎不存在，无法进入信创或商业市场
- 🏗️ **产线老化**: 28nm 制程功耗比差，在商业上无竞争力
- 🔒 **市场太窄**: 仅服务超算+国防，总市场规模<$100M/年

## 5. 市场空间量化分析

### 5.1 中国服务器 CPU 市场规模

#### 5.1.2 中国市场

**信创 CPU 关键趋势**:

- **2024-2025**: 党政信创基本完成，转向央国企和关键行业
- **2025-2026**: 金融/电信/能源等"8+2"行业信创加速
- **2026-2027**: 互联网/云厂商被纳入国产化采购比例要求
- **2027-2028**: 信创进入"深水区"——从外围系统向核心系统推进

### 5.4 三大变量下的替代速度情景

| 情景 | 假设 | 2026E 国产化率 | 2028E 国产化率 | 累计替代空间 | 概率 |

**核心判断**: 基准情景下，未来 2-3 年国产 CPU 在中国服务器市场年替代量约 **$2-3B/年**，主要蚕食 Intel 的中低端 Xeon 份额。高端 AI 服务器 CPU（搭配 H100/B200 的 Xeon 6+）和核心交易系统仍以 Intel/AMD 为主。

## 7. 对服务器 OEM/ODM 的战略影响

### 7.1 产品规划启示

| 维度 | 建议 |
|:-----|:------|
| **平台多样性** | 服务器产品线应同时支持 x86（Intel/AMD）+ ARM（鲲鹏/飞腾）+ LoongArch（龙芯）三平台，以覆盖不同客户需求 |
| **信创 SKU** | 针对信创市场开发专有 SKU，预装国产 BIOS/BMC（昆仑/百敖），通过 CCCS/信创认证 |
| **国产化率分级** | 设计 50%/70%/100% 国产化率梯度的产品满足不同客户要求 |
| **海外 vs 国内** | 海外产品线继续 Intel/AMD 为主，国内 ODM 应预留国产 CPU 替换路径 |

### 7.2 供应链策略

| 风险 | 应对 |
|:-----|:------|
| Intel/AMD 供应不确定 | 建立国产 CPU 第二货源，至少 2-3 家国产 CPU 适配验证 |
| 国产 CPU 产能不足 | 提前锁定龙芯/飞腾 2027-2028 产能配额 |
| 生态适配成本 | 建立内部信创 OS/BIOS 验证实验室，降低客户适配摩擦 |
| 制裁连锁反应 | 关键客户提供 Intel 和国产双平台切换方案 |

## 8. 综合判断

### 8.1 六大厂商分类

```text
优胜者梯队（3-5 年视角）
+--------------------------------------------------------+
|  🥇 华为鲲鹏    全栈生态 + AI 协同 + 信创主力           |
+--------------------------------------------------------+
|  🥇 海光信息    x86 兼容 + AI 推理 + 曙光渠道           |
+--------------------------------------------------------+
|  🥈 飞腾        ARM 生态 + 党政信创核心 + 量产稳定      |
+--------------------------------------------------------+
|  🥈 龙芯        自主 ISA + 涉密独占 + 工控差异化        |
+--------------------------------------------------------+
|  🥉 兆芯        桌面 x86 兼容 + 长三角本地市场           |
+--------------------------------------------------------+
|  🥉 申威        超算 + 国防专用，通用市场可忽略          |
+--------------------------------------------------------+
```

### 8.2 关键结论

1. **国产 CPU 替代是结构性的、不可逆的**：不是短期政策脉冲，而是技术+政策双驱动的长期趋势
2. **3-5 年内国产 CPU 在信创市场可达 70-80%**，但在通用互联网/高性能市场仍低于 25%
3. **六大厂商无法全部存活**：预计 2028-2030 年间出现整合，可能形成 3-4 家（鲲鹏+海光+飞腾+龙芯）的竞争格局
4. **对服务器 OEM/ODM 的战略启示**：多平台适配能力 + 国产化率梯度设计 + 信创认证体系，将成为 2027 年后竞争门槛
5. **国产 CPU 的最大瓶颈不是性能，而是生态**：x86 兼容路线（海光/兆芯）有最低迁移成本，但受制于授权限制；自主 ISA 路线（龙芯/申威）有最高自主度，但面临生态孤岛风险
