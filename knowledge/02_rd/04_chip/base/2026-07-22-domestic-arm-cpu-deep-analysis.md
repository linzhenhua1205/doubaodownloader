## 1. 执行摘要

### 核心结论

**中国 ARM CPU 产业不是一条单线，而是三个截然不同的赛道**，各自独立运转：

| 赛道 | 代表厂商 | 竞争逻辑 | 中国市场空间 | 存活判定 |
|:-----|:---------|:---------|:-----------:|:--------:|
| **服务器 ARM** 🖥️ | 鲲鹏 · 飞腾 · 平头哥 | 信创政策 + 生态兼容 | $2-3B/年 | 3家可共存 |
| **应用处理器** 📱 | 瑞芯微 · 晶晨 · 全志 · 展锐 | 全球市场化成本竞争 | $10-15B/年 | 整合至3-4家 |
| **专用/车规** 🚗 | 芯驰 · 黑芝麻 · 地平线 | 功能安全 + 场景定义 | $3-5B/年 | 快速洗牌 |

**关键判断**:

1. **服务器级 ARM（鲲鹏/飞腾/平头哥）不是直接竞争关系**——鲲鹏做全栈生态，飞腾做信创底座，平头哥做阿里云内部闭环。三者市场重叠度 <30%
2. **应用处理器 ARM 厂商的实际竞争者是联发科和高通**，而非彼此——瑞芯微、晶晨、全志各自卡位不同细分市场（AIoT/电视盒/平板），直接竞争有限
3. **"数千家芯片公司"中有实质 ARM CPU 设计能力的约 15-20 家**，其余多为 ARM MCU 级别或纯无晶圆设计（Fabless）的 IP 集成商
4. **最大的系统性风险不是国内竞争，而是 ARM 授权冻结**——ARM 在中美科技脱钩中的角色将决定整个赛道的生死

**如果只看服务器级 ARM CPU（与现有知识库相关度最高）**，结论是：

> 鲲鹏+飞腾+平头哥三家将在**2027-2028年吃掉中国信创服务器市场约40-50%的 ARM CPU 份额**（对应$1-2B）。但三家都不会威胁到 Intel/AMD 在非信创市场的地位。

```text
    +-- 国民技术 · 灵动微 · 极海 · 中微半导 · 华大
    +-- -> 它们"用ARM核"但"不做ARM CPU"，不纳入本分析
```

### 2.2 核心能力判断标准

本文"做 ARM CPU"的定义：具备**以下至少两项**能力：

1. **核心微架构设计** —— 不只是拿 ARM Cortex-A 的公版，而是有自研核心（如 TaiShan、FTC）
2. **SoC 全流程整合** —— IO/内存/互联/安全/电源管理全部自主集成
3. **软件生态维护** —— 提供操作系统适配、编译器优化、BSP 支持
4. **量产/商业闭环** —— 芯片已量产部署，有可查证的客户案例

按此标准，**具备 ARM CPU 设计能力的中国企业不超过 20 家**。其余"数千家"多为 ARM MCU 集成商、模拟芯片公司、或 IP 设计服务公司。

## 3. Tier 1 — 服务器级 ARM CPU 深度对比

> 这一层级是**国产 CPU 替代的核心战场**，直接与 Intel Xeon / AMD EPYC 竞争。三家厂商各具完全不同的基因和策略。

### 3.1 华为鲲鹏 (Kunpeng)

| 维度 | 内容 |
|:-----|:------|
| **母公司** | 华为海思 (HiSilicon) |
| **架构** | ARM v8.2，**自研 TaiShan 核心**（V110: 单核 2.6GHz IPC ~13/GHz） |
| **代表产品** | Kunpeng 920 (7nm, 48-64核), Kunpeng 930 (传闻 5nm+) |
| **制程** | 7nm (台积电受限) → 中芯国际 N+2 (7nm级) 替代 |
| **核心微架构** | TaiShan V110 — 4-wide decode, 8-issue rename, 256 ROB, 48KB L1I+32KB L1D, 512KB L2/core |
| **内存** | 8-ch DDR4-2933 / DDR5 传闻, 内存带宽 ~180 GB/s |
| **IO** | 64 lanes PCIe 4.0, 2×100G MAC + 2×25G MAC |
| **功耗** | Kunpeng 920: 150-200W (64核) |
| **软件生态** | openEuler OS + Kunpeng DevKit + GCC/LLVM 优化 + BoostKit 加速库 + 2万+ 应用适配 |
| **量产状态** | ✅ 已量产，华为云全面部署，三大运营商集采 |
| **参考价格** | ~$1,000-2,000 (非公开，信创渠道价) |

#### 核心竞争力分析

| 优势 | 评估 | 详解 |
|:-----|:----:|:------|
| **全栈生态** | ⭐⭐⭐⭐⭐ | 华为拥有国产最完整的计算堆栈：CPU+NPU+AI框架+OS+云平台。纯 CPU 竞争不如性能，但"鲲鹏+昇腾+华为云"的铁三角让客户"只要进华为的门，所有问题一次解决" |
| **自研核心深度** | ⭐⭐⭐⭐⭐ | TaiShan 是国产唯二真正自主设计的 ARM 服务器核（另一个是飞腾 FTC），非 Cortex-A76/A78 公版组装。V110 的 ROB 256 entry, 4-wide 虽然比不上 Apple/ARM 最新（512+ ROB, 8-10-wide），但对标 ARM Neoverse N1 级别 |
| **制造韧性** | ⭐⭐⭐⭐ | 7nm 被卡后，华为是中芯国际 N+2 工艺最优先客户。产能不如台积电但连续供应有保证 |
| **信创渗透** | ⭐⭐⭐⭐ | 电信运营商（移动/联通/电信）大规模部署，金融（工行/建行）进入核心系统 |

| 劣势 | 评估 | 详解 |
|:-----|:----:|:------|
| **制裁天花板** | 🔴 极高 | 华为海思在 US Entity List 上，5nm 以上的制程被全面封锁。Kunpeng 930 的 5nm 迭代卡在中芯国际 N+2 的产能和良率上 |
| **单芯片性能** | ⚠️ 中等 | Kunpeng 920 SpecINT 约 300-350 (64核)，对比 Intel Xeon 6 (Granite Rapids) 同核数约 500-600。差距 ~40-50%。差距不在设计能力而在制程 |
| **非中立平台** | ⚠️ 显著 | 华为云是鲲鹏的大本营，但阿里/腾讯/字节不会大规模采购。鲲鹏在第一 CSP 受限于华为云的竞对关系 |
| **生态锁定顾虑** | ⚠️ 中等 | openEuler 虽开源，但核心优化掌握在华为手中。客户担心 single-vendor lock-in |

#### 关键战略判断

**鲲鹏的本质不是"CPU 公司"，而是"云生态的锚点"**。华为不靠卖鲲鹏芯片赚钱，而是靠鲲鹏锁定华为云和昇腾的客户。这意味着：

- 鲲鹏在非华为生态中的推广动力不足
- 但华为云的客户数在信创市场持续增长，鲲鹏的基本盘稳固
- Kunpeng 930 的流片进度是未来 12 个月最关键的信号

### 3.2 飞腾 (Phytium)

| 维度 | 内容 |
|:-----|:------|
| **母公司** | 中国电子信息产业集团 (CEC) 旗下 |
| **架构** | ARM v8.2，**自研 FTC66x/FTC86x 核心** |
| **代表产品** | 腾锐 S2500 (64核, 服务器), D2000 (8核, 桌面), S5000C (新代) |
| **制程** | 16nm / 14nm / 7nm (S5000C 传言) |
| **核心微架构** | FTC663 — 4-wide decode, 128 ROB, 32KB L1I+32KB L1D, 256KB L2/core |
| **内存** | 8-ch DDR4-3200, 内存带宽 ~160 GB/s |
| **IO** | 64 lanes PCIe 3.0/4.0 (S2500: PCIe 3.0, S5000C: PCIe 4.0) |
| **功耗** | S2500: 150W (64核), D2000: 35W (8核桌面) |
| **软件生态** | 麒麟 OS + 适配 200+ 国产软件，信创生态兼容性仅次于鲲鹏 |
| **量产状态** | ✅ 大量量产，党政信创桌面+服务器主力选型 |
| **参考价格** | ~$500-1,000 (信创渠道价，低于鲲鹏) |

#### 核心竞争力分析

| 优势 | 评估 | 详解 |
|:-----|:----:|:------|
| **信创根正苗红** | ⭐⭐⭐⭐⭐ | CEC 旗下拥有中国电子系最大信创生态（ChinaSoft 麒麟 OS、达梦数据库、奇安信安全）。飞腾在党政信创采购中天然优先 |
| **桌面生态占位** | ⭐⭐⭐⭐ | D2000 是信创桌面 CPU 的唯一主力选型（与兆芯 KX-7000 竞争），已适配 200+ 款国产 OS/应用/外设。信创桌面的迁移摩擦最小 |
| **量产稳定** | ⭐⭐⭐⭐⭐ | CEC 背景确保产能优先。S2500 在信创服务器集采中出货量最大，2025-2026年累计出货超 50 万片 |
| **价格竞争力** | ⭐⭐⭐⭐ | 价格约为鲲鹏的 50-70%。对央国企信创采购来说，价格+稳定+政治正确是铁三角 |

| 劣势 | 评估 | 详解 |
|:-----|:----:|:------|
| **性能掉队** | 🔴 显著 | FTC663 的 128 ROB + 4-wide decode 在同频 IPC 约比 TaiShan V110 低 15-20%。加上 16nm 制程带来的频率劣势（2.0-2.3GHz vs 鲲鹏 2.6GHz），单核算力差距 25-30%。S5000C 传言补齐到 7nm/Pcie 4.0，但仍在追赶 |
| **ARM 授权风险** | 🔴 中等 | ARM 与中资股东（软银→ NVIDIA 收购失败→ IPO）的关系不确定。飞腾的 ARM 架构授权（非核心授权）可能受中美关系波及 |
| **与鲲鹏直接竞争** | ⚠️ 显著 | 同属 ARM 路线，在信创服务器市场直接与鲲鹏竞争。鲲鹏在性能/生态上领先，但在价格/信创身份上飞腾有优势 |
| **AI 能力缺失** | ⚠️ 中等 | 飞腾 CPU 无 NPU 集成，在 AI 推理场景需外挂加速卡。鲲鹏至少能与昇腾协同，海光有 DCU，而飞腾独缺 AI 板块 |

#### 关键战略判断

**飞腾的护城河不是技术，是"CEC 信用"**。

- 在党政信创市场，"CEC 下属企业"的身份比技术参数重要得多
- 但信创从党政到行业的过渡中，性能和生态权重上升 → 飞腾面临更大压力
- S5000C 的流片成功与否是飞腾能否守住服务器市场的关键指标
- 最大风险：如果信创市场 2027-2028 年趋于饱和，飞腾在开放市场的竞争力不足

### 3.3 阿里平头哥 (T-Head / Yitian)

| 维度 | 内容 |
|:-----|:------|
| **母公司** | 阿里巴巴集团 |
| **架构** | ARM v9（抢先），**自研核心**（基于 ARM Neoverse V1/C1 定制） |
| **代表产品** | Yitian 710 (5nm, 128核, ARM Neoverse N2), Yitian 710X (AI 优化版) |
| **制程** | 5nm (台积电) |
| **核心微架构** | ARM Neoverse N2（授权）+ 自研 SoC 互联（CMN-700 mesh）+ 平头哥自定义加速器 |
| **内存** | 8-ch DDR5-4800, 内存带宽 ~300 GB/s |
| **IO** | 128 lanes PCIe 5.0 |
| **功耗** | Yitian 710: 200-250W (128核) |
| **软件生态** | 阿里云生态 + 自研倚天操作系统 + 适配阿里云全栈服务 |
| **量产状态** | ✅ 已大规模部署阿里云数据中心（2023年起），2025年部署量 > 10万片 |
| **参考价格** | 内部使用不对外销售（目前） |

#### ⚡ 平头哥与鲲鹏/飞腾的根本差异

平头哥不做"国产替代"——这是个**本质区别**。

| 维度 | 鲲鹏/飞腾 | 平头哥 Yitian |
|:-----|:-----------|:--------------|
| **驱动** | 信创政策 + 国产替代 | 阿里云内部 TCO 优化 |
| **客户** | 信创集采（政府/国企/运营商） | 仅限阿里云（自用） |
| **定价** | 市场化定价，与 Intel/AMD 错位竞争 | **不考虑成本回收**，只算 TCO 节省 |
| **竞对** | Intel Xeon / AMD EPYC | Intel Xeon（阿里云采购替代） |
| **制程** | 7nm (中芯) 受限 | 5nm (台积电) 不受限 |
| **核心** | 自研 (TaiShan/FTC) | ARM Neoverse 授权 + 自研 SoC |
| **软件** | openEuler / 麒麟 | 阿里云内部栈 |

#### 核心竞争力分析

| 优势 | 评估 | 详解 |
|:-----|:----:|:------|
| **制程不受限** | ⭐⭐⭐⭐⭐ | 阿里不在 US Entity List 上，5nm 台积电产能充足。Yitian 710 的制程领先鲲鹏 2 代、飞腾 3 代。单此一项，同频功耗差 40-50% |
| **性能对标国际** | ⭐⭐⭐⭐⭐ | 128核 × 5nm + DDR5 + PCIe 5.0 → 在规模上直接对标 Intel Xeon Platinum。实测阿里云内部数据库/Web服务场景性能达到 Xeon Platinum 的 80-90%，TCO 节省 30-40% |
| **IO 密度** | ⭐⭐⭐⭐ | 128 lanes PCIe 5.0 在 AI 服务器场景中极具竞争力——可直连 8×GPU 不经过 PCIe Switch |
| **资本投入** | ⭐⭐⭐⭐⭐ | 阿里财力充裕，Yitian 项目已投入数十亿美元，无需短期盈利。这是鲲鹏和飞腾不具备的"烧钱自由" |

| 劣势 | 评估 | 详解 |
|:-----|:----:|:------|
| **不对外销售** | ⚠️ 策略限制 | Yitian 不对外销售意味着在其他厂商的服务器中看不到它。对服务器 OEM/ODM 来说，Yitian 是"不存在"的选项 |
| **核心自主度低** | ⚠️ 中低 | 使用 ARM Neoverse N2 授权核而非自研核心。相比 TaiShan/FTC，平头哥的 CPU 核心自主度本质上是"ARM 公版" |
| **生态外部性差** | ⚠️ 显著 | 平头哥的软件优化深度绑定阿里云内部栈——Prometheus/MySQL/Nginx/Redis 的 ARM 优化，对外部客户几乎不可复用 |
| **ARM v9 授权风险** | ⚠️ 中等 | ARM v9 授权受中美关系牵制，虽然阿里目前不受限，但不可预测 |

#### 关键战略判断

**平头哥是这三个中技术最强、市场化最低的一家**——不是它不想卖，而是设计和定价都没考虑市场化：

- 设计目标：阿里云内部 workload 最优，而非通用服务器市场最优
- 定价逻辑：优化阿里云 TCO，帮助阿里云降价抢客户，而非芯片利润
- 未来走向：如果平头哥 2027-2028 年开始对外销售，将对整个国产 ARM 服务器 CPU 市场产生重大影响
- 但更大可能是平头哥继续作为阿里云的"秘密武器"，不对外竞争，强化阿里云的 TCO 优势

| **核心定位** | **国产车规 ARM SoC 领导者**——覆盖座舱+网关+ADAS 全场景 |
| **量产状态** | ✅ 前装量产，定点车型数十款 |
| **特色** | ARM 核 + 自研安全岛 + 硬件虚拟化 + 国密算法加速 |

**核心竞争力**: 芯驰是国内极少数同时具备 ARM Cortex-A（应用核）+ Cortex-R（实时核）+ 车规功能安全认证的 SoC 公司。在国产车规芯片中，其 ARM SoC 产品线最完整。

**风险**: 汽车 SoC 市场正被高通 Snapdragon Ride / 英伟达 Drive / 华为昇腾碾压。芯驰的生存空间在"中端国产替代"而非"高端性能对决"。

### 5.2 黑芝麻智能 (Black Sesame)

| 维度 | 内容 |
|:-----|:------|
| **架构** | ARM Cortex-A + 自研 NPU（DynamAI NN 引擎） |

| **制程** | 16nm (A1000) → 7nm (C1200) |
| **核心定位** | **自动驾驶 + 跨域融合**（ARM CPU 作为控制面，自研 NPU 作为算力核心）|
| **量产状态** | A1000 量产，定点合资品牌/自主品牌车型 |
| **特色** | ARM 核用于控制/调度，核心算力来自自研 NPU——属于"含 ARM CPU 的 AI SoC"而非"ARM CPU 公司" |

### 5.3 地平线 (Horizon Robotics)

| 维度 | 内容 |
|:-----|:------|

## 7. ARM 架构在中国的前景与风险

### 7.1 ARM 授权模式的结构性变局

ARM 的授权模式正在经历**根本性变化**，对国产 ARM CPU 影响深远：

| 时代 | 授权模式 | 对中国厂商的影响 |
|:-----|:---------|:----------------|
| 2020 前 | ARM 中立、开放授权（ARM v8 永久可用） | 鲲鹏/飞腾免费用 ARM v8 开发自研核，无后顾之忧 |
| 2020-2023 | NVIDIA 收购案 → ARM 暂缓 IPO → 中国化放缓 | 授权冻结风险浮现，ARM 不再对中国厂商开放最新核心 |
| 2023-2025 | ARM IPO 后商业化收紧（ARM v9.2 授权费提价 3-5x） | 新授权成本激增，ARM v9 对中国限制明确化 |
| 2026+ | ARM 九大关键 AI 芯片客户清单发布，**中国厂商全部不在列** | 信号明确：ARM 正在选边站 |

**2026 年 ARM 九大 AI 芯片合作伙伴**（来源：ARM 2026 投资者日）:

| 合作伙伴 | 地区 | 合作内容 |
|:---------|:----|:---------|
| NVIDIA | 美国 | Grace CPU + AI 超级芯片 |
| Apple | 美国 | ARM 架构许可（最高级） |
| Qualcomm | 美国 | Snapdragon X Elite 等 |
| Microsoft | 美国 | Cobalt / SQ 系列 |
| AWS | 美国 | Graviton 系列 |
| Google | 美国 | Tensor / Axion |
| Meta | 美国 | MTIA 系列 |
| AMD | 美国 | Versal / Kria |
| Samsung | 韩国 | Exynos / Galaxy |

**中国厂商全部缺席**。这不仅是对华为的制裁——而是 ARM 的整体战略转向，将中国排除在高等级合作之外。

### 7.2 ARM vs RISC-V 的中国博弈

| 维度 | ARM | RISC-V |
|:-----|:----|:-------|
| 指令集自由度 | ❌ 授权控制，不可修改 | ✅ **完全开源自由，可自主扩展** |
| 成熟生态 | ✅ Linux/Android/工具链完善 | ⚠️ 快速发展中，但缺桌面/服务器生态 |
| 高性能核 | ✅ 多核/乱序/向量单元成熟 | ⚠️ 高性能（SPECINT >10/GHz）核尚缺 |
| 国产支持度 | ⚠️ 政策性中性 | ✅ **国家层面推 RISC-V**（工信部指导） |
| 对现有 ARM CPU 影响 | → 现有授权可继续 | → 新设计选择 RISC-V |
| 关键转折点 | ⏳ 2027-2028 | 🚀 2027 年平头哥 TH-510 量产 |

**平头哥 TH-510**: 阿里平头哥正在开发的高性能 RISC-V 服务器 CPU，传言 2027 年流片。如果成功，将是国产 ARM → RISC-V 的划时代事件。

### 7.3 国产 ARM CPU 的长期风险清单

| 风险 | 概率 | 时间窗口 | 受影响厂商 |
|:-----|:----|:---------|:----------|
| ARM 冻结新授权/核心更新 | 60% | 2026-2028 | 紫光展锐、瑞芯微、晶晨、全志 |
| ARM 取消现有授权 | 20% | 2027+ | 华为鲲鹏、飞腾 |
| 美国制裁扩大（ARM 纳入实体清单管控） | 30% | 2026-2027 | 所有使用 ARM v9 的中国公司 |
| RISC-V 生态成熟 → ARM 被边缘化 | 40% | 2028-2030 | 所有 ARM 厂商（需转 RISC-V） |
| ARM 授权费大幅上涨 | 80% | 2026-2027 | 所有 ARM 授权公司（影响成本） |

## 8. 竞争格局预判

### 8.1 谁将存活？谁将退出？

```text
国产 ARM CPU 厂商 2026-2030 生存预测：

🟢 极大概率存活（>90%）
+-- 华为鲲鹏 — 华为不死，鲲鹏不死。全栈生态无人能替代
+-- 阿里平头哥 — 阿里云内部需求保障，不受外部市场波动
+-- 飞腾 — CEC 信创底座，政治正确性极高

🟡 大概率存活（65-85%）
+-- 中兴微电子 — 中兴通讯内部循环，规模不大但稳定
+-- 瑞芯微 — AIoT 生态领导者，但面临 RISC-V 替代风险
+-- 晶晨半导体 — 视频壁垒深厚，但 TV 市场饱和

🔴 生存挑战（40-65%）
+-- 紫光展锐 — 手机 SoC 竞争失血，RF 物联网能养活但难增长
+-- 黑芝麻智能 — 自动驾驶 SoC 赛道烧钱快，需持续融资
+-- 芯驰科技 — 车规芯片天花板明显，高通的阴影

⚫ 可能退出/被收购（<40%）
+-- 全志科技 — 价格战利润薄，RISC-V 替代冲击最大
+-- 多家小型 ARM SoC 公司 — 资源分散，无差异化优势
```

### 8.2 对服务器 OEM/ODM 的战略建议

| 策略 | 具体行动 | 优先级 |
|:-----|:---------|:------:|
| **多平台适配** | 服务器产品线同时适配鲲鹏/飞腾/平头哥（如开放），覆盖 ARM 信创全部需求 | P0 |
| **关注 S5000C** | 飞腾 S5000C（7nm/PCIe 4.0）是信创服务器下一个增长点，提前开启适配 | P0 |
| **ARM + RISC-V 双线** | 设计时考虑 ARM/RISC-V 切换路径，预研 RISC-V 服务器 CPU 适配 | P1 |
| **CEC 渠道优先** | 信创服务器市场，通过飞腾进入 CEC 采购体系比直接竞争鲲鹏更高效 | P1 |
| **不过度押注单一 ARM 厂商** | 鲲鹏和飞腾长期竞争，服务器 OEM 应保持中立→两边都不丢 | P1 |
| **关注平头哥对外销售动态** | 如果平头哥 2027+ 对外销售 Yitian，将改变整个格局 | P2 |
| **ARM 授权风险对冲** | 关键客户提供"信创 ARM 平台 + RISC-V 后手"的切换路线图 | P1 |
