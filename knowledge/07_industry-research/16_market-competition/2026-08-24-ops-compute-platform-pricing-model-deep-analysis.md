## 1. 一句话结论

> **算力平台的收费本质是「按客户愿意为哪个价值层付钱」：硬件资产（一次性买断，毛利 3-10%）、平台软件（license/订阅，毛利 40%+）、运维服务（年费/按量，毛利 30-50%）。行业利润结构已经证明——DELL 靠服务（毛利 40%+）、HPE 靠 GreenLake 订阅（毛利 35%+）脱离硬件微利陷阱；CoreWeave 靠「合同锁定 + 边际成本定价」把 GPU 变成 9 年印钞机。我们的机会在于：以自研 BMC/RAS/固件的控制面优势为差异化入口，做「硬件销售 + 平台订阅 + 运维年费」三层组合拳，优先服务「全新运维」客户（买了算力但没有运维能力的政企/行业客户），用交钥匙交付 + 按卡收费切入，用运维订阅形成长期现金流闭环。开发路径建议：平台软件走「自研核心 + 第三方生态集成」混合路线，客户可选第三方集成作为信任兜底。** [来源: 本文 §3-§9 综合推导]

## 2. 第一性原理：算力平台收费的本质

### 2.1 客户买的是什么：三个价值层

任何算力产品，客户付钱本质上买的是三层价值：

| 价值层 | 客户买的是什么 | 典型形态 | 毛利率参考 | 竞争强度 |
|:-------|:---------------|:---------|:----------:|:--------:|
| **L1 硬件资产** | GPU/服务器/整机柜本身 | 一次性销售、交钥匙交付 | **3-10%** | 红海（浪潮 3.45-6.76%、SMCI 8.39%）[来源: 利润解构] |
| **L2 平台软件** | 调度/监控/管理/算力编排能力 | license、订阅、按量 | **40%+** | 蓝海（控制面差异化空间） |
| **L3 运维服务** | 系统持续可用的确定性 | 年费合同、人天、SLA | **30-50%** | 蓝海（本地化/响应能力壁垒） |

**关键洞察**：
1. **利润率与价值层强正相关**——L1 是「制造业地板」，L2/L3 是「软件/服务溢价」。这是 [07-20 利润解构] 的核心结论：DELL 硬件毛利 ~15% vs 服务毛利 ~40%+；HPE 整体毛利 31.38% 全靠 GreenLake 订阅拉动 [来源: 利润解构 §10.2]。
2. **L2/L3 是 L1 的「利润救生圈」**——中国服务器厂商服务收入占比 <5% [来源: 利润解构 §14.3 预警信号]，而国际品牌 DELL 服务收入占比 ~20%、HPE 更高。**卖硬件不跟服务 = 把利润让给下游**。
3. **客户愿意为「确定性」付费**——全新运维客户买不起/养不起运维团队，他们为「系统持续可用」付费的意愿远高于为「硬件参数」付费。

### 2.2 收费的二维结构：卖什么 × 怎么收

| 收费方式 | 一次性（买断） | 订阅（周期） | 按量（用量） |
|:---------|:---------------|:-------------|:-------------|
| **L1 硬件** | 整机/整机柜销售 | 融资租赁/分期 | —（很少） |
| **L2 软件** | 永久 license | SaaS 订阅 | 按卡/按节点/按 token |
| **L3 运维** | 一次性部署/调优 | 年费 SLA 合同 | 按人天/按工单 |

**行业趋势**：从左上角（一次性卖硬件）向右下角（按量卖运维）迁移——HPE GreenLake 提供 pay-per-use/订阅/购买三种消费方式并存 [来源: HPE 官网]，CoreWeave 把「算力即服务」做成 $104B 营收积压 [来源: CoreWeave 财报]。

### 2.3 本团队的第一性定位

[08-22 全栈能力差距分析] 已论证：团队资产本质是**控制面深度**（BMC 芯片/RAS 行业第二/固件/驱动/网络产品），license 模式已验证。这决定了：

> **我们的 L2/L3 差异化能力天然强于 L1 红海竞争**——BMC/RAS/固件是运维平台的「传感器与神经系统」，别人做运维平台要重新攒，我们已有底层。**运维不是软件产品的附加项，而是控制面优势的商业化出口。**

## 3. 竞品收费模式全景（MECE 对标）

### 3.1 国际 GPU 云：按小时/秒计费（RunPod/Lambda/Together/CoreWeave/Vast）

**形态特征**：按 GPU 卡/节点小时计费，秒级计费精度，价格随卡型、租期、规模三因子浮动。

| 平台 | 计费模式 | 典型价格（/GPU/hr） | 商业模式要点 |
|:-----|:---------|:-------------------|:-------------|
| **RunPod** | 按小时/按秒（Pods/Serverless/Clusters 三形态） | B300 $7.89 / B200 $6.79 / H200 $4.59 / H100 SXM $3.29 / A100 SXM $1.59 / 4090 $0.74 | 按秒计费无最低时长；Serverless 按 worker 计费（H100 $4.79）；存储 $0.05-0.14/GB/月 [来源: runpod.io 官网] |
| **Lambda** | 按小时（Instances 自助） + 1-Click Clusters（2 周-1 年合同） | Instances: B200 $6.69-6.99 / H100 $3.99-4.29 / A100 $2.79；1-Click: B200 $8.87-9.86 / H100 $5.54-6.16 | **规模折扣显式化**（16→64→256 卡递减）；1 年+ 合同价格另议 [来源: lambda.ai 官网] |
| **Together AI** | 按 GPU 小时（集群）+ 按 token（推理）+ 按量（微调） | 集群: H100 $3.99 / H200 $5.99 / B200 $8.19；预留梯度 7-30天 $3.69→181天+ $3.19；Dedicated H100 $5.49 | **预留折扣梯度最细**（7-30/31-90/91-180/181+ 天四档）；按 token 推理 DeepSeek V4 Flash $0.14/$0.28 per 1M [来源: together.ai 官网] |
| **CoreWeave** | 企业合同（批发）+ 按需 | 批发 $8-12/hr 区间；A100 合同签至 2029（9 年）；到期 H100 以 95% 原价重签 | **合同锁定 + 边际成本定价**：Q2 FY26 营收 $2.58B/+112%，营收积压 $104B，4.2GW 签约 vs 1.5GW 在线 [来源: 本地知识库 CoreWeave 分析] |
| **Vast.ai** | 市场定价（供给需求）+ 按秒 | 三档：On-Demand（保证可用）/ Interruptible（抢占 -50%）/ Reserved（1/3/6 月 -50%） | **市场撮合模式**：68+ GPU 类型、无锁定，供给过剩自动降价 [来源: vast.ai 官网] |

**对标结论**：
1. **计费粒度越来越细**：小时 → 秒 → token，粒度细是获客手段（降低试错门槛），但企业大单都是合同制（CoreWeave 模式）。
2. **价格带收敛**：H100 SXM 在 $3.29-4.29/hr 区间、B200 在 $6.69-9.86/hr 区间——**同卡型价差 ≤30%**，说明 GPU 云是「成本+溢价」定价而非差异化定价，差异化靠服务/合同/利用率。
3. **折扣结构是核心销售工具**：预留越长越便宜（Together 181 天 H100 $3.19，比按需 -20%）、规模越大越便宜（Lambda 256 卡 B200 $8.87，比 16 卡 -10%）。**「合同换折扣」是行业通行的需求确定性锁定手段。**

### 3.2 按 token/按用量计费（Serverless 推理）

**形态特征**：不卖算力卖「推理结果」，客户无基础设施概念，按 token/请求/分钟计费。

| 平台 | 计费单元 | 典型价格 | 备注 |
|:-----|:---------|:---------|:-----|
| Together AI | per 1M tokens（input/output） | DeepSeek V4 Flash $0.14/$0.28；GLM-5.2 $1.40/$4.40；Kimi K3 $3.00/$15.00 | cached input 折扣 80-90%；batch API 5 折 [来源: together.ai 官网] |
| RunPod | per request/per 1K tokens | Whisper V3 $0.05/1K 字符；Seedream 4.0 $0.027/请求；Wan 2.6 $0.03/图 | 模型模板化部署 [来源: runpod.io 官网] |
| 微调 | per 1M tokens（训练集 token 数） | Together LoRA ≤16B $0.48/1M；70-100B $2.90/1M | 按训练数据量计费，最低 $4/任务 [来源: together.ai 官网] |

**对标结论**：按 token 计费只适用于**模型服务商**（客户是应用开发者），不适合「运维+算力平台」主业——但可作为平台上的增值服务形态（算力租赁之上叠加模型服务）。

### 3.3 订阅/消费制（HPE GreenLake 模式）

**形态特征**：硬件放在客户机房，按使用量/订阅付费——「私有云公有化计费」。

| 要素 | HPE GreenLake | 对本团队的启示 |
|:-----|:--------------|:---------------|
| 消费模式 | pay-per-use（按用量）/ 订阅 / 传统购买 三选一 | 给客户「选择权」而非单一价格 |
| 交付形态 | Turnkey Private Clouds（交钥匙私有云）、Turnkey AI Factories（交钥匙 AI 工厂）、Flex Solution（按使用量本地部署） | **「交钥匙」是 GreenLake 的高频词**——HPE 已把 turnkey 作为企业 AI 的默认交付 |
| 软件平台 | 统一控制面（GreenLake 平台）+ AIOps（GreenLake Intelligence 智能运维 Agent） | 平台 + 智能运维是订阅制粘性来源 |
| 毛利效果 | HPE 整体毛利率 31.38%，GreenLake 订阅贡献核心利润 [来源: 利润解构] | **订阅制把硬件厂商毛利率从 <10% 拉到 30%+** |
| 市场认可 | 2025 Gartner MQ Leader（基础设施平台消费服务）[来源: HPE 官网] | 模式已被 Gartner 验证 |

**对标结论**：GreenLake 证明了**「硬件厂商 + 订阅制 + 交钥匙 + 智能运维」是可行且高毛利的组合**——这正是我们讨论的「运维+算力平台」方向的国际对标样板。区别在于：HPE 面向全球企业，我们聚焦国内行业客户（信创/政企/智算中心）。

### 3.4 运维服务合同（Dell/HPE/第三方）

**形态特征**：硬件销售后按年收服务费，覆盖保修/巡检/故障响应/驻场/性能调优。

| 供应商 | 服务产品 | 收费模式 | 参考费率（行业常识） |
|:-------|:---------|:---------|:---------------------|
| Dell | ProSupport / ProSupport Plus（预测性维护） | 按硬件价值比例年费 | 硬件价格的 **5-15%/年**（Plus 含预测性维护更贵）[来源: 行业常识，Dell 官网 403 未直接抓取] |
| HPE | Pointnext 服务 / Managed Services / 融资服务 | 年费 + 人天 + 订阅组合 | 服务毛利 40%+ [来源: 利润解构] |
| 浪潮/新华三 | 运维服务/维保合同（国产厂商） | 年费为主 | 硬件价格 **3-8%/年**（低于国际品牌，国产价格战）[来源: 行业常识] |
| 第三方运维 | 独立运维商（驻场/巡检/应急） | 按人天/按项目/按年 | 人天 ¥1500-3000/人天（高级工程师）[来源: 行业常识] |

**对标结论**：
1. **运维年费是硬件利润的「复利」**：一台 100 万服务器，年运维费 5-15 万，3-5 年合同累计 = 硬件价的 20-60%——**长期现金流远大于一次销售**。
2. **国产厂商运维费率低于国际品牌（3-8% vs 5-15%）**——是国产竞争劣势，也是我们的切入机会（用更高 SLA/响应承诺打差异化，而非单纯低价）。
3. **AI 运维（AIOps）是新一代溢价点**：HPE GreenLake Intelligence（智能运维 Agent）、阿里云投运维 Agent [来源: 07-29 智算日报]——**RAS+AI 预测性维护正是我们的控制面优势所在**。

### 3.5 交钥匙整机柜（turnkey）

**形态特征**：整机柜（含网络/CDU/液冷）预集成、开箱即用，客户零运维起步。

| 案例 | 内容 | 模式要点 |
|:-----|:-----|:---------|
| MiTAC 52U 整机柜 | 96 加速器/架（12×4U × 8×MI355X）+ Broadcom 800G 网络 + Nidec 200kW CDU，turnkey 交付 | 整机柜「越做越高」，开箱即用成为默认 [来源: STH via 知识库 06-26/08-08 日报] |
| NVIDIA DGX SuperPOD | 完整集群交钥匙（含液冷/网络/软件栈） | 硬件+软件+部署一体，客户只出机房 |
| L12 集群交钥匙（知识库交付层级） | L6 准系统 → L10 标准整机 → L11 整机柜 → **L12 集群交钥匙** | 交付层级越高，客户技术门槛越低、我们毛利越高 [来源: 02_rd 架构工具指南] |
| Intel+富士康 | 机架级全栈 AI 方案 | 交钥匙是反超国产生态的竞争武器 [来源: 01_survey 国内替代专题] |

**对标结论**：**交钥匙是「全新运维」客户的唯一现实选择**——客户没有运维能力，交钥匙把「部署风险」从客户转移到供应商，供应商因此获得后续运维合同的「第一优先权」。这是「交钥匙交付 + 后续运维订阅」组合的战略逻辑：**交钥匙是入口，运维是利润池**。

### 3.6 国内智算中心与算力租赁

**形态特征**：智算中心（政府/运营商/第三方）按卡出租，或整机柜交付给算力运营商。

| 模式 | 收费形态 | 参考价格（行业常识，待验证） | 备注 |
|:-----|:---------|:----------------------------|:-----|
| 智算中心算力租赁 | 按卡/小时或按月 | H800 约 ¥8-15/卡/小时；A100 约 ¥5-8/卡/小时；4090 约 ¥2-4/卡/小时（包月约为小时价 30-50% 折扣） | [来源: 行业常识估算，国内平台价格页 JS 渲染无法直接抓取，标注缺口] |
| 政企/运营商集采 | 整机/整机柜销售 + 维保 | 信创溢价 15-30% [来源: 利润解构 §5.1] | 国产化要求抬高价格带 |
| 行业算力平台（医疗/金融/科研） | 整机销售 + 平台 license + 运维年费 | 无公开统一价 | **本团队的典型目标市场** |

**对标结论**：国内「智算中心自建自营」模式利用率普遍 <30% [来源: 利润解构 §8.2]——**大量智算中心买了硬件不会运营**，这恰恰是「全新运维」需求的市场底座：硬件厂商的运维+平台服务可以填满这个缺口。

## 5. 收费模式×销售模式×交付形态三维矩阵

### 5.1 销售模式（渠道结构）

| 销售模式 | 适用场景 | 优缺点 | 毛利影响 |
|:---------|:---------|:-------|:--------:|
| **直销（大客户）** | 政企/智算中心/行业头部 | 需求把控强、可做 JDM；但销售成本高 | 中-高（可加服务包） |
| **渠道/代理** | 中小企业/区域市场 | 覆盖广、回款快；但方案一致性差 | 中（分润 10-20%） |
| **运营商/集采** | 三大运营商、东数西算 | 规模大但价格战、账期长 | 低（<10%） |
| **订阅/服务合同** | 所有存量客户 | 现金流稳定、粘性强 | 高（30-50%） |
| **算力分成** | 与算力运营商合作 | 长期收益但回收慢、风险共担 | 中（分成比例谈判） |

### 5.2 交付形态（客户看到的形态）

| 交付形态 | 定义 | 客户门槛 | 供应商毛利 | 运维粘性 |
|:---------|:-----|:--------:|:----------:|:--------:|
| **裸机销售** | 只卖硬件 | 高（客户自运维） | 低（3-10%） | 无 |
| **整机+维保** | 硬件 + 标准保修 | 中 | 低-中 | 弱（年费 3-8%） |
| **交钥匙整机柜（turnkey）** | 预集成开箱即用 | 低 | 中（硬件+部署费） | 强（部署即入口） |
| **算力平台订阅** | 平台软件 + 调度/监控 | 中低 | 高（40%+） | 强（数据沉淀） |
| **算力租赁/云化** | 按卡按量卖算力 | 最低 | 中（资本重） | 强（合同锁定） |
| **运维托管（MSP）** | 全托管运维 + SLA | 最低 | 高（30-50%） | 极强（不可替代） |

### 5.3 收费-销售-交付组合矩阵（推荐组合高亮）

| 交付形态 | 销售模式 | 收费方式 | 组合评价 |
|:---------|:---------|:---------|:---------|
| 裸机 | 直销/渠道 | 一次性 | ⭐ 红海，只做引流 |
| **交钥匙整机柜** | 直销（政企/智算） | 硬件款 + 部署费 | ⭐⭐⭐ 入口 |
| **算力平台 license** | 直销 + 订阅 | 按卡/按节点/按年 | ⭐⭐⭐⭐ 利润池 |
| **运维托管 SLA** | 订阅合同 | 年费（按卡/按节点） | ⭐⭐⭐⭐⭐ 现金流 |
| 算力租赁 | 合作运营 | 按小时/按卡 | ⭐⭐⭐ 可选（资本重） |

**推荐组合**：`交钥匙交付（入口）→ 平台 license 按卡（利润）→ 运维年费 SLA（现金流）` 三段式递进——**前段抢单、中段赚毛利、后段锁定 3-5 年**。

## 6. 我们的模式设计（控制面优势×算力平台×运维）

### 6.1 模式定位：从卖盒子到卖「可运行算力」

**一句话定位**：我们不是卖服务器的，也不是卖软件的，而是卖**「开机即用、持续可用」的算力确定性**。

```text
       Before (component/vendor)              After (turnkey compute provider)
+------------------------------+      +------------------------------+
| Sell HW -> customer self-O&M |      | Turnkey -> platform -> SLA   |
| GM 3-10% / no stickiness     |  =>  | HW GM + sub GM + O&M GM      |
+------------------------------+      | 3-5yr customer lock-in       |
                                      +------------------------------+
  Differentiator: BMC/RAS/firmware      Differentiator: control-plane x
  (control plane)                      AI-O&M x local response
```

**为什么这个定位成立**（第一性原理）：
1. **控制面即运维入口**：BMC/RAS/固件是服务器运维的「神经末梢」——我们的平台天然能拿到比第三方更深层的遥测（RAS 事件、固件日志、故障预测），这是 OpenBMC/商业平台都没有的深度。
2. **全新运维客户无选择**：客户没有运维团队，只有「交钥匙 + 托管」和「自己招人」两个选项——前者成本更低、上线更快，是我们的必然市场。
3. **国内智算中心利用率 <30% 的缺口** [来源: 利润解构 §8.2]：大量算力买了不会用，运维+运营服务需求明确。

### 6.2 三层收费组合拳

| 层 | 产品形态 | 收费方式 | 定价锚（对标） | 毛利预估 |
|:---|:---------|:---------|:---------------|:--------:|
| **L1 交钥匙交付** | 整机柜/集群预集成（含网络/液冷/部署） | 硬件款 + 部署费（一次性） | 对标 DGX SuperPOD 交付模式；部署费 = 硬件价 5-10% | 硬件 5-10% + 部署费 40%+ |
| **L2 平台订阅** | 算力调度/监控/管理平台（控制面软件化） | **按卡/月** 或 按节点/年（license） | 对标：云平台软件一般按节点月费 ¥200-1000/节点（行业常识） | 40-60% |
| **L3 运维 SLA** | 驻场/远程/巡检/AI 预测性维护 | **按卡/年** 或 按节点/年（SLA 分级） | 对标：硬件价 5-15%/年（Dell）；国产 3-8% | 30-50% |

**收费设计要点**：
1. **「按卡收费」统一 L2/L3 计费单元**——与 GPU 云行业惯例一致（按 GPU/小时/月），客户容易对比。示例：平台订阅 ¥X/卡/月 + 运维 ¥Y/卡/月，X+Y 打包成「每卡每月总拥有成本」。
2. **SLA 分级定价**（对标 Dell ProSupport vs Plus）：基础（远程 8×5）/ 高级（远程 7×24 + 备件）/ 尊享（驻场 + AI 预测性维护 + 主动更换）三档，价差 2-3 倍。
3. **合同锁定换折扣**（对标 Together/Vast）：1 年合同 9 折、3 年 8 折——把利用率不确定性转化为确定性收入（CoreWeave 的 $104B 营收积压证明合同模式有效 [来源: CoreWeave 分析]）。
4. **不碰算力租赁重资产**（除非客户要求）：算力租赁是资本游戏（GPU 采购 + 机房 + 电力），毛利虽高但资本沉淀重，初期以「帮客户管」而非「替客户买」为主。

### 6.3 定价基准与测算（示例）

以 **8 卡 H800 服务器（约 ¥120-150 万硬件）** 为例：

| 收费项 | 单价（示例） | 年收入（单台） | 说明 |
|:-------|:------------|:--------------:|:-----|
| 硬件销售 | ¥130 万（一次性） | — | 硬件毛利 5-8% |
| 部署/交钥匙 | 硬件价 5% = ¥6.5 万 | — | 一次性 |
| 平台订阅 | ¥500/卡/月 | 8×500×12 = **¥4.8 万** | L2 毛利 40%+ |
| 运维 SLA（高级） | ¥800/卡/年 | 8×800 = **¥6.4 万** | L3 毛利 40%+ |
| **3 年累计服务收入** | — | **¥33.6 万** | ≈ 硬件价 26% |

**关键测算结论**：3 年服务收入（¥33.6 万）≈ 硬件毛利的 3-4 倍——**服务的 3 年现金流贡献超过硬件本身**。10 台起步的客户，3 年服务合同 = 336 万稳定收入。这就是「软件形成闭环」的财务含义。[注: 价格为示例测算，需按实际成本结构校准]

## 8. 开发路径三选：自研/第三方合作/客户选型集成

### 8.1 三条路径对比

| 维度 | A. 全自研 | B. 自研核心+第三方生态集成 | C. 客户选第三方集成 |
|:-----|:---------|:--------------------------|:-------------------|
| **定义** | 平台软件/运维工具全部自己开发 | 自研差异化核心（控制面/RAS/AI 运维），调度/监控/门户集成第三方（K8s/Slurm/开源监控） | 只提供硬件+接口，平台运维由客户选定的第三方负责 |
| **需求定义权** | 完全自主 | 核心自主、外围协同 | 让渡给第三方/客户 |
| **前置投入** | 高（团队+周期） | 中 | 低 |
| **毛利** | 高（全栈归己） | 中-高（核心归己） | 低（只剩硬件） |
| **上线速度** | 慢（12-24 月） | **中（6-12 月）** | 快 |
| **风险** | 方向误判沉没成本 | 集成质量/第三方可靠性 | 失去软件利润+客户关系 |
| **对标** | 华为式全栈（不可复制）[来源: 能力差距分析 §2.3] | 浪潮 AIStation（平台集成第三方）+ HPE GreenLake（平台+生态） | 白牌 ODM（毛利 <10%） |
| **对本团队** | 控制面自研 ✅ + 算力面全自研 ❌（违背哑铃策略） | **控制面自研 + 算力面集成 —— 哑铃策略的标准解** [来源: 能力差距分析] | 退回老路，不建议作为主线 |

### 8.2 推荐：路径 B「自研核心 + 第三方生态集成」（混合路线）

**依据**（第一性原理 + 知识库支撑）：
1. **哑铃策略**：控制面（BMC/RAS/固件）深扎自研——这是别人没有的；算力面（调度/K8s/Slurm/监控）集成成熟开源（K8s、Slurm、Prometheus、Grafana、OpenTelemetry）——避免重复造轮子 [来源: 能力差距分析 §2.3]。
2. **需求定义权决定毛利**：核心（RAS 预测性维护、AI 运维、故障自愈）自研 = 需求定义权在手 = 毛利 40%+；外围集成第三方 = 交付周期可控 [来源: 研发模式光谱 §4 需求定义权-利润正相关]。
3. **时间窗口**：客户「尽快推出可交付」（用户原话）——6-12 月混合路线 vs 12-24 月全自研，前者先占领市场，再迭代自研深度。

**集成边界清单**（自研 vs 集成）：

| 模块 | 策略 | 理由 |
|:-----|:-----|:-----|
| BMC/固件/RAS 遥测 | **自研**（已有） | 核心差异化，行业第二水平 |
| AI 预测性维护/故障自愈 | **自研**（产学研可加速） | 新一代溢价点（HPE GreenLake Intelligence 对标） |
| 算力调度/资源池化 | 集成（K8s/KubeFlow/Slurm） | 成熟生态，避免造轮子 |
| 监控/告警/日志 | 集成（Prometheus/Grafana/ELK）+ 自研 RAS 插件 | 生态成熟，差异化在插件 |
| 运维门户/工单/计费 | **自研**（轻量） | 客户界面=品牌界面，且计费是收费载体 |
| 多卡互联/集群性能调优 | 自研（控制面优势延伸） | 与硬件深度耦合 |

### 8.3 客户选第三方集成的正确处理

用户提到「或让他们选择第三方来集成」——**这不应是主线，但可以作为信任兜底**：

- **适用场景**：客户已有 IT 供应商/信创绑定，平台必须第三方集成时。
- **正确姿势**：我们提供「硬件 + 控制面 API + 数据接口」，第三方集成我们的一等公民接口（BMC/RAS 遥测标准接口），**保证我们的硬件在任何平台下都「可运维」**。
- **战略意义**：即使客户选第三方，我们的 BMC/RAS 深度遥测仍是第三方平台的上游数据源——**控制面优势让「被集成」也有利可图**（类似 Intel 被所有云平台集成）。
- **风险控制**：接口开放协议化（Redfish 标准扩展 + 私有遥测增强），避免第三方把客户关系锁死。

| **S3 按卡统一计费** | 平台+运维打包成「每卡每月 TCO」，对标 GPU 云行业惯例 | §4.1 价格带 |
| **S4 SLA 分级 + 合同折扣** | 三档 SLA（8×5/7×24/驻场+AI），1/3 年合同换折扣 | §3.4 对标 Dell/HPE |
| **S5 标杆项目先行** | 找 1-2 个「全新运维」客户做样板（可低价），产出案例数据（利用率提升/故障下降） | 能力差距分析 §4.4「成功项目模式复制」 |
| **S6 渠道补充** | 区域代理分销交钥匙硬件，服务/订阅直销 | §5.1 销售模式 |

## 10. 给老板的汇报要点（30 秒版）

> 面向老板汇报的浓缩版——三句话讲清楚，一张表给数据。

**一句话**：我们有机会从「卖服务器」升级为「卖可运行算力」——交钥匙交付 + 平台订阅 + 运维年费三层收费，把毛利率从 3-10% 提升到综合 20-30%，并锁定客户 3-5 年。

**三句话**：
1. **行业已验证**：DELL 服务毛利 40%+、HPE GreenLake 订阅毛利 35%+、CoreWeave 靠合同锁定做到 $104B 营收积压——硬件微利的出口就是软件+服务。
2. **我们有差异化**：自研 BMC/RAS/固件是运维平台的天然底层，别人做运维要从零攒，我们已有神经系统。
3. **客户需求明确**：智算中心利用率 <30%、政企买得起养不起——「全新运维」客户需要交钥匙+托管，这是被验证的缺口市场。

**给老板的一张表**（8 卡 H800 单台 3 年测算）：

| 收入项 | 金额 | 毛利 |
|:-------|:-----|:----:|
| 硬件销售（一次性） | ¥130 万 | 5-8% |
| 部署/交钥匙 | ¥6.5 万 | 40%+ |
| 平台订阅（3 年） | ¥14.4 万 | 40%+ |
| 运维 SLA（3 年） | ¥19.2 万 | 40%+ |
| **3 年综合毛利** | **≈ 硬件毛利的 3-4 倍** | **综合 ~20-30%** |

**需要的资源**：6-12 个月、1 个产品小分队（平台+运维）、1-2 个标杆客户、产学研智能运维课题优先转化。**风险可控**：混合开发路径（自研核心+集成外围），不重资产投入。

## 11. 产品路线图：运维尽快推出，软件形成闭环

### 11.1 「尽快推出、可以交付」的最小可行闭环

用户明确要求「运维尽快推出来，可以交付，软件自己形成闭环」——设计 MVP 闭环：

```text
  [HW delivery] -> [Platform on-board (BMC/RAS telemetry)] -> [Monitor/Alert/Remote O&M] -> [SLA service]
       ^                                                                                    |
       +--------- [failure data back to R&D -> next-gen design] <--------------------------+
                        (software loop: O&M data is R&D asset)
```

**MVP 范围（3-6 月可交付）**：
1. 交钥匙部署 SOP + 整机柜预集成（现有硬件能力 + 部署流程固化）
2. 平台 v1：BMC/RAS 遥测汇聚 + 监控告警（Prometheus/Grafana 集成 + RAS 插件自研）+ 远程运维通道
3. 运维服务目录：三档 SLA 报价单 + 服务工单流程
4. 计费系统：按卡/月订阅 + 合同管理

**MVP 之后迭代**：AI 预测性维护（RAS 数据 + 机器学习）→ 故障自愈 → 利用率分析/计费 → 面向算力运营商的出租功能。

### 11.2 「软件形成闭环」的三重含义

| 闭环 | 机制 | 价值 |
|:-----|:-----|:-----|
| **收入闭环** | 交钥匙入口 → 订阅利润 → 运维现金流 | 硬件毛利 3-10% → 综合 20-30% |
| **数据闭环** | 运维遥测 → 故障库 → 设计改进 → 下一代硬件 | 运维数据成为研发资产（RAS 行业第二的强化） |
| **客户闭环** | SLA 履约 → 续约 → 扩容 → 转介绍 | 3-5 年锁定 + 复购 |

### 12.1 风险清单

| 风险 | 等级 | 缓解 |
|:-----|:----:|:-----|
| 客户被云厂商（阿里/火山）低价算力抢走 | 高 | 私有化+信创+控制面差异化；云厂商不碰政企私有化深水区 |
