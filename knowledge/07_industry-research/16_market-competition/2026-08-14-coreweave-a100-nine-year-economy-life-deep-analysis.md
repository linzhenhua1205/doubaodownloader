## 2. 经济学维度：折旧「认知战」与旧代 GPU 定价机制

### 2.1 三方认知冲突：Burry vs Kress vs Intrator

这场争论的实质是**「GPU 是什么类型的资产」**的分歧，三方各持一极：

| 立场 | 代表 | GPU 资产本质 | 寿命假设 | 推论 |
|:-----|:-----|:------------|:--------:|:-----|
| **激进做空** | Burry | 技术资产（每年换代→快速贬值） | 1-3 年 | hyperscaler 折旧不足 → 利润虚高 → 估值泡沫 |
| **厂商辩护** | Kress | 产能资产（满负荷即有价值） | 6 年+ | A100 六年后仍满载 → 折旧假设合理 |
| **市场实证** | Intrator | 产能+金融资产（可证券化） | **9 年** | 合同锁定至 2029 → 残值可预期 → 资产可抵押融资 |

**关键洞察**：三方的寿命假设差异（1-3 / 6 / 9 年）不是技术判断分歧，而是**站位的利益函数不同**。Burry 做空需要「寿命短」叙事；NVIDIA 卖新卡需要「新卡值得买」（旧卡贬值快 → 买新）；CoreWeave 融资需要「寿命长」（残值高 → 抵押价值高）。**同一物理资产，被三个参与者定价为三种寿命——这就是资产化市场的常态。**

### 2.2 旧代 SKU 定价≥数年前的微观基础

「旧代 SKU 定价≥数年前」违反直觉（电子产品应随时间贬值），其微观基础是**供给刚性 + 需求外溢**：

- **供给侧刚性**：A100 所在的机房是 20kW/rack 风冷老机房。Blackwell 进不去（6× 功率密度差，见 §3）→ 该机房**没有可替代的新 GPU 部署方案** → 存量 A100 供给曲线完全无弹性（装机容量固定）。
- **需求侧外溢**：推理需求爆发（2026 推理支出 $233B 首超训练 $190B，Gartner）+ 新 GPU 供给受限（HBM/CoWoS/电力八线同紧）→ 买不到/等不起新 GPU 的客户需求**外溢**到旧 GPU 市场。
- **TH 原文金句**：「The energized, air-cooled capacity holding them has no higher-value use」（承载它们的已通电风冷容量没有更高价值用途）——**这是供给刚性的经济学表达：沉没的电力和机房容量，其机会成本趋近于零，因此任何能覆盖边际成本的价格都是「好价格」。**

**定价锚**：旧 GPU 价格地板 = 电力 + 运维 + 资金占用（≈$0.5-1.5/hr 量级）；价格天花板 = 替代方案 TCO（新 GPU 摊薄成本）。当前八线同紧把「天花板」抬高（新 GPU 贵且缺），旧 GPU 定价随之抬升——**旧卡涨价不是因为它变好了，是因为新卡买不到了。**

### 2.3 已折旧资产的边际成本结构

这是九年寿命最核心的经济学机制：

```
旧 GPU（折旧已提完）的单位成本 ≈ 电力 + 运维 + 网络 + 资金利息
新 GPU（折旧进行中）的单位成本   ≈ 上述 + 年折旧（资本成本大头）
```

- 会计折旧期（hyperscaler 普遍 5-6 年，Burry 指控的就是这个）**结束后**，GPU 的账面成本归零，继续运行只需覆盖**边际成本**——远低于新部署的全成本。
- **边际成本定价**意味着：只要推理负载的支付意愿 > 电力+运维，旧 GPU 就能盈利。CoreWeave 财报（$2.58B/+112%）证明这不是理论，是现实。
- 对 CoreWeave 而言，**9 年合同 = 把折旧期从 5-6 年拉长到 9 年** → 单位资本成本摊薄近一半 → 利润率结构性抬升。这是财报亮眼（+112% YoY）的隐藏杠杆之一。

### 2.4 4.2GW 签约 vs 1.5GW 在线的期权结构

| 指标 | 数值 | 解读 |
|:-----|:-----|:-----|
| 签约电力 | 4.2GW | 客户承诺的**远期容量需求**（收入侧） |
| 在线电力 | 1.5GW | 实际可交付的**当期产能**（供给侧） |
| 覆盖倍数 | **2.8×** | 承诺覆盖近 3 倍交付能力 → 产能缺口信号 |

**期权解读**：电力签约合同本质是**看涨期权**——CoreWeave 以「承诺锁定」换取「未来确定性交付」，代价是违约风险（若客户弃约/需求降温，承诺变负债）。3.7→4.2GW（Q2→8月）的增长是**对需求确定性的持续加注**。

**双向风险**：
- 上行：AI 需求持续超预期 → 4.2GW 全部兑现 → 营收积压 $104B 变现
- 下行：若 2027 推理效率提升使每 token 算力需求下降（§6 边界2）→ 客户缩减承诺 → 2.7GW 未交付产能的电力/设备投资成沉没成本 → 杠杆反噬

## 3. 技术演进维度：基础设施代差成为「寿命剪刀」

### 3.1 功率密度代差：6.5kW → 120-140kW

```
DGX A100  (2020):  6.5kW 满载 / 风冷 / 适配 20kW per rack 老机房
GB200/300 (2025):  120-140kW / D2C 液冷 / ≈6× 老机房供电散热能力
Blackwell: 无法进入 Ampere 所在机房（除非重建供电+散热基础设施）
```

- **约 20× 的机柜功率密度跃迁**（20kW → 120-140kW）是三代内发生的，远超机房基础设施的改造周期（10-20 年折旧）。
- **物理锁定机制**：供电（母线/配电/断路器容量）+ 散热（风冷→液冷 CDU/管路）都是**物理基础设施**，改造代价 = 每机柜数万至数十万美元 + 停机时间——**改造成本 >> 旧 GPU 剩余价值** → 理性选择是「不改造，让旧 GPU 继续跑」。
- 这与 [07-29 整机柜四代演进](../02_rd/02_project/01_superpod/2026-07-29-integrated-rack-evolution-deep-analysis.md) 的判断完全互证：整机柜的演进（天蝎→Open Rack→400V HVDC→1MW）本质是**供电/散热的代际革命**，每一代都让上一代机房物理性「过时」——但不是「废弃」，而是**降级为低功率密度的服役层**。

### 3.2 三层生命周期失配：芯片/系统/机房

| 层级 | 典型寿命 | 折旧/改造周期 | 关键特征 |
|:-----|:--------:|:------------:|:---------|
| 芯片（GPU） | 物理寿命 10-15 年 | 会计折旧 5-6 年 | 每年换代但物理可用 |
| 系统（服务器/机架） | 5-7 年 | 3-5 年 | 可升级（内存/网络） |
| 机房（供电/散热） | **20 年+** | 10-20 年 | 物理改造极贵 |

**核心洞察**：三层寿命**严重失配**——芯片每年换代、机房 20 年才重建。**机房是最慢的变量，它决定了芯片的服役上限**。GPU 的经济寿命 ≈ min(物理寿命, 工作负载适配, **机房容量存在性**)。当机房 20 年不重建时，最老的芯片反而获得最长的实际服役窗口——**基础设施代差把「技术寿命」拉长为「经济寿命」**。

### 3.3 「没有任何形态完全存活」的再检验

08-12 「存储四形态」判断（没有任何形态完全存活）在此获得**第二实证**（第一实证为存储介质）：

- A100 **没有**「完全存活」——它的性能已被 Blackwell 超越 10×+，无法承担前沿训练；
- 但它**在特定基础设施约束下存活**——老机房风冷容量 + 推理负载 = 生存缝隙；
- **关键区别**：存储四形态的「死亡」由介质物理寿命决定；GPU 的「半死半活」由**基础设施代差 + 负载迁移**决定——比存储多了一个「人为可调」变量（负载可以迁，基础设施难以迁）。

**寿命剪刀模型**（本分析的核心概念）：

```
                    需求侧（推理负载）↑ → 剪刀张开（旧 GPU 续命）
                    供给侧（基础设施代差）↑ → 剪刀张开（新 GPU 进不来）
                    ─────────────────────────────────────
                    电力成本↑ / 推理效率↑ / Blackwell 降配↓ / 训练见顶↓
                    → 剪刀闭合（旧 GPU 退役）
```

## 4. 工作负载维度：推理迁移创造「第二生命」

旧 GPU 的第二生命来自**工作负载的迁移**——训练让位给推理：

| 负载类型 | 性能敏感度 | 旧代 GPU 适配性 | 2026 支出规模 |
|:---------|:----------:|:---------------:|:------------:|
| 前沿模型训练 | 极高（新架构必需） | ❌ 不适合 | 训练合计 $190B |
| 推理（已部署模型） | 中低（延迟/吞吐可权衡） | ✅ 适合 | 推理合计 **$233B** |
| 微调/蒸馏 | 中 | ✅ 适合 | 计入训练 |
| 数据预处理/批处理 | 低 | ✅ 适合 | — |
| 小模型/边缘推理 | 低 | ✅ 适合（能效差但可用） | — |

- **推理支出 2026 首超训练（$233B vs $190B，Gartner）**是本案例最大的基本面支撑——推理负载不追求峰值性能，追求**成本/吞吐**，旧 GPU 折旧完毕的边际成本结构天然适配。
- **效率悖论**：推理效率提升（小模型/蒸馏/稀疏化）短期**增加**需求（Jevons 悖论，杰文斯：效率→需求增长）→ 旧 GPU 继续受益；长期若效率提升速度 > 需求增长速度，每 token 算力需求下降 → 旧 GPU 需求见顶（§6 边界2）。

## 5. 商业模式与产业博弈：算力资产化的样板与镜像

### 5.1 CoreWeave 的资产化样板

CoreWeave 的商业模式本质：**资本套利（低息融资买 GPU → 高价出租）+ 残值管理（延长寿命 → 摊薄成本）**。

- **9 年合同 = 资产寿命货币化**：把「GPU 能用 9 年」这一技术事实转化为「9 年合同收入」的财务事实——这是 [08-14 $500B 融资计划「老 GPU 变现通道」](../16_market-competition/2026-08-14-industry-signals-ai-chipmaking-xbm-adi-pcie6-gpu-secondary-market-open-source-deep-analysis.md) 的微观基础：**资产可证券化的前提是残值可预期**，而 A100 合同至 2029 + 旧卡定价≥数年前，恰好提供了「残值可预期」的市场证据。
- **与 hyperscaler 的差异**：hyperscaler 自研芯片 + 自建机房（纵向整合）；CoreWeave 纯租（横向套利）——没有自研芯片负担，全部资金押注「NVIDIA 生态 + 资产寿命」。

### 5.2 NVIDIA 的「寿命管理」策略

- **旧卡保值 = 新卡定价的锚**：二手市场高残值（H100 95% 重签、A100 定价≥数年前）→ 客户买新卡时「残值预期」高 → **净购买成本下降** → 新卡需求增强。旧卡保值**不伤害**新卡销售，反而增强客户信心（资产可回收）。
- **生态锁定**：旧 GPU 满负荷运行 = CUDA 生态持续占用 = 客户迁移成本高 → 下一轮采购仍选 NVIDIA。
- **供给受限期的双赢**：HBM/CoWoS 紧缺时 NVIDIA 产能有限，旧卡高残值恰好**缓冲**客户等不到新卡的焦虑（先用旧卡顶住，等新卡交付再升级）——旧卡成了 NVIDIA 的「产能缓冲池」。

### 5.3 中国黑市镜像：管制与稀缺定价

TH 同页新闻：「China black market Nvidia prices rocket in wake of smuggling crackdown」——**同一现象的两个镜像**：

| 市场 | 稀缺来源 | 旧卡定价机制 |
|:-----|:---------|:------------|
| 美国（CoreWeave） | 基础设施代差 + 新卡供给受限 | 供给刚性 + 需求外溢 |
| 中国（黑市） | 出口管制 + 走私打击 | 政策性稀缺 → 溢价 |

**统一规律**：GPU 是「产能商品」，其价格由**可得性**而非**性能**主导。任何制造稀缺的力量（基础设施、管制、供应链）都会推高旧卡价格——这解释了为什么「旧卡定价≥数年前」可以长期存在。

## 6. 辩证批判：九年寿命的四个边界条件

九年寿命不是永恒定律，是**四个变量维持现状**的结果。任一变量反转，剪刀立即闭合：

| # | 边界条件 | 反转信号 | 影响 |
|:-:|:---------|:---------|:-----|
| 1 | **电力成本稳定** | 电价上涨（数据中心社会阻力/绿电溢价）→ 能效差的旧 GPU 边际成本飙升 | 旧 GPU 率先出局（每 token 功耗 2-3× 新卡） |
| 2 | **推理效率不超速** | 小模型/蒸馏/稀疏化使每 token 算力需求下降 50%+ → 旧 GPU 需求见顶 | 旧卡定价回落至电力成本线 |
| 3 | **Blackwell 不下探** | NVIDIA 推出风冷/降配版（进老机房）→ 基础设施代差闭合 | 老机房可部署新卡 → A100 供给刚性瓦解 |
| 4 | **训练需求持续** | 模型架构收敛（MoE 固定/合成数据见顶）→ 训练 GPU 过剩 → 二手供给暴增 | 旧卡价格崩盘（供给冲击 > 需求支撑） |

**反方观点（对 CoreWeave 叙事的质疑）**：
- 「合同签至 2029」≠「2029 仍盈利」——合同价格若含通胀/电价联动条款，电力成本上涨会侵蚀利润；
- 「旧代 SKU 定价≥数年前」是**总量口径**，未披露是短期租赁（高价）还是长期合同（锁定低价）的加权——长期合同可能是**价格滞后于市场**的结果，而非定价权体现；
- 到期 H100 95% 重签是**单个数据点**，样本不足；Burry 指控的 $176B 折旧缺口若属实，意味着 hyperscaler 的「寿命假设」是**会计手段**而非技术事实——双方都可能有偏。

## 7. 对服务器/数据中心研发的启示

1. **旧机房改造 = 真实市场**：20kW/rack 老机房是海量存量（非 AI 新建），改造为液冷/更高功率密度（CDU 桥接、供电升级）是明确需求——呼应 08-11 GoCool-150 CDU 桥接旧设施（自耗 18kW 排 150kW）的案例。**产品线应覆盖「存量机房升级」而非只押新建超节点。**
2. **风冷/液冷双形态设计**：新服务器若保留低功率风冷 SKU（对标 Intel Crescent Island 容量型思路），可进入老机房替代 A100 生态位——这是**从供给侧闭合寿命剪刀**的产品机会。
3. **资产残值管理**：企业采购 GPU 服务器时，折旧模型应从「5 年技术寿命」转向「基础设施约束下的经济寿命评估」——老机房部署的 GPU 预期服役期更长，新机房则需考虑功率密度升级速度。
4. **中国智算中心启示**：国产 GPU 同样面临「基础设施代差锁死」——已建成的风冷智算中心（大量 20-40kW/rack）不宜盲目上液冷改造，可先用国产中端卡（适配老机房功率）填充存量机房，把液冷留给新建项目。

## 9. 经济学量化模型（v1.1 深化）

> 本节把 v1.0 的定性判断（边际成本定价、期权结构、寿命剪刀）全部落到**可复现的量化模型**。所有假设显式标注，单位 USD；系统基准 = DGX A100（8×A100 80GB）。模型脚本：`tmp/coreweave_model.py`。

### 9.1 单卡九年经济账（模型 1）

**基准假设**（标注区间）：

| 参数 | 基准值 | 区间 | 依据 |
|:-----|:------:|:-----|:-----|
| DGX A100 8 卡系统采购价 | $199K | $150-250K | 2020 发布价 |
| 会计折旧期 | 5 年直线 | 3-6 年 | hyperscaler 通行 |
| 满载功耗 | 6.5kW | — | TH 原文 |
| 数据中心电价 | $0.08/kWh | $0.06-0.15 | 美国工业电价 |
| 运维+网络+机房摊销 | $10K/年 | $8-15K | 估 |
| 8 卡节点租赁价 | $8/hr | $5-20 | 批发→按需区间 |
| 年均利用率 | 60% | 50-75% | 估 |

**九年毛利矩阵（采购 $199K + 年成本 $14.6K 固定）**：

| 租赁价 \ 利用率 | 50% | 60% | 75% |
|:---------------:|:---:|:---:|:---:|
| $5/hr | **−$133K** ❌ | −$93K | −$34K |
| $8/hr | −$15K | **+$48K** ✅ | +$143K |
| $12/hr | +$143K | +$238K | +$380K |
| $20/hr（按需） | +$458K | +$616K | +$853K |

**关键洞察**：
1. **基准点（$8/hr × 60%）九年毛利仅 $48K**——利润极薄，但**转正**。这解释了 CoreWeave 商业模式的核心杠杆：**不是靠差价赚大钱，而是靠「9 年合同」把 $199K 采购成本摊到 9 年（年资本成本 $22.1K → $12.2K，−45%）**，让 $5-8/hr 的批发价也能盈利。
2. **盈亏平衡线**：约 $7.5/hr × 60%，或 $8/hr × 55%——旧 GPU 的生死线在「租赁价 × 利用率」乘积 ≥ $4.5/hr·利用率 100% 当量。
3. **利用率是第二杠杆**：$8/hr 下利用率 50%→75% 毛利 −$15K→+$143K（Δ$158K），比提价 $4/hr 更陡——**合同锁定（高利用率）比定价权更值钱**，这正是 CoreWeave 4.2GW 签约的意义：把利用率不确定性转化为合同承诺。

### 9.2 Burry $176B 折旧缺口验算（模型 2）

- 缺口 $176B（2026-2028）= 年缺口 **$58.7B**
- 缺口公式：`年缺口 = GPU 年 capex × (1/实际寿命 − 1/账面寿命)`

| 实际寿命 | 账面寿命 | 隐含 GPU 年 capex | 合理性 |
|:--------:|:--------:|:-----------------:|:-------|
| 3 年 | 6 年 | **$352B** | ✅ 自洽（hyperscaler 2026 GPU capex 量级） |
| 2 年 | 6 年 | $176B | 偏低（仅训练卡） |
| 3 年 | 5 年 | $440B | 偏高（含全部 AI 资本开支） |

**结论**：$352B 隐含值与 2026 年 hyperscaler 合计 capex（$500B+，GPU 占 60-70%）**吻合**——Burry 的 $176B 缺口在算术上成立（若 GPU 真实寿命确实 3 年而非 6 年）。但 v1.0 §6 已论证：**寿命是利益函数而非技术事实**，Kress/Intrator 的 6-9 年假设同样有基础设施约束支撑（老机房物理锁定）。三方数字自洽但前提互斥——这正是"认知战"的量化形态。

### 9.3 旧卡定价地板/天花板（模型 3）

**定价地板 = 边际成本（折旧后）**：

| 功耗 | 电价 | 年电力成本 | 单卡时价地板 |
|:----:|:----:|:----------:|:------------:|
| 400W | $0.08/kWh | $280 | **$0.032/hr** |
| 400W | $0.15/kWh | $526 | $0.060/hr |
| 700W | $0.08/kWh | $491 | $0.056/hr |

→ 8 卡节点地板 ≈ **$0.26-0.48/hr**（电力），加运维约 $1-2/hr。

**定价天花板 = 替代方案 TCO**（新 GPU 摊薄成本 + 交付等待成本）。**当前价差 $8/hr 与地板 $1.5/hr 之间是 5× 的毛利空间**——只要需求外溢存在，旧卡定价就远离地板。TH 金句"已通电容量无更高价值用途"的量化表达：**存量机房的机会成本 ≈ $0，因此任何 ≥ 边际成本的价格都是净赚**。

### 9.4 4.2GW 签约的期权量化（模型 4）

| 口径 | 换算 | 结果 |
|:-----|:-----|:-----|
| 20kW/rack × 8 卡 | 1GW = 50K rack | **400K GPU/GW** |
| 40kW/rack × 16 卡 | 1GW = 25K rack | 400K GPU/GW |
| **2.7GW 未交付**（4.2−1.5） | 20kW 口径 | **≈ 108 万 GPU** |

**期权结构量化**：2.7GW ≈ 108 万张 GPU 的**远期交付承诺**。按 $8/hr × 60% × 9 年单卡毛利 $6K 推算，108 万卡 × $6K ≈ **$648B 潜在毛利池**（未折现，粗估）——这是营收积压 $104B 的 6 倍量级。**承诺的期权价值巨大，但要求 2027 年前推理需求不塌方**（§6 边界 2 的量化锚点：每 token 算力需求降 50% → 108 万卡需求减半 → 期权变负债）。

### 9.5 边界条件量化阈值（模型 5）

**电价容忍度**（基准 $0.08/kWh、$8/hr、60% 利用率）：

| 电力成本占收入比 | 电价阈值 | 容忍倍数 |
|:----------------:|:--------:|:--------:|
| 30% | $0.222/kWh | 2.8× |
| 50% | $0.369/kWh | 4.6× |
| 70% | $0.517/kWh | 6.5× |

**能效剪刀阈值**：A100 每 token 功耗为新卡 2-3× → 电价上涨 **~1.4-3.0×** 时，同负载下 A100 的电力成本超过新卡全成本 → **剪刀闭合、A100 率先退役**。该阈值显著低于 §9.5 的 4.6× 容忍度——**能效差比电价绝对水平更早杀死旧卡**，所以边界 1（电价）与边界 2（推理效率）中，**效率提升是更致命的变量**（与 v1.0 §6 判断一致，现给出量化依据）。

### 9.6 v1.1 量化结论（更新摘要）

1. **9 年寿命的微观基础 = 边际成本定价 + 合同摊薄**：折旧完成后单卡地板 $0.03/hr，合同锁定利用率 → 旧 GPU 是"印钞机"（毛利空间 5×），但前提是**需求外溢持续**。
2. **盈亏平衡线 ≈ $7.5/hr × 60%**：CoreWeave 的定价权区间（$8-12/hr）恰好卡在盈亏线之上——这不是巧合，是融资结构倒逼的定价纪律。
3. **最脆弱变量是推理效率（非电价）**：能效 2-3× 差使效率提升对旧卡的杀伤早于电价上涨 1.5-2×。
4. **期权规模 = 108 万 GPU**：2.7GW 未交付承诺的潜在毛利池 ~$648B，兑现前提是推理需求 2027 不塌方。
