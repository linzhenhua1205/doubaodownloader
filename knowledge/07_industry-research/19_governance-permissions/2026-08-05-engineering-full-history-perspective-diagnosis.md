## §1 结论概要

1. **分类标准 v3.0 定稿**（用户定义）：工具 / 业务深度调研 / 数据导入 / 定期调研 四类为主，记忆与网页产物单列。分类正确是统计有意义的前提——此前两轮"对不上"根因是分类口径错误，不是数据错误。
2. **工程三阶段清晰可辨**：6月建立导入期 → 7月扩张加工期 → 8月收敛治理期。文件改动全景（A/M/R/D）与阶段特征完全吻合。
3. **问题高发区（churn 雷达）锁定四大治理税**：① 重命名整理税（全程 4488 次）② 索引维护税（KROOT M=466）③ discover 试验场批量加工反复（7月 3.2 万次修改）④ 格式残留（02_rd 420 处标题层级跳跃）。
4. **文件质量是下一重点**：现有 50+ check 脚本已覆盖格式/链接/索引/合规，但内容深度质量（信息密度/断言出处/论证链）仍靠人工——AI 自动优化应走"脚本检测 + AI 批处理 + 人工抽验"三级流水线。

> **说明**: 标题层级跳跃是当前最大格式残留——属**机械可修复**问题（脚本可自动调整层级），是 AI 自动优化的第一目标。

### 6.2 质量工具现状（50+ check 脚本已就位）

- **格式层**: check_md_format / format-validator / md-format / index-log-normalizer
- **链接层**: link-validator / link-fixer / link-fix-audit / source-reachability
- **结构层**: check-spec-format-standards / check-skills-registration / check-scheduled-tasks-compliance
- **内容层**: check_tech_doc_quality / doc-quality / doc-review / quantitative-check / ref-drift-detector
- **合规层**: constraint-check / strategy-compliance / relation-integrity

> **缺口**: 格式/链接/索引已脚本化且大多可自动修复；**内容深度质量**（信息密度/断言出处/论证链/创新点）仍靠人工 review——这正是"AI 自动优化"要补的空白。

## §7 AI 自动优化方案（下一阶段重点）

### 7.1 三级流水线（脚本检测 → AI 批处理 → 人工抽验）

```text
L1 脚本检测（已就位，零成本）
   +- check_md_format R1 / link-validator / index-log-normalizer --check
        -> 输出问题清单（文件×行号×类型×可修复性）

L2 AI 批处理（新增，核心杠杆）
   +- 机械修复（可自动）：标题层级跳跃 420 处、格式归一、链接重定向
   |    -> 复用 discover 批量加工模式（已有 7月 3.2 万次修改的成熟经验）
   +- 内容增强（需判断）：信息密度不足 / 缺断言出处 / 无交叉链接
   |    -> 批量脚本 + AI 逐文件处理 + 变更日志（diff 可审计）
   +- 辩证质检（多维度）：同一文件多视角审查（事实/逻辑/结构/格式）
        -> 不同 prompt 交叉验证，冲突处人工裁决

L3 人工抽验（保底）
   +- 抽样 5-10% + 关键文档全审 -> 反馈修正 prompt 与修复规则
```

### 7.2 落地五步

| 步 | 动作 | 产出 |
|:-:|:-----|:-----|
| 1 | 全库 R1 扫描基线（check_md_format --recursive 全 2,701 md） | 问题清单（预估 500-1000 处可机械修复） |
| 2 | 机械修复批处理（标题层级/格式归一），修复前备份到 bak/ | 格式 0 残留 |
| 3 | 内容深度批处理试点（选 02_rd 一个子目录）：AI 逐文件补出处/链接/信息密度，diff 审计 | 试点报告 + 修复规则 v1 |
| 4 | check 脚本入 commit 门禁（pre-commit hook 或 CI） | 防复发 |
| 5 | 月度质量扫描自动跑（复用 knowledge-special-reports-updater 模式） | 质量趋势报告 |

### 7.3 质量提升的辩证方法（多维度交叉）

- **不只看格式**：格式（机器可查）→ 结构（TOC/分层）→ 内容（信息密度/深度）→ 语义（断言出处/论证链）→ 关联（交叉链接/图谱）
- **不单点判断**：同一文档用"读者视角 / 审稿人视角 / 检索者视角"三视角评估，冲突处人工裁决
- **修复可回滚**：AI 批处理全部走 bak/ + git diff 审计（复用 8/5 link-fix-audit 模式）
