## 1. 专题概览

- **核心主题**：AI 推理/API 的"单位 Token 成本"——它的物理构成、计量规则与市场定价现状，以及对企业（尤其服务器/AI 基础设施厂商）的战略含义。
- **为什么跟踪**：Token 是 AI 时代的"算力货币"（腾讯 Token 经济学系列）；单位成本决定 AI 应用规模化边界；计费单位正在裂变，预算语言被重写——这是**每个 AI 采购者与算力供给者都必须理解的结构**。
- **业务价值**：对服务器厂商——Token/$ 是产品价值的最终度量（知识库 Token 经济模型核心指标）；对 AI 应用方——单位成本决定 ROI；对决策者——理解成本结构 = 理解 AI 产业链的价值分布。
- **关键判断**：① 单位 Token 成本正在以每年约 10 倍速度下降（超 PC/互联网历史速度），**成本下穿是 Agent 时代规模化的前提**；② Token 仍是底层计量颗粒，但**已不能单独解释 AI 账单**——计费向 search/runtime/cache/outcome 多维裂变；③ 竞争格局上"成本在下沉、价值在上移"——底层拼效率、上层拼不可替代性。

## 2. 技术深潜：单位 Token 成本背后的原理

### 2.1 Token 的计量本质：BPE 分词

Token 是 LLM 处理文本的最小单元，由 **BPE（Byte-Pair Encoding，字节对编码）** 分词算法产生：

- 中文约 **1 字 ≈ 1~2 token**，英文约 **1 词 ≈ 1.3 token**，代码约 **1 token/字符数×0.3**；
- 模型按 token 流处理（embedding→attention→输出），所以 token 是**算力的天然计量颗粒**——就像电力的 kWh、流量的 GB；
- **计量的前提是标准化**：各家分词器（GPT Tokenizer / Llama Tokenizer / Qwen Tokenizer）不同，同一段文本在不同模型下 token 数可差 30%+——这是跨模型比价的第一个隐蔽陷阱。

### 2.2 成本结构第一性原理：prefill vs decode

LLM 推理一次请求 = 两个物理阶段，成本结构完全不同：

| 阶段 | 过程 | 计算特性 | 成本特性 |
|:-----|:-----|:-----|:-----|
| **Prefill（输入处理）** | 并行处理全部输入 token，生成 KV 缓存 | 高并行度矩阵乘，**可高效批处理** | 边际成本低，随输入长度线性增长 |
| **Decode（输出生成）** | 逐 token 顺序生成（自回归） | **严格串行**，每步依赖上一步，内存带宽受限 | 边际成本高，随输出长度线性增长 |

**核心物理约束**：decode 是内存带宽密集型（每 token 需读取全部模型权重），且无法通过并行加速——**这是输出 token 成本天然高于输入的结构性原因**，与硬件（HBM 带宽）、算法（自回归）双重绑定。

### 2.3 为什么输出比输入贵 3-5 倍

市场定价中，OpenAI/Anthropic/Google 对输出 token 定价普遍是输入的 **3-5 倍**（introl 素材原话：输出生成需顺序处理，输入处理可高效并行）。对应关系：

```
输入（prefill）: 可并行 → GPU 利用率高 → 每 token 成本低 → 定价低
输出（decode） : 串行   → GPU 利用率低 → 每 token 成本高 → 定价高
```

**推论**：生成长输出（Agent 推理、代码生成、长文写作）的应用与"长输入+短回复"（RAG 问答）应用，面对完全不同的单位经济学——**Agent 时代（输出 token 占比上升）对成本结构的敏感度远高于对话时代**。

### 2.4 KV 缓存与上下文成本

- 每个活动请求的 **KV 缓存内存与上下文长度成正比**——长上下文应用压低并发、提高每 token 成本；
- KV 缓存是**固定于请求生命周期**的成本（常驻），与是否生成输出无关；
- 因此"上下文缓存"（cache read/cache write）成为独立计费项：**缓存命中（cache hit）大幅降价、缓存写入（cache write）单独收费**——这是计费单位裂变（§3.3）的第一个物理根源；
- 优化杠杆：PagedAttention（虚拟内存式管理）、前缀缓存、KV 压缩——知识库推理内存前沿（OasisKV 等）正是这一成本项的攻防前沿。

### 2.5 利用率决定真实单位成本

**API 定价掩盖了基础设施现实**——GPU 利用率才是真实单位成本的主宰：

```
每千 token 成本 $0.013 @ 100% 利用率
  → 10% 利用率时实际成本 = $0.13（10 倍恶化，比高端 API 还贵）
```

**自托管收支平衡点**（introl 素材量化数据）：

| 模型规模 | 收支平衡利用率 | 逻辑 |
|:-----|:-----|:-----|
| 7B | ~50% | 能力溢价低，只能拼成本 |
| 13B | ~10% | 能力溢价高，替代更贵 API 即回本 |
| 阈值 | 每日 >8,000 次对话 | 低于此量自托管固定成本不划算 |

**关键洞察**：较大模型在较低利用率下即可收支平衡（因为替代的是更贵的 API）——**模型能力溢价与基础设施成本之间存在直接的换算关系**，这是"买 API 还是自托管"决策的第一性框架。

### 2.6 成本下降曲线：每年 10 倍的第一性解释

**事实**：GPT-4 同等性能成本从 2022 年末 $20/M tokens → 2025 年末 $0.40/M（**50 倍下降**）；H100 云价格从峰值跌 64-75% 后稳定在 $2.85-3.50/小时（introl）。下降速度超过 PC 计算能力（摩尔定律 ~2 年 2 倍）与互联网带宽（~1.7 年 2 倍）历史。

**第一性解释——三重杠杆复合**：

| 杠杆 | 机制 | 量级 |
|:-----|:-----|:-----|
| 硬件迭代 | Blackwell FP4、HBM 带宽提升 | 单卡 4×（FP4 量化） |
| 算法优化 | 量化（8bit/4bit）、蒸馏、稀疏化 | 4-8× |
| 系统创新 | 连续批处理、推测解码、PagedAttention | 2-4× |

**复合效应**：量化 4× × 连续批处理 2× × 推测解码 2× = **16× 有效成本降低**（introl 原话）——三者叠加即"每年 10 倍"的来源。这是**学习曲线效应**（累计产量翻倍、单位成本按固定比例下降）在 AI 推理上的极端体现。

**推论**：成本下穿是 Agent 时代的前提（Google I/O 2026 判断）：Agent 任务 token 消耗是对话的数倍到数十倍，只有单位成本以数量级下降，Agent 闭环（规划-工具调用-验证）才经济可行。

## 3. 计量方法：从单维 Token 到多维账单

### 3.1 API 侧计量：Token 四分类

GitHub Usage Report 的 **per-model token 细分**给出了成本治理的**最小完备集**——四类 token 覆盖 LLM 推理成本的全部结构性来源：

| Token 类别 | 成本性质 | 优化杠杆 |
|:-----|:-----|:-----|
| **input tokens** | 每请求必付（prefill） | 精简 prompt、检索裁剪 |
| **output tokens** | 生成量决定 | 控制长度、减少废话 |
| **cache read tokens** | 命中缓存，大幅优惠 | 提高提示复用率（**杠杆最大的单一维度**） |
| **cache write tokens** | 写入缓存，单独收费 | 控制缓存写入频率 |

**原理**：这四类不是随意切分，而是对应 prefill（input）、decode（output）、KV 缓存命中（cache read）、KV 缓存写入（cache write）四个物理成本源——**计量结构 = 成本结构**。

### 3.2 定价档位体系

主流 API 定价的完整档位（腾讯文 2026-04 整理）：

| 厂商 | 计费项（Token 之外） | 说明 |
|:-----|:-----|:-----|
| **Anthropic** | session runtime $0.08/会话·小时；cache write/hit 乘数 | Agent 会话时长独立计费 |
| **OpenAI** | web search 按千次调用；container 按 session 时长；file search storage 按 GB/天；regional processing +10% | 价格页 = 资源总账 |
| **Google Gemini** | grounding（搜索增强）单列；context caching 独立计价 | 收敛但仍多维 |

**典型任务账单分解**（腾讯文案例，量化对比）：

| 任务类型 | 模型 | Token 成本 | 外围成本 | 主导项 |
|:-----|:-----|:-----|:-----|:-----|
| 轻量检索问答 | Gemini 2.5 Flash-Lite（5K+1K） | **$0.0009** | grounding $0.035（≈Token 40 倍） | **搜索/grounding** |
| 前沿模型推理 | GPT-5.4（5K+1K） | **$0.0275** | web search $0.01 + container $0.03 | **模型 + 工具同量级** |
| 一小时 Agent 编码 | Claude Opus 4.6（50K+15K） | **$0.625** | session runtime $0.08 | **模型为主** |

**结论**：没有通用的"AI 单位成本"——查资料钱花在搜索、动脑子钱花在模型、后台常驻钱花在时长。**成本大头取决于任务形态**。

### 3.3 计费单位裂变：五层结算栈

腾讯 Token 经济学提出 **AI 经济五层结算栈**——Token 只是最底层：

```
第五层 · 结果与责任层  ← outcome 定价（Intercom $0.99/次）、eval card
第四层 · 执行交付层    ← 托管/观测的数字劳动力、agent marketplace
第三层 · 知识封装层    ← Skill/Prompt/Eval/Policy/Memory
第二层 · 协议与能力层  ← MCP/A2A/Agent Skills（互操作接口）
第一层 · 公用事业层    ← Token/算力/缓存/搜索/容器（可计量认知吞吐量）
```

**分布规律**：越靠下越易单位化/路由化（按成本比价）；越靠上越嵌入上下文/责任（按结果付费）。**底层锚定投入成本，上层锚定创造价值**——"成本在下沉，价值在上移"。

**卖方信号**：OpenAI CFO（2026-01）公开三条商业化路径（订阅/广告/API）+ 未来扩展"授权、IP 协议、按结果定价"——平台自己都不再用单一按用量计费描述自己。

### 3.4 买方侧计量：Token/s · Token/Watt · Token/$

知识库 [Token 经济模型](../../02_rd/02_project/01_superpod/evaluation/2026-07-08-05-token-economics-model.md)（981 行）定义了买方/供给方的三维计量体系：

```
Token/s    = AI 工作负载的单位时间 Token 产出效率（性能维度）
Token/Watt = 能效 = Token/s ÷ 平均功率 W（绿色维度）
Token/$    = 经济性 = Token 总产出 ÷ 全生命周期 TCO（成本维度）
```

- 覆盖**推理与训练**两种负载、**单节点与超节点**两种粒度、国产/进口芯片对比；
- 已有产业落地：**ODCC Token 质量标准、华为 Token 经济学组网模型、运营商 Token 定价模式**（§6）——行业正在把 Token 作为算力的标准度量单位。

## 4. 市场现状（2026）

### 4.1 全球定价格局：三档分层

introl（2025-12 数据）整理的全球 API 定价跨越**三个数量级**：

| 档位 | 代表模型 | 输入 $/M | 输出 $/M | 特征 |
|:-----|:-----|:-----:|:-----:|:-----|
| **经济型** | Gemini Flash-Lite | 0.075 | 0.30 | 几分之一美分；Llama 3.2 3B 低至 0.06 |
| **中端生产** | Claude Sonnet 4 | 3.00 | 15.00 | DeepSeek R1: 0.55/2.19（**比西方低 90%**） |
| **前沿能力** | Claude Opus 4 | 15.00 | 75.00 | GPT-4 级；能力溢价无法被小模型复制 |

**关键事实**：
- **同模型跨提供商价格差 10 倍**（最便宜 $0.90 / 中位 $3.50 / 最贵 $9.50）——跨提供商比价在技术优化之前就能显著影响成本；
- 输出/输入比普遍 3-5 倍（§2.3）；
- 2026 年推理市场规模预测 >**$500 亿**（introl）；
- 订阅端价格战已打响：Google AI Plus $7.99→**$4.99/月**（I/O 2026），Gemini 3.5 Flash 成本 <50%、12× 加速（I/O 2026）；
- 基础设施端：H100 制造成本 ~$3,320 vs 售价 $25,000-40,000（利润率 7-12 倍，需求驱动）；云租 $2.85-3.50/h 趋于稳定。

### 4.2 中国 vs 西方：价格战的结构性教训

**中国 2024 价格战**（腾讯文）：部分厂商降价超 **97%**、推理毛利跌至负数——整场战争只围绕"谁的百万 token 更便宜"一个维度竞争。

**结构性教训**：
1. **单维竞争 = 负毛利终点**：当所有玩家挤在同一计量单位（token）上比价，价格战没有下限——**差异化必须发生在计量维度之外**（质量、生态、结果保证）；
2. **中国厂商的定价优势仍在**：DeepSeek R1 以 $0.55/$2.19 冲击市场（低 90%）——中国供给侧持续给西方施加价格压力，使所有买家受益；
3. **计费维度落后**：runtime/grounding/outcome 等维度在美国价格页已独立成行，中国仍停留在早期——**下一轮竞争将在多维计费与结果定价上展开**。

### 4.3 竞争格局与价值分层

| 玩家 | 位置 | 战略 |
|:-----|:-----|:-----|
| **OpenAI** | 前沿 + 资源总账 | 订阅/广告/API 三路径 + 未来结果定价；CFO 公开商业化路线 |
| **Anthropic** | 前沿 + Agent 会话 | Managed Agents session runtime 计费；Mythos invitation-only |
| **Google** | 全栈 + 价格屠夫 | Gemini Flash-Lite 最低价 + 订阅降价 + TPU 8t 成本 -40%（I/O 2026） |
| **DeepSeek/中国系** | 中端颠覆者 | 低 90% 定价、开源；持续价格压力 |
| **开源生态**（Together/Hyperbolic） | 经济型 | Llama 3.2 3B $0.06/M，成本千分之一 |
| **应用层**（Salesforce/Intercom） | 结果层 | Flex Credits 动作配额 / outcome $0.99 次 |

**结构趋势**："成本在下沉、价值在上移"——前沿能力集中（Mythos 邀请制），工作层持续商品化（价格持续下降）。

## 5. 五看分析

### 5.1 看宏观/行业（PESTEL + 产业链）

| 维度 | 分析 |
|:-----|:-----|
| **P 政策** | 数据主权/合规推动私有化推理（GitHub BYOK 一等公民）；AI Act 执行影响云端 vs 端侧 |
| **E 经济** | 超大规模云资本开支持续（$600B 级）；推理市场 >$500 亿且高速增长；价格战压缩毛利 |
| **S 社会** | Agent 进入日常工作流（ticket-as-spec）；token 消耗 KPI 化（"程序员一周烧掉 33 个维基百科"） |
| **T 技术** | 每年 10 倍成本下降（量化/批处理/推测解码）；KV 缓存优化是当前主战场 |
| **E 环境** | Token/Watt 成为绿色指标；液冷/800VDC 直接服务推理能效 |
| **L 法律** | 内容版权（SynthID）；AI 责任界定（outcome 定价的合同化前提） |

**产业链结构**（token 成本视角）：

```
上游 硬件/能源（GPU/HBM/电力）
  ↓  Token/$ 决定硬件价值
中游 模型/推理平台（OpenAI/Google/DeepSeek/开源）
  ↓  API 定价 = 单位 token 成本
下游 应用/Agent（企业工作流、垂直场景）
  ↓  计费单位裂变（token→outcome）
终端 用户（预算语言重写）
```

### 5.2 看市场/客户（TAM-SAM-SOM）

| 指标 | 当前（2026） | 3 年（2029） | 5 年（2031） | 依据 |
|:-----|:----------:|:----------:|:----------:|:-----|
| TAM（AI 推理总市场） | >$500 亿 | 千亿美元级 | — | introl 预测 + 年 10 倍成本下降反推量增 |
| SAM（可服务市场：企业 AI 支出） | 百亿美元级 | — | — | Gartner：AI 支出管理 2027 百亿美元 |
| SOM（成本治理/优化工具） | 早期 | — | — | 计费裂变 → 治理需求爆发 |

**客户画像与需求**：

| 客户类型 | 核心需求 | 痛点 | 付费意愿 |
|:---------|:---------|:-----|:---------|
| 超大规模（云/搜索） | 单位成本最低、规模效应 | 利用率、缓存命中率 | 高（内部优化） |
| 企业 AI 采购者 | 成本可解释、预算可控 | 计费多维化、无法对账 | 高（治理工具） |
| 开发者/独立应用 | 便宜、快、可预测 | 输出 token 贵、延迟 | 中（性价比敏感） |
| 服务器/算力厂商 | Token/$ 最优产品定义 | 利用率、能效 | 高（自托管转型） |

### 5.3 看竞争（波特五力）

| 力量 | 强度 | 分析 |
|:-----|:-----|:-----|
| 现有竞争者 | **高** | 三档分层 + 中国低 90% 定价 + 开源低价；价格战持续 |
| 新进入者 | **中** | 模型层门槛高（训练成本），但推理服务层门槛低（租 GPU 即可） |
| 替代品 | **中** | 自托管/开源（平衡点：8000 对话/天）；端侧模型（Glimmer/Nano）分流 |
| 供应商议价力 | **高** | GPU 供给集中（NVIDIA 主导），H100 利润率 7-12 倍 |
| 客户议价力 | **中→高** | 同模型跨提供商 10 倍价差 → 客户比价空间大；多维计费降低透明度 |

### 5.4 看自身（能力 × 资源 × 壁垒）

| **客户/渠道** | 中 | 服务器产品研发角色，面向数据中心客户 |
| **资金/资源** | 中 | 非云厂商，无大规模 GPU 自有池 |
| **IP/标准** | 中 | 可参与 Token 度量/能效标准（ODCC 生态） |
