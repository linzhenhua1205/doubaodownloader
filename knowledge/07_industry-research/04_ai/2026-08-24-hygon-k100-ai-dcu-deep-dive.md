## 〇、结论概要

**海光 K100-AI 是海光信息（688041.SH）深算一号 DCU 的 AI 优化型号**，产品系列官方名称为**海光 8000 系列（深算一号 = 海光 8100）** [来源: 海光招股说明书]。

核心事实（按可信度排序）：

| # | 事实 | 数值 | 来源级别 |
|:-:|:-----|:-----|:--------:|
| 1 | 深算一号计算单元 | 60-64 CU，最多 4096 核心 | 🟢 官方（招股书） |
| 2 | 精度支持 | FP64 / FP32 / FP16 / INT8 / INT4 | 🟢 官方（招股书） |
| 3 | 显存 | 32GB HBM2，4 通道，4096-bit，2.0GHz，1024GB/s | 🟢 官方（招股书+计量院） |
| 4 | 工艺 / 功耗 | 7nm FinFET / TDP 350W（典型 260-350W） | 🟢 官方（招股书+计量院） |
| 5 | 互联 | PCIe Gen4 x16 上行；xGMI x2 GPU 间互联（up to 184GB/s） | 🟢 官方（招股书+计量院） |
| 6 | K100-AI 采购规格 | FP32 ≥49 TFLOPS；TF32 ≥98 TFLOPS | 🟢 政府采购公告 |
| 7 | K100-AI 半精度 | BF16/FP16 ~192 TFLOPS（二手，口径待核） | 🟡 二手（CSDN） |
| 8 | 深算一号 FP32 峰值 | ~13.9 TFLOPS（按 4096 核 × 1.7GHz 理论推算） | 🟡 推算 |

**关键结论**：
1. **K100 有官方一手规格**，出自海光科创板招股说明书（2022-08-09），并经**中国计量科学研究院《测试报告》CLzn2020-01190** 背书——这是国产加速卡中罕见的国家级计量验证 [来源: 招股书 P140-141]。
2. **K100 与 K100-AI 是不同型号**：K100 为全精度（FP64 完整）版本；K100-AI 为 AI 优化版，FP32/TF32 算力显著更高（采购公告口径 49/98 TFLOPS），且**海光官方未公开 K100-AI 的独立 datasheet**，参数仅能从政府采购公告与第三方评测交叉获取 [来源: 国家先进技术转化应用公共服务平台 2024-11-12; 雪球 2024-08-09]。
3. **软件栈证据确凿**：海光官方 GitHub 组织（HYGON-AI，11 个仓库）模型兼容表将 **K100_AI / BW1000 / BW1100** 列为独立硬件列；驱动栈含 `libhydmi.so`（自研）+ `librocm_smi64.so`（AMD NCSA 许可证衍生），确认 **HCU = ROCm 兼容路线** [来源: github.com/HYGON-AI]。
4. **官方"手册"状态**：海光不公开发布 K100-AI 硬件用户手册 PDF（硬件手册随服务器厂商交付）；软件手册/DTK（DCU Toolkit）位于开发者站 developer.hygon.cn（调研当日 DNS 不可达，需换网络环境验证）。

## 一、产品身份与命名体系

### 1.1 命名图谱

海光产品线官方命名为"海光 8000 系列"（DCU），与 CPU 的"海光一号~四号"并列 [来源: 招股说明书 P107]：

```
Hygon DCU Product Line (Hygon 8000 series)
+-- ShenSuan-1 (Deep Computing Unit Gen1) = Hygon 8100
|   +-- K100     - full precision version (FP64 complete, 2021)
|   +-- K100-AI  - AI-optimized version (FP32/TF32 boost, 2023-2026)
+-- ShenSuan-2 (Gen2) = K200 (dev from 2020-01, mass 2023-2024)
|   +-- ShenSuan-2 AI version (single precision CU optimized)
+-- ShenSuan-3 (Gen3, 2024-2026 rumor/partial disclosure)
+-- New platform: BW1000 / BW1100 (HYGON-AI model table, 2026)
```

> ⚠️ 注意：BW1000/BW1100 仅在 HYGON-AI GitHub 模型兼容表中出现，官方产品命名未公开确认，本文不展开。

### 1.2 官方定位表述

- **DCU = 海光协处理器**（Deep Computing Unit），与 CPU 并列的主营产品 [来源: 招股书 P28]。
- 属 **GPGPU** 一种：`"海光 DCU 属于 GPGPU 的一种…全面兼容 ROCm GPU 计算生态"` [来源: 招股书 P107]。
- 兼容"类 CUDA"环境：`"由于 ROCm 和 CUDA 在生态、编程环境等方面具有高度的相似性，CUDA 用户可以以较低代价快速迁移至 ROCm 平台，因此 ROCm 也被称为'类 CUDA'"` [来源: 招股书 P107]。
- 主要部署：`"服务器集群或数据中心，为应用程序提供高性能、高能效比的算力"` [来源: 招股书 P107]。

### 1.3 研发与商业化时间线

### 2.2 架构要点（第一性原理解读）

**计算单元架构**：64 CU × 64 核心 = 4096 核心，对应 **AMD Vega 20（GCN 5.1）衍生架构**——与 AMD MI50/MI60（同为 64CU/4096 核/7nm/HBM2）核心参数高度一致 [来源: 参数对照为本文推算]。深算一号可视为 Vega 20 授权架构的本土化改版：频率微降（FP32 1.7 vs MI60 1.8GHz）、功耗略升（350 vs 300W）。

**互联架构**：GPU 间使用 **xGMI**（AMD 的 Infinity Fabric GPU 互联协议在 ROCm 生态中的命名），双链路 184GB/s——说明海光 DCU 的片间互联直接继承 AMD 技术授权，而非自研协议。这与华为 HCCS（自研）、NVIDIA NVLink（自研）形成路线对比 [来源: 招股书 P141; 交叉链接见文末]。

**算力推算**（非官方披露，标注为估算）：
- FP32 理论峰值 ≈ 4096 cores × 2 FMA × 1.7GHz ≈ **13.9 TFLOPS**
- FP64 理论峰值 ≈ 4096 × 2 × 1.5GHz ≈ **12.3 TFLOPS**（若 FP64 全速率；GCN 架构 FP64:FP32=1:2 时约 6.2 TFLOPS）
- 市场上流传的"FP32 11.5 TFLOPS"（今日头条 2025-03）接近上述 13.9 的实测/保守口径 [来源: 今日头条]

## 三、官方对比基准：深算一号 vs A100 vs MI100

招股书 P140-141 提供官方对比表，数据来源：**中国计量科学研究院《测试报告》（CLzn2020-01190）**——国家级计量机构出具，是 K100 参数最权威的官方验证 [来源: 招股书 P141]。

| 项目 | 深算一号 (海光) | NVIDIA A100 (Ampere) | AMD MI100 (CDNA1) |
|:-----|:---------------:|:--------------------:|:-----------------:|
| 生产工艺 | 7nm FinFET | 7nm FinFET | 7nm FinFET |
| 核心数量 | 4096 (64 CUs) | 2560 CUDA + 640 Tensor | 120 CUs |
| 内核频率 | FP64 up to 1.5GHz / FP32 up to 1.7GHz | up to 1.53GHz | FP64 1.5GHz / FP32 1.7GHz |
| 显存容量 | 32GB HBM2 | 80GB HBM2e | 32GB HBM2 |
| 显存位宽 | 4096 bit | 5120 bit | 4096 bit |
| 显存频率 | 2.0 GHz | 3.2 GHz | 2.4 GHz |
| 显存带宽 | 1024 GB/s | 2039 GB/s | 1228 GB/s |
| TDP | 350W | 400W | 300W |
| CPU 互联 | PCIe Gen4 x16 | PCIe Gen4 x16 | PCIe Gen4 x16 |
| GPU 互联 | xGMI x2 up to 184GB/s | NVLink up to 600GB/s | Infinity Fabric x3 up to 276GB/s |

**结论**（招股书原文）：`"在典型应用场景下，公司深算一号指标达到国际上同类型高端产品的水平"` [来源: 招股书 P141]。

**客观差距分析**（本文判断）：
- 深算一号对标的是 **A100 前一代水平**：显存带宽仅为 A100 的 50%（1024 vs 2039 GB/s）、GPU 互联带宽仅为 31%（184 vs 600 GB/s）——这两项是 AI 训练场景的核心瓶颈。
- 深算一号设计定位是 **2019-2020 年代际**（对标 MI100/V100 级别），2026 年视角下属于**国产第一代替代品**，AI 训练效率落后于 A100，但满足信创/推理/科学计算场景。

## 四、K100-AI 与 K100 的差异

### 4.1 差异确认

- 雪球用户明确指出：`"你这是海光DCU K100的参数，不是K100AI版的参数"`——证实 K100 与 K100-AI 规格不同 [来源: 雪球 2024-07-07]。
- 雪球 2024-08-09 帖子（xueqiu.com/6708171193/300519249）："海光K100 AI版是一款高性能的AI计算单元"，FP32 模式下算力性能显著高于 K100（正文 JS 渲染未完整获取，以摘要为准）[来源: 雪球]。
- 财富号文章：`"深算二号AI版用单精度的K100 AI计算单元替代了双精度…"`——暗示 K100-AI 的设计取向是**弱化/替代 FP64、强化 FP32/FP16** 的 AI 推理/训练优化 [来源: 东方财富财富号 2024-11-12，AI 生成内容，仅作线索]。

### 4.2 K100-AI 算力数据（口径分级）

| 数据 | 数值 | 口径 | 来源 |
|:-----|:-----|:-----|:-----|
| FP32（通用/向量） | ≥49 TFLOPS | 政府采购公告明确"FP32算力≥49TFLOPS" | 🟢 国家先进技术转化平台 2024-11-12 |
| TF32 | ≥98 TFLOPS | 同上公告"TF32算力≥98TFLOPS" | 🟢 同上 |
| FP32（含矩阵） | 98 TFLOPS | CSDN 评测"FP32通用算力98TF" | 🟡 CSDN 2025-11-06 |
| BF16/FP16 | 192 TFLOPS | CSDN 评测"BF16/FP16半精度峰值192TF" | 🟡 CSDN 2025-11-06 |

**解读**：采购公告 49/98 TF 与 CSDN 98/192 TF 呈 2 倍关系——合理猜测：49 TF 为**向量 FP32**（对应采购公告），98 TF 为**含矩阵指令的 FP32/TF32**（对应 CSDN），192 TF 为 **FP16/BF16 峰值**（矩阵加速）。若 K100-AI 含 Matrix Core（类似 MI100 的 CDNA 矩阵单元），FP32 Vector 49TF 与 MI100 的 FP32 Matrix 46.1TF 量级吻合——支持"K100-AI 基于 CDNA1 级矩阵扩展"的判断 [来源: 参数对照为本文分析]。

### 4.3 显存差异

- 二手信息（CSDN 2024-05-23 表格）出现"海光K100 深算二号 64GB 25TF"——该条目将 K100 与深算二号混列，**可信度低**；但 B站/抖音"海光DCU K100-AI 64G"（信创国产AI计算服务器）出现 64GB 表述 [来源: 抖音/CSDN]。**64GB 版本大概率属于深算二号（K200），K100-AI 主流为 32GB**——此项待官方确认。

### 6.2 HCU 驱动栈证据

hcu-dcgm 官方 README 披露（关键证据）：
- 运行时依赖 **`libhydmi.so`**（海光自研驱动接口）与 **`librocm_smi64.so`**（AMD ROCm SMI 库，**AMD NCSA 许可证**）——直接证明 HCU 驱动栈 = 自研封装 + ROCm 衍生 [来源: hcu-dcgm README]。
- 支持 **MIG 功能**（`libhydmi_mig.so`）——HCU 具备类似 NVIDIA MIG 的实例划分能力 [来源: hcu-dcgm README]。
- 驱动默认安装目录：`/opt/hyhal/lib`（Hygon HAL = 海光硬件抽象层）[来源: hcu-dcgm README]。

### 6.3 生态定位

- **迁移成本国产最低档**：`"业务代码里的 torch.cuda 几乎不用改"`；但 `"越往底层覆盖率掉得越快，到 warp 原语只剩一半"` [来源: 公众号"海光DCU全系列" 2026-08-17]。
- 框架支持：vLLM / SGLang / Transformers / Megatron-LM / verl / Apex / Mooncake，模型覆盖 Qwen3/DeepSeek-V3-R1/GLM/Kimi/MiniMax 等主流开源模型 [来源: inference-cookbook-das README]。
- 推理能力实证：单卡 K100-AI 可跑 14B/32B 大模型推理（B站实测）；64GB 显存压缩方案可跑 MiniMax-H3 等 [来源: B站/微信 2025-2026]。
