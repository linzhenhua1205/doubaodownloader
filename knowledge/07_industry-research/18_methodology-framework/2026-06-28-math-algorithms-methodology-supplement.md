## 一、方法论与思维模型

### 1.1 批判性思维规避逻辑谬误

**核心定义**：

- **逻辑谬误**：论证形式/推理过程存在漏洞，看似有理，实际推导无效（如偷换概念、人身攻击、以偏概全、滑坡谬误、诉诸情绪等）
- **批判性思维**：不被动接受观点，主动质疑前提、拆分论据、检验推理、区分事实与观点的思考方式

**三问自检法**：

1. **前提真吗？** — 验证论据的真实性
2. **论据和论点有关系吗？** — 检查逻辑关联
3. **推导是必然成立，还是主观猜测？** — 区分事实与观点

**思维流程**：

```text
暂停接收 -> 抓三要素（论点+论据+推理） -> 三问自检 -> 区分边界
```

**边界区分**：

- 事实 ≠ 观点
- 情绪 ≠ 逻辑
- 大众看法 ≠ 真理

### 1.2 ReAct推理循环机制

**核心原理**：
让Agent在生成结果前，分步输出推理过程，通过"逐步思考"解决复杂逻辑问题。

**核心流程**：

```text
问题 -> 分步推理（Step1明确已知条件 -> Step2推导中间结论 -> Step3验证逻辑一致性） -> 最终结果
```

**技术场景举例（BIOS启动故障排查）**：

- **问题**：服务器开机后卡在BIOS自检阶段，无法进入系统
- **推理Step1**：卡自检可能是硬件不兼容、BIOS设置错误、固件版本过低
- **推理Step2**：检查硬件日志，发现新更换的PCIe卡未被识别
- **推理Step3**：验证BIOS版本，确认当前版本不支持该PCIe卡的新固件
- **结论**：升级BIOS至最新版本，即可解决问题

**适用场景**：需要逻辑推导的任务（如故障排查、代码逻辑分析、算法设计）

### 1.3 输入输出映射分析

**系统定性**：
不属于简单线性函数，是多约束、多分支、多目标的复杂耦合系统，无法靠简易逻辑快速落地。

**输入源（带约束）**：

1. 核心原始输入：defer文件、di文件（支持压缩优化，文件性能随格式浮动）
2. 辅助上下文输入：代码知识库、全链路上下文、历史故障案例
3. 文件数量限流规则：单次接口最多传入20个文件，超量走独立扩展接口
4. 输入边界：存在数据体积上限

**中间判断层**：
输出需求分层分化：

- 需求A：代码质量综合评估报告
- 需求B：精准定位具体代码问题（多维度拆分：安全、可靠性、流程步骤等）

**落地原则**：

1. 先抽象系统输入、约束、分支规则，区分简易线性逻辑与复杂多维度耦合系统
2. 分层判定投入成本，匹配对应决策严谨程度，不浪费算力/时间在低价值小事过度推演
3. 交付物分两层：基础交付（文件/材料）+ 落地配套（步骤/方案）
4. 长期持续夯实阅读理解、逻辑拆解、行业研判三大基础能力，作为所有工作的底层支撑
5. 项目落地优先小切口具象案例，降低推进阻力，可视化呈现价值

## 二、Agent工程化与多智能体优化

### 2.1 多智能体协作模式

**AI Agent的必然性**：
生成式AI从"短文本问答"进入"工具化"阶段，但传统大模型在复杂任务中仍存在推理能力不足、缺乏工具调用协同等短板。AI Agent作为大模型的"增强形态"，通过整合推理、规划、工具调用和记忆能力，成为突破瓶颈的关键。

**多智能体蜂群协作案例（360集团"纳米AI"）**：

- 连续执行1000步复杂任务
- 任务成功率达95.4%

**智能体分级演进**：

- L1：基础问答
- L2：工具调用
- L3：推理规划
- L4：多智能体蜂群协作

### 2.2 Mesa联合策略优化

**实现原理**：
通过状态机循环实现Agent控制，核心是LangGraph状态机循环机制。

**关键优化方向**：

- 联合策略优化：多Agent协同决策
- 粒子群优化：群体智能搜索最优解
- 蚁群优化：路径寻优与资源分配

### 2.3 状态机循环实现（LangGraph）

**核心原理**：
用最通俗、最底层、带源码逻辑的方式实现状态机循环，是Agent控制系统的核心底层原理。

**状态版本控制**：

- **问题**：生产环境中，若修改Reducer逻辑（如字段类型变更），旧的状态快照可能不兼容新逻辑，导致合并失败
- **优化方案**：在Reducer中兼容旧数据格式，实现平滑迁移

## 三、数据科学与算法应用

### 3.1 用户LTV分析与增长策略

**分析流程**：

```text
用户LTV分析重要性 -> 构建分析模型 -> 依据模型定位客户价值 ->
针对不同价值客户制定维护/留存策略 -> 给出GMV持续增长办法 -> 形成完整实现方案
```

**Kmeans聚类实现**：

- **手肘法**：计算不同聚类数量（k值）下的误差平方和（SSE），绘制SSE与k值的关系曲线，曲线中"手肘"位置对应的k值即为较优聚类数量
- **业务经验结合**：结合平台业务场景和目标，对通过手肘法得到的k值进行调整，确保聚类结果具有实际业务意义

**数据整合与建模**：

- 通过ETL工具或SQL实现多源数据（数据库、API、CSV文件）的清洗、转换和加载
- 构建星型/雪花型数据模型，优化数据仓库结构，提升查询性能
- 管理数据连接池，配置数据源权限与安全策略

**API与生态扩展**：

- 开发Tableau REST API接口，实现与企业OA、CRM等系统的单点登录（SSO）集成
- 利用Tableau Extension API开发自定义可视化插件
- 设计数据管道，通过TabPy/Python脚本实现Tableau与R、Spark等工具的联动

### 3.2 AHP-CRITIC组合权重计算

**应用场景**：
多维度指标权重分配，结合主观判断（AHP）与客观数据波动（CRITIC）。

**实现步骤**：

1. 构建判断矩阵
2. 层次单排序及一致性检验
3. 计算CRITIC客观权重
4. 组合权重融合

### 3.3 基尼系数与洛伦兹曲线核心公式

**依托洛伦兹曲线定义**：

- 对角线（绝对公平线）与洛伦兹曲线围成面积：$A$
- 洛伦兹曲线下方剩余面积：$B$
- 正方形总面积：$A+B = \dfrac12$

**核心公式**：
$$G = \frac{A}{A+B} = 2A$$

**逻辑**：
曲线弯曲越大，$A$ 越大，基尼系数越高，收入分配越不平等。

## 四、AI训练与质量优化

### 4.1 数据清洗降噪

**淘汰类数据直接剔除**：

- 重复度>0.85文本、乱码、无意义短句、广告、极端情绪化内容
- 存在事实错误、时间/数值/专有名词冲突、主观偏见样本
- 回答残缺、逻辑断裂、自问自答无有效信息对话

### 4.2 高质量数据配比

**配比原则**：

- 优质结构化数据 ≥ 60%
- 闲聊/非正式文本控制在30%以内

**数据分层**：

- **通用基座**：通用百科、专业教材、权威论文、规范问答、官方文档
- **垂直场景**：行业标准、专家人工标注标准答案、业务真实优质对话

### 4.3 数据格式标准化

统一Prompt-Answer、指令-输出、多轮对话模板，规范输入输出边界，减少模型输出格式混乱。

### 4.4 回答质量优化闭环

```text
数据治理 -> 模型微调优化 -> 推理侧实时增强 -> 自动化+人工评测 -> BadCase回流迭代
```

## 五、业务分析框架

### 5.1 边缘计算中心成本分析

**场景化成本差异**：

- **轻量级场景**（如智能零售）：5年总成本约3500-6000万元
- **中高性能场景**（如智能制造）：5年总成本约7000-9000万元
- **超算级场景**（如自动驾驶）：5年总成本可达1.5-2.85亿元

**成本构成核心要素**：

- 硬件成本（服务器、存储、网络设备）
- 基础设施成本（机房建设、电力、制冷）
- 软件与运维成本（管理系统、技术支持）
- 网络与连接成本（带宽、专线）

**未来趋势**：
硬件成本绝对值上升但占比下降，基础设施与软件成本占比上升但结构优化。

### 5.2 市场决策框架（市场·逻辑·价值·行动）

**市场决策（前提）**：

- 聚焦25-45岁企业白领+个体工商户核心客群

- 应对低价竞争、供应链波动两大风险

**逻辑决策（依据）**：

- 核心变量识别

- 商业模式验证

**价值决策（目标）**：

- 用户价值定位

**行动决策（路径）**：

- 分阶段落地计划
- 关键里程碑设定
- 风险预案制定

### 5.3 GitHub Actions部署流程优化

**工具链丰富度评估**：

- 开发、测试、部署工具是否完善（IDE插件、自动化测试框架、CI/CD工具集成）

## 六、数学公式核心

### 6.1 概率计算公式

**适用**：所有结果等概率、有限个结果

$$P(A)=\frac{事件A包含的基本事件数}{试验总的基本事件数}=\frac{n(A)}{n(\Omega)}$$

**例**：掷骰子，点数为偶数

- 总事件6个，A={2,4,6}共3个
- $P=\frac{3}{6}=0.5$

### 6.2 集群互联链路数公式

**总物理链路数**：
$$\text{总物理链路数} = \dfrac{N \times (N-1)}{2}$$

**适用场景**：8卡/16卡 AI训练节点、GPU直连、低延迟共享内存集群
