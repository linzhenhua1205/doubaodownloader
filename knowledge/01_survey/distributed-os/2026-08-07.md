## §1 新增信号

- **HCCL: Collective Communication for Meta Training and Inference Accelerators**（arXiv 2608.00358, 2026-08-01, SC'26 录用）: Meta 首个片上集成后端网络的加速器 **MTIA 300** 的集合通信库，50+ 作者（含 Pavan Balaji/Sameer Kumar/Cristian Lumezanu 等网络系统专家）。核心设计：①专用**消息引擎 (ME) + 近内存计算 (NMC)** 把集合执行完全从计算阵列卸载，实现计算/通信大重叠；②**编译式通信模型**——host 生成包含依赖的完整集合描述，而非运行时解释；③跨 MTIA 300 非对称 scale-up/scale-out 网络的拓扑感知算法选择。**量化**: 训练场景 intra-rack 集合达 **940 GB/s** 且对并发计算吞吐损耗 <0.5%；推理场景用 **one-sided 原语绕过调度路径** 最小化集合延迟，并为延迟敏感负载设计计算-通信流水线。**相关性**: 极高——继 NVIDIA NCCL/AMD RCCL/Intel oneCCL 后，Meta 自研集合通信栈标志"超大规模自研芯片厂商的集合通信栈全面自研化"，编译式模型 + 片上卸载是 2026 集合通信两大新范式。URL: https://arxiv.org/abs/2608.00358

- **CommBench: Can LLMs Write Correct and Efficient GPU Communication Code?**（arXiv 2608.04450, 2026-08-05, UC Berkeley Ion Stoica 组）: 首个 GPU 通信编程评测基准——**100+ 专家构建任务**覆盖点对点、集合操作、专家并行通信、计算-通信融合、通信工具函数五类；配套**防作弊评估框架**（多 GPU 系统上自动编译/执行/验证生成的代码）与**统一指标**（功能正确性 × 通信性能联合度量）。在节点内 NVLink 与节点间 RDMA 双平台评测前沿与开源代码生成模型：**最强模型 GPT-5.5 也仅 30.7% 任务正确实现且达到有竞争力性能**。**相关性**: 高——揭示 LLM 在 GPU 通信系统编程上的巨大空白（正确性 + 性能双维度），与 08-02 收录的"LLM 生成分布式系统代码"谱系同向，且把集合通信编程确认为 AI-assisted systems programming 的新基准前沿。URL: https://arxiv.org/abs/2608.04450

- **NUNA: Characterizing and Mitigating Non-Uniform Network Access in Multi-Die GPU Scale-Up Systems**（arXiv 2608.00867, 2026-08-01, AMD 研究院）: 提出 **NUNA（非均匀网络访问）** 概念——多 die GPU 规模增大后，intra-socket 线传输延迟显著增长，GPU 间通信存在与内存 NUMA 类似的空间非均匀性。两个优化：**NUNA-aware routing (NAR)** 选择空间感知的优化 GPU 间路径；**NUNA-aware placement (NAP)** 把 threadblock 和数据放到靠近 I/O 的位置。**量化**: NAP 单独带来最多 **1.5×** 集合加速，NAP+NAR 组合达 **1.8×**；LLM 推理场景 token 输出时间平均提速 7%（最高 28%）。**相关性**: 极高——把"内存非均匀访问"分析框架推广到互连网络层，scale-up 域（NVLink/UALink 类）拓扑设计的新维度，与超节点 HBD（高带宽域）规模设计直接相关。URL: https://arxiv.org/abs/2608.00867

- **CHIARA: Configurable and Hierarchical Allreduce**（arXiv 2608.02884, 2026-08-03, Polaris/Aurora/Fugaku 三超算评估）: 可配置分层 Allreduce：通过**逻辑 batch-lane 拓扑**编码硬件层级，执行分阶段调度（任意时刻只有有界部分归约向量活跃）；跨 batch 通信经 **rotating-root lane 原语** 分布到多个 rank，避免集中 leader 瓶颈；在 Reduce-Scatter/Allgather 边界保留 lane 对齐的中间布局，免去域内重组（半组合 Rabenseifner 式）。**量化**: 在 Polaris/Aurora/Fugaku 上较厂商 MPI_Allreduce 最高 **1.94×/13.43×/13.48×** 加速，并行 k-means 端到端 2.2×。**相关性**: 高——小/中消息 Allreduce 的延迟与同步深度优化，硬件层级显式编码思路与 GPU 集群分层集合设计同源。URL: https://arxiv.org/abs/2608.02884

- **TAOT: Topology-Aware Optimal Transport for Dynamic Expert Replica Placement in MoE Training**（arXiv 2608.03676, 2026-08-04, 腾讯）: MoE 训练动态副本放置的拓扑感知最优传输：把热 expert 复制到空闲 rank 时，将热 rank 过载与空闲容量建模为**带通信成本矩阵的熵正则最优传输问题**，Sinkhorn-Knopp 迭代产出 rank 级 flow 提示，整数副本匹配 + token 分配合成可执行调度；系统层将 guest 权重传输与 home expert 计算重叠隐藏通信开销。**量化**: MoE 端到端训练 **1.43×** 加速，均衡质量不逊于 SOTA，全配置最低加权 expert 通信成本（最高降 **74%**）。**相关性**: 高——动态 MoE 副本放置从"只优化负载均衡"升级到"负载均衡 × 拓扑通信成本联合优化"，与 08-06 收录的"MoE 硬件实现"及 NVIDIA Wide Expert Parallelism 谱系直接相关。URL: https://arxiv.org/abs/2608.03676
