## 官方动态：NVIDIA NCCL 系列 blog 补录

- **NVIDIA Blog / NCCL 2.27 推理与弹性训练（2025-07-14）**: NCCL 定位从训练扩展到推理——官方明确 collectives（AllReduce/Broadcast/Reduce/AllGather/ReduceScatter）拓扑感知优化覆盖 PCIe/NVLink/Ethernet(RoCE)/InfiniBand 全互联谱系，推理场景快速 GPU 通信成 AI 规模化关键（URL: https://developer.nvidia.com/blog/enabling-fast-inference-and-resilient-training-with-nccl-2-27/）

- **NVIDIA Blog / NCCL Tuning 自定义 tuner 插件（2025-07-22）**: 平台多样化（NVLink 代际/网络拓扑差异）使 NCCL 默认配置不再最优——官方发布自定义 tuner 插件机制（NCCL_TUNER_PLUGIN），用户可按平台特征覆写算法选择/信道数/协议，填补"通用默认 vs 平台特异最优"的调优断层（URL: https://developer.nvidia.com/blog/understanding-nccl-tuning-to-accelerate-gpu-to-gpu-communication/）

- **NVIDIA Blog / NCCL 2.24 网络可靠性与可观测性（2025-03-13）**: 多 GPU/多节点（MGMN）通信在万卡规模下的可靠性治理——NCCL 2.24 引入网络错误处理增强与通信可观测性接口，为训练慢速定位提供库内信号（URL: https://developer.nvidia.com/blog/networking-reliability-and-observability-at-scale-with-nccl-2-24/）

- **NVIDIA Blog / NCCL 2.28 通信-计算融合 Device API（2025-11-10）**: 官方发布说明版——GPU-initiated networking + Device API 通信-计算融合 + Copy Engine collectives，与 08-16 已收录的 GIN 论文（2511.15076）同源，本条目为官方发布口径补充（URL: https://developer.nvidia.com/blog/fusing-communication-and-compute-with-new-device-api-and-copy-engine-collectives-in-nvidia-nccl-2-28/）

- **NVIDIA Blog / NCCL 跨数据中心通信与拓扑感知（2025-07-14）**: NCCL 开源跨 DC 通信特性——单 DC 算力不足时多 DC 协同训练成为显式支持场景，网络拓扑感知（topology awareness）扩展到数据中心级（URL: https://developer.nvidia.com/blog/nccl-deep-dive-cross-data-center-communication-and-network-topology-awareness/）

- **NVIDIA Blog / 可扩展与容错 NCCL 应用（2025-11-10）**: 运行时 rescaling（run-time rescaling）支持训练成本优化与服务停机最小化——NCCL 应用从"静态规模"走向"运行中弹性收缩/恢复"，与弹性训练主线一致（URL: https://developer.nvidia.com/blog/building-scalable-and-fault-tolerant-nccl-applications/）

- **NVIDIA Blog / NCCL Inspector Profiler Plugin 官方引入（2025-12-10）**: NCCL 官方 profiler 插件（轻量连续上报通信性能统计）首次发布介绍——解决训练中"通信阶段表现如何"不可见问题；与 08-16 已收录的 Prometheus 集成（2026-05-07）及 NIXT 导出工具论文（2608.01449）构成 Inspector 生态三件套（URL: https://developer.nvidia.com/blog/enhancing-communication-observability-of-ai-workloads-with-nccl-inspector/）
