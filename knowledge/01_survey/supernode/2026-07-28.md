### Helios 机架系统 — AMD 首套机架级 AI 方案

| 维度 | 数据 |
|:-----|:------|
| **定位** | AMD 对标 NVIDIA NVL72 的机架级 AI 系统 |
| **芯片组合** | **MI455X GPU** + **EPYC Venice CPU** (Zen 6) + **Pensando Vulcano DPU** |
| **MI455X GPU** | 2nm compute chiplets + 3nm IO dies, **432 GB HBM4**, 多计算芯粒设计 |
| **EPYC Venice CPU** | TSMC **2nm**, Zen 6, **最高 256 核/插槽**, 是 EPYC 史上最大代际性能提升 |
| **供货状态** | **Q3 2026 开始出货**, 2027 H2 扩量 |
| **机架形态** | 完整单机架系统，采用快速 scale-up 互联网络，整架作为一台单一机器运行 |

### 合作新生态

- **AMD + Cerebras**: Helios + Wafer Scale Engine 联合方案，提供超低延迟推理，Cerebras WSE 做 ULL 前端，Helios 做后端重载，5× WSE 单机性能。2026 年晚些时候 Cerebras 云服务提供
- **AMD + 开源**: ROCm.AI (Codex + Claude 赋能), Hyperloom 代码优化工具演示提升 token 速率 **38%**
- **AMD 预测**: AI 加速器 TAM **$1.4T (2030)**, 总芯片 TAM **$2T (2030)**

### 超节点架构影响分析

| 维度 | 分析 |
|:-----|:------|
| **NVIDIA NVL72 终于有了直接对手** | Helios 是首个真正意义上对标 NVL72 的机架级系统。AMD 此前只有 GPU 卡级产品，Helios 补齐了 scale-up 系统层竞争力 |

## 📌 2. ASRock Rack 4U16X-GNR2 — HGX B300 8-GPU 液冷服务器

| 维度 | 数据 |
|:-----|:------|
| **来源** | ServeTheHome, Patrick Kennedy, **2026-07-27** |
| **链接** | https://www.servethehome.com/asrock-rack-4u16x-gnr2-nvidia-hgx-b300-8-gpu-server/ |
| **可信度** | ⭐⭐⭐⭐⭐ STH 一手评测（远程访问实测） |

### 架构概览

| 组件 | 规格 |
|:-----|:------|
| **CPU** | 2× Intel Xeon 6 **Granite Rapids** (6700P/6500P) |
| **GPU** | **8× NVIDIA Blackwell Ultra (B300)** — HGX B300 完整方案 |
| **GPU 互联** | 板载 NVLink，8-GPU 全互联拓扑 |
| **内存** | **32× DDR5 DIMM** (16/CPU, Xeon 6700P 系列支持更多 DIMM) |
| **存储** | 12× 2.5" U.2 NVMe 前端（2 CPU直连 + 10 PCIe switch） |
| **网络** | **8× OSFP 800 Gbps** 前端 = **6.4 Tbps** 面板带宽 |
| **后置扩展** | 2× PCIe Gen5 x16 (NVIDIA ConnectX-7 / BlueField-3 DPU) |
| **电源** | **10× 3 kW 80Plus Titanium** PSU (冗余) |
| **散热** | **液冷 (DLC)**, 可选 **ZutaCore 两相冷却** |
| **形态** | **4U** 机箱，含可热插拔风扇模组，CPU 冷板 + 漏液检测带 |

### 液冷工程细节

| 特性 | 说明 |
|:-----|:------|
| **CPU 冷板** | 直接替换传统散热器，冷板上方可以走线，无需担心阻挡气流 |
| **漏液检测** | 冷板水管接头处带漏液检测带，一旦泄漏即触发系统关机 |
| **DLC vs ZutaCore** | DLC (传统液冷) 为主打方案；ZutaCore 提供**两相冷却**（不引入水进入循环），适合对水冷有顾虑的客户 |
| **风扇设计** | 侧面 4× 大风扇（热插拔）+ 底部 3× 小风扇，为 GPU/SSD提供辅助气流 |

### 主板设计 — 定制化 GPU 专用主板

- 主板型号 **GNR2D32G-2L+**，无标准 PCIe 插槽，全部通过 **MCIO 连接器** 分发 PCIe 通道
- MCIO 线缆通过机箱中部风扇隔板下方走线
- 前面板含 ASRock 管理口 + 2× 1GbE (Intel i350)，可通过内部线缆灵活切换前后位置
- 前面板还提供 VGA 输出（运维便利）

### 超节点部署意义

| 维度 | 分析 |
|:-----|:------|
| **HGX B300 已到批量出货阶段** | 这不是样机或预告，STH 通过远程访问操作系统做了完整评测，表明 HGX B300 方案已进入 OEM 批量供货阶段 |
| **液冷标配化** | DLC 为主、ZutaCore 两相为选，说明 NVIDIA HGX 参考设计的液冷方案已完全标准化，不再有"需额外定制"的门槛 |
| **网络密度突破** | 8× 800G OSFP = **6.4 Tbps 仅前面板**，这在 4U 空间内是非常高的网络密度。配合 ConnectX-7 或 BlueField-3，可实现单节点与超节点内其他节点的超高带宽互联 |
| **供电架构演进** | 10× 3 kW Titanium PSU = 30 kW 总供电容量，12V 传统总线。下一代超节点（如 Vera Rubin NVL72）的供电架构会向 48V/400V/800V HVDC 演进，当前 30kW 的供电密度已是 12V 极限 |
