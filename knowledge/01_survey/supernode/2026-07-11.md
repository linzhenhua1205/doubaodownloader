## 🔴 1️⃣ NVIDIA Rubin Ultra 重大架构变动：四芯片设计取消改为双芯片，Kyber 机架延至 2028

- **来源**: Tom's Hardware (Anton Shilov, 2026-06-30; Luke James, 2026-07-06) 引述 SemiAnalysis 分析师报告
- **分类**: 🏭 超节点方案 / GPU 路线图 / 机架架构
- **原文标题**:
  - 「Nvidia reportedly cancels quad-die Rubin Ultra GPU in favor of dual-GPU design, report claims」(Shilov, 6/30)
  - 「Nvidia's Kyber rack for Rubin Ultra reportedly delayed to 2028, stopgap solution also axed due to customer pushback」(James, 7/6, Updated)

### 事件一：Rubin Ultra 从四芯片（quad-die）改为双芯片（dual-die）设计

Nvidia 据报告已放弃 Rubin Ultra **四芯片（4-die）MCM 设计**方案，改为**双芯片（2-die）设计**。

| 维度 | 原方案（已取消） | 新方案 |
|:-----|:----------------|:--------|
| **芯片数/GPU** | **4 die MCM** | **2 die** |
| **HBM** | 4× HBM4E stack = **1TB/GPU** | 2× HBM4E stack = **~512GB/GPU** |
| **制程** | TSMC 3nm-class | TSMC 3nm-class |
| **功耗/GPU** | 预估 >2,000W | 预估 ~1,500W |
| **机架方案** | Kyber NVL144 (600kW/rack) | 待定（可能下修机架功率） |
| **预计首发** | 原定 2027 | 可能推迟至 **2027-2028** |

**取消原因**：SemiAnalysis 分析师报告称，quad-die 设计因 **"manufacturing execution concerns"（制造执行风险）**而被取消。4-die MCM 的良率、封装复杂度、热管理在 TSMC 3nm 节点上未达到 Nvidia 内部的商业化标准。取而代之的双芯片设计在保持足够计算密度的前提下，显著降低了制造和封装风险。

### 事件二：Kyber NVL144 机架延期至 2028，中间方案也被客户否决

Rubin Ultra 的专用机架方案 **Kyber NVL144** 已从 2027 年推迟至 **2028 年**，延迟超过 12 个月。

| 维度 | 详情 |
|:-----|:------|
| **原定出货** | 2027 年 H1/H2 |
| **最新预期** | **2028 年**（延迟>12个月） |
| **延迟原因** | **PCB midplane（中板）问题**— Kyber 机架作为 600kW 级方案，其中板 PCB 的层数、材料、信号完整性、功率承载能力均面临前所未有的工程挑战 |
| **中间方案尝试** | Nvidia 曾尝试设计一个"缩水版"中间方案来填补 2027 窗口，但**遭到主要客户（hyperscaler）否决**— 客户不愿在过渡方案上投入大量资本支出 |
| **原定规格** | 144 GPU/rack, ~600kW, 液冷, 1TB HBM4E/GPU |
| **信息来源** | SemiAnalysis 分析师报告，Tom's Hardware 7/6 更新报道 |

### Rubin Ultra / Kyber 延迟后的 Nvidia 超节点路线图

```
时间线:
2026 H2 --- Vera Rubin NVL72 (288GB HBM4/GPU, ~140kW/rack) --- Q3 量产
               v
2027 ----- Vera Rubin NVL72 放量交付 + GB300 继续
               v       +-------------------------------------+
2027 H2 ---- Rubin Ultra (Dual-die, ~512GB HBM4E) ----- + 原 Kyber 路线断裂  |
               v       +-------------------------------------+
2028 ----- Kyber NVL144 (600kW rack, 双芯片 Rubin Ultra)
               v
2028+ ---- Feynman (下一代架构)
```

### 产业影响分析

| 影响维度 | 分析 |
|:---------|:------|
| **对 hyperscaler 采购计划** | Kyber 延迟到 2028 意味着 2027 年超节点密度天花板停留在 **Vera Rubin NVL72 (~140kW/rack)**，600kW 级机架推迟一年以上。hyperscaler 可能需要调整 2027-2028 数据中心规划（功率密度假设、液冷方案、供电架构） |
| **对 AMD/Intel 窗口机会** | Kyber 延迟给了 AMD MI500 系列和 Intel Falcon Shores 一个宝贵的市场窗口——如果它们能在 2027-2028 年拿出竞品级机架方案 |
| **对液冷/供电产业链** | 600kW 机架延迟意味着产业链有更多时间成熟：800V HVDC 供电、兆瓦级液冷 CDU、大容量锂电储能的部署节奏与 Kyber 原计划之间的差距得以缩小 |
| **对 Nvidia 收入预期** | Nvidia 此前目标 $500B GPU 销售额 (late 2026)，其中 Rubin Ultra + Kyber 是关键部分。取消/延迟可能影响 2027 年收入结构，但 Vera Rubin NVL72 量产（2026 H2）可部分缓冲 |
| **Quad-die 取消与 CPX 删除的一致性信号** | 与 3 月 GTC 2026 时 Rubin CPX 加速器从路线图删除类似，Nvidia 正持续**收缩多芯片复杂方案**，优先保证可制造性和良率 |

## 🟢 2️⃣ ASUS 热实验室巡礼：GB200/GB300/Vera Rubin NVL72 机架级液冷验证

- **来源**: [ServeTheHome](https://www.servethehome.com/asus-thermal-lab-tour-2026-testing-ai-servers/) (Patrick Kennedy, 2026-07-10, 赞助参观)
- **分类**: 🔧 液冷 / 机架级验证 / 热管理
- **发表日期**: 2026-07-10

### 概述

Patrick Kennedy（ServeTheHome 创始人）于 2026 年 Q2 访问了 ASUS 位于台湾的服务器热测试实验室（QTR Lab & AI R&D Lab），该实验室专注于**从单服务器验证到完整 NVL72 机架的系统级热测试**。这是业界罕见的全尺寸机架级 AI 热测试设施公开细节。

### 关键设施

| 设施 | 规格 | 用途 |
|:-----|:------|:------|
| **Walk-in 环境实验室（步入式环境舱）** | 25°C ~ 45°C 温控，可容纳**完整机架** | 标准 DC 环境验证，液冷机架级热互作用测试（冷却液分配/歧管/压降） |
| **极端环境实验室** | **-40°C ~ +85°C**，可容纳完整机架 | 运输/存储条件模拟（满载 NVL72 机架的空运/海运场景），加速老化测试（85°C 持续运行暴露长期疲弱点） |
| **AI R&D Lab** | **1.1MW 电力容量**，1.3MW 冷水机组 | 机架级液冷集成验证，模拟生产 DC 部署环境 |

### NVL72 液冷测试细节

| 维度 | 详情 |
|:-----|:------|
| **冷却液温度** | 当前运行 **20°C**，正在测试更高温度（提升冷却液温度 → 降低冷水机能耗 ~40%） |
| **测试对象** | GB200 NVL72、GB300 NVL72、**Vera Rubin NVL72**（均在验证中） |
| **机架级测试重要性** | 液冷系统中冷却液温度/流速/压降在 72-GPU 级联下与单计算托盘**完全不同**——单节点验证无法捕捉机架级特性 |
| **冷板 + 歧管** | 全部 NVL72 机架集成冷板、歧管、漏液检测系统，验证安装流程和维护工作流 |
| **功率分配** | 架空母线供电，地板下液冷管网。1.1MW 容量覆盖多机架位置 |
| **管理平台** | ASUS Control Center (ACC) + AIDC（ASUS Infrastructure Deployment Center），提供从单节点到整个集群的遥测视图 |

### 测试方法学特点

| 特点 | 说明 |
|:-----|:------|
| **完整的机架级验证** | 传统服务器仅测试单节点（4U），ASUS 设计完整机架入舱测试。部分液冷 vs 全液冷 vs 全风冷的机架行为差异巨大 |
| **加速老化测试** | 5 年正常负载寿命通过 85°C 极端温度压缩测试周期（AI 服务器代际更迭远快于传统服务器，但组件可靠性验证仍需"时间压缩"） |
| **示波器级调试** | 同时看到 Tektronix 示波器正在对 GB300 NVL72 计算托盘做信号完整性调试 |
| **环境声噪** | 舱体运行时噪音极高，需要远程自动化监测（24/7 运行数天至数周的测试周期） |
| **带载运输验证** | 全组装 NVL72 机架的温控运输（海运/空运中的温度梯度管理）是新出现的验证需求 |

### 对超节点产业的启示

| 维度 | 分析 |
|:-----|:------|
| **液冷验证从组件级跃迁到系统级** | ASUS 的做法代表了 ODM/OEM **液冷验证范式的转变**：不再是测试单个冷板或单个节点，而是验证整机架的流体力学 + 热力学 + 电气 + 管理全面集成。这需要设施投资（1.1MW 电力 + 1.3MW 冷水机）和测试方法学（多日全自动运行）的双重升级 |
| **20°C 冷却液 → 更高温趋势** | ASUS 正在测试**更高冷却液温度**。每提高 1°C 冷却液温度，冷水机能耗降低约 1-2%。这对于万卡集群的 PUE 优化意义重大——但需平衡组件可靠性和性能余量 |
| **GB200 → GB300 → Vera Rubin NVL72 同步验证** | ASUS 实验室同时测试三代 NVL72 方案，表明**机架级液冷架构在三代之间的兼容性和继承性**——液冷基础设施（CDU/歧管/管网）的设计需要跨越两代以上产品 |
| **45°C 环境温度测试** | 45°C 覆盖全球最热 DC 场景（如中东/东南亚）。这对于全球选址受限（参考 7/7 选址困境）的超节点方案尤为重要——如果能在 45°C 环境下稳定运行，选址窗口将显著扩大 |

### 规模数据

| 指标 | 数据 |
|:-----|:-----|
| ASUS 热实验室电力容量 | **1.1 MW** |
| 冷水机组容量 | **1.3 MW**（留有裕量） |
| 环境温度测试范围 | **-40°C ~ +85°C**（极端舱） |
| DC 标准测试范围 | **25°C ~ 45°C**（步入式舱） |
| 当前冷却液运行温度 | **20°C**（正在测试更高温度） |
| 预期能效提升（温冷却液 vs 传统） | **~40% 冷水机能耗降低** |
| 液冷测试覆盖代际 | **GB200 NVL72 / GB300 NVL72 / Vera Rubin NVL72** |

## 🟡 3️⃣ Supermicro GB300 Super AI Station（DGX Station）详细拆解

- **来源**: [ServeTheHome](https://www.servethehome.com/taking-an-up-close-look-at-the-supermicro-gb300-super-ai-station/) (Ryan Smith, 2026-06-27)
- **分类**: 🖥️ 桌面超节点 / DGX Station / GB300 工作站
- **发表日期**: 2026-06-27（Computex 2026 展示）

### 概述

NVIDIA 在 Computex 2026 上正式发布了 DGX Station 桌面超级计算机方案。Supermicro 在展会现场展示了其版本——**Super AI Station**，配备 plexiglass 侧面板让参观者看清内部结构。这是**目前唯一能将 GB300 级性能放在桌面上的方案**，但起步价为 **~$125,000**（Newegg 含 affiliate link）。

### 架构详情

| 组件 | 规格 |
|:-----|:------|
| **核心芯片** | Grace Blackwell **GB300**（72核 Grace CPU + Blackwell Ultra GPU 合封） |
| **系统 TDP** | **1,600W** → **液冷**（全覆盖冷板 + 散热排循环） |
| **GPU 内存** | **252GB** HBM3e（**7/8 stack 启用**，GB300 在 DGX Station 中为降级片，1 stack 关断） |
| **GPU 带宽** | **7.1 TB/s** |
| **CPU 内存** | **496GB** LPDDR5X（4× SOCAMM 模块） |
| **网络** | **2× 400GbE** QSFP（ConnectX-8 双端口 400GbE） |
| **存储** | 4× PCIe Gen5 x4 M.2 2280（示范系统装 4× 480GB Micron 7450 Gen4） |
| **扩展** | 3× PCIe x16（x8 electrical）— 包含 1× RTX PRO 显卡槽位 |
| **显卡输出** | 需另配 RTX PRO 显卡（GB300 是纯算芯片，无图形输出能力） |
| **尺寸** | **5U**（可 rackmount，需 rackmount 套件） |

### 设计特点

- **风道设计**：前置散热排 → 3× 风扇 → 流过主板 → 后出风。**前后风道设计**使系统既可作为桌面工作站，也可通过 5U rackmount 套件入柜
- **降级芯片策略**：与 DGX Spark（GB10）类似，DGX Station 使用**降级片**（7/8 HBM stack 启用），这降低了芯片筛选成本，同时也为 OEM 提供差异化的 SKU 结构
- **ConnectX-8 双 400GbE**：两个 400GbE 端口使多台 DGX Station 可以组建小规模集群，或作为大规模集群的开发/调试前端
- **1600W 功率需求**：需要**专用电力回路**，不能用普通墙插
- **无 USB-C**：仅有 2× 前置 5Gbps USB 3 + 4× 后置 10Gbps USB 3，无 USB-C 接口

### 战略意义

| 维度 | 分析 |
|:-----|:------|
| **从机架到桌面的超节点能力延伸** | 超节点/集群通常被视为数据中心级产品，但 DGX Station 将超大算力**压缩到桌面形态**，允许开发者在本地调试/测试大规模模型，再部署到集群 |
| **1600W 桌面的信号意义** | 4年前最强的桌面工作站 ~500W，如今桌面超节点 **1600W** — 功率密度增长 >3x，液冷从"数据中心可选"变为"桌面刚需" |
| **$125K 定价 vs $5K (DGX Spark)** | 25x 价格的背后是 72核 Grace CPU + Blackwell Ultra GPU + 252GB HBM3e + 496GB LPDDR5X + 2×400GbE 的组合。对于需要本地开发千亿参数模型的开发者/初创公司来说，$125K 比购买整机架 GPU 更为经济 |
| **Windows 版本下半年** | Computex 上宣布下半年推出 DGX Station for Windows，意味着 NVIDIA 正将 AI 超节点能力推向更广泛的 Windows 开发者生态 |
