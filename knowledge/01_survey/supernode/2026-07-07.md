## 🔴 1️⃣ QTS/Blackstone 放弃弗吉尼亚 Digital Gateway——全球最大数据中心园区项目彻底终止

- **来源**: [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence) (Etiido Uko, 2026-07-03)
- **分类**: 🏭 超节点选址 / 供电散热 / 部署瓶颈
- **原文标题**: 「Blackstone-owned QTS abandons planned world's largest data center campus after years of lawsuits」

### 概述

Blackstone（全球最大另类资产管理公司）旗下 QTS 已撤回弗吉尼亚州 **Digital Gateway** 项目的最终上诉，全球最大规划数据中心园区正式终止。该项目的死亡标志着 **AI 超节点选址面临的社区阻力已升级为系统性风险**。

### 关键数据

| 指标 | 数据 |
|:-----|:-----|
| **规划建筑面积** | **2,200 万平方英尺**（约 204 万平方米） |
| **占地** | **2,100 英亩**（约 850 公顷） |
| **建筑数量** | **37 栋**数据中心建筑 |
| **业主** | Blackstone（2021 年以 $100 亿收购 QTS） |
| **终止原因** | 最终上诉被驳回（\"newspaper-notice technicality\"） |
| **诉讼时长** | 多年诉讼，社区连续反对 |
| **报道日期** | 2026-07-03 |

### 弗吉尼亚州民意的剧烈转变

| 时间 | 支持率 | 来源 |
|:----|:------|:-----|

| **2026年4月** | **35%** 支持 | 同上 |
| **降幅** | **-34pp**（3 年内断崖式下降） | — |

### 对超节点/AI 集群部署的影响

| 影响维度 | 分析 |
|:---------|:------|
| **选址难度急剧上升** | 即使 Blackstone（全球最大资管）+ QTS（专业运营商）也无法在弗吉尼亚（传统数据中心圣地）推动项目 → 超节点选址需要更长周期、更高合规成本 |
| **供电基础设施瓶颈恶化** | 不是电力不够，而是**社区不允许建** → 推动向偏远/农村/海外（如 Batam/中东）迁移 |
| **推动液冷/低水耗方案迫切性上升** | 环境争议中水耗是核心冲突点 → NVIDIA DSX 零水耗方案差异化竞争力大增 |
| **加速海外选址** | Firmus Batam（此前 7/3 报道的 360MW/170K GPU）+ 中东/东南亚选址节奏可能进一步加速 |
| **对现有集群的价值提升** | 新建项目难度加大 → 现有已投产 AI 集群的**存量价值重估**，升级替换比新建立地更有吸引力 |

### 战略解读

> **Digital Gateway 的死亡不是终点，而是 AI 基础设施部署新阶段的开始。** 当弗吉尼亚（全球数据中心密度最高的地区之一）对新建项目关上大门，超节点部署将进入：
> 1. **存量优化期**：已投产集群升级（GB200 → GB300 → Vera Rubin in-place 替换）
> 2. **海外加速期**：印尼/中东/东南亚成为新建首选
> 3. **技术缓冲期**：100% 液冷 + 零水耗 + 低噪音设计从"可选项"变为"准入门槛"
> 4. **小集群替代大集群**：更多中等规模（10-40K GPU）分散部署替代单一巨型集群

## 🟡 2️⃣ 威斯康星居民对 Microsoft AI 数据中心提起集体诉讼——噪音与光污染成为新冲突焦点

- **来源**: [Tom's Hardware](https://www.tomshardware.com/tech-industry/artificial-intelligence) (Bruno Ferreira, 2026-07-06)
- **分类**: 🔧 超节点部署 / 社会影响 / 法规风险
- **原文标题**: 「Wisconsin residents file class-action lawsuit against Microsoft's 'world's most powerful AI data center' due to data center noise」

### 概述

威斯康星州 Caledonia 居民对 Microsoft 的 **$73 亿 AI 数据中心** 提起集体诉讼，指控该设施产生**持续噪音和极端光污染**。这标志着 AI 集群部署的社会冲突已从选址争议**扩展到运营阶段的居民影响**。

### 关键数据

| 指标 | 数据 |
|:-----|:-----|
| **项目投资** | **$73 亿** |
| **位置** | 威斯康星州 Caledonia（Mount Pleasant 园区） |
| **诉讼类型** | **集体诉讼**（class-action） |
| **起诉方** | 当地居民 |
| **指控内容** | (1) 数据中心持续噪音，(2) 极端光污染，(3) 施工阶段同样严重 |
| **报道日期** | 2026-07-06 |

### 对超节点设计的影响

| 维度 | 含义 |
|:-----|:------|
| **噪音控制** | AI 集群的冷却系统（特别是风冷/风扇密集部署）的噪音水平已成为**运营合规风险** → 推动液冷（更低噪音）采用 |
| **光污染** | 大型数据中心的夜间照明（安全/运维需要）引发社区反弹 → 推动**遮光设计规范** |
| **法律风险升级** | 从选址阶段的"禁令/暂停"到运营阶段的"集体诉讼" → 超节点项目全生命周期的社会风险敞口大幅增加 |
| **对液冷的间接推动** | 液冷系统（泵+CDU）比风冷（大量高速风扇）噪音显著降低 → 成为社区友好的差异化竞争力 |

### 与条目 1 的关联

> 两条新闻共同勾勒了 **AI 超节点部署的系统性社会阻力全景**：
> - **选址阶段**：禁令、暂停令、社区公投、司法上诉（Digital Gateway → 全美 69 辖区禁令）
> - **建设阶段**：诉讼、噪音投诉、水耗争议（Microsoft Wisconsin → 29M 加仑水耗事件）
> - **运营阶段**：集体诉讼、持续社区冲突（Wisconsin 噪音/光污染诉讼）
> - **政治层面**：地方选举更迭、州立法限制、国际附加税（意大利 200% 农业区税）
