## 🔴 1️⃣ Jensen Huang 确认 Vera Rubin "giant amounts" 生产中，但 Kyber NVL144 延迟至 2028 年未正面回应

| 维度 | 数据 |
|:-----|:------|
| **来源** | Tom's Hardware (Anton Shilov, **July 15, 2026**) — 基于 Bloomberg 日本活动报道 |
| **链接** | [Tom's Hardware 原文](https://www.tomshardware.com/tech-industry/artificial-intelligence/nvidias-huang-vows-to-deliver-giant-amounts-of-vera-rubin-company-says-that-our-roadmap-is-intact) |
| **核心表态** | Jensen Huang：**"Vera Rubin is already in production. Giant amounts of production incoming."** — "传闻不属实" |
| **量产状态** | 1 月确认 Vera Rubin 平台进入生产，2 月采样。7/15 再次确认量产爬坡中 |
| **未回应的问题** | Huang **未正面回答** SemiAnalysis 关于 **Kyber NVL144 延迟至 2028 年** 的报告（PCB 中层面板可制造性问题导致铜互连 NVL144 延迟 >1 年） |
| **NVL72x2 取消** | 双机柜背靠背的 **NVL72x2 被客户拒绝**（运维/冷却/布线/机房布局不可接受），已取消 |
| **NVL576 CPO 延迟** | 8 机柜 CPO（共封装光学）NVL576 方案因 **ongoing CPO challenges** 延期或限量出货 |
| **结论** | 到 2028 年，NVIDIA 超节点 **仅有 NVL72 可规模化部署**（72 路 scale-up domain） |
| **竞争对比** | AMD Mega Pod（256 路 MI500）、Google TPU 8i（1,024-1,152 路）、TPU 8t（9,600 路）在 scale-up 规模上均可能超越 NVL72 |

### 超节点架构影响分析

| 维度 | 分析 |
|:-----|:------|
| **NVIDIA 超节点路线图受损严重** | Vera Rubin NVL72 本身量产不受影响，但 **更大 scale-up domain 的路径全数受挫**：Kyber NVL144 → 延迟至 2028，NVL72x2 → 取消，NVL576 CPO → 延迟/限量。未来 2 年 NVIDIA 顶级超节点仅 NVL72 |
| **PCB 中面板成瓶颈** | Kyber 延迟根因是 **PCB midplane 制造可量产性不足**，非芯片缺陷。反映大尺寸高速信号 PCB 正成为超节点扩展的物理瓶颈——铜互连在高带宽下的信号完整性/层数/制造良率三重约束 |
| **CPO 仍不成熟** | NVL576 依赖 8 机柜 CPO NVSwitch 互联，但 CPO 技术尚未准备好高良率量产。这对 **UALink 阵营的 CPO 路线也是警示信号** |
| **竞争窗口打开** | AMD Mega Pod（256 路 MI500）和 Google TPU 8i（1,024+ 路）在 scale-up domain 规模上获得 **2~12 倍优势**，2027~2028 年可能成为更具吸引力的超节点方案 |
| **Vera Rubin NVL72 的「巨量」生产** | 侧面说明 NVIDIA 正 **全力押注 NVL72 为标准化产品**，通过规模化降低成本、加速部署，以量代质弥补 scale-up 规模不足 |

## 🟡 2️⃣ Google 第 9 代 TPU "Humufish" 选择 Intel EMIB-T 封装：超节点芯片供应链格局变动

| 维度 | 数据 |
|:-----|:------|
| **来源** | Tom's Hardware (Anton Shilov, **July 15, 2026**) — Premium 报道，引用 SemiAnalysis |
| **链接** | [Tom's Hardware 原文](https://www.tomshardware.com/tech-industry/semiconductors/intels-emib-packaging-gains-traction-as-chip-designers-look-to-skirt-tsmcs-cowos-constraints-googles-reported-decision-for-9th-gen-tpus-highlights-intels-attractive-alternative) |
| **决策** | Google 第九代 TPU（代号 **Humufish**）选用 **Intel EMIB-T** 替代 TSMC CoWoS-L |
| **历史** | Google 从第 3 代 TPU 开始一直使用 TSMC CoWoS（S→L 演进），至今持续 |
| **技术背景** | EMIB-T 在桥接中集成 **TSV 垂直供电 + MIM 电容 + 专用地平面**，改善电源完整性；CoWoS-L 用 RDL 中介层 + LSI 桥接，全局布线密度更高 |
| **动机推测** | 技术端：EMIB-T 的 **电源完整性优势** 可能对超大功率 AI 加速器更有利 + 机械刚度（无大型 RDL 中介层减少热应力）。商业端：**CoWoS 产能受限**（NVIDIA 等提前数年预订）+ 供应链多元化 + 培育 Intel Foundry 关系 |
| **Intel EMIB-T 产能** | 此前报道 Google 2028 年预订 Intel 超 **300 万颗 TPU 封装** 产能 |

### 超节点架构影响分析

| 维度 | 分析 |
|:-----|:------|
| **封装多元化加速** | CoWoS 长期独霸 AI 芯片封装，但产能瓶颈 + 单一供应商依赖促使 **Google/Meta/微软等正向 Intel EMIB-T/其他方案分散**。这影响超节点芯片的芯片间带宽/供电/热设计 |
| **对 NVIDIA 的间接冲击** | CoWoS 主要客户 NVIDIA 的产能优先级可能因其他客户的分散而改善，但反过来 **Google TPU + Intel EMIB 可能形成更具竞争力的超节点替代方案** |
| **对 UALink/开放生态** 的推动 | TPU 长期使用自研互联，封装技术变化不影响其互联架构，但 **更多封装选择 = 更多芯片设计弹性 = 可能加速定制 AI 芯片竞争** |
| **超节点供电/散热设计联动** | EMIB-T 的垂直供电能力（TSV）对大功率 AI 芯片是优势，意味着未来 **超节点芯片级供电架构也可能演变** |

## 🟢 3️⃣ PCIe Gen7 开发已启动 + Nvidia Storage Next 成为焦点

| 维度 | 数据 |
|:-----|:------|
| **来源** | Tom's Hardware (Anton Shilov, **July 15, 2026**) — Silicon Motion 企业事业部 GM Alex Chou 专访 |
| **链接** | [Tom's Hardware 原文](https://www.tomshardware.com/pc-components/ssds/pcie-gen7-development-has-already-started-says-silicon-motions-alex-chou-nvidias-storage-next-initiative-is-becoming-a-focal-point) |
| **PCIe Gen7 状态** | 架构已定义，**内部样品 2H 2027**，目标同年量产 |
| **PCIe Gen6 状态** | 控制器设计基本完成，FPGA 验证中，**预计 2H 2026 回片** |
| **Storage Next** | NVIDIA 推动的 GPU 近邻存储架构，目标 **50M IOPS**（原目标 100M 调整为更现实水平） |
| **QoS 差异化** | SMI 开发专利流量整形引擎（PerformaShape），关注多租户环境延迟一致性 |
| **市场影响** | AI 存储需求推动，SMI 2026 Q1 收入 $3.42 亿（+105% YoY），企业 SSD 控制器正处初期爬坡 |

### 超节点架构影响分析

| 维度 | 分析 |
|:-----|:------|
| **PCIe Gen7 = 128 GT/s** | 比 Gen6 (64 GT/s) 翻倍，比 Gen5 (32 GT/s) 再翻倍。对超节点意味着 **更大 scale-up 互联带宽潜力**，但信号完整性和 PCB 设计复杂度（Gen6 已验证）将指数级增加 |
| **Storage Next 与超节点的联动** | GPU 近邻存储 = 超节点内 **KV-cache 卸载/Checkpoint 存储/模型权重加载** 的架构革新。50M IOPS 目标直接服务于 **万卡集群的存储 I/O 瓶颈** |
| **时间线对齐** | PCIe Gen7（2027~2028 量产）与 **Kyber NVL144 推迟到 2028** 时间窗口重合，未来超节点可能直接用 PCIe Gen7 替代铜互连方案 |
| **LDPC 纠错复杂度** | 16KB LDPC 引擎已占大量芯片面积，随 NAND 层数增加 → 控制器成本/功耗上升 → 超节点 TCO 中存储占比提升 |
