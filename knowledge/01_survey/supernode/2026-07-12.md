## 🔴 1️⃣ AIC F2032-01-G6 JBOF：为 Vera Rubin 超节点定义 KV 缓存存储层

- **来源**: [ServeTheHome](https://www.servethehome.com/aic-gets-flashy-with-32-ssd-bay-jbof-server-for-key-value-caching/) (Ryan Smith, 2026-07-11, Computex 2026 后续报道)
- **分类**: 🏭 超节点方案 / 存储架构 / Vera Rubin 生态
- **原文标题**: 「AIC Gets Flashy with 32 SSD Bay JBOF Server for Key Value Caching」

### 概述

AIC 在 Computex 2026 展示了 **F2032-01-G6** — 一款 2U 32-bay PCIe Gen6 JBOF（Just a Bunch Of Flash）存储服务器，专门设计为 **NVIDIA Context Memory Storage (CMX) 平台**的 KV 缓存后端，直接服务于 **Vera Rubin** 超节点机架。这是业界首款明确为 Rubin 超节点定义 KV 缓存存储层的专用硬件。

### 架构详情

```text
                      +----------------------------------------------+
                      |          AIC F2032-01-G6 (2U)              |
                      |                                              |
  GPU 集群 --800GbE--->  BlueField-4 DPU  --PCIe Gen6--->  Broadcom   |
  (Rubin NVL72)        (Grace+ConnectX-9)      |       PEX90144     |
                                              |       144-lane      |
  ---> 另一路冗余        BF4 DPU (HA 备用) ----->  PCIe Gen6 Switch   |
  ---> 故障切换                                 v        v  v  v      |
                                              32× E3.S/L NVMe SSD   |
                                              (PCIe Gen6 x2 each)   |
                      +----------------------------------------------+
```

| 组件 | 规格 |
|:-----|:------|
| **外形** | 2U JBOF 存储服务器 |
| **SSD 数量** | **32 个** E3 规格（E3.S 或 E3.L）热插拔槽位 |
| **最大容量** | **8 PB**（32 × 256TB QLC E3.L）|
| **PCIe 交换芯片** | Broadcom **PEX90144** — **144-lane PCIe Gen6** |
| **SSD 连接** | PCIe Gen6 x2/SSD（32 × x2 = 64 lanes） |
| **控制节点** | **双节点**冗余设计（每节点可装最多 2 DPU） |
| **DPU** | NVIDIA **BlueField-4**（Grace ARM CPU + ConnectX-9，**800GbE/IB**，PCIe Gen6） |
| **可用容量 (TLC)** | ~4 PB（32 × 128TB TLC E3.L） |
| **兼容标准** | NVIDIA **CMX（Context Memory Storage）** 平台 |
| **前代对比** | 前代 F2026-01-G5（26-bay, PCIe Gen5, BF3） |

### CMX 在 Vera Rubin 超节点中的角色

| 维度 | 说明 |
|:-----|:------|
| **CMX 是什么** | NVIDIA 的**上下文内存存储（Context Memory Storage）**平台，用于在大规模推理集群中管理 KV 缓存持久化。推理过程中，大模型的 KV cache 无法完全塞进 GPU HBM（288GB/GPU in Rubin NVL72），需要高速近端存储做"冷 KV cache"卸载 | 
| **为什么 JBOF 是关键** | 推理集群的性能瓶颈正从计算转向**KV 缓存吞吐量**。CMX 要求近 GPU 的高速 NVMe 存储层来存放 KV cache，JBOF 正是这个"近端缓存层" |
| **为何用 PCIe Gen6** | KV cache 的存取频率极高，需要 PCIe Gen6（~28GB/s per lane）足够带宽来匹配 800GbE 互联和 GPU 侧的数据吞吐需求 |
| **为什么采用 BF4 DPU** | BlueField-4 提供存储控制器功能 + 800GbE 网络 + 安全卸载，CGrace CPU + ConnectX-9 组合充当智能存储网关 |
| **对超节点拓扑影响** | 未来的 Vera Rubin NVL72 集群不再是纯 GPU 节点，而是 `GPU 计算域 ↔ CMX KV 缓存层 ↔ 远端对象存储` 三层架构 |

### 规模数据

| 指标 | 数据 | 对比 |
|:-----|:-----|:-----|
| 单机最大容量 | **8 PB**（2U） | 前代 F2026: 26 × PCIe Gen5 |
| 单连接带宽 | PCIe Gen6 x2 = **~56 GB/s/SSD** | 前代: PCIe Gen5 x2 = ~28 GB/s |
| 总聚合带宽 | 32 × 56 GB/s = **~1.8 TB/s**（读取峰值） | 两倍于前代 |
| DPU 网络带宽 | **800GbE/IB** per BF4 | 前代 BF3: 400GbE |
| HA 能力 | **双节点全冗余** | 单 DPU 故障不影响服务 |
| 参考定价 | 未公开（E3.L 256TB SSD 企业级定价极高） | — |

### 产业意义

> **AIC F2032-01-G6 标志着一个关键转变：Vera Rubin 超节点的存储架构从"通用共享存储"转向"专用 KV 缓存 JBOF"。** 随着推理集群规模和 KV cache 需求的爆炸式增长（万亿参数模型的 KV cache 可达 TB 级），专用 CMX 存储层成为超节点架构的必要组成部分。这也意味着超节点部署时，需额外为每 NVL72 域配套 CMX JBOF 存储容量。

| 影响维度 | 分析 |
|:---------|:------|
| **对超节点成本结构** | JBOF + BF4 DPU + 32 × PCIe Gen6 SSD 显著增加机架外的配套设备成本（在 GPU 之外） |
| **对 ODM 竞争** | AIC 先行定义 CMX JBOF 参考设计，Wiwynn/Ingrasys/QCT 等 ODM 预计跟进 |
| **对 NVMe SSD 需求** | PCIe Gen6 E3.S/L 企业 SSD 成为超节点刚需——三星 PM1763（7/8 报道）和 Micron 9650（Computex 展示）正好填补这一空白 |
| **对网络架构** | BF4 DPU 的 800GbE 网络意味着 Spectrum-X 800G 交换机需求进一步扩大 |
| **与前日 Kyber 延迟的联动** | 即使 Kyber（600kW 机架）推迟至 2028，Vera Rubin NVL72（2026 H2 量产）的 CMX 存储层已提前就绪——表明 NVIDIA 的 Rubin 生态部署节奏是**存储先行** |

## 🟢 2️⃣ Samsung PM1763 量产：首款 PCIe Gen6 企业级 SSD，针对 AI 服务器液冷优化

- **来源**: [ServeTheHome](https://www.servethehome.com/samsung-pm1763-pcie-gen6-enterprise-ssd-in-production/) (Cliff Robinson, 2026-07-08)
- **分类**: 🔧 硬件 / 存储 / PCIe Gen6 生态
- **原文标题**: 「Samsung PM1763 PCIe Gen6 Enterprise SSD in Production」

### 概述

Samsung 宣布 **PM1763** 进入量产——这是业界首款 **PCIe 6.0 企业级 SSD**，基于 Samsung 第 9 代 V-NAND 和自研 **4nm 控制器**，专门为 AI/HPC 服务器环境设计。它是 Vera Rubin 超节点时代 CMX 存储层和本地 Cache 的关键基础设施组件。

### 关键规格

| 维度 | 详情 |
|:-----|:------|
| **接口** | **PCIe Gen6 x4**（兼容 Gen5/Gen4/Gen3） |
| **外形** | E3.S / E3.L（与 AIC JBOF 槽位兼容） |
| **NAND** | Samsung **9th-gen V-NAND**（~1Tb die, ~280+ 层） |
| **控制器** | 自研 **4nm 制程**新控制器 |
| **容量** | **4TB / 8TB / 16TB** |
| **顺序读取** | **28,400 MB/s**（16TB 型号） |
| **顺序写入** | **21,900 MB/s**（16TB 型号） |
| **相比前代 PM1753** | **>2x 性能提升** |
| **AI 场景指标** | 40GB LLM 模型传输 ≈ **1.4 秒** |
| **散热优化** | ✅ **专为液冷优化**（可部署在无风扇液冷机架中） |
| **安全** | 后量子密码学 (PQC) + TEE Device Interface Security Protocol (TDISP) |
| **状态** | **量产中** （已向客户出货） |

### 对超节点架构的意义

| 维度 | 分析 |
|:-----|:------|
| **CMX JBOF 的配套存储** | 上条 AIC JBOF 需要 PCIe Gen6 NVMe SSD 来实现 56 GB/s/SSD 的性能目标，PM1763 正好补上——**存储生态与服务器生态同步成熟** |
| **液冷优化设计** | 三星明确标注 PM1763「针对液冷环境优化」— AI 超节点机架逐步从风扇散热转向全液冷，SSD 的液冷兼容性成为硬要求（风扇移除后，SSD 需单独液冷路或专用冷板） |
| **PCIe Gen6 时代提前到来** | PM1763 是**首款量产的 PCIe Gen6 企业 SSD**，与 Vera Rubin（支持 PCIe Gen6）、AMD EPYC Venice（PCIe Gen6）、Arm AGI（PCIe Gen6）几乎同时上市——**PCIe Gen6 生态在 2026 H2 集中爆发** |
| **KV Cache 性能提升** | 28.4 GB/s 读速度 × 32 盘 JBOF = **~900 GB/s 聚合读取**，足够匹配 BF4 DPU 的 800GbE（100 GB/s）网络带宽 |

### 发布时间线对比

| 代际 | SSD | 接口 | 峰值读取 | 量产时间 | 对应 GPU 世代 |
|:-----|:----|:----:|:--------:|:--------:|:-------------|
| Gen4 | PM1743 | PCIe 4.0 | 7,000 MB/s | 2021 | A100/H100 |
| Gen5 | PM1753 | PCIe 5.0 | 13,000 MB/s | 2023 | H100/B200 |
| **Gen6** | **PM1763** | **PCIe 6.0** | **28,400 MB/s** | **2026 Q3** | **Vera Rubin** |
| Gen7 (展望) | — | PCIe 7.0 | ~56,000 MB/s | ~2029 | Feynman 代 |

### 产业信号

> **Samsung PM1763 的商业化量产标志着超节点存储体系从 PCIe Gen5 → Gen6 的代际跨越。** 一方面 28 GB/s 的吞吐为 CMX KV 缓存提供了所需带宽，另一方面液冷优化设计表明 AI 超节点的全液冷环境（冷板覆盖 GPU/CPU/SSD/内存/交换机）已进入产业共识阶段。PCIe Gen6 生态（SSD + 交换芯片 + DPU + CPU + GPU）的同步成熟是 2026 H2 的关键观察变量。

## 🟡 3️⃣ Dell PowerEdge Gen 18 发布：EPYC Venice 液冷节点 + Rubin 加速卡预备

- **来源**: [ServeTheHome](https://www.servethehome.com/dell-showcases-upcoming-epyc-venice-poweredge-systems-adds-new-5-8pb-powerstore-elite/) (Ryan Smith, 2026-07-11 重新传播 / 原载 2026-05-22 DTW)

- **关联**: AMD EPYC Venice（TSMC N2, 256核）已开始量产加速（AMD 7 月初公告）

Dell 在 Dell Technologies World 2026（5月）上发布了第 18 代 PowerEdge 服务器系列，其中 **M9825** 是专为 AI 超节点场景设计的**高密度液冷旗舰**。配合 AMD EPYC Venice（TSMC N2, 最高 256 核）和 **Xeon Diamond Rapids**（2027），Dell 全面进入超节点级液冷部署时代。

| 机型 | 定位 | CPU | 散热 | 目标场景 | 出货时间 |
|:-----|:-----|:----|:----:|:---------|:--------:|

| **XE5845/XE7845** | 🟡 **AI 加速器节点** | EPYC Venice + **NVIDIA Rubin** | 风冷 | AI 训练/推理（Rubin 加速卡） | 2026 H2 |
| R6815/R8815 | 1U 企业整合 | EPYC Venice | 风冷 | 从双路整合为单路 | 2027 |
| **R9810** | 🔵 Intel 高端 | Xeon Diamond Rapids | 风冷 | Intel 生态 | **2027** |

### 与超节点整体的联动

| 联动维度 | 说明 |
|:---------|:------|
| **IR7000 的 480kW/rack 能力** | 虽然 Dell 未明确 IR7000 是否单机架 480kW（可能是多机架共享），但 480kW 的数字与 NVIDIA Kyber 的 600kW/rack 同属**兆瓦级机架**赛道——Dell 正在为超节点机架功率密度做基础设施储备 |
| **EPYC Venice 与 Rubin 配对** | XE5845/XE7845 明确标为"EPYC + NVIDIA Rubin 加速器"搭配，表明 Dell 在 Vera Rubin 超节点的 OEM 供应链中占据位置——**CPU 侧（EPYC Venice 做管理/网络/数据平面） + GPU 侧（Rubin 做计算）** 是典型的超节点控制节点架构 |
| **液冷技术验证** | Dell 从 2025 年开始推广 IR7000 液冷机架体系，M9825 是继 PowerEdge XE9640 之后的第二代液冷 AI 节点，液冷工程经验积累为 2027 年更大功率方案做准备 |

### 产业信号

> **Dell 第 18 代 PowerEdge + EPYC Venice 标志着超节点 CPU 基座的迭代：AMD EPYC Venice 是首款 N2 制程服务器 CPU（256 核、PCIe Gen6、12ch DDR5-8800），为 2026 H2 的 Vera Rubin NVL72 部署提供了控制/管理/存储节点的基础算力平台。**
