## 📌 1. ASRock Rack 4U16X-GNR2 — HGX B300 8-GPU 评测全文细节（承接 07-28/07-29 简介）

- **来源**: [ServeTheHome — ASRock Rack 4U16X-GNR2 NVIDIA HGX B300 8-GPU Server Review](https://www.servethehome.com/asrock-rack-4u16x-gnr2-nvidia-hgx-b300-8-gpu-server-intel-zutacore-review/)（Patrick Kennedy, 2026-07-27）
- **可信度**: ⭐⭐⭐⭐⭐ STH 完整评测（台北实拍 + 远程实测，厂商赞助已披露）
- **衔接**: 07-28/07-29 仅收录简介，本次提取正文完整细节

### 平台构成

| 维度 | 数据 |
|:-----|:-----|
| **机箱** | 4U 紧凑形态（对比空冷同规格显著增密） |
| **CPU** | 2× Intel Xeon 6 "Granite Rapids"（GNR2） |
| **GPU** | 8× NVIDIA Blackwell Ultra (HGX B300) |
| **互连** | 板载 NVLink interconnect（8-GPU 成熟拓扑，广泛适配训练/推理负载） |

### 本次新增关键细节

1. **双液冷版本**：传统 **DLC（Direct Liquid Cooling）** + **ZutaCore 两相冷却**可选——介电液体沸腾→冷凝，**为不愿用水回路/无需 CDU 水冷基础设施的客户提供关键折中方案**
2. **板载网络带宽**：**8× OSFP 800Gbps cages = 6.4Tbps**（前置面板，无需额外 PCIe NIC 即达）
3. **供电**：10× 3kW **80Plus Titanium** PSU（冗余）
4. **存储**：12× 2.5" U.2 NVMe（2 连 CPU + 10 连 PCIe switch 复合体）
5. **易维护设计**：前端管理口 + 2× 1GbE（Intel i350）可经内部线缆**前后互换**（单 SKU 适配不同机房布线）；侧置大风扇热插拔 + 底部 3 小风扇
6. **冷却接口**：前置 CPU 液冷进出水口（蓝=进/红=出），12 组 GPU 冷却喷嘴

### 信号解读

- HGX B300 8-GPU 是 **Blackwell Ultra 的 OAM baseboard 开放形态**（对比 NVL72 封闭整机），OEM 已量产可购
- **两相冷却（ZutaCore）上架主流 8-GPU 服务器**，标志两相方案从概念走向商用选项
- 板载 6.4Tbps 说明 **scale-out 网络带宽已下沉到 baseboard 层面**，PCIe NIC 时代逐步让位

## 📌 2. HPE Cray GX5000 — Venice 81,920 核/机架液冷密度（前几轮未覆盖）

- **来源**: [ServeTheHome — 81920 Cores Per Rack with AMD EPYC Venice at HPE Discover 2026](https://www.servethehome.com/81920-cores-per-rack-with-amd-epyc-venice-at-hpe-discover-2026/)（Patrick Kennedy, 2026-06-17，本次追踪中经 STH 站内搜索发现）
- **可信度**: ⭐⭐⭐⭐ HPE Discover 现场实拍（含工作样机，非静态 demo）

### 平台构成

| 维度 | 数据 |
|:-----|:-----|
| **刀片** | HPE Cray **GX250a** Compute Blade：**8× AMD EPYC Venice CPU**（单插槽/刀片，16 通道内存/CPU） |
| **机架密度** | **81,920 核/机架**（36 刀片×8 CPU×256 核；评论补充亦可按 40U×8×256 计算） |
| **供电** | 刀片中心 busbar（类似 ORv3 但实现不同），SP7 Venice 功耗 **700W–1400W/CPU** → **~250–320kW/rack**（40U，网络前） |
| **冷却** | 全液冷：CPU 冷板（6 螺丝点）+ **内存 DIMM 全液冷**（MRDIMM 形态）+ 1.6MW CDU |
| **网络** | **Slingshot 400**（每刀片两侧各 2 NIC，OCP NIC 3.0 类连接器直连每 CPU）；**未来可原位升级 Slingshot 800** |
| **存储** | 4 节点顶部 CPU 冷板上集成 Samsung **E1.S EDSSF SSD** 作本地快速 scratch |
| **部署** | 面罩标注 **Mission 超算**（Los Alamos，NVIDIA 合作） |

### 信号解读

- 对比当前空冷机架 ~8,000 核 → **液冷 Venice 机架 ~10× 密度跃迁**
- 液冷覆盖从 CPU/GPU 延伸到**内存子系统**（DIMM 冷板），机架功耗迈向 250kW+ 量级
- 形态从 SC25 原型（2025-11）→ Discover 2026 **工作样机**，Venice 生态落地加速
- 与 07-28 归档的 MSI Venice DLC 1OU2N（100kW/rack）互为印证：**Venice 液冷密度军备竞赛已开跑**
