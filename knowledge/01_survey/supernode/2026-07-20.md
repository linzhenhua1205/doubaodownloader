## 📌 1. MSI EPYC Venice + ORv3 液冷机架 — AMD 超节点方案浮出水面

| 维度 | 数据 |
|:-----|:-----|
| **来源** | ServeTheHome, Ryan Smith, 2026-07-19 |
| **链接** | https://www.servethehome.com/msi-slyly-shows-off-an-upcoming-dlc-amd-epyc-venice-platform-with-cd182-s6091-x2-servers-and-racks/ |
| **可信度** | ⭐⭐⭐⭐⭐ Computex 2026 实地报道，Ryan Smith（前 AnandTech EIC） |

### 架构详情

**MSI CD182-S6091-X2 (DLC) 计算节点**
- **形态**: 1OU2N（1U OCPv3 机箱内 2 个独立双路节点）
- **CPU**: AMD EPYC "Venice" 第 6 代，双路 × 2 节点 = **每 1U 4 颗 Venice**
- **内存**: 每节点 16 通道 DDR5（1DPC），**32 RDIMMs/服务器** + 内存独立液冷回路
- **互联**: PCIe Gen6 x16 扩展（FHHL + HHHL 各一），OCP 3.0 NIC 槽
- **存储**: 4× E1.S PCIe Gen6（Micron 9650 级）
- **散热**: **DLC 双回路液冷** — CPU 冷板串联 + 内存独立冷板液冷回路 + 漏液检测电路
- **BMC**: ASPEED AST2700（新世代 BMC）
- **供电**: 48VDC 总线供电（无板载 PSU）

**ORv3 整机柜**
- **规格**: 44OU，**28 个 CD182 节点**（即 112 颗 Venice CPU + 1792 条 RDIMM/机柜）
- **功率**: **100kW/机柜**
- **供电**: 2× 55kW Chicony 电源架 → 48VDC 母线
- **冷却**: 100kW Auras CDU，液对液换热
- **网络**: 32× 100GbE（数据）+ 2× 48× 1GbE（管理）

### 战略意义

- **AMD 对 NVIDIA 超节点的反击**：Vera Rubin NVL144 ≠ 唯一超节点路径。EPYC Venice 以 **16 通道 + PCIe Gen6 + DLC** 构成高密度计算阵列，1U 容纳 4 颗 CPU + 32 DIMM
- **供电架构对标**：48VDC 母线 + ORv3 标准，与 NVIDIA GB300 NVL72/GB200 NVL72 供电方案在同一赛道上
- **1.6TB/s 内存带宽**（MRDIMM Gen2）为 AI 推理/训练提供巨大 HBM 之外的内存带宽替代方案

### 规模数据

| 指标 | 单机柜 |
|:-----|:------:|
| CPU 数 | 112 颗 EPYC Venice |
| 内存通道 | 448 通道 (16ch × 28) |
| DIMM 数 | 1,792 条 |
| 功率 | 100 kW |
| 供电 | 48VDC 母线 |

## 📌 2. AIC F2032-01-G6 — Vera Rubin CMX KV 缓存 JBOF

| 维度 | 数据 |
|:-----|:-----|
| **来源** | ServeTheHome, Ryan Smith, 2026-07-11 |
| **链接** | https://www.servethehome.com/aic-gets-flashy-with-32-ssd-bay-jbof-server-for-key-value-caching/ |
| **可信度** | ⭐⭐⭐⭐⭐ Computex 2026 实地 + 规格表 |

### 架构详情

- **形态**: 2U JBOF（Just a Bunch of Flash）
- **存储**: 32× PCIe Gen6 E3 盘位（E3.S/E3.L），**最高 8PB/2U**（256TB QLC SSD）
- **I/O 交换**: Broadcom PEX90144 — **144-lane PCIe Gen6 交换芯片**
- **控制节点**: **NVIDIA BlueField-4 DPU**（Grace CPU + ConnectX-9），800GbE/InfiniBand
- **冗余**: 双节点设计，支持 DPU 全冗余热备
- **定位**: **NVIDIA CMX（Context Memory Storage）** — Vera Rubin 超节点的专用 KV 缓存加速层
- **兼容性**: PCIe Gen6 全线，BNG（Broadcom Next Gen）交换架构

### 战略意义

- **Vera Rubin 配套存储架构** — SemiAnalysis (2025-09-10) 提及的 Rubin CPX 专用预填充加速器 + AIC 这一 JBOF 共同构成 Vera Rubin 的 **存储-缓存子系统**
- **KV 缓存成为超节点标配** — 大型推理集群中，KV 缓存近 GPU 放置是 scaling 性能的关键，JBOF 将成 AI DC 常见组件
- **NVIDIA 标准化 CMX 平台** — 对 AIC 等 ODM 开放，BlueField-4 驱动，形成 Vera Rubin 存储生态

### 规模数据

| 指标 | 数据 |
|:-----|:----:|
| 形态 | 2U |
| 最大容量 | 8 PB（256TB × 32 E3.L QLC） |
| SSD 协议 | PCIe Gen6 ×2 per SSD |
| 内部交换 | 144-lane PCIe Gen6 |
| 网络 | 800GbE/IB（BlueField-4） |
| 冗余 | 双 DPU 全冗余 |

## 📌 3. ASUS 热实验室 — GB200/GB300 NVL72 液冷验证实践

| 维度 | 数据 |
|:-----|:-----|
| **来源** | ServeTheHome, Patrick Kennedy, 2026-07-10 |
| **链接** | https://www.servethehome.com/asus-thermal-lab-tour-2026-testing-ai-servers/ |
| **可信度** | ⭐⭐⭐⭐⭐ 实地参观，ASUS 赞助但内容独立 |

### 架构详情

**环境实验室（Walk-in Chamber）**
- 接受 **整机柜**（而非单节点）——专为液冷系统设计的超大腔体（25°C~45°C）
- 测试时腔体内实测含 **NVIDIA GB200 NVL72 + GB300 NVL72 整机柜**
- 液冷系统在 20°C  coolant 温度运行，同时测试更高 coolant 温度以降低 chiller 能耗

**极端环境实验室（Extreme Chamber）**
- **-40°C 至 85°C** 温域，10%~98% 湿度
- 用于出厂前可靠性验证：运输/存储/非受控环境下的整机柜耐受
- 加速老化测试：85°C 持续运行揭示数年才会暴露的失效模式
- 当前运往客户的 **NVIDIA GB200 NVL72 机柜** 全程温控运输

**R&D 液冷集成实验室**
- **1.1 MW** 功率容量
- 架空地板下冷却液配管网络（模拟真实部署的管道直径/阀门布局/漏液检测）
- 多机柜级液冷验证：冷板流量协调、压力降、传感器管理软件
- NVIDIA GB300 NVL72 整机柜正在此验证

### 战略意义

- **液冷测试从单节点 → 整机柜 → 多机柜** 三级跃迁，这是超节点时代验证范式的标志性转变
- GB200 NVL72→GB300 NVL72 过渡中，ASUS 验证重心在 **rack-scale 液冷协调**而非单板热管理
- 1.1MW 实验室容量对应 **~10 个 100kW 超节点机柜** 或数个高密度液冷集群

### 规模数据

| 指标 | 数据 |
|:-----|:----:|
| R&D 实验室功率容量 | 1.1 MW |
| 环境腔温度范围 | 25°C → 45°C（正常工作） |
| 极端腔温度范围 | -40°C → 85°C（可靠性） |
| 验证中机柜 | GB200 NVL72 / GB300 NVL72 |
| Coolant 温度 | 20°C（当前）→ 更高温度测试中 |
| 液冷级别 | 机柜级→多机柜级液冷配网 |
