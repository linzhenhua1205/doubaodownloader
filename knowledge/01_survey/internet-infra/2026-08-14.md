## 二、国内大厂开源基础设施动态（GitHub 实时 08-14）

- **字节 deer-flow**（⭐79.9k, 推送 08-13）: 长时程 SuperAgent harness，star 再涨（08-13 的 79.8k → 79.9k），仍为国内大厂 Agent 项目流量第一。来源: https://github.com/bytedance/deer-flow

- **阿里 skill-up**（⭐524, 推送 08-13）: Agent Skills 评估与进化工具，阿里跟进"技能进化/评估"赛道（与本系统 Skill 进化方向同构）。来源: https://github.com/alibaba/skill-up

- **阿里 arthas**（⭐37.5k, 推送 08-13）: Java 诊断工具常规更新，云原生可观测性组件持续维护。来源: https://github.com/alibaba/arthas

- **腾讯 WeKnora**（⭐19.8k, 推送 08-13）: 开源 LLM 知识平台——原始文档转可查询 RAG + 自主推理 agent，知识库基础设施方向（与 RAG/KV 卸载链路相关）。来源: https://github.com/Tencent/WeKnora

- **腾讯 BrowserSkill**（⭐1.0k, 推送 08-13）: 让 AI agent 使用真实已登录浏览器（CLI + 扩展），Agent 工具面（browser-use 类）在腾讯开源栈落地。来源: https://github.com/Tencent/BrowserSkill

- **百度 vLLM-Kunlun**（⭐455, 推送 08-13）: vLLM 昆仑芯硬件适配插件，连续第三日推送（08-11/08-12/08-13），国产芯片推理栈持续完善。来源: https://github.com/baidu/vLLM-Kunlun
