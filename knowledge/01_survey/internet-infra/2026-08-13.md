- **AI 数据中心岗位需求爆发**（IT之家引 Indeed, 08-09）: 美国增长最快的科技岗位转向数据中心建设所需的电工/安装工/工程师，过去两年相关招聘翻倍，时薪高出行业均值约 10 美元。基建人力瓶颈成为交付约束之一。来源: https://www.ithome.com/tag/ai/

- **Meta 发布开源 agentic 模型 Muse Glimmer（30B）**（The Verge, 08-10）: 可在单显卡设备本地运行，参数规模显著小于中国竞品（阿里 Qwen3.8-Max 2.4T / Kimi K3 2.8T），指向边缘/端侧推理基建路线。来源: https://www.theverge.com/ai-artificial-intelligence

## 二、国内大厂开源基础设施动态（GitHub 实时 08-13）

- **阿里 rtp-llm**（⭐1.3k, 推送 08-12）: 高性能 LLM 推理引擎持续活跃迭代，与 Gartner 推理支出超越训练判断方向一致。来源: https://github.com/alibaba/rtp-llm

- **阿里 tair-kvcache**（⭐225, 推送 08-12）: 云上高性能 KVCache 系统，KV 向存储层卸载方向延续，本周持续推送。来源: https://github.com/alibaba/tair-kvcache

- **阿里 anolisa**（⭐337, 推送 08-12）: Agentic Nexus Operating Layer（Agent 化操作系统层），字节 deer-flow 之后阿里在 Agent 基础设施层的对标布局。来源: https://github.com/alibaba/anolisa

- **字节 deer-flow**（⭐79.8k, 推送 08-12）: 长时程 SuperAgent harness，star 持续攀升（08-08 的 79.5k → 79.8k），仍为国内大厂 Agent 项目流量第一。来源: https://github.com/bytedance/deer-flow

- **字节 agentkit-samples**（⭐422, 推送 08-12）: 火山引擎 AgentKit（VeADK）样例集，字节 Agent 平台对外生态持续输出。来源: https://github.com/bytedance/agentkit-samples

- **百度 vLLM-Kunlun**（⭐455, 推送 08-11）: vLLM 昆仑芯硬件适配插件更新，国产芯片推理栈持续完善。来源: https://github.com/baidu/vLLM-Kunlun

- **百度 dperf**（⭐5.6k, 推送 08-07）: DPDK 高性能网络压测工具，AI 网络测试基础设施，本周无新推送（稳定态）。来源: https://github.com/baidu/dperf

- **腾讯 AngelSlim**（⭐1.5k, 推送 08-07）: 模型压缩工具包，本周无新推送（稳定态）。来源: https://github.com/Tencent/AngelSlim

## 三、观察小结

- **推理算力成为支出主战场**: Gartner 预测 2026 推理 IaaS 支出 +96% 并首超训练，与阿里 rtp-llm/tair-kvcache 的持续投入互相印证，推理侧基础设施（引擎/KV 卸载/国产芯片适配）是当下竞争焦点。
- **海外数据中心扩张进入"反对周期"**: 社区禁令、电力/排放约束、人力短缺三线收紧，选址与交付成为超大规模厂（甲骨文/Amazon 等）的新瓶颈。
- **Agent 基础设施仍是国内大厂开源主战场**: 字节 deer-flow 持续霸榜，阿里 anolisa 对标跟进；KV Cache 向存储层卸载为确定性趋势。
- **源可靠性说明**: 本次 Baidu/Bing 搜索源被反爬/无有效信息拦截，火山引擎/阿里云/腾讯云官网均为 JS 渲染；国内一手动态继续依赖 GitHub 实时仓库 + IT之家聚合。数据均来自实际抓取页面，URL 已 curl 验证 HTTP 200（3 个 GitHub 仓库页面因连接超时返回 000，但经 GitHub API 复核仓库存在且 star 数一致）。
