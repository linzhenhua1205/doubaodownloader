## 1️⃣ 🚗 Delta Parquet vs Iceberg vs Hudi — 汽车数据工程场景对比

> **论文**: arXiv:2508.13396 · SSRG IJCSE 2025 | **作者**: Dinesh Eswararaj, Ajay Babu Nellipudi, Vandana Kollati
> **提交**: 2025-08-18 | **DOI**: 10.14445/23488387/IJCSE-V12I17P104

### 实验设置

- **数据**: 真实车联网时序（车辆 ID + 时间戳 + GPS 位置 + 事件指标）
- **场景**: 实时采集 / 批量分析 / CDC 增量 / ML 特征工程
- **引擎**: Spark 3.5 + 各格式最新稳定版
- **分区**: 时间 + 车辆 ID 双级分区

### 六维对比矩阵

| 维度 | Delta Parquet | Iceberg | Hudi |
|:-----|:-------------|:--------|:-----|
| **批量查询** (TPC-DS 类) | 🟢 **优** | 🟢 **优** | 🟡 中 |
| **实时摄入** (>10K rows/s) | 🟡 中 | 🟡 中 | 🟢 **优** |
| **CDC 增量处理** | 🟡 中 | 🟡 中 | 🟢 **优** (COW/MOR) |
| **Time Travel / 版本回溯** | 🟢 **优** | 🟢 **优** | 🟡 中 |
| **ML 特征就绪度** | 🟢 **优** (Schema 治理强) | 🟡 中 | 🟡 中 |
| **存储效率** (同数据体积比) | 🟡 中 (1.0×基准) | 🟢 **优 (0.75×)** | 🟡 中 |
| **治理/合规** (ACID/审计) | 🟢 **优** | 🟡 中 | 🟡 中 |
| **云对象存储适配** | 🟡 中 | 🟢 **优**（S3 风格原生） | 🟡 中 |

### 推荐场景组合模式

```
+-------------------------------------------------------------+
|              车联网湖仓 Hub-and-Spoke 多格式架构              |
+-----------+----------------------+--------------------------+
| 层       | 格式                 | 用途                     |
+-----------+----------------------+--------------------------+
| 实时摄入层 | Hudi (MOR + CDC)    | 高频写入，增量管道        |
| 分析层     | Iceberg (分区剪枝)   | 批量 SQL 查询，云原生     |
| ML 特征层  | Delta Parquet       | 模型训练，Schema 治理     |
| Catalog层 | Unity / TreeCat     | 统一元数据 + 跨格式路由    |
+-----------+----------------------+--------------------------+
```

### 局限（论文自述 & 补充分析）

1. **引擎单一**：仅 Spark，未涉及 Flink/Presto/Trino
2. **规模受限**：单集群 <10 节点，未测试百节点以上
3. **未量化**：写入放大系数（Write Amplification）、存储长尾成本
4. **缺乏增量对比**：Hudi 在 CDC 场景的明显优势可能导致其他场景的偏见
