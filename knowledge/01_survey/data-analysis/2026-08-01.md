## 一、湖仓存储格式对比

- **来源: arXiv:2508.13396 — "A Comparative Study of Delta Parquet, Iceberg, and Hudi for Automotive Data Engineering Use Cases"** (cs.SE, 2025-08-18)
  - 使用真实世界汽车遥测时间序列数据（vehicle ID/timestamp/location/event metrics）对比三大湖仓格式，评估维度：建模策略、分区、CDC 支持、查询性能、可扩展性、数据一致性、生态成熟度
  - **关键结论**: Delta Parquet 强 ML 就绪性与治理；Iceberg 高性能批处理分析+云原生负载；Hudi 优化实时摄入+增量处理
  - **权衡要点**: 三格式在查询效率/time-travel/更新语义上各有取舍，可组合用于车队管理、预测性维护、路径优化
  - URL: https://arxiv.org/abs/2508.13396

## 二、湖仓查询优化与引擎路由

- **来源: arXiv:2506.02802 — "A Learned Cost Model-based Cross-engine Optimizer for SQL Workloads"** (cs.DB/cs.LG, 2025-06-03)
  - Lakehouse 多引擎查询场景下，用学习成本模型自动选择最优执行引擎，消除人工 a priori 知识依赖
  - **方法**: 成本预测建模为多任务学习，多预测头对应不同引擎/配置，新引擎仅需最小微调成本即可加入
  - **量化收益**: 用优化后逻辑计划做成本估计，平均 Q-error 较未优化计划降 **12.6%**；跨引擎优化器 vs 随机路由：零样本设置总工作负载运行时间降 **25.2%**，少样本设置降 **30.4%**
  - URL: https://arxiv.org/abs/2506.02802

## 三、Composable Lakehouse 架构

- **来源: arXiv:2505.13750 — "Eudoxia: a FaaS scheduling simulator for the composable lakehouse"** (cs.DB/cs.DC, 2025-05-19)
  - Bauplan 基于「spare data parts」+ 统一 FaaS 运行时（SQL + Python pipelines）构建 composable DLH，FaaS 化引入调度/优化新挑战
  - **产出**: Eudoxia 确定性调度模拟器，支持广泛工作负载 + 高度可定制调度算法实现，为开发者提供低成本基础设施评估机制
  - URL: https://arxiv.org/abs/2505.13750

- **来源: arXiv:2503.02956 — "TreeCat: Standalone Catalog Engine for Large Data Systems"** (cs.DB, PVLDB Vol 18 / VLDB 2025)
  - 主张现有湖仓存储格式存在根本局限，需专用数据库引擎充当 catalog（独立目录引擎）
  - **设计**: 层级数据模型 + 路径查询语言 + 面向范围查询与版本化的存储格式 + correlated scan
  - **核心技术**: 新 MVOCC（multi-versioned optimistic concurrency control）协议保证可串行化隔离，应对多客户端并发读写
  - 实验对比对象: Hive Metastore / Delta Lake / Iceberg
  - URL: https://arxiv.org/abs/2503.02956

## 四、AI × 数据融合

- **来源: arXiv:2503.04847 — "Role of Databases in GenAI Applications"** (cs.DB/cs.AI, 2025-03-05)
  - GenAI 应用中数据库角色三层分类：**会话上下文**（key-value/文档库）→ **情境上下文**（关系型/湖仓）→ **语义上下文**（向量库），各司其职
  - 多数据库架构使 GenAI 应用更上下文感知、个性化、高性能；强调实时查询处理、向量语义检索、数据库选择对模型效率/可扩展性的影响
  - URL: https://arxiv.org/abs/2503.04847

## 小结

- **格式三强分化持续**: Delta(ML/治理) vs Iceberg(批/云原生) vs Hudi(实时/增量)，与 07-28 调研结论一致，新增汽车工业实证
- **跨引擎优化成为热点**: 学习成本模型自动化引擎路由（Q-error ↓12.6%、运行时 ↓25-30%），回应多引擎 Lakehouse 的工程痛点
- **Catalog 独立化趋势**: TreeCat 提出专用 catalog 引擎 + MVOCC，挑战 Hive Metastore/格式内嵌 catalog 现状
- **Composable/Serverless 湖仓**: Bauplan 系继续深耕 FaaS 化调度（Eudoxia 模拟器）
- **AI 融合**: 数据库按上下文类型分层服务 GenAI 应用成为明确架构范式
