## 发现清单

- **Stateful Governance for Concurrent Agentic Systems** (2608.02764, 2026-08-05, U Maryland Yuxiang Peng/Xiaodi Wu, cross cs.MA): 并发 agentic 系统的有状态治理——为多 agent 并发执行提出状态化治理机制，解决无状态 agent 在共享数据环境下的一致性与审计问题；与 08-03 归档的"MVCC 类比无法直接移植、需 agent-first 重实现隔离"结论直接延续，治理从单 agent 走向并发群体。https://arxiv.org/abs/2608.02764

- **Evaluating LLMs in Database Scenarios: A Lifecycle Benchmark** (2608.03794, 2026-08-05): 覆盖核心数据库任务全生命周期的 LLM 评估基准——从 schema 设计、查询生成到优化调优各阶段系统评测 LLM 的数据库能力，补齐"LLM 在 DB 场景到底行不行"的量化证据；与 08-04 CITBench (表格交互处理) 同为 agentic/AI×DB 评测方向，但范围从表格扩展到完整 DB 生命周期。https://arxiv.org/abs/2608.03794

- **RAG-Stack: Co-Optimizing RAG Serving Performance and Quality** (2608.03487, 2026-08-05, Wenqi Jiang 等): RAG 服务性能与回答质量协同优化的系统层方案——将检索与生成作为联合优化对象而非分离组件，在吞吐/延迟与 RAG 质量间做显式权衡；标志 RAG 从"应用层拼装"进入"系统级协同设计"，与 lakehouse 向量/AI 数据通路优化同向。https://arxiv.org/abs/2608.03487

- **GPTKB 2.0: Direct Construction of Disambiguated Knowledge Bases from Large Language Models** (2608.03729, 2026-08-05, cross cs.CL, Razniewski 团队): 直接从 LLM 构建消歧知识库的第二代方案——解决首版中实体消歧与知识冲突问题，19页4图；LLM 作为知识库构建器从"可行性验证"进入"质量工程"阶段，与 07-28 GPTKB 系列归档形成连续追踪。https://arxiv.org/abs/2608.03729

- **On the missing data layer and a potential solution** (2608.02949, 2026-08-05, cross cs.AI, 7页): 指出 AI 应用栈中"数据层缺失"问题并提出解决方案——LLM 应用普遍缺乏结构化的数据管理与访问层，呼唤 lakehouse/数据平台在 AI 栈中承担一等公民角色；与 08-01 归档的 GenAI×数据库三层上下文架构 (2503.04847) 互为印证。https://arxiv.org/abs/2608.02949

- **AgenticER: the next frontier in Entity Resolution** (2607.27435, 2026-07-31, VLDB 2026 vision, George Papadakis 雅典团队): Agentic 实体解析前瞻论文——将实体解析（数据质量核心任务）从规则/ML 流水线推进到 LLM agent 自主编排：规划解析策略、调用工具、验证结果；标志 agentic 数据管理从湖仓层渗透到数据质量内核。https://arxiv.org/abs/2607.27435

- **Curriculum Matters: Data-Efficient Relational PFN Pretraining with Synthetic Data** (2607.29120, 2026-08-03, VLDB 2026 TaDA): 关系数据 Prior-Fitted Network 预训练的课程学习策略——用合成数据按课程顺序训练表格数据基础模型，显著提升数据效率；表格数据 foundation model 路线的训练方法论补强。https://arxiv.org/abs/2607.29120

- **Graph-Native Bitemporal Memory Store for Conversational AI Agents** (2607.26520, 2026-07-30): 对话 AI agent 的图原生双时态记忆存储——同时维护有效时间与事务时间，支持 agent 记忆的时间旅行查询；agent memory 从"KV 缓存"升级为"可审计数据库"，与 lakehouse 时间旅行语义在 agent 域对齐。https://arxiv.org/abs/2607.26520

- **Two-sided RDMA Striking Back for Disaggregated Memory Databases** (2607.26227, 2026-07-30, UT Austin): 分解内存数据库场景下双端 RDMA 方案回归——针对单侧 RDMA 的扩展性问题，用双端 RDMA 重构远程内存访问路径，降低延迟与 CPU 开销；对超节点/分解存储架构下的数据库部署有直接参考价值。https://arxiv.org/abs/2607.26227

- **Digital Asset Data Lakehouse** (2503.15968, 2025-03-20, 补档): 面向区块链数字资产的云原生湖仓架构——模块化微服务 + 湖仓存储支撑多利益相关方数据共享与近实时分析，为科研可复现性提供数据基座；补档价值: 湖仓在链上数据/数字资产域的落地形态参考。https://arxiv.org/abs/2503.15968
