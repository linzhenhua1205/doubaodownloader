## 一、本日核心发现

- **新华三/重构多中心算力互联，Scale-Across 协同训推方案（2026-08-12，H3C 官网）**: 基于高密 800G 智算 DCI 交换机 S12500R-64EP，直击百公里跨中心训推"无损协同"难题。三大技术增量：①**FastCNP 快速拥塞通知**——拥塞控制权限下沉至 DCI 边界交换机，探测到拥塞苗头即刻原地生成通知（不等接收端回传），实测拥塞响应速度 **+81.4%**、整体吞吐量 **+11%**（百公里距离下传统 CNP 一来一回耗时数十至上百微秒、信号到达时已晚）；②**32GB HBM 超大缓存 + 距离感知智能缓存调度**——多中心周期性流量洪峰下零丢包，按链路时延动态调节驻留，兼顾大缓存与低时延（长距 RoCE 一次丢包重传代价极高、直接致远端 GPU 空转）；③**800G ZR 彩光直连**——省去 OTN 电层转发环节（光-电-光转换），单纤承载多路 800G，整体建设成本 **-45%**。配套 AD-DC 智算版跨域运维（全网拓扑/光模块健康度/策略自动化下发）。背景：谷歌云荷兰 europe-west4-a 可用区因上游电网故障致制冷失效、核心服务中断近 15 小时，万卡集群多中心分散化成为必然。**信号**：FastCNP 与 IETF 快速 CNP 代理主线（08-07 收录）形成"国产厂商落地 vs 标准草案"对照，跨中心训练从"连通"转向"无损"竞争；URL: https://www.h3c.com/cn/d_202608/2893941_30008_0.htm

- **STH/NVIDIA Spectrum-X Ethernet MRC 协议细节补录（2026-05-06，本组视角增量）**: MRC（Multipath Reliable Connection）= NVIDIA 下一代 RDMA 传输协议，已通过 **Open Compute Project 发布为开放规范**——单个 RoCEv2 连接在多条网络路径同时分发流量，软件加速负载均衡 + 动态拥塞规避 + 智能重传 + **微秒级硬件故障旁路**；与 **multiplane（多平面）网络架构**协同，跨平面负载均衡，扩展至数十万 GPU。已部署 OpenAI/Oracle/Microsoft 超大规模集群；与 AMD/Broadcom/Intel 及云厂商联合开发。**信号**：NVIDIA 以"开放规范 + Spectrum-X 闭源平台"双轨对抗 Ultra Ethernet Consortium（UEC）开源叙事——MRC 在 Spectrum-4/Spectrum-5 世代已量产运行，非纸面标准；URL: https://www.servethehome.com/nvidia-spectrum-x-ethernet-mrc-is-the-custom-rdma-transport-protocol-for-gigascale-ai/

- **NVIDIA/Quantum InfiniBand UFM 一键多租户安全（2026-06-11，NVIDIA Technical Blog）**: UFM（Unified Fabric Manager）新增 **intent-based security profiles**——以意图式安全配置文件实现多租户 fabric 安全一键下发，收敛 IB 网络管理面安全配置复杂度。**信号**：AI 网络管理面从"性能调优"延伸至"多租户安全隔离"，与 RoCE/IB 混布集群的租户隔离需求同步演进；URL: https://developer.nvidia.com/blog/one-click-multi-tenant-security-with-nvidia-quantum-infiniBand/
