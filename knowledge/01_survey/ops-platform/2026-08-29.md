## 学术动态（arXiv 近一周）

- **arXiv 2608.27182「TraceBench：LLM Agent 时序根因归因的受控评测基准」**（2026-08-27）: 仿真框架生成受控 RCA 任务，系统评测 LLM Agent 在时序异常检测与根因归因上的真实能力（此前缺乏受控条件下的标准化评测）——为运维 RCA Agent 选型提供可复现评测基线。https://arxiv.org/abs/2608.27182
- **arXiv 2608.25661「从通用 Agent 到 RCA 专家：自进化 Harness 用于根因分析」**（2026-08-26）: 量化对比"直接用通用 Agent（Codex/Claude Code）诊断"与"从零构建专用 RCA Agent"两条路线，提出自进化(self-evolving) harness 路线——对 SRE 团队决定"自研 RCA 工具还是复用通用 Agent"有直接参考价值。https://arxiv.org/abs/2608.25661
- **arXiv 2608.26226「LLM Agents for Time-Series：综述」**（2026-08-26）: 以问题驱动分类法（预测推理/增强合成/异常检测等四类）系统梳理 LLM Agent 在时序任务上的设计选择差异——可作为 AIOps 场景 LLM 应用的技术地图。https://arxiv.org/abs/2608.26226
- **arXiv 2608.23547「训练期数据污染下工业控制系统异常检测模型的鲁棒性」**（2026-08-24）: 评估 ICS 异常检测流水线在训练数据被污染（日志篡改/标签错误/historian 记录操纵/不安全重训）时的鲁棒性——直接对应生产环境运维数据质量控制风险，AIOps 训练数据可信度问题。https://arxiv.org/abs/2608.23547
