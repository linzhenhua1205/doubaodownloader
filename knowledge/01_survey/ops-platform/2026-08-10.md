### arXiv 学术动态（cs.DC 检索 30 条，最新提交 08-02，周末无公告规律再次验证）

- **NIXT: NCCL Inspector Exporter Tool**（arXiv:2608.01449, 08-02, IEEE IISWC 2026）: 把 NVIDIA NCCL Inspector profiler 的海量通信统计转为可访问分析+可执行洞察的导出工具；2048 GPU H100 集群 Nemotron-4 预训练案例中，展示通信阶段随 ML 并行与 GPU 规模的变化，并对性能波动做归因、对 straggler 做根因分析——万卡训练通信可观测性从"采集指标"走向"归因定位"的工具化路径。https://arxiv.org/abs/2608.01449

- **Progressive Crystallization: 生产 AIOps agent 从探索走向确定性工作流**（arXiv:2607.07052, 07-08）: 生产云网络 AIOps 系统（月处理数万 incident）将 agent 探索定位为发现机制而非永久执行模型；三阶段执行分类法（全 agent→混合→全确定性）+ 证据驱动晋升/回退；实测 8 个月确定性执行 0%→45%，每 incident agent 成本降 >70%（期间 incident 量翻倍），可复现性与可审计性同步提升——AIOps agent 成本治理的稀缺一手实证，与"约束脚本化=最高杠杆"判断同构。https://arxiv.org/abs/2607.07052

- **Auditable Graph-Guided RCA for Kubernetes Incidents**（arXiv:2606.08590, 06-07）: 图遍历 RCA agent（LLM 推理+确定性图/工具操作），约束=只读证据收集/传播感知诊断/有界执行/独立验证；ITBench 23 场景根因实体 F1 0.6087→0.9130，但剥离场景提示后降至 0.6958，作者诚实标注为 benchmark-coupled 而非跨集群 RCA 证据——K8s 场景 RCA 可审计性设计（同裁判对比/提示消融/级联源检查/遥测无泄漏测试）的可复制框架。https://arxiv.org/abs/2606.08590

- **Why Do AI Agents Systematically Fail at Cloud RCA**（arXiv:2602.09937v2, 03-04）: 全量 OpenRCA 基准×5 个 LLM 模型=1675 次 agent 运行，将失败归类为 12 类陷阱（intra-agent 推理/agent 间通信/agent-环境交互三层）；最常见失败（幻觉式数据解读、探索不完整）跨所有能力层级模型普遍存在——根因在共享 agent 架构而非单模型能力，提示工程无法单独解决；为 RCA agent 平台设计提供失败模式检查清单。https://arxiv.org/abs/2602.09937

## 趋势研判

- **训练通信可观测性工具化主线成型**: NIXT（NCCL Inspector 导出，2608.01449）与已记录的 CCL-D（4000 GPU 集群 slow/hang 6 分钟定位，PPoPP'26）同属一条线——通信库级 profiler 数据从"工程师手工看"走向"工具自动归因"，超节点运维的通信侧诊断能力快速补齐。
- **AIOps agent 成本治理实证落地**: Progressive Crystallization 用 8 个月生产数据证明"确定性优先"（45% 确定性执行、单 incident 成本 -70%+）——agent 用于探索、脚本固化结果，与"AI 产出=毛利非净利"的判断互相印证，AIOps 平台应内置"探索→固化"生命周期而非纯 agent 化。
- **RCA agent 可审计性成为一等设计约束**: 两条独立研究（可审计图遍历 RCA + 12 类失败模式分析）共同指向"LLM-RCA 必须可验证、可归因"——证据图约束+独立校验+失败模式清单，是运维平台 RCA 功能的设计基线。
- **中文生态 Agentic AIOps 叙事升温**: 华为云选型指南把"智能体协同运维"定为年度趋势，与 08-08 记录的华为官方解读（自动化+智能化闭环）口径一致——国内厂商从"AIOps 概念科普"转向"Agentic 落地选型"阶段。
