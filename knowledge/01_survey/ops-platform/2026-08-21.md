## 一、arXiv 学术前沿（2026-07-25 ~ 08-12，运维 Agent 评测与 RCA 工具化）

- **CTBench: 电信网络运维 Agent 故障排查基准**（2026-08-12）: 专家构建的电信运维排障基准，聚焦 RCA + 路径恢复，含黄金证据步骤标注；实验显示 SOTA Agent 在路径恢复端点识别表现好，但 RCA 整体欠佳——接口状态/链路层/服务管理类故障是共同短板；**即使最终答案正确，Agent 也常缺乏证据支撑的诊断**（运维实践刚需 vs 模型能力缺口）。来源: https://arxiv.org/abs/2608.12002
- **ORCA-bench v2: oncall RCA 就绪度评测**（2026-08-05 更新）: 把通用编码 Agent 放入生产保真 oncall 场景——OTel 插桩微服务 + 6 天真实遥测（Prometheus/Jaeger/OpenSearch via Grafana）+ 源码访问 + 1079 个 RCA 任务；5 个前沿 Agent 最佳 RCA 准确率仅 **Medium 25.3% / Hard 10.0%**，最弱模型 40% 场景幻觉根因；LLM-as-judge 与人类评分 Cohen's κw=0.90；作者明示真实生产系统大一个量级，此结果为生产安全托付的下界。来源: https://arxiv.org/abs/2607.28545
- **GALA+: 图增强 LLM Agent 微服务 RCA + 事件响应**（2026-08-10, ASE'26）: 用服务依赖图约束 Agent 探索范围抑制幻觉，STRIX 模块融合 trace+图结构打分，产出排序诊断+事件摘要+分层行动建议；SURE-Score 为与 SRE 专家共建的 RCA 输出质量评测框架；**AC@1 超最强 LLM 基线 25+ 个百分点**，人类 SRE 评分最高。来源: https://arxiv.org/abs/2608.08968
- **eIRWR: 可扩展微服务 RCA（随机游走增强）**（2026-08-08）: 修正随机游走 RCA 的重启质量集中问题（power-law teleportation 锐化 + 自环/反向边）；阿里微服务轨迹数据集 12K-25K 节点上 MRR 0.75（中等可见度，2.8x 于最佳聚合基线）、高可见度 0.94；**17K 节点 <25ms，满足在线部署**。来源: https://arxiv.org/abs/2608.08073
- **NIXT: NCCL Inspector 导出工具——大模型训练通信可观测性**（2026-08-02, IISWC'26）: 将 NCCL Inspector profiler 数据转为可访问分析，2048 GPU H100 集群 Nemotron-4 预训练案例：量化通信阶段随 ML 并行度/GPU 规模的变化、性能波动归因与 straggler RCA——**万卡训练通信层 RCA 的专用工具化信号**。来源: https://arxiv.org/abs/2608.01449
- **TELLER: LLM 推理跨层 RCA**（2026-08-03, ASE'26）: 非侵入式采集 NVTX/CUPTI 追踪+服务日志，重建请求级调用链树并对齐执行步骤；Trace Pair Encoding 压缩 per-step trace 长度 80%+ 且诊断质量最佳；多模态根因模型联合定位异常步骤/可疑算子/生成自然语言解释——LLM 推理服务 RCA 基建。来源: https://arxiv.org/abs/2608.01975
- **Agentic Self-Healing: 开源供应商无关的数据/AI 管线自愈架构**（2026-08-03）: 对比现有 AI 辅助管线监控/RCA/自动修复方案后指出**缺口是架构性而非技术性**（组件已存在但碎片化于厂商平台）；提出监控+管线元数据+事故历史+确定性策略检查+AI 诊断+审批工作流+受控修复的参考架构。来源: https://arxiv.org/abs/2608.01955
- **EvoCause: LLM 引导因果图演化 RCA**（2026-07-29）: LLM 提出语义合理图编辑+确定性代码验证环闭；发布 TeleRCA 生产电信基准（**485,681 告警事件 / 194 告警类型 / 5,621 资源**）；Node F1/Case EM/Graph F1 较 PC 基线 +11.59/+9.40/+4.59 pp，告警名称语义信息对图精化贡献显著。来源: https://arxiv.org/abs/2607.27290
- **知识图谱引导 RAG-LLM 汽车 HiL 验证 RCA**（2026-08-11）: 时序记录→证据浓缩→传感器-位置传播知识增强→历史案例检索，LLM 作决策+解释层；Top-1 定位 90%（汽油机）/94%（电动车）——**KG-RAG 路线从云/微服务向行业验证场景扩散**。来源: https://arxiv.org/abs/2608.11277
- **MATERO-RCA: 工业时序上下文异常 RCA**（2026-07-31）: 模式感知轨迹级能量根集优化，联合优化根集/根因模式/反事实轨迹，MILP 保证最优搜索——工业多根因场景方法论。来源: https://arxiv.org/abs/2607.29092

## 小结（洞察）

1. **运维 Agent 进入"可测量"阶段，但能力下界仍低** —— ORCA-bench（Medium 25.3%/Hard 10.0%）、CTBench（证据缺失、弱故障类 RCA 差）密集出现，评测基准成为 Agentic 运维标配；幻觉率 40% 提示生产落地必须保留确定性兜底与人工审批。
2. **AI 基础设施垂直 RCA 工具化** —— NIXT（NCCL 通信 straggler RCA）、TELLER（LLM 推理跨层 RCA）表明大模型训练/推理运维正从通用监控分化出专用 RCA 工具链，与服务器/AI 基础设施运维平台规划直接相关。
3. **运维平台"MCP 化"+ Agentic AIOps 产品化** —— 蓝鲸 MCP Gateway（能力即工具）、天旦庙算 42（金融/电信落地）标志国内厂商从"告警+AIOps 报表"走向"平台能力开放给 Agent 自主闭环"。
4. **缺口是架构性而非技术性** —— 自愈管线论文的结论：组件已存在但碎片化于厂商平台；开源、供应商无关的编排层（监控+元数据+策略+审批+修复）是下一轮竞争点。
