## 本期新发现（2 条）

- **来源/标题: DNSSE — Directed Neuro-Symbolic Stochastic Execution for Verification of Distributed Parallel AI Programs**（arXiv:2608.07947, 08-08, ⭐3）: 分布式并行 AI 程序的混合验证框架，耦合 LLM 引导的调度预测 + 符号约束求解 + 覆盖率引导随机变异，以应对并行执行非确定性与 AI 高维非线性输入。基于 PyTorch+Ray 实现：并发 bug 检出率比最强基线 **+2.9%**，五个分布式 AI 基准分支覆盖率 **68.6%→91.6%**，并给出 LLM 引导调度探索的期望成本分析、证明 soundness/有界完备性/概率完备性。集群训练视角：分布式训练程序正确性验证工具链补强（对 FSDP/PP 等并行程序的非确定性调度 bug 有检测价值）。来源: https://arxiv.org/abs/2608.07947

- **来源/标题: RepoOMP — Repository-Aware Hotspot OpenMP Parallelization via Dependency-Aware Context Reduction**（arXiv:2608.05855, 08-06, ⭐1 弱相关）: 仓库感知的 OpenMP 热点并行化框架，用多粒度属性性能图(MAP)路由热点至规则/LLM agent，以结构化变换上下文(STC)暴露依赖事实。951 个 profiled hotspots（NPB/BOTS/FFmpeg/NCNN/GROMACS）中 372 个通过编译+负载检查+正加速验收，NPB 平均 **8.23×**、BOTS **8.96×**、330 个真实仓库热点中位 **2.25×**，相对非结构化 Claude Code 基线 agent 侧 token 成本 **-47~68%**。集群训练视角弱相关（通用多核并行化，非集群规模），但 MAP 路由+上下文约简思想可借鉴训练代码自动并行化工具。来源: https://arxiv.org/abs/2608.05855
