## 本期精选

### ⭐⭐⭐ AAFLOW+ — 分布式 KV Cache 成为 Multi-Agent 工作流的"一等公民"

- **论文**: [AAFLOW+: Stateful Operator Abstraction with Zero-Copy Distributed KV Cache Orchestration for Multi-Agent Workflows](https://arxiv.org/abs/2607.10987) (2607.10987, Tue 14 Jul)
- **核心贡献**:
  - KV cache 不再是单个 serving 实例的私有状态，而是**分布式系统的 first-class object**
  - 定义了一套 KV 操作原语: **materialization / transfer / fork / composition / eviction**
  - 运行时实现 zero-copy transfer-aware execution，agent 间共享长上下文无需重计算
  - 基于 analytical cost model（硬件微基准参数化）
- **关键指标**:
  - TTFT ↓ **50.2×**
  - Multi-agent compute cost ↓ **7.63×**（16-agent 规模）
  - KV memory ↓ **1.72–6.10×**
  - Throughput ↑ **7.74×**
  - 核心结论: **KV transmission 在中高带宽网络全面优于重计算**
- **意义**: 打破"每个 agent 独立 prefill"范式。KV 像数据库一样可共享、可传递——这对 agentic 推理的架构设计影响深远

---

### ⭐⭐⭐ Lynx — 加速 PD 分离中 KV 传输的渐进式推测量化

- **论文**: [Lynx: Progressive Speculative Quantization for accelerating KV Transfer in Long-Context Inference](https://arxiv.org/abs/2607.01831) (2607.01831, Tue 2 Jul)
- **核心贡献**:
  - 关键洞察: KV cache 的不同 bit 对注意力计算的贡献不等——**高位 bit 捕捉粗粒度结构，低位 bit 精修**
  - 将 KV cache 拆分为 **Anchor 流**（高位，高优先级）和 **Residual 流**（低位，低优先级）
  - Anchor 到达后立即开始 decode，Residual 并发传输，随后 verification 保证等精度
  - 本质是"推测性 KV 传输"——不等全部 bit 到齐就开工
- **关键指标**:
  - TTFT 可比 4-bit 激进量化，同时匹配 **BF16 精度**（其他 4-bit 方案精度损失大）
  - TTFT 较标准 8-bit KV 量化 ↑ **1.43×**
  - 精度较 SOTA ↑ 5.1%
- **意义**: 解决了 PD 分离中 KV 传输的"要么快但不准、要么准但不快"的矛盾。用推测解码的思路解决 KV 传输延迟——这是一个跨领域的巧妙迁移

---

### ⭐⭐ HyperQuant — 权重 + KV Cache 统一率失真最优量化流水线

- **论文**: [HyperQuant: A Rate-Distortion-Optimal Quantization Pipeline for Large Language and Diffusion Models](https://arxiv.org/abs/2606.23406) (2606.23406, Mon 22 Jun)
- **核心贡献**:
  - 四步流水线: **per-tile Randomized Hadamard Transform → 最优格量化(E8/D4/A2/Z) → lossless bit-stripping → Rice熵编码**
  - 统一处理权重和 KV cache，扩散模型(LTX-2 19B)同样适用
  - KV cache bias-correction 方法保持 attention 内积无偏
  - 兼容 fp8-e4m3/int8/nvfp4/mxfp4 Tensor Core
- **关键指标**:
  - H100 @ 4bps: weights ↓ **3.9×**, KV cache ↓ **3.79×**, near-lossless
  - 3–5 bits 权重/1.7+ bits KV 均优于 HIGGS/TurboQuant/OCTOPUS
- **意义**: 把权重和 KV cache 的量化统一到一个理论最优框架下。Hadamard 变换使每系数近似高斯→格量化→熵编码，理论路径清晰

---

### ⭐⭐ ATSInfer — 消费级设备上 Tensor 粒度的 CPU-GPU 混合推理

- **论文**: [Automated Tensor Scheduling for Hybrid CPU-GPU LLM Inference on Consumer Devices](https://arxiv.org/abs/2607.10183) (2607.10183, Tue 14 Jul)
- **核心贡献**:
  - 打破"以 layer/expert 粒度做 offload"的粗粒度常规——**以 tensor 粒度调度**
  - 静态 tensor 放置 + 负载感知动态传输 + 异步 CPU-GPU 协同
  - 同时支持 dense 和 MoE 模型
- **关键指标**:
  - Prefill throughput ↑ **1.94×**, Decode throughput ↑ **3.29×** (vs SOTA offloading 系统)
  - GPU 利用率、PCIe 带宽利用率均有提升
- **意义**: 消费级设备跑 LLM 的核心瓶颈在 GPU 显存不足时的 offload 调度。tensor 级调度的细粒度远高于 layer 级，首次将这一粒度推到了可行水平

---

### ⭐ ITME — CXL 解聚 TB 级显存扩展 KV Cache

- **论文**: [ITME: Inference Tiered Memory Expansion with Disaggregated CXL-Hybrid Memories](https://arxiv.org/abs/2606.12556) (2606.12556, Mon 16 Jun)
- **核心贡献**:
  - CXL-hybrid memory 提供 **TB 级 byte-addressable 远程内存扩展**
  - 批量权重的访问模式可预测 → 系统可主动管理数据在 memory-storage 层级间的移动
  - 基于 SK Hynix CMM + PCIe Gen5 NVMe SSD 验证
- **关键指标**:
  - Throughput ↑ **35.7%** (vs CPU-offloading baseline)
  - Key insight: 确定性访问模式使预取准确率远高于通用场景
- **意义**: 与 SAC 形成互补——SAC 从软件层面(cache-line 粒度)解决 CXL 解聚 KV 读取，ITME 从硬件层级(内存扩展)解决容量问题。CXL 在推理解聚场景的双路径攻击

---

### ⭐ SAECache — 语义感知前缀缓存淘汰策略

- **论文**: [Not All Tokens Are Worth Caching: Learning Semantic-Aware Eviction for LLM Prefix Caches](https://arxiv.org/abs/2605.18825) (2605.18825, Tue 12 May)
- **核心贡献**:
  - 不同 token 类型(system prompt / user query / tool output / CoT)的复用率差异高达 **756×**
  - 多队列架构: 不同语义类型的 KV block 走不同 priority 队列
  - 全自适应在线学习——无需人工调参
- **关键指标**:
  - TTFT ↑ **1.4–2.7×** vs LRU/SIEVE 等生产级策略
  - 固定参数策略在工作负载漂移时可退化 **2.7×**——自适应避免了这一失效模式
- **意义**: 工具调用 + 多轮对话场景下 token 类型复用率的差异巨大。语义感知策略本质上是"理解请求结构后再决策"，比统一 LRU 有质的不同

## 📌 趋势观察

### 1. KV Cache 正经历"解聚化 + 一等公民化"
AAFLOW+ 把 KV cache 变为分布式可共享对象，ITME/SAC 从 CXL 角度解聚容量与延迟，Lynx 用推测传输解决 PD 分离的转移瓶颈。**KV cache 的架构边界正在被全面打破**——从"和 serving 实例绑定的附属品"变成"独立的分布式系统资源"。

### 2. 量化进入"理论最优"时代
HyperQuant 的 Hadamard+格+熵编码流水线，首次在理论上逼近率失真下界。相比以往 heuristic 的逐层/逐通道量化，这是量化从"工程技巧"走向"信息论指导"的标志。

### 3. 推测解码的触角向外延伸
Lynx 把推测思想用到 KV 传输（非 token 生成），SPORK 用到 agent 工具调用。**推测模式不再只加速 token 生成，而是加速整个 inference 管线的所有等待环节。**
