## §1 集群训练可观测性 / 通信分析

- **NIXT: NCCL Inspector 导出工具**（2608.01449, 08-02, IEEE IISWC 2026录用）: 把 NCCL Inspector 的海量 profiling 数据转化为可读分析+可执行洞察；在 Nemotron-4 预训练 2048×H100 集群上实证，展示通信阶段如何随 ML 并行度与 GPU 规模变化，并完成性能波动归因与 straggler 根因分析。https://arxiv.org/abs/2608.01449

- **Bole: 混合注意力 LLM 高效树投机解码**（2608.01651, 08-03）: kernel-runtime 协同设计，把 linear-attention 递推转成树结构闭式解，全 proposal 节点并行验证——linear-attention 树验证加速 3.4-7.7×，投机状态瞬时内存 ↓82-99×（无损 token 级因子编码，仅重建采样后选中状态）；集成进 SGLang 生产引擎后离线解码吞吐最高 4.72×、较最强树投机基线 2.03×；在线 agent 负载 TTFT ↓67.6%、TPOT ↓49.9%。https://arxiv.org/abs/2608.01651

## §2 并行策略 / 序列放置

- **Zellige: 混合图像-视频 DiT 训练的可塑序列放置**（2608.01150, 08-02）: 证明 DP/CP 的 disjoint-group 放置存在组间负载失衡 vs 组内通信冗余的**根本权衡**；三组件=硬件 profile 器（step makespan/峰值内存 MAPE 仅 3.4%/1.5%）+两阶段 planner（先均衡 compute-heavy anchor 序列再打包 filler，每 batch 求解 33-119ms，较联合放置参考 makespan 差 ≤0.32%）+coalesced attention 引擎；端到端较 KnapFormer 16×A800 ↑1.12-1.48×、32×A6000 ↑1.27-1.54×。https://arxiv.org/abs/2608.01150

- **Tevatron 3.0: Megatron-Core 后端接入学术 reranker 训练**（2608.00916, 08-02）: Tevatron 集成 Megatron-Core，保留数据管线/评估/HF 兼容 checkpoint；与 FSDP 同 DP 配置下质量与效率持平、推荐单节点配置快 22%，支持 LoRA+全参微调；**Expert-Parallel 使 30B (Qwen3-30B-A3B) MoE reranker 训练在学术预算下可行**（FSDP1 不可行）；受控对比显示 MoE reranker 以 <1/2 激活参数匹配 dense 8B 质量且推理吞吐更高。https://arxiv.org/abs/2608.00916

## §3 后训练效率 / 显存优化

- **CoPES: 资源受限 agentic LLM 后训练的协作子空间进化**（2608.02391, 08-03, AAAI 2027投稿）: 将全参空间分解为低维子空间协作搜索；Qwen3.5-4B tool-using agent 上，以全参 GRPO 最优 checkpoint 的 GPU-hour 预算恢复其验证精度增益的 **92%**（标准 ES 仅 67%），理论显存需求 < 全参 GRPO 的 1/8，pass@k 全面优于标准 ES 与 LoRA-GRPO。https://arxiv.org/abs/2608.02391

- **Meganeura: Vulkan/Metal 便携 GPU 训练-推理统一栈**（2608.01563, 08-03）: 单编译器跨训练/推理两阶段；50 个 device-workload-mode 单元 48 个通过严格 f32 双门；离散 AMD GPU 上 4/5 推理负载在 ROCm PyTorch 1.10× 内、3 个训练负载更快；编译 0.1-2.4s vs torch.compile 6-96s，二进制 13MiB。https://arxiv.org/abs/2608.01563

## §4 推理侧复用（训练-推理栈融合）

- **RestoreKV: 激进 query-agnostic KV 驱逐下恢复全缓存行为**（2608.01247, 08-02）: 以"被驱逐信息随上下文变、但其紧凑补全的生成机制可跨上下文共享"为洞察——prefill 后单次 LoRA 适配 pass 生成 compact restore cache（仅训 0.4% 参数、自蒸馏自冻结全缓存模型）；5% 预算下把 KVzip 的 RULER-4K 从 38.2 提到 73.2，KVzip+ 在 16× 压缩达 86.4，一次性构建开销 <0.5%。https://arxiv.org/abs/2608.01247

## §5 相关硬件/计算原语（ISCA'26）

- **SegFold: 细粒度动态数据流加速稀疏 GEMM**（2606.26701, ISCA 2026录用）: 在静态数据流基础上引入动态调度（局部窗口复用识别+部分完成工作动态重映射），几何平均较 SOTA SpGEMM 加速器 **1.95×**、较最优静态数据流 **5.3×**——动态性解锁静态调度无法企及的复用与负载均衡增益。https://arxiv.org/abs/2606.26701
