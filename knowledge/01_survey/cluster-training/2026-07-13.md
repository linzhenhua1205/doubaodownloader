## 🔥 三大重磅

### 1. MoP: Mixture-of-Parallelisms — MoE 训练全栈并行编排框架
**arXiv:2607.01844** · 2026-07-02

**为什么重要**: 不是单一并行策略优化，而是**在 MoE 模型不同层/阶段组合不同并行策略**的统一框架——EP、TP、DP、FSDP 等不再是二选一，而是可编排的构建块。

**关键指标**:
- 比强调优的 FSDP2 基线 **4.7×–8.2× 更高 per-GPU 吞吐**（规模越大差距越明显）
- 支持 **百万级 context length** 持续训练（FSDP2 在 64K–128K 即 OOM）
- 12 节点 × 8×H200 = 96 GPU 可无损训练 **万亿参数级** MoE

**核心创新**:
- 组合并特化不同并行技术于 MoE 训练管线不同阶段
- 在 CPU/GPU 内存、CPU-GPU/GPU-GPU/节点间带宽约束下最大化效率
- **优化器步骤新策略**实现高吞吐+内存高效

> 📌 **趋势判断**: MoP 标志着 MoE 并行策略从"选一种主流方案"进入"按模型结构编排最佳组合"时代，与 Megatron Core 的 Parallel Folding (2603.07685) 形成双路线竞争。

### 2. ELDR: PD 分离中 MoE 的专家局部性感知解码路由
**arXiv:2607.00466** · 2026-07-01

**为什么重要**: PD 分离中 decode 路由仅考虑负载均衡，但对 MoE 模型不充分——每个 decode 步骤加载的专家权重不同，**同等负载的 worker 延迟可差异巨大**。

**核心创新**:
- 从请求的 prefill 专家激活构建 **expert signature**，预测生成阶段会激活哪些专家
- 离线 Balanced K-means 将签名空间分区到 decode worker；在线 locality-band 路由
- **Signature cache** 与 KV cache 同粒度共索引，prefix caching 下签名保持精确

**关键指标**（vLLM 实现，40 GPU 部署）:
- 跨三个 MoE 模型和两个工作负载，**TPOT 中值降 5.9–13.9%** vs 最强负载均衡基线
- 模型输出不变（无损路由）

> 📌 **趋势判断**: MoE 推理优化开始从"算力均衡"进入"访问模式感知"——ELDR 是首次将 expert activation pattern 纳入路由决策。

### 3. 3DLS: 3D 逻辑堆叠芯片架构分离 PD 流量
**arXiv:2607.01617** · 已录 IEEE CAL 2026

**为什么重要**: 2D/2.5D 芯片中 PD 分离的 KV 传输与 decode 侧 TP 集合通信共享同一横向 Die-to-Die 互连，**混合流量竞争**造成 decode 关键路径延迟。

**核心创新**:
- Logic-on-logic 3D 堆叠架构：KV Cache 传输走垂直互连，decode 侧 TP 集合通信保留在横向 D2D 互连
- 物理隔离而非优先级管理来解决流量竞争

**关键指标**:
- 共享基线对比：吞吐 **1.49×**、E2E 延迟 **降 60.2%**
- 优先级管理基线对比：仍保持吞吐 **1.17×**、延迟 **降 31.4%**
- 结论：物理隔离本身就有显著收益，优先级管理不能完全替代

> 📌 **趋势判断**: 首次从芯片架构层面为 PD 分离设计专用互连——给 PD 分离部署的硬件设计提供了新方向

## 📌 三大趋势

1. **MoE 并行策略进入"组合编排"时代** — MoP(按层组合并行) + Megatron Core Parallel Folding(多维度并行折叠) + UltraEP(精确负载均衡) + FEPLB(零成本 Copy Engine) = MoE 训练并行栈正在被全面重构

2. **PD 分离从系统层深入芯片层** — 3DLS(3D堆叠芯片) + SpectrumKV(逐Token精度分配) + ELDR(MoE 路由感知) = PD 分离已触达芯片架构、KV 传输协议和路由调度三个层面

3. **推测解码加速进入"组合创新"深水区** — DeLS-Spec(长短上下文解耦) + DominoTree(条件树形) + DSpark(置信度调度) 从不同角度攻克了传统块并行起草的接受率衰减问题，各有明确的性能-成本边界
