## 发现总览

- **CHIARA: 可配置分层 Allreduce**（2608.02884, 08-03, Polaris/Aurora/Fugaku）: 面向小/中消息域，用 batch-lane 拓扑编码硬件层级 + 分段调度（有界活跃 reduction vector）+ rotating-root lane 原语规避集中式 leader；半组合 Rabenseifner 布局跨 RS/AG 边界免重组。较 vendor MPI_Allreduce 提速 **1.94× / 13.43× / 13.48×**，并行 k-means 端到端 **2.2×**。https://arxiv.org/abs/2608.02884

- **CommBench: LLM 写 GPU 通信代码能力评测**（2608.04450, 08-05, UC Berkeley/微软系）: 100+ 专家级任务（p2p/集合通信/专家并行/算通融合/通信工具函数），参考实现来自专家或生产代码库蒸馏；抗作弊评估框架自动编译-执行-校验于多 GPU 系统，统一度量"功能正确+通信性能"。最强 GPT-5.5 仅 **30.7%** 任务正确且性能有竞争力——LLM 与专家级 NCCL/RDMA 代码差距显著，AI 辅助系统编程仍是开放挑战。https://arxiv.org/abs/2608.04450

- **HeteroPanacea: agentic 推理 PD-AF 分解仿真**（2608.03741, 08-04, 帝国理工/剑桥）: 三维仿真框架=分解量化 + 自动片内/片间并行调度 + PDAF NPU 架构异构；当前 GPU 下确认 PD 分解收益，吞吐最高 **+75%**；4-way PD-AF 全分解在跨模型上吞吐提升最一致（假设定制 NPU）。为异构集群（GPU+LPU 如 Vera-Rubin/Groq）的部件级硬件决策提供系统级仿真手段。https://arxiv.org/abs/2608.03741

- **MFU 作为 GPU 功耗代理的评估**（2608.03880, 08-04, MASCOTS'26 录用）: 现有功耗模型依赖硬件利用计数器（须真实运行后才存在），本文验证软件定义指标 MFU 能否作便携功耗预测器；**~3000 次单设备训练 runs × 6 款 GPU**，覆盖模型族/精度/batch/context。计算密集型（生产 LLM 训练）下线性 MFU 功耗模型拟合全部 GPU；按 (GPU, dtype, batch) 而非按 GPU 拟合，within-cell 平均误差 **~10% → ~1%**（触达跨重复测量噪声底）。https://arxiv.org/abs/2608.03880

- **SparseDitto: LLM 智能体定制稀疏 GPU Kernel**（2608.05033, 08-06, 东北大学/Northeastern）: LLM-based agentic system 为不同稀疏模式定制 GPU kernel，把"稀疏模式识别→kernel 定制"自动化；信号：稀疏训练/推理 kernel 生成进入 agent 化阶段（量化数据未获取，仅标题级信息）。https://arxiv.org/abs/2608.05033

- **KernelBrain: 预算感知的 Agentic GPU Kernel 搜索**（2608.02611, 08-05）: coarse-to-fine、budget-aware 的 agentic kernel 优化搜索——先粗筛候选再细优化，显式控制搜索预算；与 CommBench/SparseDitto 同属"agent 化 GPU 系统编程"信号（量化数据未获取，仅标题级信息）。https://arxiv.org/abs/2608.02611

## 趋势判断

- **集合通信进入"分层可配置"时代** — CHIARA 把硬件层级显式编码进拓扑（batch-lane）并用 rotating-root 摊薄 leader 瓶颈，与 08-05 NIXT 可观测性、Configurable Allreduce 形成"配置×观测"双翼；小消息域（Allreduce 长尾）成为优化新靶区。
- **GPU 系统编程 agent 化三连发** — CommBench（评测基准）× KernelBrain（搜索框架）× SparseDitto（agent kernel 定制）同日密集出现：LLM 写通信/kernel 代码的能力被系统化测量与增强，但 GPT-5.5 仅 30.7% 达标说明该领域仍是"AI 辅助"而非"AI 替代"。
- **能效建模从计数器走向软件定义** — MFU 线性功耗模型把"必须先跑才知道功耗"变成"MFU 即功耗"，per-cell 误差 ~1% 达到噪声底，为训练能耗仿真/调度提供零成本功耗代理。
- **异构分解仿真补位集群规划** — HeteroPanacea 为 GPU+LPU 异构集群的部件分工提供系统级仿真（PD 分解 +75%），训练侧异构（MFU 功耗代理）与推理侧异构（PDAF 分解）信号同频。
