## 今日发现

- **AI 数据中心"超越纯 GPU"：推理流水线解耦成三集群（P0）**（Semiconductor Engineering, 2026-08-05, Liz Allan 专家圆桌, Arm/Cadence/Expedera/Siemens EDA/Synopsys 参与）: Arm 首席 Bhattacharjee 指出推理正被解耦为 **prefill（计算极密集）→ decode（生成）→ agent tool calling/执行（可跑 CPU）** 三段，各配独立硬件+软件栈集群，经 Ethernet 拼接；NVIDIA 已推出 **Groq 3 LPU** 专用于 prefill 集群——"每个钉子不只有一个锤子（GPU）"成为行业共识，异构集群（GPU/NPU/CPU/ASIC 各司其职）将成常态；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **DigitalOcean 部署五层推理架构：异构集群降 token 成本（P0）**（Semiconductor Engineering, 2026-08-05）: 圆桌披露 DigitalOcean 宣布五层推理架构，底层明确混用 **AMD + NVIDIA + 新硬件**；目标直指提升效率、降低 token 成本；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **集群定义须匹配并行化范式拓扑（P1）**（Semiconductor Engineering, 2026-08-05, Expedera Chole）: tensor parallel（all-reduce+broadcast）、data/context/pipeline parallel 各需不同互联拓扑——tensor parallel 强依赖 NVLink 类高速互连，存储连接与内存传输同样受拓扑约束；1 GPU→8 GPU 保持接近 8× 性能仍是核心挑战；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **CPU 在 agentic 数据中心角色上升：orchestration + MCP 云管理化（P1）**（Semiconductor Engineering, 2026-08-05）: 复杂推理循环/上下文维护/分支路由等难并行任务由 CPU 承接，矩阵乘法归加速器；agentic 工作负载的 tool calling 编排变相成为云管理问题——MCP server 需响应式部署，与 UALink/NVLink 之外的"软件编排层"共同构成新瓶颈；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **加速器互联标准化时间窗：1-2 年内（P0，与历史归档互证）**（Semiconductor Engineering, 2026-08-05, Arm Bhattacharjee）: accelerator-to-accelerator 互联三路线并行——**NVLink（NVIDIA 专有）/ UALink（UA 联盟，多家支持）/ Google ICI（TPU 专有光互连）**；hyperscaler 自研芯片（TPU/MTIA/Maia）共同施压 NVIDIA 开放 NVLink，NVLink Fusion 仍锁 NVIDIA 生态；Arm 判断 **1-2 年内由 hyperscaler + AMD 推动走向标准化**——与 08-04 归档的 AMD Helios UALink 260TB/s 量产形态互证；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **Alibaba 10,000 卡集群：异构 workaround 被圆桌认可为现实路线（P1）**（Semiconductor Engineering, 2026-08-05, Siemens EDA Brunner）: 圆桌首问即讨论 Alibaba 万卡集群（缺最新 NVIDIA 芯片的 workaround）；Siemens EDA 观点：硬件厂商/系统集成商正按"如何组网"设计方案，软件负责把负载放在互联利用率最高处，hyperscaler 的 placement group 概念（VM 高速互连聚合）是关键机制；来源: https://semiengineering.com/ai-data-centers-look-beyond-just-gpus/
- **科华数据 HVDC 中国市场地位（弱信号，聚合源待验证）**（china-datacenter.com 聚合, 2026-08-03）: 第三方聚合站援引行业排名称科华数据为中国高压直流（HVDC）电源模块出货量第一、HVDC 电源系统互联网行业销售额第一；供电生态信号，但非一手源，量化数据需厂商/协会源交叉验证后方可采用；来源: https://www.china-datacenter.com
