## 1️⃣ 🔥 Micron 9650 — 首款 PCIe Gen6 数据中心 SSD，28GB/s E1.S 需液冷

**来源**: [ServeTheHome - Spotted at Computex 2026: Micron's First PCIe Gen6 Data Center SSD, the 9650](https://www.servethehome.com/spotted-at-computex-2026-microns-first-pcie-gen6-data-center-ssd-the-9650/) (Ryan Smith, July 5, 2026)

### 📊 性能规格

| 指标 | Micron 9650 Gen6 | Micron 9550 Gen5（对比基线） | 提升 |
|:-----|:---------------|:-------------------------|:----|
| **接口** | PCIe Gen6 x4 | PCIe Gen5 x4 | 2× 接口带宽 |
| **顺序读** | **28 GB/s** | ~14 GB/s | **2×** |
| **随机读 IOPS** | **5.5M** | ~3.3M | +67% |
| **顺序写** | **14 GB/s** | — | — |
| **随机写 IOPS** | 900K | — | — |
| **TDP** | **25W**（性能测度基准） | ~22W | +3W |
| **最大容量** | **30.72TB**（PRO 读优化）/ 25.6TB（MAX 混合负载） | — | — |
| **NAND** | 第9代 TLC @ **3600 MT/s** | — | — |

### 🔬 关键设计决策

| 方面 | 细节 |
|:-----|:------|
| **控制器** | Micron 自研 **首代 PCIe Gen6 控制器** |
| **NAND 节点** | G9 TLC @ 3600 MT/s — 增益主要来自控制器而非NAND本身 |
| **定位** | **读优化偏向** — AI推理/训练的存储I/O瓶颈场景 |
| **E1.S 散热** | **必须液冷**（Micron表述 "optimized" 而非 "compatible"） |
| **目标客户** | 搭配GPU服务器的超大规模数据中心 |
| **量产状态** | **已量产**（但尚无可用Gen6服务器平台） |

### ⚠️ 平台成熟度瓶颈

> **关键约束**: PCIe Gen6 服务器平台尚未批量出货。NVIDIA/AMD 预计 **2027年** 才推出Gen6服务器。Intel Xeon 7 Diamond Rapids 走不同更新路径。Arm AGI CPU（见下文）是首批支持 PCIe Gen6 的服务器CPU之一。

## 📋 本周综合趋势判断

1. **PCIe Gen6 存储先行，平台滞后**: Micron 9650 已量产但无 Gen6 服务器可用 → Arm AGI 和 Intel Diamond Rapids 将是首批量产 Gen6 平台（2027年前后）
2. **Arm 在服务器市场质变**: 从 IP 授权到自研 SoC，136核 AGI + ASRock Rack 的 OEM 落地 + Meta 为客户，Arm 服务器进入全新阶段
3. **EPYC Venice (N2) 是 2026 年最大服务器CPU升级**: TSMC N2 GAAFET + 256核 + Gen6 I/O，Dell 将推出 **10款以上** Venice 机型
4. **液冷从 "可有可无" 到 "必须"**:
   - Micron Gen6 SSD E1.S → 液冷优化
   - Dell M9825 → 全液冷 blade
   - Dell IR7000 → 480kW/rack
   - 不仅 GPU 需要液冷，连 SSD 和配电汇流排都在转向液冷
5. **HBM4 产能紧张持续到 2027+**: HBM 产能被 AI 客户锁定，连 FPGA/存储等非 GPU 领域都受影响；Samsung 试图通过代工关系挽回 HBM 竞争地位
