## 1️⃣ 🔴 NVIDIA Vera CPU 深度架构揭秘 — Olympus 核心白皮书全解析

**来源**: ServeTheHome — Ryan Smith, Jul 21 [原文](https://www.servethehome.com/diving-deeper-on-nvidias-vera-cpu-new-architectural-details-and-spec-cpu-2026-benchmarks/)

NVIDIA 于 7/21 发布 Vera CPU 完整架构白皮书，这是其自研 Olympus CPU 核心迄今为止最详尽的技术披露。

### 🎯 核心规格对比

| 规格 | Grace (Neoverse V2) | Vera (Olympus) | 提升 |
|:-----|:-------------------|:---------------|:----:|
| CPU 核心数 | 72 | **88** | +22% |
| 线程 | 72 (no SMT) | **176 (Spatial MT)** | 2.4x |
| L2 缓存/核 | 1MB | **2MB** | 2x |
| L3 缓存(统一) | 114MB | **164MB** | +44% |
| 内存带宽 | 512GB/s LPDDR5X | **1.2TB/s LPDDR5X-9600** | 2.3x |
| 内存容量 | 480GB | **1.5TB** | 3.1x |
| NVLink-C2C | 900GB/s | **1.8TB/s** | 2x |
| PCIe/CXL | Gen5 | **Gen6 / CXL 3.1** | 换代 |
| TDP | 250W | **250-450W** | — |

### 🏗️ 微架构亮点

- **取指与解码**: 16指令/cycle 取指队列 → 48指令队列 → **10-wide 解码器**
- **L1 缓存**: 64KB L1I (4-way) + 96KB L1D (6-way) — L1I 为 Zen 5 的 2 倍
- **执行管线**: **18 条** (8 整数 + 6 向量/SVE2 + 4 加载 + 2 存储)
  - 整数: 8 ALU 管线，其中 2 条复杂(乘除/CRC/移位)
  - 向量: 6 路 SVE2 FP8，2 路可处理加密运算
- **乱序引擎**: Memory Renaming (类似 AMD 近期设计) + Value Prediction + Move Elimination
- **新型图预取器 (Graph Prefetcher)**: 针对指针密集/间接寻址内存模式，识别生产者-消费者指针关系后提前预取目标数据 — 业界首创，AMD/Intel 尚无对应实现
- **Spatial Multithreading**: 88 核可同时运行 176 线程，SMT 基于分区配对设计

> 白皮书包含 SPEC CPU 2026 结果，这是 Vera 首次公开标准性能数据。Patrick Kennedy 在后续文章中做了归一化分析（见条目2）。

## 2️⃣ 🟠 Vera vs Turin 归一化框架 — Patrick Kennedy 拆解 NVIDIA 基准测试偏置

**来源**: ServeTheHome — Patrick Kennedy, Jul 22 [原文](https://www.servethehome.com/normalizing-nvidia-vera-benchmarks-to-amd-epyc-turin-a-framework/)

Kennedy 针对 NVIDIA Vera 白皮书中以 AMD EPYC Turin (9755) 为对比基准的情况，提供了行业惯用的归一化分析框架，揭示三大偏置：

### 偏置1: 内存带宽每核比较 — 分母操纵

- NVIDIA 图示: Vera **12.7GB/s** 每核 vs Turin **3.1GB/s** 每核（~4x 差距）
- **问题**: 用 Vera 的 **88 核** 做分母，Turin 的 **128 核** 做分母 — 45% 更大的分母
- 若改用 96 核 EPYC 9655 做分母，差距显著缩小
- 更关键的是: **Vera 是 2026 CPU + 2026 内存子系统 vs Turin 是 2024 CPU + 2022 内存子系统**
- AMD Venice (2026): **16ch, 1.6TB/s** — 将对 Vera 的 1.2TB/s 实现反超

### 偏置2: 核间延迟 — 单晶片优势边界

- Vera 的 monolithic 设计在 **88 核以内** 核间延迟确实优于 chiplet
- **超 88 核后反转**: Vera 的双路 128 核场景中，40 个核走 socket-to-socket 互联
- 超 176 核: 跨越 PCIe → NIC → Switch → NIC → PCIe 多层跳转
- 对 Agentic AI 负载 (1-4 核/VM)，核间延迟基本不成为瓶颈

### 偏置3: SMT 的隐式忽略

- **33% 差距**: Zen 5 SMT 第二线程贡献 ~32-33% 性能
- "单线程" ≠ "单核心": 若 Vera 无 SMT 而 EPYC 有，每核性能基数不同
- 建议行业统一采用 **per-socket** 而非 per-core/per-thread 作为比较基准

> **Kennedy 结论**: Vera 的单核性能确有优势，但 NVIDA 的 4x 叙事过度放大了代际差。AMD Venice 发布后需用同一代内存/同一代晶圆工艺做公平对比。

## 3️⃣ 🟢 Intel Xeon 6 中期升级: DDR5-8000 RDIMM + MRDIMM Gen2 兼容

**来源**: ServeTheHome — Ryan Smith, Jul 20 [原文](https://www.servethehome.com/intel-to-add-support-for-gen-2-mrdimms-and-faster-ddr5-rdimms-to-xeon-6-platform/)

Intel 于 7/20 宣布 Xeon 6 (Granite Rapids) 获得罕见的 **生命周期中期内存升级**：

### Xeon 6700P: DDR5-8000 RDIMM 支持 (2026年8月起)

- 从 DDR5-6400 提升至 **DDR5-8000**，纸面带宽 +**25%** (51.2→64.0 GB/s 每通道)
- Intel 实测: 内存带宽 +**20%**，综合负载提升 3-6%
- 延迟: JEDEC 规格 14.0ns vs DDR5-6400 的 14.38ns (降低 ~3%)
- **仅限 1DPC 操作** — 2DPC 仍限于 DDR5-5200，1DPC/2DPC 带宽差距进一步拉大
- 仅限"选定" Xeon 6700P SKU（已在 MRDIMM 下验证过 DDR5-8000 的芯片）
- 技术基础: Granite Rapids 内存控制器本就是为 MRDIMM (DDR5-8000) 过设计，RDIMM 升级是"复用余量"

### Xeon 6900P: MRDIMM Gen2 兼容 (2027 Q1)

- **不提升速度**: 仍限于 8800 MT/s (Gen1 速度)，因 Granite Rapids 内存控制器已无余量
- 核心价值: **生态延续性** — 确保 Xeon 6 和 Xeon 6+ (Clearwater Forest) 共用 MRDIMM Gen2 供应线
- 背景: Micron 已 **EOL** Gen1 MRDIMM，行业向 Gen2 转产

### 战略解读

- 时间点选择在 **AMD Advancing AI 2026 当周** 发布 — 明确的对 AMD Venice 的阻击
- Granite Rapids 到 Diamond Rapids (2027) 的过渡期内，一次罕见的中代提速

## 4️⃣ 🟢 MSI EPYC Venice 平台首次公开: 1OU2N 液冷、16ch、PCIe Gen6、100kW/rack

**来源**: ServeTheHome — Ryan Smith, Jul 19 [原文](https://www.servethehome.com/msi-slyly-shows-off-an-upcoming-dlc-amd-epyc-venice-platform-with-cd182-s6091-x2-servers-and-racks/)

MSI 在 Computex 2026 低调展出了基于 AMD EPYC "Venice" 的下一代高密度服务器平台：

### MSI CD182-S6091-X2 (DLC)

| 规格 | 参数 |
|:-----|:-----|
| 形态 | **1OU2N** (1 OCP 单元内 2 个独立节点) |
| CPU 规模 | **每节点 2× Venice** → 每机箱 4× Venice CPU |
| 内存 | **16ch DDR5/CPU**, 1DPC — 每节点 32 DIMMs |
| 互联 | **PCIe Gen6** x16 插槽 + OCP 3.0 NIC 槽 |
| 存储 | 4× E1.S Gen6 (Micron 9650 级别) |
| 散热 | **Direct Liquid Cooling (DLC)** — CPU 独立回路 + 内存独立回路 |
| 供电 | **48VDC Busbar** (无板上 PSU) |
| BMC | **ASPEED AST2700** (下一代 BMC) |

### MSI ORv3 液冷机架

| 规格 | 参数 |
|:-----|:-----|
| 高度 | **44OU** (OCP v3 标准) |
| 节点容量 | **28 台服务器** |
| CPU 总量 | **112× Venice CPU** + **1792 DIMMs** |
| 整机功耗 | **100kW/rack** |
| 供电 | 2× 55kW Chicony 电源架 → 48VDC Busbar |
| 散热 | 100kW Auras CDU (液对液) |
| 网络 | 1× 32-port 100GbE + 2× 1GbE 管理交换机 |

### 技术信号

1. **Venice 平台完整度确认**: 16-ch DDR5(1.6TB/s)、PCIe Gen6、DLC — 平台已通过 ODM 验证
2. **液冷成为标配**: CPU+内存双回路液冷证明 TDP 已远超风冷能力
3. **48VDC Busbar 供电**: 无 PSU 设计 = 去中心化供电趋势在机柜级别加速
