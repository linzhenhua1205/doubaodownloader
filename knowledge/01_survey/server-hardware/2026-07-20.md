## 1. 🔴 MSI AMD EPYC "Venice" 平台首次公开：1OU2N 液冷、16-ch、PCIe Gen6、100kW/rack

**来源**: ServeTheHome, Ryan Smith, 2026-07-19
**链接**: https://www.servethehome.com/msi-slyly-shows-off-an-upcoming-dlc-amd-epyc-venice-platform-with-cd182-s6091-x2-servers-and-racks/

### 背景
AMD 第六代 EPYC "Venice" 平台预计 **2026年下半年** 正式发布。MSI 在 Computex 2026 上"犹抱琵琶半遮面"展示了基于 Venice 的完整服务器与机架方案。

### MSI CD182-S6091-X2 (DLC) 服务器节点

| 规格参数 | 详细数据 | 备注 |
|:---------|:---------|:-----|
| 形态 | 1OU2N（1U OCPv3 机箱，2个双路节点） | 每个节点双路 |
| 每节点 CPU | 2× AMD EPYC Venice（未公布具体 SKU） | **每 1U 共 4 颗 Venice** |
| 内存每节点 | **32× RDIMMs** / 16-ch **1DPC** | 双 CPU × 16-ch = 32 DIMMs |
| 内存冷却 | 独立液冷回路 | CPU 之外内存也液冷 |
| CPU TDP | 未公布，但前代 EPYC 已高达 **500W** | Venice 16-ch 只会更高 |
| PCIe | **PCIe Gen6** | OCP 3.0 NIC + FHHL + HHHL 均为 Gen6 x16 |
| 本地存储 | 4× E1.S（PCIe Gen6） | 支持 Micron 9650 等 Gen6 SSD |
| BMC | **ASPEED AST2700** | 下一代 BMC 平台 |
| 供电 | **48VDC busbar**（无板载 PSU） | 机架级供电 |
| 液冷 | **DLC（Direct Liquid Cooling）** | CPU 串行冷板 + 内存独立回路 + 漏液检测 |

**关键设计特征**：

1. **直接液冷（DLC）全覆盖**：CPU 冷板串行连接、内存单独液冷回路。液冷从"可选"变为"必要条件"——MSI 官方表述："air reaching its limits"
2. **漏液检测电路**：CPU 冷板配备 leak-detection，具体能力未披露
3. **48VDC busbar 供电**：节点内无 PSU，依赖机架级 busbar 供电，减少空间占用
4. **ASPEED AST2700**：新一代 BMC，首次在 Venice 平台出现

### MSI ORv3 液冷整机柜

| 规格 | 数据 |
|:----|:-----|
| 机柜标准 | OCP ORv3，44OU |
| 节点数量 | **28× CD182-S6091-X2** |
| 总 CPU | **112× AMD EPYC Venice** |
| 总 DIMM | **1,792× RDIMMs** |
| 整机功耗 | **100kW** |
| PSU | 2× Chicony **55kW** power shelves → busbar |
| CDU | **100kW Auras** CDU（液对液） |
| 网络 | 1× 32-port 100GbE（数据）+ 2× 48-port 1GbE（管理） |

### 平台级性能数据推算

| 对比维度 | Current EPYC 9005 (Turin) | EPYC Venice (6th gen) | 提升 |
|:--------|:-------------------------|:---------------------|:----:|
| 内存通道 | 12-ch DDR5-6400 | **16-ch** DDR5-8000 / MRDIMM Gen2 | **+33% 通道 / +25% 速率** |
| 总带宽 (MRDIMM Gen2) | ~0.6 TB/s | **~1.6 TB/s** | **2.67x** |
| PCIe | PCIe Gen5 | **PCIe Gen6** | **2x 每通道速率** |
| 制程 | TSMC 3nm/4nm? | **TSMC 2nm**（已确认 May 21 AMD PR） | — |
| BMC | AST2600 | **AST2700** | 新一代管理平台 |
| 每 rack CPU 数 | ~56-84 (视密度) | **112 Venice** | 密度进一步提升 |

**STH 的行业观察**：
> "液冷已成为 Computex 2026 服务器展台的普遍主题。系统 TDP 持续攀升，风冷接近极限，液冷正成为实现更高性能密度的必要条件。"

## 2. 🟢 Micron 6600 ION 245TB SSD：QLC NAND 单盘近 1/4 PB

**来源**: ServeTheHome, Cliff Robinson, 2026-05-05
**链接**: https://www.servethehome.com/micron-6600-ion-245tb-ssd-announced/
**注**: 虽非最新发布，但对于理解 AI 数据中心存储密度上限有重要参考价值

### 规格详情

| 参数 | 数据 |
|:----|:-----|
| 型号 | Micron 6600 ION |
| 容量 | **245.76 TB** |
| NAND | Micron **G9 QLC** |
| 接口 | PCIe Gen5 x4 |
| 形态 | E3.L / U.2 |
| 顺序读 | **13.7 GB/s** |
| 顺序写 | 3.0 GB/s |
| 随机读 IOPS | **1.78M** |
| 最大功耗 | **30W** |

### AI 数据中心存储密度推算

| 配置 | 数据 | 对比 |
|:----|:----|:-----|
| 1U E3.L 全闪 | >**3.9 PB** | — |
| 36U 整机柜 (E3.L) | **176.9 PB** | — |
| 1EB 部署 (vs 44TB HDD) | **5.6x 机架空间节省** | 1EB 从 22 racks → 4 racks |
| 1EB 部署功耗对比 | ~**30W/盘 vs HDD 堆叠** | 大幅降低 TCO |

### 对服务器架构的影响

- QLC Gen5 SSD 以 245TB/盘将 **HDD 从近线存储全面挤出**，AI 数据湖的冷/温层也可全闪
- E3.L 形态使 1U 可部署 3.9PB，**存储密度正在赶超计算密度**
- 配合 Venice 平台的 PCIe Gen6 支持，未来容量点可能进一步突破 500TB+

## 📊 本周核心信号总结（7/20版）

1. **AMD Venice 平台首次实物曝光**：MSI CD182-S6091-X2 (DLC) 揭示了 Venice 的关键架构特征——16-ch 内存、PCIe Gen6、ASPEED AST2700 BMC。液冷已从"可选项"变为"必要条件"，连内存也需要独立液冷回路
2. **MSI ORv3 全液冷机柜达 100kW/112 CPU**：28节点 × 4 Venice = 112 颗 CPU + 1,792 DIMMs。这为 Venice 平台商用后的**超高密度 AI 训练/推理集群**提供了参考设计
3. **QLC SSD 密度突破**：245TB/盘、3.9PB/1U、177PB/rack，存储密度革命使 AI 数据湖全闪存化成为现实可行
4. **DRAM 成本压力**：内存价格"异常偏高"的声明暗示下半年服务器平台换代与 AI 需求增长将面临持续的 DRAM 供应成本压力
