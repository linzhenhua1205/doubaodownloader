## 1. 🔴 NVIDIA Vera CPU 深度架构揭秘：Olympus 核心白皮书 + SPEC CPU 2026 基准测试首曝

**来源**: ServeTheHome, Ryan Smith, 2026-07-21
**链接**: https://www.servethehome.com/diving-deeper-on-nvidias-vera-cpu-new-architectural-details-and-spec-cpu-2026-benchmarks/

### 背景
NVIDIA 于 7/21 发布 Vera CPU 全面架构白皮书，这是自 GTC 2026 发布以来最深入的技术披露，同时首次公开 **SPEC CPU 2026** 行业标准性能数据。同一天，NVIDIA 还发布了 Vera Rubin 性能/能效数据、Spectrum-6 交换机信息以及 Rubin GPU 架构细节。

### Grace → Vera 规格对比

| 特性 | Grace (Arm Neoverse V2) | Vera (NVIDIA Olympus) | 提升 |
|:-----|:-----------------------|:---------------------|:----:|
| CPU 架构 | Arm Neoverse V2 | 自研 **Olympus** | 完全自研 |
| 核心数 | 72 | **88** | +22% |
| 线程 | 72 (no SMT) | **176 (Spatial Multithreading)** | 2.44x |
| L2 缓存/核 | 1 MB | **2 MB** | 2x |
| L3 缓存 (统一) | 114 MB | **164 MB** | +44% |
| 内存带宽 | 512 GB/s (LPDDR5X) | **1.2 TB/s** (LPDDR5X) | 2.34x |
| 内存容量 | 480 GB | **1.5 TB** | 3.13x |
| SIMD | 4× 128b SVE2 | **6× 128b SVE2 FP8** | +50%，新增 FP8 |
| NVLink-C2C | 900 GB/s | **1.8 TB/s** | 2x |
| PCIe/CXL | Gen5 | **Gen6 / CXL 3.1** | 2x 速率 |
| TDP | 250W | **250-450W** | up to 1.8x |

### Olympus CPU 核心架构深度解析

**前端 (Front-End)**：
- **10-wide 解码器**（对比 AMD Zen 5 的 8-wide、Intel Cougar Cove 的 10-wide）
- 指令取指单元每周期可喂入 **16 条 64-bit 指令** 至解码队列
- 解码队列容量 **48 条指令**
- **神经分支预测器**：每周期 2 个分支、高精度，目标减少分支预测失败性能损失
- L1 指令缓存：**64 KB, 4-way**（Zen 5 的 2 倍，等于 Cougar Cove）
- L1 数据缓存：**96 KB, 6-way**

**中核 (Mid-Core / OoOE Engine)**：
- 每周期可重命名 **10 个 micro-ops**
- **Memory Renaming**（类似 AMD 近期设计）：在 load 完成前就执行依赖指令（前提是能预测/判定数据关系）
- **Value Prediction**：通过识别重复模式推测值，在结果生成前就继续执行（后续验证）
- **Move Elimination**：消除不必要的内存值移动

**后端 (Backend)**：
- **18 条执行流水线** —— 极其庞大的后端

| 执行单元类型 | 流水线数 | 详细能力 |
|:-----------|:--------:|:--------|
| **整数 (ALU)** | **8 条** | 2 条复杂 ALU（mul/div/CRC/bit shift），6 条简单 ALU（add/sub/logical） |
| **向量/浮点 (SVE2)** | **6 条** | 每条支持 SVE2 向量，新增 **FP8** 低精度支持；2 条可消费加密向量操作（AES/SHA） |
| **Load 单元** | **4 条** | 2 条纯 load + 2 条 load/store 共享 |
| **Store 单元** | **2 条** | 专用 store 流水线 |

**关键时序数据**：
- 基本 ALU 操作：**1 周期**
- 乘法：**2 周期**
- 除法：**5-20 周期**（视迭代次数）

### Scalable Coherency Fabric (SCF) 2 — Vera 片内互联

- **Vera 采用功能异构 Chiplet 设计**（与 AMD/Intel 的核心拆分式不同）：CPU core chiplet + I/O chiplet + 内存控制器 chiplet 分离
- 每个计算 chiplet 分为 **4 个象限**，每象限由 1 个 **Coherency Switch Node (CSN)** 串联
- 每 CSN 管理：2× 11 核集群 + 2× 20.5MB L3 分片 + 1 个 Memory Switch Node → 内存控制器 + 1 个 Bridge Switch Node → I/O
- SCF 总带宽：**3.4 TB/s**（外部内存子系统带宽的 2.8 倍）
- **核心间延迟**：大多在 **40ns 以内**，仅少量跨极配对超过 80ns——片内一致性延迟控制优秀

### SPEC CPU 2026 基准测试性能数据

**单线程整数性能 (1T) — Vera 领先明显**

NVIDIA 展示了 SPECrate2026_int_1T 对比数据（对比 AMD EPYC 9755 "Turin"，128核 Zen5 @ 4.1GHz，500W）：

| 测试项 | Vera vs EPYC 9755 | 备注 |
|:------|:-----------------|:-----|
| 所有整数子项 | **Vera 全线领先** | 单核 IPC 怪兽级表现 |
| 单核 IPC 优势来源 | **指令取指 ops/cycle: 1.9x-2.4x** | 10-wide + 神经分支预测的效果 |
| 后端 ops/cycle | **2.3x-4.3x** 优势 | 18 条流水线的回报 |
| Graph PageRank 核心扩展 | **Vera 29.3x @ 32核** vs EPYC ~10x | 图预取器的直接效果 |

⚠️ **专业提示**：EPYC 9755 并非 AMD 单线程性能最强的 SKU（F 系列可达 5.0 GHz），此对比偏向 Vera 优势场景。

**多线程吞吐量 (nT) — Vera 仅持平**

| 系统 | SPECrate2026_int_base | 备注 |
|:----|:---------------------|:-----|
| Dual-socket Vera (88核×2) | **925** | NVIDIA 官方数据 |
| Dual-socket EPYC 9755 (128核×2) | **898** | NVIDIA 对比数据 |
| Dual-socket EPYC 9755 (AMD 编译器优化) | **>1000** | SPEC 官方数据库 |
| Dual-socket EPYC 99xx Turin Dense (192核×2) | **>1200** | 更高核数配置 |

**关键结论**：Vera 的 88 核心在 **多线程吞吐量仅领先 Turin 3%**，落后 Turin Dense (192核) 约 **30%**。NVIDIA 未发布浮点性能数据。

### STH 评论 — 竞争定位分析

> "Vera 是一颗为**高单核 IPC**优化的 CPU，代偿是总吞吐量不及高核数竞品。但真正的问题是：Vera 上市时（2026下半年）将直面 AMD EPYC **Venice**（Zen6, 16-ch DDR5-12800, 最高 256 核/插槽），届时 Vera 88核的单核优势能否抵消核心数差距存疑。"

**关键时间轴**：
- 当前：Vera vs Turin / Turin Dense → Vera 单核胜，多核劣势明显
- 2026H2：Vera vs Venice (Zen6) → **待比较**
- 2027：Diamond Rapids (Intel) + Venice 完全铺开 → Vera 窗口期窄

**积极面**：Vera 作为 Grace 的替代者，在 **Vera Rubin 生态系统**（NVLink-C2C 1.8TB/s + Rubin GPU + NVSwitch）中定位清晰——作为 GPU companion 而非通用 CPU 与 Intel/AMD 正面竞争。

## 📊 今日核心信号总结

1. **Vera CPU 架构全面公开**（7/21 "NVIDIA Day"）：Olympus 核心 18 执行流水线、10-wide 解码器、图预取器、3.4TB/s SCF 片内互联——这是一颗定位为 **IPC 怪兽**的 CPU，在单线程性能上全面领先当前竞品，但 88 核的上限使多线程吞吐量仅持平 Turin 并落后 Turin Dense ~30%
