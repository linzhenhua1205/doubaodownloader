## 1️⃣ 🟢 NVIDIA Vera Rubin 全面投产 — TSMC 3nm，秋季出货

**来源**: [ServeTheHome — NVIDIA Computex 2026 News Bytes: Vera Rubin Now In Production](https://www.servethehome.com/nvidia-computex-2026-news-bytes-vera-rubin-now-in-production-dgx-station-gets-windows/) (Ryan Smith, June 1, 2026)

### 📊 关键规格

| 维度 | 规格 |
|:-----|:-----|
| **Vera CPU** | 88核 Olympus 架构自研CPU核心 |
| **Rubin GPU** | 新一代 Rubin 架构 GPU |
| **制程工艺** | **TSMC 3nm**（比 Grace Blackwell 的 N4 领先一代） |
| **系统平台** | NVIDIA HGX Vera 平台 |
| **当前状态** | **全面量产中 (full production)** |
| **出货时间** | **2026年秋季开始** |

### 💡 技术要点

- Vera Rubin 是 NVIDIA 下一代服务器基础设施的骨干
- Vera CPU 88核基于 NVIDIA 自研 Olympus 核心，标志 NVIDIA 从 ARM Neoverse 向自研 CPU 核心的过渡
- 秋季出货意味着 Vera Rubin 系统将在年底前进入 hyperscaler 数据中心
- 与 Vera Rubin 配套的 **PCIe Gen6 SSD**（Samsung PM1763 / Micron 9650）也已进入量产，形成端到端 Gen6 生态

## 2️⃣ 🟢 Intel Xeon 6+ Clearwater Forest 正式出货 — 288 E-cores, Intel 18A

**来源**: [ServeTheHome — Intel Xeon 6+ Clearwater Forest is Out](https://www.servethehome.com/intel-xeon-6-clearwater-forest/) (Patrick Kennedy, June 1, 2026)

### 📊 关键规格

| 维度 | Xeon 6990E+ | 对比 Xeon 6780E (上代) |
|:-----|:-----------|:---------------------|
| **核心数** | **288 E-cores** (无SMT) | 144 E-cores |
| **制程** | **Intel 18A** (RibbonFET + PowerVia) | Intel 3 |
| **内存** | **DDR5-8000**, 12通道, 最大1.5TB | DDR5 |
| **L3缓存** | **576 MB** LLC | 108 MB |
| **TDP** | **450W** (< 2W/core) | — |
| **封装** | 12计算tile + 3 base tile + 2 I/O tile + 12 EMIB tile | 单die |
| **3D封装** | Foveros Direct 3D | — |
| **平台** | Xeon 6900 series AP (与Granite Rapids同平台) | — |

### 📈 性能对比数据

| 指标 | 数值 | 对比对象 |
|:-----|:----|:---------|
| 性能提升 | **2.26×** 平均性能 vs Xeon 6780E (144核→288核) | 同代/同架构 |
| 能效提升 | **1.55×** 性能/瓦 vs Xeon 6780E | 同代/同架构 |
| 每核性能提升 | ~**13%** (扣除核心翻倍) | 同代/Zen5→Darkmont |
| vs AMD EPYC 9965 | **1.3×** per-thread, **1.3×** per-thread/watt | 288核vs192核(384线程) |
| vs Sierra Forest (telco) | **30%** 更高性能, **60%** 更好能效比, **38%** 机架功耗降低 | 同核心数 |
| 加密加速(SHA512/SM3) | **6.2×** vs EPYC 9965, **15.2×** vs Xeon 6780E | 新生代指令集 |
| 服务器整合比 | **1 rack 替换 48 racks** of Xeon 6258R (2nd Gen) | 跨代对比 |

### 💡 技术要点

- **Intel 18A 首次在数据中心处理器上量产**，RibbonFET (GAA) + PowerVia (背面供电) 双技术里程碑
- 288核全E-core设计，主攻云原生/电信/高密度工作负载
- 与 Granite Rapids (P-core) 同平台兼容，OEM支持通常是 BIOS 更新即可
- AET (Application Energy Telemetry) 新特性：per-application 核心能耗监控，用于 workload placement 和成本分摊

## 3️⃣ 🟢 Samsung PM1763 PCIe Gen6 企业级 SSD 量产 — 28.4 GB/s 读

**来源**: [ServeTheHome — Samsung PM1763 PCIe Gen6 Enterprise SSD in Production](https://www.servethehome.com/samsung-pm1763-pcie-gen6-enterprise-ssd-in-production/) (Cliff Robinson, July 8, 2026)

### 📊 性能规格

| 维度 | PM1763 (Gen6) | PM1753 (Gen5, 上代) | 提升 |
|:-----|:-------------|:--------------------|:-----|
| **顺序读** | **28,400 MB/s** | ~14,000 MB/s | **2×+** |
| **顺序写** | **21,900 MB/s** (16TB配置) | ~7,000 MB/s | **3×+** |
| **闪存** | 第9代 V-NAND | 第7代 V-NAND | 新代际 |
| **控制器** | **新开发 4nm 控制器** | — | 制程领先 |
| **容量** | 4TB / 8TB / **16TB** | 建议 | — |
| **外形** | E3.S (液冷优化) | — | — |
| **安全** | PQC (后量子密码学) + TDISP | — | 新增 |

### 💡 技术要点

- **40GB LLM 模型传输仅需 ~1.4秒**（基于28.4GB/s读速），大幅降低 AI 推理中的数据加载延迟
- **液冷优化设计**：新一代 AI 服务器正向全液冷演进（移出风扇），SSD 必须支持液冷 Thermal 设计
- **PQC 后量子加密**：首次在企业 SSD 中支持，面向长时间部署需求
- 首发面向高性能本地存储市场（而非高容量冷存储），与 PCIe Gen4→Gen5 过渡策略一致
- **Micron 9650 同期发布**（Computex 2026 展示）：28GB/s 顺序读、5.5M IOPS 随机读，最高30.72TB，同样需要液冷

## 4️⃣ 🟢 AMD EPYC Venice (SP7) — HPE Cray GX5000: 81920 核/机架

**来源**: [ServeTheHome — 81920 Cores Per Rack with AMD EPYC Venice at HPE Discover 2026](https://www.servethehome.com/81920-cores-per-rack-with-amd-epyc-venice-at-hpe-discover-2026/) (Patrick Kennedy, June 17, 2026)

### 📊 系统规格

| 维度 | 参数 |
|:-----|:-----|
| **处理器** | 8× AMD EPYC "Venice" CPU 每 blade (GX250a) |
| **核心密度** | **81,920 CPU 核心/机架** (36 blades × 8 sockets × 284.4 cores/socket?) |
| **互连** | HPE Slingshot 400 (当前) / **Slingshot 800** (未来升级) |
| **液冷** | 全液冷 Blade：CPU coldplate + DIMM 冷却 + 液冷管路 |
| **CDU** | **1.6 MW** 单 CDU 冷却能力 |
| **SSD** | Samsung E1.S EDSSF 局部高速暂存，安装在 CPU coldplate 上方 |
| **内存** | 16通道 DIMM 每 Venice socket，MRDIMM |
| **功耗密度** | ~**250-320 kW/rack** (含网络 40U) |
| **状态** | **工作系统** (Vanover VP1-01 标签确认非静态模型) |

### 💡 技术要点

- 相比当今 8,000 核/rack 的空冷密度，**Venice Cray GX5000 达到约 10× 密度提升**
- SP7 socket 功耗范围 700W-1,400W，单 rack 功耗达 250-320kW（数据中心配电新挑战）
- Slingshot 800 未来升级路径已预留，NIC pod 设计支持热插拔
- 用于 Los Alamos 国家实验室 "Mission" 超算（与 NVIDIA 合作）
