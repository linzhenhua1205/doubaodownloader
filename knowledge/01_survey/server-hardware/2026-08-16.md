## FMS 2026 存储硬件

- **ServeTheHome/Supermicro ASG-4116S-NU160R 160盘位 NVMe 4U 服务器**（08-14, FMS 2026）: 单路 AMD EPYC + 160x U.2 NVMe 盘位，配 122.88TB 级 SSD（Solidigm D5-P5336）可实现**单系统约 20PB 存储**；160 盘 x4 lanes = 640 PCIe lanes（不含 NIC），用 **PCIe switch 替代 SAS expander** 扩展（SAS 式 top-loading 拉出托盘，SSD 层在上、CPU/内存/网络层在下，免整机拉出维护）；另含 4x E1.S bay + 2x 10Gbase-T（Broadcom BCM57416）。URL: https://www.servethehome.com/160-bay-nvme-ssd-4u-server-shown-at-fms-2026-supermicro-asg-4116s-nu160r/

- **ServeTheHome/DapuStor R6060 512TB E2 NVMe SSD**（08-05, FMS 2026）: **512TB 单盘 QLC**（E2 格式，比 E3.L 加几 mm 深宽容纳更多 NAND），显著大于 E3.S/U.2 的 256TB 上限；36 个 E2 盘位服务器即可**单系统 16PB**——E2 格式价值=单 CPU/双 CPU 服务器挂更多容量，减少内存/机箱/主板数量摊薄每 TB 成本与功耗；需求侧由训练数据/推理缓存读/视频音频驱动"容量>性能"。URL: https://www.servethehome.com/gigantic-dapustor-r6060-512tb-e2-nvme-ssd-shown-at-fms-2026/

- **ServeTheHome/Kioxia CM10 系列 PCIe 6.0 企业级 SSD 首发**（08-01）: Kioxia 进入 PCIe 6.0 企业存储，BiCS FLASH Gen10 + **直液冷能力**（面向 KV cache / NVIDIA CMX context memory 等 AI 基础设施负载）；较 CM9 **顺序读 +92%、随机读 +85%**，针对万亿参数模型与百万 token 上下文；E3.S 7.5mm / E1.S 9.5/15mm（9.5mm 变体支持直冷），E3.S 双端口 HA；**2.5" 变体仍为 BiCS Gen8 TLC + PCIe 5.0**——印证 PCIe Gen6 电气要求下 U.2/U.3 向 EDSFF 转换趋势（STH 此前预警落地）。URL: https://www.servethehome.com/kioxia-cm10-series-launched-for-the-pcie-gen6-generation-of-ssds/

- **ServeTheHome/Kioxia GP1 10M IOPS SSD 现场运行**（08-07, FMS 2026）: 用 **SLC NAND（XL-FLASH gen 2）**实现**单盘 10M 随机读 IOPS**（512B block），耐久 **50 DWPD**，现场以 >10M IOPS 实时跑分展示；目标明年达**单盘 100M IOPS 量级**；E3.S/E1.S 9.5/15mm 全气冷 + 9.5mm 变体冷板液冷——超高速存储层（fast tier）承接 DRAM 部分任务，性能优先于容量。URL: https://www.servethehome.com/a-10m-iops-kioxia-gp1-ssd-shown-running-at-fms-2026/

## 互联与交换硬件

- **ServeTheHome/Microchip Switchtec PFX 160xG6 160-lane PCIe Gen6 交换芯片**（08-13, FMS 2026）: 160-lane PCIe Gen6 switch（最多 20 端口，实际常连 x16 GPU/NIC），直接对标 Broadcom/Astera Labs/Marvell——PCIe switch 从存储服务器/边缘 DL 服务器的配角变为 **AI 基础设施关键组件**（Broadcom 自 Avago-PLX 收购后长期主导该市场）；Microchip 侧重 PCIe 而非 CXL switch。URL: https://www.servethehome.com/microchip-switchtec-160-lane-pcie-gen6-switch-shown-at-fms-2026-with-xpressconnect-pcie-6-retimer/

- **ServeTheHome/Microchip XpressConnect PCIe Gen6 retimer**（08-13, FMS 2026）: PCIe Gen6 信号可达距离缩短 + 系统因组件/散热规模变大 → **retimer 成热区**（即使 NVIDIA 试图设计绕过 retimer）；retimer 通过重新定时延伸链路有效距离，Gen6 时代服务器板卡级互联的必配器件。URL: https://www.servethehome.com/microchip-switchtec-160-lane-pcie-gen6-switch-shown-at-fms-2026-with-xpressconnect-pcie-6-retimer/

## AI 推理芯片

- **ServeTheHome/AMD 收购 Taalas（模型专用 AI 推理芯片）**（08-06）: Taalas 路线与可编程 GPU 相反——**把模型直接烧入 CMOS**（不再从 HBM 加载权重+可编程矩阵），换模型=换芯片；现役 **HC1 演示卡**：Llama 3.1 8B 声称 **17,000 tokens/s/user**，TSMC 6nm、**815 mm²、53B 晶体管**（对比 H200/B200/Groq/SambaNova/Cerebras，Taalas 自测口径）；改权重/矩阵维度只需换 **2 个 mask 层**（掩膜成本远低于重新 tape out）；挑战：大模型需多颗 reticle 级芯片拼装。URL: https://www.servethehome.com/amd-to-acquire-taalas-for-model-specific-ai-inference-chips/
