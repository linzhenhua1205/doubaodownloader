## 1️⃣ 🟢 AIC F2032-01-G6 JBOF — Vera Rubin 生态的 KV Cache 存储节点

**来源**: [ServeTheHome — AIC Gets Flashy with 32 SSD Bay JBOF Server for Key Value Caching](https://www.servethehome.com/aic-gets-flashy-with-32-ssd-bay-jbof-server-for-key-value-caching/) (Ryan Smith, July 11, 2026)

### 技术详情
AIC 在 Computex 2026 展示的 **F2032-01-G6** 是一款 2U JBOF（Just a Bunch of Flash）存储服务器，专为 NVIDIA **Context Memory Storage (CMX)** 平台设计，直接集成到 **Vera Rubin** 机架生态中。

| 参数 | 规格 |
|:-----|:------|
| 外形 | **2U JBOF** |
| 存储 | **32 × PCIe Gen6 E3**（E3.L / E3.S，7.5mm） |
| 最大容量 | **8PB**（配 256TB E3.L QLC SSD 时） |
| I/O 交换 | **Broadcom PEX90144** — 144 lanes PCIe Gen6 交换机 |
| 控制器 | **NVIDIA BlueField-4 DPU**（Grace CPU + ConnectX-9） |
| 网络 | **800GbE / 800Gb InfiniBand** |
| SSD 连接 | 每 SSD 分配 **x2 PCIe Gen6 lanes**（最大化容量） |
| 高可用 | **双节点冗余** — 每节点 2 × BF-4 DPU |
| 典型场景 | KV Cache 推理加速·对象存储·Scale-out 文件系统·Flash 分层 |

### 关键设计点
- **E3 标准的 Bet**: AIC 全线转向 E3.L / E3.S 规格（非传统 U.2/U.3），靠 E3.L 达到单盘 256TB 容量天花板
- **x2 lane 策略**: 144 lanes ÷ 32 SSD = 每盘 x2 lanes，PCIe Gen6 x2 带宽 ≈ PCIe Gen5 x4，读写带宽不降反升
- **Vera Rubin 关键组件**: CMX 平台是 NVIDIA 自研 KV 缓存方案，用于大模型推理时将 KV cache 就近 GPU 存储，减少从远端模型参数加载的延迟
- **PCB 复杂度**: 单服务器需处理 32 × PCIe Gen6 + 双 BF-4 DPU 的高速信号布线，对 PCB midplane 设计提出极高要求（与 Kyber 机架 midplane 瓶颈对应）

### 行业意义
Vera Rubin 生态不再是仅 GPU+CPU 计算节点，开始系统性补齐存储/缓存平面。JBOF + CMX 可能成为大规模推理集群的标配，300B+ 参数模型的 KV cache 容量需求将推动此类设备需求爆发。

## 2️⃣ 🟢 ASUS 热实验室 2026 — Rack-scale 液冷验证的前沿

**来源**: [ServeTheHome — ASUS Thermal Lab Tour 2026 Testing AI Servers](https://www.servethehome.com/asus-thermal-lab-tour-2026-testing-ai-servers/) (Patrick Kennedy, July 10, 2026)

### 技术详情
ASUS 在台湾的 **QTR Lab** 展示了面向 AI 服务器的全流程热验证能力。关键设施：

| 设施 | 参数 | 用途 |
|:-----|:-----|:------|
| 步入式环境箱 | **25°C - 45°C**，可容纳整机架 | 标准 DC 环境验证，含 **GB200 NVL72** 整柜 |
| 极端环境箱 | **-40°C - 85°C**，10%-98% RH | 运输/存储应力加速老化（Hitachi 设备） |
| R&D 液冷实验室 | **1.1MW 功率容量** | Rack-scale 液冷集成验证 |
| 测试对象 | **GB200 NVL72、GB300 NVL72** | 整柜液冷系统级验证 |

### 关键设计点
- **环境箱直接容纳整机架**: 传统热实验室只测单节点，但液冷系统中冷却液温度/流量/压降在不同节点间有耦合关系。只有整机架测试才能发现液冷歧管行为、节点间热干扰、漏液检测系统可靠性
- **液冷温度策略**: 运行在 20°C 冷却液温度，同时测试更高温度方案。更高冷却液温度可降低冷水机组能耗，但可能影响组件可靠性和性能余量
- **运输热应力**: 当 GB200 NVL72 等整机架通过空运/海运运输时，未加电状态下的极端温度环境（航运集装箱可能达到 85°C）需要验证。这也是行业从空运转向温控卡车的原因之一
- **GB300 NVL72 测试方法论**: 从单 compute tray 的热管理 → 72 GPU 间的冷却液流量协同 → 多个冷板的流量分配 → 漏液检测系统全链路验证
- **AI 服务器功耗密度**: 单台 8-GPU 节点相当于 2015 年两个 208V/30A 机架的功耗；液冷 AI 机架功率密度远高于传统企业服务器，「风冷测试无法复现液冷在 rack-scale 下的冷却液分配挑战」

### 行业意义
液冷从「可选」走向「必须」，整机架级验证成为核心能力。1.1MW 测试容量直接对应超节点/万卡集群级部署。华硕、广达、纬颖等 ODM 正在将液冷能力从组件验证提升为整机架系统级验证，这是 rack-scale 产品化的关键门槛。

## 3️⃣ 🟡 Arm AGI 服务器首次亮相 — ASRock Rack 1U4E1S-ARM

**来源**: [ServeTheHome — ASRock Rack Had One of the First Arm AGI Servers at Computex 2026](https://www.servethehome.com/asrock-rack-had-one-of-the-first-arm-agi-servers-at-computex-2026/) (Ryan Smith, July 3, 2026)

### 技术详情
Arm 首款自研服务器 CPU **AGI** 搭载于 ASRock Rack 的 **1U4E1S-ARM** 1U 服务器中。

| 参数 | 规格 |
|:-----|:------|
| CPU | **Arm AGI** — 136 × Neoverse V3 核心 |
| 频率 | 最高 **3.7 GHz** |
| TDP | **300W** 基线 |
| 制程 | **TSMC 3nm** |
| 内存 | **12 通道 DDR5-8800**（1 DPC） |
| I/O | **96 lanes PCIe Gen6** + CXL 3.0 |
| 网络 | **OCP NIC 3.0** slot |
| 存储 | 4 × **E1.S Gen5 x4** 前插 + 2 × M.2 内插 |
| 扩展 | 1 × FHFL PCIe Gen6 x16 + 1 × HHHL PCIe Gen6 x16 |
| 电源 | 2 × **800W Titanium** 冗余 |

### 关键设计点
- **136 核 @ 300W = ~2.2W/core**，比 Intel CWF 的 <2W/core 稍高，但仍是极高能效密度
- 内存通道数 (12ch) 与核心数比例低于 Xeon/EPYC 的 12ch:288核或 12ch:192核，AGI 强调每核心内存带宽更高
- **AGI 是首批原生支持 PCIe Gen6 的服务器 CPU 之一**，96 lanes Gen6 + CXL 3.0 对标同代 Xeon/EPYC
- Meta 是首个公开大客户，ASRock Rack 为 launch supporter
- **单主板设计支持双路**（2OU2N-ARM 双节点 2U 服务器），验证了跨节点同步能力

### 行业意义
Arm 从 IP 授权商 → 芯片设计商的转变正式进入量产阶段。AGI 在 3nm 节点直接对标 x86 旗舰服务器的核心数/内存通道/PCIe Gen6 规格。若 Meta 大规模部署，Arm 服务器 CPU 市场份额将从 10%+ 级跃升至更高，且反向推动 Arm 架构在服务器生态中的软件成熟度。

## 4️⃣ 🔴 Nanya Technology DRAM ASP +70% QoQ — 产能危机持续至 2028

**来源**: [Tom's Hardware — Nanya to quadruple capital spending to $6.2B in 2027](https://www.tomshardware.com/tech-industry/nanya-to-quadruple-capital-spending-to-6-2-billion-in-2027) (Luke James, July 10, 2026)

### 技术详情
Nanya Technology 发布 Q2 2026 财报，显示 AI 驱动的 DRAM 短缺已到极端程度：

| 财务指标 | Q2 2026 | 同比变化 |
|:---------|:--------|:---------|
| 营收 | T$82.55B（$2.56B） | **+684%** |
| 净利润 | T$50.19B（$1.56B） | **+1,324%** |
| 毛利率 | **79.5%** | vs -20.6%（Q2 2025） |
| ASP | — | **+70%+ QoQ** |
| 单季利润 | — | = 2025 全年利润的 **7.6×** |

### 产能规划

| 年份 | 资本支出 |
|:-----|:---------|
| 2023 | T$13.2B |
| 2024 | T$16.1B |
| 2025 | T$13.4B |
| 2026 (预算) | T$52B |
| **2027 (预告)** | **T$200B+ ($6.2B)** |

- **新 Fab**: 新北市泰山区，1B 节点（第2代 10nm-class），首期 30K wpm（2028），最终 45K wpm
- **产品结构**: ~70% 为 DDR4 / LPDDR4，DDR5 仅贡献 ~10% 营收
- **HBM 策略**: 明确不参与 HBM2/3/3E/4 竞争，与 Etron 等合作开发边缘 AI 定制 HBM（2026 年底目标）
- **供应约束预测**: 「最严重供给约束贯穿 2026 H1~2027 H1，短缺持续到 2028」

### 行业影响
- **Nanya 79.5% 毛利率是「纯传统 DRAM」的读数** — 不含 HBM 加成。相比之下，含 HBM 的 Micron 最新季度毛利率 85%。说明传统 DRAM 的供需缺口几乎与 HBM 一样严重
- **SanDisk·Kioxia·Solidigm·Cisco 联合投资 T$78.72B 获取 Nanya 10.19% 股权** + 长期 DRAM 供应协议 —— 这些 SSD 厂商需要 DRAM 做缓存（Cache），说明存储行业也在被 AI 拉爆
- **对服务器硬件的影响**: DDR5 服务器 DIMM 成本持续攀升，Server ODM 的 BOM 压力加大，可能推动更多 CXL 内存池化方案和 HBM 直接替代传统 DRAM 的探索

## 5️⃣ 🟡 Micron 9650 PCIe Gen6 数据中心 SSD 量产 — E1.S 强制液冷

**来源**: [ServeTheHome — Spotted at Computex 2026: Micron's First PCIe Gen6 Data Center SSD, the 9650](https://www.servethehome.com/spotted-at-computex-2026-microns-first-pcie-gen6-data-center-ssd-the-9650/) (Ryan Smith, July 5, 2026)

### 技术详情

| 参数 | 规格 |
|:-----|:------|
| 接口 | **PCIe Gen6 x4** |
| 顺序读 | **28 GB/s** |
| 顺序写 | **14 GB/s** |
| 随机读 | **5.5M IOPS** |
| 随机写 | **900K IOPS** |
| 功耗 | **25W** |
| 介质 | Micron **G9 TLC** NAND @ 3600MT/s |
| 容量 | PRO: 30.72TB / MAX: 25.6TB |
| 冷却 | **E1.S 需要液态冷却**（"optimized" not just "compatible"） |

### 关键设计点
- 首代 Gen6 控制器即打满 x4 链路带宽（28GB/s ≈ PCIe Gen6 x4 极限 ≈ PCIe Gen5 x8）
- E1.S 25W 功耗迫使其成为业界首个「液冷优化」企业级 SSD —— 直接对接液冷 GPU 服务器环境
- **Gen6 平台缺失**: Micron 已开始量产，但"**没有可用的商用 Gen6 服务器平台**" 用于公开演示 —— NVIDIA/AMD 的 Gen6 平台预计 2027 年，Intel Diamond Rapids 路径不同，Arm AGI 为少数已具备 Gen6 的 CPU

### 行业意义
存储 I/O 瓶颈正在从「够用」变为「AI 训练/推理的关键限制因素」。Gen6 SSD 将存储延迟降低到接近内存级，配合 Vera Rubin 的 CMX KV Cache 架构，**存储从层次结构底层向上迁移**的趋势明显。

## 📋 跨主题洞察

### 本周信号汇总
1. **PCIe Gen6 生态加速成型**: Arm AGI（已宣布）→ Micron 9650（已量产）→ AIC JBOF（设计就绪）→ NVIDIA Vera Rubin（2026 秋出货）→ AMD 平台（2027）。Gen6 生态正在快速收敛
2. **液冷从 GPU 扩展到存储**: Micron 9650 E1.S 强制液冷 → SSD 也纳入液冷回路。AIC JBOF 的 32× Gen6 SSD + BF-4 DPU 同样预计液冷部署。服务器内部的「液冷面」正在扩大
3. **DRAM 短缺冲击 DDR5 服务器成本**: Nanya 纯 DDR4/DDR5 毛利率 79.5% 说明传统 DRAM 缺口不亚于 HBM。Server ODM 的 BOM 中 DIMM 占比大幅上升
4. **JBOF + CMX = 新型推理集群架构**: NVIDIA 正在系统性构建「GPU 近端 KV Cache」存储层，AIC F2032-01-G6 是首个明显信号。推理集群从纯计算集群演变为 **GPU 计算 + NVLink 域 + CMX 存储 + BlueField 控制** 的四层架构

### 关键跟踪项（后续关注）
- 🔲 NVIDIA Vera Rubin 秋季出货后的实际性能数据
- 🔲 Arm AGI 的 Meta 部署规模及首轮 SPEC/MLPerf 基准
- 🔲 Nanya 新 Fab 的 1B 节点良率和 DDR5 产出爬坡
