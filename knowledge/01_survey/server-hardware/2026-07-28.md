## 2️⃣ 🟠 Intel Xeon 6 内存罕见中期升级：DDR5-8000 RDIMM + MRDIMM Gen2 兼容

| 项目 | 数据 |
|:-----|:-----|
| **发布日期** | 2026-07-20 |
| **作者** | Ryan Smith, ServeTheHome |
| **Xeon 6700P** | **2026年8月起**支持 DDR5-8000 RDIMM（原上限 DDR5-6400） |
| **带宽增益** | 书面 +25%，实测 +20%，**实际负载 +3~6%** |
| **延迟改善** | JEDEC 绝对延迟 14ns（vs DDR5-6400 14.38ns），Intel 实测 -6% |
| **限定条件** | 仅 **1DPC** 模式；仅"**select**" SKU；仅 6700P（Granite Rapids-SP） |
| **Xeon 6900P** | **2027 Q1** 起兼容 MRDIMM **Gen2**（12800 MT/s），**但仅兼容不加速** |
| **背后逻辑** | Granite Rapids 内存控制器本为 MRDIMM 8800 MT/s 而**过度设计**，现复用到 RDIMM |
| **战略意图** | AMD Advancing AI 2026（7/23）前一周发布 → **明确阻击 Venice** |
| **MRDIMM Gen1** | Micron 已将其标记 EOL，产能向 Gen2 转移 |

**要点解读**：
- 这是 Intel 非常罕见的**中期规格升级**（mid-life kicker），起因是 Diamond Rapids 2027 才到
- DDR5-8000 带宽提升主要利好 **AI推理中的内存带宽瓶颈场景**（大模型推理/内存数据库）
- 2DPC 仍是 DDR5-5200 → 1DPC vs 2DPC 的内存带宽差距**从 +23% 扩大到 +54%**，容量 vs 带宽的矛盾加剧
- MRDIMM Gen2 兼容主要是**生态延续**而非性能提升——确保 6900P 用户未来还可采购到 MRDIMM

**来源**: [ServeTheHome - Ryan Smith, Jul 20, 2026](https://www.servethehome.com/intel-to-add-support-for-gen-2-mrdimms-and-faster-ddr5-rdimms-to-xeon-6-platform/)

## 3️⃣ 🟡 AMD Instinct MI350P — CDNA 4 PCIe HBM 加速卡全貌曝光

| 项目 | 数据 |
|:-----|:-----|
| **发布日期** | 2026-07-17 |
| **作者** | Patrick Kennedy, ServeTheHome |
| **内存** | **141GB HBM3e**（vs H200 NVL 144GB / RTX Pro 6000 BE 96GB GDDR7） |
| **功耗** | **600W** 被动散热 PCIe 卡 |
| **架构** | CDNA 4，支持 **FP4 / FP6 / FP8** |
| **定位** | 相当于 **MI350X OAM 的一半**（compute/memory/power 均减半） |
| **竞争对比** | MI350P FP4/FP6 规格优于 H200 NVL（Hopper 不支持）和 RTX Pro 6000 BE（无 FP6 发布数据） |
| **部署** | 已出现在 Dell Tech World, HPE Discover, Computex 2026 |
| **接口** | 无视频输出，电源接口在卡前端（同 H200 NVL 设计） |

**竞品规格对比**：

| 指标 | MI350P | H200 NVL | RTX Pro 6000 BE |
|:-----|:------:|:---------:|:---------------:|
| 架构 | CDNA 4 | Hopper | Blackwell |
| 内存 | 141GB HBM3e | 144GB HBM3e | 96GB GDDR7 |
| 功耗 | 600W | 600W | 600W |
| FP4 | ✅ 发布 | ❌未发布 | ❌未发布 |
| FP6 | ✅ 发布 | ❌未发布 | ❌未发布 |
| FP8 | 发布 | 发布 | 发布 |

**要点解读**：
- MI350P 补上了 AMD **PCIe 形态 AI 加速器**的空缺——MI350X 是 OAM 形态，功耗太高无法直接塞进 PCIe 卡
- FP6 (MXFP6) 是 MI350P 的核心差异化优势：介于 FP8 和 FP4 之间的精度，**推理时可多塞~33%参数**到同一内存
- 600W PCIe CEM 正在成为 AI 加速卡的**事实功耗标准**（三厂一致）

**来源**: [ServeTheHome - Patrick Kennedy, Jul 17, 2026](https://www.servethehome.com/the-amd-instinct-mi350p-is-a-hbm-pcie-accelerator-that-has-been-all-over/)
