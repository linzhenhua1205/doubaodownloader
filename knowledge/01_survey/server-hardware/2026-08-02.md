## 1️⃣ 🔴 Kioxia CM10 Series — 首款 PCIe Gen6 企业级 SSD（含直接液冷）

**来源**: [ServeTheHome — Kioxia CM10 Series Launched for the PCIe Gen6 Generation of SSDs](https://www.servethehome.com/kioxia-cm10-series-launched-for-the-pcie-gen6-generation-of-ssds/) (Vic A, August 1, 2026)

**背景**: FMS 2026（Santa Clara, 8月）前夕发布。Kioxia 首款 **PCIe 6.0 企业级存储**，基于 **BiCS FLASH 第10代（Gen10）NAND**，直接液冷（DLC）能力面向 AI 基础设施，目标负载为**高性能 KV cache + NVIDIA CMX 上下文内存方案**。

### 性能与规格

| 指标 | CM10 (vs CM9) |
|:-----|:--------------|
| 顺序读 | **+92%** |
| 随机读 | **+85%** |
| 接口 | PCIe Gen6 (EDSFF) / PCIe Gen5 (2.5") |
| NAND | BiCS FLASH Gen10 TLC (EDSFF) / **Gen8 TLC (2.5")** |
| 目标场景 | 万亿参数模型 + 百万 token 上下文窗口 |

### 形态矩阵（关键分化点）

| 形态 | 厚度 | 接口/NAND | 特性 |
|:-----|:-----|:----------|:-----|
| **E3.S** | 7.5 mm | PCIe 6.0 / Gen10 | dual-port 可选（HA 存储阵列） |
| **E1.S** | 9.5 / 15 mm | PCIe 6.0 / Gen10 | **9.5mm 支持直接液冷** |
| **2.5" (CM6)** | 15 mm | **PCIe 5.0 / Gen8** | dual-port，传统机箱 |

**要点解读**：
- **U.2/U.3 让位 EDSFF 的实证**：STH 长期预警"PCIe Gen6 电气要求将终结 2.5" U.2 主导地位"。CM10 首次在**同一产品家族内**做形态分化——EDSFF 用 Gen6+Gen10 NAND，2.5" 用 Gen5+Gen8 NAND，反映热/密度约束下新旧代际的分流
- **DLC 液冷进存储层**：9.5mm E1.S/E3.S 支持 direct-cold-plate 液冷，与 GPU 液冷 pod 相邻的 KV cache 存储部署对齐
- **定位**：AI 存储 tier 中的 ephemeral KV cache 层（GPU HBM 与网络存储之间利用 flash 延迟），与 NVIDIA CMX、Vera CPU、EPYC Venice 平台同步配套

## 2️⃣ 🟡 PCIe Gen6 与 Gen5 将并存于 AI 存储 — 架构迁移分析

**来源**: [ServeTheHome — PCIe Gen6 and Gen5 Will Both Matter for AI Storage](https://www.servethehome.com/pcie-gen6-and-gen5-will-both-matter-for-ai-storage/) (Patrick Kennedy, July 31, 2026)

**背景**: 2026 下半年开始 PCIe Gen6 服务器迁移（**自 2022 EPYC 9004 Genoa 引入 Gen5 以来首次代际跃迁**），但 Gen5 存储仍将长期重要——预算约束 + 供应受限时代，组织需在性能与成本间平衡。

### Gen6 平台家族（存储迁移时间表）

| CPU 家族 | 状态 |
|:---------|:-----|
| AMD EPYC Venice | ✅ 在途（已发布） |
| NVIDIA Vera | ✅ 在途 |
| Arm AGI CPU | ✅ 在途 |
| Intel Xeon 7 Diamond Rapids | ⏳ 预期 2027 |
| 多家 hype-scale 自研芯片 | — |

### 关键量化数据

- **PCIe Gen6 x16 单槽 = 800Gbps 网络带宽** ≈ **32 个 PCIe Gen3 NVMe SSD**（128 lanes）每条链路；现代服务器可挂 **8-10 条**此类链路
- **每 GPU 可达 800Gbps（或 1.2Tbps）网络带宽**——Gen6 每 lane 速率较 Gen5 翻倍
- **代际吞吐比**: 1 个 2026 PCIe Gen6 SSD ≈ **8 个 2021 年 PCIe Gen3 SSD** 的总吞吐
- **架构弹性**: 平台架构师可将带宽分配给更多设备（x2 bifurcation 替代 x4），或集中给少数设备提升单设备吞吐

### Silicon Motion SM8466（Gen6 控制器先行者）

| 指标 | SM8466 (Gen6) | SM8366 (Gen5, 参照) |
|:-----|:--------------|:--------------------|
| 顺序性能 | **>28 GB/s** | ~1/2 |
| 随机 IOPS | **>700 万** | ~1/2 |
| 接口 | PCIe Gen6 x4 | PCIe Gen5 x4 |

- 支持 **SR-IOV / Multi Physical Function 隔离** + **NVMe 2.0 Flexible Data Placement（FDP）**
- 明确瞄准 **NVIDIA CMX / KV-cache 扩展**用例
- 说明: 控制器能力 ≠ 成品 SSD 表现（取决于固件/平台/软件栈），STH 尚未实测

**要点解读**：
- **KV cache 驱动新架构**: NVIDIA CMX 等方案将数据移出昂贵的 on-accelerator HBM，跨机器边界共享 KV cache——这正是 Gen6 高带宽存储 tier 存在的核心理由
- **Gen5 继续存在的经济逻辑**: 供应受限 + 预算约束下，Gen5 SSD（存量 + 新 Gen6 平台的降级档位）继续承担推理集群/KV cache 优化的次级 tier
- **存储是下一个代际拐点**: 行业关注 CPU/GPU/网络代际切换已久，存储（Gen5→Gen6）成为 2026 H2 最后一个大迁移
