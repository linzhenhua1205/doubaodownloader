## 今日小结

- **主线1 · Agent 从"编码工具"向"白领生产力"迁移**：ChatGPT Work（$20/月）+ Codex 内部 98% vs 外部 <1% 的鸿沟，暴露 Agent 产品化的核心矛盾——工程师能用的 CLI 心智无法直接迁移给大众，harness（工具壳）成为决定普及率的胜负手，而"bitter lesson"认为模型才是护城河
- **主线2 · 小模型+RL"品味"路线挑战大模型堆料**：Inherent Faraday 27B 参数反超 Claude Opus 4.8/GPT-5.5 于论文复现，Agent 能力差距从"参数规模"转向"训练方法论"，科研 Agent 赛道（AI scientist）进入实质竞争期
- **主线3 · Agent 安全与合规从幕后走向台前**：100+ 公司联合防御声明 + Anthropic 对五角大楼诉讼首胜——应用层攻防（提示注入/越权）和政企采购准入成为 AI 应用落地的两大新约束
- **主线4 · AI 应用品牌与人才战**：Gemini 品牌定位危机揭示"AI 应用命名=大众心智占位"的新课题；Meta→OpenAI 人才流动显示 Agent 产品化人才成为头部争夺焦点
