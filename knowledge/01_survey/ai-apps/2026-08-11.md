## 🏆 TOP 发现

- **🧠 Meta 发布 Muse Glimmer——30B 端侧 agent 模型，Zuckerberg"个人超级智能"愿景首次落地**（TechCrunch, 8/10, Rebecca Bellan）— 开源权重（Apache 2.0），本质是 Meta 最强闭源模型 Muse Spark（4月发布）的开放版；设计用于**单张消费级 GPU 的 Mac/PC 本地运行**多步 agent（调用工具、写/调试代码、处理文件与截图、长工作流），支持文本+图像、100+ 语言训练。"always-on"、可离线运行。官方设想场景：管理日程、起草消息、整理文件——大量个人数据**留在设备本地处理**而非上云，以隐私为卖点的个人 agent 形态 — https://techcrunch.com/2026/08/10/metas-new-glimmer-ai-model-offers-a-hint-at-zuckerbergs-personal-intelligence-vision/
- **🤖 Anthropic 将 Claude Code auto mode 设为默认——AI 编程的"人类逐步审批"被系统性移除**（TechCrunch, 8/9, Anthony Ha）— 8月14日起 Pro/Max/Team 账号 auto mode 成为默认（3月首发测试版）。auto mode 下不再逐步请求批准，**除非动作被判定为"不可逆、破坏性、或针对环境之外"**。关键数据：1,053 名付费测试者实验中 auto mode 拦截 89% 有害动作 vs 人工审查仅 13.6%——原因在于"人工审查已习惯化：用户批准 97% 的权限提示"。同步新增 prompt injection 筛查与可定制 hard deny 规则（防数据外泄）。Claude Code 负责人 Boris Cherny："团队和我只用 auto 模式已数月" — https://techcrunch.com/2026/08/09/anthropic-is-turning-claude-codes-auto-mode-on-by-default/
- **🛠️ Discovered Materials 用 AI agent 群寻找更"凉"的芯片材料——AI 解决自己制造的问题**（TechCrunch, 8/10, Tim Fernholz）— AI 负载芯片过热是数据中心耗电/冷却主因，初创反向用 AI 求解：Anthropic 模型在自研 harness 中**生成材料候选线索** → 自训基础物理模型仿真验证。YC 出身，获 Lightspeed India 领投 $9M seed（Peak XV + Paul Graham 等天使）。创始人 Sridhar（Persona AI/Luma Labs agent 背景）+ Ramdas（斯坦福材料科学博士）。效果量化："博士期间每天约 20 次猜测 → agent 7×24 云端运行每天数千次猜测" — https://techcrunch.com/2026/08/10/discovered-materials-is-playing-ai-whack-a-mole-to-hunt-cooler-chips/
- **💰 深陷困境的 AI 对冲基金 Situational Awareness 仍向芯片初创 Source Foundry 追加 $400M**（TechCrunch, 8/9, Anthony Ha, 转 WSJ）— 累计投资达 $500M。基金由前 OpenAI 研究员 Leopold Aschenbrenner 创立（2024，无交易背景）；7 月底将公开组合大部出售给 Citadel（保留 Anthropic 股份），AUM 从 $200 亿跌至 $100 亿——AI 基础设施股下跌期仍押注"更快更便宜造芯片"的斯坦福系初创 — https://techcrunch.com/2026/08/09/embattled-hedge-fund-situational-awareness-invests-400m-in-chip-startup-source-foundry/

## 📌 本期观察

- **观察 1｜AI 编程的监督形态从"人审"转向"机器拦截"**：Claude Code auto mode 默认化 + 89% vs 13.6% 拦截率数据（人工审查习惯化后批准率 97%），标志"逐步审批"范式终结，安全逻辑变为"异常判定 + hard deny 规则 + 事后审计"——与 08-10 归档"agent 产出信任链三级（可追溯→可审查→可审计）"形成产品端呼应，AI 编程进入"默认自治、异常拦截"阶段。
- **观察 2｜端侧 AI 成个人智能主线，隐私本地化成为卖点**：Meta Glimmer（30B 单 GPU 本地运行、离线可用、个人数据不上云）与 08-08 Canva 收入预测砍 1/3（依赖第三方模型失控）互为镜像——"第一方模型 + 端侧处理"正成为应用层护城河叙事。
- **观察 3｜"AI 解决 AI 制造的问题"闭环成形**：Discovered Materials 用 agent 群做材料发现（AI 造热→AI 散热），把博士人工试错（20 次/天）升级为 agent 7×24 生成+物理模型验证（数千次/天）——AI for Science 从"辅助分析"进入"自主研究执行"，与 8/10 归档 InternAgentS 科研工作台同向。
- **观察 4｜中文 AI 应用进入"一站式平台"密集发布期**：阿里 CosyVoice Studio（语音三合一）、腾讯 WorldClaw（3D 世界）、NVIDIA Alpamayo（自动驾驶）同日发布——AI 应用从单模型转向"平台化/场景化打包"，语音/3D/车机三赛道同时加速。
