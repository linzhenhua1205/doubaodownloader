## 📚 arXiv 精选（cs.CL，07-30~08-05 提交）

- **WorldCup Arena — 前瞻性无泄漏评测**（2608.04008）: 2026 世界杯 39 天 104 场，6 个前沿 LLM（带思考+原生联网搜索）赛前填七市场预测卡，共 4,494 条打分预测。比赛结果平均 63.9%——与无脑押博彩热门持平（它们多数时候确实这么干）；模型间共识远多于正确（多数投票无增益）；对平局/进球数过度保守；最接近的强强对话预测最差。结论：当前前沿系统预测能力未显著分化。https://arxiv.org/abs/2608.04008

- **Risky Business — 忠实性 vs 安全性的对齐张力**（2608.03745）: 提出 HazMart（自主 AI 店长场景）+ Targeted Reasoning Replacement（TRR）直接干预推理链。DeepSeek-R1-Llama-70B 忠实度 97.5% 但拒绝不安全推理仅 12.3%；QwQ-32B 安全性 73.9% 但忠实度降至 74.7%——两属性内部方向反相关（峰值在 action-commit token）。表示级 steering 可独立放大安全方向 +9pp 且保住基础能力。https://arxiv.org/abs/2608.03745

- **PAST-Bench — 个人 Agent 递归自改进基准**（2608.04003）: 26 场景 204 回合，开关"经验保留"对比 7 个基座模型 × 4 个 agent 框架。改进真实但不均衡：同名增益背后"是否走 save→retrieve→update 预期通路"差异显著；据此开发 Hermes+（5 项针对性干预），在"需替换过期状态"类任务增益最大。与 Discovery Loop 的递归自改进叙事互为印证。https://arxiv.org/abs/2608.04003

- **Logic Before Language — 形式推导预预训练**（2608.03930）: Logic-PPT 用形式化推导（变量绑定/量词/长程谓词-论元组合）初始化 LM，100B token 规模下语言任务 80% 准确率**省 36B token**；机制上诱导低秩、谱集中的表示空间，**33% 剪枝稀疏度仍匹配稠密基线**——结构初始化兼得训练效率与可压缩性。https://arxiv.org/abs/2608.03930

- **When Attention Goes Blind — ALiBi 数值失效**（2608.03994）: ALiBi 线性偏置在浮点下溢时清零大量注意力权重，头部"部分失明"；SOTA 预训练模型实测存在此问题。token 检索显著受损但标准基准影响小；四种缓解中 **log 缩放距离**对 passkey 检索提升最稳。训练位置编码选择的工程警示。https://arxiv.org/abs/2608.03994

- **离线 KD + 融合分块 KL 损失 — 蒸馏工程化**（2608.03796）: 离线 KD（缓存教师 top-K logits）匹配在线蒸馏训练损失，教师移出显存，单 H200 每迭代快 **29%**、吞吐高 **41%**；融合分块 KL 损失不物化全词表 logit 张量，峰值内存线性于序列长度，**单卡上下文 4× 到 32,768 token**。https://arxiv.org/abs/2608.03796

- **M-GATE — 多语言"流利≠精通"**（2608.03803）: 30 语言 3 任务（对抗语法检测/往返翻译/tokenizer 效率），50+ 模型 80+ 配置。最强模型对抗语法项 MCC 仅 **0.36**（近随机），且系统性漏报（接受不合语法）；翻译质量与预训练数据份额强相关（r=0.86），低资源惩罚随代际收窄；推理模式稳定提升翻译但对语法检测效果小甚至为负。https://arxiv.org/abs/2608.03803

- **Agogic — 音乐 token 表示>模型规模**（2608.03999）: 固定 Qwen3.5（0.8B-27B）只换 7 种 tokenization：**表示是分布保真的绑定变量**——骨干 34× 缩放几乎不动 FMD，换表示直接减半。性能分辨率 token（10ms 定时/逐音符力度）0.8B 达 FMD 159 vs 节拍网格 272-286（低 1.7-1.8×），**0.8B 打败 27B 节拍网格**；发布 6.25M 带标题音乐语料（业界最大）。https://arxiv.org/abs/2608.03999

- **GPTKB 2.0 — 百万级 LLM 原生知识库**（2608.03729）: 直接由 LLM 构建消歧知识库：>100 万消歧实体 + 3,840 万三元组，实体/关系/类三重重规范化，首个百万级非 Wikimedia 中心 LLM 原生 KB。https://arxiv.org/abs/2608.03729

- **TurnSight — 工具推理的回合级后见自蒸馏**（2608.04007）: 针对 TIR 轨迹级 RL 信用分配粗粒度问题，用执行条件后见构造多视野监督，跨视野方向一致性筛选可靠信号，sibling rollouts 归一化调制 RL 优势。三个基准全面验证。https://arxiv.org/abs/2608.04007

- **ContinualSkillBench — Agent 技能演化真相**（2608.03874）: 5 域 × 100 互联子任务：顺序执行普遍有增益但幅度因模型/域而异；**ICL 平均表现≈显式技能维护**（增益多来自上下文适应而非可复用技能抽象）；弱模型反而积累更大更碎的技能集合。https://arxiv.org/abs/2608.03874

- **Sparse Weight Decomposition — 免训练的电路提取**（2608.03913）: 将预训练线性投影分解为两个稀疏因子，共享中间坐标作可寻址电路单元；匹配 Transcoder 保真度但**仅用其 <1% 训练数据**，GPT-2/Qwen2.5/Qwen3.5-27B 全模型替换有效，含零数据变体。https://arxiv.org/abs/2608.03913

- **SocietyBench — 反事实社会演化预测**（2608.04009）: 五平台新闻+社媒蒸馏为日期索引时间线，实体替换+日期平移构造反事实世界防记忆；5 事件 125 预测点，6 个前沿 LLM 最强仅 **75.0/100**（锚点 50）；校准强≠时间准（两轴分离），3 个 agent 框架不优于基座。https://arxiv.org/abs/2608.04009

- **TART — 多语言多 Agent 规划失败诊断**（2608.03735）: 计划-落地失败随语言资源下降而占比上升（低资源最重）；TART 表示显式注入规划器与子 agent，多语言 GAIA 上 SOTA 系统 **+5.6pp**（11 语言均值）。https://arxiv.org/abs/2608.03735

- **ParVL — MLLM 并行计算缩放**（2608.04010）: 复用 ViT+LLM 骨干、共享骨干上挂分支前缀参数实现并行缩放，~13B token 全参数 SFT；系统研究视觉-语言计算分配权衡——最优分配随任务而变，整体优于同配方单分支基线。https://arxiv.org/abs/2608.04010

- **DBLifeBench — LLM 数据库全生命周期评测**（2608.03794）: 首个覆盖设计/实现/运维/调试/维护五阶段的数据库基准；通用模型均衡，**专用 Text-to-SQL 模型在非编码阶段"灾难性遗忘"**。https://arxiv.org/abs/2608.03794

- 递归自我改进从论文概念走向创业实践（Discovery Loop）与评测基建（PAST-Bench）双线落地
