## 🔥 今日头条

- **AI4AI at Test-Time: Strong-to-Weak Capability Transfer via Harnesses**（arXiv:2608.12307, 08-12 提交）: 测试时强→弱能力转移——更强 builder 模型为弱目标模型构建推理时 harness（不改参数），ToM 基准上目标模型平均性能 0.49→0.91 近翻倍；归因分析：收益主要来自**将不稳定推理卸载到确定性代码**、基准专用路由、严格答案格式约束，而非更多推理/采样。**Harness 研究线连续第四天获实证**（08-10 HarnessOpt-Bench → 08-11 SkillProx → 08-13 Evo-Bench v2 → 今日 AI4AI），且直接验证本地「AI概率内核×工程确定性外壳」判断。https://arxiv.org/abs/2608.12307

- **Information Abundance Paradox: Long-Context Training Undermines Parametric Knowledge**（arXiv:2608.12218, 08-12 提交）: 长上下文训练的**信息丰裕悖论**——上下文越丰富，模型越倾向把信息存在上下文而非参数里：预训练增大上下文窗口仅在中间最优值前提升封闭式 MCQA，之后持续下降；SFT 更多任务相关训练上下文在有支撑上下文时提升、上下文缺失/误导时鲁棒性下降。机制：梯度压力从 FFN（参数知识）转向注意力模块。**对「上下文越长越好」假设的第一性原理级挑战，与本地「KV 分层命运/上下文成本」研究线直接互证**。https://arxiv.org/abs/2608.12218

- **Total Recall at What Cost? Benchmarking the Serving Cost of Agentic Memory Systems**（arXiv:2608.11879, 08-12 提交）: Agentic 记忆系统**服务成本基准**——对比 Mem0/Hindsight/Mastra Observational Memory vs 滚动窗口/全量重发两参考策略（400 轮对话、665 LoCoMo 问题）：① 记忆系统服务成本无法由对话长度+消息大小预测（回归漏 18-69%，由内部记忆行为驱动）；② 盈亏平衡点高度敏感（从最早几十轮到 400 轮内永不回本）；③ 无系统双赢——准确率 21-54% 区间，骨干选择影响成本与记忆系统相当。**与本地「KV 卸载/记忆分层」线的直接实证补充**。https://arxiv.org/abs/2608.11879

- **OpenAI 推出「Ultrafast」模式：GPT-5.6 Sol 提速 14×**（2026-08-14, TechCrunch, 53 分钟前）: OpenAI 发布 Ultrafast 新模式，使 GPT-5.6 Sol 以 14 倍速度运行——推理时延数量级压缩，延续「推理成本第一杠杆」判断；同日 IBM 宣布与 OpenAI 合作强化企业 AI 布局。https://techcrunch.com/category/artificial-intelligence/

### 推理与效率

- **Claim-Level Reliability Assessment for Efficient Test-Time Reasoning**（arXiv:2608.11994, 08-12 提交）: 声明级可靠性评估——测试时算力从「更多采样」重分配到「定向验证」：把推理轨迹压缩为决策关键声明集，利用「构造需全对、反驳只需一错」的不对称性；GPT-OSS-20B/CMIMC25 上超过 pass@1 达 27.15pp，自一致性 77.50→82.19% 且省 37% token。**测试时缩放的声明级精细粒度**。https://arxiv.org/abs/2608.11994

- **Who Thinks Best Depends on How Long You Let Them: Budget-Dependent Rankings**（arXiv:2608.12150, 08-12 提交）: token 预算依赖排名——改变最大生成 token（64-4096）会**反转模型排名**（全部基准 p<0.01）；3-19% 条目出现非单调行为（预算↑准确率↓）；预算感知路由捕获 14.1% oracle 差距。**评估协议需预算条件化**——与本地「评估经济学」批判线互证。https://arxiv.org/abs/2608.12150

- **When Self-Consistency Backfires: Majority Vote Hurts the Majority**（arXiv:2608.11403, 08-11 提交）: 自一致性反噬——多数投票在多数情况下反而有害（多数≠正确），对主流 self-consistency 范式的直接挑战。https://arxiv.org/abs/2608.11403

- **Hybrid Gated Attention**（arXiv:2608.11805, 08-12 提交）: 混合门控注意力架构——线性注意力与全注意力的再混合，与 08-13「Massive Activations in HLA」互证（混合架构的激活形态学）。https://arxiv.org/abs/2608.11805

- **QV-PIC: Query-Aware Visual Position-Independent Caching for RAG Serving**（arXiv:2608.12121, 08-12 提交）: 查询感知视觉 PIC 缓存——渲染图像压缩文本为视觉 token 复用 KV，查询感知双分辨率修复质量损失；F1 提升 21.6、TTFT 降 83.8%。**KV 缓存研究的视觉表示新维度**。https://arxiv.org/abs/2608.12121

- **LazyTrain: Limited-resource Allocation toward Zero-waste Yield Optimization**（arXiv:2608.11919, 08-12 提交）: 受限资源训练的零浪费调度——检查点选择/激活放置/重计算/CPU-GPU-NVMe 通信重叠统一为混合整数调度问题；H800 上 Qwen2.5-3B→Qwen3.6-27B 持续 TFLOPS 提升约 1.24×。https://arxiv.org/abs/2608.11919

### 系统与基础设施

- **Mechanist: AI as a Scientific Instrument for Discovering the Mechanisms of Intelligence**（arXiv:2608.12036, 08-12 提交）: 机制可解释性 agent 系统——13K 篇可解释性论文知识图谱 + 43M 篇跨 26 领域论文数据库 + 32 种机制分析/因果干预/验证方法库；自主发现「不安全特质可经貌似安全的训练数据跨模态转移」、信念机制理论、并落地为模型改进干预。**AI 作为科学仪器研究 AI 自身**——与本地「可解释性=控制前提」线同向。https://arxiv.org/abs/2608.12036

- **SAG: SQL-Retrieval Augmented Generation with Query-Time Dynamic Hyperedges**（arXiv:2608.12129, 08-12 提交）: SQL-RAG——文档组织为事件-实体索引（不建全局知识图谱），查询时共享实体作 join key 动态生成查询范围邻域；MuSiQue Recall@5 80.36% 超最强基线 11.52 点。**知识基础设施的增量更新友好设计**。https://arxiv.org/abs/2608.12129

- **Massive Activations in Hybrid Linear Attention LLMs**（arXiv:2608.12149, 08-12 提交）: HLA 模型大规模激活系统性研究——全注意力前尖峰（PAS）+ 线性注意力间平台（ISP）两种形态；1.2B-397B 跨五架构验证；输出门控强烈衰减绝对值但不消除层组织。**量化/稀疏化的激活侧新证据**。https://arxiv.org/abs/2608.12149


- **LODESTAR: Trustworthy Entropy via Reinforced Polarizer**（arXiv:2608.11922, 08-12 提交）: 冻结 LLM 的熵导航——RL 训练的极化解（prompt 短串，不进权重）诱导回答者少读误导段落（26.0% vs 30.3%）；所有 70 个方法×数据集 F1 单元格全胜。https://arxiv.org/abs/2608.11922
