## 1️⃣ Pre-Flight 航空基准 — 最强模型离专家仍有 12pp 差距

**来源**: arXiv:2607.01829 (2026-07-02)

**核心内容**: 首个面向航空运营专业知识的 LLM 基准。300 道多选题，覆盖 ICAO/FAA 法规、机场地面操作、航空常识和复杂运营场景。题目由空中交通管理、地面操作和商业飞行的从业者编写/审查。

**模型表现**:

| 时间点 | 最强模型 | 准确率 | 离专家参考(~95%) |
|:------|:---------|:------:|:----------------:|
| 2025 年初 | — | ~75% | ~20pp |
| 2026 年中 | 最新前沿模型(2026发布) | **82.7%** | ~12pp |

**关键发现**: 尽管一年半内提升约 8pp，但**最后一个 12-15pp 的差距极其顽固**。顶层精度→高可靠性之间存在着系统性的"最后关卡"——这在航空等高风险领域意味着 LLM 还远未达到可独立部署的水平。

**意义**: 与 OmniaBench（Agent 能力瓶颈）等发现形成互证——前沿模型在**通用能力**上爬升快，但在**专深领域**（航空法规、医疗诊断等）的专家级可靠性仍然是系统性短板。

## 2️⃣ MINDGAMES — 944 个 Agent 竞技揭示社交推理短板

**来源**: arXiv:2605.29512 · 多机构合作 · 2025 顶会竞赛

**核心内容**: 多游戏竞技场，TrueSkill 评分，944 个提交 Agent × 76 支队伍，四类游戏（Colonel Blotto / 囚徒困境 / Codenames / Secret Mafia）覆盖信念归因、对手建模、合作推理、社交欺骗四类社会推理需求。

**关键数据**:

| 发现 | 数据 |
|:-----|:------|
| 规则遵循 | **最严重瓶颈** — Agent 频繁违反游戏规则 |
| 最优策略 | 显式结构脚手架（非纯端到端推理） |
| Secret Mafia 混淆因子 | 错误-生存混杂 — 抗错误能力与策略能力在失败密集型环境中不可区分 |
| 数据集 | 29,571 局游戏，turn 级观测+动作+奖励 |

**意义**: 当前 Agent 在**多轮社会推理**中仍严重依赖人为工程化设计（结构脚手架），而非自主涌现的策略能力。失败密集型环境中 Leaderboard 排名可能反映**抗干扰能力**多于**真实策略水平**。

## 3️⃣ Multi-LCB — 12 语言编程揭示 Python 过拟合

**来源**: arXiv:2606.20517 · ICLR 2026

**核心内容**: 将 LiveCodeBench 扩展到 12 种编程语言（含 Python），揭示代码 LLM 的**多语言泛化能力差距**。评估 24 个模型。

**关键发现**:
- **Python 过拟合**: 许多模型在 Python 上表现优异，但跨语言迁移时性能断崖式下降
- **语言特异性污染**: 某些模型在特定语言上表现异常好，暗示训练数据泄露
- **推理模型 vs 指令模型**: 推理模型（如 o1/o3 系列）在跨语言场景下泛化能力更强

## 4️⃣ MemTrace — LLM 记忆系统错误追踪与归因

**来源**: arXiv:2605.28732 (v2: 2026-07-16)

**核心内容**: 提出记忆演化图（Memory Evolution Graph）框架，构建 MemTraceBench 基准覆盖 Long-Context / RAG / Mem0 / EverMemOS 四类代表性记忆系统。

**关键数据**:
- 记忆失败是**系统性**的：信息丢失 + 检索错位为根因
- 利用归因信号做 prompt 优化 → 端任务性能提升最高 **7.62%**
- 四类记忆系统有各自不同的失败模式

**意义**: 首个系统研究 LLM 记忆系统错误归因的工作，为 Agent 长期推理可靠性提供了诊断工具。

## 5️⃣ GTA — 大规模生成 Web Agent 长程任务

**来源**: arXiv:2605.29218 · ACL 2026

**核心内容**: 可扩展的 Web Agent 任务自动生成框架。覆盖 50+ 网站（电商/政府/论坛/新闻），多语言多跳支持。

**关键发现**: 自动生成的轨迹+过程级监督可系统检测 Agent 性能瓶颈。**人类-Agent 存在显著性能差距**——当前 Agent 在多跳、跨页面任务中远未达到人类水平。

## 6️⃣ Clinical Reasoning Graphs — 诊断能力≠推理一致性

**来源**: arXiv:2606.29876 · ICML 2026 Spotlight

**核心内容**: 从 750 条 LLM 诊断轨迹提取推理图，测试 5 个模型在 50 个 NEJM 案例上的推理一致性。

**关键数据**:
- 正确案例和错误案例的图相似度几乎相同 (**0.488 vs 0.484**)
- 结构化反思提示提升显性特征分析 +33%，但**不提升跨案例一致性**
- LLM 表现出 **"有诊断能力但无模式级推理一致性"**

**意义**: 最终答案准确率应补充过程级评估——仅看对错无法区分"真推理"与"模式匹配"。
