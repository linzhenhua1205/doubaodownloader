## 🔥 今日头条

- **Nvidia 研究：harness（智能体外壳）比模型更重要——Claude Opus 5 配 AVO 外壳在 ARC-AGI-3 交互推理基准拿到 100%，无外壳仅 30%**（2026-08-21, TechCrunch, Julie Bort）: （已由 market 组收录，本组从模型评测/能力边界视角补深度）① 核心数据：Nvidia 用自研 harness **Agentic Variation Operators（AVO）**——针对记忆优化 + 内置「supervisor」监督组件——把 Claude Opus 5 在 ARC-AGI-3 上从 **30% 拉到 100%**；而 30% 本身就是无 harness 时所有参测模型的最高分；② ARC-AGI-3 是「一堆无说明 2D 游戏」的交互式推理基准，模型要自己搞懂规则并赢下游戏，100% 意味着**模型玩得和人类一样好**；③ 背景张力：OpenAI 被自家模型 <10% 的分数惹恼，上月也独立做了研究——**仅调 harness 两个设置，自家模型分数翻了三倍**，但仍远未接近 100%；④ AVO 的关键创新是 **supervising agent**：Nvidia AI 部门产品 VP Adel El Hallack 描述它「almost acts like a CEO」——主 agent 走偏、走进死路、重复旧路径时 nudging 纠偏；⑤ 框架性论断：El Hallack 称「agent 不是模型的 API，而是模型 + 模型周围脚手架（harness：工具集、runtime、skills、libraries）」；⑥ 成本侧旁证：Databricks CEO Ali Ghodsi 称 7 月研究显示**同一模型配不同 harness 可造成 2x 成本差**——「你以为这是贵模型/便宜模型，其实是 harness 的选择」；⑦ 战略立场：Nvidia 强调「开放 harness 栈」（harness/基础设施/runtime 全栈可控）与 OpenAI「因模型引发安全事件而放慢训练」形成对照。URL: https://techcrunch.com/2026/08/21/nvidia-just-showed-that-the-harness-not-the-ai-model-is-now-the-real-hero/

**为什么「100%」比「30%→100%」本身更值得警惕——评测结果的「条件化」正在瓦解「模型排行榜」的单点语义**。ARC-AGI-3 的 100% 不是模型能力的一次跃迁，而是把「模型分数」从单值变成了**依赖 harness 的多元函数**：同一模型（Opus 5），在无 harness 时是 30%，配 AVO 后是 100%——3.3 倍差距完全由外围系统贡献。这与 08-19 的 TTS 在野研究（探索有效、利用失效）形成闭环：当「利用」环节（验证/挑选/纠偏）成为瓶颈时，harness 恰好是补这个瓶颈的工程杠杆——Nvidia 的 supervisor agent 本质上是在「利用」侧加了人工设计的纠错回路。第一性拆解：**模型能力 = 参数知识 × 推理算法 × 外部脚手架**，前三者是「脑」，后者是「肢体与反射弧」。长期以来行业把三者混为一个「分数」，是因为评测基准（单轮、短上下文、无工具）恰好把脚手架需求压到最低；ARC-AGI-3 这类长时程交互任务把脚手架需求放大到与模型本身可比甚至更高——**评测任务越「长时程」，分数越不反映模型、越反映系统**。这意味着：① 基准分数横向对比（OpenAI vs Anthropic vs Google）的语义在长时程基准上快速衰减，必须标注 harness 配置；② OpenAI 的「调两参数 3x」说明**harness 红利窗口极短**——任何公开的 harness 技巧都会在数月内被全行业吸收（market 组辨析给出 6-12 个月窗口判断，本组认同但认为模型侧收敛更快）；③ 对推理基础设施的含义：**软件栈（调度/KV/工具运行时）正在成为「有效模型能力」的乘数**，与 DSV4 的 prefill 预取优化（vllm 侧，MEMORY 记录）同向——这解释了为何 DeepSeek-harness 开源生态能 96h 破 129,607★：**行业共识已从「卷模型」转向「卷 harness」**。

**「AVO」不是孤例：它把 2026 年 agent 领域的三条暗线（开源 harness、监督 agent、成本优化）拧成了明牌**。把 Nvidia 的 AVO 放到今年已出现的 harness 生态里看，位置非常清晰：① **DeepSeek-harness**（开源，96h 129,607★）代表「社区共建型」——base model + 社区打磨的脚手架，胜在旋钮多、可定制、成本透明；② **Claude Code / OpenAI Codex**（商业闭源）代表「深度集成型」——模型 + harness 同厂绑定，胜在开箱性能与模型侧协同（如 Opus 5 与 AVO 的组合红利部分来自 Anthropic 模型对监督信号的顺从性）；③ **Nvidia AVO** 代表「平台中立型」——Nemo 品牌下开源组件，不绑定具体模型，强调「开放 agent 栈」（harness/基础设施/runtime 全栈可控）。三者的共同认知前提：**模型是同质化的，harness 是差异化的**。El Hallack 的一句话最锋利：「开放 harness 让你能转更多旋钮来提升精度，这关系到 OpenAI 因模型引发安全事件而放慢训练」——言下之意：**闭源模型的安全问题正成为开放 harness 的获客理由**，模型层信任赤字在向 harness 层转移。对用户（服务器/AI 基础设施决策者）的具体含义：为内部 agent 平台选型时，「模型绑定深度 vs 可移植性」的权衡将取代「模型分数」成为第一决策变量；而 ARC-AGI-3 100% 证明的「监督 agent 组件」（CEO 式纠偏）应被视作 harness 的**标准件**而非实验特性——它直接把长时程任务的失败率按数量级压低（30%→100% 的增量主要来自此组件，而非记忆优化本身）。

### 长上下文服务工程化

- **FlashPrefill V2: Block-Sparse Prefill Attention for Long-Context LLM Serving——稀疏 prefill 从原型走向生产：128K 上下文 FP8 下比 FlashAttention-2 快 47.26x**（arXiv:2608.19758, 08-20 提交, Qihang Fan/Huaibo Huang/Zhiying Wu/Bingning Wang/Ran He）: （已由 ai-frameworks 组收录，此处补服务侧关键数据）① 定位：V1 是「算法原型」，V2 沿三个维度进化为「生产可用」——**mean correction term** 抑制稀疏化近似误差（极限稀疏下性能退化可控）、**PackGQA 内存访问 + warp specialization + pingpong pipelining** 完全对齐 FlashAttention-3/4 实现并支持 FP8 推理、**原生支持 paged KV cache 与 continuous batching**（可直接作为 SGLang 等现代推理框架的 attention 后端）；② 量化数据（NVIDIA H20——「部署最广的推理加速器」之一）：128K 上下文下 FP8 精度较 FlashAttention-2 **加速 47.26x**、BF16 下 **27.19x**；FP8 下对比 FA3/4 对齐的 dense 基线仍快 **30.49x**；③ 信号含义：prefill 是长上下文推理的计算瓶颈（O(N²)），稀疏化 + FP8 + 生产集成三件套意味着**「长上下文推理的成本结构正在被系统层重构」**——与 08-21 的 MoNe（记忆外置 + 测试时学习，计算/内存双降 80%）、ai-frameworks 的 WhiteMatter（KV mixing 架构）构成 2026-08 长上下文三条并行优化路径：**算（稀疏注意力）→ 存（KV 压缩/记忆外置）→ 管（paged KV + 批处理）**。https://arxiv.org/abs/2608.19758

### 自动科研评测

- **FormalTCS: Benchmarking End-to-End Frontier Formal Theoretical Computer Science Research of LLMs——自动理论计算机科学研究的两大瓶颈被量化：autoformalization 11.5 vs 28.6，生成 64 条仅 6 条通过**（arXiv:2608.20153, 08-20 提交, Dingzirui Wang/Xuanliang Zhang/Keyan Xu/Qingfu Zhu/Wanxiang Che）: ① 基准构成：**175 个实例**，全部来自 STOC/FOCS/SODA/COLT 2025-2026 录用论文，保留论文特有定义/假设/证明依赖，并附专家验证的 Lean 形式化与证明——「端到端前沿科研」而非玩具题；② 核心发现一（形式化瓶颈）：**autoformalization 是当前最尖锐的瓶颈**——最佳模型把自然语言命题翻译成形式化定理仅得 **11.5 分**，而给定形式化陈述后证明（Pass@8）可达 **28.6**——**「把想法说成形式语言」比「在形式语言里证明」难 2.5 倍**；③ 核心发现二（品味瓶颈）：自动 TCS 研究框架生成 64 条新命题，**仅 6 条**通过专家评估 + 证明验证（通过率 9.4%）——论文称之为「limited research taste」：模型能生成、能形式化、能证明，但**「什么值得证明」这个判断**仍是最大障碍；④ 信号含义：与 08-21 的 AI Post-Training 实证（策略级缺口）、WER（自写 skill 差 8-11 分）构成三连证——**LLM 自动化的天花板不在「执行」，在「选题/策略/品味」**；FormalTCS 的价值在于它把「品味」第一次变成了可度量的基准指标（6/64），为后续「品味训练」提供了标尺。https://arxiv.org/abs/2608.20153

**这份数据的三个读法——份额、归因、方法论，每一层都值得拆开**。第一层（份额）：Anthropic 从 5 月 41% 到 7 月 44% 的爬升看似稳固，但 OpenAI 的 Q3 反超提醒我们**44% vs 40% 的 4 个百分点在「季度内可逆」的粒度上没有任何护城河含义**——两家实验室的模型发布节奏（半年一代）决定了份额曲线是锯齿状而非阶梯状。第二层（归因）：Kharazian 把 OpenAI 的反超直接归给 GPT-5.6 Sol 的产品力、把 Fable 5 的疲软归给「价格 + 监管者要求的数据保留」——**Fable 5 的 30 天数据保留政策值得单独记录**：Anthropic 为满足监管（数据可追溯/合规审计）牺牲了企业采用率，这是「合规优先 vs 采用优先」的正面碰撞，且发生在同一实验室的高端产品线上（Fable 是 Anthropic 的高端 tier，比通用聊天机器人更针对特定用例，本就更依赖数据敏感的客户）——**合规成本第一次以「市场份额」的形态被量化**。第三层（方法论）：Ramp 是「支付数据」而非「调研问卷」——支付流水的优点是**无自我报告偏差**（企业不会「声称」用了什么，只会「真的付钱」），缺点是样本偏科技业、排除大型企业（用 AmEx 等）——但恰恰是**科技业样本**对「模型采用」最敏感，因为科技企业的切换成本最低、对模型发布最敏感。**支付数据 + 模型路由器的组合（Ramp 自己就有 Router）正在成为 B 端 AI 采用的「埋点系统」**——这类数据源的商业价值与信息价值都在快速上升。

## 📌 今日信号

**信号 1 — harness 时代开启：模型评测从「单点分数」走向「条件化系统分数」，推理软件栈成为能力的乘数**。今日头条的 ARC-AGI-3 100%（Opus 5 + AVO）与昨日 TTS 在野研究（利用端验证瓶颈）、本月 DeepSeek-harness 爆火（96h 129,607★）、Databricks 2x 成本差四件事拼出完整图景：**2026H2 的 agent 性能竞争已从模型权重转移到 harness 工程**。第一性拆解：agent 任务 = 模型推理 × 记忆管理 × 工具调用 × 纠错回路，其中后三者全部由 harness 决定。Nvidia 的 supervisor agent（CEO 式纠偏）本质是把「人类专家在任务执行中的元认知监控」工程化——模型负责局部决策，harness 负责全局方向。对基础设施侧的含义有三层：① **推理服务栈的差异化价值上升**：同一模型（如 Opus 5）在不同 harness 下分数差 3.3 倍、成本差 2x——「模型即商品、服务栈即竞争力」的格局在 agent 场景成立，这与用户「软件栈决定有效算力利用率」的判断（market 组辨析）完全同向；② **评测基准需要「harness 标注」**：ARC-AGI-3 类长时程基准的分数如果不注明 harness 配置将失去横向可比性——评测基础设施（LLM-as-judge、验证器）本身也在被 harness 化（昨日 VAL/Stopping Judge Panels 同向）；③ **开放 harness 是下一个「开源模型」级战场**：Nvidia 的 Nemo 开放栈、DeepSeek-harness 开源生态、Claude Code/Codex 商业闭源形成三极——开放 harness 的「旋钮数量」优势（El Hallack 原话）对应可控性，闭源 harness 的集成深度优势对应开箱性能，这个张力将决定 agent 开发者的默认选择。

**信号 2 — 企业 AI 支出的「摇摆性」：Ramp 数据证明 B 端份额由「最近一次模型发布」驱动，sticky 假设被证伪**。Ramp 的 70,000+ 企业数据给出了目前最干净的 B 端份额快照：5 月 Anthropic 41% vs OpenAI 39%（OpenAI 失守），7 月 44% vs 40%（Anthropic 扩大），但 Q3 至今 OpenAI 反超增速——归因直接落在**模型产品力**上：GPT-5.6 Sol 受开发者欢迎、Fable 5 因价格 + 30 天数据保留拖累采用。第一性分析：**企业 AI 支出的迁移成本 = 重新集成成本 + 数据迁移成本 + 切换风险**，当模型以 API 形式消费、应用层做了模型抽象（如 Ramp 自己就有 Router）时，这三个成本都被压低——「模型路由器」的普及（Stripe-OpenRouter $7.5B 收购、Ramp 自建 Router，均昨日已收录）正在把企业从「单模型锁定」中解放出来，而**模型路由器恰恰是摇摆性的基础设施**：路由层存在 → 切换成本低 → 份额随模型发布波动。对两家实验室的含义：**护城河不在「上一个模型」，在「下一个模型」+「数据/合规绑定」**（Anthropic 的 30 天保留政策是双刃剑：合规强但吓退数据敏感客户）。对用户的含义：B 端份额数据（Ramp 类支付数据源）比发布会 PPT 更接近真实采用率，值得纳入跟踪体系——但需注意样本偏科技业、排除大型企业（AmEx 客户）的偏差。

**信号 3 — 自动科研的「双重瓶颈」被形式化：autoformalization（11.5 vs 28.6）与 research taste（6/64）——「表达形式化」比「形式内推理」难，「选什么题」比「怎么证明」更难**。FormalTCS 是本周自动科研评测最有信息量的基准：它第一次把「前沿科研」（STOC/FOCS/SODA/COLT 2025-2026 论文）变成端到端可测的流水线（生成→形式化→筛选→证明），并给出两个反直觉的量化结论：① **形式化是比证明更硬的瓶颈**——模型在给定形式化陈述时 Pass@8 28.6，但自己把自然语言变形式化只有 11.5，差了 2.5 倍；这颠覆了「证明最难」的直觉：**对 LLM 而言，「精确表达」比「逻辑推理」更难**，因为形式化需要把隐式假设/上下文依赖全部显式化（论文特意保留论文特有定义与证明依赖）；② **品味是比形式化更深的瓶颈**——64 条生成命题仅 6 条通过（9.4%），即使形式化+证明能力都够，模型仍不知道「什么值得证明」——这是 08-21 三个信号（AI-for-AI 策略级缺口、WER 自写 skill 劣化、Open-MOPD 能力整合缺口）在「科研选题」场景的定量翻版。因果链梳理：**执行级能力（写代码/调参/证明）已被 RL 信号覆盖 → 策略级能力（选题/换方法/品评价值）缺乏可监督信号 → 形式化处于两者之间（有验证器但表达歧义大）**。对用户「判断力不可外包」原则：FormalTCS 的 6/64 是最新的实证注脚——**「研究品味」在未来 12-24 个月内仍将是人类研究者的核心壁垒**，AI 能做的是把 64 条候选压缩成 6 条让人类挑。

**信号 4 — 长上下文服务进入「工程化竞赛」：稀疏算子（47.26x）+ KV 复用（ReCache）+ 记忆外置（MoNe）三路并进，推理成本结构正在被系统性改写**。FlashPrefill V2 的意义不在算法创新（块稀疏注意力 V1 已有），而在**生产化三件套**：误差校正项（极限稀疏下可控）、FA3/4 对齐的算子（warp specialization + pingpong pipelining + FP8）、原生 SGLang 集成（paged KV + continuous batching）。它用 H20（部署最广的推理加速器之一）做基准而非 H100/H200，说明目标是**存量算力的实际收益**——47.26x（FP8, 128K）不是实验室数字，是「现有集群换算子即可获得」的收益。与 ReCache（工具 agent KV 重用）、MoNe（记忆外置，昨日）、WhiteMatter（KV mixing 架构，ai-frameworks）拼图：**长上下文成本优化已从「单点技巧」变成「算子-缓存-架构-调度」四层工程体系**。第一性看：prefill 的 O(N²) 是物理瓶颈，但稀疏化把有效复杂度降到 O(N·k)（k=每块保留的 top 块数），FP8 把常数项砍半——**「长上下文」的经济学拐点正在到来**：128K 上下文推理从「贵到只给旗舰模型用」走向「默认可用」，这会反过来推高应用的上下文需求（上下文长度是「供给创造需求」最典型的算力品类）。对推理平台的含义：attention 后端的选择（dense vs sparse）、KV 管理策略（paged/复用/压缩）、精度策略（FP8 量化）将决定**同一 GPU 上长上下文服务的毛利差**——软件栈从「能用」到「好用」的差距在此显性化，与信号 1 的「harness 乘数」共同指向同一个结论：**2026H2 推理竞争力在软件栈，不在芯片纸面算力**。
