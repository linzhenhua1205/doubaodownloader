## 📚 arXiv 精选

### 推理与训练数据

- **Reasoning Core: Designing Broad Procedural Data for Completion-Supervised Reasoning Training**（arXiv:2608.05148）: 为"补全监督"推理训练设计宽泛程序化数据，覆盖多类过程性推理任务，20 页含数据与代码开源。https://arxiv.org/abs/2608.05148

- **Toward Skill-Native LLMs: Skill Entropy for Benchmarking and Training Long-Horizon Reasoning**（arXiv:2608.05139，含 Sanjeev Arora）: 提出"技能熵"（Skill Entropy）量化长程推理中的技能多样性与熟练度，同时用于基准评测与训练目标——技能原生（skill-native）模型新视角。https://arxiv.org/abs/2608.05139

- **Chained Recursive Language Models for Multi-Iteration Reasoning**（arXiv:2608.05124）: 链式递归 LM 支持多轮迭代推理，信息论视角分析迭代增益边界。https://arxiv.org/abs/2608.05124

- **Protoreasoning in Tiny Transformers**（arXiv:2608.04980）: 微型 Transformer 中的"原推理"（protoreasoning）能力研究——小模型推理萌芽态的可观测性。https://arxiv.org/abs/2608.04980

- **EASy: Towards Efficient LLM-Based Agentic System**（arXiv:2608.04588）: 面向 LLM Agent 系统的效率优化框架（preprint）。https://arxiv.org/abs/2608.04588

### Agent 与记忆

- **State2State: Environment-Derived Mid-Training for LLM Agents**（arXiv:2608.04934，姚期智/张亚勤团队）: 从环境状态迁移中构造中间训练（mid-training）数据提升 agent 能力——环境派生的状态转换学习。https://arxiv.org/abs/2608.04934

- **Caching for the Future: Scrub Jay Episodic Memory Principles for Agent Memory Systems**（arXiv:2608.04746）: 借鉴灌丛鸦（scrub jay）情景记忆"为未来缓存"的生物学原理，设计 agent 记忆系统——缓存未来要用什么，而非过去用过什么。https://arxiv.org/abs/2608.04746

- **The Personalization Mirage: How LLMs Fabricate User Profiles, and Why Self-Monitoring Misleads**（arXiv:2608.04570）: LLM 会"编造"用户画像，且自我监控反而误导个性化判断——个性化幻觉的系统性研究。https://arxiv.org/abs/2608.04570

- **When Memory Lies: An Empirical Study of Spatial Memory Staleness in VLM Agents**（arXiv:2608.04574）: VLM agent 空间记忆过期（stale）实证——记忆与环境的漂移是 agent 长程任务失败源之一。https://arxiv.org/abs/2608.04574

- **InsightEmb: Learning Action-Intent Embeddings for Agentic Insight Retrieval**（arXiv:2608.04761）: 为 agent 洞察检索学习"动作-意图"嵌入，连接行为与洞察。https://arxiv.org/abs/2608.04761

- **Guideline-as-Oracle: Zero-Annotation Training of an Ophthalmic Telephone Triage Agent**（arXiv:2608.04772）: 以临床指南为 oracle 实现零标注训练眼科电话分诊 agent——领域知识即标注源的范式。https://arxiv.org/abs/2608.04772

- **EmpaAva: An Open-source Agentic 3D-Avatar Empathetic Live Chatbot**（arXiv:2608.04709）: 开源 agentic 3D 头像共情实时聊天机器人（含 demo）。https://arxiv.org/abs/2608.04709

- **Spoken Function Calling: A New Perspective on Spoken Language Understanding for Large Audio Language Models**（arXiv:2608.05126, ACM MM 2026）: 语音函数调用——语音理解与工具调用的新交叉点。https://arxiv.org/abs/2608.05126

- **A-SR: Self-Evolving Agentic LLMs for Symbolic Regression via Hierarchical Coordination**（arXiv:2608.04872）: 分层协调的自进化 agentic LLM 用于符号回归，AI4Science 场景。https://arxiv.org/abs/2608.04872
