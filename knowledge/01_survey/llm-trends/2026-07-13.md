## 🔥 头条三：陶哲轩合著 AI4Math 路线图 — 从解题到数学研究

**来源**: arXiv:2607.07779 (Jul 10, 2026)

### 论文背景

| 维度 | 详情 |
|:-----|:------|
| **作者阵容** | Eric Jiang, Xiao Liang, ... **Terence Tao**（陶哲轩，菲尔兹奖得主）, Wei Wang 等 |
| **定位** | Position Paper，关于 AI4Math 从「解题者」到「研究伙伴」的系统性路线图 |
| **方法** | 基于交互式定理证明（ITP）的 LLM 驱动形式化证明 |
| **同行** | 涵盖数据集、自动形式化（auto-formalization）、证明合成（proof synthesis） |

### 核心论断

| 维度 | 观点 |
|:-----|:------|
| **现状** | LLM 驱动的形式化证明在已知问题上取得显著成功，但**无法处理前沿研究数学** |
| **核心瓶颈** | 开放性问题通常是**开放式的、不明确规范的、涉及多层抽象** |
| **所需转变** | 从预定义的解题器（problem-solver）→ 能够应对前沿挑战的**研究代理（research agent）** |
| **五大不足** | 数据集、关系结构、数学探索、工具生态、人机协作 |
| **输出** | 系统性综述 + 未来战略路线图 |

### 意义

- **陶哲轩本人参与**意味着这篇 roadmap 不仅是学术综述，更是**顶级数学家对 AI4Math 的判断**
- 呼应 AI 行业从「代码生成/解题」到「科学研究」的宏观转型趋势
- 与 DeepSearch-World（自蒸馏搜索 Agent）、WebSwarm（递归多 Agent 编排）等论文共同指向 **Agent 从执行→研究**的范式迁移

## 📄 arXiv 亮点（Jul 10 新收录）

### 1️⃣ 内部表征校准 — Probing 揭示模型"提前知道答案"

**来源**: arXiv:2607.08046 (Jul 10, 2026) — What LLM Forecasters Know but Don't Say

| 维度 | 数据 |
|:------|:------|
| **发现** | LLM 在生成推理链（CoT）**之前就固定了答案和置信度** |
| **方法** | 训练基于中间层激活的 Representation-Pooling Probes |
| **效果** | 校准质量远超 CoT 采样法；作为"测谎仪"追踪行为变化 |
| **Token 节省** | 根据预设答案分布的分散度路由问题可节省 **30-47%** 生成 token，精度无损 |
| **意义** | 证明内部表征可作校准、审计、路由的实用工具 |

### 2️⃣ HSP — 幻觉自博弈：小模型自进化匹配大模型（COLM 2026）

**来源**: arXiv:2607.07993 (Jul 10, 2026) — Hallucination Self-Play

| 维度 | 数据 |
|:------|:------|
| **方法** | 检测器（Detector）↔ 生成器（Generator）自博弈闭环 |
| **流程** | 检测器在标注数据上微调 → 作为奖励模型用 RLAIF 训练生成器 → 进化后的生成器产生更难检测的幻觉数据 → 再训练检测器 |
| **效果** | 小 LLM **渐进匹配甚至超越**高级 LLM 的幻觉检测能力，无需外部监督 |
| **接收** | **COLM 2026** |
| **意义** | 自博弈框架第三次在安全/对齐领域被验证有效（继 LPA、HSP） |

### 3️⃣ Tool-Making Agents — 生产环境 p50 延迟降 42%，错误率降 53%

**来源**: arXiv:2607.08010 (Jul 10, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | Agentic Tool-Making Pipeline：将反复执行的 SOP 步骤预编译为已验证的版本化工具 |
| **部署** | 在**实际物流中心告警系统**（44 节点 SOP，异构指标后端）中部署 |
| **p50 延迟** | 工具调用降低 **42%** |
| **错误率** | 在 1,500 个历史告警上降低 **53%** |
| **进一步优化** | 直接调用架构（Direct-Call）再降 **62%** |
| **意义** | 证明「自进化 Agent 制作工具」不是实验室概念，在生产环境中可测量地提升速度+可靠性 |

### 4️⃣ PLURAL — 50 万对跨国价值对齐数据集

**来源**: arXiv:2607.08034 (Jul 10, 2026)

| 维度 | 数据 |
|:------|:------|
| **规模** | ~**500,000** 偏好三元组，覆盖 **20 个国家** |
| **基础** | Integrated Values Survey（IVS）— 全国代表性调查，92 国 |
| **方法** | 两阶段生成管线：调查响应 → 保持价值信号的合成偏好三元组 |
| **语言** | 当前覆盖西班牙语等，框架可扩展至其他语言 |
| **效果** | MAE 降 **27.7%**；176 人在印度/巴西/日本判断对齐后回复更代表本国价值 |
| **意义** | 为**多元价值对齐**（Pluralistic Alignment）提供首个大规模开源资源 |

### 5️⃣ Structured Pruning — 结构化剪枝精度 ≈ 非结构化

**来源**: arXiv:2607.08027 (Jul 10, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 幂变换 + 保留符号的分数聚合 + 基于百分位的异常值消除 |
| **效果** | Llama-3-8B / Vicuna-13B / LLaVA-13B 上精度接近非结构化剪枝，同时获得**实际推理加速** |
| **意义** | 解决了结构化剪枝长期存在的**异构分数分布偏差**和**符号信息丢失**问题 |
