## 🔥 头条一：Frontis-MA1 开源 35B AI4AI 模型 — 递归自我改进逼近闭源前沿

| 维度 | 数据 |
|:-----|:-----|
| **定位** | 首个面向 **递归自我改进（RSI）** 的开源 AI4AI 模型（35B），配套 OpenMLE 全栈开源（Gym 环境 + RL + 长视野搜索 Evo） |
| **核心机制** | 四个原子程序进化算子（Draft/Improve/Debug/Crossover）经执行反馈 SFT+RL 训练，再组合为长视野搜索，训练与进化单一闭环 |
| **MLE-Bench Lite 成绩** | 基座 39.39% → OpenMLE-Evo **60.61%**（+21.2pp）→ Evo-Max **71.21%**，**超过 GPT-5.5 + Codex，接近 GPT-5.6 Sol 与 2.8T Kimi K3** |
| **约束条件** | 单卡 RTX 4090（12GB VRAM）· 每任务 12h 预算 |
| **迁移验证** | NatureBench Lite：换模型 Match-SOTA 50%→70%；换 Evo 框架 20%→50% — 模型与框架贡献可分离 |
| **开源** | 模型权重 + OpenMLE 全栈已释放（github.com/FrontisAI/OpenRSI） |

**信号**: 开源侧首次出现"小模型 + 进化搜索"逼近闭源巨头的实证路线；"改进 AI 的 AI"从概念走向可复现工程。

**来源**: [arXiv:2607.28568 — Frontis-MA1: Training an AI4AI Model towards Recursive Self-Improvement in MLE](http://arxiv.org/abs/2607.28568)

## 🔥 头条二：ORCA-bench — 前沿编码 Agent 在生产可靠性上远未就绪

| 维度 | 数据 |
|:-----|:-----|
| **定位** | 首个生产保真 **oncall 值班 RCA** 基准：真实 OpenTelemetry 微服务系统（6 天指标/日志/链路，Prometheus+Jaeger+Grafana）+ **1,079 个 RCA 任务** |
| **结果** | 5 个前沿 agent：Medium 难度最佳 RCA 准确率仅 **25.3%**，Hard 仅 **10.0%**；**Claude Fable 5 也未突破** |
| **最弱模型** | 40% 的 incident 报告幻觉出不可信的根因 |
| **关键结论** | 移除源码访问→所有指标下降；报告称该差距是"生产可靠性工程投入的下界"（真实系统比测试床大数量级） |
| **质量** | LLM-as-judge 与人工重打分 Cohen's κ_w=0.90 |

**信号**: 编码 agent 在"写代码"上进展迅猛，但在"生产事故定位"上差距巨大——运维可靠性是比代码生成更难啃的硬骨头。

**来源**: [arXiv:2607.28545 — ORCA-bench: How Ready Are Language Model Agents for Oncall?](http://arxiv.org/abs/2607.28545)

## 📰 其他重要动态（arXiv 精选 13 篇）

### A. 推理效率与模型技术

**1. WIDE — token 级动态宽度剪枝**（[arXiv:2607.28418](http://arxiv.org/abs/2607.28418)）
- 首个端到端可微的 token 级动态宽度剪枝框架：每个 token 动态选择 attention-head 组与 FFN-channel 组，粒度到 neuron-block 级
- 50% 稀疏度下：prefill 内核加速 **1.98×**、decode **4.95×**，端到端 1.68×/1.55×（接近理论极限）
- 剪枝-内核协同设计：mask 重排 + 硬件无关块级跳过 + 硬件相关块内跳过

**2. Lightning OPD 2.0 — 跨教师蒸馏风格偏差缓解**（[arXiv:2607.28449](http://arxiv.org/abs/2607.28449)）
- 解决 OPD 依赖"教师一致性"的约束：SFT 数据生成者与蒸馏教师可独立选择
- 交叉拟合风格残差化（rollout-level）剥离 style-token 偏差
- Klear-Reasoner-8B-SFT 起点：**AIME 2024 82.4%** / LiveCodeBench v5 **63.0%**

**3. SVR — 自验证细化控制测试时算力**（[arXiv:2607.28457](http://arxiv.org/abs/2607.28457)）
- 免外部验证器的多轮 RL：模型产出答案+正确性判定+置信度，自验证作为"计算控制策略"
- Qwen3.5-2B 七项数学基准 **0.563**（仅平均 **2.99** 推理轮），超过固定 10 轮基线

**4. Stage-Replay Divergence — KV cache 精度与轨迹可复现**（[arXiv:2607.28495](http://arxiv.org/abs/2607.28495)）
- 审计"stage-replay 诊断"假设：Qwen2.5 系模型 200 项对照中 BF16 出现 166 个后缀分歧，**FP32 分歧率上界 1.88%**
- 48 层 KV 双向移植使分歧轨迹完全跟随 cache 供体（24/24 + 43/43 复现）

### B. Agent 评估与工具

**5. OSReward — CUA 轨迹奖励模型标准化评估**（[arXiv:2607.28609](http://arxiv.org/abs/2607.28609)）
- 首个系统评估 VLM judge 对 computer-use agent 轨迹的可靠性：SOTA 模型存在**系统性宽松偏差**（把失败判成成功）
- 发布 OS-Shepherd 9B/35B 开源奖励模型，**成本比前沿 judge 低 30-60%**

**6. Change2Task — 从 PR 批量生成可执行编码任务**（[arXiv:2607.28591](http://arxiv.org/abs/2607.28591)）
- 把合并的 PR 转换为健康代码库上的验证任务：79.6% 验证成功率，比 PR 基线多恢复 29.2% 任务，复用现代基座省 10.8% 成本

**7. PACE — LLM 执行父订单**（[arXiv:2607.28410](http://arxiv.org/abs/2607.28410)）
- 首个 LLM 算法交易执行研究（从"买什么"到"怎么执行"）：层级规划+执行框架，深交所 Level-1 数据上超 TWAP/Almgren-Chriss 最强基线 **0.65bps**
- LLM 行为差异：高置信→更好表现（与人相反），且倾向于早执行而非拖延

### C. 对齐、安全与社会影响

**8. AISPA — 系统提示审计框架**（[arXiv:2607.28617](http://arxiv.org/abs/2607.28617)）
- 审查 **88 个商业 AI 产品、3,249 条系统提示指令**：约 **40% 产品含至少 1 条不利于用户的指令**，且保护性与问题指令常共存
- 保护性指令覆盖浅：98.9% 产品有 ≥1 条，但仅 24% 覆盖全部 8 个维度

**9. SaliTrap — LLM 常识推理显著性偏差**（[arXiv:2607.28478](http://arxiv.org/abs/2607.28478)）
- 12 个主流 LLM 全部受"显著性偏差"影响：显式干扰项（如数字）劫持模型，忽略隐含物理常识
- **关键发现：这是知识抑制而非知识缺失** — 去框架提示后恢复 90%+ 失败，轻量推理期提示即可大幅弥补，无需重训

**10. 安全微调抑制心智归因与精神信仰**（[arXiv:2607.28607](http://arxiv.org/abs/2607.28607)）
- 安全微调不仅压制模型自我意识归因，还连带降低对非人动物/自然物的心智归因与精神信仰
- 消融 safety-refusal 方向 + steering 意识向量可恢复，且不损伤 Theory of Mind — 社会推理机制上独立

**11. LLM 无法模拟人类信念更新**（[arXiv:2607.28347](http://arxiv.org/abs/2607.28347)）
- 6 个 LLM vs 391 名真实被试：仅 Qwen3-32B/GPT-5-Mini 在**给定真实初始立场**时能匹配后验分布；全部无法自生成初始立场
- 系统性偏差：过度中立、更频繁但更小的信念偏移、无法按说服力排序评论

### D. 科学应用与多模态

**12. AskChem — 化学文献 claim 级检索基础设施**（[arXiv:2607.28618](http://arxiv.org/abs/2607.28618)）
- 检索单元从"论文"变为"带出处的 claim"：2.4M claims / 147K 论文，REST/SDK/MCP 接口供 agent 使用
- GPT-5.5 reader 结合 AskChem：**100% 可解析 DOI**（无检索 88.3%），引用密度五系统最高

**13. GLM-RAG — 图语言模型检索器**（[arXiv:2607.28397](http://arxiv.org/abs/2607.28397)）
- 微调 GLM 检索器跨域泛化最佳：两个多跳基准 SOTA；GNN 检索器图覆盖率高但训练昂贵；向量基线单跳最强 — 三种范式互补
