### 1. TCA-SIR — 目标条件抽象的科学灵感检索（07-30）

| 维度 | 数据 |
|:-----|:-----|
| **问题** | 科学假设生成中，现有 SIR 方法按主题相似度排序，无法表达"候选灵感如何迁移到目标问题"——对远程灵感（remote inspiration）尤其失效 |
| **方案** | 将 SIR 重构为**目标条件抽象（TCA）**：检索对象是从候选中提取的、专门针对目标的**可迁移抽象原则**；学习生成 TCA 并预测迁移性 |
| **效果** | ResearchBench 上 HitRate@top4% 比 MOOSE-Chem **高 >10pp**，优于先验 SIR 方法和直接 LLM 检索 |
| **附加价值** | 学到的抽象比未训练 TCA prompt 更能恢复目标相关机制——既提升检索又提供可解释理由 |

**来源**: [arXiv:2607.28498 — TCA-SIR: Learning Target-Conditioned Abstractions for Scientific Inspiration Retrieval](http://arxiv.org/abs/2607.28498)

### 2. Beyond Sentiment — 金融新闻结构化信息抽取（07-30）

| 维度 | 数据 |
|:-----|:-----|
| **核心假设** | 金融新闻编码多个正交信息维度（事件类型/影响范围/时间跨度/语义置信度），单一情感分无法捕捉 |
| **方法** | LLaMA-3.1-70B 从新闻抽取 **6 个语义维度**，在 FNSPID 数据集 41,618 条 新闻-股票 对上实验 |
| **关键发现①** | FinBERT 情感特征在非线性模型下 F1=**0.576**，线性模型仅 **0.230** —— 情感-收益关系高度非线性 |
| **关键发现②** | LLM 结构化特征与情感 **53.5% 系统性分歧率** —— 捕获正交于情感的信息 |
| **关键发现③** | 双信号融合 F1=**0.600**（p<0.0001），超越任一单独信号；非情感维度独立贡献 ΔF1=+0.019 |
| **结论** | 6 个维度贡献均衡（14-21%），把新闻压缩为单一情感分会造成大量信息损失 |

**来源**: [arXiv:2607.28496 — Beyond Sentiment: Structured Information Extraction from Financial News](http://arxiv.org/abs/2607.28496)

### 3. ESPP — 人格小组模拟评估生成式 UI（07-30）

| 维度 | 数据 |
|:-----|:-----|
| **问题** | 单 LLM-as-judge 只反映单一隐含视角，无法捕捉不同人群对同一 UI 的感知差异 |
| **方案** | **ESPP 三阶段**：心理多样性、证据锚定的人格小组独立评分 → 特征衍生有界共识机制下交换意见 → Delphi 式社会加权聚合 |
| **效果** | 与人类判断 Pearson r 从 **0.716 → 0.922**；prompt-ensemble 对照组仅恢复约 1/3 差距 → 人格+证据锚定是主导改进源 |
| **附加发现** | 保留个体评分发现：用户子组对整体模型排名一致、但在具体评分维度上严重分歧 —— 单一同质 judge 会系统性抹平这种结构性分歧 |

**来源**: [arXiv:2607.28439 — Beyond a Single Judge: Simulating Social Persona Panels for Generative UI Evaluation](http://arxiv.org/abs/2607.28439)

### 4. Fairness Pruning — GLU-MLP 层人口统计偏差定位（07-30）

| 维度 | 数据 |
|:-----|:-----|
| **方法** | 最小对比 prompt 对 + 推理期激活捕获，定位对人口属性**差异反应的神经元**（down_proj 输入处评估） |
| **模型** | 至 3B 参数（Llama-3.2 系列 + Salamandra-2B） |
| **关键发现①** | 归零识别神经元改变模型对相关人口变量的响应，但产生**双向偏差失稳**（BiasScore 无符号 → 候选集混合推/拉刻板印象的神经元） |
| **关键发现②** | 干预极度外科手术式：**≤40 个神经元**（<0.031% MLP 宽度）即有效，能力保留 **99.49%** |
| **结论** | 实证确认人口偏差处理与模型能力运行在**可分离电路**上 —— 从"盲归零"走向"定向行为调制"的方法论基础 |

**来源**: [arXiv:2607.28319 — Fairness Pruning: Locating Demographic Bias in GLU-MLP Layers via Differential Activations](http://arxiv.org/abs/2607.28319)

### 5. VAD — 多模态在策略蒸馏的视觉归因（07-30）

| 维度 | 数据 |
|:-----|:-----|
| **问题** | 多模态 OPD 的 next-token 纠正是"源混合"的（视觉信号+语言先验+教师效应混杂），关键问题是估算哪些纠正是由视觉证据支持的 |
| **方案** | **反事实目标重构**：在每个学生生成前缀处，让同一教师分别在有/无视觉证据下评估，中心化 log-prob 变化量作为视觉证据方向的符号代理，投影原纠错得到干预对齐成分 |
| **效果** | 6 个细粒度视觉基准 × 4B/9B 规模，全面优于直接特权视图蒸馏与视觉优势加权；证据反驳错误答案时目标偏移更强 |
| **意义** | 反事实目标重构成为源混合监督的有效替代 |

**来源**: [arXiv:2607.28590 — VAD: Attributing Visual Evidence for Target Reconstruction in Multimodal On-Policy Distillation](http://arxiv.org/abs/2607.28590)
