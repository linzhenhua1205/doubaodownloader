### 2. 🌊 惊艳发现：只需训练**一个 Transformer 层**即可匹配全参数 RL 训练效果

**论文**: [Is One Layer Enough? Training A Single Transformer Layer Can Match Full-Parameter RL Training](https://arxiv.org/abs/2607.01232)
**来源**: arXiv:2607.01232 · July 1, 2026

| 维度 | 数据 |
|:-----|:------|
| **核心发现** | 训练**单个 Transformer 层**可以恢复全参数 RL 训练的大部分收益，某些情况下**甚至超越** |
| **关键度量** | 引入 **layer contribution** 指标：单层训练恢复的全 RL 收益比例 |
| **验证范围** | 7 个模型 × 2 个模型家族（Qwen3, Qwen2.5）× 3 种 RL 算法（GRPO, GiGPO, Dr.GRPO）× 多种任务域（数学推理、代码生成、Agent 决策） |
| **稳定模式** | RL 收益高度集中在**中间层**小部分层（甚至单层）中；输入/输出端贡献显著较低 |
| **层排序稳定性** | 跨数据集、任务、模型家族、RL 算法的**层贡献排名高度相关** |

**行业意义**:
- 对当前大规模全参数 RL 的**效率提出根本性质疑**——如果大多数层是"搭便车"的，那全参数更新浪费了大量算力
- 为**高效 RL 微调**开辟新方向：只更新高贡献中间层，可能大幅降低 RL 训练成本
- 挑战了 RL 社区"每层均匀贡献"的默认假设

### 3. 🧠 AutoMem：将记忆管理训练为独立认知技能——32B 开源模型匹敌旗舰闭源

**论文**: [AutoMem: Automated Learning of Memory as a Cognitive Skill](https://arxiv.org/abs/2607.01224)
**来源**: arXiv:2607.01224 · July 1, 2026 · [项目主页](https://autolearnmem.github.io/)

| 维度 | 数据 |
|:-----|:------|
| **核心思想** | 将 LLM 的记忆管理视为一种**可训练技能**（认知科学中的元记忆/metamemory） |
| **方法** | 两循环自动化：⓵ 强 LLM 审阅完整 Agent 轨迹并迭代改进记忆结构；⓶ 从多个 episode 中识别好的记忆决策作为训练信号 |
| **基准测试** | Crafter, MiniHack, NetHack 三个长时程程序化生成游戏 |
| **效果** | **仅优化记忆**（不修改模型任务行为）使 32B 开源模型提升 **~2x-4x**，**与 Claude Opus 4.5 和 Gemini 3.1 Pro Thinking 相当** |
| **意义** | 证明记忆管理是独立可学习的技能，在长时程任务中是**高杠杆优化目标** |

**行业意义**: 该工作证明在长时程 Agent 场景中，"记什么、怎么记"比"模型多大"更关键。为开源模型提供了绕开参数规模的竞争路径。

### 4. 🗣️ Message Passing Language Models (MPLMs)：多 LLM 线程直接通信，推理效率超越 CoT

**论文**: [Message Passing Enables Efficient Reasoning](https://arxiv.org/abs/2607.01077)
**来源**: arXiv:2607.01077 · July 1, 2026

| 维度 | 数据 |
|:-----|:------|
| **核心创新** | LLM 线程通过轻量 **send/receive 原语**直接点对点通信，而非 Fork-Join 的广播同步 |
| **两个关键机制** | ⓵ **减少通信开销**：避免冗余上下文共享；⓶ **抢占**：线程可基于部分信息提前终止 |
| **Sudoku 结果** | **渐近更小的上下文**（比串行 CoT 和并行 FJ 都小），25×25 谜题对标准 CoT/FJ 和前沿推理模型仍具挑战性 |
| **3-SAT 结果** | 抢占机制允许提前终止无望分支，提升效率 |
| **大模型兼容性** | 适当提示后，大模型可直接遵循 MPLM 协议，无需微调 |

**意义**: 将消息传递计算范式引入 LLM 推理，是对 CoT 顺序扩展和 Fork-Join 并行扩展之外的**第三种推理扩展范式**——分布式通信扩展。

### 5. 🔬 CausalMix：将数据混合优化建模为因果推断问题——超越 RegMix

**论文**: [CausalMix: Data Mixture as Causal Inference for Language Model Training](https://arxiv.org/abs/2607.01104)
**来源**: arXiv:2607.01104 · July 1, 2026

| 维度 | 数据 |
|:-----|:------|
| **问题** | 传统数据混合方法假设静态分布，数据池变化时需要**从头重新训练** |
| **方法** | 将数据池统计特征建模为**协变量**、领域混合为**处理**，用 512 次小模型（Qwen2.5-0.5B）运行拟合因果模型 |
| **效果** | 在 800K 数据池上推断最优混合比，**直接用于训练 7B 模型**并取得更好效果 |
| **扩展性** | 成功推广到长 CoT 数据（Qwen3-4B-Base） |
| **对比** | 持续超越 RegMix 等多个基线 |

**意义**: 将因果关系引入数据混合这一关键但经验性的环节，提升了可解释性和迁移性。

### 6. ⚡ GSRQ：突破 1-bit KV Cache 量化——22.20 百分点 LongBench 提升

**论文**: [GSRQ: Gain-Shape Residual Quantization for Sub-1-bit KV Cache](https://arxiv.org/abs/2607.01065)
**来源**: arXiv:2607.01065 · ICML 2026 · July 1, 2026

| 维度 | 数据 |
|:-----|:------|
| **核心** | 发现标准 $\ell_2$ K-means 在 VQ 中存在质心收缩问题，提出 Gain-Shape K-means (GSKM) 替代 |
| **1-bit 结果** | LongBench 从 **11.34 → 33.54**（22.20 百分点提升，vs VQLLM） |
| **方法** | 将 GSKM 加权扩展集成到残差量化（RQ）管线中 |
| **模型** | LLaMA-3-8B，跨比特率均有提升 |
