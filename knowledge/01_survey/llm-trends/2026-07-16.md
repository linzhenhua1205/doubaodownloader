**来源**: The Verge (Jul 15, 2026) · Thinking Machines Lab 官方博客

| 维度 | 详情 |

- **OpenAI 前高管集体出走后的首次兑现** — Mira Murati 是最高调的离职者，Inkling 是 Thinking Machines Lab 从实验室到产品的第一张牌

- **「从零训练」vs「微调开源」两条路线** — 选择前者意味着重注基础设施、数据、算力，而非快速刷分

## 🔥 头条三：Ring-Zero — 将 Zero RL 扩展到万亿参数，涌现高级认知行为 ⭐

**来源**: arXiv:2607.12395 (Jul 14, 2026)

### 核心规格

| 维度 | 数据 |
|:-----|:------|
| **模型** | **Ring-2.5-1T-Zero** — 1 万亿参数 |
| **方法** | Zero RL（仅用可验证奖励，无人类标注数据） |
| **训练优化** | 裁剪重要性采样 + 训练-推理比率校正 + 混合精度控制 |
| **评估** | 7 个数学基准，达到 competitive 性能 |
| **提出者背景** | 中国团队（作者单位来自蚂蚁集团/浙大方向） |

### 三大核心发现

| # | 发现 | 详情 |
|:--|:------|:------|
| 1 | **缩放提升显著** | 扩展到 1T 参数后**样本效率和性能天花板**均大幅提升，验证「苦涩教训」 |
| 2 | **训练两阶段** | 先**初始发现阶段**（模型学习推理模式），后**锐化阶段**（固化/精炼策略） |
| 3 | **自发涌现高级认知行为** | ——拟人化、结构化格式、**自验证**、**并行推理**、**上下文焦虑**——手工设计的启发式规则变得多余 |

### 自涌现的 5 种高级行为

| 行为 | 描述 |
|:-----|:------|
| 拟人化（Anthropomorphism） | 模型表现出类似人类的推理语气 |
| 结构化格式（Structured Formatting） | 自动组织推理链为清晰结构 |
| 自验证（Self-Verification） | 自动检查自身推理的正确性 |
| 并行推理（Parallel Reasoning） | 同时探索多条推理路径 |
| 上下文焦虑（Context Anxiety） | 对信息不足或不一致敏感，主动请求更多上下文 |

### 结构化 CoT 评估框架

| 维度 | 含义 |
|:-----|:------|
| **可理解性** Comprehensibility | 推理链对人类是否可读 |
| **可复现性** Reproducibility | 相同输入能否产生一致逻辑 |
| **效率** Efficiency | 达到正确结果所需的推理步数/token 数 |

Ring-2.5-1T-Zero 在所有三个维度上均展现明显优势。

### 产业信号

- **Zero RL + 万亿参数 = 认知涌现** — 这可能是最系统化的「RL 导致高级认知行为涌现」的实证，且无需人类监督信号
- **自验证+并行推理是推理模型的 Holy Grail** — 模型**自己学会**了检查自己、同时尝试多条路，这正是 o1/R1 类推理模型手工程序设计的自动化版本
- **这是中国团队的 1T 工作** — 表明中国 AI 实验室在「大模型+强化学习」这个前沿交叉领域已有世界级产出
- **苦涩教训再次被验证** — 搜索+缩放比手工程序更有效

### 1️⃣ EcoSpec — MoE 投机解码成本感知框架，最高 1.62× 加速

**来源**: arXiv:2607.12696 (Jul 14, 2026)

| 维度 | 数据 |
|:------|:------|
| **问题** | 投机解码的置信度驱动选词 → 专家分散（expert scattering）：高概率草案路由到不同专家，增加权重内存流量 |
| **方案** | **EcoSpec** — 将预测的边缘专家激活成本纳入草案选择的成本感知框架 |
| **模型验证** | DeepSeek-V3.1 (671B) + Qwen3-235B-A22B + GPT-OSS-120B |
| **效果** | 最高 **1.62× 端到端加速**，减少活跃专家足迹 |
| **核心组件** | 轻量专家预测器 + 动态专家缓冲区，不修改目标模型验证规则 |
| **意义** | MoE 推理优化从「加速生成」到「加速生成 + 控制专家足迹」双重优化 |

### 2️⃣ KLLMs — 抑制参数知识，让模型只依赖上下文证据

**来源**: arXiv:2607.12831 (Jul 14, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 在预训练语料中将命名实体**全部匿名化** = 切断实体链接的事实监督通道 |
| **效果** | 上下文问答/事实验证/幻觉检测等有上下文提供的任务中**持续优于基线** |
| **RAG 场景** | 证据不完美时，**相对提升 20-25%** |
| **校准** | 更好的 ECE / Brier 分数 / AUROC + 更可靠的拒绝（abstention）行为 |
| **意义** | 证明预训练阶段对知识获取方式的控制可以系统性地改变模型的认识论行为——依赖参数知识 vs 依赖上下文证据。为「更可靠的基础模型」提供了新方向 |

### 3️⃣ PalmClaw — 原生手机端 Agent 框架，任务成功率 +11.5%，耗时 -94.9%

**来源**: arXiv:2607.13027 (Jul 14, 2026)

| 维度 | 数据 |
|:------|:------|
| **定位** | 在手机本地运行 Agent 循环（会话/记忆/技能/工具/Agent 循环全在端侧） |
| **方法** | 将设备能力暴露为**工具**（显式参数 + 结构化结果 + 明确执行边界） |
| **效果** | 任务成功率相对提升 **11.5%**，完成时间**减少 94.9%**（vs GUI-based baseline） |
| **对比** | GUI 操作型 Agent（戳/滑/打字）→ 接口型（工具调用） |
| **开源** | ✅ 完全开源 |
| **意义** | 手机端 Agent 从「屏幕模拟」升级为「本地原生」，执行边界清晰度是设计关键 |

### 4️⃣ MemOps — 对话记忆生命周期操作基准

**来源**: arXiv:2607.12893 (Jul 14, 2026)

| 维度 | 数据 |
|:------|:------|
| **问题** | 现有记忆评测仅用下游 QA 准确率，混淆了**记住/忘记/更新/反思** 等不同记忆操作的失败原因 |
| **方法** | 将对话记忆建模为一系列生命周期操作，每个事件带结构化跟踪：触发条件→目标→范围→状态转换→证据 |
| **覆盖** | 6 类操作级探针，邻域证据+长上下文两种设定 |
| **发现** | Session 级检索 > Turn 级检索；长上下文模型在重建有序记忆状态轨迹上**仍然很差** |
| **意义** | 对话记忆评测从「最终答案得分」→「可解释的操作级诊断」 |

### 5️⃣ Token Reduction Is Not Cost Reduction — 来自 2,848 次 Claude Code 运行的数据

**来源**: arXiv:2607.12161 (Jul 13, 2026)

| 维度 | 数据 |
|:------|:------|
| **实验规模** | 2,908 次 Claude Code 运行（2,848 次用于分析），103 个任务，7 个仓库，3 个模型 |
| **关键发现 1** | Prompt cache 占成本主导地位——**~87%** 重建成本 / **~80%** 实际账单来自缓存创建+读取 |
| **关键发现 2** | 减少工具输出**不保证**减少账单——删除 38% 原始输出然成本**高 6.8%**（+2.8% ~ +11.3%） |
| **关键发现 3** | 压缩可能**破坏任务**——SWE-bench Go 任务中压缩使 patch 成功率从 27/40 降至 **15/40** |
| **结论** | 应以「成功调整后的账单成本」而非「token 减少量」作为优化指标 |

### 6️⃣ E3 — Agent 的「先估计再执行」，同等成功率下成本降低 85%

**来源**: arXiv:2607.13034 (Jul 14, 2026)

| 维度 | 数据 |
|:------|:------|
| **问题** | Agent 最大上下文优先策略——即使是一行编辑也重读所有文件 |
| **方案** | **E3 (Estimate → Execute → Expand)**：先估计任务复杂度→执行最小可行路径→验证失败再扩展范围 |
| **基准** | MSE-Bench（121 个确定性编辑） |
| **效果** | 任务成功率**不降**（100% 匹配最强基线），**-85% 成本，-91% tokens，-92% 检查文件** |
| **概念** | Agent Cognitive Redundancy Ratio (ACRR) — Agent 认知冗余率 |
| **实体验证** | gpt-4o 真实仓库编辑 + pytest 验证，E3 是最轻量、最快策略 |

## 📈 关键趋势

1. **「前 OpenAI 人」集体交答卷** — Mira Murati 的 Thinking Machines Lab 发布 Inkling，加上 Ilya Sutskever 的 SSI（一直低调试水），OpenAI 前核心团队的「平行宇宙」开始成形

2. **安全自动化工业化** — GPT-Red 标志着红队测试从人工→AI 模型→产品化。安全从「成本中心」变成「AI 驱动的能力中心」，拥有自研红队模型的实验室将形成系统级安全壁垒

3. **Zero RL + 万亿参数 = 认知涌现** — Ring-Zero 证明「仅靠可验证奖励的 RL」在 1T 尺度上自发产生自验证/并行推理/结构化推理链等高级行为。这是目前最清晰的「RL 缩放导致认知能力涌现」的实证

4. **MoE 推理优化进入「成本感知」时代** — EcoSpec（专家成本感知投机解码）+ UMoE（训练时专家重分配）+ StickyMoE（路由局部性）三者构成 MoE 效率的「训练+推理」全链路

5. **端侧 Agent 从 GUI 模拟→原生工具调用** — PalmClaw 的 94.9% 耗时减少说明「把设备能力暴露为工具」比「模拟点击」高效两个数量级

6. **Agent 效率从「能做」到「不做多余事」** — E3（复杂度感知，-85% 成本）+ Token Reduction ≠ Cost Reduction（2,848 次运行实证）构成 Agent 效率的正反两面

7. **中国经济区大模型加速落地** — Apple Intelligence 中国版本整合阿里 Qwen + 百度，国际巨头+本土玩家合作成为唯一可行路径
