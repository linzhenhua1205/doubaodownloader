## 📚 arXiv 精选（Tue+Wed 双批次增量）

### Agent 与自进化

- **Beyond the Capability Boundary: Zeroth-Order Optimization for Self-Evolving LLM Agents**（arXiv:2608.09292）: 自进化「能力边界」突破——既有自进化从自身采样轨迹学习，无法在困难例子上采样到正确轨迹而停滞于边界内；零阶优化（黑盒梯度估计）框架让 agent 学到边界之外。与 SkillProx（08-11）互补：一个改表示可微性、一个改优化器。https://arxiv.org/abs/2608.09292

- **Tree-of-Experience: Hierarchical Experience Management for Self-Evolving Agents**（arXiv:2608.09044）: 经验树——把环境交互转化为可靠可复用经验，经验表示与推理过程显式连接，解决反馈归因/跨任务迁移/更新检索效率三痛点。https://arxiv.org/abs/2608.09044

- **Co-Evolution in Agentic Systems: Toward Self-Directed Evolution Beyond Human Design**（arXiv:2608.10299）: 共进化综述——多组件自进化（agent×agent×环境互施自适应压力）的渐进三阶段分类法；单实体自进化受静态学习上下文（固定任务/反馈）限制。https://arxiv.org/abs/2608.10299

- **SWE-Bench ProMax: Benchmarking Agents on Large-Scale Multilingual Code Refactoring**（arXiv:2608.09802）: 代码重构基准——审计发现 SWE-bench Verified 未解实例近 60% 含缺陷测试（过窄拒正确解/过宽查未述需求），且前沿模型可逐字记忆；新基准针对大规模多语言长程重构。评估饱和与基准通胀的直接证据。https://arxiv.org/abs/2608.09802

- **DSAgentBench: Can Agents Automate End-to-End Data-Science Workflows in Real Computer Environments?**（arXiv:2608.10366）: 数据科学全流程 agent 基准——真实操作系统环境（notebook/IDE/终端/浏览器/数据库协同）下长程工作流（清洗→探索→建模→可视化→验证）自动化评估。https://arxiv.org/abs/2608.10366

### 记忆

- **Don't Scroll Back: Missing-Evidence Memory for Streaming Dialogue Summarization**（arXiv:2608.09043）: 流式对话摘要的「缺失证据记忆」——形式化设置：固定预算下用选择性记忆摘要当前窗口；核心挑战不是访问多少历史，而是**记忆能否恢复窗口自解释所需的证据**（与上下文压缩/蒸馏线互证）。https://arxiv.org/abs/2608.09043

- **StreamFlow: Dynamic Memory Flows for Streaming Video Understanding**（arXiv:2608.10949）: 流式视频理解的动态记忆流——严格因果 + 有界记忆下保留相关证据，减少对时序冗余内容的视觉编码计算（模型法需侵入式骨干更新、记忆法计算冗余，两弊皆除）。https://arxiv.org/abs/2608.10949

### 量化与推理效率

- **ReRound: Reconstructive Rounding to Resolve Midpoint Ambiguity in Calibration-Free LLM Quantization**（arXiv:2608.11045）: 无校准量化的「中点歧义」消解——RTN 对落在量化区间中心的权重存在歧义；条件扩散模型生成低比特权重的连续重建作为引导信号来消歧。与 08-11「量化损伤乘法累积」互证：量化误差预算分配的下游工具。https://arxiv.org/abs/2608.11045

- **Depth-adaptive Inference of Looped Language Models via Continuous Depth Batching**（arXiv:2608.09444）: 循环 LM 的深度自适应推理——共享层迭代块按 token 难度变循环次数（易少难多），但破坏标准批处理（同批 token 循环数不同、无统一前向）；提出连续深度批处理方案。https://arxiv.org/abs/2608.09444

- **Share First, Route What Remains: A Unified Framework for Token-Adaptive MoE Computation**（arXiv:2608.10392）: MoE「先共享、后路由」统一框架——共享专家/细粒度计算/动态路由三类决策独立做忽略基本依赖：提取可复用计算会改变剩余量与所需专家容量；统一建模。https://arxiv.org/abs/2608.10392

### 安全与评估

- **Pragmatic Attack Surface: Vulnerabilities of Implicit Context in Large Language Models**（arXiv:2608.09551）: 隐式语用上下文攻击面——现有安全对齐主要防显式语言线索，但人类语言固有语用（隐含意义/会话含义）构成新攻击面；与 08-11 StepJack（跨步骤注入）互补：一个打隐含、一个打编排。https://arxiv.org/abs/2608.09551

- **Measuring the Wrong Thing: Internal Harmfulness Scores Anti-Rank Successful Jailbreaks**（arXiv:2608.09624）: 内部有害分数与越狱成功「反排序」——有害意图是提示的属性，越狱成功是目标模型+解码策略+评判器协作的后续产物；内部分数测量了错误对象。延续 08-10「AI safety test 成为安全风险」评估经济学线。https://arxiv.org/abs/2608.09624

- **Consilience for Verifier-Free Test-Time Scaling**（arXiv:2608.09898）: 免验证器 TTS 的「共识性」——无编译器/测试用例/价值函数等外部验证器时，多路径输出一致性作为测试时缩放依据；对推理经济学有直接意义。https://arxiv.org/abs/2608.09898

- **Is This Your Final Answer? Cross-Contextual Consistency as a Measure of LLM Credibility**（arXiv:2608.10315）: 跨上下文一致性作为可信度度量——同一任务置于主题对齐、内容中立的上下文变化下，可信答案应保持稳定；区分「稳定内在信念」与「表面模式匹配」。https://arxiv.org/abs/2608.10315

- **Procedural Fairness Failures in RLHF from Preference Averaging**（arXiv:2608.10126）: RLHF 偏好平均的程序性公平失败——偏好异构时聚合为单一奖励模型，多数偏好群体支配奖励学习、少数偏好系统性欠代表；提出程序性公平定义（保留不同偏好信号）。https://arxiv.org/abs/2608.10126

### 可解释性与模型

- **Off-Axis, On Purpose: Where a Transformer Computes Concepts and Why it Does So**（arXiv:2608.10251）: Transformer「离轴计算」是有功能的——12 层模型两阶段计算，中间状态与读出轴保持 75-96 度近正交（非障碍而是功能）；把 attention 值移上读出轴的行为实验揭示概念计算位置规律。https://arxiv.org/abs/2608.10251

- **Beyond a Bag of Features: Set-Level Instability in Sparse Autoencoders**（arXiv:2608.11197）: SAE 集合级稳定性——用活跃 SAE 潜在集的重叠度量替代余弦相似度做表示相似度，集合级度量可恢复类别边界，同时暴露 set-level 不稳定性。https://arxiv.org/abs/2608.11197

- **Matryoshka Language Model Suites**（arXiv:2608.09703）: 套娃式模型套件——多尺寸子模型堆叠进单一嵌套架构端到端训练：总参数量减少、每步从最大模型向所有小子模型低成本蒸馏、训练/服务效率双提升。https://arxiv.org/abs/2608.09703
