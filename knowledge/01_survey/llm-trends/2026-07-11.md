## 🔥 头条一：OpenAI Codex 独立 App "Here to Stay" + ChatGPT Work 持续扩展

**来源**: The Verge (Jul 10, 2026) · X/@thsottiaux

OpenAI 的独立编程应用 **Codex** 工程负责人 Thibault Sottiaux 在 X 上明确澄清：**Codex 不会被废弃**，尽管 ChatGPT Work 平台已整合了 ChatGPT + Codex 的功能。Sottiaux 还预告了 Work 应用的更多更新——包括将聊天和项目移至侧边栏。

### ChatGPT Work 生态进展

| 维度 | 状态 |
|:-----|:------|
| **Codex 状态** | 独立 App 持续维护，不受 Work 影响 |
| **ChatGPT Work 新增** | 侧边栏聊天/项目管理，桌面/Web/移动端同步 |

| **Hosted Sites** | 新人功能：在业务内展示演示文稿，可能扩展为全功能网站构建器 |

### 产业信号

- OpenAI 在 **Codex（开发者）** 和 **ChatGPT Work（企业）** 两条产品线上并行推进
- 浏览器产品关停 → 资源集中到核心平台

## 📄 arXiv 亮点 (Jul 9-10 新收录)

### 1️⃣ Hidden Decoding — 序列长度扩展法：首个 100B+ MoE 固定骨干缩放

**来源**: arXiv:2607.08186 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | Hidden Decoding — 序列长度维度扩展，n 流并行 + Stream-Factorized Attention |
| **规模验证** | WeLM-HD4-80B、WeLM-HD4-617B（n=4），**首个 100B+ MoE 规模序列长度缩放方法** |
| **效率** | Stream-Factorized Attention 将注意力成本从 O(n²) 降至 O(n) |
| **创新点** | 固定 Transformer 骨干 + 增加每 token 计算量（沿序列长度维度） |
| **意义** | 提供无需重新预训练骨干网络的缩放路径 |

### 2️⃣ DeepSearch-Evolve — 自蒸馏 Web Agent 框架

**来源**: arXiv:2607.07820 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | DeepSearch-Evolve 自蒸馏框架，420K 多跳 QA 任务环境 |
| **模型** | DeepSearch-World-9B（无更强模型蒸馏） |
| **BrowseComp** | **31.2%** |
| **GAIA** | **61.5%** |
| **HotpotQA** | **93.4%** |
| **创新点** | 可验证环境驱动自进化，无需教师模型蒸馏 |

### 3️⃣ TACO — 尾部 Token 信用校准：8 基准一致超越 GRPO

**来源**: arXiv:2607.07976 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **问题** | 正信用污染（Positive-Credit Contamination）— 尾部 token 错误接收正面信用 |
| **方法** | Tail-Aware Credit Calibration (TACO)，尾部风险评分 + 细粒度信用校准 |
| **实验** | 3 种 LLM × 8 基准，**一致优于 GRPO 风格基线** |
| **效果** | 训练稳定性提升，长期 RL 持续收益 |

### 4️⃣ PLURAL — 20 国家 × 50 万偏好对的全球价值对齐数据集

**来源**: arXiv:2607.08034 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **规模** | ~500,000 偏好三元组，覆盖 20 个国家 |
| **基础** | Integrated Values Survey (IVS) — 92 国代表性调查 |
| **效果** | 目标国家文化对齐 MAE 降低 **27.7%** |
| **人工评估** | 176 名评估者（印度/巴西/日本）判定 PLURAL 对齐的回答更具代表性 |

### 5️⃣ Tool-Making Agents — 工具制造降低 42% 延迟、53% 错误率

**来源**: arXiv:2607.08010 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **场景** | 生产 Fulfillment Center 报警分类，44 节点 SOP + 异构监控后端 |
| **延迟** | Tool call 减少 p50 延迟 **42%**；直接调用架构再降 **62%** |
| **错误率** | 端到端错误率降低 **53%**（1,500 历史报警） |
| **核心** | 编译重复 SOP 步骤为经验证的版本化工具，生产时直接调用 |

### 6️⃣ From Solvers to Research — 陶哲轩联合提出 AI4Math 路线图

**来源**: arXiv:2607.07779 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **作者** | Eric Jiang 等 + **Terence Tao（陶哲轩）** |
| **定位** | LLM 驱动形式数学从"解题器"到"研究助手"的转型路线图 |
| **核心论点** | 需要从预定义解题转向开放研究 agent |
| **覆盖** | 数据集、自动形式化、证明综合的全面综述 |

### 7️⃣ Structured Pruning — Llama-3-8B 结构化剪枝保持精度

**来源**: arXiv:2607.08027 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 幂变换 + 保符号分数聚合 + 百分位数离群去除 |
| **模型** | Llama-3-8B、Vicuna-v1.5-13B、LLaVA-v1.5-13B |
| **效果** | 结构化剪枝精度 ≈ 非结构化剪枝，且实现实际推理加速 |

### 8️⃣ HSP — 幻觉自博弈：小型 LLM 匹配先进 LLM 幻觉检测

**来源**: arXiv:2607.07993 (Jul 9, 2026) — 已接收 COLM 2026

| 维度 | 数据 |
|:------|:------|
| **方法** | Hallucination Self-Play：检测器 ↔ 生成器迭代对抗训练 |
| **效果** | 小型 LLM 匹配或超越先进 LLM 幻觉检测性能 |
| **数据** | 无需外部监督，RAGTruth 基准 |

### 9️⃣ Hallucination Detection — 内部表征做校准与忠实度检测

**来源**: arXiv:2607.08046 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **关键发现** | 内部表征探头校准显著优于 chain-of-thought |
| **测谎功能** | 84% 情况下能预测行为变化方向（CoT 掩盖时也可） |
| **效率** | 单一推理前传递即可恢复承诺答案，节省 **30-47%** 生成 token |
