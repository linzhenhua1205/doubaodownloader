## 📄 arXiv 亮点（Jul 10-11 新收录）

### 1️⃣ LPA — 仅 66 句人格语句实现近零攻击率的安全对齐（COLM 2026）

**来源**: arXiv:2607.07918 (Jul 8, 2026) — **已接收 COLM 2026**

| 维度 | 数据 |
|:------|:------|
| **方法** | Latent Personality Alignment — 仅使用 **66 条**与危害无关的人格心理测量语句做对抗训练 |
| **训练数据** | 仅 66 条（标准 LAT 的 **1/75**），且不包含任何有害内容 |
| **攻击成功率** | HarmBench 上**近零**（direct + 5 种越狱方法）|
| **性能损失** | 标准基准上**无损失** |
| **训练成本** | **数分钟（单 GPU）** |
| **核心假设** | 人格锚定表示与伤害回避共享潜在结构 → 稳定人格表示间接约束越狱可利用的子空间 |
| **意义** | 证明"人格空间即安全空间"，无需有害数据即可做安全对齐 |

### 2️⃣ Jet-Long — 零样本长上下文扩展：Dynamic Bifocal RoPE

**来源**: arXiv:2607.07740 (Jul 8, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 局部 RoPE 忠实窗口 + 全局动态缩放窗口的双焦注意力 |
| **效果** | Qwen3-1.7B/4B/8B 上 RULER领先 **+4.79/+2.18/+2.03 pp** |
| **速度** | 长上下文 prefill 达 **1.39× FA2** 吞吐（H100），接近 Hopper FA4 |
| **开销** | 单 batch 生成额外开销 ≤ **4%** |
| **泛化** | 可扩展到 Jet-Nemotron 等混合注意力架构 |
| **意义** | 无需微调的零样本长上下文方案，且不牺牲短上下文性能 |

### 3️⃣ MAESTRO — MoE 结构化剪枝：全局路由感知的专家重要性评估

**来源**: arXiv:2607.08601 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 将 MoE 的专家激活轨迹建模为 Ergodig 马尔可夫链 → 稳态分布编码跨层依赖 |
| **效果** | 50% 压缩下平均性能保持提升 **+10.61%**，跨任务方差更低 |
| **覆盖** | 5 大领域（含安全、偏见、伦理） |
| **创新** | 首次从**全局路由模式**而非局部启发式做 MoE 剪枝 |

### 4️⃣ UniClawBench — 首个能力驱动的主动 Agent 基准

**来源**: arXiv:2607.08768 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **定位** | 首个**能力驱动**（而非场景驱动）的主动 Agent 基准 |
| **核心能力** | 5 项：技能使用、探索、长上下文推理、多模态理解、跨平台协调 |
| **规模** | **400 个双语**真实世界任务 |
| **评估方式** | **实时 Docker 容器** + 分步完成检查点（非预录答案）|
| **特殊设计** | 闭环评估：执行 Agent + 隐藏监督 Agent + 用户 Agent（模拟多轮反馈且不泄露评分标准）|
| **意义** | 首次将基座模型能力与 Agent 框架设计分离评估 |

### 5️⃣ WebSwarm — 递归多 Agent 编排：深广兼备的 Web 搜索

**来源**: arXiv:2607.08662 (Jul 9, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 渐进递归委派：每个搜索节点可自解决或向下委派子节点，子节点完成后向上回报 |
| **关键机制** | 先探知网页信息组织方式 → 指导节点扩展；同层兄弟节点间复用过程经验 |
| **基准** | BrowseComp-Plus、WideSearch、DeepWideSearch、GISA |
| **效果** | 一致超越单 Agent 和多 Agent 基线，尤其在深度 + 广度交织任务上 |
| **意义** | 解决了 ReAct 式 Agent 单轨迹长度 + 上下文限制的根本问题 |

### 6️⃣ ReCoLoRA — 频谱感知递归整合的持续 LLM 微调

**来源**: arXiv:2607.07719 (Jul 8, 2026)

| 维度 | 数据 |
|:------|:------|
| **方法** | 从随机 SVD 初始化适配器 → 每层有效秩通过肘部准则选择 → 主线适应 + 残差容量 |
| **效果** | 6 任务 GLUE 序列 × 4 个 7-8B 骨干，3/4 骨干取得最佳平均分 |
| **参数** | 比 LoRA/PiSSA/AdaLoRA/DoRA 等基线训练更少参数 |
| **创新** | 每新任务重新分解当前有效权重（而非原始权重）到冻结残差 + 缓慢更新主成分 + 新适配器 |

### 7️⃣ DominoTree — 条件树结构投机解码

### 9️⃣ Token-Flow Firewall — 持久 AI Agent 的语义运行时审计

|:------|:------|
