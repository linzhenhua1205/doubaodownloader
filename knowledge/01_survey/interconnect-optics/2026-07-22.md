### 🔴 25.1 MRM创纪录相干性能 — 1Tb/s @ 80km，5Tb/s/mm岸线带宽，10.4fJ/bit（Nature Photonics 2025，Laval Univ.）

**来源**: [arXiv:2412.17986](https://arxiv.org/abs/2412.17986) — Geravand, Zheng, Shateri et al. (Laval Univ.) — *Ultrafast Coherent Dynamics of Microring Modulators*，发表于 **Nature Photonics** (2025)

**核心突破**: 首次全面揭示MRM相干动态特性，解锁**相位维度**用于高速传输。

| 指标 | 数值 | 说明 |
|:-----|:-----|:-----|
| 岸线带宽密度 | **>5 Tb/s/mm** | 片上记录 |
| 符号速率 | **180 Gbaud** | |
| 净速率 | **>1 Tb/s** @ 80km | 相干传输 |
| 调制能耗 | **10.4 fJ/bit** | 创纪录能效 |
| 方案 | 推挽式MZI内嵌双MRM | 双稳态相位响应+无啁啾调幅 |
| 工艺 | CMOS兼容SiPh | 标准代工 |

**技术细节**: MRM的相位和强度调制展现出不同但耦合的动态特性，限制了直接用于高阶调制。这一挑战通过将一对MRM嵌入MZI的推挽配置中解决，实现了**双稳态相位响应**和**无啁啾幅度调制**。其幅度频率响应在谐振附近没有强峰值。

**意义**:
- MRM不再只是强度调制器件 → **相干CPO的关键使能器件**
- 10.4 fJ/bit比前序§24.4的0.78 pJ/bit（含驱动器）纯调制能耗**低75倍**——说明若计入驱动开销，MRM仍有数量级优化空间
- 5 Tb/s/mm岸线带宽 → 单芯片可实现**数十Tb/s**的总I/O带宽

### 🔴 25.2 晶圆级III-V-on-SiN量子光子平台 — <1 dB/m损耗，<25 mdB层间耦合器，15×更亮纠缠源（arXiv:2605.17738, UCSB/Caltech）

**来源**: [arXiv:2605.17738](https://arxiv.org/abs/2605.17738) — Thiel, Shen et al. (UCSB / Caltech / MIT / UC Davis) — *A Wafer-Scale Heterogeneous III-V-on-Silicon Nitride Quantum Photonic Platform*

**核心**: 首个**晶圆级III-V-on-SiN**异质集成量子光子平台，实现无妥协的"超低损耗SiN + 高性能III-V有源器件"组合。

| 指标 | 数值 |
|:-----|:-----|
| SiN波导损耗 | **<1 dB/m** |
| 层间绝热耦合器损耗 | **<25 mdB** (<0.025 dB) |
| InGaP谐振器Q值 | 固有Q >**1×10⁶** |
| 纠缠源亮度提升 | **15×**（vs 纯SiN方案） |
| InP探测器量子效率 | up to **99%** |
| 探测器带宽 | 3 GHz |
| 平台尺寸 | **晶圆级**（三英寸以上） |

**技术意义**:
- III-V（InGaP）提供**χ⁽²⁾+χ⁽³⁾**非线性，SiN提供超低损耗无源光路——**"最佳拍档"组合**
- 层间耦合器仅<25 mdB → 实现接近无损的III-V↔SiN光传输
- 与CPO/PIC代工直接兼容 → 量子+经典光互连可共享同一SiN平台

**与CPO关系**: SiN是CPO中理想的无源光路平台（宽谱、低损耗、免二光子吸收），该平台证明III-V有源器件（激光器+探测器+非线性器件）可无损伤集成到SiN上——**CPO光引擎的完整"有源+无源"单芯片方案更进一步**

### 🟢 25.3 异构InGaAs/InP平衡探测器集成至超低损SiN — 全片上激光稳频（arXiv:2607.03008, UCSB）

**来源**: [arXiv:2607.03008](https://arxiv.org/abs/2607.03008) — Chawlani et al. (UCSB) — *Heterogeneously Integrated Balanced Photodetector on an Ultra-Low Loss Silicon Nitride Delay Line Interferometer* — **2026年7月3日提交**

**核心**: 首次将**InGaAs-on-InP改进型单载流子（MUTC）平衡光电探测器**异构集成至**15米长SiN MZI干涉仪**上。

| 指标 | 数值 |
|:-----|:-----|
| 探测器类型 | InGaAs/InP MUTC平衡PD |
| 带宽 | 0.92 GHz |
| 响应度 | 0.305 A/W @ 1550nm |
| SiN波导损耗 | 2.5 dB/m @ 1600nm |
| 功能验证 | 激光稳频：23 dB噪声抑制@1kHz；光学鉴频器：10 Hz–10 MHz |

**意义**: 薄芯SiN平台首次实现高性能有源探测器+超低损耗无源光路的异构集成。激光稳频+光学鉴频功能证明**全片上自注入锁定**方案可行——CPO中激光器的频率稳定性可不再依赖外部光隔离器。

### 🟢 25.4 CPO能效量化里程碑 — 从~15 pJ/bit（可插拔）→~5 pJ/bit（CPO），路径指向<1 pJ/bit（Jun 2025, SemiEngineering/GF/Intel/Synopsys综合）

**来源**: [SemiEngineering — Co-Packaged Optics Reaches Power Efficiency Tipping Point](https://www.semiengineering.com/co-packaged-optics-reaches-power-efficiency-tipping-point/) (Laura Peters, Jun 2, 2025) — 引用GF/Intel/Synopsys/Amkor

**CPO能效对比量化数据**：

| 维度 | 可插拔光模块 | CPO初期 | CPO远期路径 |
|:-----|:-----------:|:-------:|:----------:|
| 能效（pJ/bit） | ~15 | ~5 | **<1**（GF预估） |
| SerDes信道损耗 | >20 dB | 1–2 dB | — |
| 光引擎-芯片距离 | 板级（数cm） | **~100 µm**（Intel） | 3D堆叠 |
| 每芯片光引擎数 | 1（前面板） | 4–8 SiPh芯粒 | 16+ |
| 带宽密度（Tbps/mm） | — | ~1（Amkor） | >5（MRM） |

**关键厂商观点**:
- **GlobalFoundries** (Vikas Gupta): CPO的主要优势是**从~15 pJ/bit降到~5 pJ/bit**，路径指向**<1 pJ/bit**。SiPh封装越来越CMOS-like，用JEDEC+Telcordia GR-468联合可靠性评估
- **Synopsys** (Sander Roosendaal): CPO使SerDes仅需处理**1–2 dB**损耗（原>20 dB）——SerDes功耗可降低数量级，但需内置冗余激光+自监控+BiST
- **Intel** (Mark Gardner): 评估**Monolithic-PIC**（PIC+EIC同晶圆，EMIB 2.5D）与**3D堆叠PIC/EIC**（各用最优节点，3.5D CPO）的权衡——前者电气耦合好但EIC受限先进节点，后者设计复用优但封装成本高

**可靠性基线**: SiPh器件用Telcordia GR-468评估，但GF同时使用JEDEC标准。硅材料系统"固有地比化合物半导体更可靠"。激光仍是**最大单一缺陷源**（Promex/Otte），冗余激光方案成为行业标准。

### 🟡 25.5 Ge外延占SiPh PIC成本40% — "全硅光电子"路径的经济驱动力（Apr 2026, SemiEngineering + APL Photonics）

**来源**: [SemiEngineering — Silicon Photonics Lights The Way To More Efficient Data Centers](https://www.semiengineering.com/silicon-photonics-lights-the-way-to-more-efficient-data-centers/) (Katherine Derbyshire, Apr 16, 2026) — 引用Y. Yuan et al., APL Photonics 2025

**关键数据**: 锗（Ge）用于SiPh光电探测器的外延生长占整个光集成电路成本的**高达40%**（Y. Yuan, APL Photonics 2025）。

**连锁影响**:
- Ge是SiPh接收端必需材料（Si不吸收1300–1550nm光）
- 但Ge外延（厚层，非薄SiGe纳米片）需要**专用设备+额外工艺步骤**
- 推动业界探索替代方案：
  - **III-V异质集成**（§25.2）——但成本更高
  - **"全硅"方案**（all-silicon photonics）——通过缺陷工程/能带调控让Si本身吸收长波长
  - **SiN波导**作为无源层 + InP/Ge探测器异质集成

**成本启示**: Ge外延占比揭示**SiPh PIC的量产成本大头不是光源也不是调制器，而是接收端的探测器**——CPO产业必须关注PD侧的成本优化
