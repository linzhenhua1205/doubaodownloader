## AI 研发工具链企业管控

- **GitHub/Copilot for JetBrains 企业托管设置上线**（08-18 Release）: JetBrains IDE 补齐全套企业管控——①插件治理三控：enabledPlugins（强制启用/禁用）、extraKnownMarketplaces（批准额外插件源）、strictKnownMarketplaces（限定安装来源）；②MCP server allowlist：allowedMcpServers/deniedMcpServers 集中控制开发者可连接的 MCP 服务器，阻止连出白名单外服务器；③托管 OpenTelemetry：集中配置 collector 端点/协议/service name/resource attributes/content-capture policy，托管值优先于开发者设置，遥测统一路由到批准 collector；④权限模式管控：permissions.disableBypassPermissionsMode 可禁掉 JetBrains 内 Copilot agent 的 Bypass Approvals/Autopilot。与 08-12 Agent Plugins 1.0、08-11 JetBrains memory+Ollama 构成 IDE 生态企业治理闭环。URL: https://github.blog/changelog/2026-08-18-enterprise-managed-settings-in-github-copilot-for-jetbrains

## 工程质量与安全治理度量

- **GitHub/组织级 Code Quality 趋势页签 GA**（08-19 Improvement）: org 级 Code Quality 仪表盘新增 Trends 页签，从单点快照升级为趋势视角——按 health score 或 severity 分组的 open findings 趋势图（7/14/30 天窗口），附当前总数与周期净变化；两张排名表分别列出"改进最多"与"需要关注"的仓库（按 findings 变化量排序），便于识别进展团队与风险仓库；支持页面顶部仓库过滤器联动。Enterprise Cloud/Team 可用，GHES 不支持。URL: https://github.blog/changelog/2026-08-19-track-organization-code-quality-trends
- **GitHub/Code Quality 启用变更写入审计日志**（08-20 Improvement）: 新增 3 个审计事件——repo.code_quality_enabled / repo.code_quality_disabled / repo.code_quality_updated，每条记录仓库+操作者+时间戳；由于 Code Quality 按 active committers 计费，现在可精确定位仓库何时进出计费范围（成本归因能力）；org/enterprise 两级 audit log + audit log API 均可查询，治理/财务团队可脚本化对账。URL: https://github.blog/changelog/2026-08-20-track-github-code-quality-enablement-changes-in-the-audit-log
- **GitHub/Code Quality 独立 Actions 路径 GA**（08-20 Improvement）: Code Quality 的 CodeQL 工作流从共享路径拆分——专用路径 dynamic/github-code-quality/codeql、actor 改为 github-code-quality（此前与 code scanning 共用 dynamic/github-code-scanning/codeql + github-advanced-security）；工作流运行历史与 Actions 用量报表可区分两种扫描；存量脚本/仪表盘需更新：按旧路径过滤的 Actions 用量计费报表需补新路径、按 github-advanced-security actor 识别 Code Quality 的过滤器需替换。URL: https://github.blog/changelog/2026-08-20-separate-github-actions-path-for-github-code-quality
- **GitHub/CodeQL 2.26.3**（08-19 Improvement）: 改进 GitHub Actions 查询与 JavaScript 建模（工具链常规更新，继续跟进 Actions 工作流静态分析覆盖）。URL: https://github.blog/changelog/2026-08-19-codeql-2-26-3-improves-github-actions-queries-and-javascript-modeling
- **GitHub/code scanning 新增 "Mitigated" 关闭原因**（08-20 Release）: 漏洞仍存在于代码、但外部控制（WAF/网络策略等）已缓解风险时可用新原因关闭告警；与 "Won't fix" 区分，使关闭动作对齐正式例外/风险接受流程，减少在 GitHub 之外手工跟踪缓解决策——审计语义更清晰。URL: https://github.blog/changelog/2026-08-20-code-scanning-adds-a-mitigated-alert-dismissal-reason

## 平台安全与事件响应

- **GitHub/按凭证类型批量撤销与反授权**（08-18 Improvement）: 安全事件响应用户级细粒度化——此前 kill-switch 一次性撤销用户全部凭证，现可按类型（PAT/SSH keys/OAuth app tokens/GitHub App user access tokens）精准处置，收窄爆炸半径：①类型级批量反授权（撤销指定类型全部 SSO 授权，UI+enterprise REST API）；②类型级批量撤销（如只删某 EMU 用户的全部 PAT、不动其 SSH keys）；③org 级 parity——原仅 enterprise 级的批量撤销动作下沉到 org 级（UI+org REST API）；④全部处置动作入审计日志+邮件通知受影响用户。权限要求：enterprise owner/org admin/具备 Manage enterprise credentials 权限的成员。URL: https://github.blog/changelog/2026-08-18-credential-revocation-and-deauthorization-by-token-type
