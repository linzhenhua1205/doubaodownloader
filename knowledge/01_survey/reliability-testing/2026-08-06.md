## 当日信号

- **AReaL-DTE: 快照无关的稀疏权重传输引擎**（arXiv:2608.00455, 08-01）: 在线 agentic RL 微服务架构中策略权重同步是系统开销主源——实测相邻策略版本间 **<2% BF16 权重变化**；AReaL-DTE 通过逆转 AdamW 更新按需重建被覆盖权重、流式 BF16 变更检测 + 接收端本地坐标重映射，实现快照无关稀疏传输。跨集群较 ByteCheckpoint 提速 **19.9×**、较 PULSE **3.2×**；同集群峰值 GPU 内存 **-41%**、CPU 内存 **-87%**（Qwen3-30B-A3B 四负载实测）。https://arxiv.org/abs/2608.00455
- **FT-HSDP: 10万 GPU 容错训练范式**（arXiv:2602.00277, 01-30）: 同步训练在 O(100K) GPU 下因频繁故障+长恢复时间效率极低——FT-HSDP 以数据并行副本为容错单元，故障仅下线含故障 GPU 的单副本，其余继续训练。核心技术：CPU 驱动控制逻辑 + GPU 数据搬运的 **FTAR 容错 AllReduce** 协议、非阻塞追赶协议。故障恢复 stall 从 **10 分钟 → 3 分钟**，有效训练时间 **44% → 80%**，异步恢复不损精度（Meta 生产规模）。https://arxiv.org/abs/2602.00277
- **NVIDIA MPS 故障韧性改造**（arXiv:2605.26461, 05-26）: MPS 弱故障韧性（单进程故障可终止所有共驻进程）阻碍多租户 GPU 集群采用——系统性刻画 GPU 故障端到端处理流水线后提出双机制：①对占主导的内存类故障，在开源 GPU 驱动内核模块中用软件干预实现**完全故障隔离**；②对处于闭源软件的故障，用**虚拟内存 GPU 驻留状态共享**实现快速恢复。多 GPU/多负载验证最小开销。https://arxiv.org/abs/2605.26461
- **Agora: 互联网规模无权限容错预训练**（arXiv:2607.13332, 07-14）: 利用异构、可抢占、个体所有的消费级 GPU（互联网链路）做 LLM 预训练——带宽高效流水并行分片 + 多方容错集体操作，任何单方不持完整权重（Protocol Learning）。**Pluralis-8B** 实证：330 贡献节点 40 天训 500B tokens，~170k tokens/s、4.2 tokens/TFLOP，达集中式 H100 基线 **63% 效率**，收敛差距极小。https://arxiv.org/abs/2607.13332
- **Stochastic Connectivity: 微服务可用性形式化运行时模型**（arXiv:2607.00740, 07-01）: 故障注入/混沌实验昂贵且有风险，分布式追踪+部署元数据又只是描述性的——提出基于随机连通性的端点可用性模型（类型化依赖图+副本映射+节点/边状态概率测度+请求成功谓词），可从追踪与部署产物重建、做架构 what-if 分析、在故障注入前用蒙特卡洛预分析；语义上区分副本计算故障与逻辑依赖通信故障，证明**复制无法补偿瓶颈依赖**。https://arxiv.org/abs/2607.00740
- **Honest Quorum / EBFT: agent 基础设施的认知拜占庭容错**（arXiv:2607.16109, 07-17）: 协议合规但推理出错的 agent 验证者可能背书语义无效转换——「诚实」（协议合规）≠「语义正确」，即 Honest Quorum Problem；因 agent 常共享权重/训练分布/提示词，**关联认知故障**风险高。EBFT 在传统拜占庭界之外引入两个置信度索引量（e_δ 相干无效背书、u_ε 不可用支持），分别刻画语义安全风险与活性退化；论证新增名义上不同的 agent 仅在可度量降低无效背书尾部分布时提升容错。https://arxiv.org/abs/2607.16109
