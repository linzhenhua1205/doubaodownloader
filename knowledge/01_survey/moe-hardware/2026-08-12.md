## 核心发现

- **NVIDIA 官方博客 / Nemotron 3.5 Lightning: 30B MoE 但仅 3B active**（2026-08-11）: 面向 always-on agent 高吞吐低延迟执行层（tool calls/结果验证/subagent 委派）设计的开源 MoE——30B 参数仅激活 3B/token，官方宣称较同规模模型 **输出速度最高 4×**；配套 speculative decoding（draft 模型可选）、NVFP4+Bf16 双 checkpoint、NeMo Switchyard 跨模型路由；URL: https://developer.nvidia.com/blog/nvidia-nemotron-3-5-lightning-delivers-fast-accurate-specialized-task-execution-for-long-running-agents/

- **同上 / NVFP4 跨三代 GPU 的硬件信号**: 官方明确 Lightning 复用 Nemotron 3 Ultra 同款 NVFP4 内核，**同一 checkpoint 文件同时跑 Blackwell / Hopper / Ampere**，数据中心与桌面 DGX Spark 通用——**硬件含义 ⭐⭐⭐**：MoE 稀疏激活（30B→3B active）使模型对单 GPU 显存/算力门槛大幅下移，FP4 内核成为跨代际兼容的量化锚点；与上期 Muse Glimmer 30B dense（>20K tok/s/GPU）形成**同周 dense-vs-MoE 双叙事**——NVIDIA 同时押注两条架构路线；URL: https://developer.nvidia.com/blog/nvidia-nemotron-3-5-lightning-delivers-fast-accurate-specialized-task-execution-for-long-running-agents/

- **arXiv 2608.08650 / MoE 架构演进技术综述**（2026-08-09）: 不以时间线而以**五维耦合框架**组织现代 MoE（expert granularity / expert topology / routing freedom / load balancing scope / execution structure），将 8 个架构里程碑建模为**依赖图**（6 主线 + 2 正交分支）而非 8 代线性演进；并从四控制平面（Expert Topology / Routing / Balance / Expert Parallelism）分析各系统——**硬件相关性 ⭐⭐⭐**：expert parallelism 作为独立控制平面单列，EP 通信/内存布局被提升为与路由同等的一等设计维度；URL: https://arxiv.org/abs/2608.08650

- **arXiv 2608.08081 / RotaryQuant: 120B MoE 塞进消费级硬件**（2026-08-08）: 三轴压缩同时回应消费级设备的**三重显存压力**（常驻权重 + 随上下文线性增长的 KV + 数十个需按需分页的专家子层）：① 混合精度按架构角色分配——dense 层 4-bit、路由专家 2-bit、共享专家 8-bit（高激活峰度抵抗激进压缩）；② LRU 专家 offload——真正显存压力下把非驻留专家换页到磁盘；③ IsoQuant——KV 缓存 Walsh-Hadamard 变换 + block-diagonal SO(4) 旋转等向化后 3-bit 量化；URL: https://arxiv.org/abs/2608.08081

## 格局观察

- **dense-vs-MoE 双叙事进入官方同周对打阶段**: 08-10 Meta Muse Glimmer 30B dense（规避路由开销）vs 08-11 NVIDIA Nemotron 3.5 Lightning 30B MoE/3B active（稀疏激活摊薄算力）——两者同属「本地/边缘 agentic 场景」定位，说明**该场景尚无架构定论**，硬件平台（单卡显存/FP4 内核/NVLink 域）必须同时兼容两条路线
- **消费级 MoE 硬件问题进入系统化解法期**: RotaryQuant 的三轴方案（角色化量化 + LRU 专家分页 + 等向化 KV 压缩）与此前 MawForge/PagedWeight/WiSP 同属「低资源 MoE」家族，但首次把**权重-专家-KV 三维同时建模**——消费级 GPU 的显存分层（HBM/系统内存/磁盘）成为 MoE 推理的一等约束
- **综述类产出出现**: MoE 架构综述（2608.08650）以依赖图+控制平面组织知识，标志该领域进入**范式总结期**——对硬件调研的价值是提供了 expert parallelism 与路由/拓扑/负载均衡的耦合全貌，可作超节点/单卡设计的检查清单
