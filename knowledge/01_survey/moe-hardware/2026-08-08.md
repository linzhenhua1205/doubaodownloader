## 核心发现（按硬件影响排序）

- **NVIDIA 官方博客《Delivering Massive Performance Leaps for MoE Inference on NVIDIA Blackwell》**（2026-01-08）: 软件栈+硬件协同驱动 MoE 推理飞跃——GB200 NVL72 上 DeepSeek-R1（671B 稀疏 MoE，每 token 激活 37B）经 TensorRT-LLM 优化后**每 GPU 吞吐 3 个月提升最高 2.8×**；四类优化=①PDL（Programmatic Dependent Launch）降低 kernel 启动延迟 ②Blackwell Tensor Core 底层 kernel 优化 ③**新 all-to-all 通信原语消除接收端中间缓冲**（MoE 专家数据交换直接受益）④NVFP4 4-bit 浮点硬件加速+MTP 多 token 预测+PD 分离推理；HGX B200 上 MTP 与 NVFP4 叠加带来显著吞吐提升且保精度。**叙事确立：MoE 时代 token 吞吐/瓦 的提升依赖「全栈协同」，软件优化可在不换硬件下年化数倍**。URL: https://developer.nvidia.com/blog/delivering-massive-performance-leaps-for-mixture-of-experts-inference-on-nvidia-blackwell/

- **arXiv 2605.05049《Piper: Efficient Large-Scale MoE Training via Resource Modeling and Pipelined Hybrid Parallelism》**（2026-05-06）: HPC 平台 MoE 训练瓶颈量化——建立 memory/compute/communication 数学模型，识别 4 大瓶颈=大规模 expert parallelism 的 all-to-all 延迟、通信-计算重叠不足、瘦 GEMM 负载不均、缺平台感知混合并行；流水线混合并行方案相比 X-MoE 提升 **MFU 2-3.5×**，新 all-to-all 算法较厂商实现带宽提升 **1.2-9×**。URL: https://arxiv.org/abs/2605.05049

- **arXiv 2604.14690《Switching Efficiency: A Novel Framework for Dissecting AI Data Center Network Efficiency》**（2026-04-16）: 提出**交换效率 η = 计算有效吞吐/交换容量**，分解为 Data、Routing Efficiency、Port Utilization 三因子诊断网络瓶颈；核心结论：**MoE 的 All-to-All 流量严重劣化端口利用率与路由效率**（稀疏/不均衡特性与集中式层次化交换天然冲突）；3D-Torus 对称分布式交换 vs Rail-Optimized 集中式层次交换适配不同流量模式；调整交换资源分配、扩展服务器规模、网内计算（in-network computing）、多平面设计均可改善 η。**对 AIDC 设计的意义：MoE 时代的网络度量需从「原始带宽」转向「计算有效吞吐/交换容量」**。URL: https://arxiv.org/abs/2604.14690

- **arXiv 2603.07006《Mozart: Modularized and Efficient MoE Training on 3.5D Wafer-Scale Chiplet Architectures》**（NeurIPS 2025 Spotlight, 2026-03-07）: 算法-硬件协同设计——专家分配策略实现 **on-package all-to-all**（包内通信避开跨芯片昂贵链路）+ 流式 token/expert 细粒度调度提升通信-计算重叠；架构侧以 2.5D NoP-Tree 拓扑 + 分层内存结构异构共置模块。**3.5D 晶圆级 chiplet 是 MoE 训练通信问题的硬件级解**。URL: https://arxiv.org/abs/2603.07006

- **arXiv 2510.25258《MoEntwine: Unleashing the Potential of Wafer-scale Chips for Large-scale Expert Parallel Inference》**（2025-10-29）: 晶圆级芯片（WSC）承载 EP 推理——Entwined Ring Mapping（ER-Mapping）协同映射 attention/MoE 层平衡通信压力，通信量降 **62%**；Non-invasive Balancer 将完整专家迁移拆分为多步并交替利用两层冷链路，MoE 计算+22%、通信+54%；与 NVL72 超节点相比，WSC 因更大 EP 规模平均每设备 MoE 性能高 **39%**。URL: https://arxiv.org/abs/2510.25258

- **arXiv 2511.11505《FarSkip-Collective: Unhobbling Blocking Communication in Mixture of Experts Models》**（MLSys'26, 2025-11-14）: **架构级解法**——修改模型跳过连接使计算与通信天然可重叠；将 16B~109B 系列模型全层改造并经自蒸馏保持精度（Llama 4 Scout 109B 转换后平均精度差 <1%）；DeepSeek-V3 EP + SGLang 推理 TTFT 加速 **32.6%**、prefill 阶段通信-计算重叠 **97.3%**；训练阶段 all-to-all 通信重叠 **88.9%**。**信号：从「系统级调度重叠」走向「模型架构让路通信」**。URL: https://arxiv.org/abs/2511.11505

- **arXiv 2602.00509《PROBE: Co-Balancing Computation and Communication in MoE Inference via Real-Time Predictive Prefetching》**（2026-02-03）: 面向 bursty 负载的推理系统——Gate-Initialized Lookahead Predictor 蒸馏 router 预测下一层专家激活；Hardware-Aware Balance Planning 在隐藏窗口约束下联合优化专家复制与 token 分配；Phase-Locked Co-Scheduling 以 split-phase 传输将带宽密集型专家迁移藏在计算后且不与 all-to-all 争用；极端负载波动下 prefill 延迟降 **1.32×**、decode 吞吐 +**1.26×**。URL: https://arxiv.org/abs/2602.00509

- **arXiv 2602.11686《LAER-MoE: Load-Adaptive Expert Re-layout for Efficient Mixture-of-Experts Training》**（ASPLOS 2026, 2026-02-12）: 新并行范式 **Fully Sharded Expert Parallel（FSEP）**——按设备数全分片每个专家参数、训练中经 all-to-all 以专家粒度动态恢复/重排，消除路由不均衡的 straggler 瓶颈；配合通信细粒度调度 + 负载均衡规划器，A100 集群相比 SOTA 训练系统加速最高 **1.69×**。URL: https://arxiv.org/abs/2602.11686

- **arXiv 2601.08800《MixServe: An Automatic Distributed Serving System for MoE Models with Hybrid Parallelism Based on Fused Communication Algorithm》**（ICDCS 2026, 2026-01-13）: TP-EP 混合并行 + **融合 AR-A2A 通信算法**——重叠节点内 all-reduce 与节点间 all-to-all；按模型超参与网络配置自动评估通信开销并选择最优并行策略；DeepSeek-R1/Qwen3 实测 TTFT 加速 1.08~3.80×、ITL 1.03~1.66×、吞吐提升 5.2%~50.3%。URL: https://arxiv.org/abs/2601.08800

- **arXiv 2606.15177《Coordinated Scheduling for MoE LLM Serving (Gimbal)》**（2026-06-13）: 跨层协调调度——前端 DP 引擎调度器用在线后端压力信号（KV 缓存占用/剩余 prefill/队列/MoE 专家压力）躲避过载引擎，后端专家放置用 MINLP 启发式联合考虑负载/源感知通信/迁移稳定性；相比 vLLM 平均 TTFT 降 **42.9%**、TPOT 降 **33.3%**、高负载吞吐 +3.0%。URL: https://arxiv.org/abs/2606.15177

- **arXiv 2607.20981《Beyond Independent Optimization: Compression, MoE Routing, and Quantization Interactions in Multimodal Edge Intelligence》**（2026-07-23）: 边缘多模态综述——论证视觉 token 压缩/Router 路由/量化/KV cache 策略/硬件约束五者强耦合不可独立优化（压缩改变路由分布→影响专家利用与量化敏感度；KV 策略决定多模态证据保留度；硬件约束常把计算节省转化为内存/通信瓶颈）；提出 Temporal Routing Consistency 作为视频 MoE 诊断指标。**方法论信号：硬件设计者需把「优化交互」而非「单点优化」纳入评估**。URL: https://arxiv.org/abs/2607.20981

## 洞察

- **MoE 通信优化的三层解法格局已成型**：系统层（MixServe/Gimbal/PROBE 调度重叠）→ 架构层（FarSkip 跳连接让路通信）→ 硬件层（Mozart/MoEntwine 晶圆级、Switching Efficiency 网络度量）；本期与前 4 期形成完整拼图
- **NVIDIA 官方叙事从「训练」延伸到「推理」**：08-07 期记录 GB300 预训练纪录，本期补全 Blackwell MoE 推理——all-to-all 原语去掉接收端中间缓冲、NVFP4 硬件加速、MTP 多 token 预测三件套，**每 GPU 吞吐 3 个月 +2.8×** 证明软件栈是全栈价值的重要组成部分
- **新度量信号**：Switching Efficiency η 把 AIDC 网络评估从「带宽」转向「计算有效吞吐/交换容量」，呼应 MoE 稀疏流量特征；对超节点 Scale-Up 域设计有直接参考价值
