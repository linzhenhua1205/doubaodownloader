## MoE 通信与专家并行（arXiv 增量）

- **晶圆级光互连热调谐开销：MoE 训练的跨层分析与铁电方案**（arXiv:2608.24637, 2026-08-25）: 专家并行通信密集，晶圆级 DWDM 光互连的 MRR 链路依赖热光调谐，工作负载诱发热波动超出温控环跟踪能力→通信阶段反复调谐停顿；3D 集成 GPU/EIC/PIC 栈 Ansys 热模型 + ht-sim 包级仿真，停顿时长由热模型导出而非假设；铁电电光调谐消除连续热调谐需求，消除停顿后 Mixtral 8x7B 加速 2.7x、Qwen-MoE 14.3B 3.8x、LLaMA-MoE 6.7B 3.3x——光子调谐延迟最小化是光互连 MoE 规模化性能兑现的关键约束。http://arxiv.org/abs/2608.24637
- **FreeBalance：预路由在线负载均衡，专家迁移移出关键路径**（arXiv:2608.14205, 2026-08-14）: 现有方案路由统计在 router 后收集，专家迁移落入推理关键路径；观察=在线均衡可大幅重叠进目标路由前的计算（如注意力），利用残差网络跨层隐藏表征相似性构建轻量 workload 预测器，路由决策前完成专家迁移规划，成本模型限制 swap 数使同步开销完全隐藏；max-to-mean rank 负载比降 32.8%、端到端 prefill 延迟降 13.1%，每层平均 5.1 个专家迁移开销被隐藏（约占关键路径 8.5%）。http://arxiv.org/abs/2608.14205
- **EasyBalance：跨层负载均衡，专家-设备映射零改动**（arXiv:2608.07964, ICML 2026）: 现有层内专家复制/迁移方案引入额外开销且限制扩展；洞察=其他层专家对当前层天然冗余，跨层 MoE 工作负载可联合执行互相抵消失衡；贪心调度跨层子集工作负载、推迟其余至后续均衡机会；无映射改动、即时适配，GPU 空转减少 40%+。http://arxiv.org/abs/2608.07964
- **RoutePack：MoE RL 训练联合专家放置与注意力感知打包**（arXiv:2608.12146, 2026-08-12）: MoE RL 双重负载均衡耦合——序列组合决定稠密注意力、token 路由决定稀疏专家；rollout 路由重放先验暴露每样本序列长度与逐层专家需求→层级规划器协调逐层专家重路由+注意力/专家感知打包，以 EDP-shard 感知目标最小化最慢分片成本；Ling-3.0-Tiny/Flash 上专家重路由提升 token 吞吐 3.80%/10.50%，路由感知打包再添 4.86%/3.98%，合计 8.85%/14.89%。http://arxiv.org/abs/2608.12146
- **TAOT：拓扑感知最优传输的动态专家副本放置**（arXiv:2608.03676, 2026-08-04）: 动态副本把热专家复制到空闲 rank，但忽视跨节点拓扑移动代价→通信可能超过均衡收益；将热 rank 过载与轻载 rank 余量建模为带通信成本矩阵的熵正则最优传输，Sinkhorn-Knopp 迭代产出 rank 级流提示，整数副本匹配+token 分配合成可执行调度，系统级 guest 权重传输与 home 专家计算重叠；端到端训练加速 1.43x，加权专家通信成本各配置最低、最高降 74%。http://arxiv.org/abs/2608.03676
- **Load Hijack：路由器投毒把 EP 调度变成可控 straggler 武器**（arXiv:2608.10614, 2026-08-11）: 恶意模型提供方仅修改 checkpoint 路由器权重并保留私有触发器，触发时把 token 集中到单 GPU 上共置专家→该 GPU 成 straggler 拖慢全体；三阶段优化使 92.3%-95.6% 触发 token 导向目标专家，普通输入路由接近干净参考；实测触发流量 TTFT 1.43x、吞吐 0.86x——MoE 服务需 checkpoint 路由审计与运行时负载监控。http://arxiv.org/abs/2608.10614
- **AcceptMoE：投机解码验证端承诺加权专家自选**（arXiv:2608.02989, 2026-08-04）: 树状 draft 并行验证激活各节点专家并集，token 数/专家并集/权重流量是三个独立成本度量；结合 router 分数与离线承诺概率自动调节每验证块专家数，卸载场景按 cache 驻留条件选专家而非预测自然路由；12 模型-任务对均值精度仅低 EAGLE-3 0.27pp，SGLang 单 batch 吞吐 1.290x（全驻留）/2.06x（物理卸载），主机到设备流量降 73.6%-77.1%。http://arxiv.org/abs/2608.02989

## MoE 边缘与消费级硬件（arXiv 增量）

- **EdgeXpert：MoE+投机解码协同的边缘 LLM 加速器**（arXiv:2608.05303, MICRO 2026）: 指出投机解码与 MoE 存在不兼容性（draft 多 token 验证激活专家并集）；prefill 阶段 prompt 级专家复用（轻量编码器识别重要 token 构建共享专家集），decode 阶段深度感知专家合并（仅加载显著通道+计算校准恢复精度）；Samsung 28nm @800MHz 综合，较先前工作延迟降 56.3%、能耗降 44.1%，精度近基线——MoE 稀疏性需硬件协同（通道级加载）才在边缘兑现。http://arxiv.org/abs/2608.05303
- **MoE 在消费级/边缘硬件是否真比稠密快？实证质疑**（arXiv:2606.21428 v3, 2026-06/07）: llama.cpp 实测 OLMoE-1B-7B（1.3B 激活/6.9B 总参）vs 三个稠密基线于 Apple M2 Pro 与 Jetson Orin Nano 8GB——激活参数优势仅在笔记本部分兑现（落后同激活 Llama-3.2-1B 约 10%），边缘设备进一步恶化（落后约 31%、每 token 能耗 2.1x、峰值内存触 8GB 上限）；decode 图逐节点计时显示路由仅占 MoE 块计算 <9%，差距源于总参数内存足迹、专家分发与 KV 压力——带宽受限硬件上推理成本跟随总参数而非激活参数，稀疏激活买不回设备被约束的维度。http://arxiv.org/abs/2606.21428
- **S2-MoE：边缘 MoE 自投机解码**（arXiv:2608.15018, 2026-08-15）: 朴素组合投机解码+MoE 在边缘产生过度验证开销与专家复用差；路由感知自适应投机扩展减冗余验证+复用感知专家门控+draft/target 共享上下文对齐；llama.cpp 实现，边缘设备多 MoE 模型/数据集较标准自回归最高 5.3x（均值约 2.0x）加速。http://arxiv.org/abs/2608.15018
- **DraftExpert：端侧 MoE 扩展感知自投机解码**（arXiv:2607.24434, 2026-07-27）: 面向延迟敏感单用户场景（路由专家按需从 CPU 内存/Flash 分级加载）；每层用自蒸馏训练一个轻量常驻 draft 专家（残差/logit/token/router 一致信号），固定足迹 shared+top-1+draft 组合+置信度扩展截断+目标专家预取；DeepSeek-V2-Lite/Moonlight-16B-A3B 于 CPU-GPU/Flash-NPU 卸载，decode 吞吐平均提升 1.45x、draft 接受率 84-87%、预取命中 86-88%。http://arxiv.org/abs/2607.24434

## MoE 推理与 KV cache（arXiv 增量）

- **MoEXBench：可组合 MoE 压缩基准**（arXiv:2608.21693, 2026-08-22）: 专家剪枝/权重量化/KV 压缩通常孤立评测，实际部署需堆叠组合；基准覆盖 10 个 MoE 模型（30B-235B 总参，标准注意力/混合线性注意力/滑窗注意力三架构），20%-50% 专家剪枝率、1-16 bit 量化、多 KV 精度，八模块评测套件；关键发现=组合压缩不可由单技术外推预测、压缩率不单独预测质量损失或运行时收益、专家剪枝是主导退化源。http://arxiv.org/abs/2608.21693
- **WiSP：极低资源硬件的 MoE 工作集视角**（arXiv:2606.21868, 2026-06-20）: 把低资源 MoE 服务重构为 GPU 工作集管理问题——路由专家权重与 KV cache 两股内存需求竞争有限 VRAM；路由感知专家分页仅驻留工作负载复用专家，同内存预算下 decode 吞吐较静态卸载最高 1.95x；预取帮助有限（瓶颈是 PCIe 带宽而非预测精度）→问题从预取转向分配：MV-WSA 按每字节边际延迟收益均衡专家/KV 池（受 KV 准入下限约束），在线控制器再添 1.20x 且模型输出不变。http://arxiv.org/abs/2606.21868
- **Models Take Notes at Prefill：KV cache 可编辑且可组合**（arXiv:2606.17107, 2026-06-14）: 前缀缓存只复用完全共享前缀，单字段变更使整个下游缓存失效；因果实证（四模型族）表明 prefill 时模型已把字段条件结论写入下游 notes，字段自身 KV 仅驱动 <1% 决策→KV 可编辑（errata 修正 notes，CoT 下仅改字段即恢复决策，8B 上 1.00 决策一致率、约 1% 计算）且可组合（预编译 skill RoPE 重定位拼接进任意上下文，logit 余弦 0.90-0.999、O(L) 而非 O(L²) TTFT）；在线 vLLM 前缀缓存保持 98.5% 命中率，p90 TTFT 降 53-398x——MoE/KV 多模型缓存均适用。http://arxiv.org/abs/2606.17107
- **GQE：GQA 自注意力上的专家层**（arXiv:2606.20945, 2026-06-18）: 标准稠密注意力对每 token 施加同样注意力头集合；在 GQA 组内由 router 每 token 选 k 个 query-head 专家、KV 头保持稠密不变——保留 GQA 的 KV 缓存收益仅削减活跃 query-head 计算；250M 规模 30B token 预算下匹配全激活 GQA 基线准确率，同时每 token 只激活一半 query head——注意力侧稀疏化新方向。http://arxiv.org/abs/2606.20945

## 前沿模型信号

- **Kimi K3：2.8T 参数 MoE 开源，激活 16/896 专家**（arXiv:2607.24653, 2026-08-07）: 2.8T 总参/104B 激活，原生视觉+1M context，Kimi Delta Attention+Attention Residuals+Stable LatentMoE（每 token 激活 896 路由专家中 16 个），整体 scaling 效率较 K2 提升约 2.5x；基础设施侧强调完美均衡的专家并行训练（算法-系统协同设计）+百万 token agentic RL 的持久 rollout/sandbox 状态——2.8T 权重驻留与 1M 上下文把 HBM 容量、专家卸载与 EP 互联带宽需求推到新量级，单柜承载（NVL72 级）面临压力。http://arxiv.org/abs/2607.24653
- **DiffusionGemma：MoE 基座上的扩散解码 1500 tok/s**（arXiv:2608.00146, 2026-07-31）: 从 Gemma 4 MoE（3.8B 激活/25.2B 总参）微调获得，离散扩散块并行精炼 256 token 替代逐 token 解码；训练预算 < 起始 AR 模型 10%；单张 H100 约 1500 tok/s、每次前向约 20 token，快于含 SOTA 投机解码的 AR 模型；推理形态从顺序 decode 转向并行精炼——对硬件=更宽并行度利用与不同权重/KV 访问模式，MoE 基座可承载非 AR 解码形态。http://arxiv.org/abs/2608.00146

## NVIDIA 生态动态

- **Blackwell 为 MoE 推理交付大规模性能飞跃**（NVIDIA Technical Blog, 2026-01-08）: 官方定位——模型持续变聪明→交互更频繁→需生成更多 token，平台必须以最低成本提供最多 token；Blackwell 的 MoE 推理能力（稀疏调度/专家驻留管理/推理栈优化）是 token 经济学的硬件杠杆；与 08-25 已收的 GB300 NVL72 MoE 预训练世界纪录、Qwen3.8-2.4T 机柜推理同属 NVIDIA"MoE 规模化=通信+内存体系"主线。https://developer.nvidia.com/blog/delivering-massive-performance-leaps-for-mixture-of-experts-inference-on-nvidia-blackwell/

## 趋势洞察（本组增量）

- **负载均衡从"事后修复"走向"事前预测"**：FreeBalance（路由前预测重叠）、EasyBalance（跨层联合执行、映射零改动）、RoutePack（rollout 重放先验）、TAOT（拓扑感知传输）四线一致——EP 失衡解法正从"检测-迁移-修复"转向"预测-规划-重叠"，专家权重迁移成本从关键路径剥离；对硬件启示=互联带宽不再是唯一杠杆，调度窗口、通信-计算重叠结构与拓扑感知同等重要。
- **边缘/消费级"稀疏红利"的证伪边界清晰化**：2606.21428 实证带宽受限设备推理成本跟随总参数（edge 落后稠密 31%、能耗 2.1x），而 EdgeXpert/S2-MoE/DraftExpert 的"软硬件协同+专家分级卸载"路线给出正解——纯软件 MoE 在边缘无优势，须硬件协同（通道级加载/常驻 draft 专家/路由感知分页）才能兑现稀疏激活价值；与 08-25 RotaryQuant（消费级 120B 拟合）互为印证：压缩+卸载+协同是边缘 MoE 三件套。
- **安全成为 MoE 硬件调度的新维度**：Load Hijack 证明路由器权重投毒可把 EP 调度变成可控 straggler 武器（TTFT 1.43x），checkpoint 路由审计+运行时负载监控应成为 MoE 服务基线能力——本专题此前未覆盖的风险面，与量化路由翻转（2608.11212，已由 08-25 收录）同属"路由决策脆弱性"家族。
- **前沿模型持续向超大规模 MoE 收敛+新解码形态**：Kimi K3（2.8T/104B，2.5x scaling 效率）把权重驻留与 EP 通信推到新量级，超节点单柜承载边界受挑战；DiffusionGemma 展示 MoE 基座可承载非 AR 解码（块并行精炼），硬件需同时准备"更大权重集"与"新访问模式"两类需求。
