## §1 电源架构 (Power Architecture)

### 1.1 🔌 NVIDIA Engineering SuperLab 实机展示800VDC运行Vera Rubin NVL72

### 1.4 🆕 Vicor VPD 完整技术论述 (PEN Power Corner, 2026-07-16)

Maury Wood (Vicor VP) 详细阐述了**Factorized Power Architecture (FPA)**：先稳压后变压，48V走完PCB到负载点，固定K因子电流倍增器支持48:1以上无效率损失。

**Vicor vs TLVR对比**: TLVR需要小步进比优化效率（2:1-4:1），Vicor的电流倍增器在48:1及以上无惩罚。IVR嵌入封装方案面临**可返修性**和**定制化成本**约束。

**关键预判**: 玻璃基板+面板级封装(2029~600mm面板)将导致单面板供电需求 **~30,000A**，届时VPD是唯一可行方案。

### 1.5 🆕 SemiQ QSiC Dual3 SiC模块发布 — 三阶段晶圆筛选+Gen4路线图 (PEN, 2026-07-30)

SemiQ总裁Timothy Han详解QSiC Dual3模块：1200V/1mΩ同封装最高密度，每模块50芯片(28MOSFET+22SBD)，标准EconoDual3封装兼容IGBT替换。

**三阶段筛选体系**:
- **Phase 1**: 晶圆级栅氧老化(150-175°C, >35V)→100%光学检测→KGD → ✅量产
- **Phase 2**: 高温高漏源偏压(1200V器件测至>1450V)→IATF 16949认证 → ✅量产  
- **Phase 3**: 单粒KGD(AC开关/雪崩测试/AOI) → 🚧开发中

**路线图**: 1700V/2300V Gen4 H2'26工程样片 → 3300V新平台2027

### 2.4 🖥️ ASRock Rack 4U16X-GNR2 — NVIDIA HGX B300 8-GPU 服务器深度评测

ASRock Rack 4U16X-GNR2 是面向 AI 训练/推理的高端 8-GPU 服务器，支持双 Intel Xeon 6 (Granite Rapids) + 8× NVIDIA Blackwell Ultra (B300) GPU，是 HGX B300 参考设计的主流实现。

**关键设计细节**:
- **架构**: 双 Intel Xeon 6700P 系列，16 DDR5 DIMMs/CPU (共 32 DIMMs)，高于 6900P 的内存容量
- **GPU**: 8× NVIDIA HGX B300，通过 NVIDIA NVLink 交换
- **散热**: 标配 **DLC (直接液冷)**，CPU 和 GPU 均使用冷板。**另有 ZutaCore 两相冷却可选版**（不用水的两相冷却方案）
- **冷板泄漏检测**: CPU 冷板周围布置 **泄漏检测 ribbon**，检测到泄漏可自动关机
- **冷板顶部可走线**: 因液冷不需要散热片上方气流通道，电缆可以直接从冷板上方穿过，简化理线
- **存储**: 12× 2.5" U.2 NVMe（2个直连CPU，10个通过PCIe Switch）
- **网络**: 前板 **8× OSFP 800Gbps  cages** — 无需额外PCIe卡即有 6.4Tbps 网络带宽
- **PCIe**: 后部 2× FHHL PCIe Gen5 x16 插槽（通常用 ConnectX-7 或 BlueField-3 DPU）
- **电源**: 10× 3kW 80Plus Titanium PSU（后部）
- **散热风扇**: 4× 大型热插拔风扇（侧）+ 3× 小型风扇（中央下部），辅助内存/存储/网络等组件风冷
- **前部 I/O**: 4× USB 3 Type-A + VGA + 电源按钮 + **前部管理端口/1GbE 端口**（可通过内部以太网线缆灵活配置前后位置，一个SKU覆盖多种布线需求）

**两相冷却版本**: ZutaCore 方案使用介电液体在冷板内部发生相变（沸腾→冷凝），无需水泵输运的冷却液循环到外部 CDU，适合不想部署水冷基础设施的客户。

- **来源**: [ServeTheHome - ASRock Rack 4U16X-GNR2 NVIDIA HGX B300 8-GPU Server Review](https://www.servethehome.com/asrock-rack-4u16x-gnr2-nvidia-hgx-b300-8-gpu-server/)
- **发布时间**: 2026-07-27

### 2.5 🖥️ MSI CD182-S6091-X2 (DLC) — AMD EPYC Venice 1OU2N 液冷服务器 + ORv3 机架

MSI 在 Computex 2026 展示了 AMD EPYC Venice 平台的 1OU2N 超高密度服务器节点，采用 **DLC 直接液冷**。

**核心规格**:
- **形态**: 1OU 双节点，每节点双路 EPYC Venice（OCPv3 兼容）
- **密度**: 1OU 内 4 颗 Venice CPU + 16 通道 DDR5 内存（32 RDIMMs/节点 x 2 节点）
- **插座**: 新 SP7 插槽，支持 **PCIe Gen6**
- **散热**: 双回路液冷 — CPU 回路（串行冷板）+ **内存回路**（液冷 DIMMs），均配有泄漏检测
- **后部**: 每节点 1× OCP 3.0 NIC 插槽 + 1× FHHL PCIe Gen6 x16 + 1× HHHL PCIe Gen6 x16
- **存储**: 每节点 4× E1.S Gen6 SSD 槽（支持 Micron 9650 等下一代 SSD）
- **BMC**: ASPEED AST2700（新一代 BMC）
- **供电**: **48VDC busbar**（无内置 PSU）

**MSI ORv3 液冷机架**:
- **规格**: 44OU 机架，容纳 28 个 CD182 节点（112 颗 Venice CPU + 1792 条 RDIMM）
- **功耗**: **100kW/rack**
- **电源**: 2× 55kW Chicony 电源架为 busbar 供电
- **CDU**: 1× 100kW Auras CDU（液-液换热）
- **网络**: 1× 32端口 100GbE 交换机（数据）+ 2× 48端口 1GbE 交换机（带外管理）

**意义**: 液冷使 CPU 密度达到 1OU 内 4 颗 500W+ CPU + 64 RDIMMs，这在风冷下不可实现。MSI 的 48VDC busbar 供电也反映了 OCP ORv3 标准在 AI 高密度机架中的推进。

- **来源**: [ServeTheHome - MSI Slyly Shows off an Upcoming DLC AMD EPYC Venice Platform With CD182-S6091-X2 Servers and Racks](https://www.servethehome.com/msi-slyly-shows-off-an-upcoming-dlc-amd-epyc-venice-platform-with-cd182-s6091-x2-servers-and-racks/)

### 2.8 🖥️ AMD Zen 7 拆分为三个 EPYC 家族 — Florence/Ferrara/Fidenza (TH Premium, 7/27)

| 家族 | 定位 | 核心特征 |
|:----|:-----|:---------|
| **Florence** | 通用 EPYC | 全新 Zen 7 核心 + AI compute 扩展 + 新内存技术 |
| **Ferrara** | AI 主机节点 | 出现在 Helios 600 机架中，与 MI600 GPU + Pensando "Palma"/"Levanzo" 网络配对 |
| **Fidenza** | Agentic Sandbox | 沙盒化 agentic AI 部署产品 |

**关键信息**:
- AMD 未披露 Zen 7 的任何核心数、工艺节点或插槽信息，仅表示使用 **leading-edge 工艺**
- 这是 AMD 第一次在 **发布前 2 年** 就将一个 Zen 代际拆分为 3 个明确命名的产品线
- 产品组合从 "general-purpose enterprise/cloud/telecom/SMB/HPC" 扩展到 **agentic AI + GPU head node** 两个明确 AI 细分
- AMD 参考指标从传统 CPU benchmark 转向 **AI agents per watt / per dollar / per rack**（基于 CPU thread 资源的代理估算）
- 路线图扩展到 **2030 年**: Venice→Verano→Florence/Ferrara/Fidenza→Ravenna Zen 8
- Announced TDP 已被替换为 **Default CPU Power** 新指标

- **来源**: [Tom's Hardware - AMD splits Zen 7 into three EPYC families](https://www.tomshardware.com/pc-components/cpus/amd-splits-zen-7-into-three-epyc-families-for-2028-and-starts-selling-server-cpus-by-the-agent)

### 5.6 💧 SemiEngineering 液冷综述 — 冷却技术全景（2026-01）

SemiEngineering 在 2026年1月发布深度综述《Liquid Cooling Gains Traction In Data Centers》，系统比较了三类液冷方案：

**三大液冷方案对比**:

| 方案 | 原理 | 热效率 | 优点 | 缺点 |
|:----|:----|:------|:----|:----|
| **单相冷板 (DLC)** | 冷板内流经液体（PCW 50/50），液体不沸腾 | ★★★ | 成熟、低风险、可封装级集成 | 需外部CDU、冷板-芯片间接传热 |
| **两相冷板** | 冷却液在冷板内沸腾→冷凝，利用潜热 | ★★★★ | 极高热通量密度、不含水方案 | CHF临界热通量风险、复杂 |
| **浸没式** | 整机浸入介电液体 | ★★(单相) ~ ★★★(两相) | ~100% 热捕获、冷却所有器件 | 单相冷却高功率芯片慢、维修复杂、液体成本高 |

**关键陈述**:
- 水的热导率是空气的 **20×**，密度约 **1000×**
- 单芯片冷板已达 **4kW** 解热能力，JetCool 直接喷射方案声称可达 **5kW**
- 直接喷射（jet impingement）将冷却液直接喷到硅片背面，热阻最低但需要包封隔离多个 die
- 两相冷却的 **临界热通量 (CHF)** 是关键限制：超过该点后表面液膜蒸干→冷却性能断崖下降
- 冷却液主要为 **PGW (propylene glycol + water, 常 50/50)**，介电浸没液更贵但无毒/不可燃/可生物降解
- 液冷基础设施选择决定数据中心架构：一旦选择一种冷却方式，全机架甚至全 DC 都需统一

**冷却创新公司**:
- **Alloy Enterprises**: 3D 打印堆叠锻造冷板，通道比传统金属3D打印小一个数量级，可定制热区
- **JetCool**: 直接喷射微喷嘴方案，自含式液冷单元可替换服务器风扇，降功耗 15%，免 DC 液冷改造
- **HydroGraph**: 石墨烯涂层 + 烧结镍铜多孔表面，HTC 提升 152%，CHF 提升 40%（两相冷却）

**液冷的经济与环境考量**:
- 液冷总投资包含：冷板 + CDU + 管道 + 泄漏检测 + 维护
- 热量可回收利用（暖水管供给附近居民热水）
- 大型 DC 日耗水可达 500 万加仑（相当于 1-5 万人口城镇）

- **来源**: [SemiEngineering - Liquid Cooling Gains Traction In Data Centers](https://semiengineering.com/liquid-cooling-gains-traction-in-data-centers/)
- **发布时间**: 2026-01-15

### 5.7 💧 ZutaCore 两相冷却 — ASRock B300 的可选冷却方案

ASRock Rack 4U16X-GNR2 提供两种液冷版本：传统 DLC 和 ZutaCore 两相冷却。

**ZutaCore 方案特点**:
- 使用**介电液体**在冷板内部相变（沸腾→汽化→冷凝），无需循环到外部 CDU
- 不含水 → 泄漏不会损坏电子元件
- 适合**不希望部署完整水冷基础设施**的客户
- 冷板自含式，不需要复杂的管路部署到每个机架
- 热通量密度高于单相 DLC

**与 DLC 的关键差异**: DLC 需要将水泵送到外部 CDU 降温再循环；ZutaCore 的冷凝在冷板内部完成，热量通过二次回路排出。后者的部署灵活度更高，但两相系统的复杂性和成本目前高于单相 DLC。

- **来源**: [ServeTheHome - ASRock Rack 4U16X-GNR2 NVIDIA HGX B300 8-GPU Server Review](https://www.servethehome.com/asrock-rack-4u16x-gnr2-nvidia-hgx-b300-8-gpu-server/) (Page 1-2)
- **发布时间**: 2026-07-27
