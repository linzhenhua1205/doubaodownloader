### ① AT&T × Microsoft Foundry × AMD：万亿Token级电信AI工作负载投产

| 项目 | 内容 |
|:-----|:-----|
| **来源** | [Microsoft Azure Blog](https://azure.microsoft.com/en-us/blog/att-and-microsoft-scale-trillion-token-workloads-with-microsoft-foundry-and-amd/), Jul 23, 2026 |
| **摘要** | AT&T 基于 Microsoft Foundry Managed Compute + AMD GPU 构建了 OTel2.0（电信领域 AI 模型），是首个大规模企业级异构 GPU 部署案例 |
| **关键数据** | |
| GPU 集群规模 | **约 530 颗 GPU**，其中 **430 颗 AMD Instinct MI300X**，其余为 NVIDIA GPU |
| 模型推理规模 | Phi-4 每月处理 **7,000 亿 token**（700B tokens/month），用于数据准备和合成数据生成 |
| 训练规模 | OTel2.0 总处理 **约 1 万亿 token**（1T tokens），训练量 **约 4,000 亿 token** |
| 成本节省 | 使用开源模型（Phi-4/OSS-120B/Gemma-4）替代前沿 API 模型，**节省数千万美元** |
| 部署速度 | 从过去**周级**缩短至**天级** |
| 模型生态影响力 | OTel 1.0 累计下载量超 **2,500 万次** |
| **架构特征** | 多模型多 GPU 异构策略：Phi-4 负责合成数据/数据准备，OSS-120B 负责高推理任务，Gemma-4 用于开发工作流 |
| **行业意义** | ① AMD MI300X 首次在万亿 token 级企业 AI 工作负载中大规模验证；② Microsoft Foundry Managed Compute 证明"模型+基础设施+治理"一体平台可显著降本；③ 企业 AI 从"通用模型 API"向"开源模型+托管 GPU"的经济模式转变 |

**影响判断**: 🟢 正向。这是 Microsoft 在 Azure AI 基础设施竞争中的关键里程碑——Foundry Managed Compute 提供类似 AWS Bedrock 的托管推理体验，但强调"开源模型选择+异构 GPU+成本优化"，差异化明确。AMD MI300X 的大规模验证对 NVIDIA 形成实质竞争压力。

### ② Microsoft Foundry GPT-5.6 全系列 GA + APAC Data Zone 发布

| 项目 | 内容 |
|:-----|:-----|
| **来源** | [Microsoft Azure Blog](https://azure.microsoft.com/en-us/blog/frontier-models-and-production-agents-advancing-microsoft-foundry-for-the-agentic-era/), Jul 9, 2026 |
| **摘要** | OpenAI GPT-5.6 全系列（Sol/Terra/Luna）在 Microsoft Foundry Models + Agent Service 中正式 GA，同步发布 Asia-Pacific Data Zone |
| **GPT-5.6 定价** | |
| GPT-5.6 Sol (旗舰推理) | 输入 $5/M tokens, 输出 $30/M tokens |
| GPT-5.6 Terra (均衡) | 输入 $2.5/M tokens, 输出 $15/M tokens |
| GPT-5.6 Luna (快速经济) | 输入 $1/M tokens, 输出 $6/M tokens |
| **APAC Data Zone** | 亚太客户可在区域内运行 OpenAI frontier 模型，数据不出亚太区，无额外环境拼接成本 |
| **平台规模** | **10 万+** 组织已在 Microsoft Foundry 上构建 AI 应用 |
| **投产企业** | Adobe（Agent）、**Telefónica**（网络运营 Agent 平台）、Tata Consultancy Services（Agent 优化） |
| **架构特征** | Foundry Agent Service 支持 Microsoft Agent Framework + GitHub Copilot SDK + LangGraph + OpenClaw + Hermes 等框架；内置 VNet 隔离、Toolbox（动态工具选择）、Memory（程序/用户/会话）、Routines（定时/事件触发）、Voice Live（实时语音） |
| **ROI 管理** | Agent Optimizer（自动调优降低成本）+ ROI for Agents（连接业务价值与成本衡量） |

**影响判断**: 🟢 正向。GPT-5.6 全系列在 Foundry 独占首发凸显 Microsoft-OpenAI 联盟在推理层的排他优势。Luna 定价仅 $1/M tokens 输入，与 GPT-4o mini 价格相当但能力更强，将推动低延迟高吞吐 Agent 场景爆发。APAC Data Zone 是应对亚太数据主权监管的关键布局。
