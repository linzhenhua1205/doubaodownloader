## 🔥 本期核心

### ① 🔴 AT&T + Microsoft Foundry + AMD — 万亿 token 级电信 AI 部署（Jul 23）

| 项目 | 内容 |
|:----|:------|
| **事件** | AT&T 通过 Microsoft Foundry Managed Compute 构建 OTel2.0，首次公开 trillion-token 级 AI 负载的 CSP 算力平台用量详情 |
| **时间** | 2026-07-23 发布 |
| **来源** | [Microsoft Azure Blog](https://azure.microsoft.com/en-us/blog/att-and-microsoft-scale-trillion-token-workloads-with-microsoft-foundry-and-amd/) |
| **作者** | Steve Sweetman, VP of Product Marketing, Foundry Models |

**算力规模**:

| 指标 | 数值 |
|:----|:-----|
| 🖥️ GPU 总量 | **约 530 张**（通过 Foundry Managed Compute） |
| 🟡 AMD Instinct MI300X | **430 张** |
| 💬 处理 Token 量 | **约 1 Trillion (1T)** |
| 🎯 训练 Token 量 | **约 400B** |
| 💰 成本节省 | 使用开源模型（Phi-4 等）替代 frontier 模型，**节省数千万美元** |
| 📦 模型组合 | Phi-4（~700B tokens/月数据制备）、OSS-120B、Gemma-4 |
| 🚀 部署速度 | **天级部署**替代周级基础设施准备 |
| 📊 OTel 1.0 下载量 | 超 **25M 次** |

**核心意义**:

1. **CSP 算力调度平台的真实验证** — Foundry Managed Compute 承载了真实的 trillion-token 级生产负载，提供了跨 GPU 架构（AMD MI300X + NVIDIA）的异构调度能力
2. **AMD 在 CSP 推理训练场景的关键突破** — 430 张 MI300X 是 AMD 在 Microsoft Foundry 内部署规模最大的公开案例
3. **开源模型的经济学验证** — Phi-4 替代 frontier 模型做数据制备，节省数千万美元。这是在 CSP 平台上的"算力成本优化"实战数据
4. **非技术公司的大模型自建路径** — AT&T 作为电信运营商，展示了在 CSP 平台上自建行业大模型（OTel）的完整路径
