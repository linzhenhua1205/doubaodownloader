## 📌 本期主线

### ① bmcweb Redfish 新特性 — SubProcessors 处理器核心层级 🆕
**Inspur George Liu 主导，08-01 双 commit 合入（bmcweb）**
- Processor schema (v1_18_0) 新增 **SubProcessors 集合 + 核心资源**，管理粒度从「CPU 插槽」下沉到「核心」：
  - `GET /redfish/v1/Systems/system/Processors/cpu0/SubProcessors/core0` → `ProcessorType: "Core"`
  - association 对象 (containing/contained_by) 链接，配套 phosphor-dbus-interfaces [8c79b1d](https://github.com/openbmc/phosphor-dbus-interfaces/commit/8c79b1dc0270d01c0b713a345c8ec39533c542e4)
- Redfish Validator 通过；GET/HEAD 均返回 Link header
- **意义**: 为细粒度核心级调度、故障定位、能耗/频率管理铺路；GPU 厂商(此前已合 Chassis/Processors/PCIe Gen6)之后，CPU 内部结构也成为 Redfish 可枚举对象
- 来源: [9e59f0a](https://github.com/openbmc/bmcweb/commit/9e59f0a176aac9dfa7f029370ea03c25a088d9a2) · [625222a](https://github.com/openbmc/bmcweb/commit/625222aca8b622a42c8aa1039aa8ec77ee540f81)

**Jagpal Singh Gill (Meta) + Eldin Lee (Quanta)，07-26~07-31 密集 6+ commits，07-31 合入主仓库**

## 📊 趋势观察

1. **Redfish 数据模型粒度下沉**: Chassis→Processor 关系 (NVIDIA) → PCIe Gen6 (NVIDIA) → **SubProcessors 核心级** (Inspur)，BMC 管理对象逼近硬件最小可管理单元
2. **Modbus 成为带外管理的「第四总线」**: 连续 3 批 commits 聚焦大规模传感器轮询的可靠性与启动性能（Meta 数据中心场景驱动）
3. **IPMI 双线撤退**: host-ipmid 只做缺陷修复，pid-control 已可编译期去除 IPMI 依赖
4. **内核升级是 BMC 配置的隐藏风险源**: INA238 采样电阻默认值变更案例，提醒传感器校准与内核版本强耦合
