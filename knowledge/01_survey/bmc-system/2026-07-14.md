## 🛡️ 动态 ② — CVE-2026-7254: IBM OpenBMC 未认证 DoS 漏洞

| 字段 | 值 |
|:-----|:----|
| **CVE ID** | [CVE-2026-7254](https://nvd.nist.gov/vuln/detail/CVE-2026-7254) |
| **发布时间** | 2026-05-27（NVD 收录: 2026-05-27，最后更新: 2026-06-17） |
| **来源** | IBM Corporation（自报） |
| **影响产品** | IBM OpenBMC FW1110.00 — FW1110.11 |
| **漏洞类型** | CWE-1284: Improper Validation of Specified Quantity in Input |
| **攻击向量** | CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:N/I:N/A:L **5.3 MEDIUM** |
| **CISA 评估** | SSVC: exploitation=none, automatable=yes, technicalImpact=partial |
| **IBM 公告** | https://www.ibm.com/support/pages/node/7272993 |

### 解读

- **未认证远程攻击者**可通过网络向受影响版本 IBM OpenBMC 发送特制请求，触发拒绝服务（BMC 宕机/重启）
- CWE-1284 表明是**输入数量验证缺失**——可能因超大数据包/请求导致 BMC 资源耗尽或崩溃
- CISA 评估为 **automatable=yes**（可自动化利用），但 **exploitation=none**（尚无公开利用代码）
- IBM 已于 FW1110.11 之后修复，受影响用户需升级至 >FW1110.11 版本
- 此 CVE 影响的是 IBM 定制版 OpenBMC（基于上游 OpenBMC 加 IBM 闭包），上游社区 v2.18.0 不受此直接影响
