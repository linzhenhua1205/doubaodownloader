## ② bmcweb: Fix EventService PATCH response handling (补报)

> 来源: OpenBMC GitHub — bmcweb
> 提交者: Yuvakumar-Selvamani
> 合并日期: 2026-07-16
> SHA: 509ced5

**问题**: 此前 EventService PATCH 请求的响应处理存在缺陷。当客户端向 `/EventService` 发送 PATCH 请求（修改事件订阅属性如 `DeliveryRetryPolicy`）时，响应处理逻辑不完整，可能导致客户端收到不完整的响应体或不正确的状态码。

**修复**: 修正 EventService PATCH 操作的响应构建逻辑，确保：
- 响应体正确包含修改后的 EventService 属性
- HTTP 状态码符合 Redfish 规范要求
- 错误场景下返回恰当的 @Message.ExtendedInfo

**影响**: 这是一项**合规性修复**——不影响功能可用性，但影响 Redfish 标准兼容性。在 BMC 管理平台（如 OpenStack Ironic / Redfish client 工具链）通过 PATCH 动态调整 EventService 配置的场景下，修复前客户端可能误判操作结果。

## ③ openpower-vpd-parser: vpd-tool error codes (Jul 17 续报)

> 来源: OpenBMC GitHub — openpower-vpd-parser
> 提交者: RekhaAparna01
> 合并日期: 2026-07-17
> SHA: 989d966 (该批次最新 commit)

**变更**: `vpd-tool` 工具定义**结构化错误码**，替代原有的散列错误返回方式。这是多线程 VPD 采集重构的收尾工作之一。

**意义**: 错误码结构化为 BMC 上层管理软件提供可编程的故障诊断接口。当 VPD 采集失败时，管理平台可直接读错误码定位故障类型（FRU 不在位 / 超时 / EEPROM 损坏等）。
