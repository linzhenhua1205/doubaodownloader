## 📌 本期主线: phosphor-modbus 走向「自包含检测」— Modbus 管理面架构收敛

### 1.1 entity-manager 移除 Modbus 检测/FRU 接口（架构重构信号）

| 项目 | 详情 |
|:-----|:------|
| **提交** | `97bf027789` + `4dfb8a8480` — Jagpal Singh Gil — **drop ModbusRTUDetect / Modbus FRU interface** |
| **日期** | 2026-07-30 |
| **变更** | phosphor-dbus-interfaces 删除 `ModbusRTUDetect` 配置接口 + `Modbus FRU` inventory 源接口（含生成的 meson 文件） |
| **原因** | Modbus RTU 设备的**检测与 inventory 生成已改由 phosphor-modbus 自身完成**，entity-manager 不再需要外部配置 Schema 参与 |
| **架构意义** | 设备检测逻辑从「entity-manager 外部 Schema 驱动」下沉为「phosphor-modbus 内部实现」→ Modbus 成为自包含管理单元，EM 瘦身、配置面简化。与昨日 (07-31) 报道的 Modbus RTU 性能优化 4 commits 属同一持续工程 |
| **来源** | https://github.com/openbmc/phosphor-dbus-interfaces/commit/97bf027789 · https://github.com/openbmc/phosphor-dbus-interfaces/commit/4dfb8a8480 |
