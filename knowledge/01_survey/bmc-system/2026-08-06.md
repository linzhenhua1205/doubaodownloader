## 本期核心发现

### 📌 主线一（安全）：phosphor-no-root-login distro feature — 一键关闭 root 登录，安全基线前移

- **meta-phosphor: 新增 `phosphor-no-root-login` distro feature**（Akshay Gaitonde，2026-08-05 合入）: 此前禁用 root 登录需手工协调三个独立设置——`allow-root-login` image feature、phosphor-user-manager 的 `root-user-mgmt` PACKAGECONFIG、root 账户配置；因 PACKAGECONFIG 无法依赖 IMAGE_FEATURES，新增统一 distro feature 同步三者（启用即移除 allow-root-login、禁用 root-user-mgmt、锁定 root 账户）。遵循已有 df-override 模式（`phosphor-no-ipmi-rmcp` 先例），**默认禁用**。p10bmc 实测对比：默认态 root 可经 SSH/Redfish 登录、被枚举为 managed account、处于 ipmi/web/redfish/priv-admin 组；启用后 root 登录双通道均拒绝、不再枚举、移出特权组、账户锁定。https://github.com/openbmc/openbmc/commit/08999346d2846def90bbaed96cfe49cf7dffd503

### 📌 主线二（Redfish）：bmcweb — BiosReset 跨平台化 + Fabric 资源 schema 落地

- **bmcweb: BiosReset Redfish action 从 openpower 专属走向通用**（Oliver Brewka/9elements，2026-08-05）: 原实现仅 openpower 平台可用（调用 `org.openpower` 名下 dbus 服务）；配合 platform-init 新增 cmos-reset 服务（gerrit 88369），改为调用 `xyz.openbmc_project` 名下服务，并同步适配 openpower-pnor-code-mgmt 的 busname（gerrit 88228）——BiosReset/CMOS 复位能力跨平台解耦。https://github.com/openbmc/bmcweb/commit/0f29283cbaa19978a8f9601270df23c85ca16f45
- **bmcweb: 安装 Fabric.v1_4_0 schema，`/redfish/v1/Fabrics` 资源正式可用**（Gunnar Mills/IBM，2026-08-05）: Fabric 资源早在 3132dacead0 已实现，但 JSON schema/CSDL 未随 bmcweb 安装，Redfish-Service-Validator 报 `Schema Error: Unable to locate the schema definition for the 'Fabric.Fabric' type`（bmcweb bump 93063 暴露）；本次以 symlink 方式补齐 json-schema + csdl 安装，为 Fabric 类资源（CXL/NVMe-oF 等）管理铺路。https://github.com/openbmc/bmcweb/commit/cc8f1c79e02dc50f7b5ae75c23f81150f51163cb
