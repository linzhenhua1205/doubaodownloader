### 版本定位

openUBMC 是基于 openEuler/Kunpeng 生态构建的开源 BMC 发行版。26.06 是社区第 **3 个正式版本**（前序: 25.12 LTS SP2, 26.03），定位：

> **"聚焦功能创新的社区版本，提供最新的运维增强与开发特性"**

### 亮点解读

1. **中国自主开源 BMC 生态加速** — openUBMC 依托全球计算联盟（GCC）、鲲鹏/昇腾/openEuler 生态，与华为硬件深度绑定。这是继 OpenBMC 社区主线之外，**唯一成体系的中国开源 BMC 发行版**
2. **26.06 比 26.03 固件更大**（76.4 MB → 77.27 MB），暗示新增驱动或功能模块
3. **LTS 双版并行策略** — 企业用户选 25.12 LTS SP2（保障到年底），开发者/新硬件用户选 26.06
4. **生态关系** — 参与组织包括全球计算联盟、鲲鹏社区、昇腾社区、openEuler、openGauss 等，与主流的 OpenBMC（Linux Foundation）互操作但独立演进

### 产品定位

openUBMC Studio 是**可视化 BMC 开发工具**，提供：

### 🎯 重点解读

#### 1️⃣ Meta Rainier A7 平台 — 新硬件平台入场

phosphor-dbus-interfaces 中新增 `Meta Rainier A7` 表示：

- **Meta** 继 OpenBMC 项目早期参与后，仍在为其定制硬件平台维护 OpenBMC 固件栈
- A7 可能是 Rainier 平台的**第 7 代迭代**（前序：Rainier Pass 1/2/3…），或是特定硬件版本
- 表明 Meta 在自家数据中心持续使用 OpenBMC 方案

#### 2️⃣ entity-manager: Mellanox ConnectX-6 NIC 配置

- **Mellanox ConnectX-6** (MCX653105A-ECAT) 是 NVIDIA/Mellanox 100GbE/EDR IB 网卡，说明 OpenBMC 实体配置覆盖从 CPU/GPU 扩展到了 **SmartNIC/DPU 外设**的 FRU/资产信息管理
- Potin Lai (NVIDIA) 提交了 NVIDIA cable cartridge probe 配置
- Daniel Hsu 更新了 yosemite5 (Facebook/Meta OpenBMC 参考平台) 的温度阈值

#### 3️⃣ EventLog 从 base64 → JSON

- 此变更**显著提升 Redfish EventLog API 的可用性**：之前附件下载返回 base64 编码字符串，用户/管理工具需额外解码；改为 JSON 后直接可读可解析
- 对集群级日志采集和自动化告警处理有直接价值

#### 4️⃣ 频率传感器类型

- bmcweb 此前主要支持温度/电压/电流/功耗等传感器类型，新增 `frequency` 类型意味着 BMC 可上报风扇转速、CPU/GPU 时钟频率、总线频率等动态信息
- 对**数据中心能效/散热**智能调控和**性能遥测**有支撑意义
