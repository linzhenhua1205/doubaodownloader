### 3.2 安全趋势信号

- **SMASH 服务是高风险面**: CVE-2026-3821 仅需低权限（PR:L），覆盖100+ 款 Supermicro 主板。SMASH (Supermicro 专有管理 Shell) 的安全设计已被质疑，**建议评估禁用 SMASH**
- **OpenBMC 安全加固持续**: bmcweb 本月进行了 TLS cipher 默认值升级 (→ Mozilla modern)、防御性 callback、SNMP 可构建排除。**OpenBMC 安全态度从"功能优先"转向"安全合规优先"**
- **Linux 内核 BMC 驱动安全**: 6月底连续修复 USB Type-C (wcove) 和加速度计 (bmc150) 的内核驱动漏洞，暴露了 BMC 外围器件驱动层的攻击面

## 信号交叉分析

1. **Rainier A7 → 量产窗口已开**: 过去一周内 GPIO 监控 → 电源控制 → RSE Postcode → SMBIOS MDR → 虚拟传感器 (CPU PLDM) → SOL 波特率 → I3C 寄存器全链条就绪。**Meta/Quanta 团队冲刺节奏清晰，预计1~2周内达到出货质量**
2. **BMC 安全 → 主动防护时代**: 三个月前还在被动修 CVE，现在 bmcweb 正在做防御性编程 + TLS 现代化 + SNMP 可关闭。**OpenBMC 的安全性策略正在经历转折点**
3. **固件管理 → 板级全器件覆盖**: CPLD (Lattice XO5-15D) → BIOS SPI Flash (Intel) → EEPROM (PT5161L) → Altera MAX10 FPGA → Intel E810 网卡 SPI Flash。**phosphor-bmc-code-mgmt 的器件覆盖面逐月增长**
4. **bmcweb → 双线推进**: 一边向上对接 DMTF 最新 Redfish 模型（Chassis/Processors/PCIe Gen6/EnvironmentMetrics），一边向下做安全基线加固（Mozilla Modern/防御回调/session 限流）
