### 1️⃣ bmcweb: 修复无 console server 平台 SSH port 500 错误

| 属性 | 值 |
|:-----|:---|
| **来源** | 🔧 `openbmc/bmcweb` commit `a585072a` |
| **日期** | 2026-07-06 |
| **作者** | Ed Tanous (NVIDIA) |
| **版本** | master branch (2.19-dev) |
| **重要性** | 🟡 **中** |

**概要**：
修复当系统未部署 `obmc-console-server`（SSH console）时，`/redfish/v1/Systems/system` 返回 HTTP 500 错误的 bug。部分平台（如 gb200-obmc）显式移除了 console server，现有代码未处理该情况导致内部服务器错误。

**关键特性**：
- `redfish_util.hpp`: 修正服务错误码处理逻辑，支持 `not found` 错误码传递
- `systems.hpp`: ComputerSystem handler 不再因缺少 SSH port 服务而 throw 500
- 影响范围：2 个文件（`redfish-core/lib/redfish_util.hpp` + `redfish-core/lib/systems.hpp`）
- 测试验证：gb200-obmc 平台（console server 已移除）实测 `/redfish/v1/Systems/system` 不再返回 500

**意义**：
对 NVIDIA GB200 NVL 等新一代 GPU 服务器意义重大——这些平台往往不会包含完整的 console server 栈，此修复避免了因组件缺失而导致 Redfish 根级接口不可用的场景。

### 3️⃣ IBM meta-layer: Telemetry 扩展至 500+ 传感器

| **重要性** | 🟢 **低** |

**概要**：
IBM 平台（`meta-ibm`）调整 telemetry 限值以支持 500+ 传感器，应对大规模服务器平台日益增长的传感器监控需求。IBM 的 `p10bmc` 等平台传感器密度持续增长，原有的限值已不满足需求。

**意义**：
