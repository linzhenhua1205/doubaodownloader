## ② 🛡️ BMC 安全漏洞 — 2026年7月三连击

### 2.1 CVE-2026-3820: Supermicro BMC SMTP 命令注入 (6月公告, 7/22 更新)

| 维度 | 详情 |
|:-----|:------|
| **CVE** | CVE-2026-3820 — CVSS 7.2 HIGH |
| **发现者** | Coreweave Red Team / Hoang Bui |
| **漏洞** | SMTP 服务配置允许注入特殊字符，导致任意代码执行 |
| **影响** | Supermicro AS-2115HS-TNR 等 BMC Firmware 01.08.01/01.06.04 |
| **攻击条件** | 需要管理员权限 (PR:H) |
| **修复** | 2026年6月发布修复版本，覆盖 X11~X14 全系列主板 |

### 2.2 CVE-2026-3821: Supermicro SMASH 任意代码执行 (7月公告)

| 维度 | 详情 |
|:-----|:------|
| **CVE** | CVE-2026-3821 — **CVSS 8.8 HIGH** |
| **发现者** | Anton Beidin / Eclypsium, Inc. |
| **漏洞** | SMASH 服务输入能力漏洞，授权攻击者可利用 SMASH 输入能力破坏数据完整性或发起 DoS |
| **攻击条件** | 需要低权限 (PR:L) — 比 3820 更危险 |
| **影响范围** | X13DEG-QT → X14DBG-DAP 等 **100+ 款主板** |
| **修复** | 2026年7月发布修复版本。**所有受影响板卡需更新 BMC 固件** |
| **信号** | SMASH (Supermicro 专有管理 Shell) 的安全性再次被质疑。**建议用户评估是否需要禁用 SMASH 或限制访问** |

### 2.3 CVE-2026-8058: IBM OpenBMC 密码泄露至审计日志 (7/28 公告)

| 维度 | 详情 |
|:-----|:------|
| **CVE** | CVE-2026-8058 — CVSS 4.5 MEDIUM |
| **漏洞** | IBM OpenBMC FW1110.00~FW1110.20, FW1060.00~FW1060.71 中，资源转储请求携带的密码被记录到 BMC 审计日志 |
| **影响** | 管理员可查看 audit log 中的明文密码 |
| **修复** | IBM 已发布安全通告 (https://www.ibm.com/support/pages/node/7280642) |

## 信号交叉分析

1. **Security 集中爆发**: Supermicro 两个月连续 BMC 安全公告 + IBM OpenBMC 首例 CVE + Linux 内核 BMC 驱动修复，说明 BMC 安全开始被安全社区密集扫描。**SMASH 服务 (CVE-2026-3821, 8.8) 是高风险信号** — 低权限即可远程利用
2. **Rainier A7 即将投产**: 电源控制、GPIO 监控、RSE Postcode 诊断、SMBIOS MDR、虚拟传感器（CPU PLDM）——7/27~7/28 两日内核全部合入，Meta/Quanta 团队在冲刺
3. **固件管理范围扩展**: CPLD (Lattice XO5-15D) + BIOS SPI Flash (IntelHostSPIFlash) + EEPROM (PT5161L) + Altera MAX10 FPGA，OpenBMC code-mgmt 在覆盖板级所有可编程器件
4. **Modbus RTU 性能优化**: Meta 在 phosphor-modbus 中做大量串行通信性能调优，暗示大规模传感器轮询场景的部署需求
