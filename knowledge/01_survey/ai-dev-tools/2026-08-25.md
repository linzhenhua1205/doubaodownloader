## 分析：三条主线

- **harness 三方哲学对照**：OpenAI（极简暴露式——"模型会越来越强"）vs Anthropic（对话迭代式——"反复确认降低犯错"）vs Pi/开源（自修改式——"harness 自己改自己"）。Databricks 实测 Pi > 官方 Codex 说明：**当模型足够强，harness 复杂度反而成为负资产**——对研发团队选型含义是：先评估模型能力水位，再决定 harness 投入，不必默认"官方 harness 最优"。
- **研发工具链 agent 化进入"全环节"阶段**：本周新项目覆盖 编码→调试（x64dbg-mcp）→会话管理（Wake/herdrm）→协作（cumora）→数据迁移（ai-data-extractor）→可观测（zoetrope）——且多数以 **MCP 为连接层**，说明 MCP 正在成为研发工具的"USB-C"标准，独立于具体 agent 产品。
- **agent 大众化的三个瓶颈已量化**：采纳率（内部 98% vs 外部 <1%）、成本（4 天 8000 万 token = 3x+ 订阅费）、可评估性（白领工作无代码式客观判据，GDPval 只是开始）——三者都是工程问题而非模型问题，**harness 与评测体系是下一阶段竞争主战场**。
