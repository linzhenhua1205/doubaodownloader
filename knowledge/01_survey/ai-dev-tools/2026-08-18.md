## 二、LLM 推理框架工程（vLLM Blog，2026-07~08）

- **Distributed Layerwise Offload（vLLM-Omni）**（2026-08-17）：将 DiT 权重按层分片+流式加载，124GB Cosmos3 模型在 64GB HBM 上即可服务，并估算可扩展到 200B+ 参数——显存受限场景下的大模型服务新路径。https://blog.vllm.ai/blog/2026-08-17-distributed-layerwise-offload
- **Qwen3.8-2.4T-A95B Day-0 支持**（2026-08-12）：2.4 万亿参数混合 MoE 模型开箱即用，提供 FP8/BF16 检查点 + NVFP4/MXFP4 量化权重，NVIDIA/AMD 双平台联合开发 kernel。https://blog.vllm.ai/blog/2026-08-12-qwen3.8
- **单 GPU 25K total TPS（Qwen3.5-397B-A17B-NVFP4）**（2026-08-06）：GB200 NVL72 分离式部署 + Blackwell GDN kernels + HMA cache 传输 + 异步调度修复，达到 25K tokens/s/GPU——推理性能新标杆。https://blog.vllm.ai/blog/2026-08-06-qwen35-25k-tps
- **Decode Context Parallelism（DCP）**（2026-08-07）：KV cache 按序列维度跨 GPU 分片，长上下文 agentic 负载较标准张量并行提升 3× 吞吐——长上下文 agent 工作负载的关键优化。https://blog.vllm.ai/blog/2026-08-07-decode-context-parallelism
- **DSpark 自适应验证**（2026-08-14）：按每请求置信度调度 draft 验证预算（而非逐 token 全验证），单一配置在 batch 1~256 均处吞吐/延迟前沿。https://blog.vllm.ai/blog/2026-08-14-dspark-adaptive-verification
- **Kimi K3 Day-0 支持**（2026-07-27）：混合 KDA prefix caching + DSpark 投机解码 + 生产级分离式部署，NVIDIA/AMD 双平台优化 kernel（呼应知识库 MoE 主线：K3 2.8T/104B 激活/16-of-896 EP）。https://blog.vllm.ai/blog/2026-07-27-k3
- **GLM-5.2 在 24×B300 达到 17ms 平均 TPOT**（2026-07-23）：NVFP4 + P/D 分离 + MTP 投机解码 + Model Runner V2，从 40ms 降至 17ms（−58%），展示 SLA 优先的工程权衡。https://blog.vllm.ai/blog/2026-07-23-glm-5.2-nvfp4-b300-pd
- **vLLM Semantic Router 升级为 Mixture-of-Models 系统**（2026-07-21）：从智能路由扩展为构建/评测/运行多模型系统的平台，路由→MoM 生态成为 2026 推理层新方向。https://blog.vllm.ai/blog/2026-07-21-vllm-sr-new-chapter-mom
- **DeepSeek V4 长上下文注意力落地 vLLM**（2026-04-24）：第一性原理解析 DSV4 长上下文注意力并在 vLLM 实现（与 MEMORY 中 DSV4 信号链承接：vllm prefill 预取优化 + CuMemAllocator.discard）。https://blog.vllm.ai/blog/2026-04-24-deepseek-v4

## 关键信号小结

- **AI coding agent 已进入"采用率实证 + 资本狂飙"双高阶段**：Airbnb 60% 代码、Cognition $25B / Cursor $50B 估值、Blacksmith $550M——2025 年的"AI 写代码"叙事已转化为企业财报与资本事件。
- **推理框架竞争焦点转向长上下文 agentic 负载与 MoM 路由**：DCP 3× 吞吐、25K TPS/GPU、Semantic Router→MoM，vLLM 2026 年的优化对象从"单请求吞吐"转向"agent 多轮长上下文"。
- **"AI 写码的可靠性验证"成为独立赛道**：Blacksmith 估值 10 倍 + arXiv 可靠性综述（206 条记录）+ 形式化验证研究（Vero）——验证层是 agent 生态的下一个利润池。
- **对服务器厂商含义**：agentic 负载（长上下文 + KV cache 分片）正在重新定义推理服务器的算力/显存/互联需求；DCP、层间卸载、MoM 路由等能力将影响未来平台选型与评测基准。
