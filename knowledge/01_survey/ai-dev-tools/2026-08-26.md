## TechCrunch 增量

- **Nvidia AVO harness 研究全文补全**（08-21, Julie Bort, TechCrunch）：Nvidia 研究证明长程任务中 harness（工具/记忆/规则的外围软件层）比底层模型更重要——自定义 harness（记忆处理优化 + "supervisor" 监督组件）让 Claude Opus 5 在 ARC-AGI-3（无指令 2D 游戏，需自主学会玩法）达 **100%**，裸模型 30%（各模型最高）；OpenAI 上月自行研究仅调 harness 两设置即让自家模型分数 ×3，但无人达 100%。Nvidia harness 名为 **AVO（Agentic Variation Operators）**，supervisor agent 扮演"CEO"纠偏（死路回溯、偏离引导）；El Hallak（Nvidia AI VP）定义 agent = 模型 + scaffolding/harness + runtime + skills/libraries。**成本维度**：Databricks 7 月研究（CEO Ali Ghodsi）同模型不同 harness 成本可差 **2x**；Microsoft 4 月测试 19 个 LLM 长程文档编辑全部灌满错误。Nvidia 主张开放 agent 栈（harness/infra/runtime 全可控）。**与昨日 OpenAI harness 负责人"临时拐杖"论（08-24）形成芯片厂 vs 模型厂的立场对立**，且与开源 deepseek-harness（★129K+）生态相互印证——"harness 是主角"获第三方量化支持。URL: https://techcrunch.com/2026/08/21/nvidia-just-showed-that-the-harness-not-the-ai-model-is-now-the-real-hero/

- **Claude Cowork 记忆合并（增量细节，主体已由 market 收录）**：Anthropic 将 chat 与 Claude Cowork 的记忆系统打通——任意一端学到的东西另一端直接可用（含 ongoing 聊天实时入库，替代"会话结束时总结"），用户可**读取/编辑/删除**任意主题记忆；默认不存敏感信息（健康/种族/宗教/政治/性别等），可手动开启"include sensitive topics"，保存敏感话题时通知用户；政府 ID/社保号/犯罪记录/移民身份永不保存。Free/Pro/Max 全端默认启用。**意义**：Agent 跨产品记忆打通 = "一个连续助理"，记忆可治理（透明可删）成为企业采用前提。URL: https://techcrunch.com/2026/08/25/claude-cowork-finally-remembers-what-you-told-the-app-in-chat/
