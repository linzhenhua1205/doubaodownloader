## 2. 推理优化与模型工程：SGLang v0.5.18（本组增量）

- **SGLang v0.5.18 发布**（2026-08-22, 710 PRs / 212 contributors）: ① **overlapped checkpoint staging**——启动时权重分页与 CUDA graph 捕获并行，Qwen3-32B on H100 启动快 **8.6~11.7%（prefetch）/ 2.38x（35.6s vs 84.8s）**，`--startup-weight-load-mode overlap` 开启；② **TP LMHead 改 All-to-All**：纯 DP-attention 下 DeepSeek-V4-Pro B200 decode LMHead 耗时 **320μs→169μs**、TPOT 36.97→35.67ms；③ **FlashInfer MNNVL 纯 allreduce**：非融合 allreduce 复用 MNNVL workspace 免落 NCCL，DeepSeek-V4-Flash TP4 Blackwell 小 batch **+6.9%**；④ **NVFP4 checkpoint 跑通 AMD**：Quark/ModelOpt NVFP4 权重加载时转 MXFP4，MiniMax-M2.7/GLM-5.1/Kimi-K2.6/Qwen3.5-397B/DeepSeek-R1 上 GSM8K 恢复 **97.5~100.2%**；⑤ **Kimi-K3 调优 MI355X**：grouped-head MLA verify 内核替代 split-KV 路径，并发 2-32 时吞吐 **1.37~1.77x**、ITL **1.45~2.42x**；⑥ 新增模型 Muse Glimmer/SANA-Video/LTX-2.5/Cosmos3 Edge/LingBot-Video-MoE 等，diffusion 侧 BCG 普遍 bit-exact（LTX-2 H200 e2e 10.75s→6.90s、1.56x）。https://github.com/sgl-project/sglang/releases/tag/v0.5.18
- **SGLang 工程面收敛**（同源 v0.5.18）: 编译内核缓存统一收敛到 `SGLANG_CACHE_DIR`（首次启动重编译一次）；RFC #29630 完结——JIT kernel 全部并入 `sglang.kernels`；配置系统 ServerArgs 只读化+单一审计入口；依赖升级 torch 2.13.0 + triton 3.7.1 + flashinfer 0.6.17。https://github.com/sgl-project/sglang/releases/tag/v0.5.18
- **vLLM v0.28.0**（2026-08-26, 584 commits/270 contributors）: Kimi-K3 跨栈攻坚（DCP/FlashKDA 融合/SiTU/投机预算 ~60% TTFT/每 GPU 省 ~17GiB）、DeepSeek-V4 sparse MLA 端到端、Model Runner V2 E/P/D 解耦、Tiered KV offload 成体系、`max_num_batched_tokens` 8192→16384 等——**已由 ai-frameworks 组完整收录**，此处仅交叉引用。https://github.com/vllm-project/vllm/releases/tag/v0.28.0
- **趋势判断**: 两框架 8 月下旬发布共同指向「**长上下文 + Agent 负载 + 国产/异构硬件**」三线：vLLM 押 KV 分层卸载与 E/P/D 解耦，SGLang 押启动/通信/量化三板斧；AMD ROCm 支持双双进入「旗舰模型（Kimi-K3/DSV4）可跑」阶段，NVFP4 跨厂互操作成为量化主线。

- **本周主线一：AI 编程工具从「补全/对话」全面转向「Agent 原生」**——Cursor 四连更（Origin 托管+订阅式 agents+独立 VM subagents+Builds 预热）、OpenAI Codex 周增 1.2 万星、Anthropic 插件生态双目录并行，IDE/托管/调度三层同时被 Agent 化改造，工具链锁定风险与「技能资产可移植性」问题同步上升（呼应 tech 组 Agent Skills 标准化判断）。
