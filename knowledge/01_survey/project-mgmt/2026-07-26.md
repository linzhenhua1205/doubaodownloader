### 1.2 方法论 — MCP 从开发者工具到通用项目管理

**Trello MCP 的接入层级**:
```
Claude / ChatGPT / Gemini / Cursor
         ↕ (自然语言)
    Trello MCP Server
         ↕ (API)
    Board -> List -> Card -> Checklist
```

**关键设计决策**:
- **零配置**: 用户在 AI 客户端添加 Trello MCP Server 即可使用，不需要开发者参与
- **双向**: 既可读取（"Show me cards due in July"），也可写入（"Create a board for the Italy trip"）
- **全功能**: 支持 Board/List/Card/Checklist 的 CRUD 操作

## 3️⃣ 🟢 Teamwork Graph CLI GA — 企业上下文基础设施成熟化

| 维度 | 内容 |
|:-----|:------|
| **来源** | [Atlassian Blog / Company News](https://www.atlassian.com/blog/company-news/closing-the-ai-context-gap) — Jul 7, 2026 |
| **作者** | Alan Braun (Head of Product, Ecosystem) |
| **工具** | Teamwork Graph CLI × Rovo MCP Server × Connectors × OAuth 2.1 |
| **方法论** | Context compounds — "Most AI tools are static. This one gets better without you thinking about it." |

### 3.1 关键数据

| 数据点 | 数值 | 说明 |
|:-------|:----:|:-----|
| Teamwork Graph CLI 命令数 | **567** | 跨 Jira/Confluence/JSM/Bitbucket/Assets/第三方 |
| 认证协议 | **OAuth 2.1** | 短生命期自动轮换凭证，替代静态 Token |
| 审计日志出口 | **Splunk JSON** | 完整请求链: 谁、何时、调用了什么 |
| 范围控制 | **Read/Write 分级** | 管理员设置组织策略，用户自定义个人范围 |
| 连接器数量 | **50+** | GitHub/Google Drive/SharePoint/Teams/Salesforce/Figma 等 |
| 连接器设置时间减少 | **>-40%** | 引导式配置 + 实时健康仪表盘 |
| 准确率增益 (TG CLI) | **+44%** | 预组装上下文 vs 逐工具获取 |
| Token 节省 (TG CLI) | **-48%** | 同上 |
| MCP 企业用户占比 | **>50%** | 确认企业级采用 |

### 3.2 方法论 — Context Compounds 模型

> **"Most AI tools are static. They're as smart on day 300 as they were on day one."**

Teamwork Graph 的自我增强循环:

```
工作产生(项目/事故/决策)
      v
Teamwork Graph 变丰富
      v
连接器加入 -> 外部工具上下文映射
      v
合作伙伴加入 -> 图深度对所有人增加
      v
Agent 获取更完整上下文 -> 输出更精准
      v
更多工作流过 -> (循环)
```

三层自我强化机制:
1. **工作使其更智能**: 每次团队交付项目、关闭事件、做出决策 → Graph 自动丰富
2. **工具链使其更广**: 每个开通的连接器 → 更多组织运行环境进入图谱
3. **生态使其自增强**: 更多伙伴连接 → 图对所有人更深
