## Agent 化 bug 管理（triage 自动化）

- **Linear/Teaching an agent to auto-fix bugs：triage 自动修复的真实边界**（06-12）: 工程师 Igor 数月实验结论——首次"对所有 incoming bugs 一 pass 修复"失败（上下文不足无法 one-shot），收敛后**两类问题首轮可修**：①dead feature flags——flag 100% 同结果触发 Datadog 监控 file issue，agent 跑 cleanup skill 近 100% 一次修复，人只 review+merge；②failing background tasks——失败率 >0.2% 触发，agent 有全部日志但**命中率仅约 1/3**；为省 token 加 gate：agent 必须先证明理解问题才允许尝试修复。URL: https://linear.app/now/linear-agent-bug-fix 📎 raw: tmp/raw/2026-08-16/linear-teaching-agent-auto-fix-bugs.md
- **Linear/bug 会话与 issue 共存的 "multiplayer by default" 模式**（06-12）: 报告/调查/失败/PR 全在 issue 内而非个人编辑器——自动化委派后全队可跟随进程，工程师可中途介入引导或审查；对比其他 coding agent 的 editor-led workflow，Linear Agent 设计为"通过团队已共享的工作流委派"；修不了的 bug 也先做初始调查，省接手人时间（"breadcrumbs"原则：Skills/Automations 标准化重复任务 + 代码库编码约定如安全发布方式/别碰的部分）。URL: https://linear.app/now/linear-agent-bug-fix 📎 raw: tmp/raw/2026-08-16/linear-teaching-agent-auto-fix-bugs.md
