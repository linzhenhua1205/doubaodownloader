## 🔴 Signal 1: Linear Coding Sessions 完整流水线 — 30% Bug 自动修复已成常态

| 维度 | 内容 |
|:-----|:------|
| **来源** | Linear Blog / Changelog (Jun 11, 2026) — `Coding sessions in Linear` + `Teaching an agent to auto-fix bugs` |
| **工具** | Linear Agent + Coding Sessions (Claude Code / Codex + MCP 生态) |
| **状态** | ✅ GA，Basic/Business/Enterprise 计划均可用 |

**方法论 — 自动修复流水线**:
1. **Triage Intelligence** 筛选新进入的 Bug Report
2. Agent 通过 MCP 连接 Sentry / Datadog 收集运行证据
3. 利用 Code Intelligence 深度接管代码库 → 追溯根因
4. **自动产出修复**并提交 Diff 供人类审阅

```
New Bug -> Agent 调查 -> MCP 取证(Sentry/Datadog)
       -> 代码分析 -> 根因判定 -> 修复 -> Diff/PR -> 人类审批
```

**关键数据**:
- Linear 内部用此流程处理 **~30% 的 incoming bug report**，绝大多数在**第一轮**完成
- 定价: 按 AI Credits 计费，Basic/Business/Enterprise 均可用
- 自动化的前提: Workspace Admin 在 Triage 设置中启用 Agent Automation

**增量价值** vs 之前记录:
- 06-27.md 仅记录了"30% auto-fix"数字；本篇补充了**完整流水线**（MCP 取证 → 代码分析 → 根因 → 修复）的工程实现路径
- 明确了这是**持续运行**能力而非实验性功能

## 🔴 Signal 2: Atlassian DX 纵向研究完整披露 — Productivity Gap 的根源在「协调」而非「编码」

| 维度 | 内容 |
|:-----|:------|
| **来源** | Atlassian Blog (Jul 15, 2026) — `How we're evolving Jira for AI-native software development` |
| **工具** | Jira Planner / Jira Coding Agent / Agent Sessions / Teamwork Graph / DX AI Cost Management |
| **方法论** | **Spec-Driven Development** + **Agent Orchestration** + **SDLC 对 Agent 可读化** |

**DX 纵向研究 — 首次公开完整数据**:
> 跨专业工程团队的纵向研究: AI 使用量 **+65%**，但开发者速度**未同步增长**，封顶 **+15%**，多数组织平均 **+10%**

**Productivity Gap 的归因**:
> "The gap is not because models are bad at writing code. It's because software development has never been only about writing code."

**Jira AI-native 全栈发布**:

| 能力 | 功能说明 |
|:-----|:---------|
| **Jira Planner** | Confluence Spec 双重可读（人类+Agent），从代码库+Jira历史生成结构化技术规格 |
| **Jira for Slack** | @Jira 从 Slack 对话创建 context-rich 工作项 |
| **Loom Video Prompts** | 屏幕录制 → Agent 可读指令 → Jira 工作项 |
| **Jira Coding Agent** | 内置每个付费 Jira 计划，无需切换 IDE 即可完成修复 |
| **Agent Sessions** | 统一面板查看跨空间/跨仓库的 Agent 运行状态 |
| **Coding Agent Automations** | Automation 规则引擎 → 自动分派例行工作给 Agent |
| **DX AI Cost Management** | Claude/Cursor/Copilot/Jira 统一 AI 开支 → Cost per PR 估算 |

**Teamwork Graph 上下文增益验证**:
- Agent + Teamwork Graph → **44% 更准确** + **48% 更少 Token 消耗**
- PR 周期缩短 + Routine 任务耗时减少（内部基准通过）

**Reddit Deputy CISO 背书**:
> "The bottleneck in AI-native development isn't agent capability, it's coordination at scale."

**增量价值** vs 之前记录:
- 07-19.md 记录了 headline 数字（+65%/+10-15%/+44%/-48%）
