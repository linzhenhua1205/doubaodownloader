## 2. 推理框架之 vLLM v0.24.0 (Jun 29, 2026)

> 发布链接：https://github.com/vllm-project/vllm/releases/tag/v0.24.0
> 贡献：571 commits / 256 contributors（77 位新贡献者）

### 2.1 XQA Decode Kernels (PR#43232, Jul 2 合并)

**里程碑**：将 FlashInfer TRTLLM/XQA decode 路径引入 Hopper (SM90) 上的 vLLM V1 FlashInfer attention。

| 特性 | 说明 |
|:----|:-----|
| 启用路径 | FlashInfer `trtllm_batch_decode_with_kv_cache` XQA decode on SM90 |
| 相位感知 | decode 使用 TRTLLM XQA 路径，prefill 保持 FlashInfer native 路径 |
| KV Cache 适配 | SM90 XQA decode 要求 BF16/FP16 query + FP8 KV cache |
| 分离跟踪 | prefill 和 decode query dtype 分离 |

## 6. 论文专题

### 6.1 SPORK: Self-Speculative Forking 加速 Agentic 推理
> [arXiv:2607.03333](https://arxiv.org/abs/2607.03333) | Jul 3 | cs.DC/cs.AI/cs.LG

| 指标 | 数据 |
|:----|:-----|
| GAIA P95 延迟 | **131.9 → 108.1 秒（-18%）** |
| Tool name 预测精度 | 74.6–99.6%（Qwen3-32B，5 个基准） |
| GPU 空闲时间 | 16–37% of wall time |
| 适用规模 | 4B–32B，密集和 MoE 模型 |

**核心方法**：训练无关的控制器，fork 探测器预测下一个 tool call，与 chain-of-thought 解码重叠执行。

### 6.2 KVpop: 基于未来注意力的学习式 KV 驱逐策略
> [arXiv:2607.05061](https://arxiv.org/abs/2607.05061) | Jul 6 | cs.LG

| 指标 | 数据 |
|:----|:-----|
| 75% KV cache 压缩 | **保留 98%** 全注意力性能 (Qwen3-4B, AIME/HMMT) |
| 88% KV cache 压缩 | **保留 97%** 全注意力性能 (Qwen3-4B) |
| Qwen3-8B | 更强，接近 full teacher 性能 |
| 核心创新 | 延迟记忆打分器（延迟固定步数打分，利用近未来上下文） |

### 6.3 Sangam: 用 AR 栈高效服务扩散 LLM
> [arXiv:2607.04206](https://arxiv.org/abs/2607.04206) | Jul 5 | cs.DC/cs.LG

解决扩散 LLM（dLLM）的双向注意力无法精确 AR KV 缓存的问题，利用近似缓存技术（Fast-dLLM/dKV-Cache）在自回归基础设施上高效服务 dLLM。

### 6.4 ELiTeFormer: FPGA 高效 Transformer
> [arXiv:2607.03652](https://arxiv.org/abs/2607.03652) | Jul 4 | **cs.AR**/cs.AI

首个联合优化注意力 + FFN 的 FPGA Transformer 架构，采用混合线性-三元量化，是 cs.AR 方向的硬件-算法协同设计。

### 6.5 AdaptiveSD: CPU 约束下的运行时自适应投机解码
> [arXiv:2607.03876](https://arxiv.org/abs/2607.03876) | Jul 4 | cs.LG

针对 GGUF 量化模型在 CPU 上推理的运行时自适应投机解码框架，多策略编排避免带宽饱和和不稳定性。

### 6.6 Online Linear Programming for LLM Serving
> [arXiv:2607.03948](https://arxiv.org/abs/2607.03948) | Jul 4 | cs.AI/cs.LG

将 LLM 请求路由形式化为在线线性规划，在 batch-size 和 KV-cache 约束下实现多目标优化路由，提供可解释的决策变量。

### 6.7 Hybrid Block Diffusion (HBD)
> [arXiv:2607.02805](https://arxiv.org/abs/2607.02805) | Jul 2 | cs.LG

通过部分双向性的混合块扩散语言模型，允许每个解码步提交多个 token，从根本减少 KV cache 带宽压力。

## 趋势研判

1. **Agentic 推理成为新热点** — SPORK 论文首次系统解决 agent 工具调用的 GPU 空闲问题（16-37% 浪费），方法可叠加 token 级投机解码
2. **KV Cache 路线分化加速** — 压缩/KVpop/学习式 vs 量化/GSRQ vs 投机/Lynx vs 分层/SeKV，每条路线都在 7 月有新进展
3. **Blackwell (SM100/SM120) 生态已到临界点** — SGLang KDA CuteDSL(1.52×)、TRT-LLM gen attention 默认化、vLLM SM120 DSV4 支持
4. **SGLang 版本发布频率第一** — v0.5.13(Jun13) → v0.5.14(Jun26)，每 13 天一版，vLLM 每 14 天一版
5. **Megatron Core 持续进化** — A2A 反向传播重叠和 M-FSDP 精密感知优化器是训练框架的重要改进
