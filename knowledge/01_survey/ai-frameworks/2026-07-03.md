**核心性能数据**

| 优化项 | 加速效果 | 适用场景 |
|:-------|:---------|:---------|
| CUTLASS FP8 mm odd-M via swap_ab | **180–290%** kernel speedup | 非对齐维度矩阵乘法 |

| CPU ASR preprocessing multi-threading | **2.5×** faster | 语音输入预处理 |

**关键新特性**
- **MiniMax-M3** 全链条支持（BF16/FP8/MXFP4/FP8 sparse GQA + AMD gfx950 tuning）
- **DeepSeek-V4 第四轮成熟化**：FlashInfer sparse index cache、SM120 支持、TEP=16 block-FP8

- **Rust 前端成熟**：API-key auth、CORS、14 个新端点

**安全强化**：协调安全批次（decompression bomb DoS、spec-dec token reinjection、regex timeout）

> 发布链接：https://github.com/sgl-project/sglang/releases/tag/v0.5.14

**核心性能数据**

| 优化项 | 加速效果 | 说明 |
|:-------|:---------|:-----|
| DeepSeek-V4 on GB300 | **5×** higher throughput at same interactivity | NVIDIA GB300 首发 |
| KDA CuteDSL prefill on SM100 (Blackwell) | **1.08–1.52×** vs Triton path | 可重用 scratch workspace |

| Ideogram 4 progressive resolution upsampling | **up to 1.56×** speedup | GPU DCT upsampling |

**关键新特性**
- **新模型支持**（7个）：GLM-5.2、LiquidAI LFM2.5、Kimi-K2.7-Code、Poolside Laguna-M.1、DiffusionGemma、Zyphra ZAYA1、MiMo-V2-ASR

- **Waterfill**：shared-expert dispatch 负载均衡
- **NVFP4 MoE for DeepSeek-V4** on Blackwell
- **MSCCL++ 集成** + MNNVL allreduce fusion
- **HiCache for hybrid models by default**（SWA/Mamba）
- **AMD**：breakable CUDA graph on ROCm/HIP
- **DeepSeek-V4 decode 优化**：MLA q-heads pad to 64 → FlashMLA head64 kernel (~2× cheaper)

## 2. 训练框架

### 2.1 PyTorch 2.12.0 / 2.12.1

> 发布链接：https://github.com/pytorch/pytorch/releases/tag/v2.12.0 | 2.12.1 bugfix

**重大变化**

| 变化点 | 描述 |
|:-------|:-----|
| 最小 CUDA 版本 | **CUDA 12.6**（源码编译），不再支持 < 12.6 |
| 默认 CUDA | **CUDA 13.0**（cu128 二进制已移除） |
| C++ 标准 | **C++20 最低要求** |
| Triton | 升级至 **3.7.0 → 3.7.1**（bugfix） |
| NCCL | 升级至 **2.29.7** |
| cuDNN | 升级至 **9.20.0.48** |

**核心新特性**
- **`torch.accelerator.Graph`** — 统一 CUDA/XPU/out-of-tree 的 graph capture & replay API
- **MX 量化导出** — `torch.export.save` 支持 Microscaling (MXFP4/MXFP8) 格式
- **`torch.cond` in CUDA Graphs** — 控制流可在 CUDA Graph 内捕获重放
- **Adagrad fused=True** — 与 Adam/AdamW/SGD 统一单核优化器
- **DDP `batched_grad_copy`** — 减少 per-parameter kernel launch 到 2 kernels/bucket
- **functional collectives API 自动处理 non-contiguous 输入**

**Inductor 亮点**
- 用户自定义流支持 `torch.compile`
- 异步 activation offloading (`ao::offload`/`ao::reload`/`ao::wait`)
- 用户 Triton kernel unary epilogue fusion（parse AST + inline into `tl.store`）
- `max_autotune` 扩展到 combo kernels
- XPU CUTLASS GEMM codegen

## 4. KV Cache 优化（arXiv 新论文）

### 4.1 RaBitQCache — 随机旋转二值量化 (ICML 26)

> arXiv:2606.31519 | Submitted Jun 30

**核心思路**：随机旋转二值量化 + binary-INT4 算术近似 attention 权重，无偏估计器 + 可证明误差界，自适应 Top-p 逐 token 动态调整预算。

### 4.2 HMA-Serve / MemHA — 异构内存 LLM 服务

> arXiv:2606.29986 | Submitted Jun 29

**核心思路**：GDDR 加速器做 Prefill + HBM GPU 做 Decode，跨厂商异构。

**性能数据**

| 指标 | 提升幅度 |
|:-----|:---------|
| Goodput vs memory-homogeneous | **up to 3.2×** |
| Goodput-per-dollar | **up to 4.8×** |
| 量化策略 | phase-wise：prefill 用 vendor-native 低精度、decode 用 BF16 |

### 4.3 MOCAP — Wafer-Scale Prefill Pipelining

> arXiv:2606.22968 | Submitted Jun 22 | APPT 2026

**核心思路**：面向晶圆级芯片的存储编排分块流水线。

**性能数据**

| 指标 | vs GPipe |
|:-----|:---------|
| E2E latency | **-76.4%** |
| Throughput | **3.24×** |
| Max sequence length vs Terapipe | **up to 1.31×** |

### 4.4 ViCoStream — Streaming VideoLLM >100 FPS

> arXiv:2606.19849 | Submitted Jun 18

**性能数据**：Qwen2.5-VL-3B/7B-Instruct on single A100 — **134 FPS video throughput** + <50ms TTFT

### 4.5 Recency/Frequency Adaptive KV Caching

> arXiv:2606.21238 | ICML 2026 AdaptFM Workshop | Submitted Jun 19

**核心思路**：在 recency 和 frequency 间动态分配 KV cache 空间。

**性能数据**

| 指标 | vs vLLM LRU |
|:-----|:------------|
| KV cache hit rate | **+10.8%** |
| TTFT 减少（synthetic QA） | **up to 12.6%** |
| TTFT 减少（real-world conversation） | **2.0%** |

### 4.6 MemHA — Disaggregated across Memory-heterogeneous Accelerators

同上 4.2，细化 phase-wise quantization + compute-transfer pipeline + deferred dequantization。

### 4.7 Multi-Block Diffusion LMs (MBD-LMs)

> arXiv:2606.29215 | Submitted Jun 28

**性能数据**：MBD-LLaDA2-Mini TPF 从 3.47 提升至 **6.19** (+79%)；MBD-LLaDA2-Mini-DMax 达 **TPF 9.34**

## 5. 趋势研判

1. **推理框架版本竞赛白热化** — vLLM 24.0 / SGLang 0.5.14 / TRT-LLM rc20 在 4 天内密集发布，三者都深度绑定 DeepSeek-V4 + Blackwell
2. **TRT-LLM 去 TRT 化完成倒计时** — 下个版本移除 TensorRT 后端，全面 PyTorch 原生
3. **MoE 负载均衡范式进化** — 从 heuristic → Waterfill → LPLB (linear programming) → GVR-TopK
4. **KV Cache 多维突破** — 量化(RaBitQCache)、异构(MemHA)、调度(Recency/Freq)、压缩(MBD-LM)、晶圆级(MOCAP)
5. **编译器三线并进** — Triton RDNA4 成熟 + WS 强化、PyTorch Inductor 流支持、CUTLASS FP8 优化
6. **训练框架「推理侧对齐」** — Megatron Chat API 对齐 vLLM、DeepSpeed AutoEP + Muon + AutoSP 多模态
