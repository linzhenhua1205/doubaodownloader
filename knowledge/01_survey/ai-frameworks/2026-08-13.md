## 本期发现 (12条)

### 框架与系统

- **FlashBoot：SGLang 机架级权重加载子系统**（[arXiv:2608.08482](https://arxiv.org/abs/2608.08482)，08-09）: MoE 模型在弹性部署中权重加载成为延迟预算显著部分，NVL72 上现有 loader 用不满链路带宽；三大结构性损失——权重内存碎片化（数万 per-tensor 对象致传输远低于链路带宽）、跨节点复制被 NCCL communicator 初始化门控（10-110s 才动第一个字节）、GPU→GPU clone 串行难扩展到并发多节点；FlashBoot 基于 SGLang 提出 FabricArena（连续、可导出、跨节点可寻址张量内存布局）+ FlashLoad（CPU 单批零拷贝）+ FlashClone（远程映射免 NCCL 初始化）；NVL72 + DeepSeek-V4-Pro/Flash 实测：FlashClone 映射远程权重 ~10ms（vs NCCL 10-110s）、单 clone ≥700GB/s；单节点权重加载 20.1s→0.4s（50x）、机架级并发 87s→0.32s（>270x）。URL: https://arxiv.org/abs/2608.08482 ⭐

- **OasisKV：解码期 KV 越 HBM 稀疏预取**（[arXiv:2608.08097](https://arxiv.org/abs/2608.08097)，08-08）: 长上下文/长推理负载下 KV cache 主导显存占用与访存，HBM 容量成为批大小与吞吐瓶颈；OasisKV 基于 vLLM 实现"记忆中心"设计——解码期注意力天然稀疏，仅把最相关 token 的 KV 留在 HBM，用推测解码（SD）的 lookahead token 提前准确预测未来重要 token，后台 attention pipeline 识别重要 KV 块并从高容量层（host/远端内存）预取；2048-token KV 预算下精度距 full attention 仅 0.7 点；推理负载 1.69x（0.1 点精度损失）、多 GPU 长上下文最高 2.1x；P/D 解聚下约 2x 稠密吞吐、每请求少 6.5-9.7x KV、decode 节点 host 内存少 2.2-2.6x。URL: https://arxiv.org/abs/2608.08097 ⭐

- **CDB：循环语言模型的连续深度批处理**（[arXiv:2608.09444](https://arxiv.org/abs/2608.09444)，08-10）: 循环 LM（looped LM）承诺深度自适应推理——共享层块按 token 难度循环不同次数，但打破标准批处理（同批 token 所需 loop 数不同、无统一前向传播）；vLLM 等框架按 token 级调度无法处理（token 需在前向传播中途离批）；CDB 按单个 loop 迭代粒度调度，边界阶段（token embedding/LM head）与循环步分优先级队列、提前一步做退出决策、调度与 GPU 计算重叠；Ouro 1.4B/Huginn 3.5B 上实现自适应深度理论上限的 99%，动态负载下离线吞吐 +1.5-1.9x、归一化延迟 -45~90%。URL: https://arxiv.org/abs/2608.09444 ⭐

- **KVGov：多租户 KV cache 时序侧信道防护**（[arXiv:2608.09225](https://arxiv.org/abs/2608.09225)，08-10）: 多租户 LLM 推理共享前缀缓存产生时序侧信道——恶意租户可借缓存命中延迟探测重建他人私有提示；已发布攻击 PROMPTPEEK/EarlyBird/InputSnatch 对未防护 vLLM/SGLang 最高 100% 成功率；KVGov 治理层用每主体盐 sigma_p=HMAC_K(secret, principal_id) 播种块哈希链，使缓存键跨主体密码学不相交；消融（N=1000）证明盐是必要充分组件；ORIGAMI Stackelberg 水填充审计调度器在租户异构（Gini 0.63）下把攻击者期望效用 -12.6%；Qwen2.5-7B + vLLM 0.26.0 + A100 实测冷/热 TTFT 比 0.22 证实信道在生产规模可利用；在提示分歧边界注入盐而非链根可保留约 93% 前缀缓存收益且无跨主体信号。URL: https://arxiv.org/abs/2608.09225 ⭐

### KV 缓存优化

- **KVDiagnosis：KV 压缩诊断基准**（[arXiv:2608.09412](https://arxiv.org/abs/2608.09412)，08-10）: 聚合任务分数无法揭示哪些正确执行失败及原因；KVDiagnosis 提供诊断数据集+基准：①25 方法 taxonomy 归为 5 个机制家族、链接 8 个已验证实现；②每方法设置按 per-source FullCache 对照选择 C-to-W（FullCache 正确/压缩错误）行，避免压缩器互相定义测试集；③统一记录格式关联输出与 cache/likelihood/attention/decoding 测量；Qwen3-8B 上 4 个证据感知工作负载产生 59 800 次受支持压缩运行（2600 源、12 520 C-to-W 行）；固定诊断规则下 63.2% 覆盖率低或部分；10 项诊断区分失败/成功压缩（分层 AUROC 0.684-0.871）；96 个可复现低 EAR 失败中受控 4x 证据注意力增强修复 29.2%（vs 6.3% 假干预、3.3% 对照退化）。URL: https://arxiv.org/abs/2608.09412 ⭐

- **SPECTRA：谱变换编码突破 KV 2-bit 悬崖**（[arXiv:2608.07915](https://arxiv.org/abs/2608.07915)，08-08）: KV 量化几乎全部卡在每值近 2 bit——2-bit 悬崖：4 电平太少装不下离群值重的缓存，少数大值耗尽电平、其余坍缩为噪声；SPECTRA 先做训练无关旋转把缓存重编码进自身统计定义的坐标系（消除通道强相关），少量通道承载几乎全部信息，预算集中到这些通道；Llama-3.1-8B/Qwen2.5-7B 长上下文基准上 4x 近无损、8x 仍竞争（均匀量化已崩）、最高 12x，把可用压缩推过 2-bit 悬崖，同 GPU 支持更长上下文更大批。URL: https://arxiv.org/abs/2608.07915 ⭐

- **DistillCache：RL 驱动的 KV 驱逐策略**（[arXiv:2608.08878](https://arxiv.org/abs/2608.08878)，08-09）: H2O/SnapKV 等启发式依赖静态注意力/位置信号，抓不住 token 的未来预测影响力；DistillCache 把驱逐建模为序列决策问题——轻量策略网络用内部模型信号（注意力统计、值范数、熵、位置）以 REINFORCE 训练，奖励为逐步 KL 散度以保持全缓存输出分布；Mistral-7B-Instruct-v0.3 上 25% 缓存预算保留 LongBench 94.2% 精度（超 H2O/SnapKV 最高 2.7 点、超 ForesightKV/RLKV 最高 1.4 点），吞吐最高 2.1x。URL: https://arxiv.org/abs/2608.08878 ⭐

- **RippleKV：跨层 KV 预算分配的扰动传播法**（[arXiv:2608.08684](https://arxiv.org/abs/2608.08684)，08-09）: 现有跨层分配用层深度/注意力统计/表征变化作代理，不测各层扰动如何传播到输出，敏感层欠配、容忍层过配；RippleKV 向每层 value cache 注入范数自适应扰动、在小校准集上测模型输出 KL 散度，得模型专属敏感性剖面（不必随深度单调）；按敏感性归一化+指数映射转层预算乘子，比例参数控制敏感/容忍层分配差距；LongBench 匹配预算下平均性能居同类方法之首。URL: https://arxiv.org/abs/2608.08684

- **CommitKV：Agent 多轮 KV 生命周期压缩**（[arXiv:2608.07855](https://arxiv.org/abs/2608.07855)，08-08）: ReAct 类 agent 轨迹（推理/工具调用/观察）持续累积致 KV 增长；现有驱逐以低注意力驱逐状态，但"当前轮低注意力"不等于"未来无关"——快照式驱逐无法区分暂时休眠与已完成角色的信息；CommitKV 以 commit transitions 识别 KV 生命周期：工具调用提交前/观察并入后对比各候选页删除效应，区分休眠页与高→低完成候选；贪心联合检验只退休联合效应有界的候选；降低 agent 内存、加速端到端推理、精度优于现有压缩法。URL: https://arxiv.org/abs/2608.07855

### Agentic/RL 调度

- **MISA-T：混合 RL rollout 调度**（[arXiv:2608.11152](https://arxiv.org/abs/2608.11152)，08-11）: RLVR/RLHF/agentic rollout 共享异步推理服务时序列结构、交互模式、KV 驻留时间差异显著，路由层须在不扭曲训练器负载配比下处理异构；MISA-T 结合自适应会话准入、负载感知 KV 容量分配、驻留时间感知 KV 记账；Step3.7/Qwen3.6-35B-A3B rollout-only 消融中较 sweep-tuned vLLM Router 吞吐 +53.3%/+43.6% 且保持高前缀命中；50 迭代匹配实验吞吐 +35.6%、平均迭代时间 -22.8%、任务分数相当。URL: https://arxiv.org/abs/2608.11152 ⭐

- **TideRL：就绪感知的 Agentic RL 弹性调度**（[arXiv:2608.10402](https://arxiv.org/abs/2608.10402)，08-11）: 多轮 agentic rollout 反复暂停等外部环境、恢复时上下文增长、完成时间高度可变，RL 训练 goodput 比裸 GPU 占用率更重要；TideRL 三件套——连续任务批处理（CTB）保留有用 rollout 状态、资源感知 Ref-Actor 流水（RA²P）按就绪积压/到达间隔选择解耦流式或共置聚合、弹性资源缩放（ERS）用同一就绪信号在 rollout/训练间移 rank；文本+多模态 agentic 负载上 goodput 最高 5.6x（vs 同步基线）/33%（vs 异步），KV cache 命中率 1.58x、单步训练时间 -44.3%、总等待 -77.6%。URL: https://arxiv.org/abs/2608.10402 ⭐

### VLM/多模态

- **SIEVE：跨模态残差引导的 VLM 视觉 token 剪枝**（[arXiv:2608.10489](https://arxiv.org/abs/2608.10489)，08-11）: 视觉 token 大量推高 VLM 推理成本；现有剪枝用相似度引导（pairwise 文本-视觉/视觉-视觉相关性）只抓局部层信号；SIEVE 发现关键现象——LLM 层加深时文本 token 经自注意力持续聚合视觉信息，深层更多视觉 token 可被文本子空间近似解释；提出 Cross Modal Absorption（CMA）几何量化该吸收 + Cross Modal Residual（CMR）用 Tikhonov 正则最小二乘把视觉 token 投影到文本子空间、以重建残差量化不可解释信息；结合 CMR+文本注意力相关性+残差空间多样性，LLaVA-NeXT-7B 只留 11.1% 视觉 token 保留 97.5% 性能、prefill 3.62x、端到端 2.49x、KV cache -6.02x。URL: https://arxiv.org/abs/2608.10489 ⭐

- **Gated VLA-Cache：神经内省门控的 VLA KV 复用**（[arXiv:2608.10824](https://arxiv.org/abs/2608.10824)，08-11，IROS 2026）: VLA 模型在实时控制中反复重算相邻帧几乎不变的视觉 token KV；VLA-Cache 复用静态 patch 的 KV 但只靠观察空间启发式、不管模型自身不确定性；Gated VLA-Cache 训练无关扩展——监视解码期 top-2 动作 token 的 logit margin（零成本置信信号），低于阈值即失效缓存触发全重算；LIBERO 四套件 + OpenVLA/OpenVLA-OFT 上盲缓存有害时恢复超 100% 丢失精度、保留 80% 计算节省。URL: https://arxiv.org/abs/2608.10824

## 趋势观察

- **推理框架进入"系统级重构"密集期**：FlashBoot（权重加载）、OasisKV（KV 越 HBM 预取）、CDB（循环架构调度）三者同日窗口出现且都直接构建在 vLLM/SGLang 上——框架优化从 kernel/attention 层上移到装载、调度、内存层级管理，呼应 vLLM v0.27.0 的 Model Runner V2 + 容错框架 + 解聚路由系统级动作。
- **KV 缓存研究"可诊断化/可治理化"**：KVDiagnosis（首个诊断基准：25 方法 taxonomy + 失败根因归因）与 KVGov（侧信道安全治理）标志 KV 优化从"更快更省"走向"可解释、可审计、安全"，与 08-11 期 GraceKV 全局分配、08-10 期 SPECTRA 谱变换共同构成 KV 研究的三阶演进（局部规则→全局分配→诊断/治理）。
- **Agentic/RL 负载成为调度研究主战场**：MISA-T（混合 rollout 路由）与 TideRL（就绪感知弹性调度）聚焦同一矛盾——agentic/RL rollout 的异构序列结构与 KV 驻留差异使传统 serving 调度失效；两者都强调"保持训练器负载配比"与"KV 命中率"双目标，与 08-11 期 Agora 的 agentic 架构观察形成训练侧呼应。
- **2-bit 悬崖成 KV 量化新里程碑**：SPECTRA 明确把"2-bit cliff"定义为离群值耗尽电平的问题并以谱旋转+非均匀比特分配突破至 12x，叠加 08-11 期 CubicQuant 参数化非均匀码本——低比特量化竞争从"位宽"转向"表示坐标系/码本结构"。
