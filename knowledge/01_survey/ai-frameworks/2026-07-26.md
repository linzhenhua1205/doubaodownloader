## 1. Blink — CPU-Free LLM Inference via SmartNIC + GPU

> **来源**: arXiv:2604.07609 · 2026-04-08 · ISCA

- 移除 host CPU 在稳态推理路径上，将请求处理卸载至 SmartNIC
- SmartNIC 通过 RDMA 将输入直接送入 GPU 显存
- GPU kernel 常驻执行 batching/scheduling/KV-cache 管理
- 相比 TRT-LLM/vLLM/SGLang: P99 TTFT 降低最多 8.47×, P99 TPOT 降低 3.40×, decode 吞吐提升 2.1×, 每 token 能耗降低 48.6%
- CPU 干扰下性能稳定，现有系统退化最多 2 个数量级

## 2. Strata — Hierarchical Context Caching

> **来源**: arXiv:2508.18572 · 2025-08 · 生产部署

- 分层 KV cache 架构：GPU-assisted I/O 解决 KV cache 碎片化
- Cache-aware 请求调度：将 I/O 延迟与计算重叠
- 相比 vLLM + LMCache: TTFT 降低 5×；相比 TRT-LLM: 3.75×
- 不牺牲短上下文性能

## 3. DeepSeek-V4 发布（archived）

> **来源**: arXiv:2606.19348 · 2026-06

- V4-Pro: 1.6T params (49B active), V4-Flash: 284B (13B active)
- 百万 token 上下文，CSA + HCA 混合注意力
- 1M 上下文下 FLOPs 仅 V3.2 的 27%，KV cache 仅 10%

**趋势判断**: CPU-free 推理架构 (Blink) 和分层 KV cache (Strata) 代表推理框架的两个主要演进方向。MoE 推理继续成为重点优化领域。
