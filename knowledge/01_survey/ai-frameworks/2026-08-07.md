## 一、推理服务系统与后端（2篇）

- **LLM Serving in the Wild: An Empirical Study of Frameworks, Methods, and System Designs**（[arXiv:2608.03036](https://arxiv.org/abs/2608.03036)，08-04）⭐
- **要点**: 首个对 LLM serving 框架在生产软件系统中采用情况的实证研究。识别并分析 5 个 LLM 专用框架：vLLM、SGLang、TensorRT-LLM、LMDeploy、FlashInfer，考察它们在开源软件系统中的实际使用方式（框架选择、serving 方法、系统设计模式），填补"学界提出大量推理优化技术但实践采用情况未知"的空白。
- **意义**: 首次以软件工程视角量化 serving 框架的真实落地格局——哪些框架成为主流、哪些方法被实际采用、系统集成模式如何，直接回应本追踪专题"框架生态"主线，为框架选型提供实证依据。

- **What We Observe as LLM Behavior Can Be a Side-effect of Inference Backend**（[arXiv:2608.04714](https://arxiv.org/abs/2608.04714)，08-05）⭐
- **要点**: 基准分数被当作模型属性报告，但产生分数的推理框架（HuggingFace/vLLM/Ollama）被视为无影响因子，其名称与版本几乎从不披露。全交叉实验（3 个指令微调模型 × 5 个推理框架 × 6 个基准 × 4 种生成模式）发现后端是不可忽略的变量——即使在贪婪解码、无采样噪声条件下，更换后端也会显著改变模型输出。
- **量化数据**: 3 模型 × 5 框架 × 6 基准 × 4 模式全交叉；框架选择对基准分数影响非平凡（非采样噪声可解释），生成超参数（温度/top-p）与后端的交互进一步放大分数差异。
- **意义**: 与 08-04 归档的 TV-distance 论文（2607.19510，同一模型不同引擎分布距离可计算）形成姊妹篇——后端差异从"可度量"走向"系统性实证"，强烈暗示 benchmark 报告必须披露推理后端版本，否则跨论文分数不可比；对 vLLM/SGLang 引擎切换验证有直接方法论价值。

## 二、KV Cache 压缩与量化（3篇）

- **AnchorKV: Anchor-Residual KV Cache Compression**（[arXiv:2608.02901](https://arxiv.org/abs/2608.02901)，08-03 提交/本期补录）
- **要点**: 驱逐法永久丢弃 token（被丢弃 token 若后续关键则性能退化），量化法保留全部 token 但压缩率有限。AnchorKV 用"锚点-残差"表示：小集合锚点精确存储，其余每个 token 用其最相似锚点表达，仅对模型输出影响最大的近似做细化（refinement）。
- **量化数据**: 缓存压缩 **20×** 且不丢弃任何 token；多基准一致优于同压缩率下的驱逐/量化方法。
- **意义**: "驱逐 vs 量化"两派之外第三条路——无损语义保留 + 高压缩，与 08-05 RestoreKV（恢复式驱逐）共同标志 KV 治理从"二选一"走向"混合表示"。

- **Spend Bits Where Queries Look: KV Cache Vector Quantization with Attention-Preserving Transforms**（[arXiv:2608.04074](https://arxiv.org/abs/2608.04074)，08-04）
- **要点**: 长上下文解码每步读取 KV cache，加载时间超过注意力计算时间，吞吐带宽受限。针对 2bit/元素压缩，现有最竞争方法依赖正交变换，但要么数据无关（data-oblivious）、要么用查询统计却不从失真准则推导变换。本文提出注意力保持（attention-preserving）的变换推导：按"查询关注处"分配量化位数，从失真准则出发设计变换。
- **量化数据**: 2bit/元素固定位数预算；相比随机/Hadamard 旋转类方法提升重建保真与下游精度。
- **意义**: 把"位预算分配"与"注意力分布"对齐——比特花在查询实际读取的位置，是 KV 量化从统计优化走向查询感知的第二代方法。

- **Output-Aware Rotation for INT2 KV-Cache Quantization**（[arXiv:2608.02691](https://arxiv.org/abs/2608.02691)，08-03 提交/本期补录）
- **要点**: 现有旋转类 INT2 方法在完整注意力读出前优化缓存统计或代理误差，而模型实际受经注意力与输出投影 W_O 传播的误差影响。OptR 最小化 post-W_O 注意力输出误差：将误差分解为 key 诱发与 value 诱发两项，逐头学习正交校正。
- **意义**: 把量化目标从"缓存统计保真"前移到"端到端输出保真"——与 2608.04074 同为"以最终输出为目标"的量化范式转向，INT2 极低位量化实用性提升。

## 三、KV Cache 迁移与检索（3篇）

- **Cross-Model KV Cache Transfer in LLM Families: A Closed-Form Linear Mapping for Prefill Reuse**（[arXiv:2608.03893](https://arxiv.org/abs/2608.03893)，08-04）
- **要点**: 生产部署常在同族不同规模模型间切换（成本-质量级联、对话中途切换、路由），每次切换接收方须从头重付 prefill 成本。提出跨模型 KV 迁移：接收方复用源模型 KV cache 跳过 prefill。发现匹配 KV 对（源/目标共享 KV 头数与头维度）上跨模型 KV 存在显著线性结构。
- **量化数据**: Qwen3 14B→32B 上，单源层解释目标 keys 方差的 **56%**、values 32%；多层源提升至 **79%/65%**；闭式 ridge 映射实现 prefill 复用。
- **意义**: 级联/路由场景 prefill 复用从"同模型前缀缓存"扩展到"跨模型线性映射"，对成本-质量级联 serving 的延迟/算力收益显著。

- **SAKI: Score-Aware Low-Rank Key Indexing for Long-Context KV Retrieval**（[arXiv:2608.03228](https://arxiv.org/abs/2608.03228)，08-04）
- **要点**: 现有低秩 KV 方法或保模型权重、或保 key 方差，都不直接反映推理时使用的注意力分数。推导 rank r key 压缩导致的期望注意力分数失真，证明其等价于协方差加权低秩目标；边际条件下控制失真也提升 top-k 召回。最优解为协方差加权 query-key 算子 SVD 的闭式非对称分解。
- **量化数据**: LLaMA 3.1 8B、Qwen 2.5 7B 等多模型验证；训练免费（training-free）的注意力分数保真索引优于 key 重建质量导向方法。
- **意义**: KV 检索索引目标从"重建保真"改为"注意力分数保真"——直接优化推理时真正被使用的量，与 SAKI 同批的 AnchorKV 形成压缩-检索双线呼应。

- **When Does Latent Communication Pay? A Causal Audit of Relayed KV Caches in Multi-Agent LLMs**（[arXiv:2608.04893](https://arxiv.org/abs/2608.04893)，08-05）
- **要点**: 多 Agent LLM 系统中继 KV cache 而非文本，并把收益归因于"潜在思想"交换——该归因是"中继哪个示例的 cache"的因果主张。用失配示例/置零/矩匹配随机替代进行因果审计，分两种条件：接收方是否需要发送方私有信息。
- **量化数据**: 需要私有信息时，正确中继命中率 **100%** vs 与答案无关中继仅 23-25%；跨 3 个模型家族、5 个 checkpoint、文档 QA 表面复现；不需要私有信息时（预注册条件）中继价值显著下降。
- **意义**: 首次对"KV 中继=潜在思想交换"做严格因果审计——区分"有用的是哪个 cache"而非"有 cache 就有效"，为多 Agent 通信设计的 KV 中继机制提供方法论校准。

## 四、投机解码与注意力优化（2篇）

- **AcceptMoE: Commitment-Weighted Self-Sizing Verifier Expert Sets for Efficient MoE Speculative Decoding**（[arXiv:2608.02989](https://arxiv.org/abs/2608.02989)，08-04）
- **要点**: MoE 投机解码并行验证整棵草稿树时，会激活所有树节点选中的专家并集（实际只有少数节点被接受）。token 数、激活专家并集大小、专家权重流量是三种独立成本度量——降低 token 负载不必然等比缩小专家并集，offloading 下传输流量还依赖 cache 驻留。AcceptMoE 是验证器侧专家选择器：组合目标路由器分数与离线估计的 commitment 概率，自适应选择验证专家集大小。
- **意义**: 把 MoE 投机解码的成本模型从"token 数"拆为三维（token/专家并集/权重流量），验证器自选尺寸——对 MoE 大模型（如 DeepSeek 类）投机解码的算力-带宽权衡有新指导。

- **BinaryPC: Training-Free Hashing-Based Attention via Binary Principal Components**（[arXiv:2608.04405](https://arxiv.org/abs/2608.04405)，08-05）
- **要点**: 现有稀疏注意力减少计算但精度退化/需训练/哈希昂贵。BinaryPC 是训练免费、数据感知的哈希稀疏注意力：对 d 维 key 计算二值主成分，构造紧凑二值哈希码与哈希函数。
- **意义**: 哈希注意力从"昂贵随机投影"走向"数据感知二值 PCA"，在长上下文解码的 KV 稀疏访问上与 KV 压缩方法形成互补路径（稀疏 vs 压缩双轨）。

## 五、综合观察

- **本期主线: KV 治理从"选/压二选一"走向"混合表示 + 输出目标对齐"**——AnchorKV（锚点-残差 20×）、2608.04074（查询感知位分配）、OptR（输出感知旋转）三篇同日/相邻日出现，共识指向"以最终输出保真为目标、按注意力分布分配资源"，而非均匀统计优化。
- **跨模型 KV 复用成为新热点**: Cross-Model KV Transfer 证明同族模型间 KV 线性结构显著（56-79% 方差可解释），级联 serving 的 prefill 复用从"同模型前缀"扩展到"跨模型映射"——对成本-质量级联路由场景是直接收益。
- **后端可复现性危机升级**: 2608.04714 以全交叉实证证明推理后端（HF/vLLM/Ollama）是基准分数的非平凡变量——与 08-04 TV-distance 论文呼应，LLM 基准报告"未披露后端版本即不可复现"正从观点走向实证共识。
- **08-03 提交两篇补录**: AnchorKV（2608.02901）与 OptR（2608.02691）为 08-03 提交但 08-05 窗口未捕获，本期补录——说明 40 篇扫描窗口仍偶有遗漏，后续保持 max_results≥40 继续防漏。
