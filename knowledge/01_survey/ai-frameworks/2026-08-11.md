## 本期发现 (10条)

### 框架与系统

- **GraceKV：KV 缓存压缩的全局资源分配**（[arXiv:2608.07001](https://arxiv.org/abs/2608.07001)，08-07）: 现有 KV 压缩依赖预定义固定规则（token 驱逐或合并），缓存资源无法跨层/头/上下文槽流动，也无法联合分配局部分辨率与信息覆盖；GraceKV 把压缩形式化为固定预算下的全局资源分配问题——每个 层-KV头-槽 组合为原子单元并构建原型树（叶子=token 级 KV 项，内部节点=用单一原型压缩子树 KV 空间），树根扩展信息覆盖、节点分裂提升局部分辨率，所有候选动作全局竞争共享预算；无需训练且全流程在 GPU 上完成；32 组设置中 24 组排名第一，128 倍压缩率下保持鲁棒。URL: https://arxiv.org/abs/2608.07001 ⭐

- **Autonomy-of-Heads (AoH)：冻结 QK 几何的数据无关稀疏注意力**（[arXiv:2608.06849](https://arxiv.org/abs/2608.06849)，08-07）: 现有稀疏注意力/KV 压缩依据运行时注意力分数、观察窗口、校准提示或学习门控决定保留哪些 token/头，头部诊断输入依赖、部署成本高；AoH 从 QK 投影的谱几何识别 retrieval/streaming 头——定义核注意力算子 M_h=W_K^h^T·W_Q^h，用有效秩度量头部功能（谱集中=少量主导 QK 匹配方向→retrieval 头；谱弥散=无主导全局匹配方向→streaming 头），并推导 d_head 维高效计算避免构造 d_model×d_model 全矩阵；50% 稀疏度下平均保留 Full Attention 性能的 96.5%，prefill/decode 延迟最高降 41.4%/66.0%，256K tokens 时 KV 缓存内存 -50%。URL: https://arxiv.org/abs/2608.06849 ⭐

- **HeteroPanacea：Agentic 推理的解聚仿真框架**（[arXiv:2608.03741](https://arxiv.org/abs/2608.03741)，08-04）: Agentic 推理主导推理负载后，prefill/decode 行为差异显著、需求不同算力与访存带宽，单一同构 GPU 系统难以支撑，产业转向异构解聚（如 Vera-Rubin 平台 GPU+Groq LPU）；HeteroPanacea 提供跨三轴的解聚服务系统级仿真：①解聚量化 ②自动化设备内/跨设备并行调度 ③PDAF（prefill-decode-attention-FFN）NPU 架构异构；确认 Prefill-Decode 解聚收益（较传统 serving 吞吐最高 +75%），并证明 4 路 Prefill-Decode-Attention-FFN 解聚在不同模型上吞吐提升最一致。URL: https://arxiv.org/abs/2608.03741 ⭐

- **Agentic AI 工作负载的架构启示（Agora 原型）**（[arXiv:2608.04458](https://arxiv.org/abs/2608.04458)，08-05）: 首个 agentic 工作负载架构刻画——微软 Azure 生产研究 + 开源框架对照；agentic 执行碎片化异构：请求扩展为 LLM 推理/工具调用/编排决策的工作流并反复跨越 CPU-GPU 边界，编排与工具跑在 host 上使 CPU 处于关键路径，负载随时间呈低均值+突发尖峰；暴露传统均匀服务器三大架构错配：碎片化执行闲置 CPU/GPU 容量、软件角色异构致同质 CPU 配置低效、多 agent 共享核降低微架构局部性；Agora 原型动态收割空闲 CPU 核做吞吐工作（保护 agent 尾延迟）、超订 GPU 内存+预取下一 agent 状态隐藏换入延迟、按角色池化核+亲和调度。URL: https://arxiv.org/abs/2608.04458 ⭐

- **RAC：拆分 LLM 推理的参考感知激活压缩**（[arXiv:2608.04991](https://arxiv.org/abs/2608.04991)，08-05）: 拆分推理（头/尾/工具本地、中间层云端）解决隐私与硬件成本的折中，但 local-cloud-local 路径每次调用传输边界隐状态成通信瓶颈；RAC 参考感知编解码器——prefill 上行检索精确 token 历史片段、同轮 prefill 下行复用重建上行状态、用轻量因果预测器生成边界特定解码参考；配分组仿射对齐+校准残差量化；三模型九条 模型-链路 对上 TTFT/TPOT 加速比 1.24-2.72x/1.01-2.79x，12 项非困惑度任务分数变化 -0.40~+2.50 点。URL: https://arxiv.org/abs/2608.04991

### 推理优化与硬件

- **CubicQuant：1-8 位参数化非均匀码本量化**（[arXiv:2608.06763](https://arxiv.org/abs/2608.06763)，08-07）: 权重量化需在自适应重建电平与 GPU 高效执行的规则表示间平衡（均匀整数=线性网格受限、低比特浮点=固定指数-尾数结构、学习码本=解码不规则+元数据开销）；CubicQuant 提出参数化非均匀标量格式——单调三次曲线（两个形状参数+一个缩放）把均匀间隔幅度码映射到非均匀电平，保持稠密整数码流，家族覆盖 1-8 位、对称均匀整数量化是其精确特例；W4 在 G=128 有限组下相对最优裁剪 4-bit 均匀整数 RMSE 降 3.90%(Uniform)/13.49%(Gaussian)/28.14%(Laplace)；H200 初步测量显示模型 dtype 执行在窄 GEMV 更快、Dynamic A8 随行数增长更优（负载相关交叉点）。URL: https://arxiv.org/abs/2608.06763 ⭐

- **AdaMX：异构感知的 Microscaling 低比特推理**（[arXiv:2608.03867](https://arxiv.org/abs/2608.03867)，08-04）: MX 已成低比特推理标准但 MXFP4 仍显著掉精度——现有 MX 格式跨块固定元素格式或精度恢复方案，只捕获有限量化异构性（跨块偏好元素格式/精度恢复方案不同、跨操作数权重与激活需不同编码）；AdaMX 每块选精度恢复方案、每操作数选表示，等效位宽(EBW)不增，22nm FD-SOI 加速器原型仅 +1% 系统能耗；3B-70B LLM 上消除 83% MXFP4 常识推理精度损失、82% MMLU 损失，Gemma-4 12B 四个视觉语言基准全胜 MXFP4、保持 96% FP16 精度。URL: https://arxiv.org/abs/2608.03867 ⭐

- **LLaDA-Hybrid：扩散语言模型的线性注意力改造**（[arXiv:2608.06628](https://arxiv.org/abs/2608.06628)，08-06）: dLLM 用块级半自回归解码加速推理，但每个去噪步仍要关注所有前序块、反复付出前缀注意力成本；block-hybrid attention 保留活动去噪块内精确 softmax、对前序块用线性注意力，可最小后训练改造进预训练 dLLM——LLaDA-Hybrid 替换 LLaDA 2.1 (16B) 20 层中 6 层（约 60 小时转换），HumanEval 72.0% vs 75.6%、MBPP+ 63.0% vs 57.7%；Triton 实现解码吞吐最高 +1.7x、支持更多并发请求，证明预训练 dLLM 可高效线性化。URL: https://arxiv.org/abs/2608.06628

### 记忆与 KV Cache 新视角

- **CoinRAG：上下文化信息粒 KV 缓存复用**（[arXiv:2608.07458](https://arxiv.org/abs/2608.07458)，08-07）: RAG 已有 chunk 级 KV 缓存复用避免重处理长检索上下文，但粗粒度 chunk 仍有显著信息冗余与噪声；CoinRAG 以两阶段检索在检索 chunk 内识别查询相关语义单元，组合复用离线计算的细粒度 nugget 缓存 + chunk 级上下文，低 prefill 延迟约束下优化 Pareto 前沿；LongBench 多跳 QA 上平均 F1 相对 +5.3%，显著降运营成本。URL: https://arxiv.org/abs/2608.07458 ⭐

- **WorldTrace：视频世界模型的可寻址 KV 缓存**（[arXiv:2608.07408](https://arxiv.org/abs/2608.07408)，08-07）: 交互式视频世界模型以 KV 缓存作增长型视觉记忆承载先前生成帧，但 rollout 超出训练视野后模型无法可靠寻址存储内容——时间 RoPE 偏移落出训练区间、注意力难以检索；且直接在 RoPE 旋转空间压缩会因平均不相容位置相位而损坏记忆；WorldTrace 免训练框架为每个摘要槽分配分布内虚拟位置保持可寻址性，WorldTrace-Field（时间一致性 +15.5%）与 WorldTrace-Landmark（情节回忆 +19.5%）双路线；配套 LoopBench 基准评测压缩缓存长绕行后能否重建曾访问场景。URL: https://arxiv.org/abs/2608.07408

## 趋势观察

- **KV 缓存压缩从"局部规则"走向"全局分配"**：GraceKV（全局预算竞争）与 AoH（权重空间谱几何、数据无关头诊断）共同指向——压缩决策不再依赖运行时信号/预定义规则，而是全局优化或权重静态分析，部署成本更低、鲁棒性更强。
- **Agentic 负载倒逼异构与架构重审**：HeteroPanacea（PDAF 4 路解聚仿真）与 Agora（Azure 生产实证：CPU 在关键路径、碎片化执行闲置容量）从仿真与实测两侧确认——均匀同构服务器不适配 agentic 推理，异构解聚+角色化资源池成为方向，呼应 08-10 期 Vera-Rubin 异构平台观察。
- **低比特量化进入"格式竞争"深化期**：CubicQuant（参数化非均匀码本）与 AdaMX（异构感知 MX）同日窗口出现，叠加 08-10 期 GyRot/LightRot——量化研究从"位宽"竞争转向"表示格式/精度恢复方案"竞争，且都强调 EBW 不增前提下的精度恢复。
- **KV cache 语义外延扩展**：CoinRAG（RAG 信息粒复用）、WorldTrace（世界模型可寻址视觉记忆）显示 KV 缓存研究从纯 serving 优化扩展到检索语义与生成式记忆寻址，与 08-10 期 LiveMem 状态连续性共同构成"KV 即记忆"范式。
