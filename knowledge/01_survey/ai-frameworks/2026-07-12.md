### 2.2 TRT-LLM v1.3.0rc20 — 确认是最后一版 TensorRT 后端

> 发布于 2026-06-30，已在上期详细覆盖。本期补充确认信息。

**标志性断代**: 该 RC 版本是最后一个支持 TensorRT 后端的版本，下一代将全面迁移到 **CuteDSL/CUDA Core** 路径。这与 NVIDIA Blackwell 世代完全对齐：

| 迁移方向 | 替代技术 | 说明 |
|:---------|:---------|:------|
| ❌ 下线 | TensorRT 后端 | FP16/FP8 集成推理引擎 |
| ✅ 升级 | FlashInfer TRT-LLM Gen + CuteDSL | SM100/SM120 原生 kernel，性能更高 |
| ✅ 升级 | NVFP4 CuteDSL MoE | 融合 grouped/SwiGLU GEMM 累加 pipeline |

**影响**: 意味着 TRT-LLM 从"在 TensorRT 上做二次封装"转向"直接对接 CuteDSL/FlashInfer kernel"，减少中间抽象层，但也意味着存量 TensorRT 工作流需要迁移。

## 3. arXiv 新论文精选

### 3.1 RTP-LLM — 阿里工业级推理引擎（首次完整公开）

> Alibaba RTP-LLM: Serving 100M Users with Real-Time LLM Inference
>
> https://arxiv.org/abs/2606.xxxxx (搜索可见)

| 指标 | 数据 |
|:-----|:-----|
| **覆盖用户** | 1亿+ 日活用户 |
| **KVCache 加载加速** | **4.7–6.3×** vs DSL 加载 |
| **TTFT P95 降低** | **35–37%** reduction |
| **架构创新** | 全链路 P/D 分离 + 智能 KVCache 分级 + 硬件拓扑感知调度 |

**关键洞察**: 阿里公开了面向 1 亿用户规模的工业级推理引擎 RTP-LLM 的完整设计，核心是分级 KVCache 管理策略和预填充/解码分离架构下的硬件拓扑感知调度。**TTFT P95 降低 35–37%** 和 **KVCache 加载速度 4.7–6.3×** 是两个关键工业级基线。

### 3.2 CacheTune — 频域分析 KV 复用

> CacheTune: Frequency-Domain Analysis of KV Cache Reuse for LLM Inference Serving
>
> https://arxiv.org/abs/2605.xxxxx

| 指标 | 数据 |
|:-----|:-----|
| TTFT 加速 | **3.72–4.86×** speedup over baseline systems |
| 方法 | 频域分析 KV 复用模式，预测最佳缓存策略 |
| 核心 | 将 KV 访问模式转换到频域，识别周期性复用模式 |

### 3.3 SAC — CXL 做 KV Cache Disaggregation

> SAC: CXL-Enabled KV Cache Disaggregation for LLM Inference
>
> https://arxiv.org/abs/2606.xxxxx

| 指标 | 数据 |
|:-----|:-----|
| Throughput | **2.1×** vs RDMA-based disaggregation |
| TTFT | **9.7×** improvement in TTFT |
| 方法 | 利用 CXL 内存语义访问而非 RDMA 数据传输 |

**趋势信号**: CXL 进入推理场景！这是首次将 CXL 用于 KV cache disaggregation，吞吐量翻倍的同时 TTFT 降低近一个数量级。

### 3.4 TriRoute — 联合 attention/expert/KV-cache 决策

> TriRoute: Joint Attention, Expert, and KV Cache Routing

| 指标 | 数据 |
|:-----|:-----|
| 方法 | 在单推理引擎中联合优化 attention routing、expert selection 和 KV cache placement |
| 效果 | Pareto 主导独立组合方案，tail-case 鲁棒性更优 |
| 核心 | 三个维度联合决策比分别决策更优 |

### 3.5 PolyKV — 层异构 KV Cache 压缩

> PolyKV: Layer-Heterogeneous KV Cache Compression

| 指标 | 数据 |
|:-----|:-----|
| FullKV 差距恢复 | **54.5%** on LLaMA-3.1-8B |
| 方法 | 不同 layer 配置不同的压缩策略（eviction ratio / quantization bits） |
| 核心 | 层间 KV 敏感度差异极大，统一策略损失精度 |
