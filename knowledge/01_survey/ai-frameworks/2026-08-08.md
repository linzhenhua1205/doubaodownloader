## 🆕 本期发现（11篇，全库 grep 零命中）

- **TensorCast：Tensor-as-a-Service 抽象层**（2608.06007, 08-06）: 识别张量生命周期管理为 LLM 基础设施缺失抽象层，提出 TaaS 将张量状态管理与计算逻辑解耦；TensorCast 提供一等张量抽象+可编程生命周期原语+策略/执行分离运行时；与 vLLM/SGLang 集成，覆盖权重物化/权重同步/KV 缓存管理/可编程路由；**可编程策略在高并发多轮 Agent 工作负载下改善中位 TTFT 达 93.2%**。URL: https://arxiv.org/abs/2608.06007

- **Runtime Observability for Heterogeneous Attention Memory**（2608.05863, 08-06）: 现代模型记忆四形态（普通 KV / latent cache / 学习稀疏选择器 / 循环状态）压缩失败模式各异，提出三算子运行时可观测契约+可执行请求级风险账本；跨 5 架构家族 6 配置实例化，12.4M 条读取回放 8 路并发零违规；错误度量作为类型参与组合（度量不匹配则拒组合），组合继承最弱可信层级（certified/partially certified/empirical 机器裁决）；应用到 DeepSeek-V4 压缩 KV 原型定位静默损坏到结构边界；Lean 4 形式化 + 全工件开源。URL: https://arxiv.org/abs/2608.05863

- **PLoRA：NDP 增强池化内存多-LoRA 服务**（2608.05483, 08-06）: 多-LoRA 工作负载反向于 GPU 形态（TB 级内存对几十 TFLOPS），所有现系统从 CPU DRAM 经 PCIe 暂存适配器；PLoRA 将适配器+KV cache 置于 CXL/NVLink 池化内存，GPU 通过 read-compute 接口自行驱动负载/存储；H100 服务 1000 适配器平均解码延迟 6.6x 低于真实 S-LoRA，附加设备面积 <3.4%；吞吐在 32 GB/s 饱和（仅 CXL 3.1 的 1/4），TP 分片后每 GPU 需求从 7B 降至建模 1.2T 部署。URL: https://arxiv.org/abs/2608.05483

- **QEvict：可恢复量化 KV 驱逐**（2608.05326, 08-05）: 指出基于注意力分数的驱逐策略隐含不可逆决策——被逐 token 不可能再有用，但解码中 token/窗口重要性随查询漂移；提出 Future Missed Mass 与 Global LIR 两个诊断量化"被丢弃状态未来的注意力"与"历史非活跃区域再激活"；QEvict 三档 KV 管理（全精度高置信窗口+量化可恢复中档+仅删最低置信档），量化窗口重新变重要时反量化晋升全精度；长上下文理解/检索/推理基准一致优于驱逐与量化基线。URL: https://arxiv.org/abs/2608.05326

- **ReCo：奖励协调的推理 KV 压缩**（2608.04771, 08-05）: 长 CoT 推理过度思考膨胀成本，且压缩在生成侧不免费（更小 cache 导致模型生成更多 token 部分抵消节省）；ReCo 用轻量过程奖励估计器驱动三组件：奖励自适应 KV 压缩（高奖励步更狠压缩）+ 奖励带反射 token 惩罚 + 置信度早停；跨 3 推理模型 6 基准减少生成 token 37%-65%、端到端延迟 2.08x-2.35x，同时基本保持准确率。URL: https://arxiv.org/abs/2608.04771

- **KARAT：检索式稀疏注意力的通用 PNM 加速器**（2608.03555, 08-04）: 前沿 LLM 用检索式稀疏注意力服务百万 token 上下文，KV cache 移出 GPU 内存；KARAT 为通用 PNM 设计点（大 LPDDR 容量+按检索 indexer 规模定制的通用算力），替代低强度 GEMV 专用 PIM 设计；OFMS 机会微批调度用 expert all-to-all 藏 GEMM、CMR 上下文长度感知微批再平衡；三 SOTA 模型+真实 agent 轨迹下吞吐/TDP 较 GPU-only 基线 2.09-6.13x，训练免费稀疏注意力 1.36-3.21x。URL: https://arxiv.org/abs/2608.03555

- **TaskPress：查询无关 KV 压缩**（2608.03276, 08-04）: 现有剪枝方法确定查询特定 token 重要性，无法跨未见查询复用；TaskPress 以高层任务引导构造可复用记忆表示——引导作为 prefill 期间元查询过滤无关 token；利用量化尺度因子作为零成本信号检测代表性离群值；跨长上下文多任务实验高效生成紧凑可复用 cache。URL: https://arxiv.org/abs/2608.03276

- **GMC：有依据的 VLM 消息核集压缩**（2608.02134, 08-03）: 现有评分法给视觉 token 独立重要性保留 Top-K，但文本查询消费的是视觉群体的集体有符号注意力消息，Top-K 集合会重复覆盖单一显著区域而遗漏稀疏互补证据；GMC 将保真压缩公式化为解码器消息核集构建，联合分配查询依据/外观/坐标证据支撑，将丢弃状态传输进选中的代表 token 原位再物理压缩；Qwen2.5-VL-7B 上 GMC-H2 用 80.2% 更少视觉 token 保留 97.78% 全量相对能力（GMC-L16 达 100.36%）。URL: https://arxiv.org/abs/2608.02134

- **PaDoc：布局接地并行文档解析解码**（2608.06146, 08-06）: 端到端文档解析器把页面布局与区域内容序列化为一个自回归序列，解码路径随总内容增长；PaDoc 将预测布局视为共享页面表示上的分支结构，布局流与区域内容分支并发推进，解码深度降至最长布局-内容路径；vLLM 后端以共享前缀 cache 复用并发请求服务；OmniDocBench Full 布局 F1 91.1，384 页子集 A800 上有效页吞吐 +67.4-118%、P95 延迟 -39.2-54.9%。URL: https://arxiv.org/abs/2608.06146

- **WAIT 算法突发负载扩展**（2608.06135, 08-06）: SOTA 调度算法多假设 Poisson 常数率到达，不符合真实突发流量；提出 WAIT 轻量扩展基于观测到达间隔在线估计请求强度，MMPP 合成工作负载下低到达率偏移场景吞吐高于 Sarathi-Serve/ORCA/vLLM，延迟相当。URL: https://arxiv.org/abs/2608.06135

- **GUARD：扩散 VLA 的 KV 接地失败检测**（2608.04510, 08-05）: 扩散式视觉-语言-动作策略在预测弱接地于任务证据时仍能生成看似合理动作；GUARD 估计最终 VLM KV cache 中 token 索引条目影响力，构造反事实 cache 与原始条件比较去噪响应；Pi0/SmolVLA/Alpamayo-1.5 在 LIBERO/SimplerEnv/MetaWorld/PhysicalAI-AV 上未见任务 ROC-AUC 平均 +5.73pp。URL: https://arxiv.org/abs/2608.04510

## 🔮 趋势

1. **KV 治理进入"可恢复+奖励协调"时代**：QEvict（可恢复驱逐）与 ReCo（过程奖励驱动压缩）同日/相邻日出现——共识从"驱逐/压缩二元"转向"保留可恢复路径 + 按推理轨迹状态自适应"，直接呼应 08-05 RestoreKV 的"恢复式"第三范式
2. **KV cache 从内存优化目标变为安全/审计对象**：Observability 论文把 KV 压缩的失败模式形式化为风险账本（Lean 4 可证明），GUARD 用 KV 反事实探测 VLA 接地失败——KV 成为模型行为审计的探针
3. **池化内存+近数据计算下沉到 serving**：PLoRA（CXL/NVLink 池化 + NDP）与 KARAT（PNM 检索注意力）同日出现，证明"KV 外移 GPU"从论文设想走向工程选型，且都强调链路带宽不再重要（PLoRA 32GB/s 饱和 / KARAT 2.09-6.13x）
4. **框架采用研究延续**：LLM Serving in the Wild（08-05 已归档）的实证结论继续被印证——vLLM 生态位最广，新论文（PaDoc/TensorCast/QEvict 等）均以 vLLM 为实现后端
