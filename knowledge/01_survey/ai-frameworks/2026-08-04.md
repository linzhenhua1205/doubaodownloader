## 一、推理服务系统（2篇）

### 1. DeltaServe — 推理与微调共服务的宿主无关设计（07-30）⭐
- **来源/标题**: [DeltaServe: Host-Agnostic Co-Serving of Inference and Fine-Tuning for LLMs](https://arxiv.org/abs/2607.28848)（07-30）
- **要点**: LLM serving 按峰值负载配置，流量低于峰值时大量 GPU 计算闲置。DeltaServe 将这些闲置推理容量转化为 LoRA 微调吞吐，同时保持推理 SLO。通过紧凑 hook 接口（仅需 multi-LoRA batching 支持）与现有推理引擎集成；利用推理 prefill 与 LoRA 微调前向的共享执行结构；SLO-aware 调度器仅在推理 headroom 足够时准入并执行微调。调度由 CUDA-graph-aware 延迟模型驱动（离线校准 + 在线精化）。
- **量化数据**: 与 vLLM/SGLang/S-LoRA 集成；Company X 生产 trace 上，DeltaServe on vLLM 相比 LLMStation **微调吞吐提升 2.9×**，推理 SLO 合规 100%（vs LLMStation 85%）；相比 vLLM+torchtune 基线微调吞吐 **+39%**，无需额外硬件、SLO 完全合规。
- **意义**: 首次将"推理容量闲置→微调"做成系统级共服务方案，PD/计算复用从同一模型扩展到同架构不同任务；vLLM 插件接口（hook）再次成为学术落地载体。

### 2. Conformal Cascade — 多层级联推理的分布无关精度保证（07-27）
- **来源/标题**: [Conformal Cascade: Distribution-Free Accuracy Guarantees for Multi-Tier LLM Inference](https://arxiv.org/abs/2607.25018)（07-27，v3 更新 07-31）
- **要点**: 生产级 cascade 通过置信度阈值决定"简单查询留小模型、困难查询升级大模型"，但 LLM 置信度校准差、阈值需逐模型对/逐域调参且无形式化精度界。Conformal Cascade (CC) 用**共形预测集大小作为升级规则**：校准集坍缩为单一答案则接受，否则升级。
- **量化数据**: 按层 union bound，接受层预测集以 ≥1-Kα 概率覆盖正确答案（任意用户指定 α；选择保持条件下收紧至 1-α）；18 个多选题基准 × 4 个开源模型家族的两层级联上，CC 在多数 family-benchmark 对上严格优于最强校准调优启发式 cascade；推理密集基准（majority vote 不可靠）收益最大；简单基准上绝大多数查询零精度损失地提交给小模型。无需训练、仅需黑盒 API 访问。
- **意义**: 把级联推理从"工程启发式"提升为"带形式化保证的统计框架"，对成本-精度权衡的系统化有方法论价值。

## 二、KV Cache 与注意力机制（4篇）

### 3. Through the Bottleneck — MLA 可解释性首秀（07-25）⭐
- **来源/标题**: [Through the Bottleneck: How Multi-head Latent Attention Separates Content from Position in Language Models](https://arxiv.org/abs/2607.23054)（07-25）
- **要点**: 首个 MLA（DeepSeek-V2 引入，推理期 KV cache 减 81%）机制可解释性研究。训练 114M transformer，用 SVD / 注意力头分类 / 线性探测 / 扰动归因分析 cKV 瓶颈。
- **量化数据**: (1) cKV 瓶颈学习到**纯内容表征**——实体身份保留 98% 而丢弃位置信息，验证 MLA 经 RoPE 的内容-位置分离；(2) induction head 聚居于单层（Layer 12），与标准 MHA 的分布式形成不同；(3) 单"语义枢纽"层（Layer 15）同时呈现最高 SVD 有效秩与最强扰动归因分；(4) 瓶颈全局过度供给——平均仅用 **46%** 容量。
- **意义**: MLA 不只是被动压缩注意力，而是重塑模型组织内容/位置/电路结构的方式；瓶颈过度供给 46% 为后续压缩 MLA latent state 留下空间。

### 4. SALT — 显著感知词法 Trie 长上下文压缩（07-20）
- **来源/标题**: [SALT: Salience-Aware Lexical Trie for Long-Context Compression](https://arxiv.org/abs/2607.17486)（07-20）
- **要点**: 现有 prompt 压缩按标量相关性逐句打分，把文档当无结构词袋——紧预算下出现**主题坍缩**（主导主题独占预算，丢弃低频但有任务相关性的主题）。SALT 按句子频率将每句关键词组织进 trie（主题结构的轻量可复用代理），平滑内存分配、防止主导主题垄断预算；多锚点检索激活任意深度 query 关键词节点；trie 跨对话轮次持久化，多轮使用无需重新编码文档。
- **量化数据**: 减少长上下文 prompt 的 prefill 计算与内存成本；可与面向 decode 期的 KV-cache 方法组合（互补而非替代）。
- **意义**: 主题覆盖意识（而非逐句显著性）是 prompt 压缩的新维度，与 KV cache 方法形成 prefill/decode 两阶段互补。

### 5. MoA-Structured — GQA/MQA 注意力 kernel 的数学推导（07-21）
- **来源/标题**: [MoA-Structured Decode Attention DNF Derivation, KV-Cache Accumulation, GQA/MQA, and OpenACC Kernel](https://arxiv.org/abs/2607.19456)（07-21）
- **要点**: 用 Mathematics of Arrays (MoA) 从前向 Denotational Normal Form (DNF) 推导四个内存最优推理产物：单查询 decode DNF（ψ-归约代数消除 Kᵀ buffer）、C/OpenACC GPU kernel（ONF 步长算术 + 硬件合并内存访问）、多步 KV-cache 追加 O(d_k+d_v)/step、经 ψ-selection 推导 GQA/MQA（证明 h_q/h_kv 的 KV 流量缩减）。
- **量化数据**: DRAM 流量 (d_k+nd_k+nd_v+d_v)×4B，数值误差 ≤2×10⁻⁷；kernel 与 PyTorch scaled_dot_product_attention 逐位一致（IEEE-754 精确）；GQA/MQA 流量缩减 h_q/h_kv 有证明。
- **意义**: 将注意力 kernel 优化从经验工程提升为代数推导，为跨后端（CPU/GPU/OpenACC）的一致实现提供数学基础。

### 6. KATA — 核化线性注意力突破容量墙（07-19）
- **来源/标题**: [Kernelized Linear Attention: Breaking the Capacity Wall with Symmetric Cones](https://arxiv.org/abs/2607.17419)（07-19）
- **要点**: 线性注意力在关联回忆（associative recall）上退化严重。将注意力回忆形式化为球面填充问题，从第一性原理（自对偶齐次锥验证非负注意力权重）推导特征映射；秩一 PSD 特征在容量-干扰权衡上最优；KATA 恢复参数自由凸输出门，用 Welch 干扰下限刻画关联容量；容差高于下限时无需加参数即可扩大状态，支持投影维数上指数多密钥的球面码。
- **量化数据**: 融合 Triton kernel 两个运行点——flash-attention 风格前向达 ~1.6× FlashAttention-2 吞吐；精确 O(T) chunked-state 形式在 131K tokens 达 **~11× FlashAttention-2 前向吞吐**；一阶特征关联扫描将 inter-chunk 递归深度降至 O(log(T/C))；长程 MQAR / 重复键覆盖上多个变体优于 Gated DeltaNet。
- **意义**: 为线性注意力（MLA 之外的另一条长上下文路径）提供容量保证的理论框架，Triton kernel 直接可部署。

## 三、推理优化（2篇）

### 7. SPDP — 统一静-动态剪枝的稀疏推理框架（07-24）
- **来源/标题**: [Unified Static-Dynamic Pruning for Efficient LLM Inference](https://arxiv.org/abs/2607.21985)（07-24，PVLDB 2026）
- **要点**: 静态剪枝（SP）永久移除冗余权重但缺自适应性；动态剪枝（DP）适应输入稀疏但引入运行时不规则。SPDP 统一两者：Tiled-Column-wise Bitmap Compressed (Tiled-CBC) 格式 + 两个互补 GPU kernel——CUDA-core spMspV kernel（Hybrid Activation-aware Dynamic Shared-Memory Bitmap Decoding, HAD-SMBD）做细粒度运行时激活跳过；Tensor-Core SpMM kernel 优化 prefill。
- **量化数据**: 推理优化 GPU 上平均加速 **1.24-1.37×（最高 2.51×）** over SOTA 稀疏框架 SpInfer；perplexity 匹配且稀疏度**高 25%**；推进推理效率-质量 Pareto 前沿。
- **意义**: 静/动态稀疏性联合格式-kernel 设计是 GPU 稀疏推理的新范式，直接适用于 vLLM 类引擎的权重加载路径。

### 8. TV Distance — 引擎间分布距离的统计估计（07-21）
- **来源/标题**: [Total Variation Distance Estimation in Autoregressive Models](https://arxiv.org/abs/2607.19510)（07-21）
- **要点**: 现代 LLM 部署在固定权重上叠加大量实现选择与推理优化（batching/自定义 kernel/量化），**两个引擎 serving"同一模型"可产生显著不同的分布**。研究在三种访问模型下估计两长度-n 自回归分布间的 TV 距离：样本访问 Õ(n²K/ε²)（改进 Meel et al. 的 Õ(n³m/ε⁵)）；logit 访问 O(n/ε²) 且紧；带噪 logit 访问平滑插值。
- **量化数据**: 实验直接测量 **SGLang 与 vLLM serving 相同权重的分布距离**；TV 距离在 KL 发散为无穷时仍可估计（鲁棒性关键）。
- **意义**: 首次为"同一模型不同引擎的分布漂移"提供可计算度量——对引擎切换/量化/优化验证（如 vLLM 的 mixed-dtype 融合是否改变输出）有直接应用价值。

## 四、训练-推理协同（1篇）

### 9. Stale but Stable — 异步 RL 的陈旧自适应信任域（07-21）
- **来源/标题**: [Stale but Stable: Staleness-Adaptive Trust Regions for Stabilizing Asynchronous Reinforcement Learning](https://arxiv.org/abs/2607.18722)（07-21，v3 更新 07-24）
- **要点**: 异步 RL 中 rollout 与优化解耦带来陈旧性（policy lag + 引擎延迟 + MoE routing 复合）。PPO clipping 只门控采样外更新，无法作为全策略约束。Staleness-Adaptive Trust Region (SAT) 用 detached sampled log-ratio 作陈旧性代理，经陈旧性核函数缩放识别批内高失配尾部，只收缩符号选择的名义 PPO 区间端点——普通 token 保持基线行为，仅在新截获的外带更新上更保守。
- **量化数据**: 基于 Qwen3-30B-A3B-Base 的全解耦异步 RL 设置（**SGLang 推理引擎 + Megatron 训练**）：SAT-GSPO w/ R3 达最佳 AIME24 avg@8（lag 1: 35.83, lag 8: 34.79）。
- **意义**: 训练-推理引擎解耦（SGLang+Megatron 双栈）成为异步 RL 标准架构，陈旧性感知的信任域为训练稳定性提供新旋钮——推理引擎的可观测性（lag）直接进入训练算法设计。

## 五、综合观察

1. **本期为"补录批"而非新提交**: 9 篇均为 07-19~07-30 提交、此前查询遗漏的论文（08-03 查询 20 篇 vs 本期 30 篇）。说明追踪查询的召回率依赖查询宽度，需周期性放宽关键词防漏。
2. **推理容量复用从"同任务"扩展到"跨任务"**: DeltaServe 把闲置推理 GPU 转为 LoRA 微调（2.9×），与 07-29 归档的"同架构复用"形成递进——GPU 资源池化的粒度从请求级细化到任务级。
3. **MLA 研究进入"机制理解"阶段**: 可解释性首秀（内容/位置分离、46% 容量冗余）为 MLA 进一步压缩与推理优化提供依据；KATA（线性注意力）与 Through the Bottleneck 共同显示"MLA/线性注意力"两条长上下文路径都在加深理论地基。
4. **引擎一致性成为可度量指标**: TV 距离估计为"同一模型不同引擎"提供统计工具，与 vLLM v0.25.1 mixed-dtype 融合守卫（07-16 归档）呼应——引擎优化的正确性验证正在工具化。
5. **静-动态稀疏性联合设计**: SPDP 证明统一 SP+DP 的格式-kernel 协同（1.24-1.37×）优于纯静态或纯动态，GPU 稀疏推理从"二选一"走向"联合"。
