## 4. arXiv 新论文 — KV Cache 优化

### 4.1 TriRoute: Unified Learned Routing for Joint Attention, Experts, and KV-Cache Allocation

> arXiv:2607.06601 (cs.LG, Jul 6, 2026)

**核心思想**：MoE（FFN 稀疏化）、MoD（跳过整层 Transformer block）、KV Cache 量化（attention 记忆压缩）这三个决策**强耦合**，需联合优化。

**方法**：
- 单一的轻量控制器（per-token per-layer），同时输出三个决策：attention mode (skip/local/full)、FFN expert 集合（含 null expert 恢复 MoD）、KV cache bit-width
- 通过 Heterogeneous Relaxation（Gumbel-Softmax + straight-through estimation + load-balanced top-k gating）端到端训练
- Lagrangian budget 约束控制平均计算/存储代价

**Cross-axis routing-collapse cascade**：单轴坍缩会传播至其他轴 → 提出 per-axis normalization + coupling-aware balancing loss 解决

**性能**：160M–1.3B 参数量 decoder-only 模型上，在匹配推理 FLOPs 和 memory 约束下 **Pareto 主导**最优独立 MoD+MoE+KV-quantization 组合，且在罕见实体/代码/算术（perplexity 优化的盲区）上保持更强的 tail-case 鲁棒性

### 4.2 PolyKV: Heterogeneous Retention and Allocation for KV Cache Compression

> arXiv:2606.15157 (cs.LG, Jun 13, 2026)

**核心思想**：不同 transformer 层在 prefill 和 decoding 阶段扮演不同角色，需要不同的 eviction 策略和 cache budget。现有方法使用单一压缩策略和统一 cache budget。

**方法**：
- Per-layer 信号指导路由到合适的 KV 压缩策略
- 在固定总 budget 下分配非均匀 cache budget
- 允许现有 KV cache 方法的异构组合

**性能**（LLaMA-3.1-8B, Qwen3-8B）：
- 512-token 平均 KV budget 下，**恢复 54.5% / 25.7%** 的 FullKV 性能差距（vs 最强单一策略 baseline）
- 128–1024 budget 扫描下，**持续提升 1.7%–6.4%** 相对最强 baseline（= 40.0%–54.5% FullKV 差距恢复）

### 4.3 Still: Amortized KV Cache Compaction in a Single Forward Pass

> arXiv:2606.07878 (cs.LG, Jun 5, 2026)

**核心思想**：small per-layer Perceiver（一次性训练，基模型冻结），在**单次前向传播中**生成 compact keys 和 values。

**设计目标**：轻量（推理时可调用）、有表现力（约束下保持上下文）、可跨序列复用

| 能力 | 说明 |
|:----|:------|
| 压缩比范围 | **8× 到 200×**，context 长度 8k–128k |
| RULER 长上下文 | **超过最强 baseline 8–22 点** |
| 自动摘要 | 在 HELMET 和 LongBench 上保持大部分 full-context 增益 |
| 迭代压缩 | 单次 forward pass 即可 → 可迭代应用实现超长上下文 |
