## 本期发现 (7条)

### 框架与系统

- **Full-bandwidth Transformer：隐式反馈拓宽解码垂直通道**（[arXiv:2608.08888](https://arxiv.org/abs/2608.08888)，08-09）: 自回归 transformer 沿两轴计算——水平跨生成 token、垂直穿模型深度；dense attention 给每 token 水平方向的全量过去访问，但解码步之间的垂直反馈通道狭窄：只有采样 token 返回栈底，顶层 hidden state 被丢弃；Full-bandwidth Transformer 用 gated linear unit 把上一解码步顶层 hidden state 与采样 token embedding 融合后作为下一输入（latent feedback），让未言化的计算以更新的深度预算重回栈内，同时保持标准架构/KV cache/语言建模目标；训练用 scheduled multi-pass objective（预训练后期引入 latent feedback + 少量深层 feedback pass 稳定）；1B 参数训练至 400B tokens，latent feedback 改善验证 loss。URL: https://arxiv.org/abs/2608.08888 ⭐

- **MemSpec：边缘设备预测引导的推测解码内存感知运行时**（[arXiv:2608.10362](https://arxiv.org/abs/2608.10362)，08-11）: 推测解码靠轻量 draft 模型加速目标模型解码，有效性取决于 draft 选择；在内存受限边缘设备上，draft 模型切换开销常抵消收益——核心矛盾是紧内存预算下 draft 选择与 draft 可用性错配；MemSpec 把 draft 选择与执行解耦，通过主动 resident working-set 管理（轻量预测器从 prompt/生成上下文估计 draft 有效性 + 内存感知调度器降低反应式模型加载开销）；Jetson Orin Nano 实测稳态生成吞吐较 SOTA bandit 自适应法平均 +40.7%。URL: https://arxiv.org/abs/2608.10362 ⭐

- **Aero Realtime：全双工流式多模态生成 4B 模型**（[arXiv:2608.08469](https://arxiv.org/abs/2608.08469)，08-09）: 现有流式多模态模型按 turn-based prefill-then-decode 模式处理增量观察，非全双工——新观察无法自然进入活跃生成流；Aero Realtime 把视频/音频/文本输出对齐到共享时间网格，每约 80ms 音频槽预测词元或静默 token，输入输出同步推进，单一自回归目标同时学习何时回应与生成什么；推理时仅追加最新多模态槽、前向携带先前输出状态、复用 KV cache 增量执行；提供完整训练+serving 配方（实时 QA 构建/槽对齐监督/硬件感知分布式训练）。URL: https://arxiv.org/abs/2608.08469

### KV 缓存优化

- **Consolidator：跨上下文边界的持久路由记忆学习**（[arXiv:2608.11701](https://arxiv.org/abs/2608.11701)，08-12）: 把短期记忆（STM）拷贝进慢速存储可跨上下文边界保留状态，但持久化本身不保证保留状态影响后续记忆访问；PMNet 中 Consolidator 作为共享 slot-local 算子，在累积进长期记忆（LTM）前变换路由的 STM（不重放源 token），每次 consolidation 后 KV cache 与 STM 被清空，保留的 LTM 仍可读并喂给层次路由器从而条件化后续输入访问的显式记忆槽；仅 12.35K Consolidator 参数可训练（29.95M 模型的 0.041%）；五对同检查点运行中直接 LTM 路由把更新映射回忆从 44.38±1.94% 提升至 87.02±1.76%（+42.64pp），学习型 consolidation 比强制恒等累积高 21.40±1.91pp（无路由）/68.70±1.76pp（有路由）。URL: https://arxiv.org/abs/2608.11701 ⭐

- **VoxZip：语义锚定的长上下文音频 KV 压缩**（[arXiv:2608.08569](https://arxiv.org/abs/2608.08569)，08-09）: 语音 LLM 长上下文推理被 KV cache 内存严重瓶颈化，文本中心压缩法常破坏语音连续性或丢弃语义线索；VoxZip 两阶段 train-free 框架：①用 ASR 转录作显式语义锚，时间对齐/压缩/融合音频 token，显著降低初始 KV 同时提升 token 信息密度；②基于时间衰减累积注意力的动态过滤驱逐非必要 token（缓解早期 token 偏差）；Qwen3-Omni 六项音频基准上长音频推理表现优异，短任务保持高保真感知。URL: https://arxiv.org/abs/2608.08569 ⭐

- **HoloAegis：零样本 LLM 安全护栏的极简参数拓扑推理**（[arXiv:2608.08485](https://arxiv.org/abs/2608.08485)，08-09）: 现有安全护栏两难——微调扭曲预训练表示、生成式 judge 推理成本高；HoloAegis 在冻结语义表示上做纯几何推理：唯一自由参数是 anchor 数 K 与温度 tau（构建后固定、免梯度训练），未微调编码器把文本映射到单位球后全部决策纯几何；安全评估形式化为预计算 System Topology Anchor Bank 上的 Gibbs-Boltzmann 自由能计算，Dual Time-Scale EMA 检测多轮语义漂移；Topological Boundary Stability 猜想获经验支持——稀疏 anchor 质心对高频词法扰动边界稳定远优于全向量空间法；8 基准 SOTA 准确率（AuthenHallu AUC 1.0000、HarmBench 0.9802、中文 CHIFRAUD 0.9758），亚毫秒延迟、零冷启动数据、跨语言迁移。URL: https://arxiv.org/abs/2608.08485 ⭐

## 核心趋势

1. **解码器架构在"垂直通道"上做文章**：Full-bandwidth Transformer 与 Aero Realtime 同周出现，一个拓宽层间反馈（latent feedback），一个重构流式 I/O 对齐（全双工）——在 KV cache/架构不变前提下，从解码拓扑与执行模式层面突破自回归的逐 token 串行墙
2. **边缘推理从"算法优化"进入"运行时管理"**：MemSpec（内存感知 draft 调度）+ 08-13 期 RotaryQuant（消费级 MoE 量化）共同说明边缘部署瓶颈已从模型侧（能否放下）转向运行时侧（切换/加载/驻留开销如何不吞掉收益）
3. **KV 压缩方法论继续外扩到多模态与记忆语义**：VoxZip（音频语义锚定）与 Consolidator（LTM 路由记忆）显示 KV 优化不只在文本 token 层面，音频/记忆系统正在借用同一套压缩-寻址思路；HoloAegis 则从安全角度把推理成本作为约束（生成式 judge 太贵 → 几何护栏）
