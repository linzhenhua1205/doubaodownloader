### 10.1 ⭐ Nvidia Rubin Ultra 四芯片设计取消 — 转向双芯片方案 🆕（2026-06-30）

**来源**: Tom's Hardware (Anton Shilov)
**硬件影响评级**: ⭐⭐⭐⭐⭐（超节点服务器形态重大变更信号）

| 维度 | 内容 |
|:-----|:------|
| **原方案** | Rubin Ultra GPU — 单封装集成 **4个compute die** + 1TB HBM4E |
| **新方案** | **双芯片 (dual-die) Rubin Ultra** |
| **原因** | **制造执行风险** (manufacturing execution concerns) |
| **原配套机架** | Kyber rack-scale system（GTC 2026 展示的托盘级方案） |
| **HBM4E** | 4-die → 2-die 后总容量预计从 1TB 降至 **~512GB 级别** |
| **发布时间** | Rubin 系列计划 **2027 H1** |

**对服务器形态的影响 ⭐⭐⭐⭐⭐**:
- **四芯片 → 双芯片** 是服务器加速器形态的重大转向。原计划的 1TB HBM4E 是 Kyber 超节点的核心卖点，单颗 GPU 上 4-die 的封装复杂度、散热密度、CoWoS-L 产能瓶颈迫使 Nvidia 务实降规
- 双芯片设计与当前 Vera Rubin NVL72 的设计哲学一致（Vera CPU + Rubin GPU 异构），但 Rubin Ultra 作为"旗舰中的旗舰"降规意味着 Nvidia **在封装与散热工程上遇到了实际的物理限制**
- 这一变更直接影响 2027-2028 年超节点服务器形态规划：**单单元 GPU 密度上限短期内向下修正**
- 从供应链角度：CoWoS-L 产能紧缺下 2-die 方案比 4-die 的**良率和产出量可翻倍**

**补充**: 同一报道周期内 Tom's Hardware 还提到 Nvidia Vera Rubin NVL72 机架报价已涨至 **$5M-$7M**（之前$3-4M），分析称 HBM 成本占比从 25% 向 30%+ 攀升。这从经济面上解释了 Rubin Ultra 降规的合理性。

### 10.2 ⭐ MiTAC Computex 2026 — Diamond Cooling 金刚石冷却 + 52U 特深机架 🆕（2026-06-21）

**来源**: ServeTheHome (Ryan Smith, Computex 2026 展台实拍)
**硬件影响评级**: ⭐⭐⭐⭐（新型液冷方案探索）

**核心展示内容**:

#### (1) Diamond Cooling — 金刚石辅助散热

| 参数 | 内容 |
|:----|:------|
| **技术** | 使用**合成金刚石 (synthetic diamond)** 作为导热介质 |
| **原理** | 金刚石热导率 **~2000 W/m·K**（铜的 5 倍、铝的 8 倍） |
| **场景** | 紧贴高密度加速器/CPU 热源，快速扩展热面至冷板 |
| **形态** | 金刚石导热垫/热扩散片，与液冷冷板配合使用 |
| **阶段** | 概念展示/工程样品阶段 |

**意义**: 金刚石作为热界面材料已在高端射频/激光器件中商用，MiTAC 将其引入服务器液冷散热方案展示。金刚石的超高导热率可以将热点集中热量快速扩散到更大面积的冷板上，从而降低热流密度。这是**对现有 TIM（导热凝胶/导热垫）的超越尝试**，但成本和量产可行性是最大障碍。

#### (2) 52U 特深机架

| 参数 | 内容 |
|:----|:------|
| **高度** | 52U（超过标准 42U 的 24%） |
| **深度** | 显著加深以适应 GPU 液冷管路 + 800V DC 供电母线排 |
| **配套** | 整机柜液冷方案（CDU + manifold + 盲板） |
| **目标形态** | Nvidia HGX / OCP ORv3 兼容 |

**意义**: 52U 机架是行业向更大单体机架演进的信号。52U 相比 42U 多出 **10U 净增量**，这额外空间被用于液冷管路布置+大功率供电模块，而非单纯增加计算密度。这说明液冷时代的机架设计正从"尽可能塞密度"转向"给基础设施工程留空间"。

### 10.3 Nvidia 推出 AI 云收入分成模式 — 商业模式影响基础设施部署 🆕（2026-07-02）

**来源**: Tom's Hardware (Luke James)
**硬件影响评级**: ⭐⭐⭐（商业模式→硬件部署节奏）

**核心信息**: Nvidia 宣布新的可选融资工具，在硬件销售之外**再取 AI 云收入分成（cut of AI cloud revenue）**。这意味着 Nvidia 从纯硬件供应商向"硬件 + 运营收益"双轮驱动转变。

**对服务器形态/部署的影响**:
- 如果 Nvidia 分享运营收益，它会更关注**客户的部署效果和利用率** → 可能推动更多**整机柜交付 + 预集成 + 端到端液冷验证**，减少客户自行集成的碎片化
- 收入分成模式需要 Nvidia 监控客户集群运行状态 → 可能推动 **Nvidia 对数据中心设计和配置的直接话语权**，进而影响服务器形态标准化
- 这一商业模式的长期效应：Nvidia 可能要求客户采用**指定的液冷/供电方案**以满足其 SLA

### 11.15 🎯 核心判断（2026-07-03）

1. **LTA价格上限取消是最新最严重信号** — SK hynix这一结构性动作意味着**服务器OEM价格保护机制全面瓦解**，内存采购从"年度谈判"变成"实时市场"模式

2. **涨价闭环全方位锁定**：Foundry(TSMC+15%) → 封装(ASE>+20%) → IC设计(MediaTek官方涨价) → 存储(SK hynix取消上限) → 整机(Apple全线涨价)，**无环节能吸收**

3. **BOM≈芯片>95%**经SIA-Deloitte定量确认，服务器系统厂商定价权极其有限：整机毛利持续压缩，需要寻找**非芯片差异化**（供电/散热/管理软件）

4. **供给端注资但远水不解近渴**：SK hynix KRW 100T投入但NAND Fab到2029H1 → 2026-2028供应紧张持续。**未来3年是涨价最严峻窗口**

#### 14.9 🔬 arXiv: IMEC 64×100 GHz Si WDM滤波器 🆕（2026-06-22）

**来源**: arXiv:2606.23173 — IMEC / Q. Deng et al.
**评级**: ⭐⭐⭐⭐（硅光WDM通道密度记录）

| 参数 | 数值 |
|:----|:-----|
| **架构** | 环形-MZI级联（Ring-MZI Cascade） |
| **创新点** | TOPIC（Third-Order Polynomial Interconnected Circular）弯曲波导 |
| **通道数** | **64通道 × 100 GHz间距**（6.4 nm总带宽） |

**核心贡献**: TOPIC弯曲波导首次实现低损耗半环波导，使MZI臂长差由半环结构决定，MZI与环形FSR精确对齐，彻底摆脱调谐需求。为CPO WDM提供片上多波长方案。
