## 📄 arXiv 论文（cs.DC · 本期窗口 8/14-8/17 无新增，窗口外补录 2 篇）

- **RollMux: Phase-Level Multiplexing for Disaggregated RL Post-Training（2512.11306，12/15 提交，窗口外补录）**: rollout-training 分离架构下 on-policy 算法的严格同步产生依赖气泡（一簇空闲等另一簇），RollMux 以"共执行组"抽象把集群划分为隔离局部域，双层调度（组间保守随机规划 + 组内轮转最优调度）+ 驻留约束（大规模模型状态驻留主机内存实现 warm-star 上下文切换）——**328 H20 + 328 H800 生产级测试台**评估：成本效率较标准分离 **1.84x**、较最优同置基线 1.38x，**100% SLO 达成**——RL post-training 分离架构的"气泡回收"维度，与 08-14 MISA-T（路由）/TideRL（弹性）/RoutePack（打包）构成 RL 调度家族补缺（阶段复用）。https://arxiv.org/abs/2512.11306
- **Maestro: Workload-Aware Cross-Cluster Scheduling for LLM-Based Multi-Agent Systems（2606.12950，6/11 提交，ICDCS 2026，窗口外补录）**: LLM-MAS 每次用户查询产生迭代式 LLM 调用流水线，资源消耗较单轮放大；Maestro 利用 agent 语义/角色预测每阶段输出长度与内存占用驱动三层调度（节点级动态多模型同置+层级权重缓存+弹性内存供给 / 集群级时延感知路由 / 全局工作流感知优先级），原型+trace 仿真**减少 KV 预留 HBM 67.2%**、高竞争 SLO 达成较 EDF **+23.6pp**——LLM-MAS 成为算力平台新工作负载类型，跨集群调度与 KV 容量管理需感知 agent 工作流语义（与 Ready Cohorts 的 agent 控制路径粒度互证）。https://arxiv.org/abs/2606.12950
