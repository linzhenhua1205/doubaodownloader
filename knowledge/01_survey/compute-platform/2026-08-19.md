## 一、平台调度研究前沿（arXiv 2026-08 最新）

- **arXiv/Multi-Tier SLA Scheduling (2608.16336, 08-17)**: 扩展 Llumnix 的两级优先级模型到任意层级的 SLA 调度——生产环境实际有多档 QoS 契约（延迟关键 API 到后台批处理），在 Vidur 高保真 LLM 推理模拟器中实现逐层 headroom（指数衰减）+ tier 感知派发排序 + 完整 Llumnix 迁移管线，对比 INFaaS/vLLM/Orca/Sarathi-Serve 并扫描 1-10 层。结论：**4 层优先级性价比最优**——prefill 平均加速最高 8.3x、端到端 P99 加速 3.1x（对比 INFaaS 全局路由基线），成本-延迟改进 46-68%，且 10 层时无尾延迟崩溃（开销集中于 prefill 阶段）。SLA 契约正从"高/普通"二元走向多级差异定价，与平台商业化 token 级计量（OpenCost，已由 tech 组收）同向。https://arxiv.org/abs/2608.16336
- **arXiv/SliceScheduler (2608.15762, 08-16)**: 容器粒度调度浪费容器内短命空闲切片，而算子级调度需要实时推理依赖/内存安全/集群动态——提出 Global Mapping Graph（算子依赖+张量形状+资源映射+执行状态的统一抽象）+ 全局模拟器（候选放置下的算子级执行与内存演化预测）+ 增量模拟调度 + 算子执行器四件套，PyTorch backend 生产 trace 回放：token 吞吐较现有方案提升 1.10-2.29x，SLA 违规保持 ≤9%。**调度粒度从容器/请求继续下钻到算子级**，直接针对多租户 LLM 服务的碎片化 GPU 利用。https://arxiv.org/abs/2608.15762
- **arXiv/KV-Pipe (2608.15943, 08-16)**: 把跨层 KV 共享从推理侧的 cache 压缩手段反转为**流水线均衡控制旋钮**——从尾 stage 起按 tail-first 顺序将部分 attention 层转为跨层 KV 共享，迭代重定向当前瓶颈使 FLOPs Imbalance Ratio→1；全程离线执行、零运行时开销、无需在线调优。多组 PP 配置下训练 MFU 最高 +9.2%、迭代时间最多 -9.8%（高 PP 度下 stage 失衡放大、增益更大）；推理侧附带收益：KV cache 增长与冗余 KV 投影减少，长上下文解码吞吐提升。**KV 布局成为系统-架构联合设计自由度**。https://arxiv.org/abs/2608.15943
- **arXiv/LLM-Teacher 蒸馏标注流水线 (2608.15975, 08-17)**: 面向百万级语料标注的 LLM-teacher 蒸馏作业——work-stealing ring pool（每 worker 自有队列+偷取后继+原子 CAS 恰好一次认领+陈旧认领清扫的崩溃容错）+ 按 GPU 可容纳模型副本数定内存感知并发 + 重标注基准方法论（教师重标已有金标数据集，质量=一致率、成本=实测吞吐）。偏斜负载下吞吐达静态分片的 3.4x（零偏斜时持平）；2,000 任务中途杀一半 worker **零丢失**（静态分片丢 953）；SQLite CAS 实现零依赖可复现。https://arxiv.org/abs/2608.15975
- **arXiv/DB-SpMSpV (2608.16308, 08-17, ICPP 2026)**: 双视角分块稀疏矩阵-稀疏向量乘框架——固定 2D 块 + 块级 CSR/CSC 双视图 + 单一底层块载荷同时支持行驱动 pull/列驱动 push，运行时按块稀疏度选全局遍历路径与块微内核。A100 上平均 5.48x-64.34x（vs cuSPARSE）、2.36x-14.01x（vs TileSpMSpV）；DB-Decoding 使单 token 线性层加速最高 4.50x——稀疏 LLM 推理/图遍历的底层算力库能力增量。https://arxiv.org/abs/2608.16308

## 三、追踪结论（趋势线）

- **调度语义化继续深化**: 继昨日 DriftSched/SAGA（Agent 工作流/负载语义感知）后，今日增量显示调度粒度继续下钻（SliceScheduler 容器→算子级）、SLA 契约从二元到多级差异化（Multi-Tier SLA 4 层最优）——"单点吞吐优化"彻底让位于"负载语义 × QoS 契约"联合优化，且都面向多租户 LLM 服务这一算力平台核心负载。
- **训练侧出现新的系统-架构自由度**: KV-Pipe 证明 KV 布局可以反哺流水线并行均衡（MFU +9.2%），与 KV cache 推理侧优化（8 月主线）形成闭环——平台训练栈的优化空间不再局限于并行策略与通信，扩展到模型内存布局。
- **云原生 AI 平台进入"运营化+工程化"双阶段**: KubeCon 新增 AI Inference+Agentic track、LLMOps 归属之争、平台主权多平面架构，叠加昨日 OpenCost token 级计费——平台从"能不能跑"进入"算得清账、分得清权、跨域可治理"阶段；Kubeflow 毕业（tech 组已收）为此轮平台标准化的里程碑锚点。
