## 一、平台调度研究前沿（arXiv 2026 最新）

- **arXiv/DriftSched (2606.02982, 06-19)**: 多租户 LLM 推理的 QoS 感知调度框架——admission 时工作量估计与运行时实际执行偏差（token drift）导致队列失衡与尾延迟劣化，通过工作量分类 + token 预算估计 + 在线反馈校准，估计误差平均降 38.8% (MAE) / 40.5% (RMSE)；对比 FIFO/Priority/Weighted/SJF/Aging 五种策略，SJF 综合最优：持续 GPU 争用下中位端到端延迟降约 42%、P99 降约 16%。结论：调度器选择对延迟的影响大于运行时校准本身。https://arxiv.org/abs/2606.02982
- **arXiv/SAGA (2605.00528, 06-19)**: 面向 AI Agent 推理的"工作流原子调度"——Agent 单任务执行数十至数百次链式 LLM 调用，而现有 GPU 调度器把每次调用当独立请求、丢弃步骤间 GB 级中间状态，端到端延迟膨胀 3-8x；SAGA 把整个 Agent 工作流作为一等调度单元（Agent Execution Graph 预测跨工具边界 KV cache 复用，达 Bélády 最优离线策略 1.31x 内），64-GPU 集群（SWE-bench/WebArena）任务完成时间降 1.64x（p<0.001，对比 vLLM v0.15.1 + prefix caching）、GPU 内存利用率提升 1.22x、多租户干扰下 SLO 达成 99.2%；代价是峰值吞吐较吞吐最优批调度低约 30%——面向延迟敏感的交互式 Agent 部署取舍。https://arxiv.org/abs/2605.00528
- **arXiv/Vitamin-E (2603.15042v4, 08-05 更新)**: 确定性保持的 GPU 空间共享——观察到现代 GPU 调度把逻辑结构与物理宽度解耦（同一 launch 可通过 block 放置/wave 数变化跨越一族宽度），由此导出 parallel-structure invariant：固定结构确定性负载保持 launch 不可变即可在任意分配宽度下输出比特级一致（vs 资源驱动 reshaping 会改变 greedy 解码 token）；实测 LLM 训练聚合吞吐最高 3.50x、推理 p99 延迟降 62.5%、后台训练吞吐 1.43x；机制上 TPOT-First 策略较 Throughput-Oriented 减少 TPOT SLO 违规最高 46.1%。https://arxiv.org/abs/2603.15042
- **arXiv/Hummingbird (2601.04071)**: 闭源 GPU 上微秒级抢占的 SLO 导向调度——利用空闲 GPU 时间片收割，高优先级任务 SLO 达成率较最先进空间/时间共享方案分别提升 9.7x / 3.5x；与独占执行相比，与低优先级任务共置时高优先级 SLO 达成仅下降 <1%，低优先级吞吐超时间共享方案 2.4x。https://arxiv.org/abs/2601.04071
- **arXiv/RLTune (2512.10271)**: 应用无关的 RL 调度框架——RL 驱动优先级 + MILP 作业-节点映射，在 Microsoft Philly/Helios/Alibaba 生产 trace 训练后无需逐作业 profiling 即可部署：GPU 利用率最高 +20%、排队延迟降 81%、JCT 缩短最多 70%；对异构 GPU 集群云平台（含国产混卡池化场景）有直接参考价值。https://arxiv.org/abs/2512.10271

## 四、追踪结论（趋势线）

- **调度研究从"利用率优化"转向"语义感知"**: 2026 上半年 arXiv 调度主线 = Agent 工作流（SAGA）、token drift（DriftSched）、确定性共享（Vitamin-E）、微秒抢占（Hummingbird）——单点吞吐优化已让位于"负载语义（Agent 链路/输出长度不确定性）+ QoS 契约"驱动的调度，与 tech 组 ViBE 的"执行时间均衡"（硬件感知）形成闭环。
- **平台商业化的两把尺子**: token 级计量（OpenCost/OpenRouter 同向）+ 容量承诺（PORTS-Pike 8 IT-GW 承购）——纯裸算力平台在价值链上面临双向挤压。
- **国产算力平台窗口**: 昇腾社区新闻页 JS 渲染无法抓取（持续观测缺口），国产智算平台动态建议改用华为云/官方公众号渠道；上游需求景气（中芯国际/光库科技）与终端平台产品化（Tau Scaling 双线布局，market 组已收）共振。
