## 🔴 核心动态

### 1. agent-substrate：K8s Agent 运行时新范式 — 6 agents 共享 1 Worker Pod

> 📄 CNCF Blog, Jul 7 · Lin Sun (Solo.io/CNCF Ambassador)

- **agent-substrate** 在 agent-sandbox 之上解决规模和效率问题
- 关键差异：
  - **agent-sandbox**: 关注安全隔离（Sandbox CRD + 强身份 + 持久存储）
  - **agent-substrate**: 关注**密度和效率** — 6个AIRE agent 映射到6个actor template，仅需1个Worker Pod执行（非并发时）
- 机制：Agent 无状态化 → 在安全 Worker Pod 中短突发执行 → 空闲时 suspend → 醒来可调度到任意 Worker
- Worker Pod 生命周期与 Agent actor 解耦（由 agent-substrate control plane 管理）
- 运行时：支持 gVisor / Kata Containers 轻量沙箱
- 与 kagent 集成：通过共享 Worker Pool 模板按需执行，无需每个 Agent 一个 Pod
- **对 AI 集群的价值**：数百个 Agent 可处于休眠状态等待调用，无需数百个常驻 Pod

> **Impact**: ⭐⭐⭐⭐⭐ — 直接解决 K8s 上大规模 Agent 部署的资源效率问题，与 Agentic AI 运维方向高度契合

### 2. CNCF Data Storage in Cloud Native AI 白皮书 — 三阶段存储模型

> 📄 CNCF Blog · TAG Infrastructure, Jul 8

CNCF TAG Infrastructure 发布 **Data On Kubernetes – Data Analytics and AI/ML Workloads** 白皮书，核心框架：

| 阶段 | 存储特征 | 关键难点 |
|:-----|:---------|:---------|
| **模型训练** | 吞吐优先，非顺序访问 | 随机数据打乱 + Checkpointing 同步写爆发 |
| **模型推理** | 延迟敏感，流量尖刺 | KV Cache / Prefix Cache 消除冗余计算 |
| **Agentic AI** | 闭环迭代推理 | Short-term memory + Artifact repos + Long-term memory 三层次 |

技术支柱：
- Data Lake House + Vector DB (Milvus) 融合
- **Fluid**（CNCF项目）分布式缓存编排
- CSI / COSI 标准化接口 + FUSE CSI Driver
- CDC + Kafka 实时流管道

> **Impact**: ⭐⭐⭐⭐ — AI 集群存储架构的权威框架参考

### 3. DRA 再深入：CEL选择器 + firstAvailable + NVIDIA GPU 驱动进 K8s SIGs

> 📄 CNCF Blog, Jul 1 · ChengHao Yang (CNCF Ambassador)

DRA GA (v1.35) 后的实战指南：
- **CEL 选择器**：用 `isGreaterThan()` 约束显存，按 GPU 型号标签筛选（`nvidia.com/gpu.product`）
- **`firstAvailable` 语义**：多级回退策略，DRA 调度器在候选资源间自动遍历
- **TimeSlicing** 原生支持（MIG 替代方案），时间片划分 GPU
- **Device Health 报告**（v1.34 起）: Pod 可获取 GPU 健康状况信号
- NVIDIA `dra-driver-nvidia-gpu` 已移入 K8s SIGs

> **Impact**: ⭐⭐⭐⭐⭐ — 从 Device Plugin 到 DRA 的 GPU 调度范式转移确认
