- **Kubernetes Blog/Headlamp 插件生态扩张**（07-13/06-25）: 新增 **Kubeflow 插件**（AI/ML 工作负载运维）、**Cluster API 插件**，Dashboard→Headlamp 迁移成官方推荐路径——K8s 官方 UI 生态向 AI 训练负载与声明式集群管理延伸。URL: https://kubernetes.io/blog/2026/07/13/introducing-headlamp-plugin-for-kubeflow/ | https://kubernetes.io/blog/2026/06/25/headlamp-cluster-api-plugin/ | https://kubernetes.io/blog/2026/07/13/kubernetes-dashboard-to-headlamp/
