## 一、AI 运维成本：遥测管线从「管道」升级为「控制层」

- **遥测管线控制 AI agent 成本：Omdia 调研量化「观测账单向 AI 投降」**（The New Stack, 2026-08-25, Apica 赞助 + Omdia/Informa TechTarget 调研 300+ 北美/西欧 IT 决策者）: ①**59% 企业已因监控成本终止或延迟 agentic AI 部署**——杀掉 AI 项目的不是工程团队而是财务（案例：某大行无法核算 AI 支出被迫取消项目）；②遥测爆炸：54% 企业过去一年遥测数据翻 3 倍，其中 43% 增长来自 AI/ML 负载（最大驱动）；平均可观测性支出 **$3.17M、年增 28%**；83% 将 AI 可观测性列为年度优先；未来两年预期遥测数据再增 **9.5X**，44% 企业预期 6X~100X；③根因=agent 任务 ≠ 应用请求：单任务产生多模型调用/检索/工具调用/重试/循环的 trace 分支，agent 委派再加分支；`tool_name/agent_id/trace_id` 高基数推高索引成本；35% 声称广泛部署 agentic AI 但近 2/3 仅「有所准备」；④解法=pipeline-first：源端采样（保留失败/重试/慢 trace，采样成功事件）、富化（agent/session/model/token/估算成本）、脱敏、按价值路由到不同成本档位的存储；**有遥测管线的企业 50% 更可能为 agentic 数据增长做好准备，成熟组织 80% 更可能避开成本危机**；68% 计划 6 个月内评估观测栈变更、近 1/4 不受现有厂商关系约束——**「观测管线=AI 运维的控制层」成为新架构共识**（标注：赞助研究，数值为供应商视角，需交叉验证）。https://thenewstack.io/agentic-ai-telemetry-costs/
- **CNCF 生态规模数据（2026-08 抓取快照）**（cncf.io 官网）: 228 个托管项目 / 329K 贡献者 / 22M 贡献 / 193 国家；成熟度分布=38 Graduated + 38 Incubating + 152 Sandbox；KubeCon + CloudNativeCon China 2026（上海 09-07~09，三会合一，已由 compute-platform 收录）——**毕业项目数（38）与孵化数（38）持平，Sandbox 池 152 个持续供血**，云原生生态的「AI 化 + 治理化」双轮仍在扩张。https://www.cncf.io/

## 二、K8s GPU 运维：DRA 从 API 规范走向运维实践

- **Say goodbye to K8s GPU pain：DRA 如何改变 GPU 调度**（The New Stack, 2026-08-06, Andela 赞助, DevOps/SRE 工程师实践视角）: 场景=平台团队管理 B200/H100/B300 混部 GPU 集群，周一早晨排队作业因落错节点 OOM，MIG 小切片耗尽而大切片闲置——传统修复是 **200 行 Bash 脚本每 30 分钟重配 MIG/重调度/发告警**；根因=K8s 把 GPU 当「相同单元」（`nvidia.com/gpu: 1` 是全部认知），调度器不知道 192GB B200 vs 80GB H100 的差异；行业旧解=node labels/taints/tolerations + 每 GPU 类型独立 node pool，**新增一代 GPU 要改 40 个 Helm charts**；MIG 加剧僵化（每个 profile 成为刚性资源类型、无回退逻辑：不能表达「先小切片、没有就中、再不行整卡」）；**v1.34 DRA 用 CEL 表达式把意图写进清单**——「H100 或更好且 ≥40GB 显存」「MIG 切片 small→medium→full 回退」「4 张 NVLink 互联 GPU（matchAttribute nvlinkDomain 约束）」；工程收益=**一个 manifest 取代 node selector + 每代重复的 job 定义**，异构集群（H100/B200/B300…）的整数调度模型正式退场（交叉引用：tech 组已收 DRA vs HAMi 生态观点与 v1.36 DRA 驱动扩张，本篇补运维实践与 CEL 语法细节）。https://thenewstack.io/kubernetes-dra-gpu-scheduling/

## 三、AI Agent 运维安全与身份（补录 3 条）

- **Securing sandboxes: AI agent 逃逸容器化后的后果**（The New Stack, 2026-08-22）: AI agent 运行沙箱（容器/VM/eBPF 隔离）的逃逸场景——agent 权限模型、工具调用边界与沙箱失效时的横向移动风险；与 tech 组已收的 K8s Agent Sandbox（官方工作负载级沙箱）形成「隔离机制（K8s 侧）+ 逃逸后果（安全侧）」互补视角；agent 时代沙箱安全的特殊点=agent 的自主决策使「逃逸后行为」不可预测，传统「隔离=安全」假设失效。https://thenewstack.io/securing-ai-agent-sandboxes/
- **VPN 遇到 200 个 AI agent：统一身份访问成为运维瓶颈**（The New Stack, 2026-07-14，08-17 因 slug 无法确认未收录、现经 API 定位补录）: 传统 VPN/身份边界按「人」设计，AI agent 集群（数百并发 agent 调用）带来身份生命周期（每 agent 一个身份？）、凭证轮换与最小权限的规模化难题——**「身份即基础设施」的 IAM×agent 运维新课题**；与 08-21 已收录的「Grok/Claude/Hermes agents 获职位+持久权限」同链：agent 身份治理进入平台工程视野。https://thenewstack.io/unified-access-ai-agents/
- **Why every AI agent decision needs a receipt**（The New Stack, 2026-07-17）: 「每个 agent 决策都需要收据」——AI agent 的决策可审计性：记录每次工具调用/模型选择的理由与上下文，作为审计追踪（receipt）而非只记结果；对运维团队=agent 事故复盘（为何 agent 做了 X）与合规取证的基础设施化，与 08-24 Atlassian RCA 自动化（tech 组已收）构成「决策前可解释 + 决策后可复盘」闭环。https://thenewstack.io/agent-evidence-packet-analytics/

## 六、今日小结

- **遥测管线是 AI 运维的「财务救生圈」**：Omdia 数据（59% 终止部署、9.5X 遥测增长、$3.17M 支出）首次把「观测成本」量化为 AI 项目生死的决定因素——**AI 运维的主战场从「采集更多」转向「源端治理更聪明」**（采样/富化/路由/脱敏），管线成为控制层而非管道；与 OpenCost token 成本追踪（tech 组）互补：一个管「数据进观测栈的成本」、一个管「GPU 算 token 的成本」。
- **DRA 完成「API → 实践」闭环**：tech 组收的 DRA 是规范/生态视角（v1.34 GA → v1.36 驱动扩张 → vs HAMi），本篇补运维落地视角（CEL 意图表达、MIG 回退、NVLink 拓扑约束、告别 40 个 Helm charts）——**异构 GPU 混部（H100/B200/B300）是 2026 年的默认形态，整数计数调度已成历史包袱**，DRA 的 CEL 选择器是平台团队的新技能点。
- **AI agent 运维三件套成型：身份 + 沙箱 + 证据**：本周三条补录（统一身份×200 agents、沙箱逃逸、决策 receipt）与已收录条目（Atlassian RCA、K8s Agent Sandbox、Grok/Claude 持久权限）拼出 agent 运维的完整框架——**身份治理（谁能以谁的身份调用）、运行时隔离（逃逸了怎么办）、决策审计（为什么这么做）**，三者都是「AI 原生运维」区别于传统 SRE 的新增维度。
