## 🔴 核心动态

### 1. HAMi 晋升 CNCF Incubating — GPU 虚拟化中间件正式化

> 📄 CNCF Blog, Jul 15 · HAMi Maintainers

**CNCF TOC 投票通过 HAMi 从 Sandbox 晋升 Incubating**，这是 2026 年至今最重要的 CNCF AI 基础设施项目进展之一。

**HAMi 是什么**：GPU 虚拟化中间件，解决「昂贵的 GPU 碎片化且利用率低下」的问题。

**核心技术能力：**

| 能力 | 说明 |
|:-----|:------|
| **GPU 分片** | 按显存/核心数/设备数将物理 GPU 切分为虚拟单元 |
| **多厂商统一接口** | NVIDIA + AMD + 昇腾NPU + DCU + MLU 等，单个一致接口 |
| **运行时硬隔离** | 共享 GPU 的 workloads 之间硬隔离（拦截原生 CUDA Driver） |
| **调度策略** | binpack / spread / topology-aware |
| **零应用侵入** | 无需修改应用代码或 K8s 资源清单 |

**架构组件：**

| 组件 | 角色 |
|:-----|:------|
| **Mutating Webhook** | 拦截 Pod 提交 → 重写调度字段和设备资源请求 |
| **Scheduler Extender** | 过滤/评分/绑定 Pod 到节点和设备 |
| **Device Plugins** | 注册加速器 + 分配分数设备资源 |
| **HAMi-Core** | 容器内虚拟化层，拦截 CUDA Driver 执行硬隔离 |
| **HAMi-WebUI** | 集群和设备管理可视化界面 |
| **Observability** | Prometheus 指标端点 + Grafana 仪表盘 |

**生态关键数据：**

| 指标 | 数值 |
|:-----|:-----|
| 贡献组织 | 550+ |
| GitHub Stars | ≈3,500 |
| Forks | 550+ |

**CNCF 生态集成**：
- ✅ Volcano（批调度）
- ✅ Koordinator（GPU 共享工作流）
- 🔄 Kueue（规划中）

## 🟡 重要动态

### 3. HAMi vs DRA: GPU 调度的两条路径

结合本期 HAMi Incubating + 上周 DRA 内容，GPU 调度在 K8s 上已形成两条并行路径：

| 维度 | HAMi（虚拟化中间件） | DRA（原生资源分配） |
|:-----|:--------------------|:--------------------|
| **抽象层次** | 用户态虚拟化层（拦截 CUDA） | K8s 原生 API（ResourceClass + CEL） |
| **GPU 分片** | ✅ 内存/核心/设备数 | ❌ 无分片（全设备分配） |
| **多厂商** | ✅ NVIDIA + AMD + NPU/DCU/MLU | ⚠️ NVIDIA 驱动已进入 SIG |
| **硬隔离** | ✅ CUDA driver 拦截 | ❌ 无（依赖硬件 MIG） |
| **应用侵入** | 零侵入 | 需声明 DRA resources |
| **成熟度** | Incubating（v2.9.0） | GA（v1.35） |
| **生态** | Volcano/Koordinator/Kueue | 原生 HPA/Scheduler |

**趋势判断**：两者互补而非替代。HAMi 解决「碎片化 + 多厂商」的实用主义问题，DRA 解决「原生 GPU 资源管理」的标准化问题。大规模集群可能同时使用（DRA 做资源发现 + HAMi 做资源隔离/分片）
