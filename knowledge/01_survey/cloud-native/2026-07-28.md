## 🔴 高价值条目

### 1. Confidential Containers → CNCF Incubating
- **来源**: [CNCF Blog](https://www.cncf.io/blog/2026/07/22/confidential-containers-becomes-a-cncf-incubating-project/) (Jul 22)
- **要点**: CNCF TOC 投票通过 Confidential Containers (CoCo) 晋升 Incubating
- **技术价值**: 解决云原生环境中**数据使用中保护**（data-in-use protection）——以可信执行环境（TEE）为基础，保护内存中数据不被主机/平台管理员/云服务商访问
- **AI 关联**: 多租户 GPU 集群中训练数据/模型权重的机密性保护，与 GPUs in use 机密计算配合使用
- **架构组件**: 集成 Kata Containers + TEE（Intel TDX/AMD SEV-SNP/Intel SGX）+ KBS（密钥代理服务），构成云原生机密计算全栈
- **成熟度**: 已有多个生产部署案例，社区贡献活跃

### 2. Federating clusters for zero-downtime Kubernetes
- **来源**: [CNCF Blog](https://www.cncf.io/blog/2026/07/27/federating-clusters-for-zero-downtime-kubernetes/) (Jul 27) — Dominik Táskai, CNCF Ambassador & Linkerd Contributor
- **要点**: 多区域集群联邦实现零停机架构
- **核心洞察**: 多区域部署的共同痛点——一个集群挂了，另一区域的相同服务副本"形同虚设"，因为没有跨区域流量路由的机制
- **架构方案**: Linkerd + Service Mirroring 跨集群联邦，实现：
  - 跨集群服务发现与流量切换
  - 区域故障自动摘除
  - 灰度发布跨集群
- **适用场景**: 生产级多 Region 部署、跨 AZ 容灾、全球多活
- **与 KubeCon Japan 2026 关联**: 作者将在此次 KubeCon 做相关分享

### 3. Platform engineering for the agentic enterprise
- **来源**: [CNCF Blog](https://www.cncf.io/blog/2026/07/21/platform-engineering-for-the-agentic-enterprise-managing-applications-resources-and-ai-agents/) (Jul 21) — WSO2
- **要点**: Agent 时代平台工程的演进——从管理微服务到管理 AI Agent
- **核心洞察**:
  - 平台工程的核心任务从「抽象基础设施复杂性」扩展到「抽象 Agent 编排复杂性」

- **架构演进**: K8s + Backstage + Crossplane/Crossplane Compositions 组合

## 🟡 中等价值条目

### 4. Why goodput matters more than throughput for LLM serving
- **来源**: [CNCF Blog](https://www.cncf.io/blog/2026/07/20/why-goodput-matters-more-than-throughput-for-llm-serving/) (Jul 20) — Akamas
- **要点**: LLM serving 中 goodput（有效吞吐）比 raw throughput 更有实际意义
- **关键指标**:
  - Throughput（原始吞吐）: 每秒请求数 — 容易通过降低精度/缩短输出长度来提升
  - Goodput（有效吞吐）: 满足 SLO 的每秒请求数 — 包含首 token 延迟、token 间延迟、回答质量约束
  - Goodput ratio = Goodput / Throughput — LLM serving 真实效率衡量
- **运维影响**: 优化方向应从「推高吞吐」转向「在满足 SLO 前提下最大化 goodput」

### 5. Multi-Cluster databases on Kubernetes
- **来源**: [CNCF Blog](https://www.cncf.io/blog/2026/07/22/multi-cluster-databases-on-kubernetes-architecture-and-deployment/) (Jul 22)

- **架构**: 基于 K8s Operator（Percona for MongoDB）实现跨 K8s 集群的数据库联邦

### 6. I made a policy engine think it was in production
