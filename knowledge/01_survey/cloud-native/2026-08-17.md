## Kubernetes 平台演进

- **K8s/Gateway API v1.6.0 发布：TCPRoute 与 UDPRoute 毕业至 Standard**（08-03）: v1.6.0 于 6/30 正式发布，SIG Network 博客确认 TCP/UDP 四层路由能力成为标准 API——服务网格/Ingress 之外的第四层流量治理（数据库、消息队列、gRPC 长连接等非 HTTP 场景）获得官方稳定层，Gateway API 从 HTTP 七层主战场向 L4 全域覆盖扩展，是 K8s 流量 API 标准化的关键里程碑。https://kubernetes.io/blog/2026/08/03/gateway-api-v1-6-release/
- **K8s/v1.37 Sneak Peek：发布前弃用与移除预告**（07-31）: v1.37（预计 8 月底发布，上版本 v1.36 Haru 于 4 月 22 日发布）官方预告计划中的 API 弃用/移除/替换——SELinux Volume Label 变更的 v1.37 影响（04-22 曾预告 breaking changes）与若干旧特性退役列入窗口；版本节奏维持 4 个月/版，升级路径规划需在 8 月底前完成兼容性评估。https://kubernetes.io/blog/2026/07/31/kubernetes-v1-37-sneak-peek/
- **K8s/KYAML 工具：Kubernetes YAML 美化打印标准方案**（08-11）: 面向"YAML 选择过多导致配置碎片化"痛点推出 KYAML——统一格式化的 pretty-print 工具，减少 CI 中 YAML diff 噪声与人工排版差异；反映 K8s 配置工程化从"能写"走向"规范写"的工具链补位。https://kubernetes.io/blog/2026/08/11/how-to-pretty-print-kubernetes-yaml-as-kyaml/
- **K8s/controller-runtime Cache 深度解析：控制器为何不压垮 API Server**（07-29，修订版）: Ænix 团队详解 client-go/controller-runtime 缓存机制（informer watch/本地 store/双副本一致性）——控制器负载均衡依赖缓存命中率设计，原文因多处技术错误修订重发，是 K8s 控制器开发者的权威原理文。https://kubernetes.io/blog/2026/07/29/controller-runtime-cache-explained/
- **K8s/自定义指标导出器构建指南**（07-14）: 内置 CPU/内存之外的自定义指标（队列深度、批处理时长、外部信号）接入 HPA 的实操路径——规模化扩缩容决策依赖外部信号，Kubernetes 指标生态向业务级信号扩展。https://kubernetes.io/blog/2026/07/14/custom-metrics-exporter-kubernetes/
- **K8s/AI Gateway 工作组正式成立**（03-09，补录）: AI Gateway（面向 LLM 流量治理的 API 网关层：路由/限流/成本控制/可观测）成为官方工作组的早期信号——K8s 作为 AI 基础设施的流量治理层开始标准化，与后续 Gateway API Inference Extension 一脉相承。https://kubernetes.io/blog/2026/03/09/announcing-ai-gateway-wg/
- **K8s/未修复 CVE 记录校正：Reconciling the Past**（05-26，补录）: 官方对历史未修复 Kubernetes CVE 记录做系统性修正（区分"已修复未标注"与"真未修复"）——供应链合规审计视角下 CVE 记录准确性成为安全运营前置条件。https://kubernetes.io/blog/2026/05/26/reconciling-unfixed-kubernetes-cves/

## 云原生运维与平台工程

- **TNS/容器镜像未签名：AI 时代"定时炸弹"**（08-14）: 供应链安全视角警示——大量容器镜像未签名，AI 时代镜像消费量激增放大投毒面；镜像签名/验证（cosign 类工具）从"最佳实践"升级为"生产必选项"，与 NRI 运行时供应链验证（CNCF 07-30）同窗口共振。https://thenewstack.io/unsigned-container-images-ai/
- **AWS/EKS 镜像秒级拉取：多 GB 镜像分发加速**（08-10）: EKS 通过分层预取/并发拉取/缓存亲和等手段将多 GB 镜像拉取压至秒级——AI 工作负载镜像普遍 5-20GB，节点扩容/滚动发布等待镜像成为集群效率瓶颈，镜像分发是 AI 原生运维的核心优化面（与 CNCF Dragonfly P2P 方案互补）。https://thenewstack.io/accelerating-eks-image-pulls/
- **AWS/EKS 集群生命周期：升级不再破坏业务**（08-01）: EKS 简化集群升级流程（升级前检查/自动回滚/分阶段滚动），目标"更简单更安全"的集群生命周期管理——大规模 K8s 升级仍是运维事故高发点，托管平台把升级安全性产品化。https://thenewstack.io/eks-kubernetes-upgrade-rollback/
- **TNS/大规模控制器运维经验：从意图到执行**（07-17）: 生产级 Kubernetes 控制器运维实践（reconcile 循环设计/背压/重试语义）——控制器大规模运行时的"意图-执行"差距是平台稳定性关键，操作 K8s 控制面的经验沉淀。https://thenewstack.io/kubernetes-controllers-at-scale/
- **CNCF/Kairos 自愈升级流水线：11 分钟零人工**（08-14）: Kairos（K8s 发行版）构建自愈 Kubernetes 升级流水线——无人值守完成节点升级+健康自愈，量化指标"11 分钟零人工"；边缘/远程集群升级自动化的可复现样板，运维人力成本与升级窗口风险的直接削减。https://www.cncf.io/blog/2026/08/14/eleven-minutes-zero-humans-building-a-self-healing-kubernetes-upgrade-pipeline-on-kairos/
- **CNCF/Dragonfly 轻量部署：P2P 分发免数据库栈**（08-13）: Dragonfly（CNCF 孵化，镜像 P2P 分发）推出无数据库栈的轻量部署模式——移除 etcd/Redis 依赖后单机/边缘场景落地门槛下降，P2P 镜像分发从"集群级基建"走向"轻量可选件"。https://www.cncf.io/blog/2026/08/13/lightweight-dragonfly-deployment-p2p-distribution-without-the-database-stack/
- **CNCF/健康检查反模式：误唤醒服务的修复**（07-29）: K8s 健康检查（liveness/readiness）配置不当会在空闲时"意外唤醒"服务（持续探测导致常驻进程/计费/缓存失效）——健康检查语义选择（liveness vs readiness）与探测频率的工程权衡成运维常见坑。https://www.cncf.io/blog/2026/07/29/your-kubernetes-health-checks-are-accidentally-waking-your-services-heres-the-fix/
- **CNCF/KEDA + SQS 队列深度扩缩容实践**（07-31）: KEDA 基于 Amazon SQS 队列深度做 Pod 扩缩容的官方实践——事件驱动自动扩缩（EDA）的队列指标绑定成为标准模式，消息积压驱动弹性成为事件型工作负载主流。https://www.cncf.io/blog/2026/07/31/scaling-kubernetes-pods-with-keda-based-on-amazon-sqs-queue-depth/
- **CNCF/Shadow AI 威胁建模：从开发者笔记本到 K8s**（08-07）: CI/CD 流水线中的影子 AI（未受管 AI 工具）威胁建模——AI 生成的代码/依赖进入 K8s 生产链路的供应链风险面扩展，DevSecOps 覆盖 AI 生成物成为新合规课题。https://www.cncf.io/blog/2026/08/07/shadow-ai-in-ci-cd-threat-modeling-the-path-from-developer-laptop-to-kubernetes/
- **CNCF/NRI 运行时供应链验证**（07-30）: Node Resource Interface（NRI）用于运行时供应链验证——在容器运行时层校验镜像来源/签名/策略，供应链安全从"构建时"下沉到"运行时"边界。https://www.cncf.io/blog/2026/07/30/runtime-supply-chain-verification-using-the-node-resource-interface-nri/
