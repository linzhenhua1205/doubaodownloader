## 2️⃣ 🟡 OpenTelemetry 毕业后的四大演进方向

**来源**: [CNCF Blog Jul 24 | OpenTelemetry has graduated… Now what?](https://www.cncf.io/blog/2026/07/24/opentelemetry-has-graduated-now-what/) · CNCF

**状态**: OTel 毕业后的路线图展望文章，定方向而非定细节

### 核心方向

| 方向 | 说明 |
|:-----|:------|
| **1. 声明式配置稳定化** | OTel Collector 的声明式配置（declarative config）从 Alpha 向 Stable 推进，降低运维心智负担 |
| **2. Profiling Alpha** | OTel Profiling 信号进入 Alpha 阶段，补齐「Metrics + Traces + Logs + Profiling」四支柱 |
| **3. CI-CD 可观测性** | 将 OTel 嵌入 CI/CD 管线，实现从构建到部署的全链路可观测 |
| **4. Agent 追踪** | 分布式 Agent 工作流的追踪能力，适配 Agent 化基础设施趋势 |

### 持续关注

> OTel 毕业后的核心张力：**标准化 vs 锁定**。主流 APM 厂商（Datadog/New Relic/Splunk）已内置 OTel 支持，但衍生产品可能引向商业锁定。OTel 社区需警惕「标准化外壳 + 厂商内核」的风险。
