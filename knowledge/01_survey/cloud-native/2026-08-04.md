## 一、🔴 K8s 官方：Gateway API v1.6 发布（核心增量）

- **Gateway API v1.6 官方博客（08-03, Beka Modebadze/Google, Ricardo Katz/Red Hat）**: SIG Network 宣布 Gateway API v1.6.0（6/30 发布）——**TCPRoute 与 UDPRoute 正式毕业到 Standard（GA，v1 API）**，v1alpha2 版本弃用、未来移除。至此 Gateway API 覆盖从 L7（HTTPRoute/GRPCRoute）到 L4（TCP/UDP）的**全协议栈服务路由**，成为现代、面向角色、表达力强的服务网络标准。Ingress 迁移至 Gateway API 的最后一个技术理由消失。
  https://kubernetes.io/blog/2026/08/03/gateway-api-v1-6-tcproute-and-udproute-graduate-to-standard/

- **Gateway API v1.6.0 Release Notes（06-29, GitHub 一手源）**: 除 TCPRoute/UDPRoute GA 外，本版关键变更：① HTTPRoute retries 校验收紧——`retry.codes` 必须唯一、`retry.attempts` 必须 ≥1；② TLSRoute 允许的 **CA 引用数量 8→16**；③ TLSRoute CRD 校验调整为**单资源最多 1024 个 hostnames/rules**；④ **Breaking Change**（rc.2 引入）：HTTPS 协议的 listener 现在**必须显式配置 TLS**，未配置将拒绝——存量 Gateway 升级需逐项检查。
  https://github.com/kubernetes-sigs/gateway-api/releases/tag/v1.6.0

- **Gateway API v1.6.1 patch（07-16, GitHub 一手源）**: 修复 TCPRoute/UDPRoute 多路由附加（MultipleRoutesAttachment）的 conformance 测试超时与权重路由 flake；`GatewayStaticAddresses`/`GatewayInfrastructure` 测试改为轮询状态而非假设原子可见。v1.6 系列稳定性补丁，生产采纳无阻塞项。
  https://github.com/kubernetes-sigs/gateway-api/releases/tag/v1.6.1

- **运维影响判断（分析）**: ① L4 路由 GA 意味着**非 HTTP 协议（数据库/消息队列/专有 TCP）的南北向流量可纳入 Gateway API 统一声明式管理**，无需再依赖 LoadBalancer Service 直通或自定义 Ingress Controller 扩展；② HTTPS listener 强制 TLS 校验 + retry 参数收紧是**配置面"默认安全"**延续，升级 v1.6 需纳入变更管理清单；③ v1alpha2→v1 迁移窗口已开启，存量 TCPRoute/UDPRoute 用户应规划 API 版本升级。
