## 今日焦点: Kioxia CM10 领衔 PCIe Gen6 企业 SSD 新一波

### 1. 🚀 Kioxia CM10 Series — PCIe Gen6 + 直接液冷 (08-01)

**来源**: ServeTheHome — https://www.servethehome.com/kioxia-cm10-series-launched-for-the-pcie-gen6-generation-of-ssds/

FMS 2026 前发布，Kioxia 正式进入 PCIe 6.0 企业存储：

| 维度 | 详情 |
|:-----|:-----|
| **NAND** | BiCS FLASH **第10代 (Gen10)** — EDSFF 形态 |
| **性能** | vs CM9: 顺序读 **+92%**、随机读 **+85%** |
| **目标负载** | AI KV cache 工作负载 + **NVIDIA CMX** 上下文内存方案 |
| **形态** | E3.S 7.5mm / E1.S 9.5mm·15mm；**9.5mm 变体支持直接冷板液冷 (DLC)**；E3.S 双端口 (HA) |
| **兼容** | 全形态仍兼容传统风冷环境 |

**关键洞察 — 形态分裂信号** 📌:
- 2.5" 变体 (CM6, 15mm, 双端口) 仅用 **BiCS Gen8 TLC + PCIe 5.0**，而非 Gen10 + PCIe 6.0
- 印证 STH 长期预判: **U.2/U.3 传统形态开始让位 EDSFF**——PCIe Gen6 电气要求 (信号完整性/散热) 已超出 2.5" 承载能力
- 同一产品族内双代际 (Gen6+Gen10 / Gen5+Gen8) 并行: 液冷新部署用 EDSFF，存量风冷用 2.5"
- 定位: AI 存储 tier 的 **ephemeral KV cache**，延迟介于 GPU HBM 与网络存储之间

### 2. 🔄 PCIe Gen6 与 Gen5 在 AI 存储中并存 (07-31)

**来源**: ServeTheHome (Patrick Kennedy) — https://www.servethehome.com/pcie-gen6-and-gen5-will-both-matter-for-ai-storage/

**过渡期判断**: 2026 H2 开启 PCIe Gen6 服务器换代，但 **Gen5 存储仍将重要**（预算约束 + 供应链受限时代），这是自 AMD EPYC 9004 Genoa (2022) 以来首次 PCIe 代际切换。

- **新 CPU 家族**: AMD EPYC Venice · NVIDIA Vera · Arm AGI CPU · Intel Xeon 7 Diamond Rapids (2027E)
- **结构性变化**: 上次 Gen5 过渡时无 10 万 GPU 集群；如今推理已成主导负载，存储分层: 训练高容量闪存 / GPU 节点高性能低容量 / KV cache 共享存储 / agentic AI
- **量化对比**: 1 块 2026 PCIe Gen6 SSD ≈ **8 块 2021 早期 PCIe Gen3 SSD** 的吞吐
- **网络联动**: 单 PCIe Gen6 x16 = **800 Gbps** ≈ 32 块 Gen3 SSD (128 lanes) 的吞吐；现代服务器 8-10 条此类链路；单 GPU 可用 800Gbps–1.2Tbps
- **NVIDIA CMX (Context Memory eXtension)**: 把 KV cache 数据移出昂贵 HBM、跨机器边界共享，成 Gen6 存储头号驱动场景

**Silicon Motion SM8466 (PCIe Gen6 控制器)**:
- >28 GB/s 顺序读 · **>7M 随机 IOPS**（约为 Gen5 SM8366 的 **2×**）
- 明确瞄准 NVIDIA CMX / KV-cache 扩展场景
- 支持 SR-IOV、Multi-PF 隔离、NVMe 2.0 FDP (Flexible Data Placement)

### 5. 🧭 对服务器研发的启示

1. **KV cache 成为存储新分层支点**: 从 GPU HBM → CMX/闪存 → 网络存储的延迟梯度正在固化，PCIe Gen6 + EDSFF 液冷是承载层标配
2. **2.5"→EDSFF 迁移加速**: 选型时优先评估 E1.S/E3.S 液冷兼容性，U.2 只留存量兼容
3. **内存成本进入卖方市场**: LTA 长协 (SK hynix 10 项 / Kioxia 50% 目标) + ASP 驱动复苏 → 服务器 BOM 内存/闪存占比将持续抬升，需提前锁定供应
4. **液冷从可选变必选**: Kioxia CM10 9.5mm DLC、Micron 9650 E1.S 强制液冷，全液冷机柜形态渗透不可逆
