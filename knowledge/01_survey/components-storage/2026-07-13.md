## 一、🔴 控制器与新工艺

### 1.1  Phison 1H26 营收首破 NT$100B，AI 订单延伸至 1H27

**来源**: DIGITIMES (Siu Han) · 2026-07-09
**链接**: https://www.digitimes.com/news/a20260709PD230.html (付费墙)

**核心数据**:
| 指标 | 数值 | 意义 |
|:-----|:-----|:------|
| 1H26 合并营收 | **NT$100B+ (US$3.1B)** | 首次突破千亿新台币 |
| 6月控制器出货量 | **YoY +47%** | 虽处全球短缺仍大幅增长 |
| AI 订单能见度 | 延伸至 **1H27** | 下单排期 >12 个月 |
| 营收占比 | >80% 来自"高价值"市场 | 服务器/汽车/AI 存储 |

**技术细节**:
- Phison 不仅是 NAND 控制器独立供应商，更是行业最大 IP 提供者
- 长期战略伙伴覆盖 **Kioxia / Micron / Sandisk / Samsung / SK hynix / YMTC**
- 企业级 Pascari 系列已推进至超大规模，**D206V 达 245.76TB** 单盘 U.2 PCIe Gen5
- 控制器端创新对容量扩展的重要性已"与 NAND 裸片本身同等重要"（StorageNewsletter 评论）

**行业信号**: 控制器产能是 NAND 供应的另一瓶颈节点，AI 订单排至 1H27 意味着存储超级周期至少持续至 2027 年中期。

## 二、🔴 系统级存储架构

### 2.1  DDN Infinia 2.4 + KV Cache 加速引擎

**来源**: StorageNewsletter (RAISE Summit 2026) · 2026-07-09
**链接**: https://www.storagenewsletter.com/2026/07/09/raise-summit-2026-ddn-unveils-infinia-2-4/

**KV Cache 加速性能数据**:
| 指标 | 数值 | 对照基准 |
|:-----|:-----|:---------|
| 推理速度 | **18× 更快** | 无 KV Cache 架构 |
| Token 响应 | **~10× 更快** | 同类替代方案 |
| GPU 利用率 | **99%** | 行业标杆 |
| Cost-per-token | **降低 75%** | 传统架构 |
| RAG 查询 | **22× 快于 AWS Express** | Amazon S3 Express One Zone |
| Time-to-value | **加速 25×** | — |

**Infinia 2.4 关键新能力**:
- 企业级多租户 + 身份管理 + 配额控制 + 安全隔离
- **POSIX 支持进入 Limited Availability**（RHEL/Ubuntu 客户端）
- 全兼容 S3 生态，无中断迁移
- 目标：将 AI 基础设施从"GPU 数量竞赛"转向"每 token 成本优化"

**生态合作**:
- 与 **Nebul**（欧洲主权云）和 **NVIDIA** 联合验证
- 已服务超过 **100 万 GPU** 全球部署
- 客户包括 NVIDIA / xAI / Salesforce / Mistral / SK Telecom / Yotta / TotalEnergies

**行业信号**: 数据基础设施正从"存储层"进化为 **AI 执行的主动参与者**。分布式 KV Cache 服务可能成为下一代 AI 工厂的标准组件。

## 三、🟡 NAND 闪存进展

### 3.1  Sandisk BiCS10 1Tb TLC 正式向客户送样

**来源**: StorageNewsletter (Sandisk Press Release) · 2026-07-08
**链接**: https://www.storagenewsletter.com/2026/07/08/sandisk-announces-sampling-of-bics10-1tb-tlc-3d-nand-flash-memory/

**详细技术规格**:
| 参数 | BiCS10 | BiCS8 | 改进 |
|:-----|:-------|:------|:----:|
| 层数 | **332 层** | 218 层 | +52% |
| 面密度 | **>29 Gb/mm²** | 约 18.2 Gb/mm² | **+59%** |
| 接口速度 | **4.8 Gb/s** (Toggle DDR6.0) | 3.6 Gb/s | **+33%** |
| 输入功耗 | 降低 **10%** | 基线 | — |
| 输出功耗 | 降低 **34%** | 基线 | — |
| 架构 | CBA (CMOS+Bonded Array) | CBA | 同架构 |
| 状态 | **送样** | 量产 | — |
| 容量/TLC 裸片 | **1Tb** | — | — |

**关键技术特征**:
- **Lateral Scaling**（横向微缩）是 BiCS10 的核心密度驱动——不仅仅是增加层数，而是通过孔径收缩和阵列效率优化来提高密度
- **SCA (Shared Command Address)** 协议 + **PI-LTT (Power-Isolated Low-Toggle Technology)** 贡献高速低功耗

**竞争格局**（Q1 2026 NAND 市场份额）:
| 厂商 | 份额 | 关键动向 |
|:-----|:----:|:---------|
| Samsung | **~29%** | 加速 QLC V9 (286层) 投资 |
| SK hynix/Solidigm | **~18%** | 321层 QLC 2026H2 发货 |
| Kioxia | **~14%** | 市值突破 ¥10T，目标重夺 #1 |
| Micron | **~13%** | 日本/新加坡扩产追赶 |
| Sandisk | **~13%** | 独立 + BiCS10 送样 |
| YMTC | **~13%** | 进入 Lenovo/Asus 供应链 |

**市场背景**: NAND 合约价 Q2 预计 **QoQ +70~75%**（10 年来最严重短缺），新产能预计 2027 年底前无法形成规模。

1. **存储超级周期仍在加速** — Phison 1H26 NT$100B 营收 + AI 订单看到 1H27 + Samsung/SK 联合投资 $518B + NAND 合约价 +70~75%，所有信号高度一致
