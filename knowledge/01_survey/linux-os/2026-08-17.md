## 内核发布

- **LWN/Linux 内核 7.2 正式发布**（08-16）: Linus Torvalds 宣布 7.2 发布，称最后一周改动"比预期更大"但未再推迟。显著特性：bpf() 系统调用 common attributes 支持、CPU 调度器 cache-aware load balancing、Btrfs 大 folio、swap 子系统进一步改进、Landlock 安全模块改进、dm-inlinecrypt 设备映射目标等。来源: https://lwn.net/
- **KernelNewbies/Linux 7.2 changelog——cache-aware 任务调度**（08-16）: 调度器新增缓存感知负载均衡，将共享数据的任务（如同一进程的线程）共置于同一 Last Level Cache（LLC）域内，降低 cache bouncing 与 miss，提升数据访问效率；同时新增 sched_ext 拓扑 CPU ID（cids，拓扑有序稠密编号）基础设施，为 sub-schedulers 引入做准备。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——Fair(er) GPU 调度器**（08-16）: DRM GPU scheduler 借鉴 CFS 思想重写，替换原 FIFO 算法，改善重 GPU 负载下交互客户端公平性与延迟，未发现相对 FIFO 的调度回归。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——MGLRU 回收循环优化**（08-16）: 清理并改进 MGLRU 回收循环与 dirty writeback 处理，MongoDB+YCSB 等工作负载性能最高提升 ~30%，文件 refault 大幅下降（无 swap 参与），LOC 减少且意外 OOM 更少，其他常见基准无回归。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——Swap table phase IV**（08-16）: 统一 anon/shmem swap 在 folio 中的分配与计费，合并元数据管理（移除静态数组与 map），静态元数据开销趋近于零——挂载 1TB swap 设备约节省 512MB 内存。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——USB4STREAM 数据流传输**（08-16）: 在 Thunderbolt networking 之外新增 USB4 线缆直传数据流，暴露 /dev/tbstreamX 设备，可用 read(2)/write(2) 常规文件操作传输，与 thunderbolt_net 可并存。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——Btrfs 大 folio 默认启用**（08-16）: 大 folio（6.17 起实验）转默认且无特性限制；新增 2MB huge folio 实验支持、GET_CSUMS ioctl（原始校验和，可用于 mkfs/去重优化）；DIO 不再强制串行化（吞吐 ~59% 提升）、顺序写性能提升 15%。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——dm-inlinecrypt 内联块设备加密**（08-16）: 新 dm target 支持内联块设备加密，基于 Android dm-default-key 工作，定位为 dm-crypt 的实用替代（不做 passthrough），并支持 hardware-wrapped keys。来源: https://kernelnewbies.org/Linux_7.2
- **KernelNewbies/Linux 7.2——openat(2) 扩展与 procfs 加速**（08-16）: 新增 OPENAT2_REGULAR 标志（拒绝打开非常规文件，防服务被重定向到 fifo/设备节点）与 O_EMPTYPATH（空路径重开 fd）；优化 /proc/filesystems（libselinux 频繁读取）与 /proc/interrupts 生成性能。来源: https://kernelnewbies.org/Linux_7.2

## 架构与虚拟化

- **LWN/Arm 128-bit page tables**（08-13）: Anshuman Khandual patch set 为 Arm 增加 128-bit PTE 支持——64 位时代 56 位物理地址（72PB）看似已无限制，但 Arm 架构仍在演进更大 PTE，实际受益场景尚不明确（面向更大物理内存寻址与元数据扩展）。来源: https://lwn.net/
- **LWN/KVM planes 起飞**（08-11）: Jörg Rödel、Paolo Bonzini 等开发的 KVM planes 为 Linux 提供多安全域虚拟化抽象层——CPU/软件厂商各自实现（方案各异），KVM planes 尝试统一为 Linux 可用抽象，任务量不小。来源: https://lwn.net/
- **LWN/内核 7.2 虚拟化与安全相关**（08-16 窗口）: KVM 合入 MBEC/GMET 支持（PTE 中 supervisor/user 模式执行位更细粒度分离）、TDX 模块运行时更新；Landlock 新增 UDP bind/connect/send 控制权限与 LANDLOCK_ADD_RULE_QUIET；integrity 增加 ML-DSA 签名（EVM/IMA）。来源: https://lwn.net/

## BPF 与安全

- **LWN/BPF 持续集成与稳定内核测试**（08-14）: 2026 Linux Storage/Filesystem/MM/BPF Summit 上 Ihor Solodrai 与 Shung-Hsi Yu 总结 BPF CI 现状——CI 测试状态良好，但仍有多条路径可提升稳定内核 BPF 更新测试覆盖。来源: https://lwn.net/
- **LWN/BPF 更多形式化验证**（08-10）: Kumar Kartikeya Dwivedi 在峰会讨论为 BPF 程序增加域特定不变量（domain-specific invariants）的可能性——不指向具体内核特性实现，而是概述为何需要更多形式化验证及如何与现有 BPF 生态协同。来源: https://lwn.net/
- **LWN/BPF 引入 binfmt_misc**（08-06）: binfmt_misc 多年相对静态，即将获得重大更新——支持加载 BPF 程序来决定如何运行给定程序（透明执行任意格式）。来源: https://lwn.net/
- **LWN/rsync 3.5.0 发布——33 个安全修复**（08-13）: 集中审计路径处理与 daemon 协议后修复 33 个安全问题（CVE 由 VulnCheck 分配），每个修复附带精确"引入版本"范围与回归测试；另有 companion daemon-protocol fuzzing 加固。来源: https://lwn.net/
- **LWN/QEMU 11.1 发布**（08-12）: 超过 3,200 个 commit、285 位作者，改进列表见公告与 changelog——虚拟化模拟器主线持续活跃。来源: https://lwn.net/
