## 🔴 新文章补录（深度技术）

- **LWN/Bringing BPF to binfmt_misc**（2026-08-06, corbet）: 内核执行文件机制 **binfmt_misc**（可配置用户空间执行任意格式程序，多年未大改）将获重大更新——**支持加载 BPF 程序来决定如何运行给定程序**。这是 binfmt_misc 从静态配置走向可编程决策的演进，对容器/沙箱/自定义二进制格式处理有潜在影响。来源: https://lwn.net/
- **LWN/Examining other network namespaces using BPF**（2026-08-05, daroc）: Jordan Rife（Cilium BPF 开发者）希望在 **LSFMM+BPF 峰会**推动 BPF 程序可遍历**其他网络命名空间**的 socket——BPF 开发者现场提出多个替代方案。当前 BPF 程序受命名空间隔离限制，此改动影响 K8s 网络观测能力边界。来源: https://lwn.net/
- **LWN/FUSE status and plans**（2026-08-05, jake）: FUSE 维护者 Miklos Szeredi 在 LSFMM+BPF 峰会 BoF 讨论——维护挑战、提议功能状态，及**新 FUSE API 规划**。FUSE 社区活跃度显著上升（io_uring buffer 优化同期讨论）。来源: https://lwn.net/
- **LWN/The beginning of a process-builder API**（2026-08-04, corbet）: Li Chen 回应用户态进程创建范式讨论——patch 系列展示 **process-builder API**（类 posix_spawn 替代 fork/exec 模式，从裸配置组装进程避免复制父进程）。值得注意：**该 patch 系列由 LLM 大量辅助编写**——内核补丁 AI 辅助创作进入实质案例阶段。来源: https://lwn.net/

## 🟢 生态与工具链补录

- **LWN/Rust Coreutils 0.10 released**（2026-08-06）: uutils Rust Coreutils 发布 **0.10**——GNU Coreutils 兼容测试通过数 **645/690（0.9.0 为 625）**。新增 `mv --exchange`、校验工具 OpenSSL 后端、mkdir/mkfifo/mknod 创建时应用 SELinux 标签、性能与安全改进；提供 **WASM 浏览器在线 playground**。Rust 化 GNU 工具链进度再进一步（与本周 BPF libraries Rust 生态讨论呼应）。来源: https://lwn.net/
- **LWN/b4 0.16.0 released**（2026-08-05, corbet）: Konstantin Ryabitsev 发布内核开发工具 b4 **0.16.0**——最大变化：新增 **`b4 bugs` 命令集成 git-bug**，bug 报告以 git 对象存储于仓库内，随代码 git push/pull 传播，无需外部服务。另有 b4 review 大量改进、b4 shazam 冲突解决增强、历史重写改进。内核工作流工具链持续演进。来源: https://lwn.net/
- **LWN/Fedora considers conflict-of-interest policy**（2026-08-04, jzb）: Fedora Council 审议 **COI（利益冲突）政策**草案，适用 FESCo/SIGs 等决策机构；公开讨论自 7/23 开始接近尾声，**8/13 理事会会议再议**。治理制度化细节（草案暂不适用于理事会自身）。来源: https://lwn.net/
