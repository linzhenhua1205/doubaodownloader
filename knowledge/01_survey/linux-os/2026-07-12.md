### 1️⃣ OpenShift 4.22 可观测性细节补全（之前报告未覆盖项）

**来源**: Red Hat Blog (Jul 10, Herlofsson/Florén/Parker/Martini/Evans)

之前报告已记录 Perses GA 和 OTLP 日志管道，以下为**此前未覆盖**的关键细节：

#### 🔍 Perses 仪表板 — 核心能力

| 能力 | 说明 |
|:-----|:------|
| **原生部署** | COO 1.5 元操作符统一管理生命周期 |
| **多集群视图** | 通过 ACM 集成实现跨集群仪表板可见性 |
| **RBAC 对齐** | 与 OpenShift RBAC 整合，细粒度访问控制 |
| **GitOps 友好** | 仪表板定义为 YAML → Git 存储 → CI/CD 自动部署 |
| **后端兼容** | 同时支持 Prometheus 和 Thanos 数据源 |

#### 🔍 监控栈组件升级 (4.21→4.22)

| 组件 | 4.21 | 4.22 | 变化要点 |
|:-----|:----:|:----:|:---------|
| Prometheus Operator | 0.87.1 | 0.90.1 | 安全/稳定更新 |
| Prometheus | 3.7.3 | 3.9.1 | 性能改进 |
| Kube-state-metrics | 2.17.0 | 2.18.0 | EndpointSlice 指标默认暴露 |
| Thanos | 0.39.2 | 0.41.0 | 安全/稳定更新 |
| Alertmanager | 0.29.0 | 0.31.1 | 重大版本跳跃 |
| Metrics Server | 0.8.0 | 0.8.1 | 客户端证书独立化 |

- **监控健康信号修复**: 修复了升级期间/API 限流/etcd 切换导致的误报 degraded/unavailable 状态
- **可选 ethtool 采集器**: node-exporter 新增 ethtool collector 配置入口（默认关闭，管理员可选启用）
- **EndpointSlice 迁移**: CMO/kube-prometheus/平台 Operator 全面向 EndpointSlice 迁移，降低 kube-state-metrics 废弃噪声

#### 🔍 OpenTelemetry 组件 GA

四个组件正式 GA：

1. **Probabilistic Sampler** — 按百分比采样，确定性决策保证同一 trace 采样一致性；节省存储+计算成本
2. **Tail-based Sampler** — 请求结束后评估是否保留 trace，利用完整上下文做高精度过滤
3. **Kubernetes Objects Receiver** — 采集 K8s API 原始数据，导出为 OTLP 格式日志；适合追踪 K8s 对象状态变化和 events
4. **PrometheusRemoteWrite Exporter** — 将采集的 metrics 压缩、转换后推送到 Prometheus 兼容后端

#### 🔍 Tempo 2.10.5

- **核心改进**: 增强 metric 平均值的**正确性（accuracy over time）**
- **认证增强**: 可通过 OpenShift OAuth 认证 Tempo route（不再依赖独立 Grafana 实例）

#### 🔍 日志管道

- **Azure 迁移**: CLF 升级为 OTLP 原生转发，微软 2026-09-14 废弃旧 Data Collector API，必须迁移
- **WIF 认证**: 用 Workload Identity Federation 替代静态 shared key，短生命周期令牌自动轮转，零信任安全增强
- **一键部署**: ObservabilityInstaller CRD 支持单 CR 部署完整日志栈（CLO + Loki Operator），生产就绪

### 2️⃣ OpenShift Service Mesh 3.4 — 未覆盖细节补全

**来源**: Red Hat Blog (Jul 9, Longmuir)

#### 已覆盖（07-10 报告）
- Istio 1.30 / Kiali 2.27
- Ambient mode 多集群 TP
- 共存迁移指导

#### 本次补全

| 特性 | 状态 | 说明 |
|:-----|:----:|:------|
| **原生 nftables 支持** | ✅ GA | 为 RHEL 10+ 准备，Red Hat 贡献上游，sidecar + ambient 均支持 |
| **K8s User Namespaces** | ✅ GA | sidecar 注入兼容 `hostUsers: false`，需显式配置 UID/GID range ≤65535 |
| **CRL 支持 (ztunnel)** | ✅ GA | 外部 CA 场景下验证/拒绝吊销证书，istiod 自动分发 CRL |
| **TrafficExtension API** | 🧪 TP | 统一替换 WasmPlugin + 支持内嵌 Lua 脚本，更安全替代 EnvoyFilter |
| **NetworkPolicy 加固** | ⚙️ opt-in | istiod/istio-cni/ztunnel 最小端口锁定，下个小版本默认启用 |
| **Gateway API 增强** | ✅ 新 | TLSRoute 终止+混合模式 / east-west TLS 透传 / 自定义 cipher suite |
| **Zero Trust 身份管理** | 🧪 TP | SPIRE 多因子认证 + 跨信任域联邦（含 VM 场景） |
| **AI 辅助 Kiali** | 🧪 TP | MCP + OpenShift Lightspeed，自然语言配置/排障 traffic split |
| **多租户 namespace 限制** | ✅ 新 | `RequireNamespaceGet` 限制用户只能见有 get 权限的 namespace |
| **PILOT_IGNORE_RESOURCES** | ✅ 新 | 按需忽略不需要的 Istio CRD，减少消耗和 re reconciliation |
| **Service Mesh 2.6 EOL** | ⚠️ 截止 | **2026-06-30 已 EOL**，不再提供安全修复 |
