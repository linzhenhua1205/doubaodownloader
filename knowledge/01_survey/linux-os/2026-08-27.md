## 内核主线

- **LWN: Linux 7.3 merge window 开启**（2026-08-20，corbet）: 7.3 合并窗口启动时已有 2,346 个 non-merge changesets 拉入 mainline（"仅首付"）；早期亮点包括多处理器系统上 **group scheduling 的重要重构**（cgroup 调度组在 SMP 上的工作方式重做）。来源: https://lwn.net/

- **LWN: 8 个 stable kernel 同日发布**（2026-08-27，jzb）: Greg Kroah-Hartman 公告 7.2.1 / 7.1.11 / 6.18.47 / 6.12.106 / 6.6.154 / 6.1.185 / 5.15.218 / 5.10.218 八个长期维护分支稳定版，全树重要更新，建议升级。覆盖面：LTS 主线（6.12/6.6/6.1/5.15/5.10）+ 最新分支 7.x，表明 7.x 已进入常规 stable 节奏。来源: https://lwn.net/Articles/1090942/

- **LWN: steal governor 补丁系列——虚拟化 CPU 竞争的自愿让渡机制**（2026-08-27，corbet）: Shrikanth Hegde 提交补丁，允许 VM 在高竞争时**自愿减少 vCPU 数量**缓解 CPU 争用。背景：大量 vCPU 共享少量物理 CPU 时过度订阅导致性能显著下降；机制为"软件级让渡"，无需 hypervisor 干预。对服务器虚拟化密度与 QoS 设计有直接参考价值。来源: https://lwn.net/

- **LWN: mklinux v7.0-mk2 发布——裸机多内核 Linux 概念验证**（2026-08-25，corbet）: Cong Wang 的多内核 Linux 实现：host kernel 拥有 CPU/内存/PCI 设备池，切分后经 `kexec_file_load()` 在实例上启动 spawn kernel；每个 spawn kernel 原生运行于自己的 CPU/物理内存/设备，**无仿真无 trap、无 hypervisor**（注意与旧 PowerPC MkLinux 无关）。多内核隔离在安全/性能边界场景的探索方向。来源: https://lwn.net/Articles/1038847/

## 发行版动态

- **LWN: Armbian 26.8 发布**（2026-08-26，jzb）: Arm 硬件发行版三大块更新——安装器重写为 armbian-config 模块（获得单元测试、支持 SPI/MTD 目标、eMMC 与 NVMe 分流程、可独立烧写 bootloader、bootloader 写入失败正确报错）；Armbian Imager 达到 2.0；CI 迁入独立仓库。来源: https://lwn.net/

- **LWN: Vanilla OS 3 发布**（2026-08-25，jzb）: 不可变桌面 Linux 发行版新版本，新增 **Arm64 支持**、引入 Vanilla OS SDK、用新 SDK 重写 Apx 包管理器。来源: https://lwn.net/Articles/1090527/

- **LWN: Debian 就 LLM 贡献政策投票——8 个提案**（2026-08-19，jzb）: Debian 项目对 LLM 辅助贡献投票，提案从"完全禁止 LLM 生成/辅助贡献"到"明确允许"共 8 个选项（含 NOTA）。LLM 政策从企业/工具链层面蔓延至发行版社区治理，108 条评论讨论激烈。来源: https://lwn.net/Articles/1087134/ + 投票页: https://www.debian.org/vote/2026/vote_002
