### 2️⃣ 🆕 etcd v3.7.0 发布 — K8s 核心存储大版本升级 🗄️

- **来源**: K8s Blog / etcd CHANGELOG (Jul 8, SIG etcd)
- **版本**: etcd **v3.7.0** (go 1.26.5, raft v3.7.0, bbolt v1.5.0)
- **状态**: 正式发布，已合并到 K8s v1.37 alpha.3

#### 🚨 Breaking Changes
| 项目 | 说明 |
|:-----|:------|
| 废弃 experimental 参数 | 全部移除 |
| v2discovery 移除 | 使用 v3discovery 替代 |
| client/v2 移除 | 仅保留 client/v3 |
| v2 request 移除 | apply_v2.go 已删除 |
| 单架构 Docker 标签移除 | 请使用 multi-arch manifest |

#### ⭐ 关键新特性
| 特性 | 说明 |
|:-----|:------|
| **RangeStream** | 长期请求的新特性，详情待 blog 发布 |
| **FastLeaseKeepAlive** | 跳过等待 applied index，大幅加速 lease 续约 |
| **非阻塞客户端创建** | 不再默认 honor `grpc.WithBlock` |
| **性能优化** | lease/user/role 操作性能提升**最高 2x**；key-only range 利用内存索引加速 |
| **Unix Socket 支持** | 支持 Unix Socket 端点 |
| **AuthStatus 无需认证** | 允许客户端在认证前获取认证状态 |

#### 🔐 安全修复
| CVE / 问题 | 说明 |
|:-----------|:------|
| CRL bypass on gRPC | 修复 `--listen-client-http-urls` 配置时 CRL 绕过 |
| WebSocket auth | 修复 bearer-prefixed token 认证问题 |
| crypto CVEs | CVE-2026-46598, CVE-2026-39835, CVE-2026-39828, CVE-2026-46597 |

- **对服务器团队**:
  - 🟡 **影响面较大** — Breaking changes 较多（废弃参数移除、v2 全清），升级需排查配置兼容性
  - ✅ **性能提升明确** — FastLeaseKeepAlive + Rev 操作 2x，对大规模集群控制面有实际收益

## ⚡ 内核

### 5️⃣ 🆕 [LWN] BPF 可直接发送数据包 — 从过滤到转发 🔄🐝

- **来源**: LWN.net (Jul 14+)
- **核心**: LWN 最新订阅文章 — BPF 获得了**直接发送网络数据包**的能力 (此前仅过滤/修改)
- **背景**: LSFMM+BPF Summit 后续报道系列的一部分
- **演进路径**:
  - 阶段1: BPF 仅用于网络**过滤** (tc BPF / XDP)
  - 阶段2: BPF 用于**修改**数据包 (bpf_skb_store_bytes)
  - 阶段3: 🔄 BPF 可直接**生成并发送**数据包（绕过协议栈）
- **对服务器团队**:
  - 🟡 **重要架构方向** — BPF 正在从"旁路可观测"进化为"数据面内联处理引擎"
  - 对 AI 集群：BPF 驱动的快速网络路径可能成为高性能场景的优化选项
