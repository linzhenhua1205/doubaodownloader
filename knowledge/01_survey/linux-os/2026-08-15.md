## Kubernetes 版本主线

- **Kubernetes v1.37 Sneak Peek**（07-31）: **v1.37 定于 2026-08-26 发布**；四大变更主线——①**metrics.k8s.io API 转 GA**（KEP-5207，Beta 近 9 年后毕业，HPA/kubectl top 底座无功能变化）；②**Kubelet in UserNS（Rootless 模式）转 Beta**（KEP-2033，节点组件以非特权用户运行、命名空间内保持 root 语义，缩小漏洞影响面）；③**Volume Health Monitor 重置为 Alpha**（KEP-1432，新增 4 个 CSI RPC：ControllerListVolumeHealth/ControllerGetVolumeHealth/NodeGetVolumeHealth/NodeGetStorageHealth，健康状态写入 PVC.status.healthStatus 与 Pod.status.volumeHealth，错误词表机器可解析：Inaccessible/Degraded 等）；④**SELinuxMount 转 GA 默认启用**（卷以 `-o context=<label>` 挂载替代递归 relabel，仅 CSI 驱动 opt-in；同节点多 SELinux label 共享卷的 Pod 可能启动失败，可用 `seLinuxChangePolicy: Recursive` 保留旧行为）。URL: https://kubernetes.io/blog/2026/07/31/kubernetes-v1-37-sneak-peek/

- **Kubernetes v1.37 弃用/移除预告**（07-31, 同上）: **kube-proxy ipvs 模式弃用**——v1.8 引入解决 iptables 性能瓶颈，但内核 ipvs API 无法完整实现 Service 语义（底层仍走 iptables，KEP-3866）；时间线：v1.40 默认禁用（feature gate 可选）→ **v1.43 完全移除**（KEP-5495），启动即打弃用告警，可用 `kubectl -n kube-system get configmap kube-proxy -o jsonpath='{.data.config\.conf}' | grep 'mode:'` 自查；**cgroup v1 支持进入移除通道**（KEP-5573，v1.35 起 failCgroupV1 默认 true，In-Place Pod Resize/Tiered Memory Protection 均依赖 cgroup v2）；另有 kubectl run --filename/-f 弃用、Static Pod 禁止引用 Secret/ConfigMap（bug 修复，PreventStaticPodAPIReferences gate 移除）。URL: https://kubernetes.io/blog/2026/07/31/kubernetes-v1-37-sneak-peek/

- **Gateway API v1.6.0: TCPRoute/UDPRoute 转 Standard**（08-03）: v1.6.0 于 6/30 发布，SIG Network 宣布 TCPRoute 与 UDPRoute 毕业为 Standard 通道——Gateway API 网络覆盖从 HTTP 扩展至 L4（TCP/UDP）南北向，四层负载均衡获标准 API 化路径。URL: https://kubernetes.io/blog/2026/08/03/gateway-api-v1-6-release/

- **etcd v3.7.0 发布**（07-08）: 最新 minor 版本，核心特性为长期诉求的 **RangeStream**（流式范围读，降低大规模 List/Watch 对 etcd 内存与响应延迟压力），SIG etcd 官方发布。URL: https://kubernetes.io/blog/2026/07/08/announcing-etcd-3.7/

- **Kubernetes v1.36 补遗: PSI Metrics 转 GA**（05-12）: v1.36 系列中 **PSI（Pressure Stall Information）指标毕业 GA**——节点资源压力（CPU/内存/IO 停滞时间）接入标准指标管线，与 v1.37 的 Tiered Memory Protection/内存 QoS 方向呼应，AI 训练负载的资源争用可观测性补强。URL: https://kubernetes.io/blog/2026/05/12/kubernetes-v1-36-psi-metrics-ga/

## Linux 内核动态

- **LWN/128-Bit page tables for Arm**（08-13, corbet）: Anshuman Khandual 补丁集为 Arm 增加 **128-bit PTE 支持**——现有 Arm 系统用 56 位可访问至 72PB 内存，128-bit PTE 为更大物理内存铺路，但收益方尚不明确（AI 大内存/超大系统内存域是潜在受益场景）。URL: https://lwn.net/Articles/1088125/（订阅墙，摘要自首页）

- **LWN/KVM planes head for takeoff**（08-11, corbet）: Jörg Rödel/Paolo Bonzini 等开发的 **KVM planes 抽象层**——在单虚拟化系统内创建多个安全域的跨厂商统一方案（CPU/软件厂商各自实现不同），目标让所有此类特性在 Linux 上可用，工作量不小。URL: https://lwn.net/Articles/1087590/（订阅墙，摘要自首页）

- **LWN/Block-layer error injection**（08-12）: Christoph Hellwig 补丁系列为内核增加**可配置块层错误注入接口**——现有注入无法选操作/状态码/直击目标盘（需堆叠设备），新接口经 per-disk debugfs 文件实现三件事，存储故障测试精度提升。URL: https://lwn.net/Articles/1086344/（订阅墙，摘要自首页）

- **LWN/BPF 双会议报道**（08-10~08-14）: 2026 Linux Storage/Filesystem/Memory-Management/BPF Summit 上——**BPF 正式验证（formal verification）**：Kumar Kartikeya Dwivedi 提议为 BPF 程序加域特定不变量（更安全保证）；**BPF CI 与 stable 内核测试**：Solodrai/Yu 总结 BPF CI 现状良好并列出增强路径。URL: https://lwn.net/Articles/1087069/ | https://lwn.net/Articles/1087823/（订阅墙，摘要自首页）

- **LWN/Bringing BPF to binfmt_misc**（08-06, corbet）: binfmt_misc 多年静态后迎重大更新——**加载 BPF 程序决定如何运行给定程序**（ELF/#! 之外的自定义格式执行策略化），执行语义可编程化。URL: https://lwn.net/Articles/1086947/（订阅墙，摘要自首页）

- **LWN/shadow-utils 4.20.0 移除密码过期功能**（08-07）: 周期性密码过期相关工具/功能按计划移除（2025-12 4.19.0 已弃用）——依赖 /etc/shadow 密码老化策略的组织需规划替代方案。URL: https://lwn.net/Articles/1086949/（订阅墙，摘要自首页）

## 安全与生态

- **LWN/AMD 内存控制器 bank swizzle 绕过内存保护（PoC）**（08-13）: Christopher Domas 发布 PoC——利用 AMD 内存控制器 bank swizzle 模式绕过内存保护读写任意数据（含 CPU 微码与平台安全处理器内存），可改写固件；需内核级权限（非立即威胁），但手法可能被恶意利用。URL: https://lwn.net/Articles/1088715/

- **LWN/发行版内核安全更新密集**（08-11~08-14）: Ubuntu（linux/linux-aws/linux-azure/linux-gcp/linux-oracle/linux-lowlatency 等全线）、Oracle（kernel/kernel-rt）、SUSE（kernel）、AlmaLinux（kernel）均发布内核安全更新——企业 Linux 内核补丁周保持高频节奏。URL: https://lwn.net/Articles/1088919/
