## ⚡ 内核新特性

### 1️⃣ LLM 辅助内存管理补丁集：内核社区接纳信号 🧠

- **来源**: LWN.net 2026-07-02 (corbet) — Two LLM-assisted memory-management patch sets
- **背景**: 内核社区看到大量 LLM 辅助开发的补丁涌入，多数来自不熟悉的贡献者。但本次关注的是**两位资深开发者**提交的 LLM 辅助大型补丁集
- **关键信号**:
  - **接纳差异显著**: 同样是用 LLM 辅助开发，来自**受尊敬的资深开发者的工作**得到认真评估，而来自社群新人的则被严格审查或拒绝
  - 这揭示了内核社区处理 AI 助码的核心逻辑：**人的信誉比工具来源更重要**
  - 社区正在建立隐性的 LLM 贡献衡准框架：谁写的 + 谁提交的 + 提交者是否理解代码
- **对服务器/数据中心团队的启示**:
  - 内核社区对 AI 辅助代码持**务实接纳态度**，但前提是提交者被信任
  - 如果团队要通过 LLM 工具参与内核社区，**先建立个人信誉**比提交"完美代码"更重要

### 2️⃣ 7.2 合并窗口完整回顾 — 13,412 个非合并提交 🏗️

- **来源**: LWN.net 2026-06-29 (corbet) — The rest of the 7.2 merge window
- **规模**: Linus 于 6月28日发布 7.2-rc1，关闭合并窗口；累计 **13,412 个非合并提交**，是自 2024 年 6.7 以来最繁忙的合并窗口（6.7 有 15,418 提交，含 bcachefs 历史 2,800 个）
- **后一半合并特点**: 侧重修复，但仍有大量新功能和重要变更
- **与 LWN 前一半摘要的差异**: 后一半近一半提交来自前一半摘要之后的窗口期

### 3️⃣ BPF local storage 性能优化 — 锁竞争与网络子系统的效率提升 ⚙️

- **来源**: LWN.net 2026-07-01 (daroc) — Efficient access to local storage for BPF programs
- **议题**: Amery Hung 和 Jakub Sitnicki 在 2026 LSFMM+BPF 峰会领导两场讨论
  - **Hung**: 通用锁竞争性能问题（BPF local storage 操作的热点锁）
  - **Sitnicki**: 网络子系统中 local storage 的使用分析
- **场景**: BPF 程序在网络包过滤/重定向时，需为每个内核对象关联数据，local storage API 是核心通路
- **意义**: BPF 正在从"能工作"迈向"高效能"阶段，网络数据面性能优化成为主题

## 🚢 容器与 K8s

### 5️⃣ Red Hat OpenShift Service Mesh 3.4 GA — Istio 1.30 / Kiali 2.27 🧩

- **来源**: Red Hat Blog 2026-07-02 (Jamie Longmuir)
- **版本基准**: Istio 1.30 + Kiali 2.27
- **Ambient Mode 重大进展**:
  - Sidecar ↔ Ambient 模式**共存与迁移指导**正式支持（渐进可逆）
  - **多集群 ambient mode** (multi-primary multinetwork) → **Technology Preview**，含多网络 ingress 修复
  - **ztunnel CRL 支持**: 凭吊销列表验证外部 CA 证书
  - **nftables 原生支持**: 为 RHEL 10 及以上版本准备，替代传统 iptables
- **安全加固**:
  - **核心组件网络策略**: istiod/istio-cni/ztunnel 可启用最小端口锁定（当前 default off，未来 minor release 将 default on）
  - **零信任工作负载身份管理器** (SPIRE 集成) → TP
- **新 API — TrafficExtension**: 融合 WasmPlugin + 内嵌 Lua 脚本，比 EnvoyFilter 更安全
- **Kiali 2.27**:
  - 全新**多集群感知概述页**，大幅减少大集群内存和渲染时间
  - **AI 辅助诊断**: Lightspeed 集成 + MCP 协议 → TP
  - **多租户权限**: 新增 `RequireNamespaceGet` 配置，限制用户仅可见有 get 权限的 namespace
- **生命周期**: **Service Mesh 2.6 于 2026-06-30 EOL**，未迁移者需立即联系 Red Hat
- **后续规划**: Ambient multi-primary multinetwork 目标 GA、非 OpenShift 集群的 VM 扩展

### 6️⃣ K8s AI 贡献治理 — CodeRabbit 正式上线 🤖

- **来源**: Kubernetes Blog 2026-06-26 (Kevin Hannon, Red Hat)
- **核心政策**（已写入社区规范）:
  - **透明声明**: PR 描述需标注 AI 辅助
  - **人为全责**: 禁止将 AI 列为 co-author，禁止 `assisted-by`/`co-developed` trailers
  - **CLA 检查对 co-author 启用**: AI 无法签署 CLA，为 reviewer 提供标志
  - **人类响应**: reviewer 期望与人交流，不可由 AI 代答 review 意见
- **工具链落地**:
  - **CodeRabbit** 已在 Kueue、JobSet、Agent-Sandbox 项目上线
  - **GitHub Copilot** CNCF 为 maintainer 提供访问，但局限性在于依赖贡献者 license
  - AI review 工具作为**质量门**：contributor 不必等 maintainer 即可获得快速审查
- **下一阶段探索**: AI skills 减少 maintainer 疲劳、AI 辅助 failing test triage、K8s 运维技能 AI 化
