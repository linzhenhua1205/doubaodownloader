## 内核补丁动态（LWN 08-14 最新提交，本组首录）

- **LWN/KVM: VMX: Harden against interpreting TDX vCPU as vcpu_vmx**（Sean Christopherson, 08-14）: KVM 维护者提交 VMX 侧加固补丁——防止将 TDX vCPU 误解析为普通 vcpu_vmx，属**虚拟化安全加固**（TDX 机密计算场景的类型混淆防护）；与 08-11 KVM planes 抽象（多安全域统一方案）构成 KVM 安全与架构双线推进。URL: https://lwn.net/Articles/1088960/（HTTP 200）

- **LWN/perf/core: add AUX buffer kernel-consumer API**（Kunwu Chan, 08-14）: perf 子系统新增 **AUX buffer 内核消费者 API**——AUX（辅助）缓冲区（Intel PT/ARM Coresight 等硬件 trace 数据载体）此前主要由用户态消费，内核态消费者接口补齐后，perf 数据可在内核侧直接处理（eBPF/内核事件流消费 trace 的潜在路径），可观测性栈数据通路扩展。URL: https://lwn.net/Articles/1088955/（HTTP 200）

- **LWN/rtla: Implement more robust nr_cpus handling**（Tomas Glozar, 08-14）: rtla（Real-Time Linux Analysis 工具）改进 **CPU 数量（nr_cpus）处理的健壮性**——实时调度分析工具在 CPU 热插拔/受限 cpuset 场景下的正确性修正，实时系统可观测性工具链打磨。URL: https://lwn.net/Articles/1088951/（HTTP 200）

- **LWN/PCI: tegra: Add Tegra264 support**（Thierry Reding, 08-14）: NVIDIA Tegra264 平台 PCI 控制器驱动支持——嵌入式/边缘 SoC 外设支持扩展（NVIDIA 平台生态持续补位）。URL: https://lwn.net/Articles/1088958/（HTTP 200）

- **LWN/nfs: modernize direct I/O path**（Pranjal Shrivastava, 08-14）: NFS 客户端 **direct I/O 路径现代化**改造——绕过页缓存的 I/O 通路重构（大文件/存储性能场景，与块层/文件系统 I/O 现代化主线一致）。URL: https://lwn.net/Articles/1088954/（HTTP 200）

- **LWN/dma-buf: heaps: Add support for Tegra VPR**（Thierry Reding, 08-14）: dma-buf heaps 增加 **Tegra VPR（Video Protected Region）支持**——视频受保护内存区域接入标准 dma-buf 分配器，多媒体/安全内存池管理标准化。URL: https://lwn.net/Articles/1088957/（HTTP 200）

- **LWN/Enhance RPMsg buffer management**（Tanmay Shah, 08-14）: RPMsg（Remote Processor Messaging）**缓冲区管理增强**——SoC 远程处理器通信的缓冲管理优化（异构计算/嵌入式协同场景）。URL: https://lwn.net/Articles/1088956/（HTTP 200）

- **LWN/drm/panel: add a panel_bridge to every panel**（Luca Ceresoli, 08-14）: DRM 面板驱动统一桥接化重构——为每个 panel 添加 panel_bridge（显示驱动模型收敛，减少重复实现）。URL: https://lwn.net/Articles/1088953/（HTTP 200）

- **LWN/HDMI 2.1 VRR and ALLM support**（Fangzhi Zuo, 08-14）: **HDMI 2.1 可变刷新率（VRR）与自动低延迟模式（ALLM）**显示支持补丁——图形显示栈新特性（客户端/显示器场景）。URL: https://lwn.net/Articles/1088962/（HTTP 200）

- **LWN/drm/panel: Support Retroid Pocket 6 panel**（Aaron Kling, 08-14）: 掌机面板支持新增（Retroid Pocket 6）——drm/panel 生态常规器件支持。URL: https://lwn.net/Articles/1088961/（HTTP 200）
