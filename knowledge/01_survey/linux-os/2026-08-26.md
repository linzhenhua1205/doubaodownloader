## 发行版生态侧

- **LWN/Armbian 26.8 发布**（08-26 13:54 UTC，jzb）: Arm 硬件发行版 Armbian 26.8 发布，三块大改——**安装器重写**（改为 armbian-config 模块、单元测试化、支持 SPI/MTD 目标、eMMC 与 NVMe 分离为独立流程、可单独刷 bootloader 且写入失败会真实报错而非假打印 "Done."）、**Armbian Imager 2.0**、**CI 迁入专用仓库**。虽面向单板机/边缘设备，但其「安装器模块化 + 启动介质写入失败可诊断」对服务器侧 **Arm 服务器 OS 镜像工具链**（如 Ubuntu Server for Arm、Rocky Linux for Ampere）的可用性改进方向有参考意义。来源: https://lwn.net/Articles/1090741/（200 验证通过）

## 内核生态侧

- **LWN/mklinux v7.0-mk2 发布**（08-25 20:34 UTC，corbet）: Cong Wang 发布 multi-kernel Linux 概念新版本——**一台裸机同时运行多个独立 Linux 内核，无 hypervisor**：host 内核把 CPU/内存/PCI 设备池划分为实例，通过 kexec_file_load() 向每个实例启动 spawn kernel，各 spawn kernel 原生运行在自己的 CPU/物理内存/设备上，**无模拟无 trap**，仅共享显式选择的资源。多内核隔离是内核级安全/多租户的激进方向（如不同工作负载用不同内核配置/加固面），虽仍属实验性概念（mk2 迭代），但其「无虚拟化开销的内核级分区」思路与服务器侧 **可信执行/故障隔离/内核加固** 需求同构，值得作为弱信号跟踪。来源: https://lwn.net/Articles/1090582/（200 验证通过）
