## 内核开发与生态

- **LWN/7.2 kernel 开发统计**（08-17，corbet）: 7.2 是**内核史上最繁忙的开发周期之一**，新增近 **600,000 行代码**——Linus 也承认收尾一周修复量"仍大于期望"；统计文章从提交数、作者构成、子系统分布透视内核开发社区的结构变化（维护者代际更替与自动化工具投入持续加大）。来源: https://lwn.net/
- **LWN/Fedora 准备终结 AF_ALG**（08-18）: 内核 Crypto API 的用户空间接口 **AF_ALG** 关联多个近期高危安全问题（含 **Copy Fail 及后继漏洞**），今年早些时候已被弃用；Eric Biggers 等内核开发者正推动将其从内核**彻底移除**；Fedora 计划在下一发行版**限制 AF_ALG 使用**，倒逼存量用户迁移至 netlink 等替代接口，为最终移除做准备。来源: https://lwn.net/
- **LWN/Bootstrappable builds: 如何与为何**（08-17，FOSSY 2026 报道）: Timothy Sample 在 FOSSY "Toolchains" 轨道介绍**可引导构建**——从极小的种子程序逐级构建出完整 Linux 用户空间，使每一行代码的来源完全可理解（区别于更知名的 reproducible builds）；"代码来源完全可追溯"是供应链安全的前沿议题。来源: https://lwn.net/

## 安全更新

- **LWN/周三安全更新**（08-19）: 多发行版批量修复，Ubuntu 内核包更新密集（linux、linux-aws、linux-azure、linux-gcp、linux-kvm、linux-oracle、linux-hwe-7.0、linux-realtime 等），另含 AlmaLinux kernel、Oracle kernel、SUSE kernel；非内核侧含 curl、haproxy、libssh、nodejs、ruby 等常用组件。来源: https://lwn.net/
- **LWN/周一~周二安全更新回顾**（08-17~18）: AlmaLinux/Red Hat/SUSE 均有 kernel 与 kernel-rt 更新；Ubuntu 覆盖 linux-aws-7.0、linux-azure-fde-5.15 等长期支持线——**8 月中旬各发行版内核安全更新进入高频窗口**，建议运维侧关注 kernel-rt（实时内核）同步节奏。来源: https://lwn.net/

## Kubernetes 生态（增量）

- **Kubernetes Blog/KYAML: Kubernetes YAML 格式化工具**（08-11，Kashish Verma）: 介绍 KYAML 工具——用结构化格式化输出替代手写 YAML 的多样性表达，降低 manifest 书写歧义与审查成本；反映 K8s 配置工程化方向（格式化/校验工具链持续补位）。来源: https://kubernetes.io/blog/

## 追踪信号小结

- **内核安全主线右移**: AF_ALG 移除流程启动（Fedora 带头限制）+ 多发行版内核安全更新高频——内核攻击面收敛（Crypto API 用户态接口、块设备路径）是 7.2 之后的持续方向，与 08-13 AMD 内存控制器 PoC、rsync 33 漏洞审计同属"安全纵深"主线

- **K8s 侧静默期**: 除 KYAML 工具外无核心发布增量，v1.37 发布是下一个观察点
