## ⚡ 内核新特性

### 1️⃣ `kmalloc_nolock()`: 任意内核上下文的无锁内存分配 ⚙️🆕

- **来源**: LWN.net 2026-07-07 (daroc) — Faster RCUs and lockless memory allocation
- **会议**: 2026 Linux Storage, Filesystem, Memory-Management, and BPF Summit (LSFMM+BPF)
- **核心提案**: Harry Yoo 和 Alexei Starovoitov 联合主导 `kmalloc_nolock()` 函数，允许**在任何内核上下文中进行无锁分配**
  - 与 RCU 子系统深度集成，利用 RCU 机制实现免锁分配
  - 填补了内核内存分配器的一大空白：此前在特定上下文（如 BPF 程序、某些中断路径）中无法安全分配内存
- **配套工作**: Puranjay Mohan 展示了 RCU 性能优化进展（同一 session 的背景铺垫）
- **对数据中心/服务器团队的意义**:
  - 这是**内核内存管理架构层面**的重要演进，直接影响 BPF 程序、网络数据面、实时系统的运行效率
  - `kmalloc_nolock()` 若合入，将加速 BPF 在内核中更广泛的应用场景（如高性能包处理、观测性插桩）
  - RCU 加速意味着更多内核子系统可以受益于更低开销的同步原语

### 2️⃣ 内核 iomap 层深度解析 📖

- **来源**: LWN.net 2026-07-06 (corbet) — The kernel's iomap layer
- **内容**: 系统性阐述 iomap 层的定义与作用
  - **功能**: 处理文件系统空间（文件+偏移）到存储空间（内存地址/存储块）的映射
  - **覆盖面**: 利用该映射关系处理大量通用文件系统任务，消除各文件系统实现中的重复代码
- **对服务器团队的意义**: iomap 是 XFS、ext4 等主流文件系统的底层架构支撑，理解它有助于分析存储性能瓶颈

## 🛡️ 安全

### 3️⃣ OpenSSH 10.4 发布 — 后量子签名 + SECCOMP 强约束 🔑

- **来源**: LWN.net 2026-07-06 (jzb) — OpenSSH 10.4 released
- **关键特性**:
  - 🧬 **实验性后量子签名方案**: 组合 **ML-DSA 44 + Ed25519**（IETF 草案），面向未来的量子计算威胁
  - 🔒 **SECCOMP/NO_NEW_PRIVS 强制执行**: 若编译时启用了 sandbox 支持，Linux 系统上**未启用 SECCOMP 或 NO_NEW_PRIVS 时 sshd 将直接失败退出**（之前仅记录错误）
    - 这意味着使用 `sshd -p` 或容器中运行 sshd 时，需确保 seccomp profile 配置正确
  - 含多项安全修复和 bug 修复
- **对数据中心团队的意义**:
  - ML-DSA 44 + Ed25519 混合签名是对抗量子计算威胁的前瞻性防御
  - SECCOMP 强制执行升级：**容器中运行 sshd 的场景需要立即检查 seccomp profile**，否则升级后 sshd 将无法启动

## 📦 Red Hat 产品动态

### 5️⃣ RHEL Long-Life Add-On — 无预设定终止日期的企业支持 🏢

- **来源**: Red Hat Blog 2026-07-07 (Gil Cattelain)
- **核心**: 为**关键任务工作负载**提供超越标准厂商过期日期的**扩展支持**
- **定位**: 解决企业大规模部署中对 RHEL 版本生命周期不可预知的痛点
- **适用场景**: 认证/合规要求严格的行业、无法按标准 EOL 窗口完成迁移的大型部署
- **对数据中心团队的意义**: 统一管理超大规模集群时，不同节点的操作系统版本升级窗口可以更灵活安排

### 6️⃣ Satellite 6.19 — Lightspeed 安全监控下放到离线环境 🛰️

- **来源**: Red Hat Blog 2026-07-07 (Brian Moore)
- **亮点**: **Red Hat Lightspeed on premise** 现在可以为**断网/气隙/数据主权**环境提供安全监控
- **适用场景**:
  - 涉密/合规数据中心（无法连接互联网）
  - 供应链隔离环境
  - 跨地域多集群管理
- **组合**: Satellite 6.19 + Lightspeed 本地部署 = 离线环境下的安全态势感知
