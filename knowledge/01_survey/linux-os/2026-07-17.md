## ☸️ K8s & 容器生态

### 1️⃣ 🆕 Red Hat build of Karpenter GA — 高性能节点自动扩缩器 🚀

- **来源**: Red Hat Blog (Jul 17, Modeel/Chandrasekaran) — `Introducing Red Hat build of Karpenter`
- **版本**: **Red Hat build of Karpenter** — GA on ROSA HCP
- **定位**: 高性能节点自动扩缩器，专为 Red Hat OpenShift Service on AWS (ROSA) Hosted Control Planes (HCP) 设计
- **核心能力**:
  - 动态评估工作负载需求（而非传统 HPA 的简单阈值触发）
  - 基于实际资源需求的实时节点扩缩
  - 减少节点闲置/过度配置 → 直接成本优化
- **对服务器团队**: 🟡 **值得关注**
  - Karpenter 是 K8s 节点弹性领域最活跃的开源项目之一（AWS 团队创建，CNCF 孵化）
  - Red Hat 官方 build 意味着企业级支持和集成验证
  - 趋势信号：K8s 节点弹性正在从 Cluster Autoscaler（Pod 调度触发）→ Karpenter（节点级需求驱动）演进
  - 对 AI 训练集群场景：训练作业容量的即时扩缩可能受益于 Karpenter 的低延迟节点供给

### 2️⃣ 🆕 Red Hat: AI Agent 框架不够——生产必备的 7 大平台能力缺失 🧩🤖

- **来源**: Red Hat Blog (Jul 17, Naszcyniec/Wilson) — `Why your AI agent framework isn't enough: 7 platform capabilities missing from production`
- **核心论点**: 当前 AI Agent 框架（LangChain、AutoGen 等）擅长 PoC 和原型开发，但**缺失生产部署必需的 7 个平台级能力**
- **7 大缺失能力**:

| # | 缺失能力 | 说明 |
|:-:|:---------|:-----|
| 1 | **可观测性 & 追踪** | Agent 决策链路复杂，缺乏端到端追踪导致故障定位困难 |
| 2 | **安全防护** | 提示注入、越狱攻击、数据泄漏 — 框架级防护不够 |
| 3 | **成本管控** | Agent 调用链中 Token 消耗不可预测，缺少预算控制和用量计量 |
| 4 | **多模型治理** | 生产环境使用多个 LLM，缺乏统一的速率限制/回退/路由策略 |
| 5 | **版本管理** | Agent 行为随模型更新而变化，缺乏 A/B 测试和金丝雀发布机制 |
| 6 | **规模化基础设施** | Agent 需要 GPU/CPU 混合编排，缺少统一的资源调度层 |
| 7 | **合规审计** | Agent 决策日志不足，难以满足行业合规要求 |

- **Red Hat 方案**: Red Hat AI 平台填补上述缺口（BYO Agents 治理 + 集中评估中心 + 可预测 Token 经济）
- **对服务器团队**: 🟡 **趋势信号** — AI Agent 从 PoC 走向生产时对基础设施的要求（GPU 编排/延迟敏感调度/混合资源管理）与 AI 集群规划高度相关

### 3️⃣ 🆕 Agentic AI + OpenShift + NVIDIA: 利用漏洞情报实现精准安全 🛡️🎯

- **来源**: Red Hat Blog (Jul 17, Labocki/Prasad)

  - 真实可被利用的漏洞优先级排序

  - 容器化环境中的精确安全响应
- **对服务器团队**: 🟢 参考 — 漏洞精准优先级排序对服务器运维有长期借鉴意义

### 5️⃣ 🆕 shim Secure Boot 事件持续发酵 — 各发行版正在部署 SBAT 吊销 🛡️🔴

- **来源**: LWN.net (Jul 15, corbet) — 跟进 Jul 15 已报事件
- **进展**: CMU CERT 披露后，各发行版已通过 **LVFS** 和 Windows Update 开始部署 shim 吊销
- **建议**: 服务器 Secure Boot 环境需确认 SBAT 吊销已应用
  - 检查命令: `cat /sys/firmware/efi/efivars/SbatLevel-*` 或 `mokutil --sb-state`
  - 关注各发行版 shim 安全公告
- **对服务器团队**: 🟡 **需跟进**（从 Jul 15 持续追踪）
