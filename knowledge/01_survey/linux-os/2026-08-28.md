## 内核主线

- **LWN: CVE-2026-80590 应急修复——8 个 stable 内核同日发布**（2026-08-28，jzb）: Greg Kroah-Hartman 公告 7.2.2 / 7.1.12 / 6.18.48 / 6.12.107 / 6.6.155 / 6.1.186 / 5.15.219 / 5.10.268 八个分支稳定版，每版仅含**单一漏洞修复**：CVE-2026-80590 允许将 IPv4/IPv6 分片标记为 GSO（Generic Segmentation Offload），非特权用户可利用触发**内核 panic**；漏洞自 **Linux 2.6.27（2008 年）起存在近 19 年**，覆盖面横跨 5.10 LTS 至 7.2 最新分支。意义：连续两日 8 分支同日发布（昨日 7.2.1 常规→今日 7.2.2 应急），验证 7.x 已完全融入 stable 应急维护节奏，且超长潜伏期网络栈漏洞值得 RAS/安全团队复盘同类 GSO 路径。来源: https://lwn.net/

## 容器与安全

- **LWN: 量子计算安全前瞻——"How to be safe from quantum computing"**（2026-08-24，daroc）: LWN 长文分析量子威胁时间线：混淆结果的研究证实量子计算机分解 ECDSA 密钥的**内存需求大幅降低**，后续开源研究再比 2023 年 SOTA 减半内存使用；同时硬件厂商宣称量子处理器超位置保持时间更长。结论：软件更新向稳定系统扩散极慢，**现在就该评估配置变更与协议更新**（PQC 迁移）。对服务器/数据中心的意义：TLS/SSH/内核密码学组件的后量子迁移窗口正在收窄，发行版需提前把 PQC 算法纳入默认构建。来源: https://lwn.net/

- **LWN: 周五安全更新批量推送**（2026-08-28，jzb）: 多发行版批量更新，值得注意：**SUSE 更新含 liboqs（开源量子安全加密库）与 openssl-3**（量子抗性密码学开始进入发行版维护清单）；Ubuntu 覆盖 linux-azure / linux-ibm / linux-gke / linux-raspi 等多云/多架构内核与 linux-raspi-realtime；AlmaLinux/Oracle 更新 kernel；Debian 更新 chromium 与 suricata-update；Fedora 更新 rust-h2。云内核与实时内核纳入例行维护印证 Linux 多云部署面扩大。来源: https://lwn.net/

## 开源治理

- **LWN: OpenMDW 许可证提交 OSI——LLM 材料分发许可新尝试**（2026-08-21，corbet）: Linux Foundation 的 Mike Dolan 向 OSI 提交新许可证 **OpenMDW（Open Model, Data, and Weights）**，旨在澄清 LLM 及相关材料的分发许可；此前 OSI 的 Open Source AI Definition 过程已充满争议，OpenMDW 同样共识难求（"black box 数值权重何谓自由"）。Linux 基金会主导开源治理向 AI 资产（模型/数据/权重）延伸，将影响 Linux 生态内 AI 组件的许可格局。来源: https://lwn.net/
