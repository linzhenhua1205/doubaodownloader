## 1️⃣ 🟢 gccrs: 编译 Linux kernel 取得实质性进展

| 属性 | 内容 |
|:-----|:------|
| **来源** | LWN.net — arshal, **Jul 28** 2026 17:40 UTC |
| **项目** | **gccrs** — GCC 的 Rust 前端 |
| **关键进展** | 经过半年多的密集测试，gccrs 在**编译 Linux 内核 Rust crates** 上取得显著进展 |

**详情**：
- gccrs 项目 2026 上半年将**核心目标锁定在编译 Linux 内核**上
- 通过**针对内核 crates 进行测试**，开发团队发现了并修复了多个领域的问题：

| 领域 | 已修复问题 |
|:-----|:----------|
| **属性处理** | 2月报告中详述的 attribute 处理问题已修复 |
| **名称解析** | name resolution 相关问题已修复 |
| **资源管理** | 5月报告中详述的资源管理问题已修复 |

- **当前能力**：gccrs 目前**只能处理简单的独立程序**（simple standalone programs）
- **前景判断**："that situation could change rapidly in the coming months"——情况可能在**未来数月快速改变**

**判断** 🟢：这是 Rust 进入内核的**工具链独立性里程碑**。当前内核 Rust 支持依赖 **LLVM/Clang**（rustc 基于 LLVM），这意味着 Rust 内核代码**只能由 Clang 编译**。gccrs 成熟后，GCC-only 工具链（如某些嵌入式/交叉编译场景）将能编译 Rust 内核代码。

**对服务器影响**：
- 短期内无影响（gccrs 尚不能编译完整内核）
- 长期信号：**Rust for Linux 不再绑定 LLVM**，GCC-only 服务器平台可受益
- 对 GCC 发行版（RHEL 系默认 GCC）利好

|:-------|:--------------|
| **AlmaLinux** | **kernel**, **kernel-rt**, dovecot, go-fdo-client, go-fdo-server, sssd |

| **Fedora** | btrbk, **chromium**, gpsd, kronosnet, restic |
| **Mageia** | gstreamer1.0-libav, libslirp |
| **Slackware** | libarchive, samba, seamonkey |
| **SUSE** | **chromium**, **gimp**, **glib2**, **ImageMagick**, **java**, **libssh**, **nginx**, **rsyslog**, **samba**, **sssd**, valkey, **webkit2gtk3**, yq 等大批量 |
