## 内核发布与开发

- **LWN/Linux 7.3 merge window 开启**（08-20 13:11 UTC，corbet）: 截至发稿已合入 **2,346 个 non-merge changesets**，早期合并已包含**多处理器系统 group scheduling 的重大重构**（multiprocessor group scheduling rework）——这是 7.2 之后第一个可观测的调度层信号，对多核/多 NUMA 服务器负载（AI 训练节点）的直接相关度高于一般特性；merge window 尚处早期，完整特性清单待 7.3-rc1 快照。来源: https://lwn.net/Articles/1089244/
- **LWN/七个 stable 内核同日发布**（08-19 18:02 UTC，GK-H）: **7.1.9 / 6.18.45 / 6.12.104 / 6.6.152 / 6.1.183 / 5.15.216 / 5.10.265** 同日齐发，覆盖当前 7.x 主线与 6.18/6.12/6.6/6.1/5.15/5.10 六条长期支持线——8 月中旬以来各 LTS 分支修复持续高频，建议服务器 OS 基线按 6.12（超长期支持线）与 7.1（当前 stable 线）两条路径同步跟踪。来源: https://lwn.net/Articles/1089557/
- **LWN/周四安全更新**（08-20 13:09 UTC）: 多发行版批量安全修复，**内核侧**覆盖 AlmaLinux kernel-rt、Oracle kernel、Ubuntu linux/linux-hwe/linux-realtime 系列；非内核侧含 curl、bind9、nginx、tiff、mysql8.4、podman 等——与 08-17~19 观察一致，8 月下旬各发行版内核安全更新进入高频窗口。来源: https://lwn.net/Articles/1089717/

## 发行版与社区治理

- **LWN/Debian 就 LLM 使用发起 8 提案投票**（08-19 17:36 UTC，jzb）: 7 月底 Matthias Geiger 提案**全面禁止 LLM 辅助贡献**引发社区争论后，Debian 开发者现对 8 个提案投票，光谱覆盖「完全禁止 LLM 贡献」到「明确批准」，外加"以上皆非"；结果将定义 Debian 未来贡献政策——首个主流发行版对 AI 生成代码的**正式治理决策**，对依赖 Debian 系基线的企业（含基于 Debian 的国产发行版）有政策参考意义。来源: https://lwn.net/Articles/1087134/
- **LWN/RPM 6.1.0 发布**（08-20 13:22 UTC，jzb）: 新特性含**宏定义时修饰符**、构建/校验错误处理改进、rpmsign 支持 **PKCS11 令牌签名**、新增多个人手册页；6.1.0 同时启用**仿 Linux kernel 的新发布模型**（时间驱动 minor 版本节奏）——RPM 生态向内核节奏看齐，发行版打包链路的版本规划将更可预期。来源: https://lwn.net/Articles/1089719/

## 追踪信号小结

- **7.3 调度层重构是 8 月内核最重要信号**: group scheduling 在多处理器系统的重做直接触及 CFS/调度组的 NUMA 感知与负载均衡路径——对 AI 服务器（高核数 + 大内存带宽敏感）的 OS 基线选型与内核参数调优有直接影响，7.3-rc 系列发布后值得对照 7.2 做调度延迟基线对比
- **供应链攻击面扩展至 Rust/Go 工具链层**: crates.io 恶意 crate + Go 1.27 后量子签名同步落地，指向同一结论——**构建链路可信度（签名/来源锁定）正成为 OS 与容器栈的安全主战场**，与内核侧 AF_ALG 移除、Fedora 限制同属「攻击面收敛 + 供应链硬化」双主线
- **stable 内核多分支高频更新**: 7 条线同日齐发 + 各发行版 kernel 包高频安全更新，8 月下旬建议运维基线同步节奏：7.1.x（新特性）与 6.12.x（LTS）双轨跟进
