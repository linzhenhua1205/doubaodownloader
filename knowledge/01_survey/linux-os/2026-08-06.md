## 🔴 P0 — 内核机制更新

- **Bringing BPF to binfmt_misc**（2026-08-06，LWN corbet）: 内核可通过 binfmt_misc 从用户空间配置透明执行任意格式程序，该机制已多年静态；近期有望获重大更新——**加载 BPF 程序来决定给定程序应如何运行**。信号：BPF 从"网络/跟踪/存储"继续向"进程执行路径"渗透，可执行文件格式分派将获得可编程能力。[来源](https://lwn.net/)

- **LWN 第 2026-08-06 期周报发布**（2026-08-06，LWN）: 本期 front 含 Process-builder API、Fedora COI、FUSE io_uring buffer、**BPF 网络命名空间**、FUSE plans、BPF libraries、目录创建系统调用；briefs 含 AISI hack、JFrog CVEs、npm worm、AUR 采纳、NetBSD 11.0、b4 0.16.0、Rust LLM 政策等。周报节奏正常，无突发事件。[来源](https://lwn.net/)

- **Examining other network namespaces using BPF**（2026-08-05，LWN daroc，LSFMM+BPF Summit 2026 讨论）: Jordan Rife（为 **Cilium 编写与 Kubernetes 网络交互的 BPF 程序**）希望允许有适当权限的 BPF 程序**遍历不同网络命名空间的 socket**；BPF 开发者现场提出多种替代方案。与 K8s 网络（Cilium CNI 数据面）直接相关，跨命名空间可见性是云原生网络可观测性的潜在演进方向。[来源](https://lwn.net/)

- **FUSE status and plans — 新 FUSE API 规划**（2026-08-05，LWN jake，LSFMM+BPF Summit BoF）: FUSE 维护者 **Miklos Szeredi** 主持 BoF，讨论子系统维护挑战、拟议功能及其状态，并**规划新 FUSE API**；FUSE 社区近期活跃度高。与 08-04 归档的 FUSE io_uring buffer 优化（Bernd Schubert）同属 LSFMM FUSE 议题线——**用户态文件系统 API 层正在酝酿更新**，容器存储（CSI 驱动）生态需关注兼容性。[来源](https://lwn.net/)

## 🟢 开发工具与生态

- **Rust Coreutils 0.10 发布**（2026-08-06，LWN jzb）: uutils 项目聚焦 GNU Coreutils 兼容性，**645/690 测试通过**（0.9.0 为 625，+20）；亮点：新增 `mv --exchange` 选项、checksum 工具 OpenSSL 后端、**mkdir/mkfifo/mknod 创建时即应用 SELinux 标签**，以及多项性能与安全改进；提供 WebAssembly 在线 playground。Rust 重写核心工具链持续逼近 GNU 基线（93.5% 通过率）。[来源](https://lwn.net/)
