## 发行版生态侧

- **LWN/Vanilla OS 3 发布**（08-25 13:54 UTC，jzb）: 不可变桌面 Linux 发行版 Vanilla OS 3 发布，关键变化——**新增 Arm64 架构支持**、引入 **Vanilla OS SDK**（用于构建系统镜像与工具链）、基于新 SDK **重写 Apx 包管理器**（发行版包管理与系统镜像解耦）。虽为桌面发行版，但其"不可变系统镜像 + SDK 化构建 + Arm64"组合与服务器侧 **image-based OS / 原子更新** 方向同构（Fedora CoreOS、Ubuntu Core、Flatcar 同赛道），可作 image-based OS 生态扩散的弱信号跟踪。来源: https://lwn.net/Articles/1090527/（200 验证通过）

## 追踪信号小结

- **发行版内核补丁"无窗口轮换"模式确认**: 周一 4 家（RH/Oracle/Fedora/AlmaLinux）+ Ubuntu 7.x 全线 vs 周二 5 家（AlmaLinux/Fedora/Mageia/Oracle/SUSE）且 Red Hat/Ubuntu 缺席——**各家内核安全更新独立滚动，无统一发布窗口**；服务器 OS 多发行版基线（如 RH+Ubuntu 双轨）需按天扫描两家补丁流，任一发行版窗口漂移不构成全基线安全风险，但**单发行版基线（如全 SUSE）需盯紧其连续高频批**
- **SUSE 容器栈高频补丁期再确认（连续第三批）**: 08-21→08-24→08-25 三批齐修，且修复面从容器运行时（runc/containerd）扩展到**构建（buildah）、启动镜像（dracut）、签名（cosign）、虚拟网络（openvswitch）**——"攻击面收敛 + 供应链硬化"主线（08-19 AF_ALG 移除、08-20 crates.io 攻击）持续强化
