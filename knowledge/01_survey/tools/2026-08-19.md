## Cursor（Anysphere）

- **Cursor Origin 代码托管上线**（2026-08-17）: Cursor 正式进军代码托管，Origin 早期 beta 面向全部付费计划开放，核心功能=repos + pull requests + code browsing + GitHub sync（同步仓库双向评论/合并，GitHub 仍为 source of truth）；集成 Vercel（PR 预览部署）、Depot/Buildkite（CI，可复用 GitHub Actions workflows）；仓库 URL 形如 cursor.com/codebase/acme-corp；企业组织可 opt-out。信号：编辑器 → 平台化（托管+CI/CD 生态）迈出关键一步，直面对标 GitHub。URL: https://cursor.com/changelog
- **Cloud Agents 预构建环境 Builds 提速 3x**（2026-08-13）: 引入 builds=后台预构建的开发环境副本（克隆仓库+装依赖+跑 install script），agent 启动直接进入就绪环境；内部环境启动快 10x、首 token 快 3x；构建失败不会激活（agent 继续用最后成功 build，坏 commit/依赖更新不中断运行）；Builds 面板可查状态/日志/commit SHA，对 Cloud Agents 免费。信号：云 agent 冷启动问题用「容器预热」思路解决，可用性优先于最新依赖。URL: https://cursor.com/changelog
- **Google Workspace 插件**（2026-08-03）: Cursor Marketplace 新增 Gmail/Google Drive/Google Calendar 插件，agent 可直接搜索、读取、起草、更新邮件/文件/日程。URL: https://cursor.com/changelog
- **Cursor iPad 版上线**（2026-07-29）: 全部付费计划可用，iPad 布局针对大屏重做（侧栏多 agent 并行、分屏 review）；iPhone/iPad 均支持全 PR review（评论/checks/approvals）+ Inbox；新增 Bitbucket/Azure DevOps SCM 支持、多 PR 会话。URL: https://cursor.com/changelog
- **Cursor Start 印度本地定价**（2026-07-28）: ₹649/月（税含，UPI 支付）新档位，含 Grok/Composer 模型额度、常驻 cloud agents、iOS 远程控制、插件/MCP/hooks/skills；印度市场下沉打法，本地化支付成获客杠杆。URL: https://cursor.com/changelog
