## 一、GitHub Changelog 增量信号（7月，8/01报告未覆盖）

### 1. 🗂️ Stacked PRs 进入 public preview（07-30）
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: GitHub 平台原生支持 **Stacked Pull Requests**（公共预览）。与 8/01 报告的 Copilot App stacked sessions 配套——AI 会话栈产出直接落为平台级 PR 栈，配合官方 CLI 工具 [gh-stack](https://github.com/github/gh-stack)。
- **意义**: 大型变更拆分为可独立审查的 PR 链成为 GitHub 一等公民；多 Agent 并行开发（PR 依赖图）的基础设施成型。

### 2. 🔍 Copilot code review 接入 Agent Skills + MCP（07-29 GA）
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: Copilot code review 的 **Agent skills 与 MCP（Model Context Protocol）现已 GA**——审查 Agent 可通过 MCP 工具扩展外部上下文（issue 系统、私有文档、代码扫描结果等）。
- **意义**: 代码审查从"纯LLM"走向"LLM + 工具生态"，与 7/30 报告"混合审查架构"趋势直接呼应；MCP 成为审查 Agent 的标准扩展点。

### 3. 🛡️ npm 新增发布时恶意软件扫描 + dual-use 元数据（07-28）
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: npm 引入 **publish-time malware scanning**（发布时恶意软件扫描）与 dual-use 元数据标注；同时 GitHub Actions 可**暂扣疑似恶意 workflow 等待审批**（07-28），Dependabot alerts 扩展覆盖更多生态的恶意包（07-28）。
- **意义**: 供应链安全从"事后检测"转向"发布即拦截"，包管理器成为安全执行点。与 8/01 报告的 npm 2FA 硬化构成完整安全纵深。

### 4. 🤖 Grok 4.5 加入 Copilot 模型矩阵（07-28）
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: Grok 4.5 上线 Copilot；同期 07-21 加入 Gemini 3.6 Flash，07-09 加入 GPT-5.6 Sol/Terra/Luna，07-07 Kimi K2.7，07-24 Claude Opus 5。Copilot 成为多模型聚合入口，07-31 企业团队可配置**模型策略定向**（public preview）。
- **意义**: AI IDE 的模型层"多供应商聚合"成为标配，企业级模型治理（按团队/任务路由）进入公共预览。

### 5. ⚖️ GitHub Code Quality 正式 GA（07-20）
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: 合并时质量门禁 **GitHub Code Quality 全面可用**；07-09 支持组织级定向，07-13 提供 license 估算（public preview）。
- **意义**: 质量门禁内建到 merge 流程，CI/CD 从"跑测试"演进到"AI 质量审查 + 策略门禁"。

### 6. 🩹 Agentic autofix 进入 public preview（07-10）+ 安全审查持续增强
- **来源**: [GitHub Changelog](https://github.blog/changelog/)
- **要点**: code scanning alerts 的 **Agentic autofix**（AI 自动修复安全告警）公共预览；07-14 code scanning 在 PR 上展示 AI 安全检测结果，Copilot App 新增 Security reviews。
- **意义**: "检测→修复"闭环 AI 化，安全修复成本大幅下降是 DevSecOps 落地的关键推手。

## 五、趋势小结

1. **PR 栈成为 Git 平台一等公民**：Stacked PRs public preview + gh-stack CLI + Copilot stacked sessions——多 Agent 并行开发（PR 依赖图）基础设施成型。
2. **代码审查全面 MCP 化**：Copilot code review 的 Agent skills + MCP GA，审查 Agent 可扩展任意工具上下文；混合审查架构从"方案"变为"默认"。
3. **供应链安全"发布即拦截"**：npm publish-time malware scanning + Actions workflow 暂扣审批 + 恶意包告警，安全执行点前移到发布时刻。
