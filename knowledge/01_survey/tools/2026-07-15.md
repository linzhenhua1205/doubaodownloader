## 1️⃣ Cursor 3.11 — Side Chats + 对话搜索 + 更细粒度 Agent Hooks 💬

- **来源**: [Cursor Changelog](https://www.cursor.com/changelog) · Jul 10, 2026
- **工具**: **Cursor**（AI-native IDE）

### Side Chats — 主对话旁路不中断
`/side` 或 `/btw` 或 chat panel 的 "+" 按钮打开侧边聊天，**不打断主 Agent 会话**。

| 特性 | 说明 |
|:-----|:------|
| **持久完整 Agent** | 每个 side chat 是独立的完整 Agent 对话，可后续跟进、回顾，也可 `@mention` 拉回主线程 |
| **默认只读模式** | 默认限制为读取、搜索、回答——适合查技术问题、研究替代方案、快速验证决策，不会意外修改代码 |
| **主 Agent 继续运行** | side chat 执行时主 Agent 不受影响，可并行工作 |

### Conversation Search — 按内容搜历史 Agent 对话
- Cmd+K 打开 Agent 窗口，**搜索 Agent 转录文本**（不限于名称和 PR 号）
- 本地搜索索引，**千级别对话数性能无感**
- 单对话内 Cmd+F 搜索，支持跳转匹配、计数、滚动搜索

### 全量重构的 Project/Repo Picker
- 保留在 picker 内即可连接 GitHub/GitLab/Azure DevOps 创建项目，不用跳出
- 搜索域按 `This Computer` / `Cloud` / 具体远程机器**独立作用域**
- 分支 picker 默认显示 default + 最近使用分支
- 远程机器统一入口，支持多仓库多根选择

### 新增 Agent Conversation Hooks
```
现有: tool execution, file/shell work 的 hook
新增: beforeSubmitPrompt, afterAgentResponse, afterAgentThought,
      stop, subagentStart, subagentEnd, compaction, turnCompletion
```
允许精确观察和控制 Agent 的**推理过程、子 Agent 生成、上下文压缩**等，用于构建自纠正循环。

**价值说明**: Side Chats 解决了 Agent IDE 的核心交互痛点——做一件事时临时分心查资料不再需要新建窗口或打断主任务。Conversation Search 让 Agent 对话从「用完即弃」变成**可检索的知识资产**。新的 Agent Hooks 则对**团队级 Agent 审核和可观测性**有直接价值（审计推理轨迹、控制子 Agent 行为）。

## 2️⃣ Agentic Autofix for Code Scanning — AI 自动修漏洞 (Public Preview) 🔒🛠️

- **来源**: [GitHub Changelog](https://github.blog/changelog/) · Jul 10, 2026
- **工具**: **GitHub Code Scanning** + **GitHub Copilot**
- **新功能**: Code Scanning 发现安全告警后，**Copilot Agent 自动生成修复**并创建 PR

**工作流**:

```
CodeQL 扫描 -> 发现漏洞告警
    v
Agentic Autofix 分析上下文
    +-- 理解代码语义 + 漏洞根因
    +-- 生成修复 diff（多文件跨函数）
    +-- 创建修复 PR（含修复说明 + 测试建议）
    v
开发者审查 PR -> merge
```

**关键特性**:
- 支持 CodeQL 检测到的各类安全漏洞
- 修复 diff 覆盖单函数到多文件跨函数场景
- 自动创建包含修复说明的 PR
- **Public Preview** 阶段可供试用

**价值说明**: 这是 Code Scanning 从「发现问题」到「解决问题」的质变。传统流程：告警 → 人工排查 → 修复 → PR → 合入。Agentic Autofix **压缩为：告警 → 自动修复 PR → 人工确认合入**。对于安全运维团队，这意味着从「告警疲劳」转向「修复确认」——SRR（安全修复速率）可量级提升。

## 3️⃣ GitHub Copilot 扩面 — App 全员可用 + Mobile 冲突修复 + Security Reviews 入驻 📱

- **来源**: [GitHub Changelog](https://github.blog/changelog/) · Jul 7–14, 2026
- **工具**: **GitHub Copilot**

### 3a. GitHub Copilot App 全员 GA 🎉 (Jul 7)
Copilot 桌面 Agent 应用（最初在 Microsoft Build 2026 发布）**现在对所有用户开放**，不再受限。具备完整 Agent 能力：代码生成、debug、命令行交互、多文件编辑。

### 3b. GitHub Mobile: 用 Copilot Cloud Agent 解决合并冲突 🤝 (Jul 8)
手机端 GitHub Mobile 可直接让 **Copilot Cloud Agent 自动修复合并冲突**：
- 进入冲突 PR → 触发 Copilot → Agent 分析冲突区 → 生成修复方案
- 适用于简单到中等复杂度的冲突场景

### 3c. GitHub Mobile: Copilot CLI Session 实时通知 📲 (Jul 8)
手机端接收 CLI Agent 会话的**实时推送通知**——Agent 完成、需要人工输入、等待审查时即时获得通知，相当于「随身携带 Agent 进度牌」。

### 3d. Security Reviews 入驻 Copilot App 🔐 (Jul 14)
GitHub Copilot App 内可直接发起**安全审查（Security Review）**：
- 对 PR 或代码块请求安全视角的 AI 审查
- 检测注入、密钥泄露、权限绕过等安全模式
- 结果以对话形式呈现，可追问细节

### 3e. Ask Copilot for a Repository Overview 🧭 (Jul 9)
打开陌生仓库时，Copilot 主动提供仓库概述（用途、技术栈、贡献指南）。README 不完善的仓库也能自动生成结构化的上下文总结。

### 3f. 新增模型阵容 (Jul 9)
Copilot Business & Enterprise 新增 **OpenAI GPT-5.6 Sol / Terra / Luna**（三个尺寸变体）以及 **Kimi K2.7**（Jul 7 已 GA）。

**价值说明**: 这一批更新共同指向 Copilot **从「编辑器插件」到「全表面 Agent 操作系统」的转型**。App 全员可用意味着 Agent 体验成为默认——不仅限于 VS Code。Mobile 冲突修复 + 实时通知实现了**随时随地开发**。Security Reviews 入驻 App 表明安全审查正从专项工具变为代码 AI 内置能力。Ask Repo Overview 则解决了开发者日常最高频的摩擦——进入新仓库的认知门槛。
