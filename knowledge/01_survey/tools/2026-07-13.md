## 1️⃣ CodeQL 2.26.0 — AI Prompt Injection 检测 + Kotlin 2.4.0 支持 🛡️

- **来源**: [GitHub Changelog](https://github.blog/changelog/) · Jul 10, 2026
- **工具**: **CodeQL**（语义代码分析引擎）
- **新功能**: 代码扫描AI Prompt Injection检测规则；Kotlin 2.4.0 全量支持；secret scanning 检测器类型命名优化

**价值说明**:
CodeQL 从传统漏洞检测（SQL注入/XSS）扩展到 **AI Prompt Injection 检测**，标志着代码分析工具正式进入 LLM 应用安全这一新领域。对于任何使用 LLM API（如 GPT / Claude / LLaMA）的应用，CodeQL 现在可以扫描代码中是否存在**不受控的用户输入被直接拼接到 system prompt 或 user message 中**的风险路径，这是 AI 应用安全左移的关键能力。Kotlin 2.4.0 支持则覆盖了 Android / 后端最新的语言特性。

## 2️⃣ GitHub Copilot CLI + Registrar Skills — 零 DNS 配置部署 🌐

- **来源**: [GitHub Blog](https://github.blog/news-insights/product/how-github-copilot-enables-zero-dns-configuration-for-github-pages/) · Jul 8, 2026
- **工具**: **GitHub Copilot CLI** + **Namecheap Community Skill**
- **新功能**: Copilot CLI 通过社区技能（`gh skill install github/awesome-copilot namecheap`）直接调用 Namecheap API 完成域名购买和 DNS 配置；全程不需要手动编辑 DNS 记录；从空仓库到 HTTPS 自定义域名部署约 14 分钟

**价值说明**:
这展示了 **AI Agent 与第三方基础设施 API 集成**的新范式——Copilot CLI 不再局限于代码生成和 Git 操作，而是通过「技能系统」扩展到了域名注册、DNS 配置等基础设施自动化的范畴。核心模式：
1. `gh skill install` 安装第三方 registrar 技能
2. Copilot CLI 自动获取 API key、验证权限、执行 DNS 变更
3. **审批机制**：修改前 pause 确认，避免无授权变更
4. **自动验证**：DNS 解析 + HTTP 200 双重验证

对于非 Namecheap 用户，同样的模式可以指向任意 registrar API（将 API 文档喂给 Copilot CLI 即可），这意味着**基础设施配置的「对话式自动化」**正在从代码走向 DevOps 全链路。
