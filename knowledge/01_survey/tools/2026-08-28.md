## Cursor（Anysphere）官方更新 — https://cursor.com/changelog

- **Cursor 8/27「免仓库启动」**（Start from scratch, without a repo）: Cloud Agents 不再要求连接 GitHub 等第三方 SCM，可直接从提示词开始构建，后台自动创建 Cursor Origin repo；浏览器实时预览（port-forward cloud agent 环境）+ 设计模式；支持连接 Vercel 一键发布为 live URL。https://cursor.com/changelog
- **Cursor 8/19「Cloud Agents + Harness 改进」**: 新增 Subscriptions——agent 可订阅 PR / Slack 线程 / 定时任务，事件触发自动唤醒并持续推进（如 PR 自建自修 CI、Slack 中 @cursor check back in an hour）；任意 Skill 可固定为 Custom Mode（"always on" skills）；Subagents 可运行在各自独立 VM（隔离项目副本 + 干净上下文，支持 swarm 并行测试）；新增 /goal 长期目标指令与 /loop 循环检查；steering 改进——发送后续消息不打断 agent 当前工具调用。https://cursor.com/changelog
- **Cursor 8/17「Origin 代码托管」**（早期 beta，全付费计划）: Cursor 自建代码托管平台 Origin——repos / PR / 代码浏览 / GitHub 双向同步（PR 评论双向同步至 GitHub）；GitHub repos 可同步进 Origin 且 GitHub 保持 source of truth；集成 Vercel（PR 预览部署）、Depot / Buildkite（CI 跑 GitHub Actions 工作流）；企业 org 可 opt out。https://cursor.com/changelog
- **Cursor 8/13「Builds 环境预构建」**: Cloud Agents 启动加速——内部环境 boot 快 10x、首次 token 快 3x；坏 commit/依赖更新不污染运行环境（保留最后一次成功 build）；提供 Builds 仪表盘（状态/日志/commit SHA）；包含在 Cloud Agents 内不加价。https://cursor.com/changelog
- **Cursor 8/3「Google Workspace 插件」**: 新增 Gmail / Google Drive / Google Calendar 插件，coding agent 可直接读写信件、搜索/组织文件、管理日程，无需离开 Cursor；经 Cursor Marketplace 安装。https://cursor.com/changelog

## 趋势观察

- **Cursor vs Copilot 路径分野**: Cursor 押注「agent 自治」（订阅事件、长期目标、子代理 swarm、托管环境），Copilot 押注「企业规模化」（多模型策略治理、托管设置、ROI 度量、Slack/Teams 嵌入）——前者是开发者生产力工具，后者正变成企业级 AI 开发平台
- **AI 编程工具平台化加速**: Cursor Origin 代码托管 + Marketplace 插件生态 + Vercel/CI 集成，标志着头部 AI 编程工具开始复制 GitHub 的平台飞轮（代码托管→协作→生态），对 GitHub 形成正面竞争（08-17 Origin beta 首发即覆盖 PR 双同步）
- **Agent 基础设施成为新战场**: 环境预构建（Builds）、独立子代理 VM、事件订阅、记忆/上下文层——「让 agent 持续自主运行」所需的基础设施（构建缓存、隔离沙箱、消息总线）正成为工具差异化核心（已由 tech 组收录的 claude-mem 记忆层、Agent Skills 标准化同属此趋势）
