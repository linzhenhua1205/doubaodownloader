## 1. 核心命题

对话中的核心洞察：

> 单纯下发指令"深度分析这篇文章"，放任AI自由发挥，结果必然不稳定、流于表面。
> **人类成熟的分析方法论、分析步骤、评判原则，必须完整植入提示词/工作流；成熟的分析流程固化为可复用Skill，才能实现经验沉淀、反复调用。**

---

## 2. 人工深度研读的完整流程（需复刻给AI）

### 阶段1：全景通读（宏观定位）

```text
① 识别文章类型：议论文/行业分析/叙事文稿/技术文档
② 锁定核心目标：作者想论证什么/传递什么/解决什么
③ 划分结构：引言、论据、分论点、结论、潜在留白
```

### 阶段2：逐段拆解 + 关键字挖掘（核心环节）

**区分两类关键词，不能只提取名词：**

| 关键词类型 | 定义 | 示例 |
|:-----------|:-----|:------|
| 实体关键词 | 主体、对象、指标、专有名词 | "超节点""BMCCXL" |
| 逻辑关键词 | 转折、因果、约束、对比、限定条件 | "但是""局限""前提""短期" |

**人工操作规则：**

- 关键词不能孤立抓取，必须记录**所属上下文+承担作用**
- 剔除修饰性虚词，保留能改变结论、划定边界的词汇
- 标记冲突信息、作者主观假设、未验证观点

### 阶段3：关键词链路关联（深度解读）

构建关系网络，而非单独解读单个词：

```text
A关键词 --因果---> B关键词
   |                  |
   +--矛盾---> C关键词  +--并列---> D关键词
   |                  |
   +--从属---> E关键词  +--支撑---> 核心论点
```

### 阶段4：校验、收敛、产出

1. 复盘：所有解读结论是否在原文能找到依据
2. 区分：原文观点 vs 客观事实 vs 分析者衍生推论
3. 梳理：文章优势、漏洞、隐藏前提、适用边界

## 3. 人工范式 → AI可执行约束

### 3.1 核心提示词模板

```text
你需要严格仿照专业研究员分析文本的完整流程处理下文，
禁止自由简化步骤，必须依次执行以下全部规则：

【执行步骤】
1. 宏观定性：判定文体、作者核心诉求、全文中心主旨
2. 分段解析：逐段落阅读，提取段落核心信息
3. 精准萃取关键词：
   - 分类提取实体关键词、逻辑限定词
   - 每条关键词附带原文出处语句
   - 标注该关键词在段落内承担的功能
4. 关联建模：梳理关键词之间逻辑关系，搭建观点支撑链路
5. 深度解读：严格区分原文观点、客观信息、衍生分析
6. 总结复盘：核心价值、论证短板、隐藏前提、适用范围

【硬性约束】
① 不允许只输出笼统概括
② 所有解读锚定原文素材
③ 禁止简化分析流程、跳过关键词关联环节
```

### 3.2 常见实操误区

> 很多人做关键词提取只提取名词。
> **真正具备分析价值的往往是限定词、条件词、转折词。**

```text
举例："在短期环境下该策略有效"
  普通提取：策略、环境
  深度提取：短期（重要边界约束）、策略、有效

丢失「短期」这个关键词 -> 后续全部解读产生偏差
```

## 4. 进阶：封装为Skill

### 4.1 Skill = 四层结构

```text
Skill = 固定执行流程 + 标准化约束原则 + 输出格式规范 + 常见错误规避清单
```

### 4.2 Skill化带来的能力提升

| 维度 | 零散提示词 | Skill化 |
|:-----|:-----------|:--------|
| 复现性 | 每次写的prompt不同，效果波动 | 标准化流程，可复现 |
| 传承性 | 个人经验无法传递给他人 | 方法论可共享、可迭代 |
| 迭代机制 | 无 | 持续收录踩坑案例，持续优化 |
| 集成性 | 独立使用 | 可嵌入分层架构、自动化流水线 |

### 4.3 与分层架构的集成

→ [**T02**](2026-07-30-t02-ai-layered-architecture.md)

```text
底层小模型 -> 调用【文本解析Skill】
             -> 完成素材预处理
             -> 关键词结构化提取
             -> 向上层输出规整信息
             -> 规避摘要丢失关键信息
```

## 5. 与偷懒机制的联动

→ [**T03**](2026-07-30-t03-prompt-laziness-mechanism.md)

为什么必须把人类方法论注入Skill？

- AI天然具备"最小代价输出"倾向
- 如果缺少人类分析范式作为强制流程约束 → 倾向浅层总结
- 深度提炼 ≠ 简单摘要，核心差异在**关键字精细化提取+语义关系建模+边界校验**
- 这些动作来源于人类成熟方法论，不是模型自带的
