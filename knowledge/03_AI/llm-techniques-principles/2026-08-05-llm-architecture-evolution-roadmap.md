## 〇、结论概要

**大模型架构演进的本质不是"越来越聪明"，而是"瓶颈转移"**：每一代架构都是对上一代最大瓶颈的局部优化——训练算力 → 推理成本 → 上下文/记忆 → 解码延迟 → 硬件效率。理解演进，必须先定位每一时刻的瓶颈。

**当前（2026 年中）正处于"架构分叉期"**：Transformer 一统天下的格局（2017-2022）已被打破，至少四条路线并行——**MoE 主流化**（Kimi K3 2.8T/104B 激活）、**混合架构**（Nemotron 3 Ultra Mamba-Attention）、**扩散语言模型**（DiffusionGemma 256-token 并行）、**低比特硬件协同**（BitNet v2 / NVFP4 预训练）。

**未来 12-24 个月最可能的演进方向**（按确定性排序）：

1. ✅ **MoE 精细化**：从静态路由走向动态计算分配（refinement-aware / 通信感知路由）
2. ✅ **KV 从"副产品"到"一等公民"**：压缩（sub-1-bit）→ 分层（G3.5）→ 结构化记忆（SSM 状态注入）
3. ⚠️ **扩散进入主流推理**：解码串行瓶颈是 Transformer 的物理天花板，扩散/并行生成是最接近"革命"的候选——但质量门槛未过
4. ⚠️ **算法-硬件联合设计成新常态**：1-bit 原生训练 + 专用芯片 + 低比特指令集
5. ⚠️ **连续潜空间多模态统一**：文本从离散 token 走向连续表示（语言是生成建模的最后一个离散孤岛）

## 一、演进驱动力：瓶颈转移是第一性原理

架构演进可以用一个统一框架理解：**任何生成模型的根本任务是把"序列条件概率"变成可计算的工程**，而计算受三个物理约束制约：

| 约束 | 物理本质 | 主导时期 | 代表解法 |
|:-----|:---------|:---------|:---------|
| **序列并行性** | RNN 无法并行训练 | 2017-2018 | Transformer 自注意力（O(1) 步并行） |
| **参数量/训练成本** | 稠密模型参数全激活 | 2022-2024 | MoE 稀疏激活 |
| **上下文/KV 内存** | KV Cache 随序列线性膨胀 | 2023-至今 | GQA/MLA/量化/分层/卸载 |
| **解码延迟** | AR 生成 O(T) 串行 | 2025-至今 | 推测解码→块并行→扩散 |
| **硬件效率** | 精度冗余、算力/带宽错配 | 2025-至今 | 低比特/1-bit/硬件协同设计 |

**关键判断**：架构演进 = 瓶颈的接力赛。每个"革命"其实只是把瓶颈推到下一处。**当前解码延迟与硬件效率同时成为瓶颈**——这正是扩散 LM 与低比特路线在 2026 年同时爆发的根本原因，不是巧合。

## 二、演进历程：六代架构全景

### 2.1 2017 Transformer 诞生：序列并行化革命

**瓶颈**：RNN/LSTM 的隐状态依赖使序列必须逐步计算，无法并行训练（BPTT 梯度消失/爆炸 + 顺序依赖）。

**突破**：`Attention is All You Need`（Vaswani et al., 2017）——自注意力让**任意两个位置直接交互**，序列并行度从 O(T) 降到 O(1) 步；位置编码注入顺序信息；FFN 提供非线性容量。

**第一性原理**：Transformer 的成功不是"注意力聪明"，而是**把序列计算变成了矩阵乘法**——而这正是 GPU 的天然强项。**架构-硬件契合度**从此成为模型设计的第一考量（这个基因在 2026 年的低比特/硬件协同路线中重新显性化）。

### 2.2 2018-2022 稠密 Transformer 时代：缩放定律

**瓶颈**：模型能力随参数增长，但训练成本线性上升。

**主线**：

- **decoder-only 统一**：GPT 系列证明"下一个 token 预测"足够（无需 encoder-decoder 的复杂对齐）；
- **缩放定律**（Kaplan 2020 / Chinchilla 2022）：损失 ≈ 参数² + 数据² 的幂律——**参数与数据同等重要**，Chinchilla 修正"数据饥渴"问题；
- **对齐范式**：预训练 → 指令微调 → RLHF（ChatGPT 2022 引爆点）。

**局限**：稠密模型**每个 token 激活全部参数**——推理成本与参数规模强绑定，Scaling Law 的天花板开始显现。

### 2.3 2022-2024 MoE 复兴：稀疏化

**瓶颈**：稠密模型的推理成本 = 参数总量 × 每个 token。要变强就必须变大，变大就必须全激活——矛盾。

**突破**：稀疏激活（Mixture of Experts）。

- **GShard / Switch Transformer**（2021-2022）：路由网络每 token 选 Top-K 专家；
- **Mixtral**（2023）：开源 MoE 大众化，47B 总参数 / 13B 激活；
- **DeepSeek V3 / Kimi K2**（2024-2025）：**细粒度专家 + 共享专家 + 无辅助损失负载均衡**——把 MoE 从"工程玩具"推向"主力架构"；
- **DeepSeek-V3 的 MLA（Multi-head Latent Attention）**：KV 压缩至潜空间，长上下文成本大降。

**第一性原理**：MoE 是**容量与成本解耦**的架构——参数总量决定知识容量，激活参数决定推理成本。这是"用稀疏性对抗稠密冗余"的工程实现。**2024-2025 之后，所有前沿模型无一例外转向 MoE**（GPT-4、Grok、DeepSeek、Kimi、Qwen、Gemma 4 均 MoE）。

### 2.4 2023-2025 长上下文与 KV 革命

**瓶颈**：上下文窗口扩大后，KV Cache 内存 O(T) 线性膨胀、prefill 计算 O(T²) 二次增长——长上下文是"算力+内存"双瓶颈。

**突破链**：

- **RoPE 旋转位置编码**（2021）：外推能力提升，2K → 128K；
- **FlashAttention**（2022-2023）：IO 感知的注意力实现，O(T²) 计算不变但显存带宽效率 ×倍；
- **MQA / GQA**（2023）：多头 KV 共享，KV 内存降 4-8×；
- **MLA**（DeepSeek 2024）：KV 压缩至潜空间，进一步降 ~93%；
- **1M 上下文标配**（2025-2026）：Sol/Terra/Luna 分档产品线、Kimi K3 原生 1M、Nemotron 3 Ultra 扩展至 1M；
- **KV Cache 分层**（G3.5 概念，2026）：hot HBM / warm DRAM / cold NVMe 三级——KV 从"内存问题"变成"存储问题"（与本库 08-05 IO 专题、KV 三层分层闭环）。

**第一性原理**：上下文革命 = **把注意力从"全量二次方"变成"工程可管理"**——压缩（MLA）＋ 实现优化（FlashAttention）＋ 分层存储（G3.5）三管齐下。**KV Cache 从推理的副产品升格为系统设计的一等公民**。

### 2.5 2024-2025 推理时扩展：后训练范式转移

**瓶颈**：模型前向能力封顶——预训练 Scaling Law 收益递减（数据耗尽 + 算力成本爆炸）。

**突破**：**Test-Time Compute（推理时计算）**——o1 系列（OpenAI 2024）证明"思考更久"可以换能力：RL 训练模型学会生成思维链 + 自我验证，推理阶段动态分配计算量。

**第一性原理**：这是**计算从"训练期"向"推理期"转移**的范式变化——模型不再是"一次性训练产物"，而是"可扩展的推理计算器"。对基础设施的含义：**推理算力需求不再是静态的，而是随问题难度动态变化**——直接冲击推理引擎的调度与容量规划。

### 2.6 2025-2026 架构分叉期：三条候选新范式

**瓶颈**：AR 解码的 O(T) 串行延迟 + 精度冗余导致的硬件浪费——Transformer 内部优化已近极限。

**三条候选路线**（2026 年同时爆发，详见 Part 三）：

1. **混合架构**（SSM/RNN 混合）：Mamba → Jamba → Nemotron 3 Ultra——用线性复杂度状态空间模型替换部分注意力；
2. **扩散语言模型**（Diffusion LM）：LLaDA → Mercury → DiffusionGemma——块级并行生成，解码 O(T/B)；
3. **低比特/硬件协同**（1-bit / NVFP4）：BitNet v2 → Sparse-BitNet——从"训练后用低比特推理"走向"原生低比特训练"。

**判断**：这是自 2017 年以来**第一次没有单一赢家的架构时期**。分叉不是衰退信号，而是**瓶颈多元化的必然**——不同负载（对话/Agent/长文档/边缘）开始选择不同架构。

## 三、2026 当前格局：主流架构拼图

> 本部分全部基于 2026-06~08 arxiv 一手论文/官方技术报告（✅），锚点引用知识库既有内容（🔵）。

### 3.1 MoE 主流化：Kimi K3 与 Stable LatentMoE

**Kimi K3**（Moonshot AI，2026-07-27，✅ arxiv 官方报告）：

- **2.8T 总参数 / 104B 激活**——开放权重第一梯队（记忆锚点：Kimi K3=57 分，开放权重第一）；
- **Kimi Delta Attention + Attention Residuals**：跨序列长度和模型深度的信息流改进；
- **Stable LatentMoE**：**每 token 激活 896 个路由专家中的 16 个**（16/896 ≈ 1.8%）——极细粒度稀疏；
- **缩放效率较 K2 提升 ~2.5×**（官方宣称）；
- 原生视觉 + 1M 上下文 + 多推理强度 RL 后训练（general/agentic/coding）。

**要点解读**：K3 代表 MoE 的**精细化终局**——细粒度专家（896 个）＋ 潜空间路由（LatentMoE）＋ 注意力残差。**MoE 不再是"稀疏化技巧"，而是与注意力机制深度耦合的主架构**。16/896 的激活比意味着推理内存 = 104B 权重 + KV——这对推理引擎的**内存带宽/容量规划**有直接冲击。

### 3.2 混合架构：Nemotron 3 Ultra 与 Naju

**Nemotron 3 Ultra**（NVIDIA，2026-06-12，✅）：

- **550B 总 / 55B 激活，MoE 混合 Mamba-Attention**——首个大规模商用级混合架构；
- 20T 文本 token 预训练 → 扩展至 1M 上下文 → SFT + RL + MOPD（多教师在线策略蒸馏）；
- 关键组件：**LatentMoE + MTP（多 token 预测）+ NVFP4 预训练 + 多环境 RLVR + 推理预算控制**；
- **官方宣称推理吞吐较 SOTA 公开模型高 ~6×**（⚠️ 厂商叙事，未独立验证）。

**Naju**（2026-07-23，✅）：原生离散 SSM——直接参数化离散状态转移，绕开 Mamba 的"连续时间零阶保持离散化"弯路；将递归更新分解为显式 retention 与 writing 两个独立通道，解决"长程保留 vs 主动覆盖"的矛盾。

**要点解读**：混合架构的论点是**注意力负责"精确检索"，SSM 负责"线性压缩"**——各取所长。Nemotron 3 Ultra 是 NVIDIA 对"Agentic 推理"的架构回应（与 08-05 CPU 专题的"Agentic 需要大量 CPU"叙事呼应）。**Mamba 类架构 2026 年的真正价值不在替代 Transformer，而在混合**——成为注意力的"记忆伴侣"。

### 3.3 扩散语言模型：DiffusionGemma 与 AURORA-LM

**DiffusionGemma**（Google，2026-07-31，✅）：

- **离散扩散 LM，每次迭代并行精炼 256-token 块**——彻底绕开 AR 逐 token 解码瓶颈；
- 从 Gemma 4 MoE（25.2B 总 / 3.8B 激活）微调而来，**训练预算 < 原始 AR 模型的 10%**（两阶段：SFT 教扩散 + 后续精炼）；
- 官方定位"实验性 open-weight"——**质量尚未追平 AR，但速度是核心卖点**（呼应记忆锚点：Celeris-1 2158 t/s 扩散速度革命）。

**AURORA-LM**（2026-08-03，✅）：连续潜空间扩散 LM——不把文本压成离散 token，而是保留高容量可解码的文本潜表示，让扩散模型直接学习其分布。**论点是"语言是生成建模的最后一个离散孤岛"**（图像/视频/音频早已连续化）。

**Nemotron TwoTower**（NVIDIA，2026-06-25，✅）：**双塔解耦**——冻结的 AR 上下文塔（因果处理干净 token）＋ 可训练的扩散去噪塔（双向块注意力，交叉注意力读上下文）。解决"一个网络同时做上下文表示与迭代去噪"的能力冲突。

**REFLEX**（2026-08-03，✅）：**MoE × 扩散的交叉**——把 MoE 推理重新定义为"精炼感知的计算分配"，扩散 LM 中不同块/不同精炼轮次分配不同专家算力。

**要点解读**：扩散 LM 的完整拼图已出现——**Google（DiffusionGemma）、NVIDIA（TwoTower）、学界（AURORA-LM）+ 速度验证（Celeris-1）**。这是**唯一在"解码复杂度"上做出根本性改变**的路线（O(T) → O(T/B)），但**质量门槛尚未跨越**——2026 年处于"速度革命已证、质量革命未证"的窗口期。

### 3.4 低比特/硬件协同：BitNet v2 与 NVFP4

**BitNet v2**（2025-04，✅）：**1.58-bit 权重 + 原生 4-bit 激活（Hadamard 变换）**——1-bit LLM 的规模化路线；
**Sparse-BitNet**（2026-03，✅）：1.58-bit 与半结构化稀疏天然友好——**低比特 × 稀疏的双重压缩**；
**NVFP4 预训练**（Nemotron 3 Ultra 采用）：**FP4 精度直接用于预训练**——精度从"训练后量化"前移到"训练时原生"；
**kimi-k3-in-c**（记忆锚点 🔵）：2.8T MoE 以极端量化 + 纯 C 实现单 CPU 推理（8.24GB 内存）——**开放权重的本地化硬件需求倒逼**。

**要点解读**：低比特路线的核心逻辑是**"精度冗余是当前硬件最大的浪费"**——BF16 训练/FP8 推理的大部分比特位对能力无贡献。BitNet 范式的终局是**为 1-bit 原生训练设计专用硬件**（乘法变成加法/位运算）。这是**算法主动适配硬件**的路线——与扩散（架构适配并行性）互补。

### 3.5 KV/上下文压缩前沿

| 技术 | 来源 | 要点 |
|:-----|:-----|:-----|
| **GSRQ** | 2026-07-01 ✅ | Gain-Shape 残差量化，**sub-1-bit KV Cache** |
| **ResKV / RestoreKV** | 2026-07/08 ✅ | 重建被省略的注意力贡献 / 恢复全缓存行为 |
| **S⁴R** | 2026-08-01 ✅ | 选择性采样 + 子空间 + 稀疏重建的压缩长上下文 KV |
| **Practical Online KV Compaction for Agents** | 2026-08-02 ✅ | **面向 Agent 的在线 KV 压缩实证**——直接命中 08-04/08-05 编程 Agent 专题的 KV 瓶颈 |
| **LongCat Sparse Attention** | 2026-08-03 ✅ | 流式感知的分层跨层索引稀疏注意力 |
| **Structured Memory for Edge LMs** | 2026-08-03 ✅ | **O(1) SSM 状态注入**实现持久上下文——"记忆外挂"路线 |

**要点解读**：KV 压缩已从"量化技巧"演进为**"重建式压缩 + 稀疏注意力 + 结构化记忆"三路线并行**。特别值得注意：**Agent 在线 KV 压缩成为独立研究主题**——这验证了本库 08-04 编程 Agent 专题的核心结论（KV 容量 = Agent 推理第一瓶颈）。**"记忆外挂"（O(1) SSM 状态注入）指向终极形态：上下文不靠窗口，靠记忆架构**。

## 四、第一性原理 → 路标预判（未来 12-24 个月）

> ⚠️ 本节为推断（基于 Part 二/三的事实 + 第一性原理），非既有事实。每条预判标注确定性等级。

### 4.1 五条演进主线

**主线 1：MoE 从"静态路由"走向"动态计算分配"**（确定性：高）

- 证据：REFLEX（精炼感知分配）、HetRoute/TrimMoE（通信感知路由）、vLLM MRV2 聚焦 routed-experts capture（记忆锚点 🔵）；
- 预判：路由不再"每 token 固定 Top-K"，而是**按任务难度/精炼轮次/通信代价动态分配专家与算力**——推理引擎需要支持"计算预算感知的调度"。

**主线 2：上下文从"窗口"走向"记忆架构"**（确定性：高）

- 证据：KV 压缩三路线并行 + Structured Memory O(1) SSM 注入 + 1M 标配；
- 预判：**"无限上下文"不是靠无限 KV，而是靠分层记忆**——热窗口（attention）＋ 中程压缩（MLA/SSM 状态）＋ 冷存储（G3.5 分层）＋ 外部检索（向量库）。这对存储系统的含义：**KV 分层是确定的存储新负载**（与 08-05 IO 专题、G3.5 共识闭环）。

**主线 3：扩散进入主流推理**（确定性：中高，质量是门槛）

- 证据：DiffusionGemma（<10% 训练预算微调）＋ Celeris-1 2158 t/s ＋ TwoTower/AURORA-LM；
- 预判：2026H2-2027 出现**首个质量追平 AR 的扩散模型**（大概率由 Google 或开源社区驱动）；扩散先落地于**高吞吐/低延迟敏感**场景（代码补全、批量生成、Agent 工具调用中间步骤），再逐步上探；
- **基础设施含义**：扩散推理的算力需求形态与 AR 完全不同（prefill 主导、无逐 token decode、可并行块）——**推理引擎需要新调度模型**。

**主线 4：算法-硬件联合设计成为新常态**（确定性：中）

- 证据：NVFP4 预训练、Sparse-BitNet、kimi-k3-in-c 纯 C 推理、Groq LPU 收购（记忆锚点 🔵）；
- 预判：2027 年出现**面向 1-bit/低比特原生训练的专用芯片**（ASIC 或 GPU 新指令集）；x86/ARM CPU 的向量扩展（AMX/AVX/SVE）继续加码低比特支持——**低比特从"推理优化"升格为"训练范式"**。

**主线 5：文本连续化——多模态统一**（确定性：中低）

- 证据：AURORA-LM 明确论点"语言是最后的离散孤岛"；
- 预判：中长期（2027+）文本走向连续潜空间，与图像/视频/音频共享生成框架——**单一扩散/流匹配架构统一多模态**。这是最激进但也最慢的路线。

### 4.2 三个可能的范式拐点

| 拐点 | 触发条件 | 影响 |
|:-----|:---------|:-----|
| **扩散质量追平 AR** | 任一前沿模型（≥Gemma 4 级）扩散版在标准 benchmark 追平/超越 AR 版 | 推理架构洗牌：解码不再逐 token，推理引擎/硬件全部重设计 |
| **1-bit 训练规模化** | BitNet 范式在 ≥100B 参数规模证明无损 | 算力需求断崖：训练/推理成本降 1 个数量级，专用芯片窗口打开 |
| **记忆外挂取代上下文窗口** | O(1) 记忆注入在 Agent 长会话中稳定超越 1M 窗口 | "上下文工程"让位于"记忆工程"，存储系统地位进一步上升 |

### 4.3 可证伪预测 P1-P5

| # | 预测 | 时间窗 | 证伪条件 |
|:-:|:-----|:-------|:---------|
| P1 | 首个质量追平 AR 的扩散模型出现 | 2026H2-2027 | 2027 年底前无任何扩散模型进入主流 benchmark 前三 |
| P2 | 前沿模型全部采用"细粒度专家 + 潜空间路由"MoE 形态 | 2026 年底 | 任一 Top-5 模型发布仍用粗粒度 Top-K 且无潜空间路由 |
| P3 | 混合架构（SSM+Attention）成为 100B+ 开源模型主流配置 | 2027 年中 | 2027 年开源 Top-5 中混合架构占比 < 50% |
| P4 | KV 分层存储进入生产推理系统标配 | 2027 年 | 主流推理引擎无 KV 冷热分层/卸载能力 |
| P5 | 低比特（≤4-bit）原生训练成为新模型训练默认选项之一 | 2027 年底 | 2027 年 Top 模型训练仍全部为 BF16/FP8 |

## 五、对超节点/推理基础设施的启示

1. **架构分叉期 = 基础设施的"多范式适配期"**：超节点不能只为 AR MoE 优化——需预留扩散（并行块计算）、混合（线性复杂度算子）、低比特（新精度路径）的适配能力。**"一套硬件吃所有架构"的窗口正在关闭**。

2. **KV 分层是确定的存储新负载**：无论哪条架构路线胜出，KV 从内存到存储的迁移都是确定的（G3.5 共识）。**KV 冷层存储的带宽/容量规划应立即启动**——这与 08-05 IO 专题、G3.5 分层温存储共识闭环。

3. **MoE 动态路由改变网络需求**：refinement-aware / 通信感知路由意味着**专家间通信模式从固定变为动态**——网络需要支持"流量模式不可预测"的弹性设计（呼应超节点互连的容错与动态路由议题）。

4. **扩散若成，推理引擎与硬件全重设计**：这是最大的"黑天鹅"——建议在基础设施路线图中**设立扩散推理 PoC 跟踪点**（与 GTC/FMS/ODCC 观测并行）。

5. **低比特训练改变算力账本**：1-bit 训练若规模化，**超节点的算力规划假设（FLOPs/瓦）需要重估**——"算力过剩"与"算力不足"的判断可能同时反转（训练更便宜，但推理需求随 Agent 化继续膨胀）。
