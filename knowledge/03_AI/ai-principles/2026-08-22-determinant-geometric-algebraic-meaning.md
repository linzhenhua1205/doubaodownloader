## 1. 引言：为什么行列式值得深度分析

行列式（determinant）是线性代数中一个"既简单又深刻"的对象：从代数上看，它只是 n×n 矩阵到数的一个函数；从几何上看，它回答了一个根本问题——**一个线性变换把 n 维空间中的体积放大了多少倍，以及是否翻转了方向**。

对 AI 基础设施从业者而言，行列式并非纯理论装饰，而是隐身在多个高频计算背后的数学引擎：

- 特征值问题 $\det(A - \lambda I) = 0$ 是所有谱方法（PCA、谱聚类、振动分析）的起点；
- 多元高斯分布的归一化常数含 $\det \Sigma$，一切概率生成模型都绕不开它；
- Normalizing Flow 的可训练目标里直接出现 $\log|\det J|$；
- 数值线性代数中，LU 分解算行列式是标准操作，而"用 det 判断病态"则是经典误区。

本文的目标不是罗列行列式的公式，而是建立**第一性原理**：行列式为什么存在、为什么唯一、为什么同时具有代数与几何两种面孔。核心论点是——**行列式是"体积"这一几何概念在代数上的精确化，而"体积"又反过来是行列式代数性质的几何化身**。两者由外代数这座桥完全统一。

## 2. 代数意义：行列式是唯一的多重线性交替形式

### 2.1 出发点：用"一个数"刻画可逆性

设 $A$ 是 $n \times n$ 矩阵，线性方程组 $Ax = b$。最基本的分类问题是：$A$ 是否可逆？即方程组是否对任意 $b$ 有唯一解。

代数上，$A$ 可逆 ⟺ $A$ 的行（列）线性无关 ⟺ $\text{rank}(A) = n$。但"秩"是离散的、需要全局判断的量。一个自然的追求是：**能否找到一个连续的、逐项可算的标量函数，使得"该函数非零"等价于"可逆"？**

行列式就是这个函数。它的现代公理化定义（Artin, 2010）如下。

### 2.2 公理化定义：三条性质锁定唯一函数

**定义（行列式）**：函数 $\det: \mathbb{F}^{n \times n} \to \mathbb{F}$ 是满足以下三条性质的**唯一**函数：

1. **多重线性（Multilinearity）**：对每一行（或每一列）是线性的。即固定其他行，第 $i$ 行满足 $\det(\dots, \alpha u + \beta v, \dots) = \alpha \det(\dots, u, \dots) + \beta \det(\dots, v, \dots)$；
2. **交替性（Alternating）**：交换任意两行，行列式变号；特别地，若两行相同则 $\det = 0$；
3. **归一化（Normalization）**：$\det(I_n) = 1$。

> **第一性原理洞察**：这三条性质不是随意拼凑的。它们恰恰是**"有向体积函数"应当满足的几何要求**——体积对边长是线性的（多重线性）、交换两条边的顺序会反转定向（交替性）、单位立方体体积为 1（归一化）。换言之，代数定义是从几何直觉中提炼出来的。

由这三条公理可以推导出所有经典公式：

**Leibniz 公式**（显式表达式）：
$$\det A = \sum_{\sigma \in S_n} \operatorname{sgn}(\sigma) \prod_{i=1}^{n} a_{i,\sigma(i)}$$
其中 $S_n$ 是 $n$ 阶置换群，$\operatorname{sgn}(\sigma)$ 是置换的符号（奇偶性）。这个公式是公理 2 的直接推论：交替性强制每一项只能取"每条对角线选取一个元素"的形式，符号由逆序数决定 [1]。

**Laplace 展开**（按行递归）：
$$\det A = \sum_{j=1}^{n} (-1)^{i+j} a_{ij} \det(M_{ij})$$
其中 $M_{ij}$ 是删去第 $i$ 行第 $j$ 列后的 $(n-1) \times (n-1)$ 余子阵 [2]。

### 2.3 由公理推出的关键代数性质

| 性质 | 表述 | 证明要点 |
|:-----|:-----|:---------|
| **乘法性** | $\det(AB) = \det(A)\det(B)$ | 固定 $A$，把 $B$ 看作列向量组，$B \mapsto \det(AB)$ 是满足三条公理的多重线性交替形式，由唯一性等于 $\det(A)\det(B)$ [1] |
| **可逆判据** | $A$ 可逆 ⟺ $\det A \neq 0$ | $\det A \neq 0$ ⟺ 行线性无关（交替性）⟺ 满秩 [2] |
| **转置不变** | $\det(A^T) = \det(A)$ | 行列按 Leibniz 公式展开等价（逆序数对称性）[1] |
| **初等行操作** | 行交换变号；某行乘 $c$ 则 det 乘 $c$；行加另一行的倍数不改变 det | 直接由公理 1、2 推出 |
| **上三角** | 上（下）三角矩阵的 det = 对角线元素之积 | Laplace 展开递推 |
| **群同态** | $\det: GL_n(\mathbb{F}) \to \mathbb{F}^{\times}$ 是乘法群同态 | 乘法性 + 可逆判据 |

**Cramer 法则**：若 $\det A \neq 0$，则 $Ax = b$ 的唯一解为 $x_i = \dfrac{\det(A_i)}{\det(A)}$，其中 $A_i$ 是把 $A$ 第 $i$ 列替换为 $b$ 得到的矩阵 [1]。这在理论上优雅（解的显式公式），但计算上 $O(n!)$ 不可行——实际求解用高斯消元 $O(n^3)$。**Cramer 法则的价值在理论，不在计算。**

### 2.4 特征多项式：行列式与特征值的代数纽带

**定义**：$A$ 的特征多项式为 $p_A(\lambda) = \det(A - \lambda I)$。特征值就是 $p_A(\lambda) = 0$ 的根。

由此得出两个极其重要的恒等式（对任意 $n \times n$ 复矩阵，含重数）[3]：

$$\det(A) = \prod_{i=1}^{n} \lambda_i, \qquad \operatorname{tr}(A) = \sum_{i=1}^{n} \lambda_i$$

证明要点：$p_A(\lambda) = \det(A - \lambda I)$ 的常数项（$\lambda = 0$ 时）正是 $\det A$，而 $\lambda^{n-1}$ 项的系数给出迹。**行列式是特征值的乘积**——这条代数恒等式在 4.2 节将获得几何解释。

**Cayley-Hamilton 定理**：$p_A(A) = 0$，即矩阵满足自己的特征方程 [3]。这是行列式在矩阵多项式理论中的核心应用。

### 2.5 计算复杂度：为什么实际算行列式不用定义

| 方法 | 复杂度 | 适用场景 |
|:-----|:------:|:---------|
| Leibniz 公式（定义直算） | $O(n!)$ | $n \le 8$ 的教学演示；$n=20$ 时约 $2.4 \times 10^{18}$ 项，不可行 |
| Laplace 展开递归 | $O(n!)$ | 稀疏/带状矩阵的符号计算 |
| 高斯消元 + 行交换 | $O(n^3)$ | 数值计算标准方法（见 5.5） |
| LU 分解 | $O(n^3/3)$ | 数值线性代数库（LAPACK 等）的实现方式 [5] |

> **量化对比** [5]：$n = 100$ 时，Leibniz 公式需约 $10^{158}$ 次乘法（宇宙原子数约 $10^{80}$），而 LU 分解只需约 $3.3 \times 10^5$ 次浮点运算——**差约 152 个数量级**。这是"定义用于理论、算法用于计算"的典型例证。

## 3. 几何意义：行列式是有向体积的缩放因子

### 3.1 二维：平行四边形面积

设 $A = \begin{pmatrix} a & c \\ b & d \end{pmatrix}$，列向量 $v_1 = (a,b)^T$、$v_2 = (c,d)^T$。

$$\det(A) = ad - bc = \text{平行四边形} \square(0, v_1, v_2) \text{的}\textbf{有向}面积$$

```
    y
    ^
    |       v2 = (c, d)
    |      /|
    |     / |   area = |ad - bc|
    |    /  |        = |det(A)|
    |   /   |
    |  /    |
    | /_____|
    |v1=(a,b)
    +-----------> x
```

**为什么是"有向"**：当 $v_2$ 在 $v_1$ 的逆时针方向时 $ad - bc > 0$；交换 $v_1, v_2$ 顺序则面积为负。**绝对值是有向面积，符号是定向信息** [1]。

**验证直觉**：取 $v_1 = (2,0)$、$v_2 = (0,3)$，则 $\det = 2 \times 3 - 0 \times 0 = 6$，恰为边长 2×3 矩形的面积 ✓。

### 3.2 三维：平行六面体体积与混合积

设三列 $a, b, c \in \mathbb{R}^3$，则：

$$\det[a\ b\ c] = a \cdot (b \times c) = \text{平行六面体的有向体积}$$

这就是**混合积（scalar triple product）**公式 [1]。叉积 $b \times c$ 给出底面平行四边形的**面积矢量**（大小为面积、方向为法向），再与 $a$ 点积得到"底面积 × 高"。这个公式揭示了 3D 中三个独立概念的同一性：

> **叉积 ⊗ 点积 ⊗ 行列式 = 体积**——几何对象（面积矢量）与代数对象（行列式）在此处完全等价。

### 3.3 线性变换的体积缩放：vol(T(S)) = |det A| · vol(S)

**核心定理**：设 $T(x) = Ax$ 是 $\mathbb{R}^n$ 上的线性变换，$S$ 是任意可测区域，则 [1]：

$$\operatorname{vol}(T(S)) = |\det A| \cdot \operatorname{vol}(S)$$

**证明思路（第一性原理）**：
1. 对**单位立方体**成立：由公理 1（多重线性），$T$ 把单位立方体映为平行体，其体积恰为 $|\det A|$（这本身就是 3.1/3.2 的推广）；
2. 对**任意平行体**成立：平行体是单位立方体的仿射像，体积按同一因子缩放；
3. 对**任意区域**成立：用网格把 $S$ 剖分为小平行体的并，取极限（这是黎曼积分的定义过程）[1]。

这个定理把行列式从"平行体的属性"提升为"**变换的全局属性**"：无论区域形状如何，只要被 $A$ 作用，体积就统一乘上 $|\det A|$。**行列式因此不依赖于坐标系选择**——这是它作为"几何不变量"的根本原因。

### 3.4 符号的几何含义：定向（orientation）

```
  det > 0 (preserve orientation)   det < 0 (flip orientation)   det = 0 (collapse)

  |   |            |   |            |   |            |   |          |   |          / /
  |___|    ->      |_ _|            |___|    ->      |_ _|          |___|   ->    / /
 unit square     rotated          unit square     mirrored       unit square   to line
 det = 2          det = 2          det = 1         det = -1        det = 1       det = 0
```

- $\det A > 0$：变换保持定向（右手系 → 右手系，如旋转、拉伸）；
- $\det A < 0$：变换反转定向（右手系 → 左手系，如镜像反射）。**任何反射类变换的 det 必为负**，例如 $\begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}$（交换 $x,y$ 轴）的 det = $-1$；
- $\det A = 0$：变换坍缩到低维子空间，体积信息完全丢失 [1]。

**为什么"负体积"是合法的**：几何上体积恒非负，但代数上必须允许负号，因为交替性要求"交换两列变号"。**定向正是交替性在几何世界的投影**——这是几何意义与代数意义第一次正面交汇。

### 3.5 退化情形：det = 0 即空间坍缩

$\det A = 0$ 意味着 $\text{rank}(A) < n$，即列向量线性相关，张成的平行体退化为低维对象（零体积）：

| det 值 | 变换的像 | 几何效果 |
|:------:|:---------|:---------|
| $\det A \neq 0$ | $\mathbb{R}^n$（满射且单射） | 体积保持缩放，可逆 |
| $\det A = 0$ | 维数 $< n$ 的子空间 | 至少一个方向被压扁，不可逆 |

**物理解读**：det = 0 的变换是"信息有损"的——多个输入映射到同一输出，无法从输出恢复输入。这与可逆性判据（2.3）完全一致：**代数上的"不可逆" = 几何上的"体积坍缩"**。

### 3.6 微分几何延伸：Jacobian 行列式

对非线性映射 $f: \mathbb{R}^n \to \mathbb{R}^n$，$f$ 在点 $x$ 的**局部线性近似**由 Jacobian 矩阵 $J_f(x) = (\partial f_i / \partial x_j)$ 给出。行列式在此处扮演两个角色 [6]：

1. **局部体积缩放**：$\det J_f(x)$ 是 $f$ 在 $x$ 处无穷小体积的缩放因子；
2. **局部可逆判据（隐函数定理）**：$\det J_f(x) \neq 0$ ⟺ $f$ 在 $x$ 附近是局部微分同胚。

**积分换元公式**（多重积分的核心工具）：
$$\int_{f(S)} g(y)\, dy = \int_S g(f(x))\, |\det J_f(x)|\, dx$$

这是 3.3 定理的非线性推广：线性变换的全局缩放 $|\det A|$ 被替换为非线性变换的逐点缩放 $|\det J_f(x)|$。**行列式因此从线性代数"泄漏"进整个分析学**——凡是"变量替换 + 体积度量"之处必有它 [6]。

## 4. 统一视角：几何与代数如何合流

### 4.1 外代数：行列式是最高阶外幂的缩放

行列式的几何面孔（体积）与代数面孔（多重线性交替函数）的统一框架是**外代数（exterior algebra）**。

**关键事实**：$n$ 维向量空间 $V$ 的最高阶外幂 $\wedge^n V$ 是**一维**向量空间，其非零元素 $\omega = v_1 \wedge \cdots \wedge v_n$ 就是"$n$ 维体积元"。

线性映射 $A: V \to V$ 诱导出外幂映射 $\wedge^n A: \wedge^n V \to \wedge^n V$。由于 $\wedge^n V$ 是一维的，$\wedge^n A$ 只能是数乘：

$$\wedge^n A(\omega) = (\det A) \cdot \omega$$

**这就是行列式的现代定义** [3]：**行列式是线性映射在最高阶外幂上的作用系数**。体积元 $\omega$ 在 $A$ 作用下被缩放 $\det A$ 倍——代数定义（4.1）与几何解释（第 3 节）在此完全重合，不再需要"两条平行思路"，而是**同一个对象的两种读法**。

### 4.2 det = 特征值之积：体积分解为方向缩放之积

若 $A$ 可对角化 $A = P\Lambda P^{-1}$（$\Lambda = \operatorname{diag}(\lambda_1, \dots, \lambda_n)$），则 [3]：

$$\det A = \det(P) \det(\Lambda) \det(P^{-1}) = \prod_{i=1}^{n} \lambda_i$$

**几何解读**：变换 $A$ 的总体积缩放 = 沿每个特征方向 $\lambda_i$ 的缩放之积。**总体缩放是"各方向缩放"的乘积，而不是和**——这正是"体积"的乘法本质：$n$ 维体积是 $n$ 个独立方向的长度之积。

**为什么不用可对角化假设**：任意复矩阵经 Schur 三角化 $A = UTU^*$（$T$ 上三角，对角线即特征值），$\det A = \det U \det T \det U^* = \prod t_{ii} = \prod \lambda_i$ [4]。所以"det = 特征值之积"对**一切**复矩阵（含 Jordan 块、亏损矩阵）成立。

### 4.3 为什么行列式"只有一个"

**定理（唯一性）**：所有 $n$ 重交替多重线性形式构成一维向量空间；满足 $\det(I) = 1$ 的形式存在且唯一 [3]。

**证明要点**：设 $f$ 是任意 $n$ 重交替多重线性形式。固定 $A$，映射 $B \mapsto f(AB)$ 对 $B$ 的各列是交替多重线性的，因此 $f(AB) = f(A \cdot I) = f(\text{col}_1(A), \dots, \text{col}_n(A))$，即 $f$ 完全由它在 $I$ 上的取值决定；归一化 $f(I) = 1$ 后唯一。

**意义**：这解释了为什么 Leibniz 公式、Laplace 展开、几何体积定义**殊途同归**——它们都在计算同一个对象。行列式的"定义不唯一"只是表象，唯一性定理保证了深层的一致性。**这是一个教科书级的"多条定义路径收敛到同一数学对象"案例。**

### 4.4 det / tr / rank：三个不变量的互补角色

三者都是**相似不变量**（$PAP^{-1}$ 下不变），都是特征值的对称函数，但携带的信息不同 [4]：

| 不变量 | 定义 | 信息内容 | 性质 | 几何角色 |
|:------|:-----|:---------|:-----|:---------|
| $\text{rank}$ | 列空间维数 | 映射像的维数（离散） | 整数，不可微 | 映射的"维度图像" |
| $\det$ | $\prod \lambda_i$ | 总体积缩放（含定向） | 连续，多重线性 | 体积变换（全局） |
| $\operatorname{tr}$ | $\sum \lambda_i$ | 对角线之和（导数恒等式） | 连续，线性 | 体积对参数的**变化率** |

**关键洞察（det 的信息缺失）**：$\det A = \prod \lambda_i$ 只保留特征值的**乘积**，丢失了分布信息。例如 $\lambda = (100, 0.01)$ 与 $\lambda = (1, 1)$ 都有 $\det = 1$，但前者变换在一个方向上拉伸 100 倍、另一方向压缩 100 倍，后者是恒等——**几何行为天差地别，det 却完全相同**。

**互补性**：$\operatorname{tr}$ 作为 det 的"对数导数"（$\frac{d}{dt}\det(I + tA)\big|_{t=0} = \operatorname{tr}(A)$）提供线性信息；$\det$ 提供乘积信息；$\text{rank}$ 提供结构信息。三者合起来才构成特征值的完整图景 [4]。

### 4.5 数值警告：det 不是可逆性/病态性的可靠判据

这是工程中最常被误用的一点。**数学上 $\det A \neq 0$ 判可逆是精确的；数值上用它判病态是危险的** [5]。

**问题 1：det 对尺度敏感**。$\det(cA) = c^n \det(A)$，矩阵乘个常数 det 就剧烈变化。$A = 0.1 \cdot I_{10}$ 的 det = $10^{-10}$，但它完全良态。

**问题 2：det 与病态性无单调关系**。教科书级反例（Strang 经典）[1]：

$$\det \begin{pmatrix} 1 & 1000 \\ 0 & 1 \end{pmatrix} = 1, \qquad \text{cond} \approx 10^6$$

det = 1（与单位阵相同！）但条件数高达 $10^6$——因为奇异值 $\sigma_{\max} \approx 1000$、$\sigma_{\min} \approx 0.001$。**det 只告诉你"体积缩放"，条件数才告诉你"最坏方向的误差放大"**。

| 矩阵 | det | 条件数 cond | 病态性判断 |
|:-----|:---:|:-----------:|:----------|
| $I_2$ | 1 | 1 | 良态 |
| $\begin{pmatrix}1 & 1000 \\ 0 & 1\end{pmatrix}$ | 1 | $\approx 10^6$ | **严重病态** |
| $\begin{pmatrix}1 & 1 \\ 1 & 1.0001\end{pmatrix}$ | $10^{-4}$ | $\approx 2.7 \times 10^4$ | 病态 |
| $\operatorname{diag}(1, 0.01)$ | $10^{-2}$ | 100 | 中等 |

**结论** [5]：数值上判断可逆性/病态性应使用**秩（QR/SVD 分解）**和**条件数** $\text{cond}(A) = \sigma_{\max}/\sigma_{\min}$，而不是 det。det 适合理论论证（Cramer、特征多项式），不适合数值诊断。

## 5. AI 与工程中的行列式

### 5.1 多元高斯分布的归一化常数

$d$ 维高斯分布 $\mathcal{N}(x; \mu, \Sigma)$ 的概率密度为 [6]：

$$p(x) = \frac{1}{(2\pi)^{d/2} |\det \Sigma|^{1/2}} \exp\!\left(-\frac{1}{2}(x-\mu)^T \Sigma^{-1}(x-\mu)\right)$$

**行列式在此处的作用**：
1. **归一化**：$|\det \Sigma|^{1/2}$ 保证 $\int p(x) dx = 1$（密度函数的体积缩放因子，正是 3.3 定理）；
2. **分布形状**：$\det \Sigma = 0$ ⟺ $\Sigma$ 奇异 ⟺ 分布退化到低维子空间（变量线性相关，信息冗余）；
3. **信息量**：$\frac{1}{2}\log|\det \Sigma|$ 与微分熵 $h = \frac{d}{2}(1 + \log 2\pi) + \frac{1}{2}\log|\det \Sigma|$ 直接挂钩——**det 度量了分布携带的"体积"信息** [6]。

### 5.2 PCA 与协方差矩阵的行列式

PCA 对数据协方差矩阵 $\Sigma = \frac{1}{N}\sum (x_i - \bar{x})(x_i - \bar{x})^T$ 做特征分解 $\Sigma = U \Lambda U^T$，则 [6]：

$$\det \Sigma = \prod_{i=1}^{d} \lambda_i = \text{数据点云沿各主成分方向的方差之积}$$

- $\det \Sigma$ 度量数据点云的**总体散布体积**（椭球的体积，椭球轴长 = $\sqrt{\lambda_i}$）；
- $\det \Sigma = 0$ ⟺ 数据落在低维子空间（存在零方差方向）⟺ 特征冗余可压缩；
- 降维保留的主成分数 $k$ 由 $\sum_{i=1}^{k}\lambda_i / \sum_{i=1}^{d}\lambda_i$（**迹**！）决定——这里 det 描述整体形状，tr 描述信息占比，两个不变量分工明确（呼应 4.4）[6]。

### 5.3 生成模型：Normalizing Flow 的 log|det J|

Normalizing Flow（如 RealNVP、Glow）用可逆映射 $f$ 把简单分布 $p_Z$ 变换为目标分布 $p_X$。由换元公式：

$$\log p_X(x) = \log p_Z(f^{-1}(x)) + \log|\det J_{f^{-1}}(x)|$$

**训练目标直接含行列式** [6]。工程关键：
- 一般 $n \times n$ Jacobian 的 det 计算 $O(n^3)$ 太贵，所以 flow 设计为**三角 Jacobian**（RealNVP 的 coupling layer：$\det$ = 对角线之积，$O(n)$）；
- 这也解释了为什么 flow 架构刻意保持"对角线主导"——**行列式计算的复杂度约束了网络结构设计**。这是"数学成本塑造算法架构"的鲜活案例。

### 5.4 最小二乘与正规方程

最小二乘解 $\hat{x} = (A^T A)^{-1} A^T b$ 的存在性要求 $(A^T A)$ 可逆 ⟺ $\det(A^T A) \neq 0$ ⟺ $A$ 列满秩（$\text{rank}(A) = n$）[6]。

**警告**：$A^T A$ 的条件数 = $\text{cond}(A)^2$，病态性被平方放大。所以数值稳定的最小二乘用 QR/SVD 而非正规方程——**又是"别用 det/显式逆"原则** [5]。

### 5.5 数值计算：LU 分解与 det

LAPACK 等库计算 det 的标准流程 [5]：

```
1. LU factorization with row pivoting: PA = LU
2. det(A) = (-1)^(num swaps) * prod(diag(U))
   - L has unit diagonal, contributes nothing
   - U is upper triangular, det(U) = prod of diagonal (Sec 2.3)
   - sign of P = parity of row swaps
```

复杂度 $O(n^3/3)$，一次分解同时服务求解、求逆、det 三个需求。**注意**：即使是 LAPACK 的 det 也可能下溢/上溢（$n=1000$ 时 det 可到 $10^{\pm 1000}$ 量级），工程上常改用 **log|det|**（det 的对数）——这也是 flow 损失函数用 $\log|\det|$ 的另一个实际原因。

## 6. 常见误区辨析

| # | 误区 | 真相 |
|:-:|:-----|:-----|
| 1 | $\det A = 0$ 意味着方程组"无解" | 意味着**无唯一解**：可能无解，也可能有无穷多解（取决于 $b$ 是否在列空间中）。$\det A \neq 0$ 才是"任意 $b$ 有唯一解" [1] |
| 2 | $\det$ 很小 ⟹ 矩阵病态 | **错误**。$\det$ 对尺度敏感（$\det(cA) = c^n \det A$）；病态性由条件数刻画（4.5 节的 $I_2$ vs $\begin{pmatrix}1&1000\\0&1\end{pmatrix}$ 反例）[1][5] |
| 3 | "det = 特征值之积"只对可对角化矩阵成立 | 对**任意**复矩阵（含重数、含 Jordan 块）成立，Schur 三角化证明（4.2）[3] |
| 4 | 3D 叉积就是行列式 | 叉积 $a \times b$ 是**向量**；$\det[a\ b\ c] = a \cdot (b \times c)$ 是**标量**（混合积）。两者关系密切但不同对象 [1] |
| 5 | 行列式是"算面积的公式" | 行列式是**有向体积泛函**（满足多重线性+交替的唯一函数）；面积/体积公式只是其在 2D/3D 的特例 [2] |
| 6 | 行列式的各种定义（Leibniz/Laplace/几何）是不同概念 | 它们是**同一对象**的不同计算方式，唯一性定理（4.3）保证一致性 [3] |
| 7 | 数值库用 det 判断奇异 | 数值判断用**秩**（QR/SVD）与**条件数**；det 只适合理论/精确算术（4.5）[5] |

**一句话结论**：行列式是"有向体积"的代数精确化——它是唯一满足多重线性、交替性、归一化的函数（代数），等价于线性变换对 $n$ 维体积元的缩放系数（几何），二者由外代数统一；理解它既要用公理推导代数性质，也要用平行体/体积缩放建立几何直觉，同时必须警惕它在数值诊断中的滥用。
