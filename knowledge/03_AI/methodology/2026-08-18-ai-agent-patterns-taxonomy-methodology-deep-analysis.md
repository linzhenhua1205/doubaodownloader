## §0 执行摘要

**v3.0 完成两次跃迁：本系统提炼从 3 个扩充至 12 个原创模式（Part B），并引入六大第一性原理透镜对全部模式做原理级分析（Part C）。** 核心判断：

1. **本系统不是"网络模式的消费者"，而是"模式生产者"**：12 个原创模式（流水线/上下文重置/spec 委派/落盘即完成/机器门禁/分档投入/三角验证/蒸馏门禁/分层记忆/三职责分离/独立评审链/意图锚点）中，多数是网络模式**在长期运行压力下收敛出的工程强化形态**——例如"蒸馏+人工门禁"是 MemGPT 的可靠性强化版（机器压缩 + 人审防漂移）。

2. **六大第一性原理透镜可以把 61 个模式（49 网络 + 12 本系统）全部归入六个原理簇**：博弈论（委托-代理，治自我偏爱）、信息论（率失真/信道编码，治目标漂移）、控制论（反馈回路，治偷懒）、认知科学（认知卸载）、经济学（边际收益）、系统论（故障域隔离）。**每个退化模式的"药"都能找到对应的原理级根源。**

3. **原理级洞见：模式有效的根本原因与失效边界同样来自同一原理**——例如蒸馏（信息论率失真）既解决上下文超限又必然丢边缘条件；独立评审（博弈论）既消除自我偏爱又引入评审者自身偏差（需要二阶评审）。**理解模式 = 理解原理在什么条件下成立、在什么条件下反噬。**

4. **最深的统一**：三退化模式的三个对策（计划/约束/外壳）分别对应**信息论（目标信号保真）、控制论（执行收敛）、博弈论（评估可信）**——架构问题是三类原理问题的投影，这解释了为什么"模型升级不能根治"（原理层问题无法用能力层解决）。

## Part B 本系统提炼（12 原创模式）

## §9 本系统 12 个原创模式

> 每个模式：**核心机制** | **解决的问题** | **第一性原理根源**（原理透镜见 §10）。这些模式是 CowAgent 100+ 天运行在"质量事故-修复"循环中收敛出的工程形态，**多数是网络模式在长期压力下的可靠性强化版**。

### B1 工程形态类（外壳层）

**O1. 六阶段流水线**（Input-QA→Multi-path→Convergence→Verification-loop→Constraint-enforcer→Expert-gate）

- 机制：每个阶段有明确 gate，产出经多路并行→汇聚→循环验证→约束检查→专家签收
- 解决：输出质量不可预期；"碰运气"式 AI 使用
- **原理根源：系统论（模块化 + 故障域隔离）**——每个阶段是独立故障域，错误被隔离在单阶段；同时是**控制论**：多级 gate = 级联控制器，每级检测+修正

**O2. 落盘即完成三连**（write + log + commit 验收三角）

- 机制：Done 前 check gate——文档已 write + log 已追加 + git 已 commit，任一缺失禁止收尾（RULE.md 铁律）
- 解决：AI 口头完成任务但无产物；"未落盘 = 未完成"
- **原理根源：博弈论（可验证承诺）**——口头承诺不可验证，落盘+commit 创造**可追溯的验收点**（类似合同中的书面交付物）；同时是**信息论**：产物落盘=信息从易失（上下文）到持久（磁盘）的转移

**O3. 机器门禁**（doc-final-check / link-validator / check_format）

- 机制：发布前脚本化校验（格式 R1/链接/量化来源），机器拦截而非人审
- 解决：AI 自审不可靠（自我偏爱）；人工审查成本高
- **原理根源：博弈论（规则替代裁量）**——把"评审"从人/LLM 的裁量变成**无情的规则执行**；门禁无动机、无疲劳、无偏袒——确定性评审的极致

**O4. 分档投入 + 反向激励**（调研 runner depth 字段）

- 机制：任务分档（deep ≥30KB 无上限可读全文 / track ≤15KB 读前 30 行）；verify 反向激励（<15KB 输出 WARN"检查是否被压缩"）
- 解决：任务价值与投入不匹配；"省 token"导致的浅层产出
- **原理根源：经济学（边际收益）**——不同价值任务的最优投入点不同；反向激励=把"省 token"的负激励变成"质量不达标"的显式 WARN——**用激励结构对抗偷懒**

### B2 上下文管理类（记忆层）

**O5. agent_stream 上下文重置**（外科手术式上下文管理）

- 机制："深度分析"前缀 → 重置上下文（仅 system + 当前消息，旧历史 flush_memory 不丢）；turns<5 压缩分支补 flush + summary 注入
- 解决：长上下文污染 → 目标漂移；修复 189→7 丢 85% 事故
- **原理根源：信息论（信噪比）**——上下文是共享信道，历史噪声挤占当前信号；重置=**丢弃噪声信道的干净重启**；同时是**认知科学**：类比睡眠巩固（清醒时积累噪声，睡眠时巩固重要记忆）

**O6. 分层记忆三级 + 频率判据**（MEMORY.md 长期 / memory/ 每日 / knowledge/ 结构化）

- 机制：按信息频率定存储位置（>1 周不入 memory/，<1 月不入 MEMORY.md，自动记忆一律 Candidate.md）
- 解决：记忆无层级 → 检索失效/长期信息淹没
- **原理根源：认知科学（工作记忆/长期记忆分离）**——人类记忆分层（感官/短期 7±2/长期），Agent 记忆必须同样分层；频率判据=**记忆的"热力学"：高频信息进长期存储（低熵），低频信息留短期（高熵）**

**O7. 蒸馏 + 人工审核门禁**（每日 23:50 Deep Dream 蒸馏 → Candidate.md → 人工并入）

- 机制：自动记忆不直写 MEMORY.md（hard block + 双保险），蒸馏产物进 Candidate.md，**人工审核后才可并入**
- 解决：机器蒸馏的目标漂移风险；"自动记忆污染长期记忆"
- **原理根源：信息论（率失真）**——蒸馏=有损压缩，保高频弃低频 → 边缘条件丢失 → 目标漂移；**人工门禁=在信息损失处加"人工无损检查点"**——用不可自动化的判断兜底自动化的损失

**O8. 原始意图锚点**（命题保留 §0 + Changelog）

- 机制：深度分析文档开头保留用户原始命题 + Changelog 记录版本演化；里程碑对照验证
- 解决：上下文压缩后目标漂移；"Agent 优化目标偏离用户初衷"
- **原理根源：信息论（保真度约束）**——压缩必然有损，**保真约束（原始命题保留）= 有损压缩的"无损锚点"**；类似 JPEG 保留关键帧 + 差分帧

### B3 委派与验证类（组织层）

**O9. ticket-as-spec**（任务规格化委派）

- 机制：任务以 spec（目标/验收标准/范围）委派，而非模糊请求
- 解决：完成形态模糊 → 半件事陷阱；"不敢交 = 说不清该长什么样"
- **原理根源：信息论（信道容量）**——用户到 Agent 的指令信道有损，**spec 化 = 提高信道冗余（目标/验收/范围三维编码）**；同时是**博弈论**：明确验收标准 = 委托-代理合同的显式化

**O10. 三阶段走读独立评审链**（作者 → 评审 → 安全审查）

- 机制：代码/文档经三级独立角色（作者自查 → 结构评审 → 安全攻击面审查）
- 解决：作者自审的自我偏爱；安全漏洞的盲区
- **原理根源：博弈论（委托-代理 + 激励分离）**——评审者与作者激励不同（作者想交付，评审者想找问题），**激励分离 = 对抗性验证的结构保证**；mantis 17 阶段=评审的机械化

**O11. 三角验证**（多源交叉验证铁律）

- 机制：关键量化数据须 ≥2 独立源交叉验证；import/ 素材批判使用
- 解决：单源幻觉/被操纵数据
- **原理根源：信息论（信道编码冗余）**——独立源 = 独立信道，**冗余 + 交叉校验 = 纠错编码**；与通信的奇偶校验/前向纠错同构

**O12. 三职责分离**（README 条目库 / index 自动生成 / log 全局账本）

- 机制：索引三文件各司其职，AI 禁编辑，脚本批量生成维护
- 解决：索引职责混乱 → 维护失效；AI 手编索引的漂移
- **原理根源：系统论（单一职责 + 关注点分离）**——与操作系统的文件系统/目录/日志分离同构；**AI 禁编辑 = 把确定性维护交给确定性工具（脚本）**

## §12 原理级深度分析

### 12.1 博弈论簇：为什么"独立评审"是自我偏爱的唯一解药

**第一性原理**：委托-代理理论（Jensen & Meckling 1976）——委托人（用户）无法完全观测代理（Agent）行为与能力，代理有信息优势；当代理同时是"裁判"时（自评），**裁判与运动员激励一致，评价必然偏向运动员**。自我偏爱不是"模型坏"，是**激励结构缺陷**。

**推论链**：
1. Self-Refine（自评）→ 有效上限：仅能发现"自己知道错了"的错误（初稿笔误类），无法发现"自己认为对"的错误（幻觉/偏见）——**自评的盲区 = 生成者的盲区**
2. Reflexion（外部信号）→ 有效条件：环境提供**客观误差信号**（测试失败/环境反馈），反思才有锚点
3. CRITIC（工具验证）→ 把"信号源"从自身扩展到工具（搜索引擎/解释器），**工具是第一批"外部真理"**
4. Evaluator-Optimizer（分离 LLM）→ 信号源仍是 LLM，但**权重/上下文分离**，降低同源偏差
5. 独立评审者（人/另一系统）→ 激励完全分离，但引入**二阶问题：评审者自身有偏差**
6. 机器门禁（本系统 O3）→ **用无偏差的规则替代有偏差的判断**——门禁是博弈论的最强形态：评审者没有"观点"，只有"规则"

**本系统实证**：O3 机器门禁 + O10 三阶段走读 + O11 三角验证构成三层：**规则层（脚本）→ 角色层（三级评审）→ 数据层（多源交叉）**——从机制上让"自利判定"无处可藏。

**边界**：门禁只能验证**可规则化**的质量维度（格式/链接/来源）；**不可规则化**的维度（洞察深度/逻辑严密性）仍需人审——**博弈论解药的天花板 = 规则的可表达性**。

### 12.2 信息论簇：为什么"目标漂移"是压缩的必然产物

**第一性原理**：率失真理论（Shannon 1948 / Rate-Distortion Theory）——任何有损压缩在码率 R < 信源熵 H 时必然失真；**最优压缩策略是保高频弃低频**（如 JPEG 保留低频分量）。目标的**边缘条件（低概率/长尾约束）正是低频分量**——压缩必然优先牺牲它们。

**推论链**：
1. 上下文压缩 → 边缘条件丢失（"除了 X 情况""必须在 Y 条件下"）→ 目标边界松弛 → 优化目标漂移
2. 漂移累积：每轮压缩 d_i = H(G_{i-1}) - H(G_i|G_{i-1})，总损失 = Σd_i——**漂移不是单次错误，是误差累积**
3. 防漂移的三种信息论手段：**冗余**（spec 三维编码 O9/三角验证 O11）、**保真锚点**（原始命题保留 O8/计划存 Memory）、**干净信道**（上下文重置 O5/子 Agent 干净上下文）
4. 本系统 O7 的独特解法：**蒸馏 + 人工审核门禁**——机器压缩是必然有损的，但**在损失点插入人工无损检查**（人审 Candidate.md），把"机器有损"变成"人可追溯"——**用人类判断补偿信息论极限**

**本系统实证**：O5 上下文重置（修复 189→7 丢 85% 事故）+ O8 意图锚点（§0 保留命题）+ O7 蒸馏门禁（Candidate.md 人工审核）——三层防漂移体系。

**边界**：人工审核门禁的容量有限（每日蒸馏量 > 人工可审量时，门禁形同虚设）——**信息论极限的最终解药是压缩前的无损归档**（memory.history.md 956KB 只读保留 = 无损主副本）。

### 12.3 控制论簇：为什么"循环收敛"能治偷懒

**第一性原理**：负反馈控制（控制论，Wiener 1948）——系统稳定性取决于：①误差可观测（测量）；②负反馈（修正方向正确）；③增益适当（修正幅度）。**"偷懒" = 系统提前判定"误差足够小"（完成判定失效）**，是**测量环节的缺失**——不是执行器（LLM）问题，是传感器（验收）问题。

**推论链**：
1. Ralph Loop 的收敛性依赖**环境状态可观测**（文件/测试结果变化）——观测消失，循环退化为"空转"
2. gate = 检测器 + 执行器：检测误差（格式/链接），执行修正（拦截/返工）——**gate 是"测量"的制度化**
3. 端状态验收（Anthropic）= 只测最终状态，不测过程——**把"过程不可观测"的缺陷绕开，只观测可观测的**
4. 本系统 O4 反向激励（<15KB WARN）= 在测量点加**激励信号**——把"未达标"变成显式警告，消除"无声的偷懒"
5. 深度分析铁律（≥8 turns/≥3 工具调用）= **最小激励约束**——设定"最低投入"下限，防止早期退出

**本系统实证**：Ralph 循环（pipeline-verification-loop 技能）+ O4 分档 WARN + 铁律最小工作量——三层防偷懒。

**边界**：循环收敛的前提是**误差单调可降**（每次迭代确实改进了）；若误差不可降（任务超出模型能力），循环退化为"死循环"或"幻觉收敛"——**需要最大轮数/停止条件（Guardrails exit conditions）防止发散**。

### 12.4 认知科学簇：为什么"外部化"是长任务的第一法则

**第一性原理**：工作记忆容量有限（Miller 1956：7±2），人类长任务（写作/编程/研究）的可靠执行依赖**认知卸载**（cognitive offloading）——书写、清单、备忘录、他人评审。Agent 的上下文窗口就是工作记忆，**长任务不外部化必退化**（08-17 三退化模式的认知科学根源）。

**推论链**：
1. 计划外部化（spec/PROMPT.md/ticket-as-spec）→ 把目标从易失工作记忆转移到持久介质
2. 分层记忆（O6）→ 模仿人类感官/短期/长期记忆分离；频率判据 = 记忆的"热力学"（高频进长期）
3. 技能库（Voyager）→ 程序性记忆的外部化（技能=肌肉记忆的代码形态）
4. ToT/LATS（多分支）→ 工作记忆的"并行化"（用 token 换广度，绕过 7±2 瓶颈）

**本系统实证**：O6 分层记忆 + O9 spec 委派 + 深度分析 TOC 计划前置——**知识库本身就是认知卸载的产物**（把"思考"沉淀为"文档"）。

**边界**：外部化过度 → 检索成本上升（信息在海量存储中难以定位）——**外部化需要配套检索机制**（本系统 memory_search + index 自动生成 = 外部化的检索层）。

### 12.5 经济学簇：为什么"分档投入"是最优资源配置

**第一性原理**：边际收益递减——每增加一单位投入（token/时间），边际收益递减；**最优投入点在边际收益 = 边际成本处**。任务价值不同 → 最优投入点不同；一刀切投入（都省或都砸）都是次优。

**推论链**：
1. 高价值任务（深度分析/竞品调研）→ 高投入（deep 档 ≥30KB 无上限/读全文）
2. 低价值任务（日常跟踪）→ 低投入（track 档 ≤15KB/读前 30 行）
3. 多 Agent 15× token 成本（Anthropic 实测）→ 只用于"价值 > 15× 成本"的任务
4. 本系统 O4 的反向激励 = **把"投入不足"从隐性变成显性**（WARN），让边际收益曲线可见

**边界**：价值难以事前度量（任务价值只在完成后才清楚）——**分档是事前估计，事后需验证**（verify 校验产出丰度 = 事后纠偏）。

### 12.6 系统论簇：为什么"故障域隔离"是架构的终极原则

**第一性原理**：故障域（fault domain）——错误传播受边界限制，隔离使局部错误不升级为系统错误。操作系统用进程隔离故障域，**Harness 用上下文隔离关注点**（08-05 同构论证）。

**推论链**：
1. 上下文隔离（子 Agent 干净上下文）→ 目标漂移被隔离在子 Agent 内，主 Agent 目标不污染
2. 角色分离（规划/执行/验证）→ 激励冲突被结构隔离
3. 流水线分段（六阶段 gate）→ 错误被隔离在单阶段
4. 三职责分离（O12）→ 索引系统自身的故障域隔离（脚本管确定性，AI 管创造性）

**本系统实证**：O1 六阶段流水线 + O12 三职责分离 + agent_stream 重置——**本系统架构的"操作系统化"**。

**边界**：隔离的代价是**接口开销**（跨上下文传递信息的成本/损耗——防传话游戏正是接口开销的解法）；过度隔离 → 信息碎片化。

## §13 原理失效边界（自反批判）

| 原理 | 模式 | 失效条件 | 反噬形态 |
|:-----|:-----|:---------|:---------|
| 博弈论 | 机器门禁 | 规则无法表达质量维度 | 合规但空洞的产出（格式全对、洞察为零） |
