## 基础设定

公平硬币单次正面/反面概率均为 p = q = 1/2，甲先抛掷，率先掷出正面者获胜，求甲最终获胜概率 P。

## 第一部分：初等数学（小学~初中，7种）

### 方法1：基础无穷等比数列求和

**推导**：甲获胜只能在第 1、3、5…奇数次抛掷成功：

- 第 1 次甲胜：P₁ = 1/2
- 前 2 次甲乙全反面，第 3 次甲胜：P₂ = (1/2)²·(1/2) = 1/8
- 前 4 次甲乙全反面，第 5 次甲胜：P₄ = (1/2)⁴·(1/2) = 1/32

数列为首项 a = 1/2、公比 r = (1/2)² = 1/4 的无穷等比数列：

```text
P = Σ a·r^k = a / (1-r) = (1/2) / (1 - 1/4) = 2/3
```

---

### 方法2：部分和取极限法

**推导**：前 m 轮甲获胜的累积部分和：

```text
S_m = 1/2 + 1/8 + ... + (1/2)·(1/4)^(m-1)
    = (1/2)·[1-(1/4)^m] / (1-1/4)
    = (2/3)·[1 - 1/(4^m)]
```

当 m→∞ 时，lim 1/(4^m) = 0，故 P = lim S_m = 2/3。

---

### 方法3：二进制区间长度累加

**推导**：将无穷抛掷序列 ω = (ω₁, ω₂, ω₃, …) 映射到 [0,1) 上的二进制小数：

```text
x = 0.ω₁ω₂ω₃…₂ = Σ ω_k · 2^{-k}
```

其中 ω_k = 1 表示第 k 次抛掷出正面（0 表示反面）。由于硬币公平，[0,1) 上的勒贝格测度就是概率测度。

**甲获胜 → 首位 1 出现在奇数位**。按二进制展开写出这些区间：

- 首位 1 在第 1 位（甲首掷正面）：区间 [0.1₂, 1.0₂)，即 [1/2, 1)。
  - 二进制表示：0.1xxxxxxxx…₂（首位固定为1，其余任意），测度 = 1/2

- 首位 1 在第 3 位（甲第 2 轮正面）：区间 [0.001₂, 0.01₂)，即 [1/8, 1/4)。
  - 二进制表示：0.001xxxxx…₂（前 2 位为 0，第 3 位为 1），测度 = (1/2)^3 = 1/8

- 首位 1 在第 5 位（甲第 3 轮正面）：区间 [0.00001₂, 0.0001₂)，即 [1/32, 1/16)。
  - 二进制表示：0.00001xxxx…₂（前 4 位为 0，第 5 位为 1），测度 = (1/2)^5 = 1/32

**可视化**：[0,1) 线段上的区间划分：

```text
0                                1/8   1/4               1/2                   1
+------+------+------+------+---+---+------+------+------+------+------+------+
                        ^           ^                    ^
                     甲第2轮胜   甲第3轮胜             甲首轮胜
                     [1/8,1/4)  [1/32,1/16)          [1/2,1)
```

**奇数位区间长度求和**（实质与方法 1 同一无穷级数）：

```text
P = 1/2 + 1/8 + 1/32 + 1/128 + …
  = (1/2) / (1 - 1/4)
  = 2/3
```

注意到偶数位（乙胜）对应的区间恰好填满剩下的 [0,1/2) 空间：

- 首位 1 在第 2 位（乙首轮胜）：[0.01₂, 0.1₂) = [1/4, 1/2)，测度 1/4
- 首位 1 在第 4 位（乙第 2 轮胜）：[0.0001₂, 0.001₂) = [1/16, 1/8)，测度 1/16
- 乙胜总测度：1/4 + 1/16 + 1/64 + … = (1/4)/(1-1/4) = 1/3

甲胜 + 乙胜 = 2/3 + 1/3 = 1 = 全测度 ✅ 验证区间划分完备性。

### 方法4：基础状态递推方程

**推导**：设甲先手胜率为 P：

- 甲第一次 1/2 概率掷正面直接获胜
- 1/2 概率掷反面，轮到乙抛掷；乙 1/2 概率掷正面甲直接落败，1/2 概率掷反面回到初始状态，甲胜率重回 P

列方程：P = (1/2)×1 + (1/2)×[(1/2)×0 + (1/2)P]
→ P = 1/2 + P/4 → 3P/4 = 1/2 → P = 2/3

---

### 方法5：对立事件联立方程

**推导**：设甲胜率 P，乙胜率 Q，必然 P+Q=1。
乙获得抛掷权的前提是甲首次掷反面（概率 1/2），此时乙处于先手地位，胜率等价于初始甲的胜率 P，即 Q = (1/2)P。
联立：P + P/2 = 1 → 3P/2 = 1 → P = 2/3

---

### 方法6：全概率公式展开法

**推导**：事件 A：甲最终获胜；H₁：甲首掷正面；T₁：甲首掷反面；H₂：乙首掷正面；T₂：乙首掷反面。

P(A) = P(H₁)P(A|H₁) + P(T₁)P(H₂|T₁)P(A|T₁H₂) + P(T₁)P(T₂|T₁)P(A|T₁T₂)

代入：
P(A) = (1/2)×1 + (1/2)×(1/2)×0 + (1/2)×(1/2)×P(A)
→ P(A) = 1/2 + (1/4)P(A) → 解得 P(A) = 2/3

---

### 方法7：帕斯卡分赌注博弈分配法

**推导**：游戏每一轮（甲乙各掷 1 次）无人分出胜负的概率为 (1/2)×(1/2) = 1/4。
先手拥有首次行动权，甲乙的博弈权重比等于首次能直接获胜的概率比：
甲首次直接胜率 1/2，乙需要甲先失败才有 (1/2)×(1/2) = 1/4 首次直接胜率，
权重比 w(甲):w(乙) = 1/2 : 1/4 = 2:1 → P = 2/(2+1) = 2/3

## 第二部分：高中概率数列（课内+拓展，6种）

### 方法8：几何分布奇偶筛选法

**推导**：首次出现正面的抛掷次数 X ~ Geom(p=1/2)，分布列 P(X=k) = (1/2)^k。
甲获胜等价于 k 取奇数，令 k = 2m-1：

```text
P = Σ P(X=2m-1) = Σ (1/2)^(2m-1) = (1/2)·Σ (1/4)^m = (1/2) / (1-1/4) = 2/3
```

---

### 方法9：稳态递推数列通项法

**核心思路**：把游戏看作无穷递推的数列——每一轮甲抛掷时的胜率与下一轮甲抛掷时的胜率之间存在递推关系，稳态下两者相等。

**推导**：设 a_n 为「第 n 次轮到甲抛掷时」甲最终获胜的条件概率。注意 a_n 并不要求 n 必须等于 1——只要轮到甲抛掷，游戏状态就完全相同（无记忆性），所以 a_n 与 n 无关，设稳态值为 P。

考察一次完整的甲→乙→甲回合：

甲本轮先手抛掷：

- 概率 1/2 掷出正面 → 甲直接获胜 → 此分支条件胜率 1
- 概率 1/2 掷出反面 → 轮到乙抛掷

乙抛掷时：

- 概率 1/2 掷出正面 → 乙直接获胜，甲落败 → 此子分支条件胜率 0
- 概率 1/2 掷出反面 → 轮到甲（回到初始状态） → 此子分支条件胜率仍为 P

所以：

```text
a_n = (1/2)×1 + (1/2)×[(1/2)×0 + (1/2)×P]
    = 1/2 + (1/4)P
```

由于稳态条件 a_n = P（下一轮甲抛掷的概率与当前轮相同）：

```text
P = 1/2 + P/4 -> 3P/4 = 1/2 -> P = 2/3
```

**对比方法 4**：方法 4 直接从「全局胜率 P」出发列方程，方法 9 从「条件递推 a_n → a_{n+1}」出发再取稳态。两者代数形式完全相同，但方法 9 更显式地展示了无记忆性的运用——即马尔可夫性（后文方法 16/17 将从马尔可夫链视角更系统地处理这一点）。

### 方法10：差分方程稳态求解法

**推导**：设 P=甲先手胜率，Q=乙先手胜率，对称性得 Q=P。
甲先手时：1/2 概率直接获胜；1/2 概率出反面，切换为乙先手，甲后续胜率为 1-Q：
P = (1/2)×1 + (1/2)(1-Q)，代入 Q=P：
P = 1/2 + (1/2)(1-P) → P = 1 - P/2 → 3P/2 = 1 → P = 2/3

### 方法11：概率生成函数奇偶拆分法

**推导**：设 X ~ Geom(p=1/2) 为首次抛得正面的次数，分布列 P(X=k) = (1/2)^k, k=1,2,3,…

概率生成函数（PGF）定义为 G(s) = E[s^X] = Σ_{k=1}^∞ s^k · (1/2)^k。

这是一个等比级数：首项 (s/2)，公比 (s/2)：

```text
G(s) = Σ (s/2)^k = (s/2) / (1 - s/2),   |s| < 2
```

**关键技巧**：我们需要提取奇数项的概率和 P(奇数) = Σ_{m=1}^∞ (1/2)^(2m-1)。

概率生成函数中奇偶项拆分有标准公式：

```text
P(X为奇数) = [G(1) - G(-1)] / 2
P(X为偶数) = [G(1) + G(-1)] / 2
```

验证此公式：G(1) = Σ_{所有k} 1^k·P(X=k) = 1（全概率）
G(-1) = Σ_{所有k} (-1)^k·P(X=k) = Σ_{奇} P(X=k) - Σ_{偶} P(X=k)

所以 G(1) = P(奇) + P(偶) = 1
且 G(-1) = P(奇) - P(偶)

两式相加：G(1)+G(-1) = 2·P(奇)，故 P(奇) = [G(1)+G(-1)]/2…

⚠️ 这里有个细微之处：如果 X 取值从 1 开始（而非 0），奇数/偶数的定义需要统一起点。X=1 为奇数位（甲胜），故我们要的是「奇数次」概率。

以 X=1 为第一项（奇数项起始），奇偶拆分公式变为：

```text
P(X为奇数) = [G(1) - G(-1)] / 2
```

代入计算：

```text
G(1) = (1/2) / (1 - 1/2) = (1/2) / (1/2) = 1
G(-1) = (-1/2) / (1 + 1/2) = (-1/2) / (3/2) = -1/3

P = [1 - (-1/3)] / 2 = (1 + 1/3) / 2 = (4/3) / 2 = 2/3
```

**另一种等价推导**（绕开奇偶起点争议）：

直接构造奇数项 PGF 子级数。令 j = (k-1)/2，当 k=2m-1 为奇数时：

```text
P = Σ_{m=1}^∞ (1/2)^(2m-1) = 1/2 · Σ_{m=1}^∞ (1/4)^(m-1) = 1/2 · 1/(1-1/4) = 2/3
```

**拓展**：概率生成函数还可用于快速验证分布的高阶矩，E[X] = G'(1) = 2（期望 2 次首次出正面），Var[X] = G''(1) + G'(1) - [G'(1)]² = 2。

### 方法12：大数定律频率迭代法

**核心思路**：不直接计算概率，而是思考「如果玩 N 局游戏，每局结果服从什么分布？」，利用大数定律的极限频率推演平衡方程。

**推导**：考虑大量独立重复游戏。大数定律保证：当游戏次数 N → ∞ 时，甲获胜的比例 f_N = (甲胜次数)/N 依概率收敛到 P。

现在思考每局游戏的「第一轮」结果分布。第一轮包含甲掷第一次 + 可能乙掷第一次：

1. **情形A**（概率 1/2）：甲首掷正面 → 甲直接获胜
   - 这种情况占所有游戏的 1/2，甲胜率贡献 = (1/2)·1

2. **情形B**（概率 1/4）：甲掷反面 + 乙掷正面 → 乙直接获胜
   - 这种情况占所有游戏的 1/4，甲胜率贡献 = (1/4)·0

3. **情形C**（概率 1/4）：甲掷反面 + 乙掷反面 → 无人得分，**游戏状态完全重置**
   - 这种情况占所有游戏的 1/4，但后续从甲乙交替抛掷重新开始，甲获胜的**条件概率**就是 P 本身

因此在极限 N → ∞ 下，甲获胜的频率满足：

```text
甲胜场次 = 情形A场次 + 情形C场次中甲胜场次
```

除以 N：

```text
f_N = (1/2) · (1 的极限频率) + (1/4) · (0 的极限频率) + (1/4) · (重置后甲胜的极限频率)
```

由大数定律，当 N→∞ 时 f_N → P（甲胜率整体），而重置子序列中甲胜的极限频率也是 P（因为重置后游戏与原始游戏同分布）。所以：

```text
P = (1/2)·1 + (1/4)·0 + (1/4)·P
  = 1/2 + P/4
```

解得：3P/4 = 1/2 → P = 2/3。

**这个推理的美妙之处**：不需要显式计算级数，纯粹用「频率稳定性」和「重置后的条件同分布」就得到方程。它与方法 4 在代数上等价，但推导视角不同——方法 4 是条件概率演绎，方法 12 是频率极限归纳。

**严谨性注记**：此处隐含使用了强大数定律和遍历性——重置子序列本身是独立同分布的（因为每次重置后游戏相互独立），且重置事件{C}发生概率 > 0，保证了重置子序列的样本量以 N/4 线性增长。

### 方法13：蒙特卡洛数值模拟法

**核心思路**：用计算机生成大量独立游戏样本，通过样本频率估计概率，验证理论结果的数值正确性。

**模拟算法**（多种实现风格）：

**风格1 — 直译游戏逻辑**：

```python
import random

def trial():
    """模拟一局游戏，返回 True 表示甲胜"""
    turn = 0  # 0=甲, 1=乙
    while True:
        if random.random() < 0.5:  # 掷出正面
            return turn == 0      # 甲胜当且仅当当前是甲的回合
        turn = 1 - turn            # 切换回合

N = 1_000_000
jia_wins = sum(1 for _ in range(N) if trial())
P_approx = jia_wins / N
print(f"P(甲胜) ≈ {P_approx:.6f}")  # 期望输出 ≈ 0.666667
```

**风格2 — 用几何分布直接模拟**（高效版）：

```python
import random
import math

N = 1_000_000
jia_wins = 0
for _ in range(N):
    # 首次正面时刻 T ~ Geom(1/2)
    # 模拟方法：连续抛直到正面
    t = 1
    while random.random() >= 0.5:
        t += 1
    if t % 2 == 1:  # 奇数时刻 → 甲抛的
        jia_wins += 1

P_approx = jia_wins / N
```

**收敛分析**：蒙特卡洛估计的方差和收敛速度

每次试验是伯努利随机变量 Y_i = I{甲在第 i 局获胜} ~ Bernoulli(p=2/3)，方差 σ² = p(1-p) = (2/3)(1/3) = 2/9 ≈ 0.222。

估计量 P̂_N = (1/N) Σ Y_i 的方差：

```text
Var[P̂_N] = σ² / N = (2/9) / N
标准差 σ[P̂_N] = √(2/9) / √N ≈ 0.4714 / √N
```

**误差估算**（95% 置信区间 ≈ ±1.96σ）：

| N | 标准差 | 95% 误差幅度 | 典型输出范围 |
|:-:|:------:|:-----------:|:-----------:|

## 第三部分：大学初等概率论（本科低年级，5种）

### 方法14：Doob 鞅 + 可选停时定理（正确构造）

**核心思路**：不构造资金赌博鞅（那只能得到公平博弈的结论），而是构造**条件概率鞅**（Doob 鞅），利用可选停时定理在停时处取值与初始期望相等来求解。

**构造**：令 X₁, X₂, X₃, … 为独立同分布抛掷结果（X_k=1 正面，0 反面）。定义滤流 F_n = σ(X₁, …, X_n) 为前 n 次抛掷生成的信息流。

定义 Doob 鞅：

```text
M_n = E[ I{甲胜} | F_n ]
```

即 M_n 是在已知前 n 次抛掷结果条件下甲最终获胜的条件概率。M_n 是 L¹ 有界鞅（因为值域 [0,1]），由 Doob 鞅构造定理保证。

**停时**：T = min{ k ≥ 1 : X_k = 1 }，即首次出现正面的时刻。

**可选停时定理的适用性**：

- M_n 是闭鞅（M_∞ = I{甲胜} 存在，且 M_n = E[M_∞ | F_n]）
- T 是停时，且 P(T < ∞) = 1（几乎必然有限，因为几何分布）
- E[|M_T|] ≤ 1 < ∞，且 lim_{n→∞} E[|M_n|·I{T>n}] = 0（控制条件满足）

因此可选停时定理适用：E[M_T] = E[M_0]。

**停时处的取值**：在 T 时刻，我们已经观察到了首次正面出现的位置：

- 若 T 为奇数（1, 3, 5, …）：首次正面在甲轮次，事件{甲胜}已确定，M_T = 1
- 若 T 为偶数（2, 4, 6, …）：首次正面在乙轮次，事件{甲胜}已确定，M_T = 0

所以：

```text
E[M_T] = 1 · P(T为奇数) + 0 · P(T为偶数) = P(T为奇数)
```

**而** E[M_0] = E[ I{甲胜} ] = P(甲胜)，因为 M_0 = E[ I{甲胜} | F_0 ] = E[ I{甲胜} ] = P(甲胜)。

由可选停时定理 E[M_T] = E[M_0]：

```text
P(甲胜) = P(T为奇数)
```

**问题转化**：T ~ Geom(p=1/2)，现在只需计算几何分布变量取奇数的概率：

```text
P(T为奇数) = Σ_{m=1}^∞ (1/2)^(2m-1)
          = 1/2 + 1/8 + 1/32 + 1/128 + …
          = (1/2) / (1 - 1/4)
          = 2/3
```

因此 P(甲胜) = 2/3。 ✅

**与原版推导的关键区别**：

- 原版构造简单资金鞅（每轮 ±1 公平下注），可选停时会给出 P=1/2 的悖论——因为该鞅未能编码「谁先手谁赢」的博弈结构
- Doob 条件概率鞅直接编码了「在给定信息下甲获胜的信念更新过程」，停时自然反映首次正面位置，逻辑无漏洞

**验证其他停时间的鞅特性**：如果定义停时 T' = min{ k : M_k 达到 0 或 1 }，同样可得到一致结果。Doob 鞅方法在随机过程理论中价值在于：它可以用统一框架处理更一般的停时问题（如不对称硬币、多玩家等）。

### 方法15：双向鞅边界分析法

**核心思路**：分别构造「甲获胜条件概率鞅」和「乙获胜条件概率鞅」，利用两者之和为 1 的约束，通过两个可选停时方程联立求解，不需要事先假设对称性。

**构造**：

- 甲鞅：M_n^(甲) = E[ I{甲胜} | F_n ]，初始值 M_0^(甲) = P(甲胜) = p
- 乙鞅：M_n^(乙) = E[ I{乙胜} | F_n ]，初始值 M_0^(乙) = P(乙胜) = 1-p

由定义，在任何 n 下 M_n^(甲) + M_n^(乙) = 1（给定信息下甲胜与乙胜条件概率之和恒为 1）。

**停时**：仍取 T = min{ k ≥ 1 : X_k = 1 }。

在停时 T 处，双方取值由首次正面位置决定：

```text
T 为奇数 -> M_T^(甲) = 1,  M_T^(乙) = 0
T 为偶数 -> M_T^(甲) = 0,  M_T^(乙) = 1
```

分别应用可选停时定理：

```text
E[M_T^(甲)] = M_0^(甲) = p
E[M_T^(乙)] = M_0^(乙) = 1-p
```

计算停时期望：

```text
E[M_T^(甲)] = 1 · P(T奇) + 0 · P(T偶) = P(T奇) = p
E[M_T^(乙)] = 0 · P(T奇) + 1 · P(T偶) = P(T偶) = 1-p
```

**两个方程相互独立但一致**，都给出了：

```text
p = P(T奇),   1-p = P(T偶)
```

这与方法 14 结果一致。要解出 p，仍需计算 P(T奇)——即几何分布奇数项概率：

```text
P(T奇) = Σ (1/2)^(2m-1) = 2/3
```

因此 p = 2/3。

**双向法优势**：当游戏不对称（如非公平硬币、玩家能力不同）时，分别构造两个鞅比单个鞅更灵活——可以利用 M^(甲) + M^(乙) = 1 这一恒等式作为额外约束来求解更复杂的停时间题。

### 方法16：两状态马尔可夫链稳态法

**推导**：状态定义：S₀=轮到甲抛掷；S₁=轮到乙抛掷；吸收态 A（甲胜）、B（乙胜）
转移矩阵：S₀→A 概率 1/2，S₀→S₁ 概率 1/2；S₁→B 概率 1/2，S₁→S₀ 概率 1/2。
设 u₀ 为 S₀ 下甲最终胜率，u₁ 为 S₁ 下甲最终胜率：

```text
u₀ = (1/2)·1 + (1/2)u₁
u₁ = (1/2)·0 + (1/2)u₀
```

代入 u₁ = u₀/2，得 u₀ = 1/2 + (1/2)·(u₀/2) → u₀ = 2/3。

### 方法17：吸收马尔可夫链吸收概率法

**推导**：把甲胜 A、乙胜 B 作为吸收态，非吸收态 S₀（甲回合）、S₁（乙回合）。
吸收概率方程组：

```text
P(A|S₀) = (1/2)·1 + (1/2)P(A|S₁)
P(A|S₁) = (1/2)·0 + (1/2)P(A|S₀)
```

求解得 P(A|S₀) = 2/3，即初始 S₀ 时甲胜率。

### 方法18：重期望迭代条件期望法

**推导**：用重期望公式 E[P|初始状态] = E[E[P|前两次抛掷结果]]
前两次结果分 3 类：

1. 甲首正（1/2）：甲必胜，条件胜率 1
2. 甲反乙正（1/4）：甲必败，条件胜率 0
3. 甲反乙反（1/4）：回到初始状态，条件胜率 P

P = (1/2)×1 + (1/4)×0 + (1/4)×P → 解得 P = 2/3

### 方法21：复平面母函数围道积分法

**核心思路**：利用复分析中的柯西积分公式提取幂级数的奇次项系数和。

概率母函数 G(s) = Σ_{k=1}^∞ P(X=k) s^k = Σ (s/2)^k = (s/2) / (1 - s/2)。

我们要提取的是 Σ_{k为奇数} P(X=k)，即 s 的奇次幂系数之和。

**提取奇数项的标准复分析公式**：

```text
Σ_{k为奇数} a_k = (1/2) · [G(1) + G(-1)]
```

但这是针对 k 从 0 开始的幂级数 G(s) = Σ a_k s^k。如果 G(s) 从 k=1 开始，需要调整。

使用围道积分视角：系数 a_k 可由柯西积分公式得到：

```text
a_k = (1/2πi) ∮_C G(s) / s^(k+1) ds
```

其中 C 是包含原点且位于收敛圆 |s| < 2 内的正向简单闭曲线。

奇次项系数和：

```text
Σ_{奇数k} a_k = Σ_{m=1}^∞ a_{2m-1}
              = Σ_{m=1}^∞ (1/2πi) ∮ G(s) / s^(2m) ds
              = (1/2πi) ∮ [G(s)/s²] · [Σ_{m=1}^∞ (1/s²)^(m-1)] ds
              = (1/2πi) ∮ [G(s)/s²] · [1/(1 - 1/s²)] ds
              = (1/2πi) ∮ G(s) / (s² - 1) ds
```

代入 G(s) = (s/2)/(1 - s/2)：

```text
Σ_{奇数} = (1/2πi) ∮_C (s/2) / [(1 - s/2)(s² - 1)] ds
```

这个被积函数在 C 内部有奇点。围道 C 取半径为 1 的圆 |s|=1（仅包含 s=-1 一个极点，s=1、s=2 在圆外）。

计算留数：
被积函数在 s=-1 处有一阶极点。计算 Res(s=-1)：

```text
Res(s=-1) = lim_{s->-1} (s+1) · (s/2) / [(1 - s/2)(s-1)(s+1)]
          = lim_{s->-1} (s/2) / [(1 - s/2)(s-1)]
          = (-1/2) / [(1 + 1/2)(-2)]
          = (-1/2) / [(3/2)(-2)]
          = (-1/2) / (-3)
          = 1/6
```

由留数定理：

```text
Σ_{奇数} = (1/2πi) · 2πi · (1/6) = 1/6
```

⚠️ 等等——1/6 ≠ 2/3。这里发生了什么？分析发现：递推求和公式在变换过程中丢失了首项因子。

**正确的直接推导**（避免围道变换引入误差）：

直接对级数用复平面几何级数公式：

```text
P = Σ_{m=1}^∞ (1/2)^(2m-1) = (1/2) · Σ_{m=1}^∞ (1/4)^(m-1)
```

将求和视为复函数在 z=1/4 处的值的特例：

```text
定义 f(z) = Σ_{m=0}^∞ z^m = 1/(1-z),  |z|<1
则 Σ_{m=1}^∞ (1/4)^(m-1) = f(1/4) = 1/(1-1/4) = 4/3

P = (1/2) · (4/3) = 2/3
```

**留数法校验**（用正确的围道）：不需要复杂围道，直接构造母函数奇偶拆分：

```text
P(奇) = [G(1) + G(-1)] / 2  （当 k 从 0 开始编号）
    或  [G(1) - G(-1)] / 2  （当 k 从 1 开始编号，当前场景）
```

代入 G(1)=1, G(-1)=-1/3：

```text
P = [1 - (-1/3)] / 2 = (4/3)/2 = 2/3
```

**复分析方法在概率论中的价值**不在于解决本问题（等比级数足矣），而在于推广性：当概率分布不是简单的几何分布、系数由更复杂的递推给出时，围道积分法是提取任意子序列系数的系统化工具。

### 方法22：Z变换递推求解法

**核心思路**：将序列 p_k（甲在第 k 次抛掷获胜的概率）的递推关系通过 Z 变换转化为代数方程，求解后逆变换得到闭合形式，再求总和。

**构造序列**：
甲只有在奇数轮次抛掷正面才能获胜，故：

```text
p_k = P(在第k次获胜)
    = (1/2)^k  (当k为奇数, 即前k-1次全反面)
    = 0        (当k为偶数, 乙的回合)
```

序列的前几项：p₁=1/2, p₂=0, p₃=1/8, p₄=0, p₅=1/32, …

这个序列满足一阶齐次递推（注意因为偶数项为 0，非零项每两步出现一次，实际是二阶索引内的递推）：

```text
pₖ = (1/4) · p_(k-2),  k ≥ 3
```

**Z 变换**：定义双边 Z 变换 P(z) = Σ_{k=1}^∞ p_k z^{-k}。

对递推式两边取 Z 变换（注意延迟定理 Z[p_{k-2}] = z^{-2}P(z)）：

```text
Σ_{k=3}^∞ p_k z^{-k} = (1/4) Σ_{k=3}^∞ p_{k-2} z^{-k}
P(z) - p₁z^{-1} - p₂z^{-2} = (1/4) z^{-2} P(z)
```

代入 p₁=1/2, p₂=0：

```text
P(z) - (1/2)z^{-1} = (1/4)z^{-2}P(z)
P(z) [1 - z^{-2}/4] = (1/2)z^{-1}
P(z) = (1/2)z^{-1} / (1 - z^{-2}/4)
     = (z/2) / (z² - 1/4)
     = (z/2) / [(z - 1/2)(z + 1/2)]
```

**部分分式展开**进行逆变换：

```text
P(z)/z = (1/2) / [(z - 1/2)(z + 1/2)]
       = A/(z - 1/2) + B/(z + 1/2)

A = lim_{z->1/2} (z - 1/2) · (1/2)/[(z - 1/2)(z + 1/2)] = (1/2) / (1) = 1/2
B = lim_{z->-1/2} (z + 1/2) · (1/2)/[(z - 1/2)(z + 1/2)] = (1/2) / (-1) = -1/2

所以 P(z) = (1/2)z/(z - 1/2) - (1/2)z/(z + 1/2)
```

查标准 Z 变换表：Z^{-1}[z/(z - a)] = a^k u[k]，得到：

```text
p_k = (1/2)·(1/2)^k - (1/2)·(-1/2)^k
    = (1/2)^{k+1} - (1/2)·(-1/2)^k
```

**验证**：

- k=1: p₁ = (1/2)² - (1/2)·(-1/2) = 1/4 + 1/4 = 1/2 ✅
- k=2: p₂ = (1/2)³ - (1/2)·(1/4) = 1/8 - 1/8 = 0 ✅
- k=3: p₃ = (1/2)⁴ - (1/2)·(-1/8) = 1/16 + 1/16 = 1/8 ✅

**求总概率**——对所有 k 求和：

```text
P = Σ_{k=1}^∞ p_k
  = Σ [(1/2)^{k+1} - (1/2)·(-1/2)^k]
  = (1/2)Σ (1/2)^k - (1/2)Σ (-1/2)^k
  = (1/2)·[(1/2)/(1-1/2)] - (1/2)·[(-1/2)/(1+1/2)]
  = (1/2)·(1) - (1/2)·(-1/3)
  = 1/2 + 1/6
  = 2/3
```

Z 变换法在信号处理和控制系统中有广泛延伸——序列的递推关系对应系统的脉冲响应，概率求和对应系统的稳态增益。

### 方法25：有限截断近似法

**核心思路**：无穷级数在实际计算中必须截断，分析截断误差可以评估「用多少轮就够了」。

**截断公式推导**：将游戏限制为最多 2N 轮（即 N 个完整回合，甲乙各 N 次），超时仍未出结果则视为平局（或重新开始）。甲在截断内的获胜概率是前 N 个奇数位求和：

```text
S_N = Σ_{m=1}^N (1/2)^(2m-1)
    = (1/2) + (1/2)^3 + (1/2)^5 + … + (1/2)^(2N-1)
```

这是一个有限等比级数，首项 a=1/2，公比 r=1/4，项数 N：

```text
S_N = a · (1 - r^N) / (1 - r)
    = (1/2) · [1 - (1/4)^N] / (1 - 1/4)
    = (1/2) · [1 - (1/4)^N] / (3/4)
    = (1/2) · (4/3) · [1 - (1/4)^N]
    = (2/3) · [1 - (1/4)^N]
```

**截断误差**：截断丢弃的尾部是无穷级数的剩余部分：

```text
E_N = P - S_N = (2/3) · (1/4)^N
```

**数值对比**：

| N（完整回合数） | 2N（总轮数） | S_N（累积概率） | 截断误差 E_N | 误差指数 |
|:--------------:|:-----------:|:---------------:|:------------:|:--------:|
| 1 | 2 | 0.5 | 0.166667 | 1.7×10⁻¹ |
| 2 | 4 | 0.625 | 0.041667 | 4.2×10⁻² |
| 3 | 6 | 0.65625 | 0.010417 | 1.0×10⁻² |
| 4 | 8 | 0.6640625 | 0.002604 | 2.6×10⁻³ |
| 5 | 10 | 0.6660156 | 0.000651 | 6.5×10⁻⁴ |
| 10 | 20 | 0.6666660 | 1.65×10⁻⁶ | 1.7×10⁻⁶ |
| 20 | 40 | 0.6666667 | 2.8×10⁻¹² | 2.8×10⁻¹² |

**关键观察**：

- N=5（最多抛 10 次）时 S₅ ≈ 0.666016，误差 0.065%，对大部分工程应用已足够
- N=10（最多抛 20 次）时误差 < 2×10⁻⁶，达到 6 个 9 精度
- 截断误差以公比 1/4 指数衰减——每增加一个回合（2 轮），误差减小至 1/4
- 要误差 < ε，需要 N > log(2/(3ε)) / log(4)

这解释了为什么前几轮占了大部分概率：首轮甲直接胜（50%），三轮内甲胜概率已 62.5%，五轮内 65.6%。

### 方法26：递推数值迭代法

**核心思路**：将方法 4 的递推方程 P = 1/2 + P/4 转化为迭代格式 P_(k+1) = 1/2 + (1/4)P_k，从任意初值出发，观察序列收敛到不动点的过程。

**迭代格式**：

```text
P_(k+1) = F(P_k) = 1/2 + (1/4)P_k,   P₀ = 0（或其他初值）
```

**数列的显式通项公式**（可以避开逐次迭代直接计算任意步的值）：

递推式 P_(k+1) = 1/2 + (1/4)P_k 是一阶线性非齐次递推。先求通解：

- 齐次解：P_k^(h) = C·(1/4)^k
- 特解（不动点）：令 P*= 1/2 + P*/4 → P* = 2/3

通解 = 齐次解 + 特解：

```text
P_k = C·(1/4)^k + 2/3
```

代入初始条件 P₀ = 0：

```text
0 = C·(1/4)^0 + 2/3 -> C = -2/3
```

所以：

```text
P_k = 2/3 · [1 - (1/4)^k]
```

**迭代序列展开**：

```text
P₀ = 0
P₁ = 1/2                                                                         = 0.5
P₂ = 1/2 + (1/4)·(1/2)                                                          = 0.625
P₃ = 1/2 + (1/4)·(1/2 + 1/8)                                                   = 0.65625
P₄ = 1/2 + (1/4)·(1/2 + 1/8 + 1/32)                                            = 0.6640625
P₅ = 1/2 + (1/4)·(1/2 + 1/8 + 1/32 + 1/128)                                   = 0.6660156
P₆ = 1/2 + (1/4)·(1/2 + 1/8 + 1/32 + 1/128 + 1/512)                            = 0.6665039
P₇ = 1/2 + (1/4)·(1/2 + 1/8 + 1/32 + 1/128 + 1/512 + 1/2048)                   = 0.6666260
P₈ = 1/2 + (1/4)·(1/2 + 1/8 + 1/32 + 1/128 + 1/512 + 1/2048 + 1/8192)         = 0.6666565
```

用通项公式快速计算：

- P₃ = (2/3)·[1 - 1/64] ≈ 0.666667·0.984375 = 0.65625
- P₁₀ = (2/3)·[1 - 1/4¹⁰] = (2/3)·[1 - 1/1,048,576] ≈ 0.66666603

**收敛速度分析**：

误差序列 e_k = P* - P_k = (2/3)·(1/4)^k 以指数 1/4 衰减：

- 每步迭代误差缩小至前一步的 1/4
- 达到 ε 精度所需步数：k > log(2/(3ε)) / log(4)

| 步数 k | 误差 e_k | 相对精度 |
|:------:|:--------:|:--------:|
| 0 | 0.666667 | 0 位小数 |
| 1 | 0.166667 | 0位 |
| 2 | 0.041667 | 1位 |
| 3 | 0.010417 | 2位 |
| 4 | 0.002604 | 2~3位 |
| 5 | 0.000651 | 3位 |
| 10 | 1.65×10⁻⁶ | 5~6位 |
| 20 | 2.8×10⁻¹² | 11~12位 |

**压缩映射原理**：
F(x) = 1/2 + x/4 是 [0,1] 上的压缩映射，Lipschitz 常数为 1/4：

```text
|F(x) - F(y)| = (1/4)|x - y|
```

由巴拿赫不动点定理，迭代从任意初值出发都会收敛到唯一不动点 P* = 2/3，收敛速度为线性（几何衰减），收敛因子为 1/4。这是压缩映射产生线性收敛的标准速率。

**与蒙特卡洛的对比**：

- 迭代法：10 步达到 10⁻⁶ 精度
- 蒙特卡洛：需要 10¹² 次模拟才能达到 10⁻⁶ 精度（因 O(1/√N) 收敛）

迭代法的高效性本质上是因为它利用了问题的**解析结构**——递推方程，而蒙特卡洛没有利用任何结构信息。

### 2. 各方法的深层联系

**所有 26 种方法共享同一个数学底层**：它们都是「首次正面出现在奇数位置的概率」这一命题在不同数学语言下的等价表达。各方法之间的本质差异不在于「得到了不同的结论」，而在于**把问题翻译成什么数学结构来处理**。

**关键联系图谱**：


**三种最本质的视角**：

1. **级数视角**（方法 1,2,3）：最直接的翻译——把甲胜分解成互斥路径，每条路径的概率是 1/2 的幂，问题化为等比级数求和
2. **方程视角**（方法 4,5,6,9,10,12,16,17,18,23,24,26）：利用无记忆性（马尔可夫性），把概率本身作为未知数列方程直接求解，避免显式计算无穷级数
3. **变换视角**（方法 11,21,22）：利用概率生成函数/Z 变换/复分析作为工具，把级数求和转化为代数运算或围道积分

**同一方法的多个面孔**：以「P = 1/2 + P/4」这个方程为例，它出现在：

- 方法 4（状态递推）：P = (1/2)×1 + [1/2]((1/2)×0 + (1/2)P)
- 方法 12（大数频率）：P = (1/2)·1 + (1/4)·0 + (1/4)P
- 方法 18（重期望）：P = (1/2)×1 + (1/4)×0 + (1/4)P
- 方法 24（不动点）：F(x) = 1/2 + x/4, F(x) = x

它们本质上推导了同一个方程，只是解释不同。

### 3. 方法之间可相互推导

这表明 26 种方法并非孤立存在，而是形成了完整的知识网络：

- 方法 1 的等比级数 = 方法 8 几何分布奇数项求和 = 方法 25 截断公式的极限
- 方法 4 的递推方程 = 方法 9 稳态数列 = 方法 18 重期望 = 方法 24 不动点
- 方法 5 的对立事件方程 = 方法 10 差分方程，都利用了甲/乙对称性
- 方法 11 的 PGF 奇偶拆分等价于方法 22 的 Z 变换（两者本质都是离散信号的频域分析）
- 方法 14 的 Doob 鞅将问题转化为 P = P(T为奇数)，与方法 8 的几何分布奇数项概率完全相同
- 方法 25 的截断误差 (2/3)(1/4)^N = 方法 26 的迭代误差 (2/3)(1/4)^k，两个序列完全一致（截断位置 N = 迭代步数 k）

### 5. 共性结论

所有方法的底层都是 **「首次正面出现在奇数位置的概率求解」**，只是用不同数学工具实现计算；公平硬币下先手优势固定，胜率恒为 **2/3**，乙胜率 **1/3**。
