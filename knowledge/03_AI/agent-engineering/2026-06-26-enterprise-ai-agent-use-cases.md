## 真正赚到钱（已大规模生产落地）的四个场景

### 1️⃣ 财务对账与发票处理 — ROI 最扎实

| 维度 | 详情 |
|:-----|:------|
| **原理** | OCR + 大模型读发票 → 三单匹配（发票/采购单/入库单）→ 日记账分录 → 标异常 |
| **自动化率** | 标准发票 85%–92%（Aberdeen Group） |
| **市场增长** | 财务 AI Agent 市场 2025→2026：$82.9亿→$120.6亿（+45.5%） |
| **首年 ROI** | 普遍 3–6 倍 |
| **成功原因** | 边界清晰的结构化任务：输入格式有限、输出规则明确、有校验机制兜底 |
| **关键洞察** | 不是 AI 多聪明，而是这个任务本来就不该由人做（59% 会计因超负荷每月犯错） |

### 2️⃣ 营销外联与个性化触达 — Agent 当 SDR

| 维度 | 详情 |
|:-----|:------|
| **案例 1** | JPMorgan × Persado：AI 生成营销邮件，点击率提升 450%，五年合约，内部已跑 450+ AI 用例 |
| **案例 2** | ColdIQ（Jazon）：自动筛选潜客、生成外联邮件、更新 CRM、预约会议 |
| **ROI** | 十几个月内收入数倍增长 |
| **成功原因** | 容错率天然高——邮件写得不好最坏结果没人点，不会有人起诉 |

### 3️⃣ 供应链动态调度 — 多 Agent 协作最佳战场

| 维度 | 详情 |
|:-----|:------|
| **沃尔玛** | AI Agent 路线优化：减少 3,000 万英里驾驶里程、节省 9,400 万磅 CO₂ |
| **亚马逊** | 多智能体分析购物车、预测需求、监控运输异常、自动补货 |
| **盒马鲜生** | "AI 买手"：分析购物行为+季节趋势+库存周转，自主调整选品定价，客单价 +27%，损耗率 -18% |
| **成功原因** | 决策链条长但每个节点决策空间有限——规则+数据驱动，Agent 是"永不疲倦的调度员" |

### 4️⃣ 工业预测性维护 — 老师傅经验→代码

| 维度 | 详情 |
|:-----|:------|
| **GE** | Agent 实时采集震动/温度等数据，预测故障提前报警，已跑数年 |
| **百度 AI 炼钢** | Agent 结合历史最佳工艺参数，实时分析炉况，自主给出加料指令，工人"一键操作"，效率 +20% |
| **打破误解** | AI Agent 不止处理数字世界任务——炼钢这种最传统的工业场景也能落地 |
| **关键** | 老师傅经验能否被编码为规则和数据 |

## 成功规律的共同特征

```text
                   有边界结构化工作流 <- <- <- 成功
                   +------------------------+
成功场景           | 输入可枚举              | 失败场景（全自主客服）
                   | 输出可校验              | -- 输入无边界
财务对账           | 错误可兜底              | -- 输出涉及金钱
营销外联           | 容错空间中高            | -- 错误不可逆
供应链调度         |                        | -- 容错空间极低
工业维护           +------------------------+
```

## 最该落地却流血最多的场景：全自主端到端客服

### Klarna：一个价值 $4,000 万的教训

| 时间 | 事件 |
|:-----|:------|
| 2024 | 高调宣布 AI 替代 ~700 客服，月处理 230 万对话，预计年省 $4,000 万 |
| 2025.05 | 悄悄重新招聘人类客服（Bloomberg/Forbes 报道） |
| 结论 | CEO 承认："当成本优化成为主导标准时，你最终得到的是更低的质量" |

**根因四重奏**：

#### 根因一：成本黑洞

| 案例 | 详情 |
|:-----|:------|
| **某美妆电商** | Agent 替代 50 名夜间客服，理论年省 1,000 万 RMB，首周 API 账单 27 万 RMB——成本追平人工 |
| **Uber** | 2025.12 部署 Claude Code 给 5,000 工程师，2026.04 全年 AI 预算烧光，单人月均 API $1,000–$2,000 |
| **斯坦福研究** | 重复发送的上下文占 Agent 推理账单的 62% |

#### 根因二：黑盒决策的公关炸弹

**Chevrolet 事件**（2023.11）：用户用 prompt injection 诱导 AI 聊天机器人"同意"以 $1 出售 $76,000 的汽车。授权执行金钱操作时，prompt injection 不再是笑话，而是真实资金风险。

#### 根因三：遗留系统"易碎工具链"

客服 Agent 需打通 ERP/CRM/支付/仓储等系统。内部老旧系统缺乏标准 API，Tool-calling 遇到网络抖动/超时就陷入无限重试死循环。Diagrid 研究：工作流因缺乏持久性重启时，之前花的每个 Token 都要重新花。

#### 根因四：人类语言复杂性

"退那个防晒霜…哦算了，退昨天买的眼霜，顺便改另一个订单的地址到公司，19 点前到，不然投诉"——一句话包含 5 个子任务（含中途取消），当前顶尖 LLM 也无法保证 100% 正确拆解执行。

## 给想落地 Agent 的三句话

### 第一句：放弃"全自主超级智能体"的幻想

> Klarna $4,000 万的教训。从 Human-in-the-loop 做起，Agent 处理 60–70% 简单任务，复杂决策留给人。

### 第二句：用小模型干脏活，用大模型干难活

> 高难度意图识别 → GPT-4o/Claude；普通格式提取/参数校验 → 小模型/确定性代码。可将 Token 成本降低 75%+。

### 第三句：先改系统，再上 Agent

> 拥抱 MCP 等标准化协议，先把工具链修结实。百度能在炼钢场景落地，不是大模型能炼钢，而是工艺参数和控制指令做成了标准化接口。

## 核心洞察

> **AI Agent 是面镜子，照出的是业务流程到底有多混乱。那些 Agent 落地成功的企业，不是因为它们的 AI 更强，而是因为它们的流程本来就更清晰。**
