## 一、什么是 AI 知识库

AI 知识库（Knowledge Base）是企业将**结构化/非结构化知识**经过采集、清洗、分块、向量化后，通过 RAG（检索增强生成）技术为大模型提供外部知识支撑的系统。它解决了通用大模型缺乏企业私有知识、产生"幻觉"的核心问题。

### 与传统知识库的对比

| 维度 | 传统知识库 | AI 知识库 |
|:-----|:-----------|:----------|
| 检索方式 | 关键词匹配、目录浏览 | 语义向量检索 + 关键词混合 |
| 交互方式 | 搜索→查看文档 | 自然语言问答 → 结构化回答 |
| 知识更新 | 手动编辑维护 | 自动解析 + 增量更新 |
| 理解深度 | 文档级检索 | 段落级语义理解 + 跨文档关联 |
| 输出形式 | 文件列表/文档内容 | 精炼回答 + 来源引用 |

## 二、RAG 技术原理

RAG（Retrieval-Augmented Generation）是 AI 知识库的核心技术路径。

### RAG 标准流程

```text
用户提问
    |
    v
+-------------+    +--------------+
| 查询理解      | ->  | 向量检索      |
| (意图识别)    |    | (相似度Top-K) |
+-------------+    +------+-------+
                          | 检索结果
                          v
+-------------+    +--------------+
| Prompt 组装  | <-  | 知识上下文    |
| (指令+知识)  |    | (原始文档片段)|
+------+------+    +--------------+
       |
       v
+-------------+
| LLM 生成     | -> 结构化回答
| (带来源引用) |
+-------------+
```

### 关键步骤

1. **知识入库**：文档解析 → 分块（Chunking）→ 向量化嵌入（Embedding）→ 存入向量库
2. **检索**：用户问题向量化 → 向量库相似度检索（Top-K）→ Rerank 重排序
3. **生成**：检索片段 + 用户问题 → 组装 Prompt → LLM 生成带有引用来源的回答

### 混合检索策略

| 模式 | 原理 | 适用场景 |
|:-----|:------|:---------|
| 纯向量检索 | 语义相似度匹配 | 抽象概念、意图模糊的查询 |
| 纯关键词检索 | BM25/TF-IDF 精确匹配 | 专有名词、代码片段、编号 |
| 混合检索 | 向量(0.7) + 关键词(0.3) 加权融合 | **推荐通用方案** |
| 多路召回 | 多维度检索后 RRF 算法融合 | 高精度要求场景 |

## 四、高效构建 AI 知识库方法论（四步法）

### 第一步：前期规划

- **划定知识范围**：区分结构化（规章/表格/参数）、非结构化（手册/纪要/PDF）
- **定义使用场景**：智能问答 / 文档检索 / 代码咨询 / 客服支撑
- **制定规范标准**：统一文档格式、命名规则、术语词典

### 第二步：数据采集与预处理

```text
多源接入 -> 清洗去重 -> 脱敏处理 -> 语义纠错 -> 分块拆分
```

- **分块策略**：语义分块（首选）> 固定长度分块
  - 技术文档建议 1024-2048 字符，重叠 10%-20%
  - 概念/Q&A 等短文本使用 256-512 字符
- **格式优先**：Markdown 为最佳格式，PDF 使用 MinerU 解析

### 第三步：向量化与检索配置

- **嵌入模型**：通用场景用开源模型，专业领域用领域微调模型
- **向量库**：Milvus（分布式）/ Qdrant / Chroma（轻量）/ pgvector
- **检索策略**：混合检索（向量+关键词）+ Rerank 重排序

### 第四步：运营迭代

- **定期更新**：定时批量 + 增量实时
- **效果评估**：准确率/召回率/F1 值 + 用户采纳率
- **反馈闭环**：用户反馈 → 问题分析 → 规则优化 → 知识更新

## 五、常见误区

| 误区 | 纠正 |
|:-----|:------|
| "知识库建好就能用" | 数据质量决定效果，清洗和分块是核心 |
| "向量检索就够了" | 纯向量丢失精确匹配，混合检索更优 |
| "越多越好" | 信息密度低、噪声大的知识反而污染检索结果 |
| "AI 能完全替代人工维护" | AI 辅助清洗，人工审核监督不可缺 |
| "知识库一次性投入" | 知识有时效性，需持续运营迭代 |
