## 📊 定位与说明

### 本目录是什么

discover 目录是知识库的**上游素材库**和**信息发现层**，汇集了从各种渠道获取的原始素材、AI生成笔记、问答系统导出、网页归档等内容。这些内容经过提炼、加工、结构化后，会迁移到正式的 `knowledge/` 目录中。

### 内容来源

| 来源类型 | 说明 |
|:---------|:-----|
| 🤖 **问答系统导出** | 豆包等AI对话系统的问答记录导出 |
| 📝 **AI生成笔记** | AI辅助生成的知识卡片、研究摘要 |
| 🌐 **网页文章归档** | 行业资讯、技术博客、研究报告存档 |
| 📑 **研究报告** | 专题研究汇总、数据分析报告 |

### 与 knowledge/ 的关系

```
discover/                knowledge/
┌─────────────┐         ┌─────────────┐
│  原始素材    │  提炼    │  结构化知识  │
│  AI生成笔记  │ ──────→ │  体系化整理  │
│  网页归档    │  加工    │  经过验证    │
│  问答记录    │         │  可直接使用  │
└─────────────┘         └─────────────┘
```

**使用方式**：
1. 在 discover 中快速浏览和发现有价值的信息
2. 将有价值的内容提炼、整理、验证
3. 迁移到 knowledge/ 对应分类中作为正式知识

## 📁 各子目录详细说明

### 📚 newwiki/ — 问答系统结构化知识

- **文件数量**: 23个主题文件
- **内容性质**: 从问答系统导出的知识，按主题整理的结构化文档
- **典型内容**:
  - AI技术栈全解析（Agent、大模型、伦理、应用、编程工具）
  - 基础设施（服务器硬件、数据中心、网络运维、存储）
  - 企业与职业（管理运营、职业发展、行业趋势）
  - 技术方法论（选型对比、工具方法）
- **特点**: 结构清晰、主题明确，适合系统性学习

### 🃏 newwiki2/ — AI生成知识卡片

- **文件数量**: 33个分类，约500篇
- **内容性质**: AI辅助生成的轻量化知识卡片，覆盖广泛
- **典型内容**:
  - 技术概念解释和对比
  - 产品和工具介绍
  - 行业动态速览
  - 学习笔记和思考
- **特点**: 内容丰富、更新快，适合快速浏览和发现

### 🌐 site/ — 网页文章归档

- **文件数量**: 约500篇，11个分类
- **内容性质**: 从网页抓取/收藏的文章归档
- **典型内容**:
  - AI与机器学习领域资讯
  - 云计算和技术趋势
  - 产品设计和开发实践
  - 行业动态和商业分析
  - 编程技术和数据库
- **特点**: 时效性强、来源广泛，适合了解行业动态

### 📊 root/ — 研究报告与汇总文档

- **文件数量**: 18篇报告
- **内容性质**: 专题研究报告、数据汇总分析
- **典型内容**:
  - 知识图谱与知识体系分析
  - 问题提取与分类汇总报告

  - Wiki内容摘要
- **特点**: 系统性强、有数据支撑，适合深度研究

## 🛤️ 推荐使用路径

### 路径A：快速发现

> 适合：想快速了解某个领域有什么内容

```
newwiki/ 主题总览
    ↓
选择感兴趣的主题
    ↓
深入 newwiki2/ 对应分类
    ↓
发现有价值的内容 → 迁移到 knowledge/
```

**操作步骤**：
1. 从 [`newwiki/`](newwiki/) 的23个主题入手，快速浏览
2. 找到感兴趣的领域后，进入 [`newwiki2/`](newwiki2/) 对应分类查看更多卡片
3. 将高质量内容整理提炼后迁移到正式知识库

### 路径B：深度研究

> 适合：需要对某个专题进行深入研究

```
root/ 研究报告
    ↓
了解整体框架和核心发现
    ↓
newwiki2/ 知识卡片补充细节
    ↓
site/ 行业动态验证时效性
    ↓
形成完整认知 → 输出到 knowledge/
```

**操作步骤**：
1. 从 [`root/`](root/) 的研究报告入手，建立宏观认知
2. 用 [`newwiki2/`](newwiki2/) 的知识卡片补充具体知识点
3. 用 [`site/`](site/) 的文章验证和补充最新动态
4. 整合后形成结构化知识，迁移到 knowledge/

### 路径C：资讯浏览

> 适合：了解行业最新动态和趋势

```
site/ 行业动态 / AI与机器学习
    ↓
浏览近期文章
    ↓
发现感兴趣的方向
    ↓
深入 newwiki/ 或 newwiki2/ 系统学习
```

**操作步骤**：
1. 从 [`site/`](site/) 的行业动态和AI与机器学习分类入手
2. 浏览近期文章，把握行业脉搏
3. 发现感兴趣的方向后，到 newwiki/ 或 newwiki2/ 系统学习
